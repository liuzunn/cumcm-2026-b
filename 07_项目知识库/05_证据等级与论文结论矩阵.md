# 05 · 证据等级与论文结论矩阵

> **本文件裁定：哪条结论能写、能写多强、必须加什么限定。**
> 与任何其他文件冲突时，以**更高优先级的原始来源**为准，并以本矩阵的裁定为准。

---

## 一、五级证据定义（项目强制口径）

| 等级 | 名称 | 定义 | 可写位置 |
|---|---|---|---|
| **A** | 官方真实证据 | 官方模拟器产生，可在官方产物（`.result.json` / `.jlog` / 统计队列）复核 | 「官方验证」小节；**必须标注 n** |
| **B** | 离线 Mock / 实验 | 自建 mock 或离线数值实验 | 「仿真实验」小节；**必须显式标注「自建仿真，非官方」** |
| **C** | 数学证明 | 有形式化推导或严格论证（定理 / 引理 / 充要条件） | 「模型建立」小节，可作定理陈述 |
| **D** | 工程验证 | 可重复执行的检查（哈希、协议自测、预检） | 「模型检验」或附录 |
| **E** | 尚未验证 | 未观测 / 未证实 / 未认证 | **只能写「未验证 / 未见证」**，不得拔高、不得省略 |

### 四条铁律

1. **A 与 B 永不混写** —— 同一句子里不得同时出现「官方」与「mock」口径的数字。
2. **n 必须标注** —— A 级当前为 n=1（Q3 演练）/ n=3（Q4 演练）/ n=3（Q3 正式）/ n=3（Q4 正式），**一律不得作分布性结论**。
3. **E 级不得「为了全绿」被消除** —— 未见证就写未见证。
4. **UNVERIFIED ≠ PASS** —— 证书认证结论必须逐族照抄裁定字符串。
