## 1. 问题一：五题分别属于什么类型？

### 1.1 A 题：偏微分方程类（含逆问题与移动边界）

- **判断依据**〔原文〕：题目要求给出"到药材中心距离 0、0.5、1、1.5、2 cm 处"的结果 ⇒ 存在**空间分布**；给出"对流换热系数 25 W/(m²·K)""对流传质系数 8×10⁻⁷ m/s" ⇒ **第三类（Robin）边界**；给出"水分浓度扩散系数的经验公式" ⇒ **变系数**；问题 4"药材会因水分流失发生尺寸变化" + 附件 2 给出半径序列 ⇒ **移动边界（实测：2 cm → 1.198 cm）**。
- **逐问类型**：Q1 = 正问题（给定条件求时空分布）；Q2 = 扩展的正问题（引入两阶段与经验公式，物性随 C 变化）；Q3 = **逆问题**（求达到"处处 C < 0.15"所需时间）；Q4 = **已知移动边界的正问题**（半径由附件 2 给出，**不需要解 Stefan 条件**〔归纳，N03 第 D 部分〕）。

### 1.2 B 题：仿真类 + 在线决策（搜索论）

- **判断依据**〔原文〕：题目强制"通过模拟器进行演练测试"，并给出"被清除干扰源个数的比例""平均定位清除时间"两个指标；目标数未知、位置未知、频道未知 ⇒ **在线搜索问题**；每次检测返回三类结果（no_signal / near / direction）⇒ **部分可观测**。
- **逐问类型**：Q1 = 几何与算法设计（交会定位区域直径 + 圆形覆盖判定）；Q2 = 最优实验设计（第二个检测点选哪里）；Q3 = 全向干扰源下的在线搜索-清除策略（仿真验证）；Q4 = 加入定向干扰源后的部分可观测搜索。

### 1.3 C 题：优化类（线性规划/混合整数） + 时间序列 + 随机规划

- **判断依据**〔原文〕：决策变量是"每 10 分钟的购电量 + 储能充放电量"（连续）；目标是费用最小（线性：电价 × 购电量）；约束是功率/容量上下界与储能状态转移方程（线性）；Q2 引入 5 倍紧急购电电价（分段惩罚）；Q3 引入调整购电的违约（0.5 倍）与超额（1.5 倍）电价 ⇒ **分段线性化**；Q4 电价随机波动 ⇒ **随机规划 / 鲁棒优化**。
- **逐问类型**：Q1 = 确定性单日 LP；Q2 = 全年逐日 LP（含紧急购电惩罚）；Q3 = 多阶段滚动优化（0/6/12/18 时更新预报）；Q4 = 随机优化（价格与光伏双随机）。

### 1.4 D 题：组合优化类 + 图论类 + 多目标优化

- **判断依据**〔原文〕："当两个用频计划的时间区间和频段区间都存在交叠时，则判定它们之间存在时频冲突" ⇒ 直接给出**冲突图**的建图规则；"一个用频计划只能调整其中一个参数或撤销" ⇒ **0-1 逻辑约束**；"应尽可能减少撤销……尽量减少被调整的用频计划数量……A 类优先级最高……尽量减少调整的幅度" ⇒ **加权多目标**；"频段、时间调整的最大平移幅度分别为 10Δf、5Δt" ⇒ **有界邻域**。
- **逐问类型**：Q1 = 冲突检测（区间扫描，纯算法）；Q2 = 带优先级与幅度惩罚的多目标消解（0-1 规划）；Q3 = 资源容量最大化（最大独立集 / 二维装箱）；Q4 = 决策维度 +1（间隔时长可调 ±10Δt）后的重解。

### 1.5 E 题：评价类 + 分类类 + 0-1 优化 + 随机优化（串联链）

- **判断依据**〔原文〕：Q1"从广告的设计质量与创意、关键词的管理与运用、出价策略与预算、投放策略与时间等方面分析……合理性，并分析投放效益与投放时间的变化规律和假日效应等" ⇒ **评价 + 时序分解**；Q2"按照投入成本与效益将关键词进行分类"并给出五类语义 ⇒ **二维阈值分类**（无标注样本）；Q3"在保证各推广单元的低成本、高效益、完成但不超过预算资金的条件下，选择合适的关键词……给出每个推广单元和相关联关键词的投放模型" ⇒ **0-1 规划**；Q4"考虑到每个关键词的竞价每天都在变化……存在不确定性……估计……的期望范围" ⇒ **随机优化 + 区间估计**。

## 3. 问题三与四：哪些不能直接迁移？为什么？

### 3.1 A 题：不能迁移的部分

| 不能迁移 | 为什么 | 后果 | 证据 |
|---|---|---|---|
| 2018A 的**左边界恒温（Dirichlet）** | 2026A 的烘房温度是时间的函数，且题目明确给出对流换热系数 25 W/(m²·K)；套 Dirichlet 等价于假设 h→∞ | **系统性低估表面升温滞后**，表层温度偏高 | 〔归纳〕N03 第 D-N1 条 |
| 2018A 的**用实测数据反演换热系数** | 2026A 的 h 与 k_m 已由附录 2 给定，**没有自由度**；强行反演会得到不唯一甚至非物理的解 | 引入无意义的不确定性，浪费篇幅 | 〔归纳〕N03 第 D-N2 条 |

## 4. 问题五：可以组合哪些方法？（五题的推荐技术路线）

### 4.1 A 题推荐组合

    主链：物理建模（Fourier + Fick） → 耦合 PDE → 隐式有限差分（圆柱坐标）
          → 追赶法/稀疏求解 → 时空结果落盘
    增强：① 坐标变换处理 Q4 的收缩域（ξ = r/R(t)）
          ② 变物性线性化（每步用上一时刻的 C、T 更新 D、k、ρ、c_p）
          ③ Q3 用"单调性证明 + 求根/二分"求烘干时间
          ④ 验证三件套：网格收敛性表 + 质量守恒校验 + 与常系数解析解对照
          ⑤ 敏感性：D 的系数、h、k_m、Δt、Δr 的扫描

### 4.2 B 题推荐组合

    主链：几何定位（交会区域） → 贝叶斯信息更新 → 覆盖/搜索路径规划
          → 策略参数化 → 官方模拟器批量演练 → 正式测试
    增强：① Q1 用凸包 + 旋转卡壳求定位区域直径，并证明"以直径为直径的圆能否覆盖"
          ② Q2 用"信息增益"或"定位误差椭圆的面积最小"作为选点判据
          ③ Q3 用螺旋/牛耕式基线 + 频道扫描顺序优化 + near 信号触发的局部清除
          ④ Q4 加入定向干扰源后，用"同一地点误差固定"这一性质避免重复测量
          ⑤ 用自建离线仿真做超参数搜索，再用官方模拟器验证（正式测试只有 3 次）

### 4.3 C 题推荐组合

    主链：数据整理（10 分钟粒度对齐） → 线性规划（含储能状态方程）
          → 分段线性化（紧急购电 5 倍、违约 0.5 倍、超额 1.5 倍） → 求解器
    增强：① Q3/Q4 用滚动时域（0/6/12/18 时更新）+ 情景生成（预报误差分布拟合）
          ② 用"不储能 / 只按需购电"作为基线对比
          ③ 约束可行性回代（储能电量轨迹必须落在 1200—10800 kWh）
          ④ 敏感性：光伏预报误差、电价波动幅度、储能效率
    风险提示：储能 SOC 的 MILP 与滚动随机优化在本资料包内**无先例**，需自行构建并做严谨的建模说明

### 4.4 D 题推荐组合

    主链：参数解析（把 150 条计划展开为"占用格集合"） → 冲突检测（区间扫描）
          → 冲突图 → 加权多目标 0-1 规划（含"只能调一个参数"的大 M 线性化）
          → 求解器 → 消解后重新检测（硬验证）
    增强：① Q3 建为最大独立集/二维装箱的容量最大化，并给出上界
          ② 用"全部撤销"与"贪心消解"作为基线对比
          ③ 规模分析：150 条 → 冲突对数量 → 决定用精确法还是启发式
          ④ 幅度惩罚与优先级保护用字典序或分层权重，并做权重敏感性

### 4.5 E 题推荐组合

    主链：数据审计（2227 行 / 1884 词 / 40% 零消费） → Q1 评价 + 时序分解
          → Q2 二维阈值分类（成本 × 效益，含阈值敏感性）
          → Q3 0-1 规划（关键词 × 日期 × 推广单元，预算约束）
          → Q4 随机优化 + 区间估计
    增强：① 用分层/面板结构处理"关键词截面 × 单元日序列"（本语料唯一先例是 2023 C126 的贝叶斯层级模型 + MCMC）
          ② 用"年度汇总 → 日度决策"的口径说明（这是本题最大难点）
          ③ 用"均匀投放"作为基线对比
          ④ 区间估计要给分布假设依据与置信水平
