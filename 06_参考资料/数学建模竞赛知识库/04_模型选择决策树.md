# 04_模型选择决策树

> 本文档把「题眼 → 数学结构 → 模型」写成**可执行的判定流程**。核心原则：**不是从模型清单往下套题，而是从题目条件往上推数学结构**。
> 证据标注：〔原文〕/〔归纳〕/〔推理〕。

---

## 0. 总决策树

    读题：逐问提取【动词】（求/预测/评价/设计/安排/分析/判定/检验）
      │
      ▼
    是否存在【决策变量】？（能让别人判对错，且答案是方案/数值/表）
      ├─ 是 ──► A. 优化分支
      └─ 否 ──► B. 非优化分支

    【A. 优化分支】
      目标几个？
        ├─ 1 个 ─────────────► 单目标优化
        ├─ ≥2 且分先后 ──────► 字典序多目标（ε-约束 / 逐层求解）
        └─ ≥2 且可折中 ──────► Pareto 多目标（加权扫描 / NSGA-II）
      变量类型？
        ├─ 连续 ──► LP / NLP / QP
        ├─ 整数 ──► ILP
        ├─ 0-1 ──► 0-1 规划 / 组合优化
        ├─ 排列 ──► TSP / 调度
        └─ 函数（策略/控制律）──► 最优控制 / 动态规划
      线性吗？非线性先尝试线性化（分段、绝对值、max、0-1乘积、分式）
      规模？  ≤10² 用精确法；10²~10⁴ 用求解器；≥10⁴ 或 NP-hard 用启发式 + 下界
      有不确定性？ ──► 随机规划 / 鲁棒优化 / 机会约束

    【B. 非优化分支】
      输出是「未来数值」？ ──► 预测分支（§3.1）
      要求「排序/分级」？ ──► 评价分支（§3.2）
      有物理机理/时空演化？ ──► 机理分支（§3.3）
      有网络/冲突关系？ ──► 图与路径分支（§3.4）
      要求「判定类别」？ ──► 分类分支（§3.5）

**四条并行叠加判据**（无论落在哪个分支都要检查）：

1. **是否含随机性？** 有 → 叠加概率统计层（假设检验 / 蒙特卡洛 / 随机或鲁棒优化）。
2. **是否含网络或冲突关系？** 有 → 叠加图论层（最短路 / TSP / 网络流 / 着色 / 独立集）。
3. **是否强制使用仿真器？** 有 → 叠加仿真层（DES / ABM / 官方模拟器）。
4. **是否要求排序或分级？** 有 → 叠加评价层（赋权 + 合成）。

## 1. 第一层判定：有没有决策变量？

### 判定问句

> 「题目要我**决定**什么吗？如果我随便给一个答案，题目能不能判对错？」

- 能判对错，且答案是「一个方案 / 一个数 / 一张表」 → **有决策变量 → 优化分支**。
- 答案是「解释 / 规律 / 判定 / 排序」 → **无决策变量 → 非优化分支**。

〔原文佐证〕_keydocs/数学建模国赛常见题型及算法汇总.txt：「优化题：问句关键词：最优方案、最大、最小、如何安排；**一定存在决策变量**。」

## 2. 优化分支：五级判定

### 第 1 级：目标有几个？

| 情形 | 判定依据 | 处理 |
|---|---|---|
| 1 个目标 | 只有一句「使……最大/最小」 | 单目标优化 |
| ≥2 个目标且**有先后** | 出现「前提」「优先」「其次」 | **字典序多目标**（ε-约束 / 逐层求解） |
| ≥2 个目标**并列可折中** | 出现「既要……又要……」「尽可能……而……尽可能……」 | **Pareto 多目标**（加权和 + 权重扫描 / NSGA-II） |

**关键判别**：先判断两个目标是**冲突**还是**同向**。
- 冲突（相关系数为负）→ 真多目标，画 Pareto 前沿。
- 同向（如「最小化成本」与「最小化材料用量」）→ **伪多目标**，应合并或改成一个主目标 + 一个约束〔推理〕。

### 第 2 级：决策变量是什么类型？

| 变量类型 | 识别信号 | 模型族 |
|---|---|---|
| 连续实数（产量、功率、金额、时间） | 可以取小数 | LP / NLP / QP |
| 整数（人数、件数、车次数） | 不可分割 | ILP |
| 0-1（选/不选、开/关、投放/不投放、撤销/保留） | 二选一 | 0-1 规划 / 组合优化 |
| 排列顺序（访问顺序、加工次序） | 「先后」「顺序」 | TSP / 调度 |
| 分段区间（时段、频段、班次） | 「第 t 时段」「频段区间」 | 时段索引 MILP |
| 函数（控制律、策略） | 「策略」「控制策略」「轨迹」 | 最优控制 / 动态规划 / 强化学习 |

### 第 3 级：目标与约束是线性的吗？

- **全部线性** → LP / MILP。
- **含乘积、平方、指数、max/min、绝对值、分段** → NLP；但**先尝试线性化**：
    - 分段线性 → 辅助变量 + SOS2 / 大 M；
    - 绝对值 |x| → x⁺ − x⁻；
    - max(x₁,…,xₙ) → 引入 z 与 z ≥ xᵢ；
    - 乘积 x·y（其中一个为 0-1）→ 大 M 线性化；
    - 分式目标 → Charnes-Cooper 变换。
- **无法线性化且非凸** → NLP + 多起点 / 全局优化（差分进化、遗传算法、模拟退火）。

### 第 4 级：问题规模有多大？

| 规模（决策变量数 × 约束数） | 推荐解法 |
|---|---|
| ≤ 10² 且结构良好 | 精确法（LP/MILP 求解器、动态规划、分支定界），**必须给最优性说明** |
| 10² ~ 10⁴ | MILP 求解器（设时限）+ 紧松弛建模 |
| ≥ 10⁴ 或 NP-hard 且时限紧 | 启发式 / 元启发式 + **下界论证** + 与贪心基线对比 |
| 目标函数需调用数值仿真/PDE 求解 | 代理模型（Kriging / 响应面 / RBF）+ 贝叶斯优化 |

**国赛时限提醒**：比赛只有 3 天，优化模型的求解时间必须可控。**能用求解器就不要自己造轮子**〔归纳〕。

### 第 5 级：是否存在不确定性？

- 参数确定 → 确定性优化。
- 参数是随机变量且**分布已知** → 随机规划（两阶段 / 机会约束 / 样本平均近似 SAA）。
- 只知道区间 / 不确定集 → **鲁棒优化**。
- 只有历史数据 → 情景生成（Bootstrap / 蒙特卡洛）+ 随机规划。

## 3. 非优化分支：预测 / 评价 / 机理 / 网络 / 分类

### 3.1 预测分支决策树

    是否给了自变量（外生变量）？
    ├─ 是 → 回归 / 机器学习
    │      ├─ 样本量 < 50        → 线性回归 + 正则化；灰色关联
    │      ├─ 样本量 50 ~ 10⁴    → 随机森林 / XGBoost / GAM
    │      └─ 样本量 > 10⁴       → 梯度提升 / 深度网络
    └─ 否 → 只靠自身历史
           ├─ 样本量 < 20        → 灰色 GM(1,1)；Logistic / 饱和曲线
           ├─ 有趋势无季节       → ARIMA / 指数平滑
           ├─ 有季节             → SARIMA / Holt-Winters / STL+ARIMA
           ├─ 有突变             → 变点检测 + 分段建模
           └─ 多变量互相影响     → VAR / 状态空间 / 卡尔曼滤波

**判别「该用机理还是时序」的关键问句**：
> 题目是否给出了**物理参数**（导热系数、扩散系数、阻力系数、反应速率）？
> 给了 → 机理（ODE/PDE）；只给了观测值 → 时序 / 回归。〔归纳，见 03_题眼识别库 第 2.3 节〕

### 3.2 评价分支决策树

    有量化数据吗？
    ├─ 没有（或极少） → AHP（专家判断矩阵 + 一致性检验）
    └─ 有数据
       ├─ 指标数 > 8 且相关性强 → PCA / 因子分析降维后再评价
       ├─ 指标方向混合（正/负） → 先正向化，再 TOPSIS / 灰色关联 / RSR
       ├─ 结果是「等级」而非「排序」 → 模糊综合评价 / 聚类分级
       ├─ 需要「客观」赋权 → 熵权法 / CRITIC / 变异系数
       └─ 需要「可解释 + 稳健」 → 主客观组合赋权（AHP+熵权，博弈论或最小偏差定比例）

    合成方法选择：
      排序问题 → TOPSIS / RSR / 灰色关联
      分级问题 → 模糊综合评价 / 聚类 / 阈值法
      效率问题 → DEA

### 3.3 机理分支决策树

    物理量随什么变化？
    ├─ 只随时间 → ODE
    │   ├─ 单变量、机理清楚 → 解析解优先
    │   ├─ 多变量耦合       → 方程组 + 数值解（RK4 / ode45 / BDF）
    │   ├─ 分年龄/分阶段    → Leslie 型差分递推
    │   └─ 有反馈/长期演化  → 动力系统 + 稳定性分析 / 系统动力学
    └─ 同时随时间和空间 → PDE
        ├─ 抛物型（扩散、热传导、渗流） → 热传导/扩散方程
        │   ├─ 边界恒温/恒浓度              → Dirichlet
        │   ├─ 边界给定通量（绝热、不透水） → Neumann
        │   ├─ 边界对流换热/传质（给了 h、k_m） → Robin   ← 2026A 属此类
        │   └─ 区域随时间变化（收缩/膨胀）  → 移动边界（Stefan）+ 坐标变换
        ├─ 双曲型（波动、振动、传输线） → 波动方程
        ├─ 椭圆型（稳态、静电场、稳态渗流） → Laplace / Poisson
        └─ 含反应项 → 反应-扩散方程

**离散方法选择**：

| 情境 | 方法 |
|---|---|
| 规则区域（矩形/圆柱/球） | 有限差分（FDM） |
| 复杂几何 | 有限元（FEM）/ 有限体积（FVM） |
| 需要高精度且解光滑 | 谱方法 / 高阶差分 |
| 变系数且非线性 | 隐式格式 + 牛顿迭代（每步线性化） |
| 一维或轴对称 | 三对角方程组 + 追赶法（Thomas） |
| 移动边界 | 坐标变换（固定域变换 ξ=r/R(t)）或 ALE |

### 3.4 网络与路径分支决策树

    要解决网络的什么问题？
    ├─ 两点间最省        → 最短路（Dijkstra / Floyd / A*；边权时变则用时间展开图）
    ├─ 连通所有点最省    → 最小生成树（Kruskal / Prim）
    ├─ 走遍所有点回起点  → TSP（精确：分支定界 / Held-Karp；近似：2-opt / LKH）
    ├─ 多车多起点        → VRP / MTSP（节约算法、插入法、蚁群）
    ├─ 最大流量/最小费用 → 最大流（Ford-Fulkerson / Dinic）、最小费用流
    ├─ 一对一分配        → 指派问题（匈牙利算法）
    ├─ 冲突/互斥         → 冲突图 → 着色 / 最大独立集 / 最小顶点覆盖
    └─ 覆盖所有需求点    → 集合覆盖（LP 松弛 + 舍入；或贪心 + 下界）

**时变网络警告**：只要边权依赖时间（2025D 的巷道水位、2024E 的交通流），**不能**直接用静态最短路〔归纳〕。

### 3.5 分类分支决策树

    有没有带标签的训练样本？
    ├─ 有 → 监督分类
    │   ├─ 样本少、维度低、需可解释 → 逻辑回归 / 判别分析 / 决策树
    │   ├─ 样本中等、需高精度       → 随机森林 / XGBoost / SVM
    │   └─ 类别不均衡               → 代价敏感 / 重采样 / 阈值调整
    └─ 没有（题目只给了类别「定义」） → 规则/阈值分类
        ├─ 定义基于 1 个指标                → 单阈值（分位数 / 均值 / 业务阈值）
        ├─ 定义基于 2 个指标（如成本 vs 效益） → 二维四象限 + 原点特判   ← 2026E 属此类
        ├─ 定义基于多个指标                 → 综合得分阈值 / 聚类后贴标签
        └─ 必须先探索结构                   → 聚类（K-means / 层次 / DBSCAN / 一维最优分割）

**高频误判**：把「题目给了类别语义」当成「有监督分类任务」。2026E 题只给了五个类别的**语义描述**，没有标注样本〔原文〕，因此正确路线是「二维阈值 + 敏感性分析」，而不是训一个分类器〔推理〕。

## 4. 决策树防呆分支：拿到题先问这 12 个问题

| # | 问题 | 若答「是」 |
|---|---|---|
| 1 | 题目是否给了**物理参数**？ | 优先机理建模 |
| 2 | 是否存在**决策变量**？ | 必须建优化模型，即使题目没说「最优」 |
| 3 | 是否要求**输出结果文件**（result.xlsx）？ | 输出格式即硬约束，先读模板确定行列含义 |
| 4 | 是否有**多个小问且性质不同**？ | 混合模型 + 技术路线图 |
| 5 | 是否有**强制外部工具**（模拟器 / 软件）？ | 先跑通接口再想算法 |
| 6 | 是否给了**数据但没给模型**？ | 数据驱动方法（统计 / 机器学习 / 聚类） |
| 7 | 是否要求**排序或分级**？ | 评价模型 |
| 8 | 是否含**随机性或误差**？ | 概率层叠加 |
| 9 | 是否含**网络结构**（节点-边）？ | 图论层叠加 |
| 10 | 是否要求**敏感性 / 鲁棒性分析**？ | 建模时就设计好参数扫描 |
| 11 | 是否有**多目标且互相冲突**？ | Pareto 或字典序 |
| 12 | 是否有**隐含约束写在附录 / 脚注**？ | 逐条抄录成约束清单 |

## 5. 模型关系图：基础模型 → 改进模型 → 高级模型

### 5.1 优化族谱

    线性规划 (LP)
     ├─ 变量取整 → 整数规划 (IP)
     │   ├─ 变量限 0-1 → 0-1 规划
     │   │   ├─ 网络结构 → 网络流 / 指派 / 最小费用流
     │   │   └─ 集合结构 → 集合覆盖 / 背包 / 设施选址
     │   └─ 时间分阶段 → 多阶段 MILP / 滚动时域
     ├─ 目标多个 → 多目标规划
     │   ├─ 加权 / ε-约束 → 单目标化
     │   └─ 直接求 → Pareto 前沿 / NSGA-II
     ├─ 出现非线性 → 非线性规划 (NLP)
     │   ├─ 凸   → 内点法 / SQP，全局最优
     │   └─ 非凸 → 多起点 / 全局优化 / 元启发式
     └─ 参数不确定 → 随机规划 / 鲁棒优化 / 机会约束

〔原文佐证〕用户任务书给出的范式：「线性规划 → 整数规划 → 多目标优化 → 鲁棒优化」。

### 5.2 预测族谱

    均值/趋势外推（朴素预测）
     ├─ 加自回归结构 → AR / MA / ARMA
     │   ├─ 差分平稳化 → ARIMA
     │   ├─ 加季节项   → SARIMA / Holt-Winters
     │   └─ 加波动项   → GARCH
     ├─ 加外生变量   → 回归 / ARIMAX / 传递函数
     ├─ 小样本指数律 → 灰色 GM(1,1) / 灰色 Verhulst
     ├─ 加状态空间   → 卡尔曼滤波 / 动态线性模型
     ├─ 数据驱动     → 随机森林 / XGBoost / LSTM / Transformer
     └─ 多模型       → 组合预测（加权 / Stacking / 误差修正）

〔原文佐证〕任务书范式：「普通预测 → 时间序列 → 机器学习 → 集成学习」。

### 5.3 机理族谱

    经验公式 / 集总参数模型（Biot 数小）
     ├─ 分空间 → 一维 ODE / PDE
     │   ├─ 多层多区域 → 界面耦合（温度连续 + 通量连续）   ← 2018A 的核心创新
     │   ├─ 变物性     → 非线性 PDE
     │   ├─ 变区域     → 移动边界（Stefan）
     │   └─ 多物理场   → 热-湿-力耦合   ← 2026A 属此类
     ├─ 加随机 → 随机微分方程 / 不确定性量化
     ├─ 加控制 → 最优控制 / 模型预测控制（MPC）
     └─ 加数据 → 灰箱 / 物理信息神经网络（PINN）/ 参数在线辨识

### 5.4 评价族谱

    专家打分
     ├─ 结构化 → AHP
     ├─ 客观化 → 熵权 / CRITIC / 变异系数
     ├─ 组合   → 主客观组合赋权（博弈论 / 最小偏差 / 最大熵）
     ├─ 降维   → PCA / 因子分析赋权
     └─ 合成
         ├─ 排序 → TOPSIS / RSR / 灰色关联 / VIKOR
         ├─ 分级 → 模糊综合评价 / 聚类 / 云模型
         └─ 效率 → DEA / SBM

## 6. 2026 年五题的决策路径（实走一遍）

### 6.1 A 题「药材的烘干问题」

    有决策变量吗？
     Q1/Q2：没有（求给定条件下的温度 / 浓度分布） → 非优化分支 → 有机理参数 → PDE
     Q3：没有决策变量，但要求「确定烘干所需要的时间」 → 逆问题（求达标时刻）
     Q4：半径随时间变化 → 仍是 PDE，但区域变化 → 移动边界
    最终：
     主模型 = 圆柱坐标非稳态热传导 + 水分扩散耦合 PDE
     数值   = 隐式有限差分（Crank-Nicolson 可选）+ 追赶法 / 稀疏求解
     特殊   = 变物性（D 依赖 C 与 T，k / ρ / c_p 依赖 C）
     难点   = Q4 移动边界 + Q1/Q2 的两阶段（预热平衡 + 恒温干燥）参数切换
     验证   = 网格收敛性 + 与附件 1 的烘房条件一致性 + 质量守恒

### 6.2 B 题「无线电干扰源定位与清除」

    有决策变量吗？
     Q1：无（给定检测点与示向度，求定位区域直径） → 几何 + 算法设计
     Q2：有（第二个检测点选哪里） → 最优实验设计
     Q3/Q4：有（机器狗的完整策略） → 在线决策 + 路径规划
    最终：
     主模型 = 交会定位误差区域模型 + 贝叶斯信息更新 + 覆盖/搜索路径规划
     算法   = 凸包 + 旋转卡壳（Q1）；信息增益贪心（Q2）；牛耕/螺旋基线 + 滚动重规划（Q3/Q4）
     特殊   = 必须使用官方模拟器（HTTP+JSON），20 分钟程序时间上限
     验证   = 演练测试 + 同一批案例的策略对比 + 三次正式测试日志

### 6.3 C 题「微网与电网调控」

    有决策变量吗？有（各时段购电量、充放电量） → 优化分支
    目标几个？Q1/Q2 一个（费用最小）；Q3 多类费用可合成一个总费用
    变量类型？连续（kWh）
    线性吗？目标线性（电价 × 购电量），储能状态方程线性 → LP
    有不确定吗？Q3/Q4 有（光伏预报误差、实时电价） → 随机规划 / 滚动优化
    最终：
     主模型 = 带储能状态方程的线性规划（LP），多阶段版本用滚动时域 + 情景树
     算法   = LP 求解器（scipy.linprog / Gurobi / CVXPY）；分段线性化处理违约与超发电价
     验证   = 与「不储能」基线对比；预报误差敏感性；约束可行性回代

### 6.4 D 题「时频冲突检测与消解」

    有决策变量吗？有（调整哪个计划、怎么调、是否撤销） → 优化分支（0-1 + 整数）
    目标几个？多个且带优先级（撤销数↓、调整数↓、幅度↓、优先级保护） → 字典序 / 加权多目标
    结构？二维区间冲突 → 冲突图
    最终：
     主模型 = 冲突图 + 加权多目标 0-1 规划（大 M 线性化「只能调一个参数」）
     算法   = 冲突检测用区间扫描；消解用 MILP 求解器 + 大规模启发式
     Q3     = 最大独立集 / 二维装箱的容量最大化
     Q4     = 决策维度 +1（间隔时长）后的重解
     验证   = 消解后重新检测冲突数必须为 0（硬检验）；与「全部撤销」基线对比

### 6.5 E 题「SEM 广告投放策略」

    Q1 有决策变量吗？没有（分析合理性 + 规律） → 评价 + 时间序列
    Q2 有决策变量吗？没有（分类） → 二维阈值分类（成本 × 效益）
    Q3 有决策变量吗？有（选哪些关键词、哪天投、投多少） → 优化分支（0-1 + 预算约束）
    Q4 有决策变量吗？有 + 不确定 → 随机优化 + 区间估计
    最终：
     主模型 = 评价（Q1）→ 分类（Q2）→ 0-1 规划（Q3）→ 鲁棒/随机优化 + 区间估计（Q4）的串联
     关键   = 层级结构（方案 5 / 推广单元 12 / 关键词 1884）与预算约束的一致性
     验证   = 分类阈值敏感性 + 投放策略与「均匀投放」基线对比 + 期望范围的分布假设检验

## 7. 决策树使用中的三个常见误用

1. **顺序误用**：先选了喜欢的模型，再回头给题目贴标签。正确做法是**从题目条件往上推**，让数学结构决定模型。
2. **粒度误用**：把「整道题」判成一个类型。正确做法是**逐问判定**（2026 A 题四问是三种不同性质）。
3. **复杂度误用**：认为「越复杂的模型越好」。_keydocs/AI+数学建模工作流讲义.txt 明确把「模型堆砌，听起来高级但不落地」列为风险之一〔原文〕；本知识库 08_高分论文创新方法库.md 给出「什么才算真创新」的判据。
