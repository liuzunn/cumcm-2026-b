> **这是一套把 1992—2026 年国赛真题、338 篇可读优秀论文、25 份 AI 提示词、全部模板与赛题附件，转换成"比赛现场可直接调用的建模能力"的知识库。**

## 一、这个知识库是什么

### 1.1 一句话
**它不是资料摘要，而是一套"看到题目 → 识别题型 → 找到题眼 → 建立数学结构 → 选择模型 → 选择算法 → 编程实现 → 验证结果 → 找创新点 → 写成论文"的操作系统。**

### 1.2 它由哪几层构成

| 层 | 文件 | 回答的问题 |
|---|---|---|
| **索引层** | `01_资料索引.md` | 资料包里有什么？哪些读得到、哪些读不到？ |
| **识别层** | `02_数学建模题型体系.md`、`03_题眼识别库.md` | 这道题是什么类型？哪句话决定了选哪个模型？ |
| **决策层** | `04_模型选择决策树.md` | 按什么顺序判定？每一级看什么？ |
| **知识层** | `05_数学模型库/`（54 张模型卡）、`06_算法库/`（24 张算法卡） | 这个模型/算法怎么用、什么时候不能用、坑在哪？ |
| **经验层** | `07_优秀论文逆向分析/`（4 份，含 2025 年扫描件图像阅读版） | 高手是怎么做的？为什么这么做？ |
| **创新层** | `08_高分论文创新方法库.md` | 什么才算真创新？怎么写才像创新？ |
| **工具层** | `09_Prompt工程/`（12 份可直接复制的模板） | 怎么让 AI 帮忙而不被 AI 带偏？ |
| **执行层** | `10_数学建模竞赛标准作战流程.md` | 72 小时怎么排？每一步的输入输出与完成判据是什么？ |
| **落地层** | `11_2026赛题模型映射表.md` | 当前 2026 年五道题，分别该怎么做？ |
| **元层** | `12_知识关联图.md`、`13_知识缺口.md`、`14_学习测试结果.md` | 知识之间怎么连？我还不知道什么？这套知识能不能用？ |

## 二、怎么使用（三种典型场景）

### 场景 A：比赛刚开始，拿到赛题（0—1 小时）

    1. 打开 03_题眼识别库.md 的 §0 总映射表，扫一遍题眼信号词
    2. 打开 09_Prompt工程/01_赛题分析Prompt.md，把题目贴进去，得到"逐句拆解表 + 小问拆解表 + 题型判定表 + 数据缺口表 + 提交物清单"
    3. 打开 02_数学建模题型体系.md 对号入座，确认每问的题型标签
    4. 打开 11_2026赛题模型映射表.md（若是 2026 年题），直接看对应题的"可迁移 / 不能迁移 / 推荐组合"
    5. 【人工拍板】三人各自独立判定题型后合并——**这是防止集体误判的最有效手段**

### 场景 B：建模中途卡住（"这个模型到底能不能用？"）

    1. 打开 04_模型选择决策树.md，从"有没有决策变量"开始重走一遍判定
    2. 打开 05_数学模型库/<对应类别>/<模型名>.md，重点看第 12 节"适用条件"、第 13 节"不适用情况"、第 14 节"常见错误"
    3. 打开 07_优秀论文逆向分析/，搜索同类题的论文，看别人在同样条件下选了什么都遇到了什么坑
    4. 打开 06_算法库/，按问题规模选算法（注意"适用规模与适用条件"一节）

### 场景 C：提交前自查（最后 4 小时）

    1. 09_Prompt工程/08_结果验证Prompt.md   → 四层检验（数值 / 有效性 / 鲁棒性 / 提交物合规）
    2. 09_Prompt工程/10_模型检查Prompt.md   → 红队审查（六类攻击 + 严重度分级）
    3. 09_Prompt工程/11_最终审稿Prompt.md   → 评委视角六维评分 + 合规终检 + 三档修改清单
    4. 10_数学建模竞赛标准作战流程.md 的 Step 16 → 支撑材料清单逐项核对

## 四、如何选择模型（四步）

**第 1 步：判定有没有决策变量。**
问自己："题目要我决定什么？随便给个答案能被判对错吗？" 能 ⇒ 优化分支；不能 ⇒ 非优化分支。

**第 2 步：在对应分支里逐级细化。**
- 优化分支：目标几个 → 变量类型 → 线性否 → 规模多大 → 有不确定性否（详见 `04_模型选择决策树.md` §2）
- 非优化分支：预测 / 评价 / 机理 / 网络 / 分类 五条路（详见 §3）

**第 3 步：至少给出 1 主 + 2 备选。**
备选不是凑数——**要能说出备选在什么条件下会优于主模型**，这本身就是论文"模型选择"一节的加分点。

**第 4 步：查"不适用情况"再动手。**
每个模型卡片都有第 13 节"不适用情况"与第 14 节"常见错误"，**先看这两节能省下大量返工**。

### 三条防呆规则〔归纳〕
1. **题目给了物理参数就别做纯数据拟合**——参数就是机理建模的邀请函。
2. **小规模问题用求解器，别用元启发式**——LP/MILP 能精确求解却上遗传算法，是丢分而非创新。
3. **每问都要重新判定题型**——2026 A 题四问分属正问题、扩展正问题、逆问题、移动边界问题。

## 六、如何进行模型验证

### 6.1 四层验证框架（标准答案）

| 层 | 检查什么 | 具体手段 |
|---|---|---|
| **① 数值正确性** | 离散化是否收敛 | 网格/步长收敛性表（步长减半比较输出变化）；与解析解或退化模型对照；质量/能量守恒校验 |
| **② 模型有效性** | 模型是否符合现实 | 与实测数据对比（R²/RMSE/最大绝对误差）；约束满足度；与基线的对比 |
| **③ 鲁棒性** | 结论是否稳定 | 参数扫描（±10%）；蒙特卡洛误差传播；**不同算法交叉验证** |
| **④ 提交物合规** | 是否符合交付要求 | 结果文件行列与模板一致；小数位数；文件命名；支撑材料完整；AI 使用披露 |

### 6.2 必须知道的一个事实〔归纳，N03 对 14 篇机理类论文的统计〕
> **14 篇论文中：0 篇做过网格无关性表，0 篇做过质量守恒校验，0 篇做过与解析解对照。**
> 这意味着：在 2026 A 题（以及任何 PDE 题）上做这三件事，**本身就是差异化优势**。

### 6.3 最有效的三种验证（按性价比排序）
1. **双算法交叉验证**——同一问题用两种原理不同的方法求解并报相对误差（2025A A196 用粒子群验证变步长搜索，相对误差 0.01%；2025B B060 用周期公式与牛顿迭代互验）。
2. **退化模型对标**——把完整模型退化到简单情形，看能否复现简单模型的结果（2010A 令 α=β=0；2026 A 可让附录 3 退化为附录 2）。
3. **硬约束回代**——把最终解代回全部约束逐条验证（2026 D 题消解后冲突数必须为 0；2026 C 题储能电量必须落在 1200—10800 kWh）。

## 七、如何进行论文写作

### 7.1 标准八段式（来自对 14 篇机理类论文 + 5 篇 2025 年论文的章节对齐统计）

    摘要        总起句点明核心工具/产出物 → 逐问一段（方法名 + 关键数值）→ 关键词与摘要方法一一对应
    一、问题重述    用自己的语言，不照抄原题
    二、问题分析    逐问写"条件句 → 模型"的因果链（最加分的一节）
    三、模型假设    每条：假设内容 + 设立依据 + 对模型的影响
    四、符号说明    三线表，必须有单位
    五、模型建立与求解（按问分章）
                  每问五件套：控制方程/目标函数 + 初始条件 + 边界条件（说明第几类）+ 约束 + 离散格式/算法
    六、模型检验与灵敏度分析
    七、模型评价    优点具体、缺点真实、改进方向明确
    八、参考文献    近 5 年为主，中外结合
    附录          完整可运行代码 + 中间结果

### 7.2 六个高频扣分点（均有实例）
| # | 扣分点 | 实例 |
|---|---|---|
| 1 | **摘要与正文数值不一致** | N03 统计的 14 篇中至少 6 篇有此问题 |
| 2 | **自定阈值充当通过标准** | 2018A 某篇用"偏差指数 0.4593 < 0.5"判"模型正确"，阈值无依据 |
| 3 | **自述模型名与实际实现不符** | 2018A 某篇称"蒙特卡洛"，全文检索"置信/方差/标准差/均值"零命中 |
| 4 | **区间/数值不自洽** | 2025C C023 出现 [47.0, 46.8] 这类上界小于下界的区间 |
| 5 | **结果量级不合理** | 2025D D037 给出 50249.91 min（约 34.9 天），与题目物理量级需核对 |
| 6 | **同一批数据既估参又验证** | 无独立验证集 |

### 7.3 图表规范
- **每个图必须服务于一个结论**，图注写"它证明了什么"，而不是重复标题。
- 坐标轴必须有单位；图注 30—50 字并含至少一个具体数值。
- 技术路线图、指标体系图、建模流程图是"结构性得分图"，优先级高于装饰性图表。

## 九、证据分级约定（全库统一）

| 标注 | 含义 |
|---|---|
| 〔原文〕 | 真题或论文原文明确写出，可直接引用 |
| 〔原文-图像〕 | 来自扫描件的图像阅读，逐字取自扫描页 |
| 〔归纳〕 | 由多份资料交叉归纳得出 |
| 〔推理〕 | 本知识库的合理推导，**不是资料中的结论** |
| 【未在资料中找到】 | 资料包中确实不存在，不做补白式编造 |

**使用提醒**：引用时必须保留这些标注。**切勿把〔推理〕当成〔原文〕**——用户明确要求"禁止把自己的推测伪装成资料中的结论"。

## 十、这套知识库的边界（必读）

1. **它不包含 2026 年五题的任何答案或结果数值**——资料包中不存在官方答案，本知识库也未做实际求解。
2. **它明确记录了所有读不到的资料**——见 `13_知识缺口.md`。例如 2020A/2019A 优秀论文是纯扫描件（正文一个字都没有）、2019D/2019E 共 8 篇是"零正文空壳"、2016A 等年份只精读了 1—2 篇。
3. **它记录了库内"零先例"的方法**——最要紧的两条：**储能 SOC 的 MILP 与滚动/两阶段随机优化，在 338 篇可读优秀论文中 0 次出现**；**二维阈值分类的统计依据与阈值稳健性，0 篇做过**。这两条恰好是 2026 C 题与 E 题的核心方法。
4. **它的自检结论来自同一主体**——`14_学习测试结果.md` 的测试者与被测者是同一主体，价值在于暴露缺口，不是能力评分。
5. **"本语料无先例"不等于"赛场上无人用过"**——这是两个不同的命题，本知识库严格区分。

## 十一、最终原则

> **看到题目 → 快速识别题型 → 找到题眼 → 建立数学结构 → 选择模型 → 选择算法 → 编程实现 → 验证结果 → 找创新点 → 写成论文。**

这条链路里，**任何一环断了，分数就断在那里**。而历年最常见的断点不是"模型不够高级"，而是：
- **没读附录里的约束**（2026 A 的物性公式、C 的储能参数都在附录）；
- **没有验证就说模型有效**；
- **摘要与正文数字不一致**。

把这三点做到，就已经超过大多数参赛队了。
