# 02_数学建模题型体系

> 本文档从 1992—2026 年共 **35 个年份、约 165 道国赛真题** 与 **338 篇可读优秀论文** 中归纳而成。
> **证据标注规则**：〔原文〕= 真题/论文原文明确写出；〔归纳〕= 由多份资料交叉归纳；〔推理〕= 本文档的合理推导。
> **目录索引**：每一种题型给出「题型名称 → 题型特征 → 如何识别 → 核心数学模型 → 常用算法 → 适用条件 → 优点 → 缺点 → 常见错误 → 论文写法 → 优秀论文案例 → 可创新方向」12 段结构。

---

## 0. 使用说明（先读这 60 秒）

1. **题型不是互斥标签**。国赛真题绝大多数是"一题多型"：2026 A 题同时是"PDE 类 + 参数反演 + 优化类"；2026 C 题同时是"优化类 + 时间序列类 + 随机规划类"。
2. **判断题型的目的不是贴标签，而是确定"决策变量 / 目标 / 约束"三件套长什么样**。同是"优化"，决策变量是"连续产量"还是"0-1 选择"还是"时间序列路径"，直接决定模型族。
3. **每道题都应至少给出 1 个主模型 + 1 个备选模型 + 1 个融合/创新模型**，这也是国赛评分里"模型建立"一项的常见加分点〔归纳，来源 `_keydocs/数学建模问题求解AI提示词.txt` 的"方案1 基础适配 / 方案2 创新融合"要求〕。

## 2. 题型 1：预测类

- **题型名称**：预测类（Forecasting）
- **题型特征**：给出一段历史数据，要求给出未来某时段的数值、区间或趋势；常伴随"未来 N 年/N 天/N 小时"。
- **如何识别**：题面出现"预测 / 预估 / 预报 / 未来走势 / 发展趋势 / 估计……将达到"。2025C 题面为"预测该运动者的实际跳远成绩"；2023E 为"预测分析该水文站未来两年水沙通量的变化趋势"〔原文〕。
- **核心数学模型**：灰色 GM(1,1)；ARIMA/SARIMA；指数平滑；多元线性回归与非线性回归；状态空间与卡尔曼滤波；Leslie 矩阵与差分递推；组合预测（加权/最优线性组合）；机器学习预测（随机森林、XGBoost、LSTM）。
- **常用算法**：最小二乘/极大似然参数估计；AIC/BIC 定阶；差分与平稳性检验（ADF）；滚动预测（walk-forward）；交叉验证；残差诊断；不确定度量化（自助法 / 分位数回归）。〔归纳〕
- **适用条件**：数据时间跨度 ≥ 30 个观测点且采样规律；序列具有可识别的趋势/季节/周期成分；预测期不超过样本长度的 1/3〔推理〕。
- **优点**：结论直接、可量化、可给出置信区间；与题目"要数值"的要求天然吻合。
- **缺点**：外推能力受结构性变化限制；小样本下过拟合风险高；多变量耦合预测易漏掉因果结构。
- **常见错误**：① 不做平稳性检验直接套 ARIMA；② 用全样本调参后再在"训练集"上报精度（数据泄漏）；③ 灰色预测在数据非指数增长时强行使用；④ 只报点预测不给区间；⑤ 用 R² 代替预测误差指标（R² 高不代表外推好）。
- **论文写法**：先给"数据特征诊断图（时序图 + 自相关图 + 分解图）"，再写"模型识别→参数估计→检验→预测→区间"；关键句："为检验外推能力，将 20XX 年数据留作测试集，模型在测试集上的 MAPE 为 X%"。配图建议：原始-拟合-预测对比折线 + 预测区间带 + 残差自相关图。
- **优秀论文案例**：2005A 长江水质预测《基于回归分析的长江水质预测与控制》《水质的评价和预测模型》；2007A 人口预测《基于差分方程的人口预测模型》《基于Leslie模型的中国人口预测及模特卡罗仿真》；2016C 电池剩余放电时间预测；2023E 黄河水沙《黄河水沙监测数据分析》相关展示论文 E032/E176。〔归纳，来源 `_notes/_论文文本清单.tsv`〕
- **可创新方向**：① **组合预测**：用"误差倒数加权"或"最优权重（最小方差）"把 GM(1,1) 与 ARIMA 组合，并证明组合优于任一单项〔推理〕；② **预测 + 决策闭环**：2026 C 题要求"根据预报制定购电策略"，可把预测误差直接嵌入随机优化，做"预测-决策联合评估"；③ **不确定性量化**：用分位数回归或 conformal prediction 给出可校准的预测区间。

## 3. 题型 2：评价类

- **题型名称**：评价类（Multi-criteria Evaluation）
- **题型特征**：对象集合 ≥ 2，指标集合 ≥ 3，要求排序、分级或打分。
- **如何识别**：题面出现"评价 / 评估 / 比较 / 排序 / 优劣 / 合理性分析 / 影响力"；或出现"从……等方面分析……的合理性"（2026 E 题 Q1 原文即为此类〔原文〕）。
- **核心数学模型**：层次分析法（AHP）；熵权法、CRITIC、变异系数法；TOPSIS / 灰色关联 / RSR（秩和比）；模糊综合评价；主成分分析赋权；组合赋权（主客观加权）；DEA。
- **常用算法**：判断矩阵特征向量与一致性检验（CR<0.1）；极差/向量归一化；欧氏/马氏距离；隶属度函数构造；Kappa 一致性检验；Bootstrap 权重稳定性检验。〔归纳，来源 `_keydocs/数学建模国赛常见题型及算法汇总.txt` 与 `_keydocs/数学建模问题求解AI提示词.txt`〕
- **适用条件**：指标体系可覆盖评价目标的主要维度；指标间相关性可控（否则用 PCA/因子分析降维）；数据可获得或可合理量化。
- **优点**：结构清晰、易解释、易画图；TOPSIS 对正负向指标混合场景区分度高。
- **缺点**：权重选择直接决定结论，主观赋权易受质疑；TOPSIS 无法独立赋权，必须配权重方法；模糊综合评价的等级划分带人为性。
- **常见错误**：① 指标重复（如同时用"GDP"和"人均GDP"）；② 忘记正负向处理；③ 熵权法在指标数值差异极小时权重爆炸；④ AHP 判断矩阵不通过一致性检验仍继续用；⑤ 只给排序不给稳健性说明。
- **论文写法**：先画**指标体系层级图**，再给**指标说明三线表（指标/含义/单位/方向/数据来源）**，然后"赋权→合成→排序→稳健性"。关键句："为验证排序结论不依赖赋权方法，我们用熵权法、CRITIC 与 AHP 三种权重分别计算，得到的三组排序 Spearman 秩相关系数均大于 0.9"。配图：指标体系图、权重柱状图、得分排序条形图、权重敏感性折线图。
- **优秀论文案例**：2005A 长江水质综合评价《长江水质综合评价与预测的数学模型》；2006A 出版社资源配置《层次分析思想在出版社资源配置中的应用》；2008B 高等教育学费（13 篇，含《高校学费合理性研究》）；2010B 上海世博会影响力《对上海世博会文化影响力的定量评估》；2010D 学生宿舍设计方案评价（4 篇）；2012A 葡萄酒的评价（4 篇，含 A285）。〔归纳〕
- **可创新方向**：① **主客观组合赋权 + 博弈论组合**（用博弈均衡确定主客观权重比例）；② **动态评价**：把时间维度引入 TOPSIS，做"时序动态综合评价"；③ **可解释性**：用 SHAP/敏感性指数解释"排名为什么这样"，而不止给排名。

## 4. 题型 3：优化类

- **题型名称**：优化类（Optimization）
- **题型特征**：存在**决策变量**，要求"最大/最小/最优/最省/最经济/如何安排"。**这是国赛唯一 19/19 年全部出现的题型**〔归纳〕。
- **如何识别**：题面出现"使……最大/最小/尽可能……/最优方案/最经济/如何安排/如何设计"。
- **核心数学模型**：LP / IP / 0-1 规划 / MILP；非线性规划（NLP）；动态规划（DP）；多目标规划；鲁棒优化与随机规划；网络流；混合整数非线性规划。
- **常用算法**：单纯形法、内点法（LP/QP）；分支定界、割平面（MILP）；序列二次规划、信赖域（NLP）；梯度下降/牛顿法；启发式与元启发式（GA/SA/PSO/ACO/DE/TS）〔详见 `06_算法库/`〕。
- **适用条件**：决策变量、目标、约束可显式写出；目标与约束的数学性质（线性/凸/整数）被明确识别；规模在求解器可承受范围内。
- **优点**：结论明确且可执行；可做灵敏度分析与对偶分析，容易写出深度。
- **缺点**：建模错误会导致"数学上最优、现实中不可行"；大规模 MILP 求解时间不可控（对比赛时限致命）。
- **常见错误**：① **漏约束**（题目里以附注、附录、表格脚注形式给出的约束）；② 单位不统一（万元 vs 元、kW vs kWh、分钟 vs 小时）；③ 把非线性项当线性处理（未做分段线性化/未验证凸性）；④ 用元启发式求小规模精确可解问题，反而丢精度；⑤ 只给最优解不给"解的可行性验证"。
- **论文写法**：标准四段——"决策变量 → 目标函数 → 约束条件 → 求解算法"。变量定义用三线表（符号/含义/类型/单位/取值范围）；约束逐条给现实含义；结果给"最优方案表 + 与基准方案对比 + 灵敏度分析"。关键句："约束 (3.7) 表示第 t 时段储能电量不低于安全下限，该约束源于附录 1 的'电量必须保持在 1200—10800 kWh 之间'"。配图：建模流程图、可行域示意、最优解与参数关系曲线、甘特图（调度类）。
- **优秀论文案例**：1998A 投资组合《风险投资组合的线性规划模型》；2000B 钢管订购运输（8 篇）；2003B 露天矿车辆安排（9 篇）；2004B 电力市场输电阻塞《电力市场输电阻塞管理模型(特等奖)》；2011B 交巡警服务平台；2018B RGV 动态调度《基于 0-1 规划的单 RGV 动态调度模型》；2021C 原材料订购与运输；2024C 农作物种植策略。〔归纳〕
- **可创新方向**：① **从"求最优解"升级到"求鲁棒/随机最优解"**（2026 C 题的光伏预测误差、2026 E 题的竞价不确定性天然适配）；② **分层/分解求解**：把大 MILP 拆成"分配层 + 调度层"，用滚动时域（MPC）思想求解；③ **多目标 Pareto 前沿**而非单点加权解。

## 5. 题型 4：分类类

- **题型名称**：分类类（Classification）
- **题型特征**：给定类别定义（可能不均衡），把样本判归某一类。
- **如何识别**：题面出现"分为……类 / 判定 / 识别 / 判别 / 归类"；2026 E 题 Q2 明确给出 5 类（黄金词/重点词/潜力词/问题词/无效词）与 2 个维度（成本、效益），**这是"二维阈值分类"而非机器学习分类**〔原文〕。
- **核心数学模型**：判别分析（Fisher/贝叶斯）；逻辑回归；决策树与随机森林；SVM；KNN；阈值/规则分类；聚类后再贴标签（半监督）。
- **常用算法**：交叉验证；类别不均衡处理（重采样、代价敏感）；混淆矩阵与 F1/AUC；特征选择（方差过滤、递归消除、L1）；SHAP 可解释性。
- **适用条件**：类别定义清晰且可操作化；有标注样本或类别阈值可从题意导出。
- **优点**：直接给出判定规则，便于业务落地。
- **缺点**：类别边界模糊时精度下降；样本极不均衡时少数类识别差。
- **常见错误**：① **把"题目给了类别定义"当成"有标签数据"**（2026 E 题的五类词并无标注样本，只能用成本/效益二维阈值或聚类划分，且必须自证划分合理性）〔推理〕；② 不做类别不均衡处理；③ 用准确率评价不均衡分类；④ 特征与标签存在信息泄漏。
- **论文写法**：先给**分类标准的形式化定义**（如"设消费额中位数为 C₅₀、效益指标中位数为 B₅₀，则黄金词 = {C ≤ C₅₀ 且 B ≥ B₅₀}"），再给分类结果分布表，最后给"分类边界的敏感性分析"（阈值上下浮动 10% 时各类词数量的变化）。配图：二维散点分类图、混淆矩阵、特征重要性条形图。
- **优秀论文案例**：2000A DNA 序列分类（6 篇，含《DNA序列分类的数学模型》）；2005C 雨量预报方法优劣评价；2006D 煤矿瓦斯（分类+网络流）。〔归纳〕
- **可创新方向**：① **阈值内生**：把分类阈值作为决策变量，与下游优化（2026 E 题的投放优化）联合建模，形成"分类-决策闭环"；② **可解释分类**：用决策树/规则集输出"业务可读"的判词；③ **不确定性分类**：给出每个关键词属于各类的概率而非硬标签。

## 6. 题型 5：聚类类

- **题型名称**：聚类类（Clustering）
- **题型特征**：无标签，要求按相似性分组，常伴随"分群/分组/划分/典型日/典型场景"。
- **如何识别**：2025C NIPT"依据 BMI 对孕妇进行合理分组"〔原文〕；2026 E"按照投入成本与效益将关键词进行分类"（可先用聚类探索）〔推理〕。
- **核心数学模型**：K-means / K-medoids；层次聚类；DBSCAN；高斯混合模型（GMM）；谱聚类；动态规划最优分段（一维有序聚类）；约束聚类（单调性约束）。
- **常用算法**：肘部法则/轮廓系数/CH 指数定 K；Gap Statistic；Bootstrap 稳定性；类内-类间距离准则；对有序列数据用**最优分段（Fisher 最优分割 / 动态规划）**。
- **适用条件**：样本规模可控；距离度量有意义；簇结构确实存在（先做可视化或 Hopkin 统计量）。
- **优点**：无需标签，探索性强；可为后续分类/优化提供结构。
- **缺点**：K-means 需预设 K 且对异常值敏感；DBSCAN 参数 eps/minPts 敏感；聚类结果不稳定。
- **常见错误**：① 不做标准化就聚类（量纲小的变量失效）；② 用 K-means 处理非凸簇；③ 只给聚类图不给 K 的选择依据与稳定性检验；④ 对**有序变量**（如 BMI 分组必须连续且单调）直接套 K-means，得到不连续的分组〔推理，2025C 题的关键坑〕。
- **论文写法**：先"数据分布探索图"，再"K 的选择（肘部+轮廓系数+稳定性）"，然后"聚类结果与业务解释"，最后"聚类稳健性（Bootstrap 重抽样下 ARI 均值）"。关键句："考虑到 BMI 分组必须是连续区间且组内风险单调，我们采用带单调性约束的一维动态规划最优分割，而非 K-means"。
- **优秀论文案例**：1994B 锁具装箱（聚类+组合）；2000A DNA 序列（聚类与分类并用）；2009D 会议筹备（分组）。**2025C NIPT 论文 C023 使用"动态规划聚类 + 单调性控制"完成 BMI 分组**〔原文，据 C023 摘要，原文为扫描件，经图像阅读核对〕。
- **可创新方向**：① **约束聚类**（连续性、单调性、组规模均衡）；② **聚类-回归联合**：先分组再对每组单独建模，用分组前/后 R² 提升量化分组价值；③ **聚类稳定性作为模型检验的一部分**。

## 7. 题型 6：回归类

- **题型名称**：回归类（Regression）
- **题型特征**：要求"分析……与……的关系""建立……与……的关系模型""分析影响因素"。
- **如何识别**：2025C Q1"分析胎儿 Y 染色体浓度与孕妇的孕周数和 BMI 等指标的相关特性，给出相应的关系模型，并检验其显著性"〔原文〕；2026 A 题附录直接给出物性经验公式，属"已知回归式需拟合系数"〔推理〕。
- **核心数学模型**：一元/多元线性回归；多项式与非线性回归；岭回归/LASSO/弹性网；广义线性模型（Logistic/Poisson）；混合效应模型（随机截距/随机斜率）；分位数回归；广义可加模型。
- **常用算法**：最小二乘/加权最小二乘/极大似然；逐步回归与 AIC/BIC 选择；正则化路径与交叉验证；残差诊断（正态性、异方差、自相关）；多重共线性诊断（VIF）；稳健标准误。
- **适用条件**：自变量与因变量关系可由函数族近似；样本量 ≥ 变量数的 10 倍〔推理〕；数据独立同分布或可用混合效应处理分组结构。
- **优点**：可解释性强、系数有明确含义、便于做显著性检验。
- **缺点**：线性假设过强；对异常值敏感；遗漏变量会导致系数有偏。
- **常见错误**：① 不做残差诊断；② 直接对非线性关系套线性回归；③ 忽略**分组结构**（同一孕妇多次检测的重复测量必须用混合效应模型而非普通回归）〔推理，2025C 的核心方法学点〕；④ 只报 p 值不报效应量与置信区间；⑤ 用 R² 比较不同因变量变换后的模型。
- **论文写法**：先给散点矩阵与相关系数矩阵，再给模型形式与估计结果表（系数、标准误、t 值、p 值、置信区间），然后"模型诊断（残差图 + QQ 图 + VIF）"，最后"结论解释（每增加 1 单位 X，Y 平均变化 β，95%CI）"。关键句："由于同一孕妇存在多次检测，数据存在嵌套结构，我们采用含随机截距与随机斜率的线性混合效应模型（LMEM），固定效应为孕周与 BMI"。
- **优秀论文案例**：2005A《基于回归分析的长江水质预测与控制》；2008B《多因子影响下的高等教育学费模型》；**2025C 论文 C023 使用 LMEM，R²=0.8092**〔原文，据 C023 摘要〕。
- **可创新方向**：① **混合效应 / 分层建模**处理重复测量；② **非线性 + 可解释**（GAM 或分段回归）；③ **因果推断**：从"相关"升级到"控制混杂后的效应估计"（倾向得分、工具变量）〔推理〕。

## 8. 题型 7：微分方程类（ODE）

- **题型名称**：微分方程类（Ordinary Differential Equations）
- **题型特征**：题目描述"随时间变化的速率/增长/衰减/传播/冷却/运动"，要求给出演化规律。
- **如何识别**：出现"变化率""增长率""传播""衰减""冷却""动力学""随时间变化"；或给出物理定律（牛顿冷却、Fourier、Fick、Malthus/Logistic）。
- **核心数学模型**：一阶/高阶 ODE；方程组（SIR/SEIR、Lotka-Volterra、房室模型）；分龄组递推（Leslie）；带时滞或脉冲的 ODE；最优控制（Pontryagin）。
- **常用算法**：解析求解（分离变量、常数变易）；数值求解（Euler、RK4、ode45、BDF/刚性求解器）；参数辨识（最小二乘 + 优化）；相图与稳定性分析（Jacobian 特征值）；灵敏度分析（Sobol/局部）。
- **适用条件**：机理清楚，且变量随时间连续变化；参数可从数据估计或有文献值。
- **优点**：机理性强、说服力高、易得高分；参数有物理解释。
- **缺点**：参数难标定；模型对参数敏感；刚性方程数值求解需谨慎。
- **常见错误**：① 不顾量纲与量级直接求解（刚性）；② 用显式 Euler 解刚性方程导致数值爆炸；③ 参数辨识时初值给错陷入局部最优；④ **不给"模型与实测的对比验证"**；⑤ 忽略守恒律（能量、质量），导致结果非物理。
- **论文写法**：机理推导要有依据（引用物理定律与题给条件），模型假设用"假设内容 + 依据 + 影响"三要素写；求解给"离散格式 + 步长选择理由 + 稳定性分析"；验证给"与实测/守恒量对比"。关键句："取时间步长 $Delta t=1$ s、空间步长 $Delta x=0.1$ mm，步长比 $r=aDelta t/Delta x^2approx 50 gg 0.5$，显示格式不再稳定，故必须采用隐式格式"〔原文句式，来源 2018A 优秀论文〕。
- **优秀论文案例**：1996A 最优捕鱼策略（7 篇）；2003A SARS 传播（9 篇，含《考虑自愈的SARS的传播模型》）；2009A 制动器试验台（6 篇）；2013A 车道被占用（5 篇，含《基于差分方程和元胞自动机的交通阻塞模型》）。〔归纳〕
- **可创新方向**：① 从确定性 ODE 升级到**随机微分方程 / 带噪声的动力学**；② **最优控制**：把"给定策略求演化"升级为"求最优策略"；③ **参数可辨识性分析**（哪些参数组合可辨识，哪些不可辨识——这是 2026 A 题的潜在加分点）。

## 9. 题型 8：偏微分方程类（PDE）

- **题型名称**：偏微分方程类（Partial Differential Equations）
- **题型特征**：物理量同时随**时间与空间**变化；涉及传热、传质、扩散、波动、电磁场。
- **如何识别**：出现"温度分布""浓度分布""热传导""扩散""漫延""场""空间不同位置"；2026 A 题要求给出"到药材中心距离 0、0.5、1、1.5、2 cm 处"的结果〔原文〕，是**空间分布**的直接标志。
- **核心数学模型**：热传导方程（抛物型）、扩散方程（Fick 第二定律）、波动方程（双曲型）、Laplace/Poisson 方程（椭圆型）、对流-扩散方程、反应-扩散方程、**移动边界/Stefan 问题**（2026 A 题 Q4 半径从 2 cm 收缩到 1.198 cm）〔原文〕。
- **常用算法**：有限差分法（显式/隐式/Crank-Nicolson）；有限元法；有限体积法；谱方法；方法线（MOL）；坐标变换处理变域；自适应网格；三对角方程组的追赶法（Thomas）。
- **适用条件**：控制方程与边界条件（Dirichlet/Neumann/Robin）明确；区域几何可用规则网格或简单变换处理；参数可估计。
- **优点**：物理机理最扎实，是 A 题级别的"硬核"解法；可与参数反演、优化结合形成完整闭环。
- **缺点**：实现复杂、调参耗时；数值稳定性与精度需专门论证；三维/变系数问题计算量大。
- **常见错误**：① **边界条件类型搞错**（把对流换热写成恒温）；② 圆柱/球坐标在 r=0 处的奇异性未处理；③ 变系数问题仍用显式格式；④ 只给数值结果不给**网格收敛性验证**（步长减半结果是否收敛）；⑤ 移动边界问题忘记做坐标变换，直接删网格导致守恒量丢失；⑥ 无量纲化没做，导致量级混乱。
- **论文写法**：按"控制方程 → 边界条件与初始条件 → 无量纲化（可选）→ 离散格式与稳定性 → 求解与验证 → 结果分析"五段写。关键句："为验证网格无关性，将空间步长由 0.2 mm 减半至 0.1 mm 后，中心温度在 1800 s 时刻的相对变化小于 0.05%，说明数值解已收敛"。配图：温度/浓度时空云图、不同时刻的径向剖面曲线、网格收敛性曲线、与实测对比图。
- **优秀论文案例**：2018A 高温作业专用服装设计（3 篇，含《基于非稳态导热的高温作业专用服装设计》）；2020A 回焊炉温曲线（《基于一维热传导方程的回焊炉炉温模型》，注：**该批 PDF 为扫描件，正文未能文本化**）；2025B 碳化硅外延层厚度（B060，含"双光束干涉 + Drude 模型 + 牛顿迭代反演"，**扫描件，经图像核对**）。〔归纳〕
- **可创新方向**：① **变物性 + 移动边界**耦合（2026 A 题 Q4 的天然创新点）；② **参数反演 + 不确定性量化**（用贝叶斯或集合卡尔曼反演 D、h、k_m 并给出后验区间）；③ **降阶模型（POD/代理模型）**加速优化循环。

## 10. 题型 9：动力系统类

- **题型名称**：动力系统类（Dynamical Systems）
- **题型特征**：多个状态变量相互耦合、存在反馈与演化，关注长期行为（平衡点、周期、混沌）。
- **如何识别**：出现"系统""反馈""稳定""演化""平衡状态""多主体互动"（2026 B 题的多干扰源环境可视为动力系统）〔推理〕。
- **核心数学模型**：状态空间模型；离散映射；Lotka-Volterra；SIR 族；系统动力学（存量-流量-反馈回路）；多智能体模型。
- **常用算法**：数值积分；相图绘制；不动点求解与 Jacobian 特征值判定；分岔分析；李雅普诺夫指数；系统动力学仿真（Vensim/Stella 思路用 Python 复现）。
- **适用条件**：系统内部存在明确反馈机制；状态变量的时间尺度可分辨。
- **优点**：适合宏观长期趋势与政策情景分析；图示（因果回路图）非常直观。
- **缺点**：参数多且难标定；定量精度低于 ODE；易变成"定性画图"。
- **常见错误**：① 只有因果回路图没有方程（缺乏定量）；② 参数靠猜，不做校准；③ 不检验稳定性。
- **论文写法**：先给**因果回路图/存量流量图**，再给方程系统，然后给仿真结果与情景对比（基准/乐观/悲观）。关键句："在基准情景下系统于第 8 年达到稳态；当政策参数上升 20% 时，稳态水平提高 12%，但到达稳态的时间延长至 11 年"。
- **优秀论文案例**：2007A 中国人口增长（含系统动力学〔推理〕）；2003A SARS 传播（动力系统 + 预测）。〔归纳〕
- **可创新方向**：① 系统动力学 + 优化（把政策参数作为决策变量）；② 多主体仿真（ABM）刻画 2026 B 题的搜索-清除过程。

## 11. 题型 10：图论类

- **题型名称**：图论类（Graph Theory）
- **题型特征**：对象间存在"连接/相邻/可达/冲突"关系，需在图上做结构分析。
- **如何识别**：出现"网络""节点""路径""连通""相邻""覆盖""冲突对"；2026 D 题的"当两个用频计划的时间区间和频段区间都存在交叠时，则判定它们之间存在时频冲突"〔原文〕——**这是把冲突关系建图的标准指令**。
- **核心数学模型**：邻接矩阵与关联矩阵；连通性/强连通；最短路径；最小生成树；匹配与指派；网络流；着色与独立集；覆盖；中心性；PageRank/特征向量排序。
- **常用算法**：BFS/DFS；Dijkstra/Floyd/Bellman-Ford；Kruskal/Prim；匈牙利算法；Ford-Fulkerson/最小费用流；贪心着色/DSATUR；最大独立集启发式〔详见 `06_算法库/图与网络算法/`〕。
- **适用条件**：关系可离散化为边；节点/边数在可求解规模内。
- **优点**：结构清晰、算法成熟、可视化漂亮（网络图是论文加分项）。
- **缺点**：大规模 NP-hard 问题需近似；图的构建方式（边权定义）会显著影响结论。
- **常见错误**：① **边的定义不严谨**（"冲突"是否传递？时间区间 [a,b) 与 [b,c) 是否算重叠？2026 D 题用半开区间 [80,90) 与 [35,40)，**端点相接不算冲突**，这是必须写清的边界规则）〔推理，据 2026 D 题附件格式〕；② 有向图当无向图处理；③ 不检查图连通性就开始排序；④ 最短路上直接套 Dijkstra 而忽略负权。
- **论文写法**：先给"图的形式化定义"（顶点集、边集、边权定义），再给"图的性质统计"（节点数、边数、度分布、连通分量数），然后算法与结果。关键句："将 150 个用频计划视为顶点，若两计划存在时频冲突则连边，得到冲突图 $G=(V,E)$，其中 $|V|=150$、$|E|=$（实测值），图的最大度为 D，说明冲突分布呈……"。
- **优秀论文案例**：1993B 足球队排名（竞赛图 + 特征向量法）；1998B 灾情巡视（MTSP + 图论）；2011B 交巡警平台（图论 + 选址）；2020D 信贷（网络结构辅助）。〔归纳〕
- **可创新方向**：① **冲突图 + 着色/独立集**直接给出消解下界（2026 D 题的天然创新点）；② 图上机器学习（GNN）预测冲突风险〔推理〕；③ 多层网络（时间层 × 频段层）联合建模。

## 12. 题型 11：路径规划类

- **题型名称**：路径规划类（Path Planning / Routing）
- **题型特征**：要求给出"怎么走/走哪条/走遍所有点/最短时间"，常带载具速度、时间窗、容量约束。
- **如何识别**：出现"路线""路径""巡视""遍历""最短时间""逃生""巡游"；2026 B 题要求机器狗"从原点出发……完成任务的时间越短越好"〔原文〕；2025D 题要求"最佳逃生路径"〔原文〕。
- **核心数学模型**：最短路；TSP/MTSP；VRP 及其变体（CVRP、VRPTW）；中国邮递员问题；覆盖路径规划（栅格/牛耕式）；带时变权的最短路（2025D 中巷道水位随时间变化，边权是时间的函数）。
- **常用算法**：Dijkstra/A*；2-opt/3-opt/Or-opt；插入法（最近插入、最远插入）；Clarke-Wright 节约算法；蚁群/遗传；LKH；时变最短路的时间展开图或标签算法。
- **适用条件**：路网/区域可离散化为图或栅格；移动时间可计算（速度 × 距离）。
- **优点**：结果直观、易可视化、与题目要求的"方案"高度契合。
- **缺点**：大规模 TSP/VRP 精确解不可行；启发式结果不稳定，需多次运行报最优/均值。
- **常见错误**：① 忽略"必须返回起点"（是否为回路）；② 忽略时间窗与容量；③ **时变网络**直接当静态最短路算（2025D 的致命错误）〔推理〕；④ 不报路径的可行性验证（是否真的走通）。
- **论文写法**：给出"图的构建 → 距离矩阵 → 算法 → 路径结果表（节点序列 + 分段耗时）→ 总时间"。关键句："由于巷道水位随时间上升，边权 $w_e(t)$ 分段变化，我们采用时间展开图将其转化为静态最短路问题，节点数由 N 增至 N×T"。
- **优秀论文案例**：1998B 灾情巡视路线（5 篇）；2007B 公交线路选择（8 篇，含《基于最小换乘次数的公交路线选择研究》）；2011B 交巡警平台调度；2025D 矿井突水逃生（D037，"实时动态网络的 Dijkstra 算法 + BFS 广度优先搜索"）〔原文，据 D037 摘要，扫描件经图像核对〕。
- **可创新方向**：① **在线路径规划**（2026 B 题中目标是逐步发现的，必须滚动重规划）；② 路径 + 任务分配的联合优化；③ 鲁棒路径（考虑检测误差导致目标位置不确定）。

## 13. 题型 12：调度类

- **题型名称**：调度类（Scheduling）
- **题型特征**：在时间轴上分配有限资源（机器、车辆、人员、频段、储能）以完成一组任务。
- **如何识别**：出现"安排""排班""调度""时序""什么时候做什么"；2026 C 题（储能何时充放）、2026 D 题（频段-时间资源分配）都是调度问题〔推理〕。
- **核心数学模型**：单机/并行机调度；作业车间调度（JSP）；资源受限项目调度（RCPSP）；周期性调度与班次设计；带储能的状态方程约束调度（2026 C）；区间调度与频道分配（2026 D）。
- **常用算法**：列表调度与优先规则；分支定界；约束规划（CP）；MILP；遗传算法/禁忌搜索；滚动时域优化（MPC）；离散事件仿真评估。
- **适用条件**：任务集与资源集明确；时序约束（先后、互斥、容量）可写成线性/逻辑约束。
- **优点**：直接对应实际运营，结果可用甘特图展示，说服力强。
- **缺点**：多数变体 NP-hard；多目标（效率 vs 公平 vs 成本）难以归一。
- **常见错误**：① 漏掉"切换时间/启动成本"；② 忽略资源容量上限（如"每两个相邻工作点之间最多只能容纳 2 台"〔原文，1995B〕）；③ 只给一张调度表不给**调度规则说明书**（1995B 明确要求"一份供现场人员使用的调度规则说明书"〔原文〕）；④ 甘特图与表格数据不一致。
- **论文写法**：先"调度问题三要素表（任务/资源/约束）"，再"数学模型（决策变量 = 何时何资源做何任务）"，然后"算法 + 甘特图 + 指标统计"。关键句："与单纯的静态排班不同，本问的资源可得性随水位变化，因此我们采用每 60 s 滚动一次的重调度机制"。
- **优秀论文案例**：1995B 天车与冶炼炉作业调度（15 篇，含《天车与冶炼炉作业调度的Petri网模型》）；2001B 公交车调度（8 篇）；2007D 体能测试时间安排/巡检排班；2017D 巡检线路的排班（3 篇）；2021D 连铸切割的在线优化；2023D 湖羊空间利用率（D039）。〔归纳〕
- **可创新方向**：① **在线/实时调度**（异常事件触发重调度，2026 D 题的"调整幅度"代价天然适配）；② 调度 + 鲁棒性（需求/时长不确定）；③ 用仿真验证调度方案的鲁棒性。

## 14. 题型 13：机器学习类

- **题型名称**：机器学习类（Machine Learning）
- **题型特征**：数据量大、维度高、关系非线性且难以机理建模；目标是预测、分类或特征重要性。
- **如何识别**：附件提供数千至数十万行数据（2026 E 题 2227 行关键词、2026 C 题 365×144 时间序列）〔原文〕。
- **核心数学模型**：随机森林/GBDT/XGBoost/LightGBM；SVM；神经网络与 LSTM；集成学习（Bagging/Boosting/Stacking）；降维（PCA/t-SNE/UMAP）；聚类。
- **常用算法**：K 折交叉验证；网格/贝叶斯超参搜索；特征工程（滑窗、滞后、周期编码）；正则化；SHAP/特征重要性；Stacking 融合。
- **适用条件**：样本量足够（一般 ≥ 数百）；有可用的验证集；特征与目标有统计关联。
- **优点**：拟合复杂非线性能力强，预测精度通常优于传统模型。
- **缺点**：黑箱、可解释性弱；小样本易过拟合；**国赛评审对"堆模型"并不买账**（`_keydocs/AI+数学建模工作流讲义.txt` 明确写道"模型堆砌，听起来高级但不落地"是风险之一〔原文〕）。
- **常见错误**：① 数据泄漏（用未来数据构造特征、标准化用了全样本）；② 不做基线对比（不与线性回归/灰色模型比）；③ 只报精度不报特征重要性；④ **把"用了复杂算法"当成创新**（用户明确禁止，`08_高分论文创新方法库.md` 详述）。
- **论文写法**：必须有"数据规模与特征表 → 基线模型 → 改进模型 → 消融实验 → 特征重要性/可解释性 → 误差分析"。关键句："为证明集成模型的增益来自模型结构而非特征本身，我们做了消融实验：去掉滚动统计特征后 XGBoost 的 RMSE 由 0.83 升至 1.47，说明特征工程贡献大于模型选择"。
- **优秀论文案例**：2000A DNA 分类（神经网络/判别）；2008B《基于BP神经网络的我国高等教育学费模型研究》；2019E《基于数据挖掘对"薄利多销"进行分析》；2020C 信贷决策（决策树 + 非线性规划：《基于梯度下降的决策树算法与非线性规划的信贷风险评估与信贷策略模型》）。〔归纳〕
- **可创新方向**：① **机理 + 数据混合建模**（PINN、灰箱模型）——这是当前最容易拿"创新分"的方向；② **可解释机器学习**（SHAP + 业务解释）；③ **不确定性量化**（分位数回归森林、深度集成）。

## 15. 题型 14：时间序列类

- **题型名称**：时间序列类（Time Series）
- **题型特征**：数据按时间等间隔或不等间隔采集，存在自相关、趋势、季节、周期、突变。
- **如何识别**：出现"随时间变化""季节性""周期性""突变""逐时/逐日/逐月数据"；2023E 题面即"分析近 6 年该水文站水沙通量的突变性、季节性和周期性等特性"〔原文〕。
- **核心数学模型**：AR/MA/ARMA/ARIMA/SARIMA；VAR（向量自回归）；GARCH（波动聚集）；状态空间与卡尔曼滤波；STL 分解；小波分析；变点检测（PELT、贝叶斯变点）；Hurst 指数。
- **常用算法**：ADF/KPSS 平稳性检验；ACF/PACF 定阶；AIC/BIC；Ljung-Box 残差检验；滚动预测；谱分析（FFT）找周期；小波多尺度分解。
- **适用条件**：序列长度足够（一般 ≥ 50 点）；结构相对稳定；采样间隔一致。
- **优点**：能显式刻画自相关与季节性；可给出置信区间；诊断工具成熟。
- **缺点**：对结构突变敏感；多变量序列需 VAR 或协整分析；长程预测发散。
- **常见错误**：① 不做平稳化；② 用 R² 评价时序模型（应看 MAPE/RMSE 与残差白噪声检验）；③ 忽略节假日的日历效应（2026 E 题明确要求分析"假日效应"〔原文〕）；④ 只做一个模型不做对比。
- **论文写法**：图（时序图 + 分解图 + ACF/PACF + 谱图）→ 检验 → 建模 → 预测与区间 → 突变/周期结论。关键句："对去趋势序列做 FFT 后，在 365 天与 182.5 天处出现显著峰值，与年周期及半年周期的物候规律一致"。
- **优秀论文案例**：2023E 黄河水沙监测数据分析（E032、E176）；2024E 交通流量管控；2005A 长江水质时间序列。〔归纳〕
- **可创新方向**：① **多尺度分解 + 分别建模 + 重构**（EMD/VMD + 各分量预测）；② **变点检测 + 分段建模**；③ 时序 + 因果（Granger 因果、传递熵）。

## 16. 题型 15：多目标优化类

- **题型名称**：多目标优化类（Multi-objective Optimization）
- **题型特征**：两个及以上互相冲突的目标，不存在单一最优解，只有折中解集。
- **如何识别**：题面出现两个并列的"尽可能/尽量"（1998A"使净收益尽可能大，而总体风险尽可能小"〔原文〕）；或出现"在……前提下，使……"（2026 B 题 Q3"在确保所有干扰源被清除的前提下，完成任务的时间越短越好"〔原文〕）。
- **核心数学模型**：多目标规划（加权和、ε-约束、目标规划、min-max）；Pareto 最优与支配关系；多目标进化算法（NSGA-II/III、MOEA/D、SPEA2）。
- **常用算法**：权重扫描构造 Pareto 前沿；ε-约束法；NSGA-II 非支配排序 + 拥挤度；理想点法（TOPSIS 思想）；交互式方法。
- **适用条件**：目标之间确实冲突（需先证明冲突性，否则退化为单目标）；目标可比或可归一。
- **优点**：结论更贴近真实决策；Pareto 前沿图是论文的高分图。
- **缺点**：计算量大；权重选择仍需主观判断；结果解释复杂。
- **常见错误**：① **伪多目标**：两个目标其实同向（如"最小化成本"和"最小化材料用量"），强行做 Pareto 属于画蛇添足〔推理〕；② 只做加权和而不给权重敏感性（不同权重给出完全不同的解）；③ 目标未归一化就加权；④ 不给 Pareto 前沿图，只给一个"综合最优解"。
- **论文写法**：先"目标冲突性论证"，再"Pareto 前沿 + 拐点/膝点解推荐"，最后"与单目标解对比"。关键句："两目标相关系数为 −0.83，说明确实冲突；我们采用 ε-约束法扫描得到 42 个非支配解，并推荐拐点解（成本 8.4 万元、风险 0.19）作为实施方案"。
- **优秀论文案例**：1998A 投资组合（多目标 + 有效前沿）；2001B 公交车调度（乘客等待 vs 公司成本）；2021C 订购与转运（经济性 vs 损耗）。〔归纳〕
- **可创新方向**：① **多目标 + 鲁棒**（在不确定参数下求鲁棒 Pareto 前沿）；② **分层多目标**（2026 B 题的"先保证清除率，再最小化时间"是典型的字典序多目标）〔原文〕；③ 交互式/偏好驱动的多目标决策。

## 17. 题型 16：博弈类

- **题型名称**：博弈类（Game Theory）
- **题型特征**：多个决策主体，各自最优反应相互影响。
- **如何识别**：出现"多方""竞争""对抗""策略互动""其他玩家也会……"；2020B 穿越沙漠 Q3 的多玩家版本是国赛最典型的博弈题〔原文〕。
- **核心数学模型**：完全信息静态博弈（Nash 均衡）；动态博弈（子博弈完美均衡、逆向归纳）；演化博弈（复制动态）；Stackelberg 主从博弈；拍卖与竞价模型。
- **常用算法**：纳什均衡求解（支持枚举、Lemke-Howson、非线性互补）；最优反应迭代；复制动态数值积分；逆向归纳；MILP 编码均衡条件。
- **适用条件**：参与者、策略集、收益函数可明确写出；理性假设成立。
- **优点**：能刻画多主体的策略互动，理论高度高。
- **缺点**：均衡可能不存在或不唯一；难以验证；与国赛"给方案"的要求衔接需额外说明。
- **常见错误**：① 把单人优化问题硬说成博弈；② 只算均衡不讨论**均衡的现实意义与可实现性**；③ 忽略信息结构（谁在什么时候知道什么）。
- **论文写法**：先"博弈三要素（参与人、策略、收益）"，再"均衡求解与存在性/唯一性讨论"，最后"政策含义"。关键句："由于收益矩阵满足超模性，博弈为超模博弈，纯策略纳什均衡存在；我们进一步证明在给定参数区间内均衡唯一"。
- **优秀论文案例**：2020B《基于动态规划、统计分析、静态博弈的穿越沙漠游戏策略设计》；1993B 足球队排名（竞赛图与博弈）；2007C 手机套餐（博弈视角）。〔归纳〕
- **可创新方向**：① **博弈 + 仿真**（有限理性下的演化结果）；② **主从博弈 + 优化**（上层定价、下层响应）；③ 2026 E 题的竞价环境可建为"不完全信息竞价博弈"〔推理〕。

## 18. 题型 17：概率统计类

- **题型名称**：概率统计类（Probability & Statistics）
- **题型特征**：含随机变量、随机过程、测量误差、抽样、假设检验。**这与优化类并列为 19/19 年全部出现的基础题型**〔归纳〕。
- **如何识别**：出现"随机""误差""概率""置信度""抽样检测""分布""波动"；2024B Q1"在 95% 的信度下认定零配件次品率超过标称值，则拒收"〔原文〕；2026 B 题的"示向度误差在 [−1°,1°] 范围内"〔原文〕。
- **核心数学模型**：常见分布与参数估计；假设检验（U/t/χ²/F）；序贯概率比检验（SPRT）；贝叶斯推断；随机过程（泊松、马尔可夫、布朗运动）；极值理论；置信区间与 Bootstrap。
- **常用算法**：MLE/矩估计；Bootstrap/Jackknife；蒙特卡洛；MCMC（Metropolis-Hastings、Gibbs）；EM 算法；序贯抽样设计。
- **适用条件**：随机机制可设定；样本量足以支撑统计推断；分布假设可检验。
- **优点**：结论带置信水平，严谨；是机理模型的必要补充。
- **缺点**：分布假设不成立时结论失效；小样本下功效不足。
- **常见错误**：① 样本量与检验功效不匹配（2024B Q1 要求"检测次数尽可能少"的抽样方案，必须做**功效分析**而非简单套公式）〔推理〕；② 把"置信度"与"概率"混为一谈；③ 多重比较不校正；④ 蒙特卡洛不报重复次数与标准误。
- **论文写法**：先"随机变量的分布假设与依据"，再"统计量与检验"，最后"结论 + 置信区间 + 功效"。关键句："为在 95% 信度下判定次品率是否超过标称值 10%，我们采用单侧二项检验；给定功效 0.8 与允许误差 0.03，所需最小样本量为 n=…，该方案的实际犯第一类错误概率为 4.8%"。
- **优秀论文案例**：2024B 生产过程决策（抽样检测）；1999A 自动化车床（分布拟合 + 更新过程）；2009B 眼科病床（排队论 + 蒙特卡洛：《基于蒙特卡洛模拟的眼科病床安排排队模型》）；2024D 反潜深弹命中概率（截尾正态 + 概率积分）。〔归纳〕
- **可创新方向**：① **贝叶斯方法**给出参数后验分布（比点估计更有说服力）；② **序贯/自适应抽样**（2024B 的"检测次数尽可能少"）；③ 不确定性传播分析（把检测误差传播到最终决策）。

## 19. 题型 18：仿真类

- **题型名称**：仿真类（Simulation）
- **题型特征**：系统复杂到难以解析求解，或题目**强制要求**用仿真器。
- **如何识别**：出现"模拟""演练测试""通过模拟器""蒙特卡洛"；**2026 B 题是本资料包中唯一强制外部仿真器的题**——题目要求"通过模拟器进行演练测试"并提交三次正式测试的日志〔原文〕。
- **核心数学模型**：离散事件仿真（DES）；蒙特卡洛仿真；元胞自动机；多智能体仿真（ABM）；系统动力学仿真；数字孪生式仿真。
- **常用算法**：事件调度/时间推进机制；随机数生成与方差缩减（对偶变量、控制变量、重要性抽样）；重复运行与置信区间；敏感性/情景分析；拉丁超立方抽样。
- **适用条件**：系统过程可分解为事件序列；随机因素可参数化；有验证真值或一致性检验手段。
- **优点**：能处理解析不可解的系统；可直接复现"过程"，与题目的策略要求高度一致。
- **缺点**：结果随机，必须做重复次数与置信区间论证；计算量大；**仿真结果不等于最优解**。
- **常见错误**：① 只跑 1 次仿真就报结果；② 不报随机种子与重复次数；③ 把仿真当优化（只评估不搜索）；④ **不验证仿真器与模型的对应关系**（2026 B 题必须用官方模拟器，自建仿真只能用于离线策略开发）〔推理〕。
- **论文写法**：给"仿真流程图 + 参数表 + 重复次数与置信区间 + 结果分布"；策略类论文还要给"消融/对比实验（不同策略在同一批案例上的表现）"。关键句："为避免单次运行的偶然性，每个策略在 100 个随机生成的案例上各运行一次，报告清除比例的均值与 95% 置信区间"。
- **优秀论文案例**：2025A 烟幕干扰弹（A196 用多起点变步长搜索 + 差分进化，并用粒子群交叉验证，相对误差 0.01%）〔原文，据 A196 摘要，扫描件经图像核对〕；1999A《刀具问题的仿真及灵敏度分析》；2009B 蒙特卡洛排队仿真；2018A《基于多原则比较和蒙特卡洛模拟的 RGV 动态调度模型》。〔归纳〕
- **可创新方向**：① **仿真 + 优化（Simulation-based Optimization）**：用仿真评估、用算法搜索，形成闭环；② **方差缩减**提升仿真效率；③ **数字孪生式在线仿真**（2026 B 题的连续重规划）。

## 20. 题型 19：组合优化类

- **题型名称**：组合优化类（Combinatorial Optimization）
- **题型特征**：决策空间是有限但巨大的离散集合（排列、子集、分配、着色、覆盖）。
- **如何识别**：出现"选择哪些""如何分组""调整哪些""撤销哪些"，且选项数是离散的；2026 D 题的"一个用频计划只能调整其中一个参数或撤销"〔原文〕是典型组合决策。
- **核心数学模型**：背包/装箱；指派；TSP/VRP；着色；覆盖与集合覆盖；最大独立集/团；排序与排样；调度。
- **常用算法**：精确法（分支定界、割平面、动态规划、列生成）；近似法（贪心、局部搜索、2-opt）；元启发式（GA/SA/ACO/TS/LNS）。
- **适用条件**：问题可离散化；解空间有可利用的结构（如区间图、二分图）。
- **优点**：模型与实际决策一一对应；可用下界/上界论证解的质量。
- **缺点**：多数问题 NP-hard；大规模下只能近似；需给出解质量评估。
- **常见错误**：① 不做**问题规模评估**就上元启发式（小规模应用精确解并给最优性证明）；② 不给上下界或与贪心基线的对比；③ 元启发式只报一次运行的最优值（应报多次运行的均值/最优/方差）；④ 约束处理用惩罚函数但惩罚系数无依据。
- **论文写法**：给"问题规模表 → 精确/近似选择理由 → 算法 → 解质量评估（与下界/基线的 gap）"。关键句："该问题规模为 $|V|=150, |E|=$…，属于中等规模 NP-hard 问题，我们先用贪心构造初始解（目标值 X），再用禁忌搜索在 30 s 内改进至 Y，与线性松弛下界 Z 的 gap 为 3.7%"。
- **优秀论文案例**：1994B 锁具装箱；1997B 截断切割；2003B 露天矿车辆安排；2018B RGV 调度；2023B 多波束测线（测线布置）；2023D 湖羊羊栏分配。〔归纳〕
- **可创新方向**：① **问题结构利用**（识别区间图/二分图从而用多项式算法）；② **精确法与启发式混合**（大邻域搜索 + 精确子问题）；③ 面向 2026 D 题的"最小调整代价冲突消解"可建为**加权最小顶点删除/着色**问题。

## 21. 题型 20：混合模型类

- **题型名称**：混合模型类（Hybrid Modeling）
- **题型特征**：单一模型无法覆盖题目要求，需要多模型串联、并联或嵌套。
- **如何识别**：题目有 3—5 问且各问性质不同；或一问内同时要求"分析规律 + 给方案 + 检验"。
- **常见混合结构**：
  - **串联型**：聚类分群 → 分群回归 → 分群优化（2025C NIPT 的典型结构〔归纳〕）。
  - **并联型**：多模型并行求解 → 结果对比/集成（2025A A196 用差分进化与粒子群互验〔原文〕）。
  - **嵌套型**：优化问题的目标函数由仿真/数值解给出（2026 A 题的"优化烘干制度"需反复求解 PDE）。
  - **评价-优化型**：先评价排序，再对优选对象做优化（2026 E 题 Q2→Q3 的结构〔推理〕）。
  - **机理-数据型**：机理模型给结构，数据驱动标定参数（2026 A 题的经验公式 + 反演）。
- **核心数学模型**：上述各模型的组合。
- **常用算法**：分层求解、交替迭代、代理模型加速、模型集成。
- **适用条件**：各子问题可独立定义；接口（变量传递）明确。
- **优点**：贴合真实问题、体现工作量和思维深度，是拿高分的主要路径。
- **缺点**：容易变成"模型堆砌"；接口不清会导致逻辑断裂；计算量叠加。
- **常见错误**：① **堆模型不解释为什么**（`_docs/AI+数学建模工作流讲义` 明确警告："模型堆砌，听起来高级但不落地"〔原文〕）；② 子模型之间变量命名/单位不一致；③ 上一问的输出没有真正成为下一问的输入（伪串联）。
- **论文写法**：必须画**总体技术路线图**，明确"每问用什么模型、为什么、模型之间如何衔接"；每问开头写"问题 X 分析"，说明该问的输入来自哪里。关键句："问题 2 得到的分群方案作为问题 3 的分层结构输入；为避免分组误差向下传播，我们在问题 3 中对分组边界做了 ±1 组的稳健性检验"。
- **优秀论文案例**：2025A A196《多情形下无人机烟幕遮蔽策略的建模与优化研究》（二分查找 + 多起点变步长搜索 + 差分进化 + 分层次优化，五问四算法）〔原文〕；2025C C023（混合效应 + 动态规划聚类 + Z 值判定 + FDR 控制）〔原文〕；2025E E030（Savitzky-Golay 滤波 + Spearman 相关 + 随机森林 + 多元回归）〔原文〕。
- **可创新方向**：① **机理-数据混合**（PINN/灰箱）；② **多模型结果集成**（用误差加权或 Stacking 融合多个模型的预测）；③ **分层/分阶段优化**（2026 B 题 Q5 的"先任务分配、再单目标求解、最后取时间区间交集"就是分层次优化）〔原文〕。

## 22. 题型判定的操作流程（比赛现场版）

```
读题
 ↓
逐问提取"动词"：求/预测/评价/设计/安排/分析/判定/检验
 ↓
判断是否存在【决策变量】？
 ├─ 是 → 优化类（继续判：目标几个？变量连续/整数/0-1？目标与约束线性否？）
 └─ 否 → 继续
 ↓
判断输出是否为【未来数值】？
 ├─ 是 → 预测类（继续判：有无外生变量？序列是否平稳？样本量？）
 └─ 否 → 继续
 ↓
判断是否需要【排序/分级】？
 ├─ 是 → 评价类（继续判：指标数、方向混合否、有无数据定权）
 └─ 否 → 继续
 ↓
判断是否有【物理/时空演化】？
 ├─ 是 → 只有时间 → ODE/动力系统；时间+空间 → PDE
 └─ 否 → 继续
 ↓
判断是否有【网络/路径/冲突关系】？
 ├─ 是 → 图论 / 路径规划 / 调度 / 组合优化
 └─ 否 → 概率统计类或纯数据分析类
 ↓
最后：检查是否一题多型 → 若是，设计混合模型结构与衔接
```

**重要提醒**：以上是**判定顺序建议**，不是硬规则。2026 五题全部为混合题型，必须多标签判定。

#### 3.5 给备赛的直接结论〔推理〕

1. **优化是唯一的"必修课"**：14 年中 13 年都有优化题，2020/2023/2024 三年更是每题都含优化标签。**LP/IP/NLP/多目标/MILP 建模 + 求解器（Gurobi/CPLEX/LINGO）+ 启发式（GA/SA/PSO）必须熟练。**
2. **数据处理是最大的"隐形分差"**：2018 年后几乎每套题都有"清洗—对齐—特征工程"的硬需求（发票、流水、车牌、光谱、投影矩阵）。**pandas/numpy 的熟练度直接决定能不能开始建模。**
3. **机理题在"窄化"但没消失**：2018A、2019A/B、2020A、2022A 都是高门槛机理题；想在 A 题出彩，**微分方程/偏微分方程 + 数值解（有限差分、RK）是硬通货**。
4. **评价题要"轻量化"**：不要再用"指标—赋权—打分"三段式凑篇幅，后期的评价都是**为了支持某个优化/风险决策**（2020C、2021C）。**评价类标签仍在，但独立成题的场景已经很少。**
5. **文件交付能力要专门练**：结果文件命名、格式（保留几位小数、行列顺序）、模板对齐，是被大量队伍忽视的固定失分点。
