# 二分法与黄金分割

## 1. 算法解决什么问题

一维搜索（line search）问题：在已知的单峰/单调区间 $[a,b]$ 上找函数零点或极值点，且**不能或不想求导**。国赛里它几乎总是出现在"外层套一个物理模型、内层需要反解一个参数"的场合——比如给定吃水深度反求重物球质量、给定储油量反求油位高度、给定热功率反求镜场间距。

- **二分法**：找单调连续函数的**根**（$f(x)=0$），每次把区间砍半。
- **黄金分割法（0.618 法）**：找**单峰函数的极小值点**，每次按黄金比缩短区间，比二分法更省函数求值次数。

两者都属于"精确算法"（ε-最优），不是启发式。

## 2. 输入与输出

| | 二分法 | 黄金分割法 |
|---|---|---|
| 输入 | 连续函数 $f$、含根区间 $[a,b]$、精度 $\varepsilon$、最大迭代 $N_{\max}$ | 单峰函数 $f$、单峰区间 $[a,b]$、精度 $\varepsilon$ |
| 前置条件 | $f(a)\cdot f(b)<0$ | $[a,b]$ 上 $f$ 严格单峰（$\exists$ 唯一极小） |
| 输出 | 近似根 $x^*$，满足 $|x^*-x_{\text{true}}|\le \varepsilon$ | 近似极小点 $x^*$ 与最优值 $f(x^*)$ |
| 可选输出 | 迭代次数、每步区间宽度（画收敛图用） | 总函数求值次数（写"仅用 xx 次试验"这一亮点） |

**工程包装**：国赛里真正的输入往往是"一个黑箱物理模型 + 一个约束"，例如〔原文〕2016A："以浮标的吃水深度为搜索变量，采用二分法……以锚链与海床的夹角小于 16° 为约束条件，逐步增加重物球的质量，采用二分法向水深 18m 进行逼近"。此时 $f$ 是"给定质量 $m$ → 解静力平衡 → 返回锚链夹角"的复合函数。

## 3. 算法步骤（伪代码级）

### 3.1 二分法（求根）

1. 输入 $f,\ a,\ b,\ \varepsilon,\ N_{\max}$。
2. **前置检查**：计算 $f_a=f(a)$、$f_b=f(b)$。若 $f_a\cdot f_b>0$，**报错退出**（区间内无根或根个数为偶），不要硬跑。
3. $k \leftarrow 0$。
4. **循环**：当 $(b-a)>\varepsilon$ 且 $k<N_{\max}$：
   1. $m \leftarrow (a+b)/2$，计算 $f_m=f(m)$。
   2. 若 $|f_m|\le \delta_f$（函数值容差，处理"根处函数值很小但区间未缩够"的情况），提前返回 $m$。
   3. 若 $f_a\cdot f_m<0$：置 $b\leftarrow m,\ f_b\leftarrow f_m$；否则置 $a\leftarrow m,\ f_a\leftarrow f_m$。
   4. $k \leftarrow k+1$。
5. 返回 $x^*=(a+b)/2$，及区间宽度 $b-a$ 作为误差上界。
6. 若循环因 $k=N_{\max}$ 退出，**必须在论文里声明"达到最大迭代次数，容差未满足"**，不要假装收敛。

### 3.2 黄金分割法（求单峰极小）

1. 输入 $f,\ a,\ b,\ \varepsilon$。取 $\tau=(\sqrt5-1)/2\approx0.618$。
2. $x_1 \leftarrow b-\tau(b-a)$，$x_2 \leftarrow a+\tau(b-a)$；计算 $f_1=f(x_1),\ f_2=f(x_2)$。**本步用了 2 次函数求值**。
3. **循环**：当 $(b-a)>\varepsilon$：
   1. 若 $f_1<f_2$：极小在左段 → $b\leftarrow x_2,\ f_2\leftarrow f_1$；$x_2\leftarrow x_1$；$x_1\leftarrow b-\tau(b-a)$；计算 $f_1=f(x_1)$。（**只新增 1 次求值**）
   2. 否则：$a\leftarrow x_1,\ f_1\leftarrow f_2$；$x_1\leftarrow x_2$；$x_2\leftarrow a+\tau(b-a)$；计算 $f_2=f(x_2)$。
4. 返回 $x^*=(a+b)/2$，$f^*=\min(f_1,f_2)$。
5. （可选）若已知 $f$ 是凸的，可在 step 3 前先用三点法/二阶差分**验证单峰性**，否则结果无保证。

### 3.3 外层套约束时的标准做法（国赛实战形态）

1. 固定一个待反解参数 $p$。
2. 写一个函数 `solve_physics(p)` 返回全部中间物理量。
3. 把"约束不满足"翻译成**有符号的残差** $g(p)$（如"锚链夹角 $-16°$"），保证 $g$ 对 $p$ 单调。
4. 用二分法对 $g(p)=0$ 求根，得到临界 $p^*$。
5. **用 $p^*$ 反向验算**全部原始约束（夹角、力矩、几何），把验算结果写成一张表放进论文。

## 4. 复杂度与收敛性

| 指标 | 二分法 | 黄金分割法 |
|---|---|---|
| 时间复杂度 | $O(\log_2\frac{b-a}{\varepsilon})$ 次函数求值 | $O(\log_{1/\tau}\frac{b-a}{\varepsilon})\approx O(1.44\log_2\frac{b-a}{\varepsilon})$ 次求值 |
| 单次迭代求值数 | 1 次 | 首轮 2 次，此后 **1 次/轮** |
| 空间复杂度 | $O(1)$ | $O(1)$ |
| 收敛速度 | 线性（公比 $1/2$） | 线性（公比 $\tau\approx0.618$） |
| 收敛性质 | **全局收敛**到区间内唯一的根（前提：连续 + 端点异号） | **全局收敛**到区间内的极小点（前提：严格单峰） |
| 精度-迭代关系 | 迭代 $k$ 次后误差 $\le (b-a)/2^{k+1}$ | 迭代 $k$ 次后误差 $\le \tau^{k-1}(b-a)$ |

**关键结论**：
- 两者都是**全局收敛**（在各自前提成立时），这是它们相对牛顿法/梯度法的最大优势——**不需要初值猜测，不会发散**。
- 二分法只能求**根**，不能直接求极值；要求极值需先求导再求根（相当于牛顿法的降级版）。
- 黄金分割法**只保证局部区间内的单峰极小**；若真实函数多峰，返回的是"你给的区间内那一个谷底"，论文里必须写清区间是怎么定的。
- 二分法**不能处理端点同号的区间**，这是最常见的现场崩溃点。

## 5. 参数与调参要点

| 参数 | 推荐取值 | 依据 |
|---|---|---|
| 区间宽度容差 $\varepsilon$ | 物理量 = 物理量有效位的 1/10～1/100。工程尺度（米）取 $10^{-4}\sim10^{-6}$；比值/角度取 $10^{-6}\sim10^{-8}$ | 〔推理〕通用经验。论文中应写成"$\varepsilon$ 由附件数据的有效位数确定" |
| 函数值容差 $\delta_f$ | 约为 $f$ 在根附近量纲尺度 $\times10^{-6}$ | 〔推理〕通用经验 |
| 最大迭代 $N_{\max}$ | $N_{\max}=\lceil\log_2((b-a)/\varepsilon)\rceil+5$，一般 50～100 足够 | 〔推理〕通用经验 |
| 初始区间 $[a,b]$ | **必须来自物理边界**，不要瞎猜。例如质量上界取"材料强度允许的最大值"，下界取 0 | 〔推理〕通用经验 |
| 黄金比 $\tau$ | 固定 $0.6180339887$，**不要四舍五入成 0.618** | 〔推理〕通用经验；0.618 的截断会破坏"每轮只新增 1 次求值"的复用性质 |
| 多点扫描辅助 | 先用 200～1000 点粗扫画 $f$ 的形状图，再定区间 | 〔推理〕通用经验；也是论文里最好看的一张图 |

**调参坑**：区间取得太宽会掩盖多峰，太窄会漏掉根。稳妥做法是先粗扫画出 $f(x)$ 曲线图，**图上肉眼确认单调/单峰**，再启动算法——这张图同时是论文的支撑图。

## 6. 优点

1. **无导数**：只要函数值可算，适用于黑箱物理仿真（解一次 ODE、跑一次有限元、查一次表）。
2. **全局收敛、绝不发散**：不需要初值，这对"参数物理意义明确、区间好定"的国赛题是决定性的。
3. **实现极短**，20 行以内，几乎不可能写错；现场时间紧张时是最稳的求解器。
4. **误差有解析上界** $(b-a)/2^{k+1}$，论文里可以直接写"精度可控到 $10^{-6}$"，非常好看。
5. 黄金分割法**自动复用**中间点，比"三等分搜索"省 1/3 的函数求值，正好呼应〔原文〕2018A"尽量用最可能少的试验"的表述。
6. 可与物理模型**解耦**：算法只认一个标量函数，模型改了算法不用改。

## 7. 缺点

1. **只能处理一维**。多参数反解必须退化成"固定其余参数，逐个扫"，或者换 Nelder-Mead / PSO。
2. **要求单峰/单调**。真实目标函数常带噪声（蒙特卡洛估出来的目标函数），二分法会被噪声带偏——此时应改用"多次重复取均值"或增大 $\varepsilon$。
3. **收敛慢**：线性收敛。要到 $10^{-10}$ 需要约 34 次迭代（二分），对"每次求值要跑 10 秒的仿真"来说很贵。
4. 二分法**不能直接优化**，必须先知道导数的符号结构；很多队伍误把它当优化器用，结果在题干要求的"最大值"上给出一个中点。
5. 黄金分割法**不能处理带约束问题**；约束要靠外层循环（"逐步增加质量"）人工扫描，精度受外层步长限制。

## 8. 适用规模与适用条件

**适用条件（全部满足才用）**：
- 决策变量**维数 = 1**（或可解耦成 1 维嵌套）；
- 目标/残差函数**连续**，且在给定区间上**单调**（二分）或**严格单峰**（黄金分割）；
- 单次函数求值代价可接受（$\lesssim$ 秒级），总求值次数 $\le 100$；
- 参数有**明确的物理上下界**可以定出 $[a,b]$，且区间内**有且只有一个**目标根/极值。

**适用规模**：变量维数 1；函数求值次数 $10^0\sim10^2$ 量级；精度 $10^{-4}\sim10^{-8}$。国赛中典型场景：反解单个物理参数（吃水深度、重物球质量、镜场间距、储油高度）、单变量成本最优。

## 9. 不适用情况

- **决策变量 $\ge2$ 且不可解耦**：不要硬套。例如多镜场排布、多时段调度。
- **目标函数非单峰且无法给出单峰区间**：黄金分割法会收敛到错误谷底而毫无警告。
- **函数带随机噪声**（蒙特卡洛估计、随机仿真）：二分法会在噪声下随机游走；应先固定随机种子或对同一 $x$ 多次求均值。
- **函数不连续 / 阶跃**（如"平台数只能取整数"的阶梯成本）：二分法会在跳变点上震荡，应改用**枚举 + 剪枝**或整数规划。
- **$f(a)\cdot f(b)>0$**：例题中根成对出现或区间定错，必须先画图重新定区间。
- **需要 $\varepsilon<10^{-10}$ 的高精度**：二分法迭代次数线性增长，应改用牛顿法（若导数可得）或 Brent 法。
- **需要同时给出全局最优性证明**：一维搜索给不出。

## 10. Python / MATLAB 实现要点

**Python**
- 首选现成函数，别手写：`scipy.optimize.brentq(f, a, b)`（二分+反二次插值的混合，比纯二分快得多，且保证收敛）、`scipy.optimize.bisect`（纯二分）、`scipy.optimize.minimize_scalar(f, bounds=(a,b), method='bounded')`（黄金分割类）。
- **必须捕获异常**：`brentq` 在端点同号时抛 `ValueError`，要 `try/except` 后给出"区间需重新选取"的诊断信息，而不是让程序崩掉。
- 手写二分时用 `while (b-a) > eps and k < Nmax`，**不要用 `while f(m) != 0`**（浮点永不相等，会死循环）。
- 高代价函数要**缓存**：`functools.lru_cache` 包一层，避免重复求解同一个物理模型。
- 记录每轮 `(k, a, b, f(m))` 到 list，最后画收敛曲线。

**MATLAB**
- `fzero(f, [a b])` 是求根首选（同样是混合方法）；`fminbnd(f, a, b)` 是黄金分割+抛物线插值的单峰求极小。
- 老国赛代码常用 `fminsearch`（Nelder-Mead），注意它**不是**一维单峰搜索，是单纯形下山法，不要混为一谈。
- 传播向量参数的函数签名写成 `@(x) mymodel(x, fixedParams)`，避免用全局变量。
- 用 `optimset('TolX',1e-8,'MaxIter',100)` 显式设置容差，**并在论文中写明该设置**。
- 画图：`fplot` 粗扫原始函数，再叠加迭代点，一张图同时展示单峰性和收敛过程。

## 11. 国赛论文中的写法与案例

### 推荐句式（可直接套用）

> 由于模型（x）中（参数）与（约束量）之间不存在显式解析关系，无法直接求导，本文采用二分法迭代求解。以（物理边界）确定搜索区间 $[a,b]=[\cdot,\cdot]$，取精度 $\varepsilon=10^{-6}$，迭代 $k$ 次后区间宽度降至 $\cdot$，得到（参数）$=\cdot$，此时（约束量）$=\cdot$，满足题设要求。

> 目标函数 $f(\cdot)$ 在 $[a,b]$ 上连续且单峰（见图 x），故采用黄金分割法（0.618 法）搜索其极小点。该方法每轮仅需新增 1 次函数求值，迭代 $n$ 次总求值次数为 $n+1$，相比逐点遍历有效减少了试验次数。

### 配图建议
1. **函数形状图**：横轴参数、纵轴残差/目标值，标出初始区间端点与最终解，证明"单峰/单调"这一前提。
2. **区间收缩过程图**：横轴迭代次数，纵轴区间宽度取对数坐标，呈直线说明线性收敛（斜率即 $-\log_2 2$）。
3. **双层结构流程图**：外层"参数扫描"、内层"物理模型求解"，被二分法框住，用于说明"算法与模型解耦"。
4. **表格**：迭代次数 | 区间 $[a_k,b_k]$ | 中点 $m_k$ | $f(m_k)$ | 区间宽度——这张表是评审最认可的可复现性证据。
