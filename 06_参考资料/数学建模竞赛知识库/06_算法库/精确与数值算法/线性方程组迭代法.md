## 1. 算法解决什么问题

**大规模稀疏线性方程组 $Ax=b$ 的求解**，当 $n$ 太大（$10^4\sim10^8$）以至于直接法（高斯消元）的内存 $O(n^2)$ 或时间 $O(n^3)$ 不可承受时使用。

国赛里的典型来源：**二维/三维 PDE 的有限差分/有限元离散**（热传导、渗流、污染扩散）产生的稀疏矩阵——每个节点只与邻居耦合，矩阵高度稀疏，但规模 $n=10^4\sim10^6$。

方法谱系（按"用不用 $A$ 的结构信息"排序）：

| 方法 | 需要的信息 | 特点 |
|---|---|---|
| **Jacobi 迭代** | 只用对角线 | 最简单，收敛最慢，可并行 |
| **Gauss–Seidel 迭代** | 用最新已更新的分量 | 比 Jacobi 快约 2 倍，串行 |
| **SOR（超松弛）** | Gauss–Seidel + 松弛因子 $\omega$ | $\omega$ 最优时比 GS 快一个数量级 |
| **共轭梯度法 CG** | 只用矩阵-向量乘 $Ax$ | **对称正定**问题的标准解法，Krylov 子空间法 |
| **GMRES / BiCGSTAB** | 只用 $Ax$ | 非对称问题的 Krylov 方法 |
| **预处理 Krylov（PCG / ILU-GMRES）** | $Ax$ + 预条件子 | 大规模稀疏问题的现代标准 |

国赛中**最常出现的是 Gauss–Seidel**，其次是**共轭梯度法**（见第 11 节案例）。

## 2. 输入与输出

**输入**
- 系数矩阵 $A$（稀疏，用 `scipy.sparse` 的 CSR/COO 存储；**绝不构造稠密矩阵**）；
- 右端向量 $b$；
- 初值 $x^{(0)}$（默认全零；用上一步的解热启动可大幅减少迭代）；
- 收敛容差 $\varepsilon$（相对残差）；
- 最大迭代次数 $N_{\max}$；
- （SOR）松弛因子 $\omega$；（PCG）预条件子 $M^{-1}$。

**输出**
- 近似解 $x^{(k)}$；
- **迭代次数 $k$**、**最终相对残差** $\|b-Ax^{(k)}\|/\|b\|$；
- 残差历史 $\{\|r^{(k)}\|\}$——论文里画收敛曲线用；
- 是否收敛的布尔标记（**必须检查**）。

## 3. 算法步骤（伪代码级）

### 3.1 Jacobi 迭代

1. 输入 $A,b,x^{(0)},\varepsilon,N_{\max}$；$k\leftarrow0$。
2. **循环**：
   1. 对每个 $i$：$x_i^{\text{new}}=\dfrac{1}{a_{ii}}\Big(b_i-\sum_{j\ne i}a_{ij}x_j^{\text{old}}\Big)$。（**用旧值算全部，再统一更新**——这是 Jacobi 与 GS 的唯一区别）
   2. 计算相对残差 $\text{res}=\|b-Ax^{\text{new}}\|/\|b\|$。
   3. 若 $\text{res}<\varepsilon$ → 收敛，返回。
   4. $x^{\text{old}}\leftarrow x^{\text{new}}$；$k\leftarrow k+1$。
   5. 若 $k=N_{\max}$ → **报"未收敛"并给出当前残差**，不要静默返回。
3. 输出 $x$ 与残差历史。

### 3.2 Gauss–Seidel 迭代

1. 输入同 3.1。
2. **循环**：
   1. 对每个 $i$（**按顺序**）：$x_i\leftarrow\dfrac{1}{a_{ii}}\Big(b_i-\sum_{j<i}a_{ij}x_j^{\text{new}}-\sum_{j>i}a_{ij}x_j^{\text{old}}\Big)$——**原地更新**，$x_j^{\text{new}}$ 立即可用。
   2. 每完成一轮（或每若干轮）计算相对残差。
   3. 收敛/超限判断同 3.1。
3. 输出。

### 3.3 SOR（逐次超松弛）

1. 取 $\omega\in(0,2)$；先算 GS 的候选值 $x_i^{\text{GS}}$。
2. $x_i\leftarrow(1-\omega)x_i^{\text{old}}+\omega\, x_i^{\text{GS}}$。
3. 其余同 GS。
4. **最优 $\omega$ 估计**：对相容排序的对称正定三对角矩阵，$\omega_{\text{opt}}=\dfrac{2}{1+\sqrt{1-\rho(J)^2}}$，其中 $\rho(J)$ 是 Jacobi 迭代矩阵的谱半径。若未知，取 $\omega=1.5\sim1.9$ 试。

### 3.4 共轭梯度法（CG，要求 $A$ 对称正定）

1. 输入 $A,b,x^{(0)},\varepsilon,N_{\max}$。
2. $r^{(0)}\leftarrow b-Ax^{(0)}$；$p^{(0)}\leftarrow r^{(0)}$；$k\leftarrow0$。
3. **循环**：
   1. $\alpha_k\leftarrow\dfrac{(r^{(k)},r^{(k)})}{(p^{(k)},Ap^{(k)})}$。
   2. $x^{(k+1)}\leftarrow x^{(k)}+\alpha_k p^{(k)}$。
   3. $r^{(k+1)}\leftarrow r^{(k)}-\alpha_k Ap^{(k)}$。
   4. 若 $\|r^{(k+1)}\|/\|b\|<\varepsilon$ → 返回。
   5. $\beta_k\leftarrow\dfrac{(r^{(k+1)},r^{(k+1)})}{(r^{(k)},r^{(k)})}$；$p^{(k+1)}\leftarrow r^{(k+1)}+\beta_k p^{(k)}$。
   6. $k\leftarrow k+1$；超限则报未收敛。
4. 输出。

### 3.5 预处理 CG（PCG，实战推荐）

1. 选预条件子 $M$（对角 Jacobi / 不完全 Cholesky IC(0) / 代数多重网格 AMG）。
2. 把上面的内积 $(u,v)$ 换成 $(u,M^{-1}v)$，即每步多解一次 $Mz=r$。
3. 其余同 CG。**好的预条件子能把迭代次数从 $10^4$ 降到 $10^2$**。

## 4. 复杂度与收敛性

| 方法 | 每次迭代时间 | 空间 | 收敛条件 | 收敛率 |
|---|---|---|---|---|
| Jacobi | $O(\text{nnz}(A))$ | $O(n)$（另存 $A$ 需 $O(\text{nnz})$） | **严格对角占优** 或 $\rho(D^{-1}(L+U))<1$ | $\rho(J)^k$，线性 |
| Gauss–Seidel | $O(\text{nnz})$ | $O(n)$ | 严格对角占优，或 $A$ 对称正定 | $\rho(G)^k$（对三对角 $=\rho(J)^2$），**约快 2 倍** |
| SOR | $O(\text{nnz})$ | $O(n)$ | $0<\omega<2$ 且 $A$ 对称正定 | $\omega_{\text{opt}}$ 时比 GS 快一个数量级 |
| CG | $O(\text{nnz})$ | $O(n)$ | **$A$ 对称正定** | 误差界 $\le2\big(\frac{\sqrt\kappa-1}{\sqrt\kappa+1}\big)^k$，$\kappa=\text{cond}(A)$ |
| PCG | $O(\text{nnz}+\text{预条件代价})$ | $O(n)$ | 同上，$M$ 对称正定 | 用 $\kappa(M^{-1}A)$ 代替 $\kappa(A)$ |
| GMRES | $O(k\cdot\text{nnz})$（需存 $k$ 个基向量） | $O(kn)$ | $A$ 非奇异 | 到第 $m$ 步残差最小 |

**必须写进论文的结论**：
1. **迭代法不是无条件收敛的**。Jacobi/GS 只在 $A$ **严格对角占优**（或对称正定）时保证收敛。有限差分离散的热传导矩阵满足这一条件——这是它们能用在这里的原因，论文中应当验证并说明。
2. **CG 要求 $A$ 对称正定**。对非对称问题用 CG 会失败，应改用 GMRES/BiCGSTAB。
3. **CG 的理论收敛步数 $\le n$**（精确算术下），但实际收敛速度由**条件数 $\kappa$** 决定：$\kappa=10^6$ 时可能要 $10^3$ 步。**预处理是必需的，不是可选项**。
4. **收敛率是线性的**：每步误差乘一个固定因子 $\rho<1$，误差 $\sim\rho^k$。这就是为什么"残差-迭代"图在半对数坐标下应是直线。
5. **网格越细条件数越差**：二维 Poisson 问题 $\kappa=O(h^{-2})$，迭代次数 $O(h^{-1})$。这正是多重网格（MG）被发明的原因——MG 可做到与 $h$ 无关的总代价。

| CG 预条件子 | 默认对角（Jacobi）最省事；追求性能用 IC(0) 或 AMG | 〔推理〕通用经验 |

## 6. 优点

1. **内存极省**：$O(\text{nnz}(A))$，$n=10^6$ 的稀疏矩阵在现代笔记本上完全可解；直接法需要 $O(n^2)$ 内存而根本装不下。
2. **每次迭代代价低**：$O(\text{nnz})$，即"每个非零元一次乘法"，向量化后极快。
3. **可以随时中断**：拿到"当前残差"就有质量保证，时间不够也能交一个还不错的近似解——比赛现场的巨大优势。
4. **天然适配时间步进**：上一步的解作初值，几步就收敛，比每步从头解快一个数量级。
5. **热启动可复用**：参数微调（灵敏度分析）时，旧解几乎总是好的初值。
6. **有成熟库**：`scipy.sparse.linalg.cg / gmres / bicgstab / spilu`、MATLAB `pcg / gmres / bicgstab / ilu`、PETSc、hypre。
7. **可并行**：Jacobi 与 CG 的矩阵-向量乘天然并行。

## 7. 缺点

1. **不保证收敛**：不满足对角占优/对称正定时会发散或震荡，程序可能"跑完但结果全错"。
2. **收敛速度依赖条件数**：网格加密一倍，迭代次数翻倍（Poisson 型问题）。粗网格上很快，细网格上很慢。
3. **CG 只适用对称正定**：非对称问题必须换 GMRES/BiCGSTAB，选错方法会得到垃圾结果。
4. **GMRES 内存随迭代数增长**（要存 Krylov 基），需重启（GMRES(m)），重启又可能停滞。
5. **精度通常低于直接法**：相同残差容差下，迭代解的有效数字一般比直接法少。
6. **参数（$\omega$、预条件子）需要调**，$\omega$ 选错可能比 GS 还慢。
7. **对病态问题（$\kappa>10^{12}$）**无预条件时基本不可行。
8. **诊断困难**：发散时"残差曲线往上走"往往要跑几千步才发现。

## 8. 适用规模与适用条件

**适用条件**：
- $A$ **稀疏**（$\text{nnz}\ll n^2$，如每行只有 3～7 个非零元）；
- $A$ **严格对角占优**（Jacobi/GS/SOR 收敛的充分条件）或**对称正定**（CG 收敛的充分条件）；
- $n\gtrsim10^4$（规模小的时候直接法更快）；
- 条件数 $\kappa(A)\lesssim10^{8}$；更大时必须有预条件子；
- 可以接受"近似解 + 残差容差"形式的结果。

**适用规模**：$n=10^4\sim10^8$；每行非零元 5～50；迭代次数 $10^1\sim10^4$；总耗时毫秒到分钟。

**国赛典型形态**〔归纳〕：二维热传导/扩散方程的隐式差分、地下水渗流、污染物迁移、电磁场、大规模最小二乘（正规方程）。

## 9. 不适用情况

- **$n<2000$ 的稠密矩阵**：直接法（`numpy.linalg.solve`）更快、更准、更省心。
- **矩阵不对称不定**：CG 不适用；GS 也可能不收敛，需 GMRES/BiCGSTAB 且要有预条件。
- **需要极高精度（相对残差 $<10^{-12}$）**：迭代法受舍入误差限制，通常达不到。
- **病态问题（$\kappa>10^{12}$）且无预条件**：直接用正则化 + 直接法更稳。
- **$A$ 固定但右端项有多个**：做一次 LU（$O(n^3)$ 但只做一次）可能比反复迭代更划算，需按 $n$ 权衡。
- **非对角占优且非对称正定**：需先做行/列均衡（equilibration）或换方法。
- **只需求解一次的小规模问题**：不要为了"看起来高级"而用迭代法。

## 10. Python / MATLAB 实现要点

**Python**
- 构造稀疏矩阵：`A = sparse.coo_matrix((data,(rows,cols)), shape=(n,n)).tocsr()`——**CSR 做矩阵-向量乘最快，务必转换**。
- 求解：`from scipy.sparse.linalg import cg, gmres, bicgstab, spsolve`；`x, info = cg(A, b, rtol=1e-8, maxiter=5000, M=Mprec)`。**`info=0` 才是收敛**，非 0 必须处理。
- 预条件：`ilu = spilu(A)` → `M = LinearOperator(A.shape, ilu.solve)`，配合 `gmres(A,b,M=M)`。
- 手写 Gauss–Seidel 时用 CSR 的 `indptr/indices/data` 三数组手动循环，**不要用双重 for 索引稠密矩阵**（慢 100 倍）。
- 残差历史：用 `callback=` 参数或自己写外层循环记录。
- 对角占优检验：逐行比较 $|a_{ii}|$ 与行内其余元素绝对值之和。
- 大规模网格：用 `pyamg`（代数多重网格）作预条件，迭代次数能从 $10^3$ 降到 $10^1$。

**MATLAB**
- `x = pcg(A,b,tol,maxit,M)`、`gmres(A,b,restart,tol,maxit,M)`、`bicgstab`；返回 `[x,flag,relres,iter,resvec] = pcg(...)`——`flag=0` 才收敛，`resvec` 直接可画收敛曲线。
- 稀疏矩阵用 `A = spdiags(...)` 或 `sparse(i,j,v,m,n)`；**绝不用 `zeros(n)`**。
- 预条件：`[L,U] = ilu(A, setup)` → `pcg(A,b,tol,maxit,L,U)`。
- 手写 GS 用切片而非逐元素循环：`x(i) = (b(i) - A(i,[1:i-1 i+1:n])*x([1:i-1 i+1:n]))/A(i,i);`。
- 内置 `A\b` 对稀疏矩阵会自动选直接法（UMFPACK）或迭代法，**论文里要明确说明用的是哪一种**，否则"用了方法却说不清"是失分点。
- 检查矩阵性质：`issymmetric(A)`、`diag(A)`、`condest(A)`。

## 11. 国赛论文中的写法与案例

### 推荐句式（可直接套用）

> 对（二维热传导）方程采用隐式差分格式离散后，得到规模为 $n=\cdot$ 的稀疏线性方程组 $Ax=b$。系数矩阵每行仅含 $\cdot$ 个非零元，且满足严格对角占优条件，因此可用迭代法求解。本文采用**高斯-赛德尔迭代法**，收敛容差取 $10^{-8}$（相对残差），初值取上一时间步的解。平均每个时间步迭代 $\cdot$ 次即达到容差，残差收敛曲线见图 x（半对数坐标下近似为直线，验证了线性收敛）。

> 由于该模型的系数矩阵对称正定，本文进一步采用**共轭梯度法**求解，其误差满足 $\|x^{(k)}-x^*\|_A\le2\big(\frac{\sqrt\kappa-1}{\sqrt\kappa+1}\big)^k\|x^{(0)}-x^*\|_A$。相比高斯-赛德尔迭代，共轭梯度法将迭代次数由 $\cdot$ 降至 $\cdot$，计算时间缩短 $\cdot\%$。

> 为保证收敛性，本文事先对系数矩阵进行对角占优检验：$\min_i\big(|a_{ii}|-\sum_{j\ne i}|a_{ij}|\big)=\cdot>0$，满足迭代法的收敛条件。

### 配图建议
1. **稀疏结构图（spy plot）**：展示矩阵非零元分布（带状/五点格式），说明"为什么用迭代法"。
2. **残差收敛曲线**：半对数坐标，横轴迭代次数、纵轴相对残差，多条线对应不同方法（Jacobi / GS / SOR / CG）——**方法对比图，最有说服力**。
3. **迭代次数随网格规模的变化图**：横轴 $n$（对数），纵轴迭代次数，展示随条件数增长的规律。
4. **解的等值线/热力图**：最终温度场或浓度场分布。
5. **表格**：方法、迭代次数、耗时、最终残差四列对比表。
