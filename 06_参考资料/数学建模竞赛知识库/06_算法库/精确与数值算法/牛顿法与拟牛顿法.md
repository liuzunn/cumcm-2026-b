## 1. 算法解决什么问题

**连续可微函数的根求解与非约束/等式约束极小化**，且要求**快速（超线性以上）收敛**。

- **牛顿法（求根）**：用一阶泰勒展开线性化 $f(x)=0$，迭代 $x_{k+1}=x_k-f(x_k)/f'(x_k)$。
- **牛顿法（优化）**：对目标 $\min \varphi(x)$ 用二阶泰勒展开，迭代 $x_{k+1}=x_k-H^{-1}\nabla\varphi(x_k)$，$H$ 为 Hessian。
- **拟牛顿法（Quasi-Newton）**：Hessian 太贵或不可得时，用**割线信息逐步构造 Hessian 的近似**（BFGS / DFP / SR1），只需求梯度。国赛里最常用的是 **BFGS** 与 **L-BFGS**，以及"介于牛顿法与梯度下降之间"的 **Levenberg–Marquardt (LM)**。

国赛中的典型形态：**参数反演 / 非线性最小二乘**——"给定观测数据，反求少数几个物理参数使残差平方和最小"。这就是〔原文〕2015A 的写法：**"以影长差值平方和最小为目标函数，运用拟牛顿迭代法对模型进行求解"**。

## 2. 输入与输出

| | 牛顿法（求根） | 拟牛顿法（优化） | LM（非线性最小二乘） |
|---|---|---|---|
| 输入 | 标量/向量函数 $F$（向量时需 Jacobian $J$）、初值 $x_0$ | 目标 $\varphi$、梯度 $\nabla\varphi$（可数值差分）、初值 $x_0$ | 残差向量 $r(x)$ 与其 Jacobian $J(x)$、初值 $x_0$ |
| 可选输入 | 解析导数、容差、最大迭代 | 线搜索参数、Hessian 初值 $H_0=I$ | 阻尼因子 $\lambda$ 初值与更新规则 |
| 输出 | 近似根 $x^*$ | 近似极小点 $x^*$、梯度范数 $\|\nabla\varphi(x^*)\|$ | 参数估计 $\hat\theta$、残差平方和 $\mathrm{SSE}$ |
| 附带输出 | 二次收敛的证据（每步误差平方） | 迭代次数、函数求值次数（写进论文） | 参数的**置信区间**（由 $(J^\top J)^{-1}\sigma^2$ 得到，写论文极加分） |

## 3. 算法步骤（伪代码级）

### 3.1 牛顿法求根（标量版）

1. 输入 $f,\ f',\ x_0,\ \varepsilon_{\text{tol}},\ N_{\max}$。
2. $k\leftarrow0$。
3. **循环** 当 $k<N_{\max}$：
   1. 计算 $f_k=f(x_k)$。若 $|f_k|\le\varepsilon_{\text{tol}}$，返回 $x_k$。
   2. 计算 $d_k=f'(x_k)$。**若 $|d_k|<$ 微小阈值（如 $10^{-12}$），判定为"导数为零/平坦区"，退出并报告失败**——这是牛顿法最经典的崩溃点。
   3. $x_{k+1}\leftarrow x_k-f_k/d_k$。
   4. **防越界**：若 $x_{k+1}$ 跑到物理可行域外（如浓度<0、角度>90°），用回溯 $x_{k+1}\leftarrow x_k+\tfrac12(\text{clip}(x_{k+1})-x_k)$ 拉回。
   5. 若 $|x_{k+1}-x_k|\le\varepsilon_{\text{tol}}\cdot\max(1,|x_k|)$，返回 $x_{k+1}$。
   6. $k\leftarrow k+1$。
4. 返回最后一次迭代值并**声明未达容差**。

### 3.2 拟牛顿法 BFGS（优化，实战主力）

1. 输入 $\varphi,\ \nabla\varphi,\ x_0,\ \varepsilon_g$（梯度范数容差），$N_{\max}$。
2. 初始化 $H_0\leftarrow I$（或按变量尺度给对角阵），$g_0\leftarrow\nabla\varphi(x_0)$，$k\leftarrow0$。
3. **循环** 当 $\|g_k\|>\varepsilon_g$ 且 $k<N_{\max}$：
   1. 取搜索方向 $p_k\leftarrow -H_k g_k$。
   2. **检查下降性**：若 $g_k^\top p_k\ge0$（数值误差导致），重置 $H_k\leftarrow I$ 并重算 $p_k=-g_k$。
   3. **线搜索**：用 Armijo 或 Wolfe 条件找一个步长 $\alpha_k$（Wolfe 条件才能保证 BFGS 的曲率更新合法）。
   4. $s_k\leftarrow\alpha_k p_k$；$x_{k+1}\leftarrow x_k+s_k$；$g_{k+1}\leftarrow\nabla\varphi(x_{k+1})$；$y_k\leftarrow g_{k+1}-g_k$。
   5. **曲率条件检查**：若 $s_k^\top y_k\le 10^{-10}\|s_k\|\|y_k\|$（$y$ 太扁平），**跳过本次更新**，$H_{k+1}\leftarrow H_k$（这是 BFGS 数值稳定的关键，很多人漏掉）。
   6. BFGS 更新：
      $$H_{k+1}=\Big(I-\frac{s_k y_k^\top}{y_k^\top s_k}\Big)H_k\Big(I-\frac{y_k s_k^\top}{y_k^\top s_k}\Big)+\frac{s_k s_k^\top}{y_k^\top s_k}$$
   7. $k\leftarrow k+1$。
4. 返回 $x^*=x_k$。**再次验证 $\|g\|$ 与物理约束**。

### 3.3 Levenberg–Marquardt（非线性最小二乘，国赛最常用形态）

1. 输入残差函数 $r(x)\in\mathbb R^m$、初值 $x_0$、$\lambda_0>0$、$\nu>1$（如 10）、容差。
2. 计算 $\mathrm{SSE}(x_0)=\|r(x_0)\|^2$；$k\leftarrow0$。
3. **循环**：
   1. 计算 $J_k=\partial r/\partial x|_{x_k}$（解析或**前向差分**）。
   2. 解线性方程组 $(J_k^\top J_k+\lambda_k I)\,\delta=-J_k^\top r(x_k)$。
   3. 试探步 $x_{\text{new}}=x_k+\delta$，算 $\mathrm{SSE}(x_{\text{new}})$。
   4. **若下降**：接受，$x_{k+1}\leftarrow x_{\text{new}}$，$\lambda_{k+1}\leftarrow\lambda_k/\nu$（趋向高斯-牛顿，收敛更快）。
   5. **若未下降**：拒绝，$\lambda_{k+1}\leftarrow\lambda_k\cdot\nu$（趋向梯度下降，更稳），回到 3.1 重解。**注意 $\nu$ 不能太大**，否则一次拒绝就把步长压死。
   6. 停止判据：$\|\delta\|\le\varepsilon_x$ 或 $\|J^\top r\|\le\varepsilon_g$ 或 $\lambda_k>\lambda_{\max}$。
4. 输出 $\hat x$；再由 $\hat\sigma^2=\mathrm{SSE}/(m-n)$、$\mathrm{Cov}=\hat\sigma^2(J^\top J)^{-1}$ 给出**参数的置信区间**。

## 4. 复杂度与收敛性

| 方法 | 单次迭代代价 | 空间 | 收敛阶 | 收敛类型 |
|---|---|---|---|---|
| 牛顿法（求根，标量） | $O(1)$ + 1 次 $f'$ | $O(1)$ | **二次（$q=2$）** | 局部 |
| 牛顿法（优化，$n$ 维） | $O(n^3)$（解 $H\delta=-g$）+ Hessian 计算 | $O(n^2)$ | **二次** | 局部 |
| 拟牛顿 BFGS（存 $H$） | $O(n^2)$（矩阵更新 + 乘法），线搜索另计 | $O(n^2)$ | **超线性（$q\approx1.6$）** | 局部（对凸问题全局） |
| L-BFGS（存 $m$ 个向量） | $O(mn)$ | $O(mn)$，$m$ 取 5～20 | 超线性 | 局部 |
| LM | 每步解 $n\times n$ 线代：$O(mn^2+n^3)$ | $O(mn)$ | 残差为零时接近二次；否则线性 | **全局收敛到局部极小**（阻尼保证下降） |
| 数值差分梯度（前向） | 每步多 $n$ 次函数求值 | — | 精度 $O(h)$，会**污染收敛阶**，实际只有线性 | — |

**必须写进论文的三句话**：
1. 牛顿/拟牛顿法**只能保证局部收敛**——初值必须落在吸引域内。多个局部极小的问题（参数反演常有多解）**必须做多初值重启**，并在论文里报告"取 $K$ 组不同初值，最优值一致"。
2. **BFGS 在目标函数凸且线搜索满足 Wolfe 条件时全局收敛**；非凸时只保证收敛到驻点（可能是鞍点或极大点），因此要检查 Hessian 近似是否正定。
3. **LM 是国赛里最稳的**：阻尼因子保证每步都下降，因此具有全局收敛性；代价是残差非零时只有线性收敛。

## 5. 参数与调参要点

| 参数 | 推荐取值 | 依据 |
|---|---|---|
| 初值 $x_0$ | 用**物理先验**定，例如参数的可测量估计值；或先做 200 点粗网格取最优作为初值 | 〔推理〕通用经验；国赛论文必须交代初值来源，否则结果不可复现 |
| 梯度容差 $\varepsilon_g$ | $10^{-6}\sim10^{-8}$（归一化后）。若目标量纲是"元"，取 $10^{-3}$ 量级即可 | 〔推理〕通用经验 |
| 步长容差 $\varepsilon_x$ | $10^{-8}\sim10^{-10}$（相对） | 〔推理〕通用经验 |
| 最大迭代 $N_{\max}$ | 200～1000 | 〔推理〕通用经验 |
| 差分步长 $h$（数值梯度） | $h\approx\sqrt{\epsilon_{\text{mach}}}\cdot\max(1,|x|)\approx1.5\times10^{-8}\cdot\max(1,|x|)$（前向）；中心差分 $h\approx\epsilon^{1/3}\approx6\times10^{-6}$ | 〔推理〕数值分析标准结论 |
| LM 初始 $\lambda_0$ | $10^{-3}\cdot\mathrm{diag}(J^\top J)_{\max}$（按尺度缩放），或直接 $10^{-3}$（变量已归一化时） | 〔推理〕通用经验 |
| LM 增减因子 $\nu$ | 2～10，文献常取 10 | 〔推理〕通用经验 |
| L-BFGS 记忆长度 $m$ | 5～20 | 〔推理〕通用经验 |
| 多初值重启次数 | 5～20 组，覆盖参数可行域；报告最优值一致的组数 | 〔推理〕通用经验 |
| 变量缩放 | **必须做**：把每个参数除以自身量级，使各维尺度相近 | 〔推理〕；不缩放是"BFGS 不收敛"的头号原因 |

〔原文〕参数佐证：2015A 太阳影子定位 (1) 讨论了 LM 的参数作用——**"Levenberg-Marquardt 算法是介于牛顿法与梯度下降法之间的一种非线性优化方法……$\lambda$ 很小时（蜕化为）牛顿法步长；$\lambda$ 很大时，蜕化为梯度下降法的最优步长计算式"**。可直接引用这句话解释 LM 的阻尼机制。

**调参坑**：
- 数值梯度步长 $h$ 太小 → 相减抵消误差爆炸；太大 → 差分误差主导。二者必须在同一量级上权衡，$h\sim10^{-6}$（中心差分）是安全默认。
- 变量量纲差异大（一个参数是 $10^{6}$、另一个是 $10^{-3}$）而不缩放，$H$ 条件数爆炸，BFGS 不动或乱跑。

## 6. 优点

1. **收敛速度最快**：牛顿法二次收敛（误差每步平方），一般 5～10 次迭代就到机器精度；这是网格搜索永远比不了的。
2. **拟牛顿法只需求梯度**，不需要 Hessian 与二阶差分，$n$ 维问题的实施成本从 $O(n^3)$ 降到 $O(n^2)$，是"没有解析 Hessian 时的最优选择"。
3. **LM 对初值不敏感**（相对纯牛顿），能处理残差非零的过定问题，是参数反演的标准武器。
4. **自带精度评估**：LM 可从 $(J^\top J)^{-1}\hat\sigma^2$ 直接给出参数的**协方差与置信区间**，这是国赛论文"模型检验"章节的高级素材。
5. 与 Python/MATLAB 生态深度绑定，`scipy.optimize.least_squares` / `lsqnonlin` 一行调用即可拿到工业级实现。
6. 迭代过程可以画出"残差 vs 迭代次数"的单调下降曲线，可复现性强。

## 7. 缺点

1. **只有局部收敛**。初值选错 → 收敛到另一个局部极小或直接发散，且**程序不会报错**。参数反演题如果有多个物理上说得通的解，必须多初值验证。
2. **需要导数**。黑箱仿真（只能给函数值）时只能数值差分，代价是每步多 $n$ 次仿真，且精度下降、收敛阶退化到线性。
3. **Hessian 可能奇异或非正定**，牛顿方向可能是上升方向，直接导致发散。必须有"方向下降性检查 + 阻尼/正则化"。
4. **对噪声敏感**：目标函数带随机性（蒙特卡洛估计）时，差分梯度被噪声淹没，需先固定随机种子或平滑。
5. **不处理约束**。国赛题目多数带约束（角度<16°、产量≥0），直接套牛顿法会跑出不可行解；需外层惩罚函数或改用 SQP / `scipy.optimize.minimize(method='SLSQP')`。
6. 每步都要解线性方程组，$n$ 大（如 $n>2000$）时内存与时间不可接受，需换 L-BFGS 或共轭梯度。
7. **不能给出全局最优性证明**；论文里不能写"求得全局最优"，只能写"求得一个局部最优解，并通过多初值验证其稳定性"。

## 8. 适用规模与适用条件

**适用条件**：
- 目标/残差函数**一阶连续可微**（或可接受的数值差分近似）；
- 参数维数 $n$ **较小**：BFGS 存 Hessian → $n\lesssim1000$；L-BFGS → $n\lesssim10^5$；
- 目标函数**局部凸或在初值附近无强多峰**；
- 单次函数求值**便宜**（毫秒级），因为一次梯度差分要 $n+1$ 次求值；
- 有合理的**物理初值**。

**适用规模**：参数维数 $n=1\sim50$（国赛绝大多数参数反演题的规模）；迭代次数 $10\sim10^2$；精度可达 $10^{-10}$。

## 9. 不适用情况

- **目标函数不可微、阶跃或离散**（整数决策变量、分段常数成本）：梯度不存在，改整数规划或直接搜索法（Nelder-Mead / PSO / GA）。
- **强多峰且无任何先验**：改全局优化（PSO / 差分进化 / 多起点 + 局部精修）。
- **目标函数带显著随机噪声**且无法固定种子：改无导数方法（如 `scipy.optimize.minimize(method='Nelder-Mead')`）或先做代理模型。
- **维数极高**（$n>10^5$，如深度学习级别的参数）：需 SGD/Adam（见"梯度下降与随机梯度"卡片）。
- **约束主导且可行域狭窄**：牛顿方向几乎必定越界，应直接用 SLSQP / 内点法 / 罚函数法。
- **需要严格全局最优**（如小规模整数规划）：用分支定界，不用牛顿法。
- **函数求值极贵**（单个 ODE 解要 10 分钟）：应改用代理模型（Kriging/响应面）+ 少量精算点，而不是让拟牛顿法做上百次差分。

## 10. Python / MATLAB 实现要点

**Python**
- 首选 `scipy.optimize`：`least_squares(fun, x0, method='lm')`（LM，需 $m\ge n$）、`method='trf'`（信赖域，支持边界，**n 多或带约束时首选**）、`minimize(fun, x0, jac=..., method='BFGS')`、`root(fun, x0, jac=..., method='hybr')`。
- **边界一定要用 `bounds=` 传进去**（`least_squares` 的 `trf` 支持），这比事后 clip 可靠得多。
- **尺度问题**：`x_scale='jac'` 让 scipy 自动按 Jacobian 缩放，能解决大半不收敛问题。
- Jacobian 若能解析就给 `jac=`；否则用 `diff_step=1e-6` 控制差分步长，**不要用默认值就不管**。
- 结果一定要检查 `res.success`、`res.status`、`res.optimality`，并在论文附录里贴出；`success=False` 时结果不可用。
- 多初值：用 `for x0 in starts: ...` 收集所有解，报告"最优值一致率"。这是参数反演题最容易被追问的点。
- 置信区间：`res.jac` → `cov = np.linalg.inv(J.T@J) * res.fun.dot(res.fun)/(m-n)`。

**MATLAB**
- `lsqnonlin`（LM / 信赖域反射）是参数反演首选；`fsolve` 求根（默认信赖域 dogleg）；`fminunc` 无约束优化（可选 `'quasi-newton'` = BFGS）。
- 用 `optimoptions('lsqnonlin','Display','iter','SpecifyObjectiveGradient',true,'StepTolerance',1e-10)` 显式设置，并把 `Display→iter` 的迭代表**截图进附录**，是最省事的可复现性证据。
- 提供解析 Jacobian 时，写成 `[F,J]=myfun(x)` 并设 `'SpecifyObjectiveGradient',true`，速度提升数倍。
- 变量缩放用 `TypicalX` 选项，等价于 Python 的 `x_scale`。
- 老论文代码常用 `nlinfit` / `lsqcurvefit`，本质相同，注意它们的默认算法是 LM。

## 11. 国赛论文中的写法与案例

### 推荐句式（可直接套用）

> 模型（x）的参数无法由观测数据直接解出，为此建立以残差平方和为目标的非线性最小二乘问题 $\min_{\theta}\sum_{i=1}^{m}\|y_i-f(t_i;\theta)\|^2$。由于目标函数二阶连续可微，本文采用拟牛顿法（BFGS）迭代求解，梯度由中心差分近似（步长 $h=10^{-6}$），变量经量纲归一化处理。取（物理先验）作为初值，迭代 $k$ 次后梯度范数降至 $\cdot$，得到参数估计 $\hat\theta=(\cdot,\cdot,\cdot)$，残差平方和 $\mathrm{SSE}=\cdot$。

> 为进一步检验解的稳定性，本文分别取 $K=20$ 组随机初值重复求解，其中 $\cdot$ 组收敛到同一解，最优值相对偏差小于 $10^{-6}$，说明该局部最优解在所考察的初值范围内具有稳定性。

> （若用 LM）Levenberg-Marquardt 方法在阻尼因子 $\lambda$ 较小时退化为牛顿法步长、较大时退化为梯度下降法步长，因而兼具牛顿法的快速收敛与梯度法的全局稳定性。

### 配图建议
1. **收敛曲线**：横轴迭代次数，纵轴梯度范数（对数坐标）或残差平方和——直线段即超线性/二次收敛的直观证据。
2. **拟合对比图**：原始数据散点 + 模型拟合曲线 + 残差子图（三个子图纵向排列，标准高水平画法）。
3. **参数置信区间图**：误差棒图（估计值 ± 95% CI），直接支撑"参数估计精度"论述。
4. **初值稳健性图**：$K$ 组初值 → 收敛解的散点/箱线图，说明解的稳定性。
5. **流程图**：数据 → 残差函数 → Jacobian → LM 迭代 → 置信区间，一张图讲清整条反演链。
