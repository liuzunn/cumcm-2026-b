# 分支定界与割平面

> **证据等级约定**：〔原文〕= 在语料文件中直接读到原句；〔归纳〕= 由多篇语料归纳出的共性；〔推理〕= 语料未直接支持，按通用算法经验给出。

> 本文只读语料、不改原文；所有"优秀论文案例"均为实际检索命中，未命中一律标【资料中未找到直接案例】。


## 1. 算法解决什么问题

**整数规划（IP）与混合整数线性规划（MILP）的精确求解**：
$$\min\ c^\top x \quad \text{s.t.}\ Ax\le b,\ x\ge0,\ x_j\in\mathbb Z\ (j\in\mathcal I)$$

- **分支定界（Branch and Bound, B&B）**：先解 **LP 松弛**（把整数约束去掉），得到下界；若松弛解含小数，就按某个小数变量**分支**成两个子问题，递归求解，用"当前最好整数解"（上界）剪掉不可能更优的分支。
- **割平面法（Cutting Plane, Gomory）**：不分支，而是**不断加入有效不等式（割）**切掉松弛解周围的小数区域，使 LP 最优解逐步逼近整数极点。

**现代求解器（Gurobi / CPLEX / CBC / LINGO / intlinprog）用的是二者融合的"分支切割（Branch-and-Cut）"**——这才是你在国赛里真正调用的东西。

**国赛中的定位**〔归纳〕：凡是"数量必须是整数""选或不选""平台只能建整数个""书号只能分配整数本"的题，本质都是 IP，评委期望你写出 0-1 变量模型并说明用分支定界求解。

## 2. 输入与输出

**输入**
- 线性目标 $c$、线性约束 $A,b$；
- **整数变量的下标集合** $\mathcal I$（其余为连续变量，构成 MILP）；
- 变量上下界（**上界极其重要**，是剪枝的关键）；
- 求解器选项：最优性间隙容差、时间上限、启发式开关、割平面生成强度。

**工具签名**
- Python：`scipy.optimize.milp(c, constraints=..., integrality=..., bounds=...)`（SciPy ≥1.9）、`pulp.PulpSolver`、`gurobipy`
- MATLAB：`intlinprog(f, intcon, A, b, Aeq, beq, lb, ub, options)`
- LINGO：`@bin(x)`（0-1）、`@gin(x)`（一般整数）、`@bnd(l,x,u)`

**输出**
- 最优整数解 $x^*$ 与最优值 $z^*$；
- **求解状态**：`Optimal / Infeasible / Unbounded / TimeLimit / NodeLimit`；
- **最优性间隙（MIP Gap）** $=\dfrac{z_{\text{best integer}}-z_{\text{LP bound}}}{|z_{\text{best integer}}|}$——**这是写论文时必须报告的量**；
- 探索节点数、割平面数量、根节点 LP 界（用于画收敛图）。

## 3. 算法步骤（伪代码级）

### 3.1 分支定界（求最小化问题）

1. 初始化：上界 $\bar z\leftarrow+\infty$（当前最好整数解），活跃节点集合 $\mathcal L\leftarrow\{\text{根节点}\}$，下界 $\underline z\leftarrow-\infty$。
2. **循环** 当 $\mathcal L\neq\varnothing$：
   1. **选节点**（Node Selection）：从 $\mathcal L$ 中按规则取一个节点——深度优先（省内存）/ 最好界优先（最快改界）/ 混合（现代求解器默认）。
   2. **解 LP 松弛**：得到松弛最优值 $z_{\text{LP}}$ 与解 $x_{\text{LP}}$。
   3. **剪枝检验**：
      1. 若 $z_{\text{LP}}\ge\bar z$ → **按界剪枝**，丢弃该节点，continue。
      2. 若 LP 不可行 → **按可行性剪枝**，丢弃，continue。
      3. 若 $x_{\text{LP}}$ 已满足全部整数约束 → 得到整数可行解；若 $z_{\text{LP}}<\bar z$，更新 $\bar z\leftarrow z_{\text{LP}}$ 并记录 $x^*$；丢弃节点，continue。
   4. **分支**：选一个取小数值的整数变量 $x_j$（**分支变量选择**：最分数（most fractional）/ 伪成本 / 强分支），生成两个子节点：
      - 左：$x_j\le\lfloor x_j^{\text{LP}}\rfloor$
      - 右：$x_j\ge\lceil x_j^{\text{LP}}\rceil$
   5. 把两个子节点加入 $\mathcal L$，并更新全局下界 $\underline z=\min_{N\in\mathcal L}z_{\text{LP}}(N)$。
   6. **终止检验**：若 $\bar z-\underline z\le\varepsilon_{\text{gap}}\cdot|\bar z|$，或节点数/时间超限，跳出循环。
3. 输出 $x^*,\bar z$，**同时报告 gap 与是否证明最优**。若因超限退出，**必须写"未证明最优，返回当前最好可行解"**，不能写"最优解"。

### 3.2 割平面法（Gomory 分数割）

1. 解 LP 松弛。若解已是整数 → 完成；若无可行解 → 无解。
2. 取一个取值为**分数**的基变量 $x_{B_i}=\bar b_i$。
3. 从其所在行生成 **Gomory 割**：
   $$\sum_{j\notin B}\big(f_{ij}-\lfloor f_{ij}\rfloor\big)x_j\ \ge\ f_{i0}-\lfloor f_{i0}\rfloor,\qquad f_{ij}=[B^{-1}A]_j$$
   其中 $f_{i0}=\bar b_i-\lfloor\bar b_i\rfloor$。
4. 把割加到 LP 中，用**对偶单纯形法**重新求解（加割后原基不再可行但保持对偶可行，对偶单纯形最省事）。
5. 回到步骤 1。若割不改善目标值或 LP 无界 → 说明纯割平面法停滞，**转分支**（这就是 branch-and-cut）。
6. 终止：解为整数、或目标值改进小于容差、或迭代次数超限。

### 3.3 实用替代：LP 松弛 + 四舍五入/启发式修补（国赛常见做法）

1. 解 LP 松弛，得 $x^{\text{LP}}$。
2. **向下取整**得可行解 $x^{(1)}$；再试**向上取整**得 $x^{(2)}$（可能不可行，需修复）。
3. 对不可行的候选，按"对目标影响最小的方向"逐个调整变量直至可行（**修复启发式**）。
4. 取所有候选中最好的可行解作为上界 $\bar z$，作为 B&B 的初始界——**这一步能把求解时间砍掉一半以上**。
5. **必须声明**："该解为启发式可行解，不保证全局最优"，除非你跑了完整 B&B 到 gap=0。

## 4. 复杂度与收敛性

| 指标 | 分支定界 | 割平面（纯 Gomory） | Branch-and-Cut |
|---|---|---|---|
| 时间复杂度 | 最坏 $O(2^n)$（节点数指数）；实践常为多项式级 | 理论上有限步收敛，但**每步数值误差积累** | 介于二者之间，是工业标准 |
| 单节点代价 | 一次 LP：$O(mn)$～$O(n^3)$ | 一次对偶单纯形 + 生成割 | 同左 + 割管理开销 |
| 空间复杂度 | $O(\text{节点数}\times mn)$（活跃节点树） | $O(mn)$（割不断累加，矩阵变大） | $O(\text{节点数}\times mn)$ |
| 收敛性 | **有限步内找到并证明全局最优**（若允许无限时间） | 有理论有限收敛性；**实际因浮点误差常停滞** | 有限步收敛 |
| 最优性 | **全局最优 + 最优性证明**（gap=0） | 全局最优 | 全局最优 |

**必须写进论文的结论**：
1. B&B 给出的是**全局最优解 + 最优性证明（gap = 0）**，这是它相对 GA/PSO 等启发式的最大卖点——**能用 B&B 就绝不要用启发式**。
2. 最坏复杂度指数级，因此**规模是决定性因素**：0-1 变量超过约 200～300 个、或对称性极强时，B&B 可能跑不完。
3. 纯割平面法因浮点误差会**停滞**（割加了很多但界不动），所以现代求解器都是 branch-and-cut。
4. **关键加速手段**排在效果顺序：紧的 LP 松弛 > 好的初始可行解（上车界）> 变量界 > 分支变量选择规则 > 割平面强度。
5. 若求解器因时间上限退出且 **gap > 0**，论文里**只能写"得到了一个可行解，其与理论下界的间隙为 x%"**。

## 6. 优点

1. **全局最优 + 可证明**：返回最优解的同时给出最优性间隙，是论文中最强的结论形式。
2. **通用性强**：只要能写线性模型，任何整数/0-1 问题都能套，不需要针对问题设计启发式。
3. **可提前终止**：给上时间限制就能拿到"最好的可行解 + 与下界的间隙"，**比赛现场永远不会空手而归**。
4. 与 LP 求解器生态完全兼容，建模代码与 LP 版几乎相同，只多一个"整数变量下标"参数。
5. **剪枝机制可解释**：节点数、界的变化可以直接画成"搜索树 / 界收敛图"，论文里的技术含量很高。
6. 与启发式**互补**：先用贪心/GA 求上界，再交给 B&B，能显著加速（warm start）。

## 7. 缺点

1. **最坏指数复杂度**。规模稍大（0-1 变量 $\gtrsim300$）或结构不良时求解器可能跑几小时也给不出 gap=0。
2. **对模型形式极敏感**：同一个问题的两种等价写法（如"big-M 写法" vs "凸包写法"），LP 松弛紧度天差地别，求解时间可差 100 倍。
3. **对称性问题**（多个同型对象完全可互换）会导致搜索树指数级爆炸，必须额外加破除约束。
4. **数值不稳定**：大 M 太大、系数数量级差异大时，求解器可能误报不可行。
5. **"看起来收敛了"陷阱**：gap 容差默认 $10^{-4}$，某些题会停在 gap=0.9% 就返回，被当成"最优解"写进论文——**必须显式报告 gap**。
6. **不适用非线性**：目标或约束含非线性时需先线性化（引入辅助变量），或改用 MINLP 求解器。
7. 无法像 GA 那样"随时给一个还不错的解"——早期的 B&B 只有下界，没有可行解（所以 warm start 很重要）。

## 8. 适用规模与适用条件

**适用条件**：
- 模型**线性**（目标与约束），变量含整数/0-1；
- 整数变量数量在求解器可承受范围内：**0-1 变量 $\lesssim300$、一般整数变量 $\lesssim500$、总变量 $\lesssim10^5$**（经验值，视结构而定）〔推理〕；
- 变量的**上下界可以写紧**；
- 可以接受分钟级甚至小时级的求解时间，或接受带 gap 的近似最优。

**适用规模**：国赛中典型规模是几十到几百个 0-1 变量（书号分配 72 个科目、DVD 分配数百会员、选址十几个平台），**绝大多数能在秒级到分钟级解出**。

## 9. 不适用情况

- **变量数极大（$10^4$ 量级 0-1 变量）且结构无特殊性质**：应改用列生成、拉格朗日松弛或专用启发式。
- **目标/约束非线性**：先线性化，否则无效。
- **对求解时间有硬上限（如 1 分钟）而问题 NP-hard 且规模大**：直接用启发式（GA / SA / 贪心）拿可行解更现实。
- **对称性极强且无法破除**：如"把 8 台同型 CNC 分成若干组"这类问题，搜索树会爆炸；需换建模方式。
- **连续问题**：直接用 LP/NLP，不要套整数规划的壳。
- **需要给出解的质量保证但可接受非最优**：可用启发式 + 下界估计，比硬跑 B&B 划算。
- **纯割平面法**单独使用：浮点误差导致停滞，**不要单独实现**，用 branch-and-cut。

## 10. Python / MATLAB 实现要点

**Python**
- `scipy.optimize.milp(c, constraints=LinearConstraint(A,b_l,b_u), integrality=[1]*n, bounds=Bounds(lb,ub))`：`integrality=1` 整数，`2` 半连续，`3` 半整数。
- 结果对象里 `res.mip_gap`、`res.mip_node_count`、`res.mip_dual_bound` —— **这三个数直接写进论文**（gap、节点数、下界）。
- 建模友好的选择：`pulp`（`LpVariable(cat='Binary')`）、`mip`、`gurobipy`。Gurobi 用 `model.setParam('MIPGap', 1e-4)`、`model.setParam('TimeLimit', 600)`。
- **手写 B&B 只为教学/论文展示**：核心是 `queue` + `linprog` 递归；规模超过 20 个 0-1 变量就别手写了。
- 剪枝时务必用**相对 gap** 而不是绝对差，否则量纲大的题剪不动。
- 对称性破除：加约束 `x[0] >= x[1] >= ...`，往往能带来数量级的加速。

**MATLAB**
- `intlinprog(f, intcon, A, b, Aeq, beq, lb, ub, options)`；`intcon` 是整数变量的**下标向量**（这个参数漏写等于白跑）。
- `options = optimoptions('intlinprog','MIPGap',1e-4,'MaxTime',600,'Display','iter')`。
- `[x,fval,exitflag,output] = intlinprog(...)`；`output.mipgap`、`output.numnodes`、`output.branchbound`（即下界）—— 三件套照抄进论文。
- `exitflag=1` 表示"求到最优"；`exitflag=2` 表示"因节点/时间上限退出，返回的是当前最好可行解"——**这一区分必须写进论文**。
- 现代写法 `optimproblem` + `optimvar(..., 'Type','integer')` 更不易错。
- LINGO：`@bin` / `@gin` 即启用分支定界；求解报告里 "Best Objective" 与 "Best Bound" 的差就是 gap。

## 11. 国赛论文中的写法与案例

### 推荐句式（可直接套用）

> 由于（决策量）具有整数/二值性质，本文建立 0-1 整数规划模型。模型共含 $n$ 个 0-1 变量、$m$ 个约束。本文采用分支定界法求解：先求解其线性规划松弛得到下界，再对取分数值的变量分支，并以当前最好整数解为上界剪枝。求解在（LINGO 11 / intlinprog / Gurobi）中完成。

> 求解结果为 $z^*=\cdot$，最优性间隙 $\text{gap}=\cdot\%$（求解器报告节点数 $\cdot$，根节点下界 $\cdot$）。由于 gap 为 0（或小于 $10^{-4}$），可判定该解为**全局最优解**。

> （若未跑满）在 600 秒时间上限内求解器返回了当前最好可行解 $z=\cdot$，对应下界 $\cdot$，最优性间隙 $\cdot\%$；因此该解是**一个高质量的可行解，但未获全局最优性证明**。

### 配图建议
1. **搜索树示意图**：根节点标 LP 下界，分支后标左右子节点的界，被剪掉的节点打叉——直观展示"剪枝"，评审非常吃这一套。
2. **界收敛曲线**：横轴时间/节点数，纵轴"上界（最好整数解）"与"下界（LP 界）"两条曲线逐步靠近，中间阴影即 gap。
3. **LP 松弛解 vs 整数解的对比表**：突出"松弛解有小数 → 必须整数规划"的必要性。
4. **灵敏度表**：关键约束右端项变动时最优整数解如何变化（整数规划的灵敏度是不连续跳变的，这一点值得讨论）。
