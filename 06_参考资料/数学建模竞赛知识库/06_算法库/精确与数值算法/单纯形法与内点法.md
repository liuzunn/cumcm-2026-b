## 1. 算法解决什么问题

**线性规划（LP）的精确求解**：
$$\min_{x}\ c^\top x \quad \text{s.t.}\ Ax=b,\ x\ge0$$

- **单纯形法（Simplex）**：沿可行域（多面体）的**顶点**做基变换，从一个基本可行解跳到相邻且目标更优的基本可行解，直到最优。1947 年以来的工业标准算法。
- **内点法（Interior Point, IPM）**：从可行域**内部**出发，沿牛顿方向穿越内部逼近最优解，典型代表是原始-对偶路径跟踪法。

**国赛中的定位**〔归纳〕：绝大多数队伍不会手写单纯形表，而是**调用求解器**（LINGO / MATLAB linprog / Python scipy / Gurobi），论文里写"采用单纯形法求解"。评委真正看的是**模型形式化得对不对**，而不是你手写没写单纯形表。因此本卡片重点在"什么时候该用 LP、什么时候不能用 LP"。

## 2. 输入与输出

**标准形输入**
- 目标系数向量 $c\in\mathbb R^n$；
- 约束矩阵 $A\in\mathbb R^{m\times n}$（稀疏是常态）；
- 右端项 $b\in\mathbb R^m$（**要求 $b\ge0$**，否则先对相应行乘 $-1$）；
- 变量下界（默认 $x\ge0$）、上界，以及等式/不等式类型。

**常用工具签名**
- Python：`scipy.optimize.linprog(c, A_ub, b_ub, A_eq, b_eq, bounds, method='highs')`
- MATLAB：`linprog(f, A, b, Aeq, beq, lb, ub, options)`
- LINGO：`min=...;` `@sum(...)` `@bin(x)` `@gin(x)`

**输出**
- 最优目标值 $z^*$；
- 最优解 $x^*$（可能是**多个最优解之一**，见第 14 类坑）；
- 松弛变量取值与**影子价格（对偶变量）**——国赛论文灵敏度分析章节的关键产物；
- 状态码：`optimal / infeasible / unbounded / numerical`。**必须检查状态码。**

## 3. 算法步骤（伪代码级）

### 3.1 单纯形法（两阶段法）

1. **化标准形**：引入松弛变量把 $\le$ 变 $=$，引入剩余变量把 $\ge$ 变 $=$；对 $b_i<0$ 的行整体乘 $-1$。
2. **构造初始基**：若松弛变量恰好构成单位阵，直接得到初始基本可行解；否则进入**第一阶段**——引入人工变量，以"人工变量之和最小"为目标求解辅助 LP。
3. **第一阶段**：用单纯形法把人工变量全部赶出基。若辅助问题最优值 $>0$，**判定原问题无可行解**，终止。
4. **第二阶段**：以原目标 $c^\top x$ 为目标，从第一阶段得到的基出发继续迭代。
5. **每次迭代**：
   1. 计算检验数 $\sigma_j=c_j-z_j=c_j-c_B^\top B^{-1}a_j$。
   2. **最优性检验**：若所有 $\sigma_j\ge0$（对 $\min$ 问题），当前解最优，终止。
   3. **进基**：选 $\sigma_j<0$ 中最小者（Dantzig 规则）或最大改进者（最陡边规则）。
   4. **最小比值检验**：$\theta=\min\{b_i/a_{ij}\mid a_{ij}>0\}$。**若无 $a_{ij}>0$，判定问题无界**，终止。
   5. **出基**：取达到最小比值的基变量出基（**Bland 规则**可避免循环：同比值时取下标最小者）。
   6. 做一次**转轴（pivot）**，更新基与基本可行解。
   7. 迭代计数 +1；超过 $N_{\max}$ 则报"迭代超限"。
6. 输出 $x^*$、$z^*$、最优基 $B$、影子价格 $y^\top=c_B^\top B^{-1}$。

### 3.2 原始-对偶内点法（路径跟踪）

1. 化问题为 $\min c^\top x$ s.t. $Ax=b,\ x\ge0$；写出对偶 $\max b^\top y$ s.t. $A^\top y+s=c,\ s\ge0$。
2. 初始化**严格可行内点** $x^0>0,\ s^0>0,\ y^0$（可用大 M 法或不可行内点启动）；取障碍参数 $\mu>0$、中心参数 $\sigma\in(0,1)$。
3. **迭代**：
   1. 计算对偶间隙 $\mathrm{gap}=x^\top s$。若 $\mathrm{gap}<\varepsilon$，终止。
   2. 计算牛顿方程右端 $r_c=Ax-b$、$r_b=A^\top y+s-c$、$r_{xs}=XSe-\sigma\mu e$。
   3. 解正规方程 $(A\Theta A^\top)\Delta y=r_a$，其中 $\Theta=XS^{-1}$；再回代求 $\Delta x,\Delta s$。
   4. 沿方向做**线搜索**：取满足 $x+\alpha\Delta x>0,\ s+\alpha\Delta s>0$ 的最大 $\alpha$ 再乘 0.99。
   5. 更新 $x,s,y$；$\mu\leftarrow\sigma\mu$。
4. 输出 $x^*$；**对偶变量 $y^*$ 即影子价格**，直接进灵敏度分析章节。

## 4. 复杂度与收敛性

| | 单纯形法 | 内点法 |
|---|---|---|
| 单次迭代时间 | $O(mn)$（用 $B^{-1}$ 更新），重解一次系统 $O(m^2n)$，稀疏下更低 | 解一次 $A\Theta A^\top$：稠密 $O(n^3)$，稀疏 Cholesky $O(n^{1.5}\sim n^2)$ |
| 迭代次数 | 平均 $O(m)$；**最坏 $O(2^n)$（Klee–Minty 立方体）** | 理论 $O(\sqrt n\log(1/\varepsilon))$ |
| 空间 | $O(mn)$ | $O(mn)$（稀疏格式可大幅降低） |
| 收敛类型 | **精确**：有限步终止于顶点（退化时有循环风险） | **渐近**：收敛到最优，需容差判定 |
| 最优解形态 | 一定落在**顶点**上 | 从内部逼近顶点 |
| 全局性 | **全局最优**（LP 是凸问题） | **全局最优** |

**必须写进论文的结论**：
1. LP 是**凸优化**，任何局部最优即全局最优；单纯形法找到的解**就是全局最优**，可以放心写"最优解"。
2. 单纯形法**最坏情况指数时间**，但实践中平均 $O(m)$ 次迭代，规模 $10^4$ 以内毫无压力。
3. 内点法**多项式时间**，规模上到 $10^6$ 变量时通常比单纯形法快，但解只在容差意义下最优，且**不直接给顶点解**（需交叉后处理）。
4. **退化**（多个基变量取 0）会导致循环；Bland 规则理论上可杜绝，工程上更常用扰动法。

## 5. 参数与调参要点

| 参数 | 推荐取值 | 依据 |
|---|---|---|
| 求解器方法选择 | Python 用 `method='highs'`（HiGHS，自动选单纯形/内点）；MATLAB 用 `'dual-simplex'` 或 `'interior-point'` | 〔推理〕通用经验 |
| 最优性容差 | 默认 $10^{-7}$；报告时目标值保留 4～6 位有效数字 | 〔推理〕通用经验 |
| 可行性容差 | 默认 $10^{-7}\sim10^{-8}$ | 〔推理〕通用经验 |
| 最大迭代 | 求解器默认即可；手写时设 $N_{\max}=10^4$ | 〔推理〕通用经验 |
| 变量/约束缩放 | 求解器自动；**手写时务必做**（把 $A$ 的行列归一化） | 〔推理〕；不缩放是"误判不可行 / 数值不稳定"的头号原因 |
| 大 M 的 $M$ | 取"比最优目标值大 2～3 个数量级"，**不要取 $10^{15}$** | 〔推理〕；$M$ 太大会让条件数爆炸 |
| 建模必备 | 所有变量写清上下界；LINGO 中 `@free(x)` 表自由变量，`@gin` 表整数，`@bin` 表 0-1 | 〔原文〕语料中大量论文使用 `@bin` / `@gin`（2011B 交巡警、2005B DVD 等） |

**真正决定成败的"参数"在建模层**：
- 约束方向（$\le$ / $\ge$ / $=$）写反；
- 忘写非负约束；
- 把"每个会员最多租 3 张"写成 $x_{ij}\le3$ 而不是 $\sum_j x_{ij}\le3$（**漏求和号**，是 0-1 规划最常见的错）。

## 6. 优点

1. **精确、可证明的最优**：LP 是凸问题，返回的是全局最优，可以理直气壮写"最优解"。
2. **有高可靠开源/商业求解器**，几十行建模代码即可求解上万变量的问题。
3. **天然输出影子价格与灵敏度报告**，是"模型检验 / 灵敏度分析"章节的现成素材。
4. **求解极快**：$10^3$ 变量的 LP 通常 $<0.1$ 秒，可以嵌套进枚举或分支定界的外层反复调用。
5. 是**整数规划、分支定界、列生成、拉格朗日松弛**的公共内核算子——掌握它就掌握了整条优化方法链的底座。
6. 建模语言（LINGO / PuLP / GurobiPy）与数学式子几乎一一对应，论文公式可近似直接抄进代码，**可复现性强**。

## 7. 缺点

1. **只能处理线性**。乘积项、平方项、取最大值、比例、绝对值都会破坏线性，必须引入辅助变量线性化（如 $z=\max(x,y)$ 需 3 条约束），变量数会暴涨。
2. **需连续变量**。整数/0-1 变量必须交给分支定界，规模一大就爆。
3. **单纯形法有退化循环与最坏指数复杂度**风险。
4. **内点法不直接给顶点解**，与"必须整数、必须选或不选"的现实决策脱节。
5. **模型写错时求解器不报错**，只返回一个"看起来合理"的答案，评委也难以察觉——最危险的失败模式。
6. **对数量级差异敏感**，未缩放时可能误判"不可行"。
7. **无解时难以定位原因**（不可行？无界？数值问题？），需分步松弛约束排查。

## 8. 适用规模与适用条件

**适用条件**：
- 目标与所有约束**关于决策变量都是线性的**；
- 决策变量**连续**，或整数变量少（$\lesssim100$）可交给分支定界；
- 规模：单纯形 $n,m\lesssim10^5$；内点法稀疏 $n\lesssim10^6$；
- 系数矩阵最好**稀疏**（运输问题、网络流天然稀疏）。

**适用规模**：变量 $10^1\sim10^6$；约束 $10^1\sim10^6$；求解时间毫秒到分钟。国赛题规模通常在几十到几千变量，**LP 属于"轻松搞定"档次**。

**典型国赛形态**〔归纳〕：生产计划、资源分配、运输/配送、书号与名额分配、投资组合（线性版）、下料问题（松弛版）、DVD 分配。

## 9. 不适用情况

- **目标或约束含非线性**：如"每件产品收益随产量递减""安全库存 $\propto\sqrt{\cdot}$"。应做分段线性化近似，或直接用非线性规划。
- **必须整数/0-1 且规模大**：如 72 个科目分配整数书号、上千个 0-1 选址变量 —— 先 LP 松弛再分支定界；直接套 LP 会得到"半本书号"的荒唐答案。
- **含"若…则…"逻辑约束**：需引入大 M 与 0-1 变量，本质已是混合整数规划。
- **目标函数不连续 / 分段常数**。
- **需要鲁棒或随机优化**：参数不确定时应建鲁棒 LP 或随机规划，普通 LP 会给出过度乐观的解。
- **规模极大且矩阵稠密**（$n>10^5$ 且稠密）：内存不足，需列生成或分解算法。
- **只有一个变量且可解析求解**：直接求导更快。

## 10. Python / MATLAB 实现要点

**Python**
- 首选 `scipy.optimize.linprog(c, A_ub=..., b_ub=..., A_eq=..., b_eq=..., bounds=..., method='highs')`；**先检查 `res.status`**：`0` 最优、`2` 不可行、`3` 无界。
- 大规模/整数：`pulp`（建模友好）、`mip`；商业级 `gurobipy` / `docplex`。
- `res.ineqlin.marginals` / `res.eqlin.marginals` 即**影子价格**，直接做灵敏度分析。
- **bounds 一定要显式给**（`bounds=[(0,None)]*n`），不要依赖默认。
- 数值问题：先把 $A$ 每行除以 $\|A_i\|$、$b$ 同除，做行缩放。
- 用 dict / DataFrame 管理变量名，**别用裸下标堆叠**——错一个下标会让整个结果错而无人察觉。

**MATLAB**
- `linprog(f, A, b, Aeq, beq, lb, ub, options)`，`options = optimoptions('linprog','Algorithm','dual-simplex','Display','iter')`。
- `[x,fval,exitflag,output,lambda] = linprog(...)`：`exitflag=1` 才最优；`lambda.eqlin` / `lambda.ineqlin` 是**对偶变量（影子价格）**。
- `optimvar` + `optimproblem`（R2017b+）是更现代的建模写法，支持 `'Type','integer'` / `'Type','binary'`，比手拼矩阵不易错。
- 老国赛代码用 `bintprog`；该函数已在 R2019a 移除，新代码用 `intlinprog`。
- 想在附录展示单纯形表：把 `Display` 设为 `'iter'`，或自写教学版单纯形表函数逐步打印。

**LINGO（国赛最常用的 LP 工具）**〔原文：语料中 LINGO 出现极高频〕
- 结构：`MODEL:` … `MIN=` / `MAX=` … `@SUM(SET(i): c(i)*x(i))` … `@BIN(x)` / `@GIN(x)` … `END`。
- `SETS:` 段定义集合与属性，是 LINGO 建模核心，比写循环清爽。
- 用 `@FOR` 生成约束族；`@FREE` 解除非负；`@BND` 给上下界。
- 求解报告中的 "Dual Price" 一列就是影子价格，**直接截图进论文**。
- 整数问题会启用分支定界（见"分支定界与割平面"卡片）。

### 推荐句式（可直接套用）

> 该问题的目标函数与全部约束均为决策变量的线性函数，故建立线性规划模型：$\min z=\sum_i\sum_j c_{ij}x_{ij}$，s.t. 供需平衡约束、容量约束、非负约束。模型含 $n$ 个决策变量、$m$ 个约束。本文调用（LINGO 11 / MATLAB linprog / Python scipy）的（单纯形法 / 对偶单纯形法 / 内点法）求解，得到最优目标值 $z^*=\cdot$，最优决策方案见表 x。

> 为分析约束松紧对结果的影响，本文利用求解器输出的**对偶变量（影子价格）**进行分析：约束（x）的影子价格为 $\cdot$，表示该约束右端项每增加 1 个单位，总成本将下降 $\cdot$ 元，因此（资源）是当前方案的瓶颈。

> 由于线性规划为凸优化问题，其任一局部最优解即为全局最优解，因此上述结果具有全局最优性。
