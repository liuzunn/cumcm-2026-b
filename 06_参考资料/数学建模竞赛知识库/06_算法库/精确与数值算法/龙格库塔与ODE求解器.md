## 1. 算法解决什么问题

**常微分方程初值问题（IVP）的数值求解**：
$$\frac{dy}{dt}=f(t,y),\qquad y(t_0)=y_0,\qquad y\in\mathbb R^d$$

国赛里的机理类题目（传染病 SIR/SEIR、种群动力学、航天器轨道、传热、药代动力学、无人机运动学）几乎全部归结为求解一个 ODE 系统。显式解析解通常不存在，必须数值积分。

**方法族**：
- **Euler 法**：一阶，$O(h)$，教学用，实际太粗糙；
- **中点法 / Heun 法**：二阶，$O(h^2)$；
- **经典 RK4（四阶龙格-库塔）**：$O(h^4)$，**国赛最常用的"手工方法"**；
- **自适应步长 RK（RK45 / Dormand-Prince）**：自动控制步长，是现代求解器（`ode45`、`solve_ivp`）的默认内核；
- **刚性求解器（BDF / Radau / LSODA / `ode15s`）**：用于刚性方程（快慢时间尺度差几个数量级，如带反应的化学反应、带快动力学的传染病）。

## 2. 输入与输出

**输入**
- 右端函数 $f(t,y)$（必须是可调用的函数，参数通过闭包/额外参数传入）；
- 初值 $y_0$ 与积分区间 $[t_0,t_f]$；
- 方法阶数（RK4 / RK45）与**误差容差**（`rtol`、`atol`）或固定步长 $h$；
- （反演问题额外需要）待估参数 $\theta$ 与观测数据 $\{(t_i,y_i^{\text{obs}})\}$。

**输出**
- 网格点上的近似解 $\{y(t_i)\}$（稠密输出模式可插值到任意 $t$）；
- **求解器统计量**：函数求值次数 `nfev`、成功步数、失败步数、是否触发刚性警告——**这些是论文里证明"解可靠"的证据**；
- （反演）参数估计 $\hat\theta$、残差平方和。

**关键**：输出必须包含**收敛性验证**——把步长减半再解一次，比较两次解的最大偏差（Richardson 检验），这是评审最看重的数值可信度证据。

## 3. 算法步骤（伪代码级）

### 3.1 经典四阶龙格-库塔（固定步长）

1. 输入 $f,\ t_0,\ t_f,\ y_0,\ h$；令 $N=(t_f-t_0)/h$（取整并**修正 $h$** 使区间被整除）；$y\leftarrow y_0$，$t\leftarrow t_0$。
2. **对 $i=1\dots N$**：
   1. $k_1\leftarrow f(t,\ y)$。
   2. $k_2\leftarrow f\big(t+\tfrac h2,\ y+\tfrac h2 k_1\big)$。
   3. $k_3\leftarrow f\big(t+\tfrac h2,\ y+\tfrac h2 k_2\big)$。
   4. $k_4\leftarrow f\big(t+h,\ y+h k_3\big)$。
   5. $y\leftarrow y+\dfrac h6(k_1+2k_2+2k_3+k_4)$。
   6. $t\leftarrow t+h$；把 $(t,y)$ 存入结果数组。
3. **保量修正**：若系统有守恒量（总人口、总能量、质量），检查 $|\text{不变量}(y)-\text{不变量}(y_0)|$；若漂移显著，改用**保结构方法**或在每步后投影回可行流形。
4. 输出解数组。

### 3.2 自适应步长 RK（Dormand–Prince RK45，`ode45` / `solve_ivp` 内核）

1. 输入 $f$、$[t_0,t_f]$、$y_0$、相对容差 $\text{rtol}$、绝对容差 $\text{atol}$、初始步长 $h_0$。
2. 用 RK45 的两个嵌入公式同时算出**四阶解 $y^{(4)}$ 与五阶解 $y^{(5)}$**。
3. **误差估计**：$\text{err}=\|y^{(5)}-y^{(4)}\|$（按分量用 $\text{atol}+\text{rtol}\cdot|y|$ 归一化）。
4. 若 $\text{err}\le1$：**接受步**，$t\leftarrow t+h$；否则**拒绝步**，$t$ 不变。
5. **调整步长**：$h_{\text{new}}=h\cdot\min(5,\max(0.2,\ 0.9\cdot\text{err}^{-1/5}))$。
6. 若 $h<h_{\min}$ 仍无法满足容差 → 报"容差过严或方程刚性"，**提示改用刚性求解器**。
7. 重复 2～6 直到 $t\ge t_f$（最后一步裁剪到 $t_f$）。
8. **稠密输出**：用 Step 2 中保存的中间级导数构造三次 Hermite 插值，可在任意 $t$ 处求值（`t_eval` / `dense_output=True`）。

### 3.3 反演形态：ODE + 参数估计（国赛最常见）

1. 定义 `simulate(theta, t_eval)`：给定参数 $\theta$，用 `solve_ivp` 解得 $y(t;\theta)$。
2. 定义残差 `resid(theta) = y(t_i;theta) - y_i^obs`。
3. 用 `scipy.optimize.least_squares` / MATLAB `lsqnonlin` 最小化 $\|\text{resid}\|^2$。
4. **注意**：外层优化每次迭代都要重新积分整个 ODE，因此**单次积分必须足够便宜**（$<0.1$ 秒）且**必须给解析或固定的 `rtol`**（否则优化器看到的残差带噪声，梯度会被毁掉）。
5. 反演完成后**复核**：把估计参数代回积分，画拟合曲线与残差图。

## 4. 复杂度与收敛性

| 方法 | 阶数 | 单步代价 | 全局误差 | 稳定性 |
|---|---|---|---|---|
| 显式 Euler | 1 | 1 次 $f$ 求值 | $O(h)$ | 条件稳定，$h<2/\|\lambda\|$ |
| 隐式 Euler | 1 | 每步解一次线性/非线性系统 | $O(h)$ | **A-稳定**（无条件稳定） |
| 中点法 / Heun | 2 | 2 次 | $O(h^2)$ | 条件稳定 |
| **经典 RK4** | 4 | **4 次** | $O(h^4)$ | 条件稳定（稳定域约 $|\lambda h|<2.78$） |
| RK45（Dormand–Prince） | 5(4) | 6 次 | 自适应 | 条件稳定 |
| BDF / Radau（隐式） | 变阶 | 每步解线性系统 | 自适应 | **A-稳定 / L-稳定**，适合刚性 |

**复杂度**：固定步长 RK4 共 $N$ 步，每步 4 次 $f$ 求值 → **时间 $O(N\cdot c_f)$**，空间 $O(d)$（只存当前解）或 $O(Nd)$（存全部）。自适应方法的时间取决于解的"难度"，不可预先确定。

**收敛性（必须写进论文）**：
1. 单步误差 $O(h^{p+1})$，**全局误差 $O(h^p)$**——RK4 即 $O(h^4)$：**步长减半，误差降为 $1/16$**。这是做收敛性验证图的理论依据。
2. 显式方法**只是条件稳定**：刚性方程（$|\lambda|h$ 很大）会数值爆炸。判据：若解的时间尺度相差 $10^3$ 倍以上（如快反应 + 慢扩散），**必须用隐式/刚性求解器**。
3. 自适应方法通过误差控制**保证每步局部误差在容差内**，但**不保证全局误差也在容差内**（全局误差可能累积放大，尤其对混沌系统）。
4. **混沌系统（如三体、Lorenz）**：任何数值方法都无法长期跟踪真实轨道，只能保证"统计意义正确"；论文中必须承认这一点。
5. 刚性判据：若求解器反复报"step size below minimum"或需要极小步长，即为刚性。

## 6. 优点

1. **高阶精度、实现简单**：RK4 只有 4 行核心代码，却能到 $O(h^4)$，性价比最高。
2. **无需导数**：与泰勒级数法不同，RK 只需 $f$ 的函数值，非常适合机理模型（$f$ 往往由物理公式组合而成）。
3. **自适应版本（RK45）几乎免调参**：给定容差就自动选步长，是现代求解器的默认，工程上极其省心。
4. **自启动**：不像多步法需要额外的启动过程，RK 从第一步就是高阶。
5. **可输出稠密解**：`dense_output=True` 得到连续函数，便于与观测时刻对齐、做参数反演。
6. **有配套生态**：`scipy.integrate.solve_ivp`、`ode45`、`ode15s` 覆盖了几乎所有场景，且求解器统计量（`nfev`、步数）能直接用作论文的可复现证据。
7. **收敛阶可验证**：步长减半误差降 16 倍，可以画一张极漂亮的 log-log 收敛图。

## 7. 缺点

1. **RK4 的稳定域有限**（约 $|\lambda h|<2.78$），**刚性方程会直接数值爆炸**——这是国赛机理题最常见的翻车点（如带快速反应项的传染病模型）。
2. **固定步长无法自适应**：解在某个区间变化剧烈时，全局精度被最坏区间拖累；用统一的小步长又会浪费大量计算。
3. **自适应方法不保证能量/质量守恒**，长时间积分会出现系统性漂移（如种群模型出现负人口）。
4. **误差控制是局部的**：局部误差满足容差 ≠ 全局误差满足容差；论文中不能写"误差小于 $10^{-6}$"除非你做了全局验证。
5. **对间断/不连续右端**（如"当温度超过阈值时切换策略"）表现差，步长会反复被拒，需分段积分或在间断点分界。
6. **反演嵌套代价高**：外层优化每次迭代都重新积分，$10^4$ 次积分 × 每次 0.1 秒 = 17 分钟，在比赛中很容易超时。
7. **混沌系统给不出长期可信轨道**，容易被误解为"模型不准"。

## 8. 适用规模与适用条件

**适用条件**：
- 问题可写成**一阶 ODE 系统**（高阶方程先化为一阶系统）；
- 右端 $f$ **连续**（最好 Lipschitz 连续，保证解唯一）；
- **非刚性**（时间尺度差异 $\lesssim10^2$ 倍）→ 显式 RK；**刚性** → 隐式求解器；
- 状态维数 $d\lesssim10^3$（再大应考虑稀疏/并行）；
- 积分区间内解的光滑度足够（无强间断）。

**适用规模**：状态维数 $d=1\sim10^3$；积分步数 $10^2\sim10^6$；单次求解耗时微秒到秒级。

**国赛典型形态**〔归纳〕：传染病动力学（SIR/SEIR）、种群竞争、航天器轨道与软着陆控制、传热、药代动力学、无人机运动、烟幕扩散。

## 9. 不适用情况

- **刚性方程**（快慢尺度差 $10^3$ 倍以上）：显式 RK 的步长会被最快尺度锁死，效率极低甚至溢出。必须改 `BDF` / `Radau` / `ode15s` / `LSODA`。
- **高维 PDE 空间离散后的 ODE 系统**（$d>10^4$）：显式方法受 CFL 条件限制，步长极小；应用隐式方法 + 迭代线性求解。
- **需要严格守恒**的长期积分（天体力学、长期气候）：应用辛方法（Störmer-Verlet / 隐式中点）而非 RK。
- **不连续右端或事件驱动系统**：需配合事件检测（`events=`）分段积分，否则步长控制会失效。
- **问题有随机性**：应改用 SDE 求解器（Euler-Maruyama / Milstein）。
- **只需要稳态解**：直接把 $dy/dt=0$ 作为代数方程组求解（`fsolve`），不必积分到稳态——这能省下 99% 的时间。
- **解析解存在且简单**：直接给解析解更好，数值解只作为验证。

## 10. Python / MATLAB 实现要点

**Python**
- 首选 `scipy.integrate.solve_ivp(fun, t_span, y0, method='RK45', rtol=1e-8, atol=1e-10, t_eval=..., dense_output=True, events=...)`。
- **`fun(t, y, *args)` 的签名不能变**；参数用 `args=(p1,p2)` 或在闭包里捕获（推荐闭包，可读性好）。
- `method` 选项：`'RK45'`（默认，非刚性）、`'DOP853'`（8 阶高精度）、`'LSODA'`（自动刚性检测）、`'BDF'`/`'Radau'`（刚性）。
- 结果对象：`sol.t`、`sol.y`、`sol.nfev`、`sol.success`、`sol.status`——**`sol.success=False` 时结果不可用，必须处理**。
- 事件检测（如"温度首次达到 44℃ 的时刻"）：写 `def event(t,y): return y[0]-44`，设 `event.terminal=True`。
- 反演：`least_squares(residual, theta0, diff_step=1e-6)`，其中 `residual` 内部调 `solve_ivp`；**把 `rtol` 固定死**，否则优化器会被噪声梯度带偏。
- 保量修正：每步后检查 `abs(sum(y) - sum(y0))`，必要时投影。

**MATLAB**
- `[t,y] = ode45(@(t,y) odefun(t,y,p), tspan, y0, options)` 是国赛代码最常见的写法。
- `options = odeset('RelTol',1e-8,'AbsTol',1e-10,'Stats','on')`；`Stats` 打开可打印步数与函数求值次数，直接抄进论文。
- 刚性 → `ode15s` / `ode23s`；高精度 → `ode113`（变阶 Adams）。
- 事件：`options = odeset('Events', @myEventsFcn)`，返回 `[value, isterminal, direction]`。
- 反演：`lsqnonlin(@(p) myResidual(p, tdata, ydata), p0)`，其中 `myResidual` 内部调 `ode45`。
- **注意死循环风险**：某些参数会让 `ode45` 步长无限缩小；设 `odeset('MaxStep', T/100)` 兜底。
- `deval` 可以把 `sol` 插值到任意时刻（等价于 Python 的 `dense_output`）。

## 11. 国赛论文中的写法与案例

### 推荐句式（可直接套用）

> 模型（x）为一阶常微分方程组初值问题 $\dfrac{dy}{dt}=f(t,y;\theta),\ y(0)=y_0$。由于该方程组无解析解，本文采用**四阶龙格-库塔法**进行数值求解。取步长 $h=\cdot$，相对误差容差 $10^{-8}$，积分区间 $[0,T]$。为验证数值结果的可靠性，本文将步长减半后重新求解，两次解的最大相对偏差为 $\cdot$（$<10^{-6}$），且相应减小到原来的约 $1/16$，与 RK4 的 $O(h^4)$ 精度阶一致。

> 求解结果显示：在 $t=\cdot$ 时刻（某状态量）达到峰值 $\cdot$，随后（演化趋势）。该结果与附件中的实测数据对比，最大相对误差为 $\cdot\%$。

> 需要说明的是，显式龙格-库塔法为条件稳定方法，其稳定域为 $|\lambda h|\lesssim2.78$。本文模型的（快/慢）时间尺度比为 $\cdot$，落在稳定域内，故采用显式方法求解（若该比值超过 $\cdot$，则应改用 BDF / ode15s 等刚性求解器）。

### 配图建议
1. **解曲线图**：横轴时间，纵轴各状态量，多条曲线叠加；关键阶段用阴影或竖线标注（如"封城措施实施"）。
2. **相图（phase portrait）**：如 S–I 平面轨迹，直接展示动力学结构。
3. **收敛阶验证图**：双对数坐标，横轴 $h$，纵轴与参考解的最大误差，斜率 $-4$ 即验证 RK4 的阶——**这是最能体现数值素养的一张图**。
4. **拟合对比图**：实测散点 + 模型曲线 + 残差子图（反演题必备）。
5. **参数敏感性图**：逐个参数变动 ±20%，画关键输出指标的变化曲线（或龙卷风图）。
6. **求解器状态表**：方法、容差、步数、函数求值次数、最大残差——一张小表即可证明可复现。
