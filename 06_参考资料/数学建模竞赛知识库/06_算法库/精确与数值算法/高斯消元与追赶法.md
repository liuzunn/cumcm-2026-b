# 高斯消元与追赶法

## 1. 算法解决什么问题

**稠密或三对角线性方程组 $Ax=b$ 的直接求解**。这是几乎所有数值方法的最后一公里：有限差分/有限元离散后的 PDE、回归的正规方程、样条插值的系数求解、状态空间模型的隐式时间步，最后都归结为解一个线性方程组。

- **高斯消元（Gaussian Elimination）**：用行变换把 $A$ 化为上三角，再回代。带**列主元**的版本（GEPP）是通用稠密方程组的标准解法。
- **LU 分解**：把 $A=LU$ 预先分解；当需要对同一个 $A$、多个右端项 $b$ 反复求解时（国赛里非常常见——每个时间步的 $b$ 都不同），LU 只算一次，之后每次只需 $O(n^2)$ 前代回代。
- **追赶法（Thomas 算法，TDMA）**：专门解**三对角方程组**的 $O(n)$ 直接法。有限差分热传导、对流扩散、三次样条插值的系数方程都是三对角的，这是国赛机理类题目里最高频的线性代数工具。

## 2. 输入与输出

**高斯消元 / LU**
- 输入：系数矩阵 $A\in\mathbb R^{n\times n}$ 或 $A\in\mathbb R^{m\times n}$（最小二乘）、右端 $b$；
- 输出：解 $x$；或 $L,U,P$ 因子；附带**条件数估计**（判断解是否可信）。

**追赶法**
- 输入：三条对角线（下对角 $a_1,\dots,a_{n-1}$、主对角 $b_1,\dots,b_n$、上对角 $c_1,\dots,c_{n-1}$）与右端 $d_1,\dots,d_n$。
- 前置条件：**对角占优** $|b_i|\ge|a_{i-1}|+|c_i|$（严格不等号至少在一处成立）；热传导隐式格式天然满足。
- 输出：解向量 $x$，以及中间量 $\beta_i$（可复用）。
- 复用价值：若 $A$ 不变而 $d$ 随每个时间步变化，把消元阶段的 $\beta_i$ 预存，每个时间步只需 $O(n)$ 回代。

## 3. 算法步骤（伪代码级）

### 3.1 高斯消元（含列主元，GEPP）

1. 输入 $A,b$；令 $n=\dim A$；构造增广矩阵 $[A\,|\,b]$。
2. **对 $k=1$ 到 $n-1$**：
   1. **选主元**：在列 $k$ 的第 $k\dots n$ 行中找出 $|a_{ik}|$ 最大者，记为第 $p$ 行。
   2. 若 $|a_{pk}|<\tau$（阈值，如 $10^{-14}\cdot\|A\|_\infty$），**判定矩阵奇异或严重病态**，报错并给出条件数估计，不要继续。
   3. 交换第 $k$ 行与第 $p$ 行（**$b$ 也要交换**，忘了这一步是最经典 bug）。
   4. **消元**：对 $i=k+1\dots n$：$m_{ik}=a_{ik}/a_{kk}$；$a_{ij}\leftarrow a_{ij}-m_{ik}a_{kj}$（$j\ge k$）；$b_i\leftarrow b_i-m_{ik}b_k$。
3. **回代**：$x_n=b_n/a_{nn}$；对 $i=n-1\dots1$：$x_i=\big(b_i-\sum_{j>i}a_{ij}x_j\big)/a_{ii}$。
4. **验算**：计算残差 $r=b-Ax$，报告 $\|r\|_\infty/\|b\|_\infty$。**如果残差大于 $10^{-8}$，解不可信**，需改用迭代精化或换方法。
5. 输出 $x$ 与残差。

### 3.2 LU 分解（Doolittle / 带主元）

1. 输入 $A$；令 $U\leftarrow A$，$L\leftarrow I$，$P\leftarrow I$。
2. 对 $k=1\dots n-1$：
   1. 选主元（同 3.1），交换 $U$ 与 $P$ 的相应行。
   2. 对 $i=k+1\dots n$：$l_{ik}=u_{ik}/u_{kk}$；$U_{i,k:n}\leftarrow U_{i,k:n}-l_{ik}U_{k,k:n}$。
3. **求解 $Ax=b$**：先解 $Ly=Pb$（前代，$O(n^2)$），再解 $Ux=y$（回代，$O(n^2)$）。
4. **多右端项复用**：$L,U,P$ 只算一次，对每个新 $b$ 只做步骤 3。
5. 输出 $L,U,P$；若需要，用 $\|U\|\|U^{-1}\|$ 估计条件数。

### 3.3 追赶法（Thomas 算法，三对角）

1. 输入 $a_{1..n-1}$（下）、$b_{1..n}$（主）、$c_{1..n-1}$（上）、$d_{1..n}$。
2. **前向消元（追）**：
   1. $\beta_1\leftarrow b_1$；若 $|\beta_1|<\tau$ → 报错（首个主元过小）。
   2. $\gamma_1\leftarrow d_1/\beta_1$。
   3. 对 $i=2\dots n$：
      1. $\beta_i\leftarrow b_i-a_{i-1}c_{i-1}/\beta_{i-1}$。
      2. 若 $|\beta_i|<\tau$ → 报错（矩阵非对角占优或奇异）。
      3. $\gamma_i\leftarrow\big(d_i-a_{i-1}\gamma_{i-1}\big)/\beta_i$。
3. **后向回代（赶）**：$x_n\leftarrow\gamma_n$；对 $i=n-1\dots1$：$x_i\leftarrow\gamma_i-\dfrac{c_i}{\beta_i}x_{i+1}$。
4. **验算**：抽查 3～5 个分量验证 $a_ix_{i-1}+b_ix_i+c_ix_{i+1}=d_i$（因为整条向量验算会破坏 $O(n)$ 的意义，只验算关键点即可）。
5. 输出 $x$。**若时间步循环内 $A$ 不变**，把 $\beta$ 与 $c_i/\beta_i$ 预存复用。

## 4. 复杂度与收敛性

| 方法 | 时间复杂度 | 空间复杂度 | 收敛性 |
|---|---|---|---|
| 高斯消元（无主元） | $O(n^3/3)$ | $O(n^2)$ | **直接法，有限步精确**（在精确算术下） |
| 高斯消元（GEPP） | $O(2n^3/3)$（含行交换开销） | $O(n^2)$ | 直接法；**数值后向稳定** |
| LU 分解 + 多右端 | 分解 $O(2n^3/3)$；每次求解 $O(2n^2)$ | $O(n^2)$ | 直接法 |
| 追赶法 | **$O(n)$**（前向 $\approx3n$ 乘除，回代 $\approx2n$） | $O(n)$ | 直接法 |
| 三对角 LU（同解多个 $d$） | 分解 $O(n)$；每次求解 $O(n)$ | $O(n)$ | 直接法 |

**必须写进论文的结论**：
1. 高斯消元与追赶法都是**直接法**：没有"收敛速度"问题，在精确算术下**有限步给出精确解**。
2. 实际精度由**条件数**决定：前向误差界 $\dfrac{\|\delta x\|}{\|x\|}\lesssim \kappa(A)\dfrac{\|\delta b\|}{\|b\|}$。$\kappa(A)=10^{k}$ 意味着损失 $k$ 位有效数字。
3. **追赶法要求对角占优**，此时它是数值稳定的（无主元选取也安全，误差放大因子 $\le2$）。**热传导隐式差分格式天然严格对角占优**，因此可放心使用。
4. 一般三对角矩阵**不做主元选取可能不稳定**；若不满足对角占优，应改用"带部分主元的追赶法"或直接上 `scipy.linalg.solve_banded`。
5. 高斯消元在**无主元**时可能因小主元导致灾难性误差放大——**必须选主元**。

## 5. 参数与调参要点

| 参数 | 推荐取值 | 依据 |
|---|---|---|
| 主元阈值 $\tau$ | $10^{-14}\sim10^{-12}$ 乘以 $\|A\|_\infty$ | 〔推理〕通用经验 |
| 残差可接受阈值 | $\|r\|_\infty/\|b\|_\infty<10^{-10}$（双精度）；$<10^{-8}$ 为最低要求 | 〔推理〕通用经验 |
| 条件数警戒线 | $\kappa(A)>10^{12}$ → 双精度下解基本无效，需正则化（Tikhonov）或用更高精度 | 〔推理〕数值分析标准结论 |
| 追赶法的对角占优检验 | 断言 $|b_i|\ge|a_{i-1}|+|c_i|$，至少一处严格 | 〔推理〕；**这是必须在代码里 assert 的条件** |
| 网格/时间步比 | 隐式格式 $\Delta t$ 不受稳定性限制，但精度上建议 $\Delta t\sim\Delta x^2/\alpha$ 量级 | 〔推理〕；热扩散系数 $\alpha$ 决定 |
| 病态问题处理 | 加 Tikhonov 正则 $(A^\top A+\lambda I)x=A^\top b$，$\lambda$ 取 $10^{-6}\sim10^{-3}$（用 L 曲线法定） | 〔推理〕通用经验 |
| 变量/方程缩放 | 把每行除以该行系数范数（**equilibration**），可使条件数改善几个数量级 | 〔推理〕通用经验 |
| 稀疏存储 | 三对角用三个一维数组，绝不构造 $n\times n$ 稠密矩阵 | 〔推理〕；$n=10^5$ 时稠密矩阵需 80 GB，三数组只需 2.4 MB |

**国赛中真实出现的组合方式**〔原文〕：
- `2009A：制动器试验台混合电模拟控制方法分析.pdf.txt`："首先用**三次样条插值及追赶法**（求解）……简记 $Am=g$，用追赶法，求出 $m_j$。求解 $Am=g$ 等价于求解三角方（程组）" —— 三次样条插值的系数矩阵恰好是三对角，这是"样条 + 追赶法"的标准搭配。
- `2018A：高温作业专用服装设计.pdf.txt`："（后向差分）格式并整理得到代数方程组，**采用追赶法求解方程组**"；代码段"Step4：**利用追赶法解三对角线性方程组**"。

## 6. 优点

1. **精确、无迭代**：直接法一步到位，不需要初值、不需要收敛判据，对国赛现场极其友好。
2. **追赶法是 $O(n)$**：$n=10^5$ 的网格也能秒解；这是它能成为热传导类题目标配的原因。
3. **数值稳定有理论保证**：GEPP 后向稳定；追赶法在对角占优下误差放大因子 $\le2$。
4. **可复用**：LU 分解后，多个右端项只花 $O(n^2)$；追赶法的 $\beta$ 也可复用，正好匹配"时间步进"的计算模式。
5. **实现短，易验证**：追赶法不到 20 行，用解析解（如稳态温度）可以立刻验算。
6. 与所有数值 PDE 方法（有限差分、有限元、有限体积）天然衔接，是机理类建模的通用底座。
7. 配套工具成熟：`numpy.linalg.solve`、`scipy.linalg.solve_banded`、`scipy.linalg.solve_triangular`、MATLAB 反斜杠算子 `\`（自动识别三对角并走 banded 求解）。

## 7. 缺点

1. **$O(n^3)$ 是硬墙**：$n=10^4$ 的稠密矩阵需 $\sim10^{12}$ 次浮点运算，秒级到分钟级；$n=10^5$ 直接不可行（需迭代法或稀疏技术）。
2. **稠密矩阵内存 $O(n^2)$**：$n=10^5$ 需 80 GB，必须用稀疏格式。
3. **追赶法只对三对角**：五对角/带状需推广为带状 LU，实现复杂度上升。
4. **不做主元时可能不稳定**：追赶法在非对角占优时误差放大因子可达 $2^n$ 级〔推理〕。
5. **病态问题（$\kappa$ 大）无法根治**：直接法会如实放大误差，需要正则化——而正则化会引入偏差，得在论文里权衡说明。
6. **无解的诊断能力弱**：矩阵奇异时报错信息通常只有"singular matrix"，需要自己加条件数估计来定位。
7. **不是"最优解"意义上的算法**：它解的是方程，不是优化问题；把它当"求解器"写进优化章节属于概念混淆。

## 8. 适用规模与适用条件

**适用条件**：
- 问题最终归结为 **$Ax=b$**，且 $A$ 已知且不随迭代剧烈变化；
- 稠密高斯消元：$n\lesssim5\times10^3$（单机内存与秒级时间）；
- 带状/三对角：$n$ 可达 $10^6$；
- 追赶法：**必须**满足对角占优（或其弱化形式）；
- 条件数 $\kappa(A)\lesssim10^{10}$。

**适用规模**：三对角 $n=10^2\sim10^6$；稠密 $n=10^2\sim5\times10^3$；带状带宽 $w$，代价 $O(nw^2)$。

**国赛典型形态**〔归纳〕：热传导/扩散方程隐式差分、三次样条插值、回归正规方程、状态空间递推、网络节点电位方程。

## 9. 不适用情况

- **$n$ 大且矩阵稀疏但非带状**（如二维/三维 PDE 的离散矩阵）：用迭代法（CG / GMRES / 多重网格），直接法会 fill-in 爆炸。
- **$A$ 奇异或接近奇异**：应改用最小二乘/伪逆（`numpy.linalg.lstsq`）或正则化，直接法会给出巨大的、无意义的解。
- **三对角但严重非对角占优**：追赶法不稳定，应改用带主元的带状求解或迭代法。
- **$A$ 随每次迭代变化**（非线性问题的 Newton 步）：LU 复用的前提失效，每次都要 $O(n^3)$ 重分解——此时应考虑拟牛顿法（少分解几次）。
- **只需要近似解且 $n$ 极大**：迭代法（Jacobi / CG）在少量迭代内就能给够精度，比直接法快得多。
- **超定方程组 $m\gg n$**：不要构造 $A^\top A$（条件数平方恶化），直接用 QR 或 SVD。
- **问题本身是优化问题**：不要用解方程的方式硬套。

## 10. Python / MATLAB 实现要点

**Python**
- **不要手写高斯消元**，用 `numpy.linalg.solve(A, b)`（内部 LAPACK `dgesv`，带主元）；`scipy.linalg.lu(A)` 得 $P,L,U$；`scipy.linalg.lu_factor` + `lu_solve` 用于多右端复用。
- 三对角：**不要构造稠密矩阵**，用 `scipy.linalg.solve_banded((1,1), ab, d)`，其中 `ab` 是 $(3,n)$ 的带状存储，**上对角要放在第一行且右移一位**（这个偏移极容易错，务必用小例子验证）。
- 三角求解用 `scipy.linalg.solve_triangular(A, b, lower=True)`，比 `solve` 快一倍。
- 条件数：`np.linalg.cond(A)`；残差：`np.linalg.norm(b - A@x, np.inf)/np.linalg.norm(b, np.inf)`——**每次求解后都打印残差**，这是最便宜的调试手段。
- 手写追赶法时把 `beta` 存下来供时间步循环复用：`betas = np.zeros(n)`。
- 稀疏场景用 `scipy.sparse.linalg.spsolve`（直接法）或 `cg`/`gmres`（迭代法）。

**MATLAB**
- `x = A\b` 是万能写法：MATLAB 会自动识别矩阵结构（三对角 → banded solver，三角 → 前代/回代，稀疏 → 稀疏 LU），**比手写快且稳**。
- 三对角用 `spdiags([a b c], [-1 0 1], n, n)` 构造稀疏矩阵，再 `A\d`。
- 显式 LU：`[L,U,P] = lu(A)`；多右端用 `x = U\(L\(P*b))`。
- 条件数：`cond(A)`、`condest(A)`（稀疏版）；残差 `norm(b-A*x, inf)/norm(b, inf)`。
- 老国赛代码中的追赶法一般写成 `function x = zhuigan(a,b,c,d)`，用 `for` 循环实现——**注意 MATLAB 的循环在 $n=10^5$ 时很慢**，尽量向量化或直接用 `spdiags` + `\`。
- 与 `pdepe`（MATLAB 内置一维抛物/椭圆 PDE 求解器）对比，可以论证"自行离散 + 追赶法"的必要性。

## 11. 国赛论文中的写法与案例

### 推荐句式（可直接套用）

> 对（热传导）方程采用（Crank–Nicolson / 后向差分）格式离散，得到形如 $Am=g$ 的**三对角线性方程组**，其中系数矩阵满足严格对角占优条件。由于三对角方程组可用追赶法在 $O(n)$ 时间内精确求解，本文采用追赶法（Thomas 算法）逐时间步求解，得到时间-空间二维的温度分布（见图 x）。

> 为保证数值可靠性，本文对每一步解进行残差检验，$\|g-Am\|_\infty/\|g\|_\infty<10^{-12}$，且系数矩阵条件数约为 $\cdot$，说明该离散系统良态。

> 由于系数矩阵 $A$ 不随时间变化，本文在首个时间步完成消元后保存中间量 $\beta_i$，后续时间步仅需 $O(n)$ 的回代运算，显著减少了计算量。

### 配图建议
1. **三对角矩阵结构图**（spy 图或非零元示意图）：直观说明"为什么可以用追赶法"，是机理类论文的加分图。
2. **温度/浓度时空演化热力图**：横轴位置、纵轴时间、色标为温度，一张图讲完整个解。
3. **网格收敛性验证图**：横轴网格数 $n$（对数），纵轴与解析解/细网格解的最大误差（对数），斜率 $-2$ 即验证了二阶精度。
4. **残差与条件数表**：每个时间步（或每 100 步）的残差和条件数，作为数值可靠性的证据。
5. **解法对比表**：追赶法 vs 直接求逆 vs MATLAB 反斜杠的耗时对比（同样精度下），证明选型合理。
