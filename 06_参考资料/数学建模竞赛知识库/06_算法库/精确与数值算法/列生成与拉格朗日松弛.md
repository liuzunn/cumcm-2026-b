## 1. 算法解决什么问题

**变量极多或约束极多的大规模线性/整数规划**。这类问题的共同特征是：把问题完整写出来会有**指数级个变量**（或约束），根本存不下，但**最优解里只有极少数变量取非零**。

- **列生成（Column Generation, CG）**：不枚举全部变量，只维护一个**受限主问题（RMP）**，用**定价子问题（pricing problem / 子问题）**按对偶价格找出"有利可图"的新变量（列）加入 RMP，反复迭代直到没有可改进的列。适用于**变量爆炸**（如切割下料、乘务排班、车辆路径）。
- **拉格朗日松弛（Lagrangian Relaxation, LR）**：把"难约束"（耦合约束）以乘子 $\lambda$ 的罚项形式移到目标里，得到**易解的松弛问题**；通过调整 $\lambda$ 求对偶界。适用于**约束爆炸**（如"每辆车"耦合约束、多时段耦合约束）。

两者经常配合使用：**LR 用于快速求界，CG 用于求精确解**；或在 branch-and-price 中嵌套。

## 2. 输入与输出

### 列生成
- **输入**：主问题（set partitioning / covering 形式）$\min\sum_{k}c_k x_k$ s.t. $\sum_k a_{ik}x_k\ge1\ \forall i$；一个能"给定对偶价格 $\pi$，返回使 $\bar c_k=c_k-\pi^\top a_k$ 最小的列"的**定价子问题**；初始可行列（人工列或贪心列）。
- **输出**：最优整数解、最优列集合、迭代次数、每轮定价子问题的最小检验数 $\min\bar c_k$。
- **判优条件**：当 $\min_k \bar c_k\ge0$ 时，RMP 的最优解即原主问题 LP 的最优解。

### 拉格朗日松弛
- **输入**：原问题 $\min c^\top x$ s.t. 易约束 $Ax\le b$、难约束 $Dx\le d$；乘子 $\lambda\ge0$；步长规则参数。
- **输出**：**对偶界** $L(\lambda)$（对 min 问题是下界）、乘子最优值 $\lambda^*$、由松弛解**修复出的可行解**（上界）。
- **关键副产品**：上下界之差 → 最优性间隙；这是论文里最有价值的数字。

## 3. 算法步骤（伪代码级）

### 3.1 列生成

1. **构造初始 RMP**：只放入少量容易得到的可行列（如每个需求一条"单独服务"的列）。若 RMP 不可行，加人工列并以大 M 惩罚。
2. **循环**（迭代计数 $t=1,2,\dots$）：
   1. **解 RMP 的 LP 松弛**，得到对偶变量 $\pi$（覆盖约束的对偶价）。
   2. **解定价子问题**：$\min_k\ \bar c_k=c_k-\pi^\top a_k$。
      - 若子问题结构是**最短路**（车辆路径类）→ 用带负权边的最短路（Bellman-Ford / 标签法）。
      - 若是**背包**（下料类）→ 用 DP 求 $\max\pi^\top a$ s.t. 尺寸约束。
      - 若是**多时段耦合**（排班类）→ 用 DP 或分层的状态图最短路。
   3. **收敛检验**：若 $\min_k\bar c_k\ge-\varepsilon$（$\varepsilon=10^{-6}$），**LP 已最优**，跳出循环。
   4. 否则，把使 $\bar c_k<0$ 的列（**可加多列**，别一次只加一列，收敛快得多）加入 RMP。
   5. $t\leftarrow t+1$；超过 $N_{\max}$ 报未收敛。
3. **整数化**：对最终的列池做**分支定价（branch-and-price）**或直接解一个只含已生成列的 IP（set partitioning），得到整数可行解。
4. 输出整数解，并报告"LP 下界、整数解、gap"。

### 3.2 拉格朗日松弛

1. 识别**难约束** $Dx\le d$（去掉它问题就变简单的那组约束）。
2. **构造拉格朗日函数**：$L(x,\lambda)=c^\top x+\lambda^\top(Dx-d)$，$\lambda\ge0$。
3. **松弛问题**：$L(\lambda)=\min_{x\in X}L(x,\lambda)$，其中 $X=\{x: Ax\le b\}$ 是易约束集。**这个子问题必须能被高效求解**（如按变量可分离 → 每个变量独立取最优；若是背包/最短路 → 有专用算法）。
4. **对偶问题**：$\max_{\lambda\ge0}L(\lambda)$——是凹函数最大化，用**次梯度法**求解。
5. **次梯度法迭代**：
   1. 给定 $\lambda^{(t)}$，解松弛子问题得 $x^{(t)}$。
   2. 计算次梯度 $g^{(t)}=Dx^{(t)}-d$；若 $g^{(t)}\le0$（难约束已满足），则 $x^{(t)}$ 是原问题可行解，更新上界 $\bar z\leftarrow\min(\bar z,c^\top x^{(t)})$。
   3. 更新乘子：$\lambda^{(t+1)}=\max\{0,\ \lambda^{(t)}+\theta_t g^{(t)}\}$。
   4. **步长**：$\theta_t=\dfrac{\alpha_t(\bar z-L(\lambda^{(t)}))}{\|g^{(t)}\|^2}$，$\alpha_t$ 从 2.0 开始，连续若干轮界不改进则减半。
   5. 更新下界 $\underline z=\max_t L(\lambda^{(t)})$。
   6. 停止：$\bar z-\underline z\le\varepsilon$，或 $\alpha_t<10^{-4}$，或迭代超限。
6. **修复**：对最终的 $x^{(t)}$ 施加难约束（如把超载的货物重新分配），得到原问题的**可行解**，这才是有用的答案。
7. 输出：下界 $\underline z$、可行解上界 $\bar z$、gap、乘子 $\lambda^*$（**乘子的物理意义往往是"影子价格"，可作灵敏度分析的依据**）。

## 4. 复杂度与收敛性

| | 列生成 | 拉格朗日松弛 |
|---|---|---|
| 每轮时间 | RMP 的 LP：$O(\text{列数}\times m)$；定价子问题：依赖结构，如最短路 $O(nm)$、背包 DP $O(nW)$ | 解松弛子问题 + $O(n)$ 更新乘子 |
| 迭代次数 | 经验几轮到几百轮 | 次梯度法**无有限收敛保证**，实践几十到几千次 |
| 空间 | $O(\text{生成列数}\times m)$（列数远小于全枚举） | $O(nm)$（原问题规模） |
| 收敛性 | **收敛到 LP 松弛的最优值**（理论上有限步，实践可能尾端收敛慢——"尾部效应"） | **对偶函数凹，次梯度法收敛到对偶最优**；但**对偶间隙（duality gap）一般不为 0** |
| 最优性 | CG 给 **LP 松弛的全局最优**；整数最优需 branch-and-price | LR 只给**界**，不给原问题最优解 |

**必须写进论文的三句话**：
1. **列生成只保证 LP 松弛最优**，整数最优必须再接分支定价；论文中不能混写。
2. **拉格朗日松弛给的是下界（对 min 问题）**，且当问题**不具备整数性（integrality property）**时，对偶间隙 $>0$——即"松弛界的最大化"达不到原问题最优值。这一点必须在论文中明确指出，否则结论不严谨。
3. **次梯度法不保证单调改进**，界会上下波动，因此必须记录"历史最好界"而不是"最后一次的界"。

## 5. 参数与调参要点

| 参数 | 推荐取值 | 依据 |
|---|---|---|
| CG 检验数容差 $\varepsilon$ | $10^{-6}$（LP 收敛判定） | 〔推理〕通用经验 |
| CG 每轮加列数 | 3～50 列（加多列显著缓解尾部效应） | 〔推理〕通用经验 |
| CG 最大迭代 $N_{\max}$ | 500～5000 | 〔推理〕通用经验 |
| CG 初始列 | 贪心生成的可行列（每个需求一条单独列 + 若干贪心合并列） | 〔推理〕通用经验 |
| 次梯度初始步长比例 $\alpha_0$ | 2.0（经典取值）；保守可取 0.5～1.0 | 〔推理〕通用经验 |
| 步长衰减 | 连续 $k$ 轮（$k=5\sim20$）界不改进则 $\alpha\leftarrow\alpha/2$ | 〔推理〕通用经验 |
| $\alpha$ 终止阈值 | $10^{-4}\sim10^{-3}$ | 〔推理〕通用经验 |
| LR 迭代上限 | 500～5000 | 〔推理〕通用经验 |
| 乘子初值 $\lambda^{(0)}$ | 0，或用 LP 松弛的对偶解热启动（**强烈推荐**，能省一半迭代） | 〔推理〕通用经验 |
| 停止 gap | $1\%\sim5\%$（工程可接受）；严格证明需接近 0 | 〔推理〕通用经验 |
| 修复策略 | 按"违反量/成本比"排序后逐个调整；或对难约束做一次小规模 IP | 〔推理〕通用经验 |

**调参坑**：
- 次梯度步长衰减太快 → 提前停滞在半路；太慢 → 界长期震荡。
- CG 只加一列（最负检验数）→ 收敛极慢，是初学者最常见的低效写法。
- CG 的 RMP 数值不稳定（列之间高度相似、退化严重）→ 需要列池去重与列管理。

## 6. 优点

1. **能处理"写不出来"的问题**：变量数是天文数字（如切割方案数、路径数）时，只有 CG 能精确求解。
2. **LR 能给高质量的界**：即使不给最优解，一个紧的下界对论证"我们的启发式解已经接近最优"极其有用——这是提升论文档次的高级手法。
3. **LR 的乘子有明确物理意义**（影子价格），可直接用于灵敏度分析与资源定价讨论。
4. **子问题常常是经典问题**，可复用现成算法（最短路、背包 DP），实现成本可控。
5. **可与启发式互补**：LR 提供界，启发式提供可行解，二者合起来就是完整的"上下界夹逼"论证。
6. 在论文中属于**明显高于平均水平的技术含量**，且可以画出"界随迭代收敛"的漂亮曲线。

## 7. 缺点

1. **实现门槛高**：CG 需要正确推导对偶与定价子问题；LR 需要识别合适的难约束并保证子问题可解。写错一步结果全错且难以察觉。
2. **LR 对偶间隙一般不为 0**，不能声称"求得最优解"。
3. **次梯度法收敛慢且不单调**，调参经验性强。
4. **CG 的尾部效应**：最后 1% 的目标改进可能要花掉一半的迭代。
5. **必须自己写整数化环节**（branch-and-price 很难写），比赛现场时间成本极高。
6. **国赛题目规模通常不需要**：几十年国赛语料中未检索到使用案例（见第 11 节），说明**绝大多数国赛题用不到**，属于"炫技但可能跑偏"的方法。
7. 对**问题结构**要求苛刻：如果问题本身不具可分性/列结构，强行套用只会更慢。

## 8. 适用规模与适用条件

**适用条件（列生成）**：
- 问题天然写成 **set partitioning / covering** 形式，变量是"方案/路径/模式"；
- 变量的**显式枚举数 $\ge10^5$**，但最优解中非零变量数 $\ll$ 总变量数；
- 定价子问题**能被多项式时间求解**（最短路、背包、分配等）；
- 能接受"先得 LP 界、再整数化"的两阶段流程。

**适用条件（拉格朗日松弛）**：
- 约束可以清晰分成"易"和"难"两组；
- 去掉难约束后，松弛问题**具有可分离结构**或对应经典多项式问题；
- 只需要**界**（用于评价启发式解的质量）或界 + 修复可行性；
- 问题规模大（$n\ge10^3$）但结构规整。

**适用规模**：CG 主问题变量 $10^{5}\sim10^{12}$（隐式）；LR 原问题变量 $10^{3}\sim10^{5}$；迭代 $10^{1}\sim10^{3}$ 次。

## 9. 不适用情况

- **小规模问题（变量 $<10^4$）**：直接把模型全写出来交给求解器，秒级解完。用 CG/LR 是**过度设计**，浪费宝贵的比赛时间。
- **问题不具可分结构**：LR 去掉难约束后子问题仍是 NP-hard，则毫无收益。
- **需要精确的整数最优解且比赛时间有限**：branch-and-price 实现成本太高。
- **变量数不多但约束极多**：应对偶地考虑"行生成"（cutting plane）而不是列生成。
- **目标是"能跑出来就行"的国赛题**：直接用 LINGO / intlinprog / 启发式更稳妥、更省时。
- **非线性结构**：CG/LR 建立在**线性对偶**之上，非线性问题需要专门的分解方法（如 Benders 分解的扩展）。
- **数据本身带噪声/不确定**：应先做鲁棒化处理，否则精确分解无意义。

## 10. Python / MATLAB 实现要点

**Python**
- RMP 用 LP 求解器直接解：`scipy.optimize.linprog`（`method='highs'`，`res.eqlin.marginals` 取对偶价）或 `gurobipy`（`model.getAttr('Pi', constrs)`）。
- 定价子问题按结构选工具：最短路用 `networkx.bellman_ford_path`（支持负权）；背包用 numpy DP；小规模直接暴力枚举。
- **列管理**：用 `dict` 以列的签名（如排序后的 0-1 向量元组）为键去重，否则 RMP 会因重复列退化。
- LR：子问题若可分离，用 numpy 向量化一次算完所有变量；次梯度实现注意 `lambda = np.maximum(0, lam + theta*g)`——**乘子必须投影到非负**。
- 记录"历史最好下界"与"历史最好上界"，最后画双曲线图。
- 环境：`pulp` 适合快速搭 RMP，`gurobipy` 有内置的列生成接口（`Model.addVar` 动态加列 + `model.optimize`）。

**MATLAB**
- `linprog` 的多输出 `lambda.eqlin` / `lambda.ineqlin` 提供对偶价，可驱动定价子问题。
- 最短路子问题用 `shortestpath(G, s, t)`（不支持负权）→ 需改用手写 Bellman-Ford 或标签设定法。
- 背包子问题用向量化 DP：`for i=1:n, for w=W:-1:a(i), f(w)=max(f(w), f(w-a(i))+pi(i)); end, end`。
- 矩阵改为 cell 数组或稀疏矩阵动态扩容；**频繁 `A=[A; newcol]` 会极慢**，建议预分配或每次重建。
- MATLAB 没有现成的 branch-and-price，整数化阶段可导出列池到 `intlinprog`。
- 老国赛代码完全未见 CG/LR 实现，**若要使用需自行从零实现**。

### 推荐句式（可直接套用，仅在你真的实现了时使用）

> 由于（方案/路径/模式）的总数达 $\cdot$ 量级，无法显式枚举，本文采用列生成法求解。主问题为集合覆盖形式，初始列由贪心策略生成；每次迭代求解线性松弛获得对偶价格 $\pi$，并以（最短路 / 背包 DP）求解定价子问题 $\min(c_k-\pi^\top a_k)$。迭代 $\cdot$ 轮后检验数全部非负，得到线性松弛下界 $\cdot$；再对已生成列求解整数主问题，得到可行解 $\cdot$，最优性间隙 $\cdot\%$。
