## 1. 算法解决什么问题

**大规模组合优化与连续非凸优化的全局搜索**。模拟退火（SA）把优化问题类比为固体的退火过程：在高温时允许**以一定概率接受更差的解**（依 Metropolis 准则），使搜索能跳出局部最优；随着温度下降，接受差解的概率降低，最终收敛到一个高质量解。

国赛里的三类落点〔归纳〕：
1. **整数/0-1 规划的大规模近似求解**（交巡警平台选址、铺设方案）——SA 比 GA 更好写；
2. **TSP 及排列类问题**（碎纸片拼接复原、路径规划）——用"交换两点/逆序片段"作邻域扰动；
3. **给别的模型做参数精修**（先用贪心/LP 得到可行解，再用 SA 在其邻域内改进）——**这是国赛最有效的用法**（见 2000B、2023C235）。

## 2. 输入与输出

**输入**
- 目标函数 $E(x)$（"能量"，即要最小化的目标；最大化则取负）；
- **解的表示与邻域扰动方式**（如"随机交换两个位置"、"随机改变一个整数变量 ±1"）——**这是设计核心**；
- 初始温度 $T_0$、终止温度 $T_f$（或最小温度阈值）、降温系数 $\alpha$、每个温度下的 Markov 链长度 $L$；
- 初始解 $x_0$（**强烈建议用贪心/LP 松弛构造，而不是纯随机**）；
- 约束处理（罚函数或邻域内保证可行性）。

**输出**
- **历史最优解 $x^*$**（注意：不是最后那个解！SA 结束时当前解可能比历史最优差）；
- 最优能量 $E^*$、温度-能量曲线、接受率曲线；
- 多次独立运行的统计量。

## 3. 算法步骤（伪代码级）

1. **构造初始解**：$x\leftarrow x_0$（贪心/启发式生成），计算能量 $E\leftarrow E(x)$。
2. **初始化参数**：$T\leftarrow T_0$，$x^*\leftarrow x$，$E^*\leftarrow E$，记录历史。
3. **循环** 当 $T>T_f$（或达到迭代上限）：
   1. **内循环** 重复 $L$ 次（Markov 链长，每个温度下的抽样次数）：
      1. **扰动**：在当前解的邻域内随机生成候选 $x'=N(x)$（如交换两个位置、某个变量加随机增量）。
      2. **计算能量差**：$\Delta E=E(x')-E(x)$。
      3. **Metropolis 接受准则**：
         - 若 $\Delta E\le0$：**接受**，$x\leftarrow x'$，$E\leftarrow E'$；
         - 若 $\Delta E>0$：以概率 $P=\exp(-\Delta E/T)$ 接受（即取随机数 $u\sim U(0,1)$，若 $u<P$ 则接受）。
      4. **更新历史最优**：若 $E<E^*$，则 $x^*\leftarrow x$，$E^*\leftarrow E$。（**这一步在内循环里面，不能省**）
   2. **降温**：$T\leftarrow\alpha T$（$\alpha\in(0.8,0.999)$），或 $T\leftarrow T_0/\ln(1+k)$ 等对数降温。
   3. **自适应（可选）**：若当前温度的接受率 $>0.9$（太热，浪费）或 $<0.1$（太冷，卡住），则调整 $\alpha$ 或重设 $T$。
4. **终止**：返回历史最优 $x^*$、$E^*$ 与温度-能量曲线。
5. **稳健性检验**：$K=10\sim30$ 次独立运行，报告最优值的均值、标准差与最好值。

## 4. 复杂度与收敛性

| 指标 | 量级 |
|---|---|
| 时间复杂度 | $O\big(L\cdot\log_\alpha(T_f/T_0)\cdot c_{\text{neighbor}}\big)$，其中 $c_{\text{neighbor}}$ 是计算一次邻域解代价的代价 |
| 迭代总次数 | $L\times\#\text{温度层数}$。例：$T_0=10^5,T_f=10^{-4},\alpha=0.995$ → $\ln(10^9)/\ln(1/0.995)\approx4140$ 层；$L=100$ → 41.4 万次评价 |
| 空间复杂度 | $O(\text{解的长度})$，只存当前解与最优解 |
| 收敛性 | 理论上（无限慢降温 + 无限长 Markov 链）**以概率 1 收敛到全局最优**（Hajek 定理要求对数降温 $T_k\ge c/\ln k$） |
| 实践收敛 | **指数降温 + 有限链长只能保证收敛到局部最优或高质量近似解** |

**必须写进论文的结论**：
1. **SA 的全局收敛性只在"对数降温 + 无限长 Markov 链"下成立**，而工程上用的是指数降温，因此**实际只能保证收敛到近似最优**，不能写"求得全局最优"。
2. 降温越慢、链越长，解越好但时间越久——这是 SA 唯一的核心权衡。
3. **接受率**是诊断 SA 是否在正确温度区间的关键指标：理想状态是在 $T_0$ 时接受率约 0.8～0.95，在 $T_f$ 时接近 0。
4. **SA 与 GA 的本质区别**：SA 是**单点**搜索 + 概率跳出，内存开销极小；GA 是**种群**搜索 + 交叉。SA 更省内存、代码更短；GA 更容易并行。

## 5. 参数与调参要点

| 参数 | 推荐取值区间 | 依据 |
|---|---|---|
| 初始温度 $T_0$ | **按接受率标定**：调整 $T_0$ 使初始接受率落在 0.8～0.95；粗略公式 $T_0\approx-\dfrac{\overline{\Delta E^+}}{\ln p_0}$，$p_0=0.9$ | 〔推理〕通用经验；也有"取初始解能量标准差"的取法 |
| **国赛原文参数**（可直接引用） | 〔原文〕`2011B：交巡警服务平台的设置与调度（1）`："用模拟退火法求解模型时，设置**初始温度 $T_0$ 为 100000**，**终止温度（$10^{-4}$）**，**温度衰减系数为 0.995**，**Markov 链长度为 100**，求得一个较优解的目标值为 1.013" | 〔原文〕`2011B（1）`——**国赛语料中最完整的一组 SA 参数，可直接照抄** |
| 终止温度 $T_f$ | $10^{-4}\sim10^{-6}$；或"连续 $k$ 个温度层最优解不变"即停 | 〔推理〕通用经验 |
| 降温系数 $\alpha$ | 0.8～0.99（$alpha$ 越大越慢越好）；工程常用 0.9～0.995 | 〔推理〕通用经验 |
| Markov 链长 $L$ | 问题规模的 $1\sim10$ 倍；$L\in[50,1000]$ | 〔推理〕通用经验 |
| 邻域扰动幅度 | 初期大步长（全局探索）、后期小步长（局部精修）；可实现为"扰动强度随 $T$ 线性递减" | 〔推理〕通用经验；〔原文〕2008A 亦提到"**扰动最大最小范围 $L_{\max},L_{\min}$**" |
| 初始解 | **用贪心或 LP 松弛构造**，不要纯随机；〔原文〕2000B："以**所得可行解为初始点**，采用模拟退火算法，求得最后的近似最优解" | 〔原文〕`2000B：管道订购和运输` |
| 接受率监控 | $T_0$ 时 0.8～0.95；终止时 <0.05 | 〔推理〕通用经验 |
| 独立运行次数 | 10～30 次 | 〔推理〕通用经验 |
| 约束处理 | 罚函数（$E'=E+M\cdot\text{violation}$）或**邻域内保证可行**（推荐后者：扰动只在可行域内进行） | 〔推理〕通用经验 |
| 参数调整以缩短时间 | 〔原文〕2023C235："该模拟退火模型较传统的模拟退火模型**调整了相关参数**，采用较（快的降温/较小的链长，以）算法的运行时长" | 〔原文〕`2023年展示论文_C235.pdf.txt` |

**调参坑**：
- **$T_0$ 太高 / 降温太慢** → 时间全花在随机游走上；〔原文〕2015A 自述"由于要求**较高的初始温度、较慢的降温速率、较低的终止温度，以及各温度下足够多次的抽样，因此优化过程较长**"。
- **$T_0$ 太低 / 降温太快** → 退化为贪心的局部搜索，跳不出局部最优。
- **忘记记录历史最优** → 返回最后一步的解，通常比历史最优差。
- **$\Delta E$ 量纲很大（如成本 $10^6$ 元）时直接用 $\exp(-\Delta E/T)$** → 下溢为 0，接受率恒为 0；应把 $E$ **归一化**（除以初始能量的量级）。

## 6. 优点

1. **能跳出局部最优**：Metropolis 准则让它有机会接受差解，这是它相对爬山法的根本优势。
2. **实现极短（30 行左右）**，且**参数只有 4 个**（$T_0,T_f,\alpha,L$），比 GA 少一半。
3. **内存开销极小**：只保存当前解与最优解，$O(\text{解长})$，可处理很大的解空间。
4. **对目标函数无任何要求**：不要求连续、可导、凸，甚至可以是黑箱仿真。
5. **易于与约束结合**：只要"扰动后能判断可行性"即可；邻域内保证可行是最省事的约束处理方式。
6. **适合做"精修"**：先用贪心/LP 得到一个还不错可行解，再用 SA 在其邻域内改进——**这是国赛最实用、最容易出好结果的组合**〔归纳：2000B、2023C235〕。
7. **与 GA 混合效果好**：〔原文〕2014A 的"自适应模拟退火遗传算法（ASAGA）"就是国赛里的成功范例。
8. **国赛接受度高**："模拟退火"在语料中共命中 **154 处**。

## 7. 缺点

1. **参数敏感且需要标定**：$T_0$ 和 $\alpha$ 选错直接影响质量，且没有万能取法。
2. **收敛慢**：要保证质量需要"高温 + 慢降温 + 长链"，总评价次数常达 $10^5\sim10^6$。
3. **单点搜索**：一次只有一个解在走，无法利用种群信息，也无法天然并行（只能靠多起点并行）。
4. **不保证最优**，也无法判断是否已到最优；必须多次运行看稳定性。
5. **对邻域结构的设计极度依赖**：邻域设计不好（扰动太大/太小）算法要么乱跳要么卡死。
6. **结果解读麻烦**：需要解释"温度-能量曲线"和"接受率"，如果曲线不好看反而暴露调参问题。
7. **对离散可行域有陷阱**：若邻域扰动常产生不可行解，接受率会被不可行性主导而非被目标主导。
8. **早期没有"种群多样性"概念**，容易在高温期浪费大量函数评价。

## 8. 适用规模与适用条件

**适用条件**：
- 目标函数**非凸、多局部极值**，或**离散/组合**；
- **解的邻域结构可以明确定义**（这是 SA 能否用的判定条件）；
- 单次能量评价**便宜**（$\lesssim10$ ms）——因为总评价次数在 $10^4\sim10^6$ 量级；
- 可以接受"近似最优"，不需要最优性证明；
- 内存受限（SA 比 GA 省内存）。

**适用规模**：决策变量 $10\sim10^5$；温度层数 $10^2\sim10^4$；链长 $50\sim1000$；总评价次数 $10^4\sim10^6$。

## 9. 不适用情况

- **小规模精确可解问题**（0-1 变量 $\lesssim300$ 的整数规划）：分支定界能给**精确最优 + 证明**，用 SA 是自降档次。
- **目标可微且光滑**：梯度法/拟牛顿法快几个数量级且更准。
- **单次评价极贵（$>1$ 秒）**：SA 需要 $10^5$ 次评价，根本跑不完。应先降到"贪心 + 小邻域局部搜索"。
- **邻域无法定义**（如目标依赖连续高维参数且无自然邻域）：改 PSO/DE 或梯度法。
- **需要严格满足硬约束且扰动极易越界**：会产生大量不可行候选，效率崩溃。此时应把扰动设计成**结构上保可行**的算子。
- **问题规模极小（变量 $\lesssim10$）**：枚举即可。
- **需要最优性界**：SA 给不出上界/下界。需配 LR/CG。
- **评委明确不认可的场景**：〔原文〕2003B 评述"也有一些队采用遗传算法、**模拟退火法**、层次分析法，等等。由于解题速度和结果相差都较大，**这方面没有太理想的答卷**"——当题目已有精确解法（如该题的整数规划 + LP）时，硬上 SA 会被扣分。

## 10. Python / MATLAB 实现要点

**Python**
- 没有标准库，自己写约 30 行即可；或用 `scikit-opt` 的 `SA`、`simanneal` 包。
- 核心循环骨架：`while T > Tf:` → `for _ in range(L):` → `x_new = neighbor(x)` → `dE = E(x_new)-E(x)` → `if dE<=0 or np.random.rand() < np.exp(-dE/T): x = x_new`。
- **`np.exp(-dE/T)` 必须防止下溢**：当 `-dE/T < -700` 时直接判为拒绝；或改为对数比较 `np.log(u) < -dE/T`。
- **能量归一化**：把 $E$ 除以初始能量的量级，让 $T_0$ 的取值有通用性（$T_0=1$ 量级即可）。
- 邻域函数用局部拷贝：`x_new = x.copy(); i,j = np.random.choice(n,2,replace=False); x_new[i],x_new[j]=x_new[j],x_new[i]`。
- **必须保存 `best_x`、`best_E`**，并用 `history.append((T, E, best_E))` 记录曲线。
- 降温用 `T *= alpha`，并加 `if stall_counter >= k: break` 提前终止。
- 多起点并行：`multiprocessing.Pool` 跑 30 个种子——SA 天然适合多起点并行。

**MATLAB**
- 官方：`simulannealbnd(@fun, x0, lb, ub, options)`；`options = saoptimset('InitialTemperature',1e5,'TemperatureFcn',@temperatureexp,'ReannealInterval',100,'MaxIter',1e5,'Display','iter')`。
- 自定义邻域：`options.AnnealingFcn = @myNeighbor`；自定义接受函数：`options.AcceptanceFcn`。
- 画图：`options.PlotFcns = {@saplotbestf, @saplottemperature, @saplotf}`——**三张图可直接进论文**。
- 手写版常见于老国赛代码〔原文〕：`2011B 交巡警（3）_论文程序_附件` 中即有 `%%退火算法第二次规划`、`function [jiegq fanan Sum]`（`1.2 模拟退火算法在第一问中的求解二次规划问题`）等函数，可作实现参考。
- 参数写法照抄国赛惯例：`T0=100000; Tf=0.0001; alpha=0.995; L=100;`。
