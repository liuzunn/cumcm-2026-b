## 1. 算法解决什么问题

**连续实数空间的全局优化**，尤其是**目标函数不可导、维数中等（$D=5\sim100$）、需要高精度解**的场景。差分进化（DE）与 GA 同属进化算法，但**不用二进制编码、不用交叉概率决定交叉位**，而是用**种群中两个随机个体之差**作为扰动方向：
$$v=x_{r_1}+F\cdot(x_{r_2}-x_{r_3})$$
这个"差分向量"会自动适应种群的分布尺度——**搜索初期种群分散，差分大（全局探索）；后期种群聚集，差分小（局部精修）**。这是 DE 相对 GA 最优雅的地方，也是它在连续优化竞赛（CEC benchmark）上长期占优的原因。

国赛里的落点〔归纳〕：**连续非线性规划 / 参数反演 / 曲线拟合**——凡是 PSO 能用的地方 DE 都能用，且在高维、高精度场景下通常更稳。

## 2. 输入与输出

**输入**
- 目标函数 $f(x)$；
- 变量维数 $D$、各维取值范围 $[x_j^{\min},x_j^{\max}]$；
- 种群规模 $NP$、缩放因子 $F$、交叉概率 $CR$、最大代数 $G$；
- 变异策略（`DE/rand/1`、`DE/best/1`、`DE/current-to-best/1` 等）与交叉方式（二项式 / 指数）；
- 约束处理（罚函数 / 边界反射 / 可行性规则）。

**输出**
- 最优个体 $x^*$ 与目标值 $f(x^*)$；
- 收敛曲线；
- 多种子独立运行的统计量。

## 3. 算法步骤（伪代码级）

以经典 **DE/rand/1/bin** 为例：

1. **初始化**：在 $[x^{\min},x^{\max}]$ 内均匀随机生成 $NP$ 个个体 $x_i$（$i=1\dots NP$）；评价适应度 $f(x_i)$。$g\leftarrow0$。
2. **循环** 对 $g=1\dots G$：
   1. **对每个目标个体 $i=1\dots NP$**：
      1. **变异（Mutation）**：随机选三个互不相同且不等于 $i$ 的下标 $r_1,r_2,r_3$；
         $$v_i=x_{r_1}+F\cdot(x_{r_2}-x_{r_3})$$
      2. **边界处理**：对越界分量，用"反射"（$v_j\leftarrow 2x_j^{\min}-v_j$）或"重初始化"或"截断到边界"。
      3. **交叉（Crossover，二项式）**：生成 $j_{\text{rand}}\sim U\{1,\dots,D\}$；
         $$u_{ij}=\begin{cases}v_{ij},& \text{若 } \text{rand}_j\le CR \text{ 或 } j=j_{\text{rand}}\\ x_{ij},& \text{否则}\end{cases}$$
         （**强制至少一位来自变异向量**，这是防止试验向量等于原个体的关键）
      4. **选择（Selection，贪婪）**：评价 $f(u_i)$；
         $$x_i\leftarrow\begin{cases}u_i,& f(u_i)\le f(x_i)\\ x_i,& \text{否则}\end{cases}$$
   2. 记录本代最优与平均适应度。
   3. **（可选）自适应**：若连续若干代无改进，则调整 $F$ 或 $CR$（jDE 策略：$F,CR$ 逐个体自适应）。
3. **终止**：返回历史最优个体与目标值。
4. **稳健性检验**：多种子运行，报告统计量。

### 常用变异策略（论文中要写明用的是哪一种）

| 策略 | 公式 | 特点 |
|---|---|---|
| `DE/rand/1` | $x_{r_1}+F(x_{r_2}-x_{r_3})$ | 探索强、收敛慢，**默认首选** |
| `DE/best/1` | $x_{\text{best}}+F(x_{r_1}-x_{r_2})$ | 收敛快、易早熟 |
| `DE/current-to-best/1` | $x_i+F(x_{\text{best}}-x_i)+F(x_{r_1}-x_{r_2})$ | 平衡，JADE 的基础 |
| `DE/rand/2` | $x_{r_1}+F(x_{r_2}-x_{r_3})+F(x_{r_4}-x_{r_5})$ | 探索最强，需 $NP\ge11$ |
| `DE/best/2` | $x_{\text{best}}+F(x_{r_1}-x_{r_2})+F(x_{r_3}-x_{r_4})$ | 收敛最快、易早熟 |

## 4. 复杂度与收敛性

| 指标 | 量级 |
|---|---|
| 时间复杂度 | $O(G\cdot NP\cdot(D+c_f))$，$c_f$ 为单次目标评价代价 |
| 空间复杂度 | $O(NP\cdot D)$（种群 + 变异向量 + 试验向量） |
| 单代操作 | 变异 $O(NPD)$、交叉 $O(NPD)$、选择 $O(NP\cdot c_f)$ |
| 收敛性 | **无全局最优保证**；对连续可微函数，DE 的种群会以一定速率收敛到局部最优 |
| 收敛速度 | 比 GA 慢一些（$\beta$ 型收敛），但**解的精度更高、更稳** |

**必须写进论文的结论**：
1. **DE 不保证全局最优**；论文写"近似最优解"。
2. **DE 的核心优势在"精度"而非"速度"**：在 CEC 连续优化基准上，DE 家族长期优于 GA 与 PSO，尤其在高维、多峰、带噪声场景〔推理：属优化领域公认结论，语料未涉及〕。
3. **DE 的种群必须足够大**：$NP\ge4D$ 是经验下限（保证变异所需的 $r_1,r_2,r_3$ 有足够选择空间）；$NP<4$ 时算法退化。
4. **DE 的贪婪选择（一对一的"父子竞争"）保证了种群平均适应度单调不增**，这是它数值稳定、不易退化的原因，也是它区别于 GA 的重要特征。
5. **约束处理是 DE 的弱点**：DE 没有"修复算子"的传统，通常靠罚函数或可行性规则（Deb 规则：可行解优于不可行解；都可行时比目标；都不可行时比违反度）。

## 5. 参数与调参要点

| 参数 | 推荐取值区间 | 依据 |
|---|---|---|
| 种群规模 $NP$ | **$4D\sim10D$**（$D$ 为维数）；经验下限 $NP\ge4D$ 且 $\ge10$ | 〔推理〕通用经验 |
| 缩放因子 $F$ | 0.4～1.0（常用 0.5～0.8）；$F$ 大→探索强，$F$ 小→收敛快 | 〔推理〕通用经验 |
| 交叉概率 $CR$ | 0.1～1.0；**可分离问题取 0.9～1.0**（逐维独立），**不可分离问题取 0.1～0.5** | 〔推理〕通用经验 |
| 最大代数 $G$ | 200～2000；或"最优值停滞 50 代"即停 | 〔推理〕通用经验 |
| 变异策略 | 默认 `DE/rand/1`；追求精度用 `DE/current-to-best/1`；追求收敛速度用 `DE/best/1` | 〔推理〕通用经验 |
| 交叉方式 | `bin`（二项式）默认；`exp`（指数）适合可分离问题 | 〔推理〕通用经验 |
| 自适应参数（推荐） | jDE：每个个体带自己的 $F_i,CR_i$，$F_i$ 以概率 0.1 重置为 $0.1+0.9u_1$，$CR_i$ 以概率 0.1 重置为 $u_2$ | 〔推理〕通用经验 |
| 边界处理 | **反射**优于截断（截断会造成大量个体堆在边界上）；也常用"重初始化到 $[x^{\min},x^{\max}]$ 内均匀随机" | 〔推理〕通用经验 |
| 约束处理 | Deb 可行性规则（锦标赛选择时：可行优先、都不可行比违反度） | 〔推理〕通用经验 |
| 多起点运行 | 10～30 次独立运行 | 〔推理〕通用经验 |
| 停止判据 | 目标值停滞代数 $\ge50$，或目标值相对改进 $<10^{-8}$ | 〔推理〕通用经验 |

**调参坑**：
- **$NP<4D$** → 变异所需的三个互异个体选择受限，种群多样性不足，早熟。
- **$CR$ 与问题可分离性不匹配** → 可分离问题用低 $CR$ 会收敛极慢；不可分离问题用高 $CR$ 会破坏变量的相关性。**这是 DE 调参最核心的一条**。
- **$F>1$** → 变异过大，算法退化为随机搜索。
- **$F$ 固定为很小（如 0.1）** → 后期步长太小，早熟停滞。
- **边界用截断** → 大量个体聚集在边界，搜索能力骤降。
- **忘记"强制至少一位交叉"** → 试验向量可能等于原个体，该个体永远不会更新。

## 6. 优点

1. **参数极少（3 个：$NP,F,CR$）**，且推荐区间宽，鲁棒性好——比 GA 的算子设计省心得多。
2. **不需要编码/解码**：直接在连续空间操作，比 GA 的实数编码 + 算术交叉简单。
3. **差分向量的自动尺度自适应**：这是 DE 最优雅的机制，搜索尺度天然跟随种群分散程度。
4. **精度高**：对连续优化问题，DE 通常能达到比 GA/PSO 更高的最终精度。
5. **贪婪选择保证种群不退化**：平均适应度单调改善，数值行为稳定。
6. **实现极短**（约 40 行），且与 numpy 向量化配合极好——一次迭代可用矩阵运算完成全部个体。
7. **与其他方法混合容易**：DE + 局部搜索（Memetic DE）、DE + 代理模型都有成熟套路。

## 7. 缺点

1. **不适合离散/组合问题**：虽然有二值 DE、排列 DE，但远不如 GA/SA 自然。
2. **收敛速度中等**：比 GA 和 PSO 慢一些。
3. **高维时性能退化**：$D>100$ 时需要 $NP\ge400$，计算量爆炸。
4. **约束处理能力弱**：没有专门的修复机制，硬约束问题需要大量定制。
5. **参数虽少但仍需调**：$CR$ 对"可分离性"敏感，调错会显著变慢。
6. **无全局最优保证**，且和所有元启发式一样面临早熟风险。
7. **国赛使用极少**：全语料中"差分进化"仅 **1 处命中**（见第 11 节），说明**评委对它不熟悉**——用它时必须把原理讲清楚，否则可能被当成"没做功课"。

## 8. 适用规模与适用条件

**适用条件**：
- 决策变量是**连续实数**；
- 变量维数 $D=2\sim100$（最甜区间 5～50）；
- 目标函数**不可导或黑箱**，单次评价便宜（$\lesssim10$ ms）；
- 可行域是**简单的箱式约束** $[x^{\min},x^{\max}]$（DE 对箱式约束处理最自然）；
- 追求**高精度**解而非快速得到一个粗糙解。

**适用规模**：$D=2\sim100$；$NP=4D\sim10D$（20～500）；$G=200\sim2000$；总评价次数 $10^4\sim10^6$。

## 9. 不适用情况

- **离散/组合优化**（TSP、排班、0-1 规划）：用 GA/SA/分支定界。
- **变量维数极低（$D\le2$）**：解析法或黄金分割/牛顿法更快更准。
- **单次评价极贵（$>1$ 秒）**：$10^4$ 次评价跑不完；改用代理模型或降低 $NP,G$。
- **复杂约束（非线性等式约束、网络耦合约束）**：DE 的罚函数法难以稳定收敛，应改用 NLP 求解器（SLSQP / IPOPT）或约束优化专用算法。
- **需要精确最优**：用分支定界或凸优化（若问题是凸的，直接求解比 DE 好）。
- **目标是低精度快速解**：PSO 收敛更快，或贪心 + 局部搜索更省时间。
- **变量的可行域非箱式且难以判定可行性**：DE 的边界处理机制失效。

## 10. Python / MATLAB 实现要点

**Python**
- 库：`scipy.optimize.differential_evolution(func, bounds, strategy='best1bin', maxiter=1000, popsize=15, tol=1e-8, mutation=(0.5,1), recombination=0.7, polish=True, seed=0)`。
  - **注意 `popsize` 是"每维的倍数"**：实际种群大小 $= \text{popsize}\times D$。所以 `popsize=15, D=5` → 只有 75 个个体，而 `popsize=15, D=50` → 750 个个体。**这是最容易搞错的参数含义**。
  - **务必设 `polish=True`**：DE 收敛后用 L-BFGS-B 做一次局部精修，精度能提升好几个数量级——这是 `scipy` 版 DE 最实用的开关。
  - `mutation=(0.5,1)` 表示 $F$ 在区间内随机（抖动），比固定 $F$ 更稳健。
  - 设 `seed` 保证可复现；`workers=-1` 可并行评价。
- 手写版：用 numpy 广播，一次算完整个种群：
  - `idx = np.argsort(np.random.rand(NP,3), axis=1)` 得到互异三元组（免循环）；
  - `V = X[r1] + F*(X[r2]-X[r3])`；
  - `mask = np.random.rand(NP,D) < CR`；`jrand = np.random.randint(D, size=NP)`；`mask[np.arange(NP), jrand] = True`；
  - `U = np.where(mask, V, X)`；
  - 边界反射：`U = np.where(U<lb, 2*lb-U, U)`，上界同理（多反射几次或直接 clip 兜底）。
  - 选择：`better = f(U) <= f(X)`；`X[better] = U[better]`。
- **DE 的向量化程度极高**，60 行代码能跑到每秒上万次评价。

**MATLAB**
- 无官方 `differentialevolution` 函数；`ga` 可模拟但不是 DE。需自行实现（30～50 行）或从 File Exchange 取。
- 向量化写法与 Python 类似，用 `randperm` 生成三元组、`bsxfun`/隐式扩展做广播。
- 与 `fmincon` 混合（Memetic DE）：DE 跑完后用 DE 的解作 `fmincon` 初值做局部精修——**这是最推荐的国赛用法**。
- 画图：收敛曲线（最好值 + 平均值 + 标准差带）、参数 $F$/$CR$ 对最终精度的热力图。
- 由于国赛 MATLAB 代码中几无 DE 先例，**若要用，必须在论文中完整写出算法流程**，不能只写"采用差分进化算法求解"。
