## 1. 算法解决什么问题

**连续（或可编码为连续）非线性优化问题的全局搜索**，尤其是**目标函数不可导、计算一次很贵、但可行域是多维连续空间**的场景。粒子群优化（PSO）模拟鸟群觅食：每个"粒子"是一个解，有位置 $x$ 和速度 $v$，它同时向**自己的历史最好位置 $pbest$** 和**群体的历史最好位置 $gbest$** 学习。

国赛里的三类落点〔归纳〕：
1. **优化模型的求解器**——写好目标函数与约束后，直接扔给 PSO 搜（比网格遍历快得多）；
2. **替代网格遍历**——参数维数 $\ge3$ 时网格法指数爆炸，PSO 是标准替代方案；
3. **参数反演/拟合**——最小二乘目标不可微或地形复杂时用 PSO 替代 LM。

**重要的适用性说明**：〔原文〕`2009A` 明确指出"**由于粒子群算法有较快的收敛性和运算速度，在可行域为凸集的场合下较适用**，同时为了克服其易收敛于局部最优解的缺点，本题使用了**加入变异机制的粒子群算法**"。这句话可作为"何时用 PSO"的国赛级依据。

## 2. 输入与输出

**输入**
- 目标函数 $f(x)$（最大化则取负）；
- **变量维数 $D$ 与各维取值范围 $[x_j^{\min},x_j^{\max}]$**（边界必须先给，否则粒子会飞出）；
- 种群规模 $N$、最大迭代次数 $T_{\max}$；
- 惯性权重 $w$（或线性递减区间）、学习因子 $c_1,c_2$、速度上限 $v_{\max}$；
- 约束处理方式（罚函数 / 边界截断 / 可行域投影）；
- （可选）变异概率 $p_m$（防早熟）。

**输出**
- **全局最好位置 $gbest$** 及其目标值 $f(gbest)$；
- 收敛曲线 $\{f(gbest^{(t)})\}$；
- 每代粒子的多样性指标（可选，用于论证"没有早熟"）；
- 多次独立运行的统计量。

## 3. 算法步骤（伪代码级）

1. **初始化**：
   1. 对每个粒子 $i=1\dots N$，在 $[x^{\min},x^{\max}]$ 内**均匀随机**生成位置 $x_i$（推荐用拉丁超立方或 Sobol 序列提高覆盖均匀度）；
   2. 速度 $v_i$ 在 $[-v_{\max},v_{\max}]$ 内随机生成，或置 0；
   3. 计算适应度 $f_i=f(x_i)$；$pbest_i\leftarrow x_i$，记录 $f(pbest_i)\leftarrow f_i$；
   4. $gbest\leftarrow\arg\min_i f(pbest_i)$，记录 $f(gbest)$。
2. **循环** 对 $t=1\dots T_{\max}$：
   1. **更新惯性权重**：$w_t=w_{\max}-(w_{\max}-w_{\min})\dfrac{t}{T_{\max}}$（线性递减）或自适应。
   2. **对每个粒子 $i$**：
      1. 生成随机数 $r_1,r_2\sim U(0,1)^D$（**逐维独立**，不要用一个标量）。
      2. **速度更新**：
         $$v_i\leftarrow w_t v_i+c_1 r_1\odot(pbest_i-x_i)+c_2 r_2\odot(gbest-x_i)$$
      3. **速度限幅**：$v_{ij}\leftarrow\mathrm{clip}(v_{ij},-v_{\max,j},v_{\max,j})$。
      4. **位置更新**：$x_i\leftarrow x_i+v_i$。
      5. **边界处理**：越界分量截断到边界（或反射），**并把该维速度置 0 或反向**——只截断位置不处理速度会让粒子"贴边抖动"。
      6. **约束处理**：若不可行，按罚函数计入适应度（$f'=f+M\cdot\text{violation}$）。
      7. **评价** $f_i=f(x_i)$；若 $f_i<f(pbest_i)$，则 $pbest_i\leftarrow x_i$。
      8. **若 $f_i<f(gbest)$**，则 $gbest\leftarrow x_i$。
   3. **（可选）变异**：以概率 $p_m$ 对部分粒子施加随机扰动或重新初始化，用于防早熟〔原文：2009A 即"加入变异机制的粒子群算法"〕。
   4. 记录 $f(gbest^{(t)})$。
3. **终止**：返回 $gbest$ 与 $f(gbest)$。
4. **稳健性检验**：$K=10\sim30$ 次独立运行，报告均值/标准差/最差值。

## 4. 复杂度与收敛性

| 指标 | 量级 |
|---|---|
| 时间复杂度 | $O(T_{\max}\cdot N\cdot(D+c_f))$，$c_f$ 为单次目标评价代价 |
| 空间复杂度 | $O(N\cdot D)$（位置 + 速度 + pbest） |
| 单代操作 | 速度更新 $O(ND)$、位置更新 $O(ND)$、评价 $O(Nc_f)$ |
| 收敛性 | **无全局最优保证**。Clerc 的收缩因子版本在特定参数下保证收敛到**一个稳定点**（可能是局部最优） |
| 收敛速度 | 早期极快（通常快于 GA），后期易停滞 |

**必须写进论文的结论**：
1. **PSO 不保证全局最优**，且**收敛快正是它的风险**——粒子很快聚到 $gbest$ 附近，多样性丧失即"早熟收敛"。
2. 参数选择的经典理论结果（Clerc & Kennedy）：取收缩因子 $\chi=\dfrac{2}{|2-\varphi-\sqrt{\varphi^2-4\varphi}|}$，$\varphi=c_1+c_2>4$（常取 $c_1=c_2=2.05$，$\varphi=4.1$，$\chi\approx0.729$）时**算法收敛且速度不发散**。等价地，取 $w=0.729,\ c_1=c_2=1.494$。
3. **标准 PSO 只在 $c_1,c_2,w$ 满足特定关系时收敛**；参数取歪会导致速度爆炸或粒子立即停滞。
4. **早期收敛速度极快既是优点也是陷阱**：〔原文〕2015A 用它替代网格法把时间"大大缩短"，且"两种算法的结果极为接近"——说明**在解空间较规整时 PSO 是可靠的加速手段**。

## 5. 参数与调参要点

| 参数 | 推荐取值区间 | 依据 |
|---|---|---|
| 种群规模 $N$ | 20～100（维数大时 $N\approx10+2\sqrt D$，国赛常取 30～50） | 〔推理〕通用经验 |
| 最大迭代 $T_{\max}$ | 100～1000；以"gbest 停滞 30 代"提前终止 | 〔推理〕通用经验 |
| 惯性权重 $w$ | **线性递减 $0.9\to0.4$**（最经典）；或固定 0.729（等价收缩因子版） | 〔推理〕通用经验 |
| 学习因子 $c_1,c_2$ | $c_1=c_2=2.0$（经典）；或 $c_1=c_2=1.49445$ 配 $w=0.729$（Clerc 收缩版） | 〔推理〕通用经验 |
| 速度上限 $v_{\max}$ | 每维取 $0.2\sim0.5\times(x_j^{\max}-x_j^{\min})$ | 〔推理〕通用经验；**不设 $v_{\max}$ 是 PSO 数值爆炸的头号原因** |
| 变异概率 $p_m$ | 0.05～0.2（仅当出现早熟时启用） | 〔推理〕通用经验；〔原文〕2009A 使用"加入变异机制的粒子群算法"以克服"易收敛于局部最优解"的缺点 |
| 终止判据 | $f(gbest)$ 停滞 $\ge30$ 代，或达到 $T_{\max}$ | 〔推理〕通用经验 |
| **国赛原文参数** | 〔原文〕`2023年展示论文_C228`："（采用 GBest PSO，）**调整惯性权重的值，平衡粒子的全局搜索和局部搜索能力；引入了约束因子来控制粒子**（速度）"；"经过**粒子群 7 轮 300 次迭代**得到 7.1 至 7.7 每日收益的最大值" | 〔原文〕`2023年展示论文_C228`（改进版全局 PSO，含惯性权重调整 + 约束因子 + 迭代规模） |
| 多起点运行 | 10～30 次独立运行 | 〔推理〕通用经验 |
| 约束处理 | 罚函数为主；边界用截断 + 速度置零 | 〔推理〕通用经验 |

**调参坑**：
- **不设 $v_{\max}$** → 速度指数增长，粒子飞出可行域，结果出现 inf/nan。
- **$w$ 固定为 1 或更大** → 速度不衰减，永不收敛。
- **变量量纲差异大而不归一化** → 某一维新占主导，其他维几乎不动。**务必先把所有变量缩放到 $[0,1]$ 或 $[-1,1]$ 再跑 PSO**，最后反缩放。
- **$gbest$ 保存的是粒子对象的引用而非副本** → 后续位置更新会"污染" $gbest$（Python 中必须调用 .copy()）。
- **$pbest$ 与 $gbest$ 更新顺序写反** → 不影响正确性但影响收敛，标准写法是先更新 $pbest$ 再更新 $gbest$。

## 6. 优点

1. **收敛速度快**：通常比 GA 少几倍的函数评价即可到好解；〔原文〕2015A 明确记录"两种算法的结果极为接近，但**粒子群算法计算时间要远小于网格逼近算法**"。
2. **实现极短**：核心只有速度/位置两行更新公式，比 GA 少编码/解码/交叉等一堆算子。
3. **参数少（3 个：$N,w,c_1/c_2$）**，且经典取值有理论支撑（Clerc 收缩因子）。
4. **不需要编码/解码**：直接在连续空间搜索，天然适合实数参数优化（GA 需实数编码 + 交叉算子设计）。
5. **内存小**：$O(ND)$。
6. **对目标函数无任何要求**：不可导、黑箱、带噪声都能用。
7. **有成熟库**：`pyswarm`、`pyswarms`、`scikit-opt`；MATLAB 有官方 `particleswarm`。
8. **在"凸可行域"上表现最好**：〔原文〕2009A 指出"在**可行域为凸集的场合下较适用**"——这是国赛语料里对 PSO 适用性最明确的判断。

## 7. 缺点

1. **早熟收敛是最主要问题**：$gbest$ 一旦吸引全部粒子，搜索即停止；这正是 2009A 要引入变异机制的原因〔原文〕。
2. **不保证最优**，且无法判断是否到达最优。
3. **对参数敏感**：$w,c_1,c_2,v_{\max}$ 取歪会导致爆炸或停滞，没有通用万能取值。
4. **处理约束能力弱**：罚函数需要调系数；硬约束（如 0-1 变量）需额外离散化处理（此时不如 GA/SA）。
5. **不适合离散/组合问题**：虽有二进制 PSO（BPSO），效果通常不如 GA 与 SA。
6. **结果受随机种子影响**：必须多次运行报告统计量。
7. **理论分析弱**：只有收敛到稳定点的结论，没有全局最优保证。
8. **维数灾难**：$D>100$ 时性能迅速退化。

## 8. 适用规模与适用条件

**适用条件**：
- 决策变量是**连续实数**（或可自然编码为实数、并能合理取整回来）；
- 可行域**连通、边界明确**（最好是凸集）〔原文依据：2009A〕；
- 目标函数**不可导、黑箱或计算昂贵**，但单次评价可接受（$\lesssim10$ ms，因为要评价 $10^3\sim10^5$ 次）；
- **参数维数 $D=2\sim50$**（最甜区间 3～20，正是国赛优化题的典型规模）；
- 可接受"高质量近似最优"。

**适用规模**：$D=2\sim50$；$N=20\sim100$；$T_{\max}=100\sim1000$；总评价次数 $10^3\sim10^5$。

## 9. 不适用情况

- **需要精确最优且规模可解**（线性/整数规划、$D\le2$ 的解析可解问题）：用 LP/分支定界/解析法，PSO 只会更慢更差。
- **离散组合优化（TSP、排班、大量 0-1 变量）**：GA/SA/蚁群更合适；BPSO 效果通常不佳。
- **单次评价极贵（$>1$ 秒）**：$10^4$ 次评价需数小时，比赛跑不完；应先做代理模型或减少 $N,T_{\max}$。
- **目标函数多峰且峰值极窄**："针尖状"最优区域 PSO 很难命中；应结合局部精修（Memetic：PSO + 拟牛顿）。
- **需要严格满足硬约束**：罚函数法常给出不可行解；应改用带约束处理机制的变体或换方法。
- **维数极高（$D>100$）**：收敛极慢，应考虑分解、代理模型或梯度法。
- **目标函数不连续/阶梯**：速度更新会产生"跨台阶"的无效扰动，效率低。
- **需要最优性界**：PSO 给不出。

## 10. Python / MATLAB 实现要点

**Python**
- 库：`pyswarm.pso(func, lb, ub, swarmsize=50, maxiter=200)`（参数含义与标准 PSO 略有差异，注意换算）；`pyswarms` 更灵活；`scikit-opt` 的 `PSO` 类最贴近标准公式。
- 手写版约 40 行：`for t in range(T):` → `w = w_max - (w_max-w_min)*t/T` → `r1=np.random.rand(N,D); r2=np.random.rand(N,D)` → `V = w*V + c1*r1*(Pbest-X) + c2*r2*(Gbest-X)` → `V=np.clip(V,-Vmax,Vmax)` → `X=np.clip(X+V,lb,ub)`。
- **`r1, r2` 必须逐维独立**（`np.random.rand(N,D)`），不能用 `np.random.rand(N,1)` 广播到全维——后者会让所有维同步，严重削弱搜索能力。
- **归一化**：先把变量线性映射到 $[0,1]$，PSO 跑完再反缩放，这是解决量纲问题的通用做法。
- 防早熟：每次迭代以 5% 概率对随机 10% 的粒子重置位置。
- 保存全局最优时用 `Gbest = X[best_idx].copy()`，避免引用污染。
- 记录 `history.append(f(Gbest))`，配合 `matplotlib` 画收敛曲线。

**MATLAB**
- 官方 `particleswarm`（Global Optimization Toolbox，R2015a+）：`particleswarm(@fun, nvars, lb, ub, options)`；`options = optimoptions('particleswarm','SwarmSize',50,'MaxIterations',500,'HybridFcn',@fmincon)`。**`HybridFcn` 是亮点：PSO 全局搜索 + fmincon 局部精修**，强烈推荐用于国赛。
- 手写版在国赛老代码中很常见；核心是矩阵化的速度/位置更新，用广播（R2016b+ 支持隐式扩展）或 `repmat`。
- 画图：`options.PlotFcn = @pswplotbestf`。
- `optimoptions('particleswarm','UseVectorized',true)` 可并行评价整个种群（把目标函数写成接受 $N\times D$ 矩阵的形式），速度提升数倍。
