## 1. 算法解决什么问题

**离散/组合优化与无导数黑箱优化的全局搜索**。当你写不出梯度、解空间是"选或不选""排列顺序""整数分配"，且规模大到无法枚举时使用。遗传算法（GA）模拟自然选择：用**编码**表示解，用**适应度**评价优劣，用**选择-交叉-变异**产生新一代种群。

国赛里 GA 的三类落点〔归纳〕：
1. **0-1 / 整数分配问题**（书号分配、任务分配、选址）——直接用 0-1 编码或整数编码；
2. **排列优化（TSP 类）**（碎纸拼接、装配顺序、路径规划）——用排列编码 + 顺序交叉；
3. **给别的模型调参**（优化神经网络初始权值、优化模拟退火的初值）——把 GA 当外层优化器。

## 2. 输入与输出

**输入**
- **编码方案**：二进制 / 整数 / 实数 / 排列（**这是最关键的建模决策，比算法参数重要得多**）；
- **适应度函数** $f(\cdot)$：必须把"约束违反"折进去（罚函数或修复算子）；
- 种群规模 $N$、交叉概率 $p_c$、变异概率 $p_m$、最大代数 $G$；
- 选择算子（轮盘赌 / 锦标赛 / 随机遍历采样）、交叉算子（单点 / 均匀 / 顺序 OX / 部分匹配 PMX）、变异算子（位翻转 / 交换 / 逆序）；
- 终止条件（最大代数 / 适应度停滞代数 / 时间上限）。

**输出**
- **最好个体**及其解码后的决策方案；
- 最好适应度值 $f^*$、**进化曲线** $\{f_{\text{best}}^{(g)}, f_{\text{avg}}^{(g)}\}$；
- 多次独立运行的结果分布（**必须报告，否则结论不稳健**）。

**约束处理的三种写法**（论文里要说清选了哪种）：
- 罚函数法：$f'(x)=f(x)-M\cdot\max(0,g(x))$，$M$ 取目标量级的 $10^2\sim10^4$ 倍；
- 修复算子：把不可行个体投影到可行域（如"超量则按性价比从低到高删除"）；
- 惩罚 + 修复混合（推荐）。

## 3. 算法步骤（伪代码级）

1. **编码与解码**：确定基因型 → 表现型的映射。例如 0-1 编码时第 $i$ 位表示"是否选择第 $i$ 项"；整数编码时基因是分配数量。
2. **初始化种群**：随机生成 $N$ 个个体（**注意可行性**：可用贪心生成若干合法个体填充，提高初始质量）。$g\leftarrow0$。
3. **适应度评价**：对每个个体解码 → 计算目标值 → 处理约束 → 得到适应度 $f_i$。（目标为最小时取 $f_i=1/(1+\text{obj}_i)$ 或 $-\text{obj}_i$）
4. **循环** 当 $g<G$ 且未满足终止条件：
   1. **选择**：按适应度从当前种群中选出 $N$ 个父代。
      - 轮盘赌：$P_i=f_i/\sum_j f_j$（**要求 $f_i>0$，负适应度必须平移**）；
      - 锦标赛：随机取 $k$（通常 $k=2$）个，取最优——**更稳健，推荐**；
      - 随机遍历采样（`sus`）：抽样误差比轮盘赌小。
   2. **交叉**：以概率 $p_c$ 对每对父代执行交叉，产生两个子代（单点 / 多点 / 均匀 / 问题专用算子如 PMX、OX）。
   3. **变异**：以概率 $p_m$ 对每个基因位执行变异（0-1 翻转 / 实数加高斯扰动 / 排列交换两点）。
   4. **精英保留**：把上一代最好的 $e$ 个个体（$e=1\sim2$）**直接复制**到新种群——**不加精英，GA 的最好解会随代数波动甚至退化**。
   5. **重插入**：用子代替换父代（全替换 / 代沟 GGAP 部分替换）。代沟 $\text{GGAP}=0.9$ 表示保留最好的 90%、用子代替换最差的 10%。
   6. 评价新种群；更新历史最好解；$g\leftarrow g+1$。
5. **终止**：输出历史最好个体、其解码方案与适应度。
6. **稳健性检验**：用不同随机种子独立运行 $K=10\sim30$ 次，报告最优值的**均值、标准差、最差值和命中率**。

## 4. 复杂度与收敛性

| 指标 | 量级 |
|---|---|
| 时间复杂度 | $O(G\cdot N\cdot c_{\text{eval}})$，其中 $c_{\text{eval}}$ 是单个体评价代价（若目标可 $O(1)$ 计算则为 $O(GN)$） |
| 空间复杂度 | $O(N\cdot L)$，$L$ 为染色体长度 |
| 单代操作 | 选择 $O(N)$、交叉 $O(NL)$、变异 $O(NL)$ |
| 收敛性 | **无全局最优保证**；理论上（精英保留 + 有限状态马尔可夫链）**以概率 1 收敛到全局最优**，但所需代数可能是指数级的 |
| 收敛速度 | 早期指数增长（模式定理），后期停滞于局部最优 |

**必须写进论文的结论**（**这一节最容易写错，务必照抄下面的措辞**）：
1. **GA 是随机搜索算法，不保证找到全局最优解**。论文中**禁止**写"求得全局最优解"，应写"求得一个高质量可行解"或"求得近似最优解"。
2. 理论上精英 GA 以概率 1 收敛到全局最优（Rudolph 定理），但这是**无限时间**的结论，对比赛无实操意义。
3. **GA 对编码方式和适应度函数设计的敏感度，远高于对 $p_c$、$p_m$ 的敏感度**。把时间花在编码上。
4. **早熟收敛（premature convergence）是 GA 的头号问题**：种群多样性丧失，所有个体趋同。对策：加大变异率、引入小生境/共享、重启、多种群。
5. **没有"收敛"这个概念可以用来判定最优**：适应度曲线平了不代表找到了最优，只代表搜索停滞。因此**必须做多次独立运行**。

## 5. 参数与调参要点

| 参数 | 推荐取值区间 | 依据 |
|---|---|---|
| 种群规模 $N$ | 20～200；染色体长 $L$ 时取 $N\approx2L\sim10L$；国赛题目常取 30～100 | 〔推理〕通用经验 |
| 交叉概率 $p_c$ | 0.6～0.95（常用 0.8～0.9） | 〔推理〕通用经验 |
| 变异概率 $p_m$ | 0.001～0.1；**连续/实数编码取 $1/L\sim1/10$**，排列编码（交换变异）取 0.1～0.3 | 〔推理〕通用经验 |
| 最大代数 $G$ | 100～2000；以"适应度停滞 30～50 代"作为实际终止判据 | 〔推理〕通用经验 |
| **国赛原文参数**（可直接引用） | 〔原文〕`2011A：城市表层土壤重金属污染分析（1）`代码：**`NIND=40; %种群大小`**、**`GGAP=0.9; %代沟`**、**`Chrom=crtbp(NIND, LIND*NVAR); %初始种群，二进制编码`**、`reins(...) %重插入子代的新种群`；正文"**重插算子：设置代沟为 0.9，每次将适应度最高的 90% 保存下来，其余 10%（用子代替换）**" | 〔原文〕`2011A（1）`——这是国赛论文里**可直接抄用的完整参数组** |
| 精英个体数 $e$ | 1～2（占种群 1%～5%） | 〔推理〕通用经验；太多会加速早熟 |
| 选择算子 | 锦标赛（$k=2$）最稳健；轮盘赌需保证适应度非负 | 〔推理〕通用经验 |
| 罚系数 $M$ | 目标函数量级的 $10^2\sim10^4$ 倍；**过大导致可行域边缘全是"坏"个体、搜索失去梯度** | 〔推理〕通用经验 |
| 自适应参数 | 交叉/变异概率随适应度自适应（好个体小变异、差个体大变异），见 2014A 的自适应模拟退火遗传算法 ASAGA | 〔原文〕`2014A：嫦娥三号…(5)`（"利用如下方式进行交叉操作""设交叉概率为 $p_c$，交叉系数为 $r$，则利用如下公式进行自适应调整"） |
| 停止判据 | 最大代数 或 适应度停滞代数 $\ge30$ 或 时间上限 | 〔推理〕通用经验 |

**调参坑**：
- **适应度必须为正**才能用轮盘赌；负值或零会让概率无意义，需先做平移 $f_i\leftarrow f_i-\min_j f_j+\epsilon$。
- **约束惩罚给得太重** → 所有个体适应度都极差，选择压力消失（"谁都一样烂"），算法退化为随机搜索。应先做修复算子。
- **变异率设 0** → 只能靠交叉，容易早熟；**变异率设 1** → 退化为随机搜索。

## 6. 优点

1. **无导数、无梯度要求**：适应度函数可以是黑箱（调用一次仿真、跑一次排队模型），这是它相对牛顿/梯度法的根本优势。
2. **天然处理离散与组合问题**：0-1、整数、排列编码都很自然；不需要把整数变量松弛成连续。
3. **并行性好**：适应度评价可完全并行，种群级并行也容易。
4. **全局搜索能力强**：多点搜索 + 交叉算子使它能跳出局部最优，比单纯爬山法稳健得多。
5. **鲁棒、易于与其他方法混合**：与模拟退火混合（ASAGA）、与神经网络混合（GA-BP）、与局部搜索混合（Memetic）都是成熟套路，并且〔原文〕`2014A` 与 `2013A` 都有实例。
6. **单次运行即可给出"进化曲线"**，可视性极好，论文图好画。
7. **有成熟工具箱**：MATLAB 全局优化工具箱的 `ga`、Python 的 `DEAP`/`pymoo`/`scikit-opt`，几十行就能跑通。
8. **国赛接受度极高**：语料中"遗传算法"共命中 **244 处**，是出现频率最高的智能算法。

## 7. 缺点

1. **不保证最优，且无法判断是否已到最优**。适应度曲线平了只能说明停滞。
2. **参数多、敏感**：$N,p_c,p_m$、编码、选择/交叉/变异算子、罚系数，组合爆炸。不同参数的运行结果方差可能很大。
3. **早熟收敛**：种群多样性丧失后基本无力回天。
4. **计算代价高**：$O(GN)$ 次适应度评价；若单次评价要跑一次仿真，$G=500,N=100$ 就是 5 万次仿真，比赛时间根本不够。
5. **对约束问题的处理"软"**：罚函数法得到的解可能仍是不可行的；修复算子要针对问题定制，费时。
6. **结果不可复现**（除非固定种子）：不同种子结果差异明显，评审若复现不出会质疑。
7. **编码方式设计错误会导致算法根本搜不到好解**：例如 0-1 编码处理"总数为定值的分配问题"时，交叉后总数会变，必须专门设计修复。
8. **对目标函数的量纲/尺度敏感**（尤其用轮盘赌时）。

## 8. 适用规模与适用条件

**适用条件**：
- 目标函数**不可导、黑箱、或带离散变量**；
- 解空间**组合爆炸**（无法枚举）但**可行解容易表示**；
- 单次适应度评价**便宜**（$\lesssim10$ ms）——这是硬约束，因为要评价上万次；
- **可以接受"近似最优"**，不需要最优性证明；
- 问题有**一定规模**（决策变量 $\ge10$）：变量太少时枚举/精确算法更快更好。

**适用规模**：决策变量 $10\sim10^4$；种群 20～200；代数 100～2000；总评价次数 $10^4\sim10^6$。若需要 B&B 级别的精确解且规模不大（0-1 变量 $\lesssim300$），**优先用分支定界**。

## 9. 不适用情况

- **小规模问题（变量 $\lesssim15$）**：直接枚举或分支定界能在毫秒内给出**精确最优解**，用 GA 只会更慢、更差，还失去"最优性"这一结论。
- **目标函数可微且光滑**：梯度法/拟牛顿法快几个数量级。
- **单次适应度评价极贵（$>1$ 秒）**：$10^4$ 次评价需要 3 小时，比赛不可行。应改用代理模型 + 少量采样，或降低种群/代数并配合局部搜索。
- **需要严格满足硬约束**（如"每辆车必须恰好满载"）：GA 会大量产生不可行解；应优先建模为整数规划交给 B&B，或设计强修复算子。
- **需要最优性证明或界**：GA 给不出。此时应使用分支定界，或"LR/CG 求界 + GA 求可行解"的组合。
- **染色体长度极大（$L>10^5$）**：收敛极慢，交叉破坏性大。
- **问题本身有精确多项式算法**（最短路、最小生成树、指派、最大流）：用专用算法，不要用 GA。

## 10. Python / MATLAB 实现要点

**Python**
- 优先用成熟库：`pymoo`（多目标 NSGA-II 强）、`DEAP`（灵活、易自定义算子）、`scikit-opt`（`GA` 类，最少代码）；简单问题也可自己写（50 行以内）。
- 关键结构：`population = np.random.randint(2, size=(N, L))`（0-1）或 `np.random.choice(n, size=(N,L), replace=False)`（排列）；适应度用列表推导批量算。
- **向量化适应度评价**：把解码写成 numpy 广播操作，比循环快 10～100 倍。
- 选择算子手写锦标赛：`idx = np.random.randint(0, N, (N, 2)); winners = idx[np.arange(N), np.argmax(fitness[idx], axis=1)]`。
- 排列问题**必须用顺序交叉 OX 或 PMX**，用单点交叉会产生重复基因的非法解。
- 精英保留：`pop[0] = best_individual.copy()`（记得 `.copy()`，否则会被后续变异污染）。
- 多次运行：`results = [run_ga(seed=s) for s in range(30)]`，报告 `np.mean`、`np.std`、`np.min`。

**MATLAB**
- 官方：`ga`（Global Optimization Toolbox）——`ga(@fitness, nvars, A, b, Aeq, beq, lb, ub, @nonlcon, options)`；`options = optimoptions('ga','PopulationSize',40,'CrossoverFraction',0.8,'MaxGenerations',500,'Display','iter')`。
- **国赛老代码的主流写法是谢菲尔德大学遗传算法工具箱（GAOT）**〔原文〕：`crtbp`（创建二进制种群）、`crtbase`、`ranking`、`select`（`sus`/`rws`）、`recombin`（`xovsp`/`xovdp`）、`mut`（`mut`/`mutbga`）、`reins`（重插入）、`bs2rv`（二进制转实数）。
  - 〔原文〕`2011A（1）`的完整调用序列：`Chrom=crtbp(NIND, LIND*NVAR); ... [Chrom ObjV]=reins(Chrom,SelCh,1,1,ObjV,ObjVSel);`，配 `NIND=40; GGAP=0.9;`——**这套代码可以直接复用，且是语料中真实存在的国赛实现**。
- 现代写法：`optimproblem` + `optimvar(..., 'Type','integer')` 交给 `ga` 的混合函数 `ga(..., 'HybridFcn', @fmincon)`。
- 画进化曲线：把 `options` 的 `'PlotFcn', @gaplotbestf` 打开，或记录 `state.Best`。

## 11. 国赛论文中的写法与案例

### 推荐句式（可直接套用）

> 由于（决策变量）为 0-1 变量且问题规模为 $\cdot$，属于 NP 难组合优化问题，难以用精确算法在可接受时间内求解，本文采用遗传算法进行求解。染色体采用（一维整数 / 二进制）编码，长度为 $\cdot$；适应度函数取（目标函数的倒数 / 负目标值），并对违反（约束）的个体施加罚函数 $M\cdot\max(0,g(x))$。种群规模 $N=40$，代沟 $\text{GGAP}=0.9$，交叉概率 $p_c=0.8$，变异概率 $p_m=0.05$，最大代数 500，采用随机遍历采样选择算子与重插入策略保留每代适应度最高的 90%。

> 算法迭代 $\cdot$ 代后收敛，得到最优目标值 $f^*=\cdot$，对应方案见表 x。为验证结果的稳定性，本文以 30 组不同随机种子独立运行，最优值的均值为 $\cdot$，标准差为 $\cdot$，30 次全部收敛到同一解，说明该解具有较好的稳定性。

> 由于遗传算法为随机搜索算法，本文所得结果为一个高质量的近似最优解；为进一步验证其接近最优，本文同时用（LINGO / 分支定界）求解同一模型的（线性松弛 / 精确解），得到 $\cdot$，与遗传算法结果的相对偏差为 $\cdot\%$。

### 配图建议
1. **进化曲线**：横轴代数，纵轴适应度（两条线：种群最优、种群平均）——最标准的 GA 图。
2. **收敛稳定性图**：多次运行的适应度曲线叠加（或箱线图），证明结果稳健。
3. **染色体/编码示意图**：画出 0-1 串与决策量的对应关系，帮助评审理解编码设计。
4. **方案可视化**：如分配方案的热力图、路径图、选址分布图。
5. **GA 与精确解/其他方法的对比表**：目标值、求解时间、相对偏差。
