## 1. 算法解决什么问题

**离散/组合优化问题的局部搜索强化**。禁忌搜索（Tabu Search, TS）是"带记忆的爬山法"：每一步从当前解的邻域中选出**最好的、且不在禁忌表中的**移动；同时把刚走过的移动（或其反向）记入**禁忌表**，在一定步数内禁止重复，从而避免在原地打转、跳出局部最优。

与 SA/GA 的区别：**TS 是确定性的**（给定初值，结果可复现），它不靠随机性跳出局部最优，而靠**记忆结构**。这是它最独特的价值。

国赛里的落点〔归纳〕：**调度、排班、路径、分配**等有明确"移动"定义的组合问题。理论上很契合 2018B RGV 动态调度这类题，但语料中**未找到正文使用案例**（详见第 11 节）。

## 2. 输入与输出

**输入**
- 目标函数 $f(x)$（最小化）；
- **解的表示**与**邻域结构 $N(x)$**（如"交换两个任务""把某任务移到另一个机器""交换两个节点的访问顺序"）；
- **禁忌表长度 $L$（禁忌步数 / tenure）**；
- **禁忌对象**：通常禁"移动的反向"（如刚交换了 $(i,j)$，则在 $L$ 步内禁止再交换 $(i,j)$）；
- **特赦准则（Aspiration Criterion）**：若某个被禁忌的移动能产生**优于历史最优**的解，则解除禁忌、允许执行；
- 最大迭代次数 $T_{\max}$、邻域采样规模（大规模问题只采样部分邻域）；
- 约束处理（修复算子 / 罚函数 / 只生成可行移动）。

**输出**
- **历史最优解 $x^*$**（注意：TS 的当前解可能比历史最优差）；
- 最优目标值、迭代-目标值曲线；
- 禁忌表的使用统计（可选）。

## 3. 算法步骤（伪代码级）

1. **构造初始解**：$x\leftarrow x_0$（贪心/启发式生成）；$x^*\leftarrow x$，$f^*\leftarrow f(x)$；禁忌表 $\mathcal T\leftarrow\varnothing$；$t\leftarrow0$。
2. **循环** 当 $t<T_{\max}$ 且未满足终止条件：
   1. **生成候选邻域**：$\mathcal N=\{x'\in N(x)\}$（大规模问题可只随机采样 $N_s$ 个候选）。
   2. **筛除禁忌**：对每个候选 $x'$，检查对应的移动 $m(x\to x')$ 是否被禁忌。
      - 若 $m$ 在禁忌表中，但 $f(x')<f^*$（**特赦准则**），则**解除禁忌**，仍作为候选。
      - 否则剔除该候选。
   3. **选取最优候选**：$x_{\text{next}}\leftarrow\arg\min_{x'\in\mathcal N}f(x')$。
      - **若邻域全被禁忌且无特赦候选**：允许选择禁忌表中的最优移动（"破禁"），或重启/扰动当前解。
   4. **执行移动**：$x\leftarrow x_{\text{next}}$。
   5. **更新禁忌表**：把移动的反向 $\bar m$ 加入 $\mathcal T$，并记录其禁忌解除时刻 $t+L$；把到达解除时刻的条目移出。
   6. **更新历史最优**：若 $f(x)<f^*$，则 $x^*\leftarrow x$，$f^*\leftarrow f(x)$。
   7. $t\leftarrow t+1$。
3. **终止**：返回 $x^*,f^*$。
4. **（可选）多样化策略**：若连续 $K$ 步最优值无改进，则对当前解施加一次大的随机扰动（或从历史解池中随机重启），再继续 TS。

### 关键设计点（论文中必须写清）

| 设计项 | 常见做法 |
|---|---|
| 解的表示 | 排列（TSP/排班）、0-1 向量（选址）、整数向量（分配量） |
| 邻域结构 | 交换两点（swap）、插入（insert）、逆序（2-opt）、±1 调整、把一个任务移到另一台机器 |
| 禁忌对象 | ①移动本身；②移动的反向；③解的分量取值（如"$x_3=5$"在 $L$ 步内被禁） |
| 禁忌长度 $L$ | 固定值（$L=7\sim20$）或动态（$L$ 在 $[L_{\min},L_{\max}]$ 间随机） |

## 4. 复杂度与收敛性

| 指标 | 量级 |
|---|---|
| 时间复杂度 | $O(T_{\max}\cdot\|N(x)\|\cdot c_f)$；邻域大小 $O(n^2)$ 时（交换类邻域）每次迭代 $O(n^2 c_f)$ |
| 空间复杂度 | $O(\|\mathcal T\|+\text{解长})$，禁忌表通常 $O(n^2)$ 或 $O(L\cdot\text{移动编码})$ |
| 收敛性 | **确定性算法**：给定初值与邻域，结果唯一可复现 |
| 最优性 | **无全局最优保证**；理论上（禁忌表足够长 + 邻域连通）可遍历整个解空间，但需指数级时间 |
| 收敛速度 | 每次迭代只走"一步最好的移动"，比 GA/SA"每代评价整个种群"快得多 |

**必须写进论文的结论**：
1. **TS 不保证全局最优**，但它是**确定性**的——这是它相对 SA/GA/PSO 的独特优点，**结果可复现**（论文中不必报告多种子统计量，这是一个实实在在的加分点）。
2. **禁忌长度 $L$ 是唯一的核心参数**：$L$ 太小则循环（在几个解之间来回跳），$L$ 太大则搜索受限（好移动被长期禁止）。这是 TS 调参的全部难点。
3. **特赦准则不可省**：没有它，一个能带来突破性改进的移动可能因被禁忌而永远无法执行。
4. TS 的效率来自"**每步只评价邻域**"，与 GA/SA 的"每代评价整个种群"不同；因此 TS 在**邻域评估便宜**时特别高效。
5. 理论上若邻域图连通且禁忌表足够长，TS 最终会访问所有解；但所需迭代次数是指数级的，**实际中止时无最优性保证**。

## 5. 参数与调参要点

| 参数 | 推荐取值区间 | 依据 |
|---|---|---|
| 禁忌长度 $L$ | **7～20**（固定）；也常用 $L=\sqrt n$ 或 $L=0.1n$；动态禁忌表：$L$ 在 $[5,15]$ 内随机 | 〔推理〕通用经验 |
| 最大迭代 $T_{\max}$ | $1000\sim10000$；或"最优值停滞 200 步"即停 | 〔推理〕通用经验 |
| 邻域规模 | 完整邻域（$n\le100$）；大规模时随机采样 $N_s=50\sim200$ 个移动 | 〔推理〕通用经验 |
| 特赦准则 | **必开**：允许优于历史最优的被禁忌移动 | 〔推理〕通用经验 |
| 初始解 | 贪心/启发式构造（**显著影响最终质量**） | 〔推理〕通用经验 |
| 多样化策略 | 连续 $K=50\sim100$ 步无改进 → 随机扰动或重启 | 〔推理〕通用经验 |
| 禁忌对象 | 首选"移动的反向"，实现最简单 | 〔推理〕通用经验 |
| 约束处理 | 邻域只生成可行移动（推荐）；或罚函数 | 〔推理〕通用经验 |
| 终止判据 | 迭代上限 或 停滞步数 或 时间上限 | 〔推理〕通用经验 |
| **国赛原文提及** | 〔原文〕`2018B：RGV 的动态调度优化问题.pdf.txt`："（可）以采用混合遗传算法[1]、**禁忌搜索算法**[2] 等" | 〔原文〕仅为"未来改进方向"的提及 |

**调参坑**：
- **$L$ 固定为 1～3** → 会在两个解之间来回震荡（"循环"），永远出不去。
- **$L$ 设得过大（如 $>n$）** → 几乎所有移动都被禁，算法被迫一直"破禁"，退化为随机游走。
- **忘记特赦准则** → 可能错过唯一能突破的移动。
- **邻域太大且不做采样** → 每次迭代 $O(n^2)$ 次评价，$n=1000$ 时一步就要百万次评价。
- **把"当前解"当作结果返回** → TS 的当前解通常比历史最优差（因为它允许"上坡"），**必须返回历史最优**。
- **禁忌表用 list 存储并做线性成员查找** → 每次 $O(L)$；应在实现中用 dict 或数组按移动编码索引，做到 $O(1)$ 查表。

## 6. 优点

1. **确定性、可复现**：给定初值与参数，结果唯一。**这是它相对所有随机元启发式的最大优势**，论文中不需要报告"20 次运行的均值±标准差"。
2. **效率高**：每次迭代只评价一个邻域，比 GA"每代评价整个种群"省得多；邻域评估便宜时尤其快。
3. **有记忆、能跳出局部最优**：靠禁忌表而非随机性，跳出机制是**结构化的**，比 SA 的概率接受更可控。
4. **容易与问题结构结合**：可以设计"只产生可行移动"的邻域，天然处理复杂约束。
5. **改进过程可解释**：每一步移动都有明确业务含义（"把任务 3 从机器 A 移到机器 B"），论文叙事非常好看。
6. **与局部搜索无缝衔接**：TS 本质上就是"强化版局部搜索"，可从任何贪心/启发式解出发继续改进。
7. **实现中等难度**（约 80 行），远比 branch-and-price 之类的精确方法容易。

## 7. 缺点

1. **结果强烈依赖初始解**：初始解差时，TS 可能一直在很差的区域里打转。
2. **禁忌长度 $L$ 难调**，不同问题的最优 $L$ 差异很大。
3. **无全局最优保证**，也没有最优性界。
4. **邻域设计是决定性的**：邻域太大→慢，太小→困在局部；而邻域设计高度依赖问题，无法通用。
5. **大规模问题上效率下降**：完整邻域代价 $O(n^2)$，$n>1000$ 时必须采样，采样又可能错过好移动。
6. **"当前解 vs 历史最优"容易写错**，很多实现返回了错误的解。
7. **国赛接受度低**：全语料中"禁忌"仅 **1 处命中**，且是参考文献式的提及。用它需要自己把原理讲清楚。
8. **不适合连续优化**：邻域概念在连续空间不自然（需离散化）。

## 8. 适用规模与适用条件

**适用条件**：
- 问题**离散/组合**，且**"移动"可以明确定义**（这是 TS 能否用的判定条件）；
- 邻域大小可控：完整邻域 $O(n^2)$ 时 $n\lesssim500$；采样邻域可支持更大的 $n$；
- 邻域内的解**容易评价**（$\lesssim1$ ms），因为每次迭代要评价整个邻域；
- 有**不错的初始解**（贪心能给出）；
- **需要可复现的结果**（这是选 TS 的核心理由之一）。

**适用规模**：决策变量 $n=10\sim1000$；迭代 $1000\sim10000$ 次；每次迭代评价邻域 $O(n)\sim O(n^2)$ 个解。

## 9. 不适用情况

- **连续优化**：邻域定义不自然，应改用 PSO/DE/梯度法。
- **邻域评估昂贵（每次 $>10$ ms）**：一次迭代要评价上百个邻域解，无法承受。
- **需要最优性证明**：TS 给不出；小规模问题应直接用分支定界。
- **解空间高度不连通**（可行移动很少）：TS 会在可行域里"走不动"。
- **大规模问题（$n>5000$）**：邻域太慢或采样太粗，效果差。
- **初始解无法构造或质量极差**：TS 会浪费大量迭代在爬出坏区域。
- **问题有明显的专用多项式算法**（最短路、指派、最大流）：用专用算法。
- **需要快速给一个粗糙解**：贪心更快；TS 需要上千次迭代才能体现价值。

## 10. Python / MATLAB 实现要点

**Python**
- **没有标准库**，需自行实现（约 80 行）；也可参考 `tabu-search`、`scikit-opt` 中的 TS 实现，但国赛建议自写以便定制邻域。
- 核心骨架：
  - `tabu = {}`（键为移动编码，值为解除禁忌的迭代号）——**用 dict 做 O(1) 查表，不要用 list**；
  - `for t in range(Tmax):` → 遍历或采样邻域生成候选 → 对每个候选判断 `tabu.get(key, -1) > t and f(cand) >= best_f` 则跳过（禁忌且不能特赦）→ 取最优候选 → 执行移动 → `tabu[reverse_key] = t + L` → 更新历史最优。
- **移动编码**：用元组作 dict 键，如 `("swap", i, j)`、`("move", task, from_m, to_m)`；反向移动编码要与正向区分。
- **邻域采样**：`cands = [random_move(x) for _ in range(Ns)]`，$N_s=100$ 是常用折中。
- **修复算子**：若移动后不可行，先尝试修复（比"直接丢弃"利用率更高）。
- 返回 `best_x, best_f`；同时记录 `history` 画曲线。
- 由于是确定性的，用同一个 `random.seed()` 也能保证复现（若邻域是随机采样的）。

**MATLAB**
- 无官方 TS 函数，需自行实现。结构同上；用 `containers.Map` 或稀疏矩阵做禁忌表。
- 用**结构体数组**或**矩阵行**表示解，避免 cell 数组（速度慢）。
- 邻域评价向量化：把 $N_s$ 个候选拼成矩阵一次算完目标值（如 `sum(A.*B, 2)`），比循环快得多。
- 画图：迭代-最优值曲线、禁忌表命中率曲线、解的移动轨迹可视化。
- 由于国赛 MATLAB 代码中几乎无 TS 先例，**若使用必须在论文中完整给出算法流程、禁忌规则与特赦准则**。
