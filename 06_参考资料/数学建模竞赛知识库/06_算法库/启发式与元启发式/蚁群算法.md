## 1. 算法解决什么问题

**图上的路径/排列优化问题**，最典型的是**旅行商问题（TSP）**、**车辆路径问题（VRP）**、**网络路由与公交路径选择**。蚁群算法（ACO）模拟蚂蚁觅食：蚂蚁在路径上留下**信息素**，后续蚂蚁以较大概率选择信息素浓度高的边；同时信息素随时间**挥发**，使得差路径逐渐被淘汰，好路径被不断强化。

国赛里的落点〔归纳〕：**路径选择类题目**（公交线路选择、巡检路线、配送路线）。语料中唯一的完整实现出现在 2007B 公交线路选择题。

**关键定位**：ACO 是**专门为路径类问题设计的**算法。如果你的问题不是"在图上找路径/排列"，用 ACO 的效果通常不如 GA/SA。

## 2. 输入与输出

**输入**
- **图结构**：节点集合、边集合、边权 $d_{ij}$（距离/时间/费用）；
- **构造图的规则**：对公交类问题，需先定义"什么算一条边"（直达边、换乘边、步行边）——**这一步是建模难度所在，而不是算法本身**；
- 蚂蚁数量 $m$、最大迭代次数 $T_{\max}$；
- 信息素重要度 $\alpha$、启发式信息重要度 $\beta$；
- 信息素挥发率 $\rho$、信息素总量常数 $Q$；
- 信息素上下界（MMAS 版本）；
- （可选）禁忌表/已访问集合、局部搜索算子（2-opt）。

**输出**
- **最优路径**及其总代价；
- 每代最优代价的收敛曲线；
- 每条边上的最终信息素分布（可画热力图）。

## 3. 算法步骤（伪代码级）

### 3.1 蚁周系统（Ant Cycle，解 TSP）

1. **初始化**：对每条边 $(i,j)$ 设 $\tau_{ij}\leftarrow\tau_0$（常取 $\tau_0=1$ 或 $1/(n\cdot L_{\text{nn}})$，其中 $L_{\text{nn}}$ 是最近邻启发式路径长度）；设置 $\eta_{ij}=1/d_{ij}$。
2. **循环** 对 $t=1\dots T_{\max}$：
   1. **构造解**：对每只蚂蚁 $k=1\dots m$：
      1. 随机（或按规则）选一个起点，加入禁忌表 $\text{tabu}_k$。
      2. 当 $\text{tabu}_k$ 未覆盖全部节点时：
         1. 计算所有可行邻居 $j\notin\text{tabu}_k$ 的转移概率
            $$p_{ij}^k=\frac{\tau_{ij}^{\alpha}\,\eta_{ij}^{\beta}}{\sum_{l\notin\text{tabu}_k}\tau_{il}^{\alpha}\,\eta_{il}^{\beta}}$$
         2. **轮盘赌**选一个 $j$，加入 $\text{tabu}_k$。
      3. 回到起点形成闭合回路，计算路径长度 $L_k$。
   2. **（可选）局部搜索**：对每只蚂蚁的解施加 2-opt / 3-opt 改进（**这一步对最终质量影响最大**）。
   3. **信息素挥发**（对所有边）：$\tau_{ij}\leftarrow(1-\rho)\tau_{ij}$。
   4. **信息素沉积**：
       - **蚁周（Ant Cycle）**：$\Delta\tau_{ij}^k=Q/L_k$ 若蚂蚁 $k$ 经过边 $(i,j)$，否则 0；$\tau_{ij}\leftarrow\tau_{ij}+\sum_k\Delta\tau_{ij}^k$；
       - **蚁量（Ant Quantity）**：用 $Q/d_{ij}$（局部信息，通常效果差）；
       - **蚁密（Ant Density）**：用常数 $Q$。
       - **精英策略**：额外让当前全局最优路径多沉积一次（$\Delta\tau^{\text{best}}=e\cdot Q/L_{\text{best}}$）。
   5. **信息素限幅（MMAS，推荐）**：$\tau_{ij}\leftarrow\mathrm{clip}(\tau_{ij},\tau_{\min},\tau_{\max})$，$\tau_{\max}=1/(\rho L_{\text{best}})$，$\tau_{\min}=\tau_{\max}/(2n)$。**只允许全局最优蚂蚁更新信息素**（避免过早收敛）。
   6. 记录本代最优路径；更新全局最优。
3. **终止**：输出全局最优路径与代价。**注意：输出的应是历史最优解，不是最后一代的解。**
4. **稳健性检验**：多次独立运行报告统计量。

## 4. 复杂度与收敛性

| 指标 | 量级 |
|---|---|
| 时间复杂度 | $O\big(T_{\max}\cdot m\cdot n^2\big)$（每只蚂蚁每步要算 $O(n)$ 个转移概率，共 $n$ 步） |
| 加上局部搜索 | $+O(T_{\max}\cdot m\cdot n^2)$ 每只蚂蚁一次 2-opt（可迭代多次则更高） |
| 空间复杂度 | $O(n^2)$（信息素矩阵 + 距离矩阵）；**这是 ACO 的硬伤**，$n=10^4$ 时矩阵已 800 MB |
| 收敛性 | **无全局最优保证**；MMAS 版本有"以概率 1 收敛到最优"的理论结果（在特定参数条件下） |
| 收敛速度 | 慢。前期需要积累信息素，通常要几十到几百代才显现优势 |

**必须写进论文的结论**：
1. **ACO 不保证全局最优**；论文中应写"求得近似最优路径"。
2. **ACO 的收敛依赖"正反馈"**，因此对**参数 $\alpha,\beta,\rho$ 极其敏感**：$\alpha$ 太大会过早收敛到次优路径，$\rho$ 太小信息素累积失控，$\rho$ 太大则历史经验被快速遗忘。
3. **ACO 的时间开销主要在"每只蚂蚁构造一条完整路径"上**，$O(mn^2)$ 每代；而 GA 每代只需 $O(mn)$。因此**当 $n>200$ 时 ACO 会明显慢于 GA**。
4. **信息素矩阵是 $O(n^2)$ 空间**，稠密图 $n=5000$ 时无法承受；需要对稀疏图用邻接表实现。
5. **MMAS 的上下界限制是防早熟的关键机制**，比朴素 ACO 稳健得多。

## 5. 参数与调参要点

| 参数 | 推荐取值区间 | 依据 |
|---|---|---|
| 蚂蚁数量 $m$ | 节点数 $n$ 的 $0.5\sim1$ 倍，或固定 20～50；经典建议 $m\approx n$ | 〔推理〕通用经验 |
| 信息素重要度 $\alpha$ | 1～2（常用 1） | 〔推理〕通用经验 |
| 启发式重要度 $\beta$ | 2～5（常用 2～3）；$\beta$ 越大越"贪心" | 〔推理〕通用经验 |
| 信息素挥发率 $\rho$ | 0.1～0.5（常用 0.1～0.3）；$\rho$ 大→遗忘快→探索强 | 〔推理〕通用经验 |
| 信息素总量 $Q$ | 1～100（只影响尺度，可通过归一化消除；常取 1） | 〔推理〕通用经验 |
| 初始信息素 $\tau_0$ | $1/(n\cdot L_{\text{nn}})$，$L_{\text{nn}}$ 为最近邻路径长度（MMAS 推荐） | 〔推理〕通用经验 |
| 信息素上下界 | $\tau_{\max}=1/(\rho L_{\text{best}})$，$\tau_{\min}=\tau_{\max}/(2n)$ | 〔推理〕通用经验 |
| 最大迭代 $T_{\max}$ | 100～500；或"最优路径停滞 50 代"即停 | 〔推理〕通用经验 |
| 精英蚂蚁数 $e$ | 1～5（或在 MMAS 中只让最优蚂蚁更新） | 〔推理〕通用经验 |
| **国赛原文描述** | 〔原文〕`2007B：《公交路线的最优化选择》`："产生大量蚂蚁，**不断地更新各条路线的信息素**，以最后一只蚂蚁选择的路径为算法（结果）"；并有独立小节"**2. 拓展二：蚁群算法模型**" | 〔原文〕`2007B：《公交路线的最优化选择》` |
| 变量/图规模 | $n\lesssim500$ 时 ACO 表现良好；$n>2000$ 建议换方法 | 〔推理〕通用经验 |
| 局部搜索 | **强烈建议配 2-opt**，质量提升远大于调参 | 〔推理〕通用经验 |

**调参坑**：
- **$\rho$ 设为 0** → 信息素无限累积，所有蚂蚁走同一条路，算法立刻早熟。
- **$\alpha$ 过大（$>3$）** → 完全被信息素主导，退化为"跟随历史最优"，早熟。
- **$\beta$ 过大** → 退化为最近邻贪心，丢失全局性。
- **忘记挥发** → 算法等价于贪心。
- **用蚁量（Ant Quantity）模型却指望好结果** → 蚁量模型的局部更新会过度强化短边，通常不如蚁周模型。
- **对非路径问题硬套 ACO** → 需要人为构造"图的边"，往往建模别扭且效果差。

## 6. 优点

1. **天然适配路径/排列问题**：解就是一条路径，不需要设计编码与交叉算子（GA 需要设计 OX/PMX 等专用算子）。
2. **正反馈机制**：好路径被自动强化，后期收敛稳定。
3. **分布式计算**：$m$ 只蚂蚁的路径构造完全独立，可并行。
4. **鲁棒性好**：对图结构的扰动不敏感，路径代价变化时算法能自适应调整（因为信息素会重新分布）。
5. **容易加入问题特有的启发式**：$\eta_{ij}$ 可以取"1/换乘次数""1/票价"等任意启发信息，这正是〔原文〕2007B 公交题所利用的灵活性。
6. **信息素矩阵本身有可视化价值**：可以画成边的粗细/颜色图，直观展示"哪些路段是主干"。
7. **在动态/在线场景下有独特优势**：环境变化（如某条路堵了）时，信息素会自然衰减并重新学习。

## 7. 缺点

1. **慢**：$O(mn^2)$ 每代，且需要几百代；比 GA 慢一个数量级。
2. **$O(n^2)$ 空间**：大规模稠密图直接内存爆炸。
3. **参数多且敏感**（$\alpha,\beta,\rho,Q,\tau_0,m$），调参成本高。
4. **易早熟收敛**：正反馈是双刃剑，所有蚂蚁涌向同一条路径后不再探索。
5. **不适合连续优化**：虽然可以离散化，但明显不如 PSO/DE。
6. **不适合非路径类组合问题**（如 0-1 背包、集合覆盖）：需要人为构造图，建模不自然。
7. **理论最优性无保证**，且收敛分析复杂。
8. **国赛实际使用极少**：全语料中"蚁群算法"仅命中 9 处，其中**只有 1 处是真正实现**（2007B），其余均作为"未来改进方向"或参考文献列出一一这说明 ACO 在国赛中的**实战价值有限**，评委也未必加分。

## 8. 适用规模与适用条件

**适用条件**：
- 问题**天然是图上的路径/排列问题**（TSP、VRP、路由、网络设计）；
- 节点数 $n=20\sim500$（$n<20$ 用精确算法/DP；$n>500$ 用启发式 + 局部搜索或 LKH 类专用算法）；
- 边权**非负**，且可定义启发信息 $\eta_{ij}$；
- 图可以**稀疏存储**（邻接表）；
- 可接受"近似最优路径"，不需要最优性证明。

**适用规模**：$n=20\sim500$；$m=20\sim50$；$T_{\max}=100\sim500$；总路径构造次数 $10^4\sim10^6$。

## 9. 不适用情况

- **非路径类优化问题**（0-1 规划、连续参数优化、资源分配）：用 GA/SA/PSO/整数规划。
- **小规模 TSP（$n\le20$）**：动态规划（Held–Karp，$O(n^2 2^n)$）能给精确最优解。
- **大规模 TSP（$n>2000$）**：ACO 的 $O(n^2)$ 空间与时间都撑不住，应改用 LKH、Christofides 近似算法或"贪心 + 2-opt/3-opt"。
- **单次路径评价极贵**（每次要跑仿真）：ACO 需要 $10^5$ 次评价，跑不完。
- **需要严格满足约束（时间窗、容量）且约束复杂**：标准 ACO 的转移概率机制难以直接处理，需要大量定制。
- **需要最优性界**：ACO 给不出。
- **规模大但结构规整的路径问题**：先用 Dijkstra/Floyd 求最短路，再用精确/贪心组合，往往比 ACO 又快又好。

## 10. Python / MATLAB 实现要点

**Python**
- 库：`ACO-Pants`、`scikit-opt` 的 `ACA`（蚁群，TSP 版）、`ant-colony` 包；小规模建议自己写（约 60 行），便于加自定义启发信息。
- 核心数据结构：`tau = np.ones((n,n))*tau0`、`eta = 1/dist`（`np.fill_diagonal(eta, 0)` 防自环）。
- **转移概率用向量化**：`prob = (tau[i]**alpha)*(eta[i]**beta); prob[visited]=0; prob/=prob.sum()`，再用 `np.random.choice(n, p=prob)`。
- **禁忌表用布尔数组**（`visited = np.zeros(n, dtype=bool)`）比 list 的 `in` 判断快得多。
- 信息素更新：先全局挥发 `tau *= (1-rho)`，再对每只蚂蚁的路径加权累加；**用 gather/scatter 而非双重循环**。
- **MMAS 限幅 + 只让最优蚂蚁更新**是提高质量最有效的一招。
- 加 2-opt 局部搜索：`def two_opt(route):` 遍历所有 $(i,j)$ 交换，代价下降就接受——**这一步通常比调 $\alpha,\beta,\rho$ 有效十倍**。
- 稀疏图时用邻接表 + `scipy.sparse`，不要用稠密 $n\times n$ 矩阵。

**MATLAB**
- 官方无 ACO 函数，需自行实现或从 File Exchange 取（`ACO-TSP` 类代码很多）。
- 向量化转移概率：`P = (tau(i,:).^alpha).*(eta(i,:).^beta); P(visited)=0; P=P/sum(P); j = randsample(n,1,true,P);`。
- 信息素更新用矩阵运算：`tau = (1-rho)*tau; for k=1:m, for step=1:n-1 ... end, end` —— 内层循环难以避免，注意预分配。
- 画图：信息素热力图 `imagesc(tau)`、最优路径演化图、收敛曲线。
- 与国赛老代码风格一致：[原文] 2007B 那篇用的是"产生大量蚂蚁，不断更新各条路线的信息素"的朴素实现，可在论文中引用其思路作为对照。

## 11. 国赛论文中的写法与案例

### 推荐句式（可直接套用）

> 在问题一的求解中，本文将（公交网络 / 路网）抽象为带权有向图 $G=(V,E)$，节点表示站点、边表示可通行路段，边权取（行驶时间 / 票价 / 换乘惩罚）。考虑到该问题本质上是在图中寻找最优路径序列，本文采用蚁群算法求解：$m$ 只蚂蚁独立构造路径，转移概率由信息素 $\tau_{ij}$ 与启发信息 $\eta_{ij}=1/d_{ij}$ 共同决定（$\alpha=\cdot,\ \beta=\cdot$）；每轮迭代后按 $\tau_{ij}\leftarrow(1-\rho)\tau_{ij}+\sum_k Q/L_k$ 更新信息素，$\rho=0.2$。

> 为避免算法过早收敛，本文采用最大-最小蚁群系统（MMAS），将信息素限制在 $[\tau_{\min},\tau_{\max}]$ 内，并仅允许当前全局最优路径参与信息素更新。同时对每只蚂蚁的解施加 2-opt 局部优化。

> 算法迭代 $\cdot$ 代后，最优路径总代价稳定于 $\cdot$，相比（Dijkstra 最短路 / 贪心）方案，考虑换乘惩罚后的综合代价下降 $\cdot\%$。

### 配图建议
1. **网络拓扑图 + 最优路径高亮**：最直观的一张图。
2. **收敛曲线**：横轴迭代次数，纵轴最优路径长度与平均路径长度（两条线）。
3. **信息素演化热力图**：多帧（第 1、10、50、200 代）展示信息素如何集中到最优路径上——**ACO 独有的好图**。
4. **参数敏感性图**：$\rho$ 或 $\beta$ 变化 → 最终路径长度，展示最优参数区间。
5. **方法对比表**：ACO vs Dijkstra vs 贪心 vs GA 的路径代价与耗时。
