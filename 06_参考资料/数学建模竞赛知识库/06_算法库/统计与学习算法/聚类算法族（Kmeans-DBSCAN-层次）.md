# 聚类算法族（Kmeans-DBSCAN-层次）

## 1. 算法解决什么问题

**无监督分组**：把 $N$ 个样本按"相似度"分成若干组，使组内相似、组间相异。国赛里的用途高度集中〔归纳〕：

1. **数据预处理/降维**：把几千个散点聚成十几类，再按类做后续建模（选址、定价、分类）；
2. **对象分群与画像**：会员价值分群、商品分级、站点分类、区域划分；
3. **异常检测**：把不属于任何簇的点识别为异常（DBSCAN 天然支持）。

三种主流算法的**核心差别在"簇的形状假设"**：

| 算法 | 簇的形状假设 | 是否需要指定簇数 | 对噪声 | 复杂度 |
|---|---|---|---|---|
| **K-means** | **球形/凸的**，大小相近 | **需要**（$K$ 由人定） | 敏感（异常值会拉偏质心） | $O(NKd\cdot I)$ |
| **DBSCAN** | 任意形状（基于密度连通） | **不需要**（由 $\varepsilon$ 与 MinPts 决定） | **能识别噪声点** | $O(N\log N)$（有索引） |
| **层次聚类** | 任意形状（取决于链接准则） | 不需要（切树得到） | 敏感（单链接易受链式效应影响） | $O(N^2\log N)$ 或 $O(N^2)$ |

**国赛语料中三者都有真实案例，且有一篇论文直接给出了"K-means 与层次聚类只适用于凸样本集"的判断**〔原文，见第 11 节〕——这条判断非常关键。

## 2. 输入与输出

**共同输入**
- 数据矩阵 $X\in\mathbb R^{N\times d}$；
- **距离度量**：欧氏距离（默认）、曼哈顿距离、余弦距离、相关系数距离。**度量选错会让聚类结果毫无业务意义**；
- **是否需要标准化**：**几乎总是需要**（不同量纲的指标不加权会主导距离）。标准化方式：z-score 或 min-max；
- **是否要降维**：$d$ 大时先用 PCA 降到 2～10 维（也便于可视化）。

**各自的专属输入**
- **K-means**：簇数 $K$、初始化方式（`k-means++` 推荐）、最大迭代次数、重启次数 `n_init`。可用 **肘部法（Elbow）/ 轮廓系数（Silhouette）/ Gap 统计量** 辅助定 $K$。
- **DBSCAN**：邻域半径 $\varepsilon$、最小点数 MinPts。可用 **k-距离图（k-distance plot）** 辅助定 $\varepsilon$。
- **层次聚类**：**链接准则**（单链 single / 全链 complete / 平均 average / Ward 最小方差）、距离度量、切割高度。

**输出**
- **簇标签** $\{c_i\}$（K-means/DBSCAN），或**树状图（dendrogram）**（层次聚类）；
- 各簇的**质心/代表点**（K-means）；
- **异常点标记**（DBSCAN 输出 $-1$）；
- 质量指标：**轮廓系数（Silhouette, $[-1,1]$，越接近 1 越好）**、CH 指数、DB 指数、簇内平方和 SSE；
- **可视化**：二维散点按簇着色 + 簇边界/凸包。

## 3. 算法步骤（伪代码级）

### 3.1 K-means（Lloyd 算法）

1. **标准化**数据：$X\leftarrow(X-\mu)/\sigma$（按列）。
2. **选 $K$**（本身是一个超参数）：用肘部法/轮廓系数在 $K=2\dots K_{\max}$ 上试，取拐点。
3. **初始化质心**：用 **k-means++**：
   1. 随机选 1 个点作第一个质心；
   2. 对每个点计算它到最近已选质心的距离平方 $D(x)^2$；
   3. 以概率 $\propto D(x)^2$ 选下一个质心；
   4. 重复直到选出 $K$ 个质心。
   （相比纯随机初始化，k-means++ 能显著减少陷入差局部最优的概率）
4. **循环**（最多 $I$ 次）：
   1. **分配步**：对每个样本 $i$，$c_i\leftarrow\arg\min_k\|x_i-\mu_k\|^2$。
   2. **更新步**：$\mu_k\leftarrow\dfrac{1}{|\{i:c_i=k\}|}\sum_{i:c_i=k}x_i$。
   3. **若所有 $\mu_k$ 的变化 $<\varepsilon$ 或达到 $I$ 次**：终止。
   4. **若出现空簇**：把空簇的质心重置为"离其他质心最远的那个样本点"。
5. **多次重启**：用 `n_init=10\sim50` 个不同初值重复 1～4 步，取 **SSE 最小**的解。
6. **评估**：计算轮廓系数、SSE；画肘部图与轮廓图。
7. **输出**簇标签与质心。

**关键限制**：K-means 最小化的是 $\text{SSE}=\sum_k\sum_{i\in C_k}\|x_i-\mu_k\|^2$，**这隐含着"簇是球形的、各簇方差相近"的假设**。

### 3.2 DBSCAN（基于密度的聚类）

**定义**：$\varepsilon$-邻域 $N_\varepsilon(p)=\{q\mid d(p,q)\le\varepsilon\}$。若 $|N_\varepsilon(p)|\ge\text{MinPts}$，则 $p$ 是**核心点**；否则若 $p$ 在某核心点的邻域内，则是**边界点**；两者都不是则为**噪声点**。

1. **选参数**：$\text{MinPts}=2d$（常用，$d$ 为维数）或 $\text{MinPts}=4\sim10$；$\varepsilon$ 用 **k-距离图**（对每个点算它到第 MinPts 近邻的距离，升序排序后画曲线，取"肘部"处的距离作为 $\varepsilon$）。
2. 标记所有点为"未访问"，$\text{cluster}\leftarrow0$。
3. **对每个未访问点 $p$**：
   1. 标记 $p$ 为已访问；求 $N_\varepsilon(p)$。
   2. **若 $|N_\varepsilon(p)|<\text{MinPts}$** → 暂时标记为**噪声**（后续可能被归为边界点）。
   3. **否则**（$p$ 是核心点）：
      1. $\text{cluster}\leftarrow\text{cluster}+1$；把 $p$ 归入簇 $\text{cluster}$。
      2. 令种子集合 $S\leftarrow N_\varepsilon(p)\setminus\{p\}$。
      3. **当 $S$ 非空**：
         1. 取 $q\in S$，$S\leftarrow S\setminus\{q\}$。
         2. 若 $q$ 未被访问：标记为已访问；求 $N_\varepsilon(q)$；若 $|N_\varepsilon(q)|\ge\text{MinPts}$，则 $S\leftarrow S\cup N_\varepsilon(q)$（**密度可达的传播**）。
         3. 若 $q$ 尚未归入任何簇：归入簇 $\text{cluster}$（**边界点也会被吸收**）。
4. 所有点处理完毕后，仍标为噪声的点即**异常点**（标签 $-1$）。
5. **输出**：簇标签（含 $-1$）、簇个数（**由算法自动确定，无需预设**）。

### 3.3 层次聚类（凝聚式，自底向上）

1. **初始化**：每个样本自成一簇，共 $N$ 簇；计算 $N\times N$ 距离矩阵。
2. **循环** $N-1$ 次：
   1. 找出**距离最近的两个簇** $(A,B)$。
   2. **合并** $A,B$ 为新簇 $A\cup B$。
   3. **更新距离矩阵**（关键，取决于链接准则）：
      - **单链（single）**：$d(A\cup B,C)=\min\{d(A,C),d(B,C)\}$——能发现长条形簇，但**易受"链式效应"影响**把不相干的点串起来；
      - **全链（complete）**：$d(A\cup B,C)=\max\{d(A,C),d(B,C)\}$——倾向紧凑的等直径簇，对异常值敏感；
      - **平均链（average）**：取所有跨簇点对距离的平均——折中；
      - **Ward**：合并后 **SSE 增量最小**——**最常用，倾向产生大小相近的球形簇**。
   4. 记录合并过程（用于画树状图）。
3. **输出树状图**；在合适的**切割高度**处切一刀，得到 $K$ 个簇。
4. **选择切割高度**：看树状图中"最长的垂直距离"（最大的合并跳跃）处切。
5. **（可选）用轮廓系数辅助定 $K$**。

### 3.4 国赛实用流水线

1. **标准化** → 2.（$d$ 大时）**PCA 降维** → 3. **多种聚类方法并行**（K-means / DBSCAN / 层次）→ 4. **用轮廓系数/CH 指数比较** → 5. **选业务上最可解释的那一个**（**可解释性优先于指标**）→ 6. 把簇标签作为**新特征**输入后续模型（回归/评价/选址）。

## 4. 复杂度与收敛性

| 算法 | 时间复杂度 | 空间复杂度 | 收敛性 |
|---|---|---|---|
| **K-means（Lloyd）** | $O(NKd\cdot I)$，$I$ 为迭代次数（通常 $10\sim100$） | $O(NK+Nd)$ | **保证收敛**（有限步内 SSE 单调不增并停止），但**只收敛到局部最优**，且结果依赖初始化 |
| K-means + k-means++ | 初始化 $O(NKd)$；总体同左 | 同上 | 期望意义下 SSE 有 $O(\log K)$ 近似保证（相对最优） |
| **DBSCAN（无索引）** | $O(N^2)$ | $O(N)$ | **确定性算法**（给定 $\varepsilon,\text{MinPts}$ 结果唯一，与点的处理顺序无关）；**无"收敛"概念** |
| DBSCAN（KD-tree/ball-tree 索引） | 平均 $O(N\log N)$ | $O(N)$ | 同上；但**高维时索引失效**，退化为 $O(N^2)$ |
| **层次聚类（朴素）** | $O(N^3)$ | $O(N^2)$ | **确定性算法**，结果唯一 |
| 层次聚类（最近邻链 / Lance–Williams 优化） | $O(N^2\log N)$ | $O(N^2)$ | 同上 |
| 层次聚类（Ward + 堆优化） | $O(N^2\log N)$ | $O(N^2)$ | 同上 |

**必须写进论文的结论**：
1. **K-means 只保证收敛到局部最优**，且**结果依赖初始化**——所以必须用 `k-means++` + 多次重启（`n_init\ge10`），并报告"多次运行结果是否一致"。
2. **K-means 的收敛是"有限步终止"**（每次迭代 SSE 严格下降，而可能的划分有限），但**不是收敛到全局最优**。
3. **K-means 隐含"簇是凸的、各向同性的、大小相近"的假设**。这一条在国赛语料里有直接原文支持：〔原文〕`2017B：“拍照赚钱”的任务定价 (5)`："K-means 聚类、层次聚类等，以上的聚类方法**一般只适用于凸样本集的聚类**。不（适用于任意形状的簇）"——**可直接引用作为方法选型依据**。
4. **DBSCAN 与层次聚类是确定性算法**：给定参数，结果唯一可复现，**不需要报告多种子统计量**。这是它们的实用优势。
5. **DBSCAN 自动确定簇数并能识别噪声**，但**对 $\varepsilon$ 极其敏感**：$\varepsilon$ 稍大 → 所有点聚成一簇；稍小 → 全是噪声。**必须做 $\varepsilon$ 的敏感性分析**。
6. **DBSCAN 在高维数据上失效**（距离集中现象：高维空间中几乎所有点对的距离都差不多），应先降维。
7. **层次聚类的 $O(N^2)$ 空间**：$N=10^5$ 时距离矩阵需 80 GB，不可行（需用 BIRCH/CURE 等可扩展版本）。
8. **聚类质量的评价指标（轮廓系数等）只是参考**——**业务可解释性优先**。这一点在论文里写出来会显得成熟。

## 5. 参数与调参要点

### K-means

| 参数 | 推荐取值 | 依据 |
|---|---|---|
| **簇数 $K$** | 用**肘部法**（SSE 曲线的拐点）+ **轮廓系数**（最大处）+ **业务可解释性**三者综合定；通常在 $2\sim10$ | 〔推理〕通用经验；〔原文〕2018C 用 RFMT 得分聚类、2017B 对任务点聚类，均需先定 $K$ |
| **初始化** | **k-means++**（默认，必用） | 〔推理〕通用经验 |
| **重启次数 `n_init`** | **10～50**（sklearn 新版默认 `'auto'`，数据量小可显式设为 20） | 〔推理〕通用经验 |
| **最大迭代 $I$** | 100～300 | 〔推理〕通用经验 |
| **收敛容差** | 质心位移 $<10^{-4}$ | 〔推理〕通用经验 |
| **距离度量** | 欧氏；高维稀疏数据用余弦 | 〔推理〕通用经验 |
| **标准化** | **必须**（z-score）；若某指标有明确重要性，改用加权距离 | 〔推理〕通用经验 |
| **空簇处理** | 重置到最远点 | 〔推理〕通用经验 |

### DBSCAN

| 参数 | 推荐取值 | 依据 |
|---|---|---|
| **MinPts** | $2d$（$d$ 为维数）或 $4\sim10$；经验规则 $\text{MinPts}\ge d+1$ | 〔推理〕通用经验 |
| **$\varepsilon$** | 用 **k-距离图**（$k=\text{MinPts}$）的肘部；**必须做敏感性分析**（$\varepsilon$ 在 $\pm20\%$ 内变动时簇结构是否稳定） | 〔推理〕通用经验 |
| **距离度量** | 欧氏（标准化后） | 〔推理〕通用经验 |
| **降维** | $d>10$ 时先用 PCA 降到 2～10 维 | 〔推理〕通用经验 |
| **噪声点处理** | 保留为独立类别（可作为异常检测结果）或单独分析，**不要简单删除** | 〔推理〕通用经验 |
| **国赛改进案例** | 〔原文〕`2017B (5)`："由于本题**任务点分布不均匀**，我们考虑**对 DBSCAN 算法进行改进：算法的半径**（随密度自适应）" | 〔原文〕`2017B：“拍照赚钱”的任务定价 (5)`——**变半径 DBSCAN** 的国赛实例 |

### 层次聚类

| 参数 | 推荐取值 | 依据 |
|---|---|---|
| **链接准则** | **Ward**（默认推荐，倾向紧凑等大小簇）；数据有长条形结构时用 single；对异常值敏感的场景避免 complete | 〔推理〕通用经验 |
| **切割高度 / 簇数** | 选树状图中**最大垂直跳跃**处切；或用轮廓系数辅助 | 〔推理〕通用经验 |
| **距离度量** | 欧氏（配 Ward）；Ward 要求欧氏距离 | 〔推理〕通用经验 |
| **规模上限** | $N\lesssim5000$（$O(N^2)$ 内存）；更大用 BIRCH/CURE | 〔推理〕通用经验 |
| **可视化** | 树状图 + 二维散点着色（两图并列） | 〔推理〕通用经验 |

**三家共用的调参坑**：
- **不标准化** → 数值大的指标支配距离，聚类结果毫无业务意义（**这是头号错误**）。
- **用轮廓系数"精确选 $K$"而不看业务** → 数学上最好但业务上不可解释的分组没有价值。
- **对同一批数据只跑一次** → K-means 必须多初值重启，否则可能落入差局部最优。
- **在原始空间做可视化却不降维** → $d>2$ 时用 PCA/t-SNE 降到 2 维展示，并说明"可视化仅为展示，聚类在原始（或 PCA 前若干主成分）空间完成"。
- **DBSCAN 用默认 $\varepsilon=0.5$** → 不标准化时这个默认值毫无意义。

## 6. 优点

**K-means**
1. **快**：$O(NKd\cdot I)$，$N=10^5$ 也是秒级；是三者中唯一能轻松处理大数据集的。
2. **简单直观、易解释**：质心可以直接理解成"典型对象"，业务上好讲。
3. **有成熟的选 $K$ 工具**：肘部法、轮廓系数、Gap 统计量。
4. **收敛有保证**：有限步终止且 SSE 单调不增。
5. **可作为其他算法的初始化**（如 GMM 的 EM、K-means++ 的种子）。
6. **输出即"分组标签"**，可直接作为后续模型的特征。

**DBSCAN**
7. **不需要预设簇数**：簇的个数由数据本身决定。
8. **能发现任意形状的簇**（长条形、环形、S 形），这是 K-means 做不到的。
9. **能识别噪声/异常点**（标签 $-1$），本身就是异常检测工具。
10. **确定性算法**：给定参数结果唯一，可复现，论文里不需要报告多种子统计量。
11. **对异常值鲁棒**：异常点不影响核心点的密度判定（K-means 会被异常值拉偏质心）。

**层次聚类**
12. **不需要预设簇数**：树状图给出所有可能的簇数，切哪里由你定。
13. **树状图极具可解释性**：完整展示"谁先和谁合并"，是论文里极好看的图。
14. **确定性算法**，结果可复现。
15. **能揭示层次结构**：若数据本身有层级（如"大类—小类"），层次聚类天然契合。

## 7. 缺点

**K-means**
1. **必须预设 $K$**，而 $K$ 往往是主观的。
2. **只能发现球形/凸的、大小相近的簇**〔原文依据：2017B（5）明确指出"K-means 聚类、层次聚类等，以上的聚类方法一般只适用于凸样本集的聚类"〕。
3. **对初始化敏感**，只收敛到局部最优。
4. **对异常值敏感**（异常值会显著拉偏质心）。
5. **各簇方差不同时效果差**（假设各向同性）。
6. **必须用欧氏距离**（用其他度量时"质心"的含义不成立）。

**DBSCAN**
7. **对 $\varepsilon$ 极其敏感**，且参数难调（必须画 k-距离图）。
8. **密度差异大的数据上失效**：全局固定的 $\varepsilon,\text{MinPts}$ 无法同时识别稀疏簇与稠密簇（这正是 2017B 要改成**变半径** DBSCAN 的原因〔原文〕）。
9. **高维失效**（距离集中现象），必须降维。
10. **无索引时 $O(N^2)$**，大样本慢。
11. **不产生"质心"或"代表点"**，业务解释不如 K-means 直接。

**层次聚类**
12. **$O(N^2)$ 空间与 $O(N^2\log N)$ 时间**，$N>5000$ 基本不可行。
13. **合并不可撤销**：一旦合并错了，后续无法纠正（贪心性质）。
14. **对噪声和异常值敏感**（尤其 single/complete），会产生"链式效应"或"孤立簇"。
15. **对链接准则的选择敏感**，不同准则结果差异明显。

## 8. 适用规模与适用条件

| | K-means | DBSCAN | 层次聚类 |
|---|---|---|---|
| **样本量 $N$** | $10^2\sim10^6$ | $10^2\sim10^5$（有索引）；$\lesssim10^4$（无索引） | $\lesssim5000$ |
| **维数 $d$** | $\le100$（先 PCA 更好） | $\le10$（**高维必须降维**） | $\le50$ |
| **簇形状** | **凸/球形** | **任意形状** | 取决于链接准则 |
| **簇密度** | 要求相近 | **要求相近**（否则需变参数） | 灵活 |
| **噪声** | 敏感 | **能识别** | 敏感 |
| **必需条件** | 需先定 $K$ | 需调 $\varepsilon$ 与 MinPts | 需选链接准则与切割高度 |
| **确定性** | 否（多初值重启） | **是** | **是** |

**国赛典型规模**〔归纳〕：附件数据通常 $N=10^2\sim10^4$、$d=2\sim10$——**三种方法都能用**，选择应基于"簇形状假设"与"是否需要异常检测"。

## 9. 不适用情况

**K-means 不适用**：
- **簇是非凸/任意形状**（环形、月牙形、长条形）→ 用 DBSCAN 或谱聚类。
- **簇的密度/大小差异极大** → 用 DBSCAN（变参数）或 GMM。
- **数据含大量异常值且不处理** → 先剔除或改用 DBSCAN。
- **类别变量为主**（无连续距离概念）→ 用 K-modes / K-prototypes。
- **簇数 $K$ 无法确定且业务无先验** → 用 DBSCAN/层次聚类。

**DBSCAN 不适用**：
- **各簇密度差异很大** → 全局参数失效；用 OPTICS 或自适应 DBSCAN。
- **维数很高（$d>20$）且未降维** → 距离集中，算法失效。
- **需要"质心/代表点"** → K-means 更直观。
- **$N$ 极大（$>10^5$）且无索引支持** → $O(N^2)$ 不可行。
- **参数无法通过 k-距离图合理确定**（如数据高度连续、无密度间隙）→ 说明数据本身可能没有"密度分离"的簇结构。

**层次聚类不适用**：
- **$N>5000$** → 内存与时间不可行。
- **需要在线/增量聚类** → 层次聚类是批处理的。
- **早期合并错误无法挽回的场景**（如合并后再无法拆开）→ 用 K-means/DBSCAN。
- **只需一个固定簇数的最终划分** → 直接 K-means 更快。

**三家共用的不适用情况**：
- **数据本身没有簇结构**（近似均匀分布）：任何聚类都会"强行分组"，结果无意义。**应先用 Hopkins 统计量或可视化检查是否存在簇结构**。
- **需要"正确的"分组标签**：聚类无监督，没有客观正确答案，必须靠**业务可解释性**与**外部指标**（若有标签）验证。

## 10. Python / MATLAB 实现要点

**Python（`scikit-learn` 生态）**
- **标准化 + 降维**：`StandardScaler().fit_transform(X)`；`PCA(n_components=0.9).fit_transform(X)`（保留 90% 方差）。
- **K-means**：`KMeans(n_clusters=K, init='k-means++', n_init=20, max_iter=300, random_state=0).fit(X)` → `.labels_`、`.cluster_centers_`、`.inertia_`（SSE）。
- **选 $K$**：`for K in range(2,11): KMeans(...).fit(X); inertia` 画肘部图；`silhouette_score(X, labels)` 画轮廓图。
- **DBSCAN**：`DBSCAN(eps=eps, min_samples=minPts, metric='euclidean').fit(X)` → `labels_`（$-1$ 为噪声）。**k-距离图**：`from sklearn.neighbors import NearestNeighbors; d,_ = NearestNeighbors(n_neighbors=minPts).fit(X).kneighbors(X)`，取 `d[:,-1]` 排序后画曲线找肘部。
- **层次聚类**：`scipy.cluster.hierarchy.linkage(X, method='ward')` → `dendrogram(Z)` → `fcluster(Z, t=K, criterion='maxclust')`。
- **评价**：`silhouette_score`、`calinski_harabasz_score`、`davies_bouldin_score`（后两者越大/越小越好）。
- **可视化**：PCA/t-SNE 降到 2 维后 `plt.scatter(X2[:,0], X2[:,1], c=labels, cmap='tab10')`；DBSCAN 的噪声点单独用黑色叉号标出。
- **易错点**：`KMeans` 的 `n_init` 在 sklearn 1.4+ 默认改为 `'auto'`，**显式写死数值更稳妥**；`random_state` 必设。

**MATLAB**
- **K-means**：`[idx, C, sumd] = kmeans(X, K, 'Replicates', 20, 'Distance','sqeuclidean', 'Start','plus')`——**`Replicates` 就是重启次数，务必调大**；`'Start','plus'` 即 k-means++。
- **DBSCAN**：**MATLAB 无内置 DBSCAN**（`dbscan` 在 Statistics and Machine Learning Toolbox R2019a+ 提供：`idx = dbscan(X, eps, minPts)`；早期版本需自写或从 File Exchange 取）。
- **层次聚类**：`Z = linkage(X, 'ward')` → `dendrogram(Z)` → `T = cluster(Z, 'maxclust', K)`。
- **评价**：`evalclusters(X, idx, 'silhouette')`、`evalclusters(X, idx, 'CalinskiHarabasz')`——**`evalclusters` 可以直接帮你选 $K$**。
- **可视化**：`gscatter(X(:,1), X(:,2), idx)`；`silhouette(X, idx)` 直接画轮廓图。
- 标准化：`zscore(X)`；降维：`[coeff, score] = pca(X)`。
- 老国赛代码常写显式 `for` 循环实现 K-means，注意**预分配**与**向量化距离计算**（`pdist2`）。

### 推荐句式（可直接套用）

> 为将（$\cdot$ 个任务点 / 会员 / 站点）划分为若干具有相似特征的群体，本文采用聚类分析方法。由于（数据特征），本文首先对各指标进行 z-score 标准化以消除量纲影响，再用主成分分析降维至（$\cdot$）维。

> **（K-means）** 采用 K-means 聚类算法，以 k-means++ 方式初始化质心，并以 20 组不同初值重复运行取簇内平方和最小者。簇数 $K$ 通过肘部法与轮廓系数共同确定：当 $K$ 由 2 增至 10 时，簇内平方和 SSE 及轮廓系数如图 x 所示，$K=\cdot$ 时 SSE 曲线出现明显拐点且轮廓系数达到最大，故取 $K=\cdot$。

> **（DBSCAN）** 考虑到（任务点）分布不均匀且可能存在异常点，K-means 的球形簇假设不再适用，本文采用 DBSCAN 密度聚类算法。参数通过 k-距离图确定：取 MinPts$=\cdot$，绘制各点到第 MinPts 近邻距离的升序曲线，在曲线拐点处取 $\varepsilon=\cdot$。算法识别出 $\cdot$ 个簇及 $\cdot$ 个噪声点，噪声点对应（异常任务点 / 定价异常区域），单独分析。

> **（改进 DBSCAN）** 由于本文数据（任务点分布不均匀），固定半径的 DBSCAN 难以同时识别稀疏与稠密区域，本文对 DBSCAN 进行改进，使邻域半径随局部密度自适应变化（见第 $\cdot$ 节）。

> **（层次聚类）** 采用 Ward 最小方差法进行层次聚类，以树状图（图 x）展示合并过程，在最大垂直跳跃处切割得到 $\cdot$ 个簇。

> 为验证聚类结果的合理性，本文计算了轮廓系数（Silhouette $=\cdot$）并与（其他方法）的结果进行对比（表 x）。同时，所得分组在业务上具有明确含义：（簇 1）为（高价值会员 / 热销单品），（簇 2）为（…），与实际情况相符。

> 需要说明的是，聚类分析为无监督方法，不存在唯一的"正确"分组；本文的分组结果以业务可解释性为主要判断依据，并以轮廓系数作为辅助指标。
