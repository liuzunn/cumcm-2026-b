# 交叉验证与超参数搜索

> **证据等级约定**：〔原文〕= 在语料文件中直接读到原句；〔归纳〕= 由多篇语料归纳出的共性；〔推理〕= 语料未直接支持，按通用算法经验给出。
> **语料范围**：`_work_extract\*.txt`（1992—2025 国赛真题+优秀论文）、`_work_extract\_keydocs\*.txt`（方法汇总）、`_work_extract\2026真题\*.txt`。
> 本文只读语料、不改原文；所有"优秀论文案例"均为实际检索命中，未命中一律标【资料中未找到直接案例】。


## 1. 算法解决什么问题

**模型泛化能力的评估**与**超参数的自动选择**。这两个问题在国赛里成对出现：你训练了一个回归/分类/神经网络模型，评委一定会问"这个结果是不是过拟合？""参数（如 BP 网络隐层节点数、正则化系数、聚类数 $K$、灰色模型阶数）为什么这么选？"——交叉验证与超参数搜索就是回答这两个问题的标准工具。

- **交叉验证（Cross-Validation, CV）**：把数据切成 $k$ 折，轮流用 $k-1$ 折训练、1 折验证，用 $k$ 次验证误差的平均作为泛化误差的估计。它比"单次留出法"更稳健，尤其在样本量小时（国赛附件数据往往只有几十到几百条）。
- **超参数搜索**：在候选参数空间中寻找使交叉验证误差最小的参数组合。四种策略：
  - **网格搜索（Grid Search）**：穷举笛卡尔积；
  - **随机搜索（Random Search）**：在参数分布中随机采样 $n$ 次（Bergstra & Bengio 2012 证明在高维空间中通常优于网格搜索）；
  - **贝叶斯优化**：用代理模型（高斯过程/Tpe）引导采样，样本效率最高；
  - **Hyperband / 逐次减半**：用少量数据快速淘汰差配置，适合深度模型。

**国赛里的三类落点**〔归纳〕：
1. **模型选型与验证**：把数据分成训练/验证集，用交叉验证比较不同模型（回归 vs 灰色 vs 神经网络），说明"选它不是拍脑袋"；
2. **超参数确定**：BP 网络隐层节点数、SVM 的 $C$ 与 $\gamma$、随机森林树数、灰色模型的背景值系数、K-means 的 $K$；
3. **防止过拟合的证据**：在论文"模型检验"章节给出训练误差与验证误差的对比曲线。

## 2. 输入与输出

**输入**
- 数据集 $\{(x_i,y_i)\}_{i=1}^{N}$（$N$ 常常只有 $30\sim500$，这是国赛数据的特点）；
- 模型类（如"单隐层 BP 网络""$k$ 阶多项式回归"）与训练算法；
- 评价指标（回归：RMSE / MAE / $R^2$；分类：准确率 / F1 / AUC）；
- 折数 $k$、重复次数、随机种子；**时间序列时必须用滚动/前向验证，不能随机切分**；
- 超参数搜索空间与搜索策略。

**输出**
- **交叉验证误差的均值与标准差**（标准差重要，它反映稳定性）；
- 最优超参数组合；
- **每个超参数对验证误差的影响曲线**（网格搜索天然产出，画出来极有说服力）；
- （最终模型）在全量训练集上重训后的测试性能；
- **过拟合证据**：训练误差 vs 验证误差的对比。

**必须交代的三件事**（否则结论不可信）：
1. **切分方式**（$k$ 折 / 留一 / 滚动）与折数；
2. **评价指标**及其计算方式；
3. **是否是分层/分组切分**（分类问题要分层；同一样本的多次测量要按组切分，否则数据泄漏）。

## 3. 算法步骤（伪代码级）

### 3.1 $k$ 折交叉验证

1. 输入数据 $D$、折数 $k$（常用 5 或 10）、模型训练过程 $\mathcal A$、指标 $\text{metric}$。
2. **打乱数据**（若非时间序列），切分为 $k$ 个大小近似相等的折 $D_1,\dots,D_k$。
   - **分类问题**：用**分层切分**，保证每折中各类比例与原数据一致；
   - **时间序列**：**不能打乱**，用滚动窗口（见 3.4）。
3. **对 $j=1\dots k$**：
   1. 训练集 $\text{Tr}=D\setminus D_j$；验证集 $\text{Val}=D_j$。
   2. **在 $\text{Tr}$ 上训练**：$\hat f_j=\mathcal A(\text{Tr})$。
   3. **在 $\text{Val}$ 上评估**：$e_j=\text{metric}(\hat f_j,\text{Val})$。
4. **汇总**：$\bar e=\frac1k\sum_j e_j$，$s_e=\sqrt{\frac{1}{k-1}\sum_j(e_j-\bar e)^2}$。
5. **输出** $\bar e\pm s_e$。
6. （可选）**重复 $R$ 次不同的随机切分**，报告 $\bar e$ 的分布——数据量小时推荐（$R=5\sim10$）。

### 3.2 网格搜索 + 交叉验证

1. 定义每个超参数的候选列表 $\Theta_1\times\Theta_2\times\dots\times\Theta_d$（笛卡尔积）。
2. **对每个参数组合 $\theta$**：
   1. 用 3.1 计算其交叉验证误差 $\bar e(\theta)$。
3. **选最优**：$\theta^*\leftarrow\arg\min_\theta\bar e(\theta)$。
4. **重训**：用**全部数据** $D$ 以 $\theta^*$ 重新训练最终模型。
5. **报告**：
   - 最优超参数及其 CV 误差；
   - **参数敏感性图**（每个超参数单独变化时的 CV 误差曲线）；
   - **计算成本**：$|\Theta_1|\times\dots\times|\Theta_d|\times k$ 次模型训练——**这个数字要在论文里算出来**，体现工作量与复杂度意识。

### 3.3 随机搜索（高维时优先）

1. 为每个超参数指定**采样分布**（连续用对数均匀或正态，离散用均匀）。
2. **重复 $n$ 次**（$n=30\sim200$）：
   1. 从分布中采样 $\theta$；
   2. 计算 CV 误差 $\bar e(\theta)$；
   3. 记录 $(\theta,\bar e(\theta))$。
3. 取 $\bar e$ 最小的 $\theta$；用全部数据重训。
4. **报告**：采样点散点图（横轴某个超参数、纵轴 CV 误差），展示"哪些区域好"。

### 3.4 时间序列的正确验证方式（国赛极易做错）

1. **滚动前向验证（Rolling / Walk-forward）**：
   - 用 $[1,t]$ 训练，预测 $t+1$；然后 $t\leftarrow t+1$ 重复。
   - **绝不使用未来数据**。
2. **扩展窗口 vs 固定窗口**：数据量多时用固定窗口；趋势明显时用扩展窗口。
3. **报告**：预测误差随预测步长（1 步、3 步、7 步）的变化曲线。

### 3.5 嵌套交叉验证（严格的做法）

1. **外层**：$k_{\text{out}}$ 折，用于**评估**"整个建模流程（含调参）"的泛化误差。
2. **内层**：在每个外层训练集内做 $k_{\text{in}}$ 折 CV，用于**选超参数**。
3. **输出**：外层各折的测试误差均值——**这是无偏的泛化误差估计**。
4. 代价：$k_{\text{out}}\times k_{\text{in}}\times|\Theta|$ 次训练。数据量小、参数少时才可行。

## 4. 复杂度与收敛性

| 方法 | 时间复杂度 | 说明 |
|---|---|---|
| $k$ 折 CV | $k\times c_{\text{train}}(N(1-1/k))$ | $c_{\text{train}}$ 是单次训练代价 |
| 留一交叉验证 (LOO) | $N\times c_{\text{train}}$ | **$N$ 次训练**，$N>200$ 时太贵；但有近似公式（对线性模型可用帽子矩阵一行代码算出） |
| 网格搜索 CV | $|\Theta|\times k\times c_{\text{train}}$ | **随超参数个数指数增长** |
| 随机搜索 | $n\times k\times c_{\text{train}}$ | 与维数**无关**（这是它优于网格搜索的根本原因） |
| 贝叶斯优化 | $\approx(10\sim50)\times k\times c_{\text{train}}$ | 样本效率最高，但有代理模型开销 |
| 空间复杂度 | $O(N\cdot d)$ | CV 本身几乎不额外占内存 |

**收敛性（必须写对）**：
1. **交叉验证误差是泛化误差的（近似）无偏估计**，但**方差较大**，尤其在 $N$ 小时；因此**必须报告标准差**，而不是只报均值。
2. **CV 不估计"某一个具体模型的误差"，而是估计"建模流程的误差"**——这句话在论文里写出来会显得很专业。
3. **$k$ 的选择是偏差-方差权衡**：$k$ 大（如 LOO）→ 偏差小但方差大、计算贵；$k=5$ 或 $10$ 是实践中的标准折中。
4. **网格搜索没有收敛性概念**（穷举），随机搜索与贝叶斯优化是**启发式搜索**，不保证找到全局最优超参数。
5. **超参数的最优值对数据切分敏感**：在小数据上，不同切分可能选出不同超参数——**应报告多个切分下的最优参数是否一致**。
6. **过拟合验证集的危险（"CV 过拟合"）**：如果反复用同一个验证集挑模型，验证集就变成了训练集的一部分。严格做法是**嵌套 CV**。

## 5. 参数与调参要点

| 参数 | 推荐取值区间 | 依据 |
|---|---|---|
| **折数 $k$** | 5 或 10（标准）；$N<50$ 时用 LOO 或 $k=N$/5 的"留一/留五"；$N>10^4$ 时 $k=3\sim5$ 省时间 | 〔推理〕通用经验 |
| **重复次数 $R$** | 5～10（不同随机切分），报告均值的分布 | 〔推理〕通用经验 |
| **评价指标** | 回归：RMSE、MAE、$R^2$；分类：准确率、F1、AUC。**多指标并列报告更稳** | 〔推理〕通用经验 |
| **网格搜索范围** | 每个超参数取 5～10 个值，**先粗后细（两阶段）**：粗网格定位区间，再在小区间细搜 | 〔推理〕通用经验 |
| **网格搜索规模控制** | 总组合数 $\times k$ 应控制在可接受时间内（如 $\le$ 10 分钟）；一般不超过 $10^3$ 组 | 〔推理〕通用经验 |
| **随机搜索采样数 $n$** | 30～200（超参数 $>4$ 个时优先用随机搜索） | 〔推理〕通用经验 |
| **BP 网络隐层节点数** | 常用经验式 $h=\sqrt{n_{\text{in}}+n_{\text{out}}}+a$（$a=1\sim10$），或 $h=2n_{\text{in}}+1$；**应通过 CV 确定而非直接套公式** | 〔推理〕通用经验 |
| **正则化系数 $\lambda$ / SVM 的 $C,\gamma$** | 在**对数尺度**上搜索：$10^{-4},10^{-3},\dots,10^{3}$ | 〔推理〕通用经验 |
| **随机种子** | **必须固定**（`random_state=0`）；报告"以 5 个不同种子重复，结果一致" | 〔推理〕通用经验 |
| **数据切分比例（若用留出法）** | 训练:测试 = 7:3 或 8:2；**时间序列绝不随机切分** | 〔推理〕通用经验 |
| **国赛原文的验证表述** | 〔原文〕`2017C：颜色与物质浓度辨识 (2).pdf.txt`："硫酸铝钾的数据共有 35 个，有**充足的数据进行数据间的交叉验证**，提高了（…）" | 〔原文〕`2017C（2）` |

**调参坑（国赛高频翻车点）**：
1. **时间序列随机切分** → 用未来预测过去，误差小得离谱，结论完全错误。**必须用滚动验证**。
2. **数据泄漏**：标准化/归一化在**切分之前**对全量数据做 → 验证集的信息泄漏进训练。**正确做法：先切分，再只在训练集上 fit 标准化器，用同一变换作用于验证集**。
3. **同一样本的重复测量被分到不同折** → 数据泄漏；应按"组"切分（GroupKFold）。
4. **只报均值不报标准差** → 掩盖了不稳定性。
5. **用测试集调参** → 测试集不再是独立的，结论无效。
6. **折数 $k$ 太大而 $N$ 太小** → 每折训练样本太少，模型方差巨大。
7. **标准化/特征选择放在 CV 循环外** → 同第 2 条，是最隐蔽也最常见的错误。
8. **网格搜索维度爆炸** → 5 个超参数 × 10 个取值 = $10^5$ 组 × 10 折 = $10^6$ 次训练，跑不完。

## 6. 优点

1. **给出可信的泛化误差估计**：这是回答"模型是不是过拟合"的唯一标准手段，直接对应论文的"模型检验"章节。
2. **数据利用率高**：每个样本都既被训练也被验证过一次，对国赛这种小数据集（几十到几百条）特别重要。
3. **超参数选择有依据**："我们用 10 折交叉验证在 $h\in[3,20]$ 中选出了 $h=8$"远比"我们取 8 个隐层节点"有说服力。
4. **实现成本低**：`sklearn.model_selection.cross_val_score` / `GridSearchCV` 一行调用；MATLAB 有 `cvpartition` + `fitrnet` 的自动调参。
5. **可产出极好看的图**：每个超参数对验证误差的影响曲线，是论文里最受欢迎的图之一。
6. **适用于任何模型**：不要求模型可导、可微，只要求能训练和预测；对灰色模型、神经网络、随机森林一视同仁。
7. **可量化"模型选择"的收益**：不同模型的 CV 误差对比表，直接支撑选型结论。

## 7. 缺点

1. **计算代价成倍增长**：$k$ 折就是 $k$ 倍训练时间；再加上超参数搜索，成本是 $|\Theta|\times k$ 倍。国赛现场时间宝贵。
2. **小数据上方差大**：$N=30$ 时，不同切分的 CV 误差可能相差很大，选出的超参数不稳定。
3. **时间序列上有陷阱**：随机 CV 在时序数据上是**错误的**，会给出过于乐观的估计。
4. **数据泄漏风险高**：预处理、特征选择、标准化、缺失值插补若放在 CV 循环外，结果全部虚高，而且**不会报错**。
5. **网格搜索维数灾难**：超参数个数增加时组合数指数爆炸。
6. **CV 误差与测试误差仍有差距**：CV 估计的是"流程误差"，最终模型在全量数据上重训后，其表现会因训练数据变多而略有不同。
7. **对超参数的最优值无理论保证**：随机搜索/贝叶斯优化都是启发式。
8. **国赛语料中直接案例很少**：见第 11 节——国赛论文往往只写"用附件 3 的数据做检验"，而**不写标准的 $k$ 折流程**，因此你若规范地做了 CV，**反而是相对优势**。

## 8. 适用规模与适用条件

**适用条件**：
- 数据是**独立同分布**的（非时间序列），或能正确构造滚动验证方案；
- 样本量 $N\ge30$（$N<30$ 时 CV 的方差太大，应改用 LOO 或 Bootstrap，并明确声明局限）；
- 有**多个候选模型或超参数**需要选择；
- 单次训练**便宜**（$\lesssim$ 秒），因为要重复 $k\times|\Theta|$ 次；
- 需要报告泛化能力（论文的模型检验章节）。

**适用规模**：$N=30\sim10^5$；$k=5\sim10$；超参数组合 $10\sim10^3$ 组；总训练次数 $10^2\sim10^4$。

## 9. 不适用情况

- **样本量极小（$N<20$）**：每折训练集太小，CV 结果无意义；应改用留一法 + Bootstrap，并在论文中**明确承认样本量的局限**，而不是强行给一个精确的"泛化误差"。
- **时间序列且不做滚动验证**：随机 CV 完全失效。要么用滚动验证，要么明确说"本文不做泛化误差估计，仅做拟合优度与残差检验"。
- **单次训练极贵（$>1$ 小时）**：$k\times|\Theta|$ 次训练不可行；应用随机搜索 + 少量折数，或贝叶斯优化。
- **数据有分组结构（同一对象多次测量）且不按组切分**：数据泄漏，结果无效。
- **模型是确定性机理模型**（如微分方程模型、物理仿真）：没有"训练"环节，CV 无从谈起；此时应做**参数敏感性分析**与**残差分析**替代。
- **只有一个候选模型且无超参数**：CV 只能给一个误差数字，价值有限。
- **题目明确要求"用全部数据建模并给出预测"**：CV 只是辅助，不应占用过多比赛时间。

## 10. Python / MATLAB 实现要点

**Python**
- **sklearn 全流程**：
  1. 切分：`KFold(n_splits=10, shuffle=True, random_state=0)`、`StratifiedKFold`（分类）、`TimeSeriesSplit`（**时间序列专用**）、`GroupKFold`（分组）；
  2. 评估：`cross_val_score(model, X, y, cv=cv, scoring='neg_mean_squared_error')`；
  3. 调参：`GridSearchCV(model, param_grid, cv=10, scoring=..., n_jobs=-1)`、`RandomizedSearchCV(..., n_iter=100)`；
  4. 结果：`gs.best_params_`、`gs.best_score_`、`gs.cv_results_`（**`cv_results_` 可直接转成 DataFrame 画超参数敏感性图**）。
- **防止数据泄漏的正确姿势：用 `Pipeline`**：`Pipeline([('scaler', StandardScaler()), ('model', SVR())])` —— 这样标准化器在每折内单独 fit，**这是最容易被忽略也最重要的一条实践**。
- 贝叶斯优化：`optuna`（`study.optimize(objective, n_trials=100)`）或 `scikit-optimize`；**`optuna` 的 `study.trials_dataframe()` 与可视化非常适合论文插图**。
- 时间序列：`TimeSeriesSplit(n_splits=5)`，或手写滚动窗口循环。
- 报告：`print(f"{scores.mean():.4f} ± {scores.std():.4f}")`——**均值 ± 标准差**是标准格式。
- **必须固定 `random_state`**；建议用 5 个不同种子重复，报告结果一致性。

**MATLAB**
- `cvpartition(N, 'KFold', 10)`、`cvpartition(y, 'Stratified', 10)`；`cvpartition(N, 'Leaveout')`（留一）；`cvpartition(N, 'HoldOut', 0.3)`。
- 手写循环：`for i = 1:k, trIdx = training(cv, i); teIdx = test(cv, i); ... end`。
- 自动调参：`fitrnet(X, y, 'OptimizeHyperparameters', 'auto', 'HyperparameterOptimizationOptions', struct('AcquisitionFunctionName','expected-improvement-plus','KFold',10,'ShowPlots',true,'Repartition',true))`——**R2021a+ 的 `fitrnet`/`fitcnet` 支持内置贝叶斯优化调参，一行搞定**。
- `fitcecoc`、`fitrsvm`、`fitrensemble` 同样支持 `OptimizeHyperparameters`。
- 交叉验证误差：`kfoldLoss(crossval(model, X, y, 'KFold', 10))`、`kfoldPredict`。
- 画图：`plotPartialDependence`、`HyperparameterOptimizationOptions` 的 `ShowPlots=true` 会直接画出目标函数最小值随迭代的收敛图。
- **注意**：MATLAB 的 `crossval` 不会自动处理标准化；若在循环外做了 `zscore`，就产生了数据泄漏——**必须在每折内对训练集 `zscore` 并用同一 `mu,sigma` 处理验证集**。

## 11. 国赛论文中的写法与案例

### 推荐句式（可直接套用）

> 为避免模型过拟合并客观评估其泛化能力，本文采用 **10 折交叉验证**：将 $\cdot$ 组样本随机划分为 10 折（分类问题采用分层抽样以保证各折类别比例一致），轮流以其中 9 折训练、1 折验证，取 10 次验证误差的均值作为泛化误差的估计。数据标准化（z-score）在每一折内部单独完成，以避免验证集信息泄漏。

> 交叉验证结果为：均方根误差 $\text{RMSE}=\cdot\pm\cdot$（均值 ± 标准差），决定系数 $R^2=\cdot$。训练集误差为 $\cdot$，验证集误差为 $\cdot$，二者接近，说明模型未出现明显过拟合。

> 由于本文数据为时间序列，若采用随机划分会造成未来信息泄漏。因此本文采用**滚动前向验证**：以第 1 至 $t$ 期数据训练、预测第 $t+1$ 期，逐步向前滚动。该方式保证任何一次预测均只使用历史信息。

**结论与建议**〔推理〕：
1. 交叉验证与超参数搜索在国赛优秀论文中**基本没有规范使用先例**，国赛队伍普遍只写"用附件数据做了检验"或"拟合优度 $R^2=\cdot$"；
2. **这恰恰是一个低成本的加分点**：规范地做一次 10 折 CV 并报告"均值 ± 标准差"、画出超参数敏感性曲线，就能在"模型检验"章节显著高于平均水平；
3. 但要注意**国赛数据量往往很小**（如 2017C 只有 35 组），此时应在论文中**明确说明样本量限制**，并同时用残差分析、灵敏度分析等传统手段佐证，而不是把 CV 当成唯一证据；
4. **时间序列题（如 2023E176 类水文题）绝对不能用随机切分做 CV**，必须用滚动前向验证或明确声明不做泛化误差估计。
