# EM算法与MCMC

## 1. 算法解决什么问题

这两类方法解决的是同一类问题的两个侧面：**当模型里存在"看不见的东西"时，如何做参数估计与不确定性量化**。

- **EM 算法（Expectation–Maximization）**：在**含隐变量**或**数据缺失**时求**最大似然估计**。它把难解的对数似然拆成两步交替进行：
  - **E 步**：在给定当前参数下，计算隐变量的**后验期望**（即"补全"缺失信息）；
  - **M 步**：用补全后的数据求参数的**最大似然估计**（通常有闭式解）。
  典型用途：高斯混合模型（GMM）参数估计、隐马尔可夫模型（HMM，Baum–Welch）、缺失数据插补、混合回归。

- **MCMC（Markov Chain Monte Carlo）**：当后验分布**无法解析计算**时，通过构造一条**马尔可夫链**使其平稳分布恰为目标后验，从链中抽样来近似后验。两大主流：
  - **Metropolis–Hastings**：提议一个新样本，以 $\alpha=\min\{1,\ \frac{p(\theta')q(\theta|\theta')}{p(\theta)q(\theta'|\theta)}\}$ 接受；
  - **Gibbs 抽样**：逐维从条件后验中抽样（Metropolis 的特例，接受率恒为 1）。
  典型用途：贝叶斯参数估计、后验预测区间、分层模型、复杂似然的统计推断。

**国赛定位**〔归纳〕：
- **EM 算法**：全语料检索**零命中**（见第 11 节）——**不建议在国赛中作为主打方法**，除非题目明确需要混合模型/缺失数据处理。
- **MCMC**：语料中有**少数几处真实使用**（贝叶斯模型求解、解的精修、Gibbs 抽样仿真），是**可以写进论文的加分项**，但必须把"为什么需要 MCMC"（后验无解析解）讲清楚。

**国赛里最常见的两类需求**：
1. **参数估计 + 不确定性**：不只给点估计，还要给**置信区间/后验区间**——这是 MCMC 相对最小二乘的核心增量；
2. **含缺失值/隐类别的建模**：数据里有"看不见的类别标签"（如用户分群）时，EM 是标准解法。

## 2. 输入与输出

### EM
- **输入**：观测数据 $X$；**模型形式**（含隐变量 $Z$ 的联合分布 $p(X,Z\mid\theta)$）；初值 $\theta^{(0)}$；收敛容差 $\varepsilon$；最大迭代 $N_{\max}$。
- **输出**：$\hat\theta_{\text{MLE}}$；每次迭代的对数似然 $\ell(\theta^{(t)})$ 序列（**必须单调不减**，这是 EM 的收敛证书）；隐变量的后验概率（如 GMM 的软分配 $\gamma_{ik}$）。

### MCMC
- **输入**：**目标后验的未归一化密度** $\tilde p(\theta\mid X)\propto p(X\mid\theta)p(\theta)$（**只需正比常数，不必归一化**——这是 MCMC 最大的便利）；提议分布（MH）；初值；链长 $N$、预热期 $N_{\text{burn}}$、稀疏间隔 $\text{thin}$；先验分布。
- **输出**：后验样本 $\{\theta^{(t)}\}$；**后验均值/中位数**（点估计）；**95% 可信区间**（2.5% 与 97.5% 分位数）；**后验预测分布**（对未来观测的预测）；诊断量：**接受率、迹图（trace plot）、Gelman–Rubin $\hat R$、有效样本量 ESS**。

**国赛论文必须给出的 MCMC 诊断**（否则结果不可信）：
1. **迹图**：链是否稳定在某个水平带内（无趋势、无周期性跳跃）；
2. **接受率**：MH 在 0.2～0.5 之间为宜（高维时 0.234 是理论最优）；
3. **多条链的 $\hat R$**：应 $<1.1$；
4. **有效样本量 ESS**：应 $\ge$ 几百。

## 3. 算法步骤（伪代码级）

### 3.1 EM 算法

1. 输入数据 $X$、模型、初值 $\theta^{(0)}$、容差 $\varepsilon$、$N_{\max}$；$t\leftarrow0$。
2. **E 步（期望）**：对每个样本 $i$，计算隐变量的后验
   $$Q_i(z)\leftarrow p(z\mid x_i,\theta^{(t)})=\frac{p(x_i,z\mid\theta^{(t)})}{\sum_{z'}p(x_i,z'\mid\theta^{(t)})}$$
3. **M 步（最大化）**：求使期望完全数据对数似然最大的参数
   $$\theta^{(t+1)}\leftarrow\arg\max_{\theta}\sum_i\sum_z Q_i(z)\ln p(x_i,z\mid\theta)$$
4. **收敛检验**：计算 $\ell(\theta^{(t+1)})=\sum_i\ln\sum_z p(x_i,z\mid\theta^{(t+1)})$；
   - 若 $\ell(\theta^{(t+1)})-\ell(\theta^{(t)})<\varepsilon$，或 $t\ge N_{\max}$，终止；
   - **若似然下降，说明实现有 bug**（EM 理论保证单调不减）。
5. $t\leftarrow t+1$，回到 E 步。
6. **输出** $\hat\theta$ 与似然序列。
7. **多初值重启**（**必做**）：EM 只保证收敛到**局部最优**（或鞍点），必须用 $K=10\sim50$ 组初值重复运行，取似然最大者，并报告"命中最优解的初值比例"。

### 3.2 Metropolis–Hastings（MCMC）

1. 输入未归一化后验 $\tilde p(\theta\mid X)$、提议分布 $q(\cdot\mid\cdot)$（常用对称随机游走 $\mathcal N(\theta^{(t)},\sigma^2I)$）、初值 $\theta^{(0)}$、链长 $N$。
2. 对 $t=0\dots N-1$：
   1. **提议**：$\theta'\sim q(\theta'\mid\theta^{(t)})$。
   2. **计算接受比**：$\alpha=\min\left\{1,\ \dfrac{\tilde p(\theta'\mid X)\,q(\theta^{(t)}\mid\theta')}{\tilde p(\theta^{(t)}\mid X)\,q(\theta'\mid\theta^{(t)})}\right\}$（对称提议时比例项为 1）。
   3. **接受/拒绝**：取 $u\sim U(0,1)$；若 $u<\alpha$ 则 $\theta^{(t+1)}\leftarrow\theta'$，否则 $\theta^{(t+1)}\leftarrow\theta^{(t)}$。
   4. 记录 $\theta^{(t+1)}$ 与是否接受。
3. **丢弃预热期**：去掉前 $N_{\text{burn}}$（通常前 20%～50%）个样本。
4. **稀疏化（可选）**：每隔 $\text{thin}$ 个样本取一个，降低自相关。
5. **计算后验统计量**：均值、中位数、2.5%/97.5% 分位数（可信区间）。
6. **诊断**：画迹图；统计接受率；跑 $m=4$ 条不同初值的链计算 $\hat R$。
7. **自适应调参（可选）**：若接受率过高（$>0.5$）说明提议步长太小 → 增大 $\sigma$；过低（$<0.2$）→ 减小 $\sigma$。

### 3.3 Gibbs 抽样

1. 把参数分组 $\theta=(\theta_1,\dots,\theta_d)$，要求每组对**其余参数的条件后验**可以采样（常见为共轭结构）。
2. 对 $t=0\dots N-1$，对 $j=1\dots d$：
   1. $\theta_j^{(t+1)}\sim p(\theta_j\mid \theta_1^{(t+1)},\dots,\theta_{j-1}^{(t+1)},\theta_{j+1}^{(t)},\dots,\theta_d^{(t)},X)$。
3. 其余同 MH（预热、稀疏化、诊断）。
4. **Gibbs 是 MH 的特例**（接受率恒为 1），但当条件分布能直接采样时比 MH 高效得多。

### 3.4 国赛实用组合：EM 求初值 + MCMC 做不确定性

1. **先用 EM（或最大似然/最小二乘）求点估计** $\hat\theta$，作为 MCMC 的**初始值**（大幅缩短预热期）。
2. 指定先验（弱信息先验或题目给出的物理范围）。
3. 用 MH / Gibbs 跑 MCMC，得到后验样本。
4. 报告：点估计（后验均值）＋ 95% 可信区间 ＋ 后验预测区间。
5. **对比**：把后验均值与 EM/MLE 的点估计对比，若接近则说明结果稳健（这是论文里很好的验证段）。

## 4. 复杂度与收敛性

| 方法 | 时间复杂度 | 空间复杂度 | 收敛性 |
|---|---|---|---|
| EM | 每次迭代 $O(N\cdot K\cdot d)$（$N$ 样本、$K$ 隐状态、$d$ 维参数）；迭代次数通常 $10\sim10^3$ | $O(NK)$（存后验） | **似然单调不减**（理论保证）；**只收敛到局部最优或鞍点，不保证全局最优**；收敛速率线性，速率取决于缺失信息比例 |
| Metropolis–Hastings | 每次迭代 1 次后验密度计算 $O(1)$；总 $O(N\cdot\text{cost})$ | $O(N)$（存全部样本） | **遍历性条件下收敛到目标后验（几乎必然）**；但**无有限步收敛保证**；高维时接受率急剧下降 |
| Gibbs 抽样 | 每次迭代 $d$ 次条件采样 | $O(N)$ | 同上；条件分布有闭式时效率高 |

**必须写进论文的结论**：
1. **EM 只保证似然单调不减，不保证收敛到全局最优**——它收敛到**局部极大或鞍点**。**必须多初值重启**，论文中不能写"求得全局最优参数"。
2. **EM 的收敛速率是线性的**，且速率与"缺失信息比例"成正比：缺失信息越多，收敛越慢。可以在论文中提到这一性质来解释迭代次数。
3. **MCMC 不是优化算法**：它**采样**而非求极值。它给出的是后验分布，因此**天然提供不确定性量化**——这是它相对最小二乘/EM 的核心增量。
4. **MCMC 在无限长时间下才收敛到目标后验**（在遍历性条件下）；有限链长只给出近似。因此**必须报告诊断量**（$\hat R$、ESS、接受率、迹图）。
5. **MH 在高维下效率急剧下降**（接受率随维数指数衰减），需要自适应提议、Hamiltonian Monte Carlo（HMC/NUTS）等改进。
6. **Gibbs 的条件分布若相关性强，也会混合很慢**（"慢混合"问题）。
7. MCMC 的误差是 $O(1/\sqrt{\text{ESS}})$ 量级：**要精度提高 10 倍，样本量要提高 100 倍**。

## 5. 参数与调参要点

### EM

| 参数 | 推荐取值 | 依据 |
|---|---|---|
| 初值 $\theta^{(0)}$ | **多初值重启 $K=10\sim50$ 组**，取似然最大者；GMM 可用 k-means 结果作初值 | 〔推理〕通用经验 |
| 收敛容差 $\varepsilon$（对数似然增量） | $10^{-6}\sim10^{-8}$（相对增量） | 〔推理〕通用经验 |
| 最大迭代 $N_{\max}$ | 100～1000 | 〔推理〕通用经验 |
| 正则化 | 协方差矩阵加 $\epsilon I$（$\epsilon=10^{-6}$）防奇异 | 〔推理〕通用经验 |
| 停止判据 | 似然增量 $<\varepsilon$ **或**参数变化 $<\varepsilon$ | 〔推理〕通用经验 |

### MCMC

| 参数 | 推荐取值 | 依据 |
|---|---|---|
| **提议步长 $\sigma$（随机游走 MH）** | **按接受率标定到 0.2～0.5**（高维时理论最优约 0.234）；常用做法：预热期自动调整至目标接受率 | 〔推理〕通用经验 |
| **链长 $N$** | $10^4\sim10^6$（取决于 ESS 需求与单次似然代价） | 〔推理〕通用经验 |
| **预热期 $N_{\text{burn}}$** | 链长的 20%～50%；用迹图确认"已稳定"后再定 | 〔推理〕通用经验 |
| **稀疏间隔 thin** | 5～50（降低自相关与存储量；**注意 thin 不能提高 ESS**，只是省内存） | 〔推理〕通用经验 |
| **并行链数 $m$** | 4～8 条（**用于计算 Gelman–Rubin $\hat R$，这是 MCMC 收敛的标准诊断**） | 〔推理〕通用经验 |
| **收敛判据** | $\hat R<1.1$，且迹图无明显趋势 | 〔推理〕通用经验 |
| **有效样本量 ESS** | $\ge$ 400（最低），建议 $\ge10^3$ | 〔推理〕通用经验 |
| **先验选择** | 弱信息先验（如正态 $\mathcal N(0,100^2)$、均匀分布覆盖物理可行域）；**论文中必须写明先验及其影响** | 〔推理〕通用经验 |
| **似然数值稳定性** | 对数似然里加 `1e-12` 防 log(0)；用 log-sum-exp 技巧 | 〔推理〕通用经验 |

**调参坑**：
- **EM 用单一初值** → 收敛到局部最优而毫不知情。**这是最常见的错误**。
- **EM 的似然在下降** → 一定是 E 步或 M 步实现有 bug（EM 理论保证单调不减）。
- **MCMC 步长固定不调** → 接受率 0.01（几乎不移动）或 0.99（原地随机游走），两种情况都得不到有效后验。
- **忘记丢弃预热期** → 后验统计量被初值污染。
- **报点估计不报区间** → 浪费了 MCMC 最大的价值（不确定性量化）。
- **只跑一条链** → 无法计算 $\hat R$，无法论证收敛。
- **把 Metropolis 准则说成"模拟退火"或反之** → 概念混淆（见第 11 节的重要提醒）。
- **对未归一化后验忘了"只需正比"这一便利** → 白白去算归一化常数（通常算不出来）。

## 6. 优点

**EM**
1. **数值稳定**：每步都提高似然，不会像梯度法那样发散或震荡。
2. **无需步长/学习率**：没有"调步长"的烦恼。
3. **M 步常有闭式解**（GMM、HMM），实现简洁。
4. **天然处理缺失数据**：E 步就是在"补全"缺失信息。
5. **保证似然单调不减**：单调性本身就是可写进论文的收敛性证据。

**MCMC**
6. **只需未归一化后验**：这是它最优雅的性质——不必计算归一化常数（那通常是不可积的）。
7. **天然给出不确定性**：后验分布、可信区间、后验预测分布一次全给，**远强于点估计**。
8. **理论基础坚实**：收敛性有 MCMC 遍历定理支撑。
9. **适用面极广**：任何能写出似然与先验的模型都能用，包括复杂分层模型。
10. **可诊断**：$\hat R$、ESS、迹图、接受率——有完整的收敛诊断工具箱，这在元启发式里是罕见的。
11. **国赛语料中有真实使用**：2018A 用 MCMC 精修解、2023C126 用 WinBUGS 做 MCMC 贝叶斯预测、2013A 用 Gibbs 抽样仿真。

## 7. 缺点

**EM**
1. **只收敛到局部最优**，且**收敛速率线性**（缺失信息多时非常慢）。
2. **必须知道隐变量的条件分布形式**；非共轭结构时 M 步没有闭式解，需嵌入数值优化。
3. **不能给出不确定性**（只有点估计），标准误需额外用 Louis 方法或 Bootstrap。
4. **协方差可能退化**（GMM 中某个分量的方差趋于 0，似然趋于无穷）——著名的奇异性问题。

**MCMC**
5. **慢**：通常需要 $10^4\sim10^6$ 次似然计算，单次似然贵时完全跑不动。
6. **不保证有限步收敛**，必须靠诊断量判断，而**诊断量只能否定收敛，不能肯定收敛**。
7. **高维效率低**：MH 的接受率随维数急剧下降。
8. **强自相关**：相邻样本高度相关，有效样本量远小于链长。
9. **实现门槛高**：提议分布、先验、诊断都要对，写错了可能"看起来收敛但结果全错"。
10. **结果依赖先验**：先验选得不好会系统性偏置结论，而且必须诚实报告。
11. **国赛接受度不确定**：语料中命中很少（MCMC 5 处），评委可能不熟悉；**必须把"为什么需要它"讲透**。

## 8. 适用规模与适用条件

**EM 适用条件**：
- 模型**明确含有隐变量或缺失数据**；
- **完全数据**的对数似然有闭式 M 步（共轭结构）；
- 数据量 $N$ 中等（$10^2\sim10^6$），单次迭代便宜；
- **可以接受局部最优**，并愿意做多初值重启。

**MCMC 适用条件**：
- 需要**贝叶斯后验推断**（不只要点估计，还要区间）；
- 后验**无解析形式**（否则直接算）；
- **能计算未归一化的后验密度**（似然 × 先验）；
- 单次似然计算**便宜**（$\lesssim$ ms），因为要算 $10^4\sim10^6$ 次；
- 参数维数 $d\lesssim20$（MH）；更高维需要 HMC/NUTS 或 Gibbs；
- 模型是**分层/随机效应**结构（这是 MCMC 最有优势的场景）。

**适用规模**：
- EM：$N=10^2\sim10^6$，$K=2\sim50$ 个隐状态，$d=1\sim100$；迭代 10～1000 次。
- MCMC：链长 $10^4\sim10^6$，参数维数 $d=1\sim20$（MH）/ $1\sim100$（HMC）；单次似然 $\lesssim$ ms。

## 9. 不适用情况

**EM 不适用**：
- **没有隐变量、完全数据似然有闭式解**：直接求导即可，用 EM 是画蛇添足。
- **目标是全局最优**：EM 给不出；应多初值 + 全局优化。
- **M 步无闭式解且数值优化昂贵**：每次迭代都要跑一次内层优化，代价爆炸。
- **需要不确定性量化**：EM 不直接给；应用 Bootstrap 或 MCMC。
- **参数维数极高**：EM 迭代次数与维数耦合，会非常慢。

**MCMC 不适用**：
- **只需要点估计**：用 MLE/最小二乘/EM 快几个数量级。
- **单次似然计算昂贵（$>1$ 秒）**：$10^5$ 次计算需要一整天，比赛不可行。应改用**代理模型 + MCMC**（贝叶斯优化风格）或变分推断（VI）。
- **参数维数极高（$d>100$）**：MH 完全失效，需 HMC/NUTS 或变分推断。
- **离散组合空间很大**：MCMC 可以但混合极慢；改用 SA/GA。
- **题目只要求"给一个数"**：MCMC 的复杂度换不来收益，且论文篇幅会失衡。
- **需要可复现的确定结果**：MCMC 是随机的，必须固定种子并报告诊断量。
- **时间预算紧张的国赛现场**：除非你在前一天已经写好并调通代码，否则不要在比赛现场现学 MCMC。

## 10. Python / MATLAB 实现要点

**Python**

*EM*
- 没有统一库；`sklearn.mixture.GaussianMixture` 内部就是 EM，可直接用（`n_init` 控制初值重启次数，**默认 1，应改成 10～50**）。
- `sklearn.mixture.GaussianMixture(n_components=K, n_init=20, max_iter=500, tol=1e-6, init_params='kmeans')`——**用 k-means 初始化能显著提高收敛质量**。
- 手写 GMM-EM 注意：协方差矩阵加 `reg_covar=1e-6` 防奇异；用 `logsumexp` 算混合权重的 E 步防下溢。
- **必做检查**：把每次迭代的 `log_likelihood_` 画出来，确认单调不减。

*MCMC*
- **PyMC**（`import pymc as pm`）是现代首选：`with pm.Model():` → 定义先验与似然 → `pm.sample(draws=2000, tune=1000, chains=4, target_accept=0.9)` → 自动输出 $\hat R$、ESS、迹图。**一行代码就有完整诊断**。
- **numpyro / PyStan**：NUTS（HMC）实现，高维更强。
- `emcee`：轻量 MH 集成采样器，适合自写似然函数。
- 手写 MH 骨架（约 30 行）：
  1. `theta = np.zeros((N, d))`；`theta[0] = theta0`；
  2. `for t in range(N-1):` → `prop = theta[t] + sigma*np.random.randn(d)` → `log_alpha = logpost(prop) - logpost(theta[t])`（对称提议）→ `if np.log(np.random.rand()) < log_alpha: theta[t+1]=prop else: theta[t+1]=theta[t]`。
  3. **在对数域比较**（`log_alpha` vs `np.log(u)`），避免 `exp` 下溢。
- **诊断必备**：`pip install arviz` → `az.plot_trace(idata)`、`az.rhat(idata)`、`az.ess(idata)`。
- 采样后**必须**：丢预热、算 95% 区间、画后验分布直方图、做后验预测检验。

**MATLAB**
- 统计与机器学习工具箱中有 `fitgmdist(X, K, 'Replicates', 20, 'RegularizationValue', 1e-6)`——**`Replicates` 就是多初值重启次数，默认 1，务必调大**。
- `mvnrnd`、`mvnpdf` 用于高斯混合。
- **MATLAB 没有内置 MCMC**（`slicesample` 是切片采样，可用于一维/低维后验；`mhsample` 是 MH 采样器，R2019a 起提供）。
  - `samples = mhsample(x0, nsamples, 'logpdf', @logpost, 'proprnd', @proposal, 'symmetric', true, 'burnin', 1000, 'thin', 5)`。
  - `slicesample` 无需调步长，适合低维后验。
- 诊断：手写 $\hat R$ 计算（多链方差 / 链内方差之比）；画迹图用 `plot(chain)`。
- 若国赛语料中的做法是 BUGS/WinBUGS（见 2023C126），可在 MATLAB 之外的 `OpenBUGS/JAGS` 中建模（Gibbs 抽样），论文中要写清软件与链长。
- 自己手写 MH 时，**先验与似然都必须在对数域实现**，否则浮点下溢会让链卡死。

### 配图建议
1. **痕迹图（trace plot）**：多条链叠画，横轴迭代、纵轴参数值——**MCMC 论文的第一必备图**。
2. **后验边际分布图**：每个参数的直方图（核密度），标注均值与 95% 分位数。
3. **后验联合分布等高线图**（两参数）：直接展示参数相关性。
4. **收敛诊断图**：横轴迭代、纵轴 $\hat R$ 或 ESS，展示随迭代收敛。
5. **后验预测检验图**：观测数据直方图 vs 后验预测样本分布，**这是贝叶斯建模最有说服力的验证图**。
6. **EM**：对数似然随迭代单调上升的曲线（**必须单调，否则说明实现有误**）+ 多初值收敛结果的箱线图。
