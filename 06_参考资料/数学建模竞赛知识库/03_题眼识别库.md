# 03_题眼识别库

> **什么是题眼**：题干里那个"一旦出现，就基本锁定某类数学模型"的句子或短语。它的作用是**把自然语言的题目条件翻译成数学结构**。
> **证据标注**：〔原文〕= 真题/论文原句；〔归纳〕= 由多份资料归纳；〔推理〕= 合理推导。

## 1. 优化族题眼

### 1.1 「使总成本最小 / 使总费用最小 / 最经济」

- **题眼原句**：〔原文·2000B〕"请制定一个主管道钢管的订购和运输计划，使总费用最小（给出总费用）"；〔原文·2021C〕"为该企业制定未来 24 周每周最经济的原材料订购方案"；〔原文·2026C〕"尽可能节省微网的购电费用"。
- **对应问题类型**：优化类（目标是货币成本的加性函数）。
- **数学结构**：min Σ c_i x_i，其中 c_i 为单位成本、x_i 为决策量。
- **推荐模型**：线性规划 / 混合整数线性规划（成本可线性分解时）；运输问题与最小费用流（网络上的流量分配）。
- **推荐算法**：单纯形 / 内点法；分支定界（含整数变量）；大规模用 Lingo / Gurobi / CBC；小规模用枚举校验。
- **备选模型**：动态规划（分阶段决策且状态可压缩，如多期订购）；鲁棒优化（成本含不确定参数）。
- **不推荐模型**：遗传算法等元启发式——**小规模 LP/MILP 用求解器即可得全局最优，用元启发式反而丢精度且无法证明最优性**。
- **常见坑**：① 成本项漏项（运输费、装卸费、违约费、贴现）；② 单位不统一（万元 vs 元）；③ 分段费率未做分段线性化；④ 忘记非负之外的实际上下界。

### 1.2 「使……尽可能大 / 收益最大 / 效益最大」

- **题眼原句**：〔原文·2026E〕"合理利用有限的广告资金实现广告投放综合效益的最大化"；〔原文·2023C〕"使得商超收益最大"；〔原文·2012B〕"使小屋的全年太阳能光伏发电总量尽可能大"。
- **对应问题类型**：优化类（收益/产量/效益的加性函数）。
- **推荐模型**：线性/整数规划；收益含乘积项（价格×销量）→ 非线性规划或分段线性化；含随机需求 → 随机规划 / 报童模型。
- **推荐算法**：MILP 求解器；非线性 → SQP / 内点法；含不确定性 → 情景法 + LP。
- **备选模型**：二次规划（收益函数二次可微时）。
- **不推荐模型**：对非凸目标直接上梯度法（易陷局部最优且无说明）。
- **常见坑**：① 收益与成本混淆（未做净收益）；② 忽视"不超过预算"这类上界约束；③ 目标尺度差异导致求解器数值问题（应先无量纲化）。

### 1.3 「在……前提下，使……」（字典序 / 分层目标）

- **题眼原句**：〔原文·2026B-Q3〕"要求在确保所有干扰源被清除的前提下，完成任务的时间越短越好"；〔原文·2021D〕"优先考虑切割损失，要求切割损失尽量小……其次考虑用户要求"；〔原文·2023A〕"在达到额定功率的条件下，单位镜面面积年平均输出热功率尽量大"。
- **对应问题类型**：多目标优化中的**字典序多目标**（不是加权多目标！）。
- **推荐模型**：字典序（Lexicographic）多目标规划；ε-约束法；分层优化。
- **推荐算法**：逐层求解——第 1 层求 min f1 得 f1*，第 2 层加约束 f1 ≤ f1*+δ 再求 min f2。
- **备选模型**：大 M 加权法（把第一目标加权到极大），但**必须说明权重选择依据**。
- **不推荐模型**：简单加权和（会把"前提"变成"可以违反一点点"，与题意不符）。
- **常见坑**：① 用加权和替代字典序，导致主目标被牺牲；② 第 1 层容差 δ 无依据。

### 1.4 「资源有限 / 预算不超过 / 不超过……上限」

- **题眼原句**：〔原文·2026E〕"完成但不超过预算资金"；〔原文·2026C·附录1〕"储能设备的最大容量为 12000 kWh，最大充放电功率为 5000 kW"。
- **对应问题类型**：约束优化（关键是"发现约束"）。
- **推荐模型**：在 LP/MILP/NLP 中加入容量约束与状态方程约束。
- **推荐算法**：同 1.1；含状态转移时用 LP（状态方程线性）或动态规划。
- **备选模型**：拉格朗日松弛（约束复杂时给出上界）。
- **不推荐模型**：无约束优化。
- **常见坑**：① **题目把约束写在附录/附件说明/表格脚注里**（2026 A 题附录 2/3/4、2026 C 题附录 1 都是这种位置）；② 容量约束与功率约束混淆（kWh vs kW）；③ 忘记状态变量的时间耦合（今天用完明天就少）。

### 1.5 「选择哪些 / 是否 / 撤销 / 取舍」

- **题眼原句**：〔原文·2026D〕"一个用频计划只能调整其中一个参数或撤销"；〔原文·2021C〕"该企业应至少选择多少家供应商"；〔原文·2024B〕"对零配件（零配件1 和/或零配件2）是否进行检测"。
- **对应问题类型**：组合优化 / 0-1 规划。
- **数学结构**：x_i ∈ {0,1}，或带互斥约束 x_i + x_j ≤ 1。
- **推荐模型**：0-1 整数规划（MILP）；集合覆盖 / 背包；含逻辑条件时用大 M 法线性化。
- **推荐算法**：分支定界；割平面；规模大时用列生成或"启发式 + 下界论证"。
- **备选模型**：贪心 + 局部搜索（必须给与下界的 gap）。
- **不推荐模型**：连续 LP 后四舍五入（会产生不可行解）。
- **常见坑**：① 忘记整数约束；② **"只能调一个参数"这类"或"约束**未用 0-1 变量刻画；③ 撤销惩罚未进入目标函数。

### 1.6 「如何安排 / 什么时候做 / 排班 / 调度」

- **题眼原句**：〔原文·1995B〕"请给出一个（或几个）具体的调度方案"；〔原文·2017D〕巡检线路的排班；〔原文·2026C〕"在每天 0:00 制定微网当天的计划购电策略"。
- **对应问题类型**：调度类。
- **推荐模型**：MILP（时间索引变量）；RCPSP；周期性调度；状态方程型调度（储能）。
- **推荐算法**：MILP 求解器；约束规划；滚动时域（MPC）；列表调度 + 仿真评估。
- **备选模型**：离散事件仿真评估候选方案；遗传算法（大规模时）。
- **不推荐模型**：单纯排队论（除非题目明确服务过程为随机流）。
- **常见坑**：① 漏掉"切换时间 / 启动成本"；② 资源容量上限（如 1995B 的"每两个相邻工作点之间最多只能容纳 2 台"〔原文〕）；③ 只给排班表不给**调度规则说明**（1995B 明确要求）。

### 1.7 「最优控制 / 分阶段决策 / 轨迹设计」

- **题眼原句**：〔原文·2014A〕"确定嫦娥三号的着陆轨道和在 6 个阶段的最优控制策略"；〔原文·2025A〕"设计烟幕干扰弹的投放策略"。
- **对应问题类型**：最优控制 / 动态优化。
- **推荐模型**：Pontryagin 极大值原理；动态规划（离散时间）；直接法（控制离散化 → NLP）。
- **推荐算法**：直接配点法 → NLP 求解器；打靶法；状态维数低时用动态规划。
- **备选模型**：参数化 + 元启发式（工程常用，须说明最优性无保证）。
- **不推荐模型**：静态优化（丢掉时序结构）。
- **常见坑**：① 状态方程与代价函数不一致；② 终端约束遗漏；③ 控制量物理约束缺失。

## 2. 预测族题眼

### 2.1 「预测未来 N 年 / N 天 / N 小时」

- **题眼原句**：〔原文·2011C〕"预测从 2011 年至 2035 年的山东省职工的年平均工资"；〔原文·2023E〕"预测分析该水文站未来两年水沙通量的变化趋势"。
- **对应问题类型**：预测类（长期 / 短期外推）。
- **推荐模型**：长期（年尺度、样本少）→ 灰色 GM(1,1)、Logistic / 饱和曲线、Leslie 型递推；短期（日/小时尺度）→ ARIMA/SARIMA、指数平滑、机器学习。
- **推荐算法**：最小二乘 / 极大似然；AIC/BIC 定阶；灰色模型的级比检验与后验差检验；滚动预测。
- **备选模型**：组合预测（误差倒数加权）；状态空间 + 卡尔曼滤波。
- **不推荐模型**：深度网络（年尺度样本常只有几十点，必过拟合）。
- **常见坑**：① 不做平稳性 / 级比检验；② 用 R² 报时序精度（应用 MAPE / RMSE）；③ 长期预测不给区间；④ 把"预测"与"情景假设"混为一谈（2011C 明确要求"做出你认为简化、合理的假设"）。

### 2.2 「估计 / 反演 / 确定参数 / 标定」

- **题眼原句**：〔原文·2015A〕"建立数学模型确定直杆所处的地点"；〔原文·2017A〕CT 系统参数标定；〔原文·2026A〕附录给出物性经验公式（需拟合 / 反演系数）。
- **对应问题类型**：参数估计 / 反问题。
- **推荐模型**：最小二乘 / 加权最小二乘；极大似然；贝叶斯反演；Tikhonov 正则化；MCMC。
- **推荐算法**：Levenberg-Marquardt；lsqnonlin / scipy.optimize.least_squares；全局搜索（差分进化）避免局部最优；MCMC 给后验分布。
- **备选模型**：网格搜索 + 插值（低维参数时最稳）。
- **不推荐模型**：纯梯度法处理多峰目标（会陷局部最优）。
- **常见坑**：① **参数可辨识性未讨论**（不同参数组合给出相同输出）；② 未做初值敏感性；③ 只给点估计不给不确定度；④ 残差未诊断。

### 2.3 「随时间变化规律 / 变化趋势」

- **题眼原句**：〔原文·2020A〕"请对焊接区域的温度变化规律建立数学模型"；〔原文·2026A〕"建立预热平衡阶段药材温度和水分浓度变化规律的数学模型"。
- **对应问题类型**：机理建模（ODE/PDE）**或**时间序列——需进一步判别。
- **判别规则**：若题目**给出了物理参数**（导热系数、比热、密度、扩散系数）→ 机理建模；若只给观测序列无参数 → 时间序列〔推理〕。
- **常见坑**：拿到"变化规律"就写 ARIMA，而题目其实给了物理参数——这是历年最常见的**题型误判**〔归纳〕。

## 3. 评价族题眼

### 3.1 「评价 / 评估 / 比较 / 排序 / 优劣」

- **题眼原句**：〔原文·2016B〕"请选取合适的评价指标体系，用以评价小区开放对周边道路通行的影响"；〔原文·2012A〕"分析附件 1 中两组评酒员的评价结果有无显著性差异，哪一组结果更可信"；〔原文·2024E〕"评价临时管控措施在两条主路上的效果"。
- **对应问题类型**：评价类。
- **推荐模型**：指标体系 + 赋权（AHP / 熵权 / CRITIC）+ 合成（TOPSIS / 灰色关联 / 模糊综合 / RSR）。
- **推荐算法**：判断矩阵特征向量 + CR 一致性检验；极差 / 向量归一化；欧氏距离；隶属度函数。
- **备选模型**：PCA 降维后评价；DEA（多投入多产出效率评价）。
- **不推荐模型**：直接对原始指标求和（未考虑量纲与方向）。
- **常见坑**：① 指标重复 / 共线；② 忘记正负向处理；③ 熵权法在指标差异过小时权重失真；④ 不做权重稳健性检验；⑤ **题目要求"分析合理性"时只给排序不做解释**（2026 E 题 Q1 就是"分析合理性"）。

### 3.2 「影响因素 / 相关性 / 关系模型 / 显著性」

- **题眼原句**：〔原文·2025C-Q1〕"分析胎儿 Y 染色体浓度与孕妇的孕周数和 BMI 等指标的相关特性，给出相应的关系模型，并检验其显著性"；〔原文·2012C〕"研究脑卒中发病率与气温、气压、相对湿度间的关系"。
- **对应问题类型**：回归类 / 统计推断。
- **推荐模型**：多元线性回归；广义线性模型；**混合效应模型（重复测量时必用）**；分位数回归；灰色关联（样本极少时）。
- **推荐算法**：最小二乘 / MLE；逐步回归 + AIC/BIC；VIF 共线性诊断；残差诊断；Bootstrap 置信区间。
- **备选模型**：随机森林 + SHAP（非线性且需重要性排序时）。
- **不推荐模型**：直接套线性回归而忽略分组结构（2025C 的同一孕妇多次检测）。
- **常见坑**：① 只报 p 值不报效应量；② 不做残差诊断；③ 把"显著性"与"重要性"混淆；④ 多重比较不校正（2025C Q4 用到 FDR 控制）。

### 3.3 「空间分布 / 不同区域的……程度」

- **题眼原句**：〔原文·2011A〕"给出 8 种主要重金属元素在该城区的空间分布，并分析该城区内不同区域重金属的污染程度"。
- **对应问题类型**：评价类 + 空间统计。
- **推荐模型**：地统计（克里金插值、变异函数）；内梅罗污染指数；单因子指数；空间聚类；核密度估计。
- **推荐算法**：反距离加权 / 克里金；空间自相关（Moran's I）。
- **常见坑**：① 不考虑空间自相关就做普通回归；② 插值外推超出数据范围；③ 污染指数标准未给依据（应引用国标）。

## 4. 机理族题眼

### 4.1 「温度分布 / 浓度分布 / 扩散 / 传热 / 漫延 / 浓度变化」

- **题眼原句**：〔原文·2026A〕"请建立预热平衡阶段药材温度和水分浓度变化规律的数学模型……给出 100、300、600、900、1200、1500、1800 s，到药材中心距离 0、0.5、1、1.5、2 cm 处的结果"；〔原文·2025D〕"建立突水水流在巷道的流动漫延模型"；〔原文·2020A〕"焊接区域的温度变化规律"。
- **对应问题类型**：偏微分方程类（时空场）。
- **数学结构**：抛物型 PDE：∂u/∂t = ∇·(D∇u) + S，配初始条件与边界条件。
- **推荐模型**：热传导方程 / 扩散方程（Fick 第二定律）；对流-扩散方程；反应-扩散方程；变物性版本（系数是 u 的函数）；移动边界版本（Stefan）。
- **推荐算法**：有限差分（隐式 / Crank-Nicolson）→ 三对角或带状方程组 → 追赶法 / 稀疏求解器；有限元（几何复杂时）；方法线（MOL）。
- **备选模型**：集总参数模型（Biot 数小时把物体视为等温体）；降阶模型（POD）。
- **不推荐模型**：时间序列预测（丢失空间维度，无法回答"距中心 x cm 处是多少"）；纯回归拟合（无外推能力）。
- **常见坑**：① **边界条件类型判断错**——给出"对流换热系数 h"就必须用 Robin 边界 −k·∂T/∂n = h(T−T∞)，不能写恒温；② 圆柱 / 球坐标 r=0 处 1/r·∂(r ∂T/∂r) 的奇异性；③ 变系数问题仍用显式格式；④ 只给结果不做**网格收敛性检验**；⑤ 移动边界不做坐标变换导致守恒量丢失；⑥ 单位换算（cm↔m、min↔s、℃↔K——**尤其指数中含 1/T 时必须用 K**）。

### 4.2 「随时间变化 / 增长 / 衰减 / 传播 / 冷却 / 速率」

- **题眼原句**：〔原文·1996A〕"建立数学模型分析如何实现可持续捕获"；〔原文·2003A〕SARS 传播；〔原文·2024A〕"请给出从初始时刻到 300 s 为止，每秒整个舞龙队的位置和速度"。
- **对应问题类型**：ODE / 动力系统类。
- **推荐模型**：一阶 / 高阶 ODE；SIR/SEIR；Leslie 递推；牛顿冷却；几何运动学方程。
- **推荐算法**：能解析解则给解析式；数值解用 RK4 / ode45 / BDF；参数辨识；相图与稳定性。
- **常见坑**：① 刚性方程用显式 Euler；② 不检验守恒量；③ 参数无来源；④ 不解释长期行为（平衡点 / 周期 / 发散）。

### 4.3 「运动 / 轨迹 / 几何关系 / 遮蔽 / 相交」

- **题眼原句**：〔原文·2025A〕"每架无人机投放两枚烟幕干扰弹至少间隔 1 s……云团中心 10 m 范围内的烟幕浓度在起爆 20 s 内可为目标提供有效遮蔽"；〔原文·2024A〕板凳龙运动学；〔原文·2026B〕示向度与交会定位。
- **对应问题类型**：几何 / 解析类 + 运动学。
- **推荐模型**：参数方程描述轨迹；向量与射线-面 / 射线-体相交判定；遮蔽条件化为几何不等式；二分法求有效遮蔽时间区间。
- **推荐算法**：解析求交 + 二分 / 牛顿求根；时间离散扫描 + 事件检测；多起点局部优化。
- **常见坑**：① 遮蔽判定的"充分必要"未论证（2025A 优秀论文先证明"有效遮蔽时间区间是连续区间，且只需判断圆柱体上下底面是否被完全遮蔽"〔原文〕）；② 忽略重力与匀速下沉的叠加；③ 时间区间端点处理。

## 5. 网络与路径族题眼

### 5.1 「网络 / 节点 / 连线 / 连通 / 相邻」

- **题眼原句**：〔原文·2025D〕"图 2 是一个矿井巷道网络的示意图，其中黑点表示巷道断面底边的中点"；〔原文·1998B〕灾情巡视公路网。
- **对应问题类型**：图论类。
- **推荐模型**：邻接矩阵 / 关联矩阵；连通性与连通分量；中心性；最短路与最小生成树。
- **常见坑**：① 有向 / 无向混淆；② 端点相接是否算邻接（2025D 与 2026D 都必须写清）；③ 不检查连通性。

### 5.2 「冲突 / 互斥 / 干扰 / 不能同时」

- **题眼原句**：〔原文·2026D〕"当两个用频计划的时间区间和频段区间都存在交叠时，则判定它们之间存在时频冲突"；〔原文·1994B〕"若二者相对应的 5 个槽的高度中有 4 个相同……则可能互开"。
- **对应问题类型**：图论 + 组合优化（冲突图）。
- **推荐模型**：冲突图 G=(V,E)；图着色；最大独立集；最小顶点覆盖；区间图上的贪心。
- **推荐算法**：贪心着色 / DSATUR；分支定界求独立集；若识别出是区间图则用多项式算法。
- **不推荐模型**：直接上遗传算法而不先分析图的结构（丧失可证明的最优性）。
- **常见坑**：① **区间端点规则未定义**（2026D 附件用半开区间 [80,90)、[35,40)，端点相接不算重叠）〔推理，据附件格式〕；② 周期性占用只检查第一次时间区间（实际要检查全部"使用次数"次占用）；③ 撤销 / 调整代价未加权。

### 5.3 「路线 / 巡视 / 遍历 / 逃生 / 巡游」

- **题眼原句**：〔原文·2025D〕"协助安全生产部门为各矿工设计最佳逃生路径"；〔原文·1998B〕"设计总路程最短且各组尽可能均衡的巡视路线"；〔原文·2026B〕"完成任务的时间越短越好"。
- **对应问题类型**：路径规划类。
- **推荐模型**：最短路（含时变权）；TSP/MTSP；VRP；覆盖路径；栅格 A*。
- **推荐算法**：Dijkstra（静态非负权）；时间展开图 + Dijkstra（时变权）；A* + 启发式；2-opt / 插入法（TSP 类）。
- **不推荐模型**：静态最短路直接用于**时变网络**（2025D 的巷道水位随时间上升，边权是 t 的函数）。
- **常见坑**：① 是否要求回到起点；② 时变权处理；③ 路径可行性未回代验证。

### 5.4 「搜索 / 发现 / 定位未知目标」

- **题眼原句**：〔原文·2026B-Q3〕"现派出一只机器狗从原点出发，测向机初始频道为 1，对目标区域中的干扰源进行自动定位并清除"；〔原文·2026B-Q4〕"既有全向干扰源，又有定向干扰源……定向方向也未知"。
- **对应问题类型**：在线搜索 + 路径规划 + 决策策略（搜索论 / 最优搜寻）。
- **推荐模型**：搜索论（给定先验分布与检测函数，最大化发现概率）；贝叶斯信息更新（每次检测后更新目标后验）；覆盖路径规划（牛耕式 / 螺旋式）；部分可观测马尔可夫决策过程（POMDP）形式化。
- **推荐算法**：贪心信息增益（下一检测点选使后验熵最小者）；螺旋 / 牛耕扫描基线；滚动时域重规划；蒙特卡洛模拟评估策略。
- **备选模型**：把目标视为静态，化为"覆盖 + 定位"两阶段策略。
- **不推荐模型**：一次性离线 TSP（目标是逐步发现的，无法离线规划）。
- **常见坑**：① 忽略"移动中无法检测"（必须停下来 5 s）〔原文〕；② 忽略频道切换 1 s 的累计代价；③ 忽略"距离 ≤5 m 且角度覆盖内则无法获得示向度，可直接清除"这一特殊规则〔原文〕；④ 定向干扰源"有效覆盖角度范围为定向方向两侧各 90°"，在其外检测不到信号，**若把 no_signal 当成"无目标"会误删区域**〔推理〕。

### 5.5 「交会定位 / 示向度 / 方位 / 角度测量」

- **题眼原句**：〔原文·2026B-Q1〕"已知若干个检测点坐标及某干扰源关于这些检测点的示向度，请给出采用交会定位法计算多边形定位区域直径（即区域内任意两点之间距离的最大值）的算法"；〔原文·2022B〕"纯方位无源定位……该无人机与任意两架发射信号无人机连线之间的夹角"。
- **对应问题类型**：几何定位 + 误差传播。
- **推荐模型**：交会定位（两条以上方位线的交点）；误差带 / 可行域（±1° 误差形成的四边形区域）；最小二乘方位定位；凸多边形直径计算（旋转卡壳）。
- **推荐算法**：射线求交（解析）；凸包 + 旋转卡壳求直径 O(n log n)；蒙特卡洛评估误差影响。
- **备选模型**：加权最小二乘 / 最大似然定位（多测量值融合）。
- **不推荐模型**：只取两条射线求单点（忽略 ±1° 误差，得不出"定位区域"）。
- **常见坑**：① 忽略角度误差形成的是**区域**而非点；② 方位角定义（2026B 定义"x 轴正向逆时针旋转"，与常规罗盘方位角不同）〔原文〕；③ 平行射线无法交会；④ 计算"多边形定位区域直径"时把非凸多边形直接取顶点最大距离（错，需先求凸包）。

## 6. 随机与统计族题眼

### 6.1 「随机 / 误差 / 概率 / 置信度」

- **题眼原句**：〔原文·2024B-Q1〕"在 95% 的信度下认定零配件次品率超过标称值，则拒收这批零配件"；〔原文·2026B·附录2〕"所有这些误差在 [−1°, 1°] 范围内"；〔原文·2024D〕"潜艇中心实际位置的 3 个坐标是相互独立的随机变量……Z 服从单边截尾正态分布"。
- **对应问题类型**：概率统计类。
- **推荐模型**：假设检验；序贯抽样（SPRT）；贝叶斯推断；误差传播（一阶 / 二阶）；蒙特卡洛；截尾分布。
- **推荐算法**：二项 / 正态检验；功效分析与样本量计算；Bootstrap；MCMC；随机抽样积分。
- **常见坑**：① 样本量不给功效分析（2024B 要求"检测次数尽可能少"的抽样方案，必须做功效分析）；② 置信度与概率混淆；③ 截尾分布直接用正态（2024D 明确给的是**单边截尾正态**，密度函数分母是 1−Φ((l−h₀)/σ_z)）〔原文〕；④ 误差传播只做一阶近似而不做蒙特卡洛验证。

### 6.2 「不确定性 / 波动 / 期望范围」

- **题眼原句**：〔原文·2026E-Q4〕"考虑到每个关键词的竞价每天都在变化，相应的展现量、展现位、点击量、浏览量和注册量等因素存在不确定性……并估计关键词的竞价、展现量……的期望范围"。
- **对应问题类型**：随机优化 / 区间估计。
- **推荐模型**：情景分析；鲁棒优化；机会约束规划；随机规划（两阶段 / 多阶段）；区间预测（分位数回归、Bootstrap）。
- **推荐算法**：抽样 + LP 求解；样本平均近似（SAA）；CVaR 优化。
- **常见坑**：① 把期望当确定值优化（"确定性等价"谬误）；② 不给分布假设依据；③ 把"期望范围"误解为"均值的置信区间"而非"随机变量取值区间"〔推理，须在论文中明确口径〕。

## 7. 仿真族题眼

### 7.1 「模拟 / 仿真 / 演练测试」

- **题眼原句**：〔原文·2026B·附录3〕"请先下载无线电干扰源环境模拟器（简称模拟器）用于测试……机器狗程序通过 HTTP+JSON 接口与模拟器进行通信"；〔原文·2026B〕"被清除干扰源个数的比例""平均定位清除时间"。
- **对应问题类型**：仿真类 + 在线决策。
- **推荐模型**：策略-仿真闭环；离散事件仿真；蒙特卡洛评估。
- **推荐算法**：策略参数化 + 批量演练对比；方差缩减（同一批案例比较不同策略）；滚动决策。
- **常见坑**：① 只跑一次就下结论；② 不先用演练测试调参就直接上正式测试（**2026B 只有 3 次正式测试机会**）〔原文〕；③ 日志文件不导出（题目要求在支撑材料中提供，正式测试日志有 2 MB 上传上限）〔原文〕；④ 程序死循环导致虚拟时间超时〔原文〕。

### 7.2 「多次实验 / 重复 / 稳定性」

- **推荐做法**：报告重复次数、随机种子、结果的均值 / 标准差 / 置信区间；做方差缩减。
- **常见坑**：只报最优一次；不做显著性比较。

## 8. 分类与聚类族题眼

### 8.1 「分类 / 判定 / 识别 / 归类」

- **题眼原句**：〔原文·2026E-Q2〕"按照投入成本与效益将关键词进行分类：(1) 黄金词：低成本，高效益；(2) 重点词：高成本，高效益；(3) 潜力词：低成本，低效益；(4) 问题词：高成本，低效益；(5) 无效词：无成本，无效益"；〔原文·2000A〕DNA 序列分类。
- **对应问题类型**：分类类。
- **推荐模型**：**二维阈值分类**（成本、效益两维各设阈值，四象限 + 原点零成本零效益特判）；判别分析；逻辑回归；决策树 / 随机森林。
- **推荐算法**：分位数 / 均值 / 中位数阈值法 + 敏感性分析；需数据驱动时先聚类再贴标签。
- **不推荐模型**：直接上深度网络（**题目没有标注样本**，2026E 只有关键词的消费额与行为指标）〔推理〕。
- **常见坑**：① 把"题目给了类别语义"误认为"有监督学习任务"；② 阈值选择不给依据（应做"阈值 ±10% 时分类稳定性"分析）；③ "无效词：无成本，无效益"是原点特判，不能并入"潜力词"；④ 忘记"关键词"与"推广单元""方案"的层级关系（同一关键词可出现在多个单元）。

### 8.2 「分组 / 分群 / 划分 / 最佳时点」

- **题眼原句**：〔原文·2025C-Q2〕"试对男胎孕妇的 BMI 进行合理分组，给出每组的 BMI 区间和最佳 NIPT 时点，使得孕妇可能的潜在风险最小"。
- **对应问题类型**：聚类类 + 优化（分组边界与组内决策联合优化）。
- **推荐模型**：一维最优分割（Fisher 最优分割 / 动态规划）；带单调性约束的聚类；K-means（连续变量且无单调要求时）。
- **推荐算法**：动态规划求最优分割点 O(n²K)；约束优化；分组稳定性检验（Bootstrap）。
- **不推荐模型**：K-means（分组边界不连续、不保证单调性，与"BMI 区间"的语义不符）。
- **常见坑**：① 分组数是超参数却当成确定值（应给选择依据）；② 组内样本过少；③ 分组后不做组间差异显著性检验；④ 最优时点与分组分开求解导致次优（应联合优化）。

## 9. 多目标族题眼

### 9.1 「既要……又要…… / 尽可能……而……尽可能……」

- **题眼原句**：〔原文·1998A〕"使净收益尽可能大，而总体风险尽可能小"；〔原文·2012B〕"使小屋的全年太阳能光伏发电总量尽可能大，而单位发电量的费用尽可能小"；〔原文·2014B〕"折叠桌的设计应做到产品稳固性好、加工方便、用材最少"。
- **对应问题类型**：多目标优化。
- **推荐模型**：加权和法（需权重依据）；ε-约束法；Pareto 最优前沿；目标规划（Goal Programming）。
- **推荐算法**：权重扫描；NSGA-II；ε-约束逐次求解。
- **常见坑**：① **目标其实同向却硬做多目标**（伪多目标）；② 不归一化就加权；③ 只给一个折中解不给前沿；④ 不做权重敏感性。

## 10. 2026 年五题题眼精读（现场版）

> 以下逐题列出**真正决定模型选择的题眼句**，并给出同义扩展（写论文时要能识别变体）。

### 10.1 2026 A 题「药材的烘干问题」

| 题眼原句〔原文〕 | 落到的数学结构 | 模型 |
|---|---|---|
| "某中药材形状大致呈圆柱形，长为 25 cm，半径为 2 cm" | 轴对称二维（r,z）或一维径向（忽略端面效应） | 圆柱坐标热传导方程 |
| "水分浓度（即干基含水率）为 2.55 kg/kg" | 含水率 C 作为场变量 | 扩散方程 |
| "烘房的温度（单位：°C）和水分浓度（单位：kg/kg）的变化情况见附件 1" | 边界条件**时变** | 时变 Dirichlet / Robin 边界 |
| "密度 820 kg/m³、比热容 2600 J/(kg·K)、热传导系数 0.36 W/(m·K)、对流换热系数 25 W/(m²·K)、对流传质系数 8×10⁻⁷ m/s" | 给出 h 与 k_m ⇒ 表面为**对流边界（第三类）** | Robin 型：−k ∂T/∂n = h(T∞−Ts)，−D ∂C/∂n = k_m(Cs−C∞) |
| "D = 7×10⁻⁹ e^(−0.89/C)" | 扩散系数是场变量的函数 ⇒ **非线性** PDE | 变系数扩散方程（需迭代 / 线性化） |
| "给出 100、300、600、900、1200、1500、1800 s，到药材中心距离 0、0.5、1、1.5、2 cm 处的结果" | 需要**时空分布** ⇒ 必须数值解 PDE | 有限差分 / 有限元 |
| 问题 3 "按照烘干要求，药材各处的水分浓度应低于 0.15 kg/kg，请确定药材烘干所需要的时间" | **"处处 < 阈值"是无穷维约束** ⇒ 需先证单调性再降维为端点/最慢点约束，再用二分或求根 | PDE 解 + 单调性论证 + 二分法 |
| 问题 2/3 "相关经验公式统一采用附录 3 中的公式"；问题 4 "相关经验公式见附录 4" | 物性随含水率变化，且 Q2/Q3 与 Q4 用的是**两套不同的经验公式** | 变物性 PDE（ρ=650+128C 等）；Q4 用 ρ=760+90C 一套 |
| "ρ=650+128C，c_p=1450+2736·C/(C+1)，k=0.21+0.38·C/(C+1)，D=2.4×10⁻³e^(−0.45/C)e^(−3850/T)" | 指数中含 1/T ⇒ **温度单位陷阱** | T 必须取**开尔文**；直接代入摄氏度会得到荒谬量级 |
| 问题 4 "药材会因水分流失发生尺寸变化……确定药材的烘干时长" + 附件 2 半径 2→1.198 cm | **移动边界（收缩域）**，且 R(t) 由附件 2 给出 ⇒ 是**已知移动边界**，不需要解 Stefan 条件 | 定域坐标变换 ξ = r/R(t)；不要解 Stefan 条件 |
| "所有结果保留四位小数""每隔 1 s、……每隔 0.1 cm 的完整结果" | 输出网格被题目**写死** | 网格设计受题目反向约束 |

**关键提醒**：题目把 Δt=1 s、Δr=0.1 cm 的**输出网格写死了**，但**计算网格可以更细**（先加密计算再插值输出），这是本题最容易被忽略的工程细节〔推理〕。

## 11. 题眼识别的三条铁律〔归纳〕

1. **题眼优先于直觉**。先扫题眼词，再读细节。不要一看到"预测"就写 ARIMA，也不要一看到"最优"就写遗传算法。
2. **约束藏在附录里**。2026 A 题的物性经验式在附录 3/4、C 题的储能参数在附录 1、D 题的调整上限在正文末段、E 题的分类定义在问题 2 的括号里——**逐条抄录成"约束清单"再开始建模**。
3. **每一问都要重新识别题型**。同一道题的 4—5 问经常是不同类型（2026 A 题 Q1/Q2 是 PDE 正问题、Q3 是求达标的逆问题、Q4 是移动边界 PDE）；用同一套模型硬套所有小问是历年最常见的失分点〔归纳〕。
