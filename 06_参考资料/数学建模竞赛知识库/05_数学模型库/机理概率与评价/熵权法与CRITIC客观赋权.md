# 熵权法与CRITIC客观赋权

## 1. 模型用途

客观赋权法解决的是这样一类问题：**已经有一张"方案 × 指标"的完整数值矩阵，权重不该由人拍脑袋定，而应由数据自身的信息结构决定**。熵权法（Entropy Weight Method）用"指标的离散程度"衡量其信息量，CRITIC 法则同时看"离散程度"与"指标间冲突程度"。它们要回答的是同一个问题：**在这张数据表里，哪个指标更有分辨力，因而应该占更大权重？**

在数学建模竞赛里，客观赋权法的正确出场位置：

1. **综合评价/排序的指标赋权**：题目给了多方案 × 多指标的数值表，要求"构建评价体系并排序"〔原文：2016B《小区开放道路通行影响》用熵权法确定 6 个交通指标的权重，再与模糊综合评价结合；2017B《"拍照赚钱"的任务定价》用熵权法计算 1875 位会员的"任务完成能力"〕。
2. **把多目标规划转化为单目标**：目标之间量纲不同、冲突且无法人工确定重要性时，用熵权法定权后加权求和〔原文：2016A《基于极值系泊系统设计》把"浮标吃水深度 h、游动区域 x、钢桶倾角 phi"三目标用熵权法合成单目标〕。
3. **作为主观赋权（AHP）的客观对照/修正项**〔原文：2008B《关于高等教育学费标准的评价及建议》用熵值取权法修正 AHP 的组合权重〕。

**它不能做什么**：熵权法**没有"重要性"概念**，只有"分辨力"概念。一个极其重要但所有方案取值几乎相同的指标（如"安全合规性"全部为 1），熵权法会给出接近 0 的权重。这是熵权法最反直觉、也最容易被评委抓住的点。

## 2. 题目特征

出现下列**任一**条件句时，应优先用熵权法/CRITIC：

- 题目给出了**完整的多方案 × 多指标数值矩阵**（附件 Excel、表格数据）；
- 题干要求"**客观地确定权重**""**避免主观因素**""**建立客观评价体系**"；
- 题目**没有给出任何专家意见、问卷或重要性排序**，队伍无从构造判断矩阵；
- 评价对象数量明显多于指标数量（样本数 n >> 指标数 m），数据信息量足够支撑统计赋权；
- 题干属于"**多目标规划**"且目标量纲不可公度、又无先验偏好。

典型真题：2016A 系泊系统设计（多目标赋权）、2016B 小区开放道路通行影响（交通指标赋权）、2017B 拍照赚钱任务定价（会员能力赋权）、2008B 高等教育学费标准（熵值取权修正 AHP）、2005A 长江水质评价（可作为水质指标赋权）。

**反向判据**：如果题目只给了 4 个备选方案、3 个指标，且指标数值是专家打的分，那么样本量太小，熵权法算出的权重没有统计意义，应该改用 AHP〔推理〕。

## 3. 数学原理

### 3.1 熵权法：信息熵 → 差异系数 → 权重

**信息熵**度量的是一个分布的"不确定性/混乱程度"。对指标 j，把各方案在该指标上的取值归一化成概率分布 p_ij，则该指标的熵为

$$e_j=-k\sum_{i=1}^{n}p_{ij}\ln p_{ij},\qquad k=\frac{1}{\ln n}.$$

取 k = 1/ln n 的目的是让 e_j 归一化到 [0, 1]：当某个方案在某指标上独占全部份额（p_ij = 1，其余为 0）时 e_j = 0（信息量最大）；当各方案在该指标上完全均匀（p_ij = 1/n）时 e_j = 1（信息量为 0）。

由此定义**差异系数**（也叫信息效用值、信息熵冗余度）：

$$d_j=1-e_j .$$

d_j 越大，说明该指标在各方案间分布越不均匀、越能区分方案，故应给越大权重：

$$w_j=\frac{d_j}{\sum_{j=1}^{m}d_j}.$$

**核心直觉**：熵权法给"所有方案取值都一样"的指标打 0 分权重，给"区分度最大"的指标打最高权重。它衡量的是**分辨力**，不是**重要性**。

### 3.2 归一化：熵权法最容易出错的一步

p_ij 必须是正数、且对每个 j 满足 Σ_i p_ij = 1。因此原始数据必须先做**非负归一化**：

- **极差归一化（min-max）**：正向指标 x'_ij = (x_ij − min_i x_ij)/(max_i x_ij − min_i x_ij)；负向指标取 1 减该式。缺点：极差为 0 时整列变成 0，全部 p_ij = 0 无法取对数。
- **比重法（归一化到和为 1）**：x'_ij = x_ij / Σ_i x_ij，再令 p_ij = x'_ij。这是 2016A(3) 与 2016A(5) 代码中实际使用的做法〔原文：附录程序 8 中 f(i,j) = R(i,j)./sumBycols(1,j)，随后 Hj = -k*sum(f.*lnfij,1)〕。
- **向量归一化**：x'_ij = x_ij / sqrt(Σ_i x_ij²)，但结果可为负，需再平移。

**关键结论**：**同一份数据换一种归一化方式，算出的权重会不同**。这是熵权法的固有性质，不是错误——但论文里**必须做归一化方式的敏感性分析**（见第 14 节第 2 条）。

### 3.3 零值与负值：取对数前的强制处理

ln(0) 是 −∞，因此 p_ij = 0 会直接让程序报错或返回 NaN/Inf。实际论文中至少出现过三种处理：

1. **约定 0·ln0 = 0（推荐）**：数学上 lim(p→0+) p·ln p = 0，因此当 p_ij = 0 时该求和项直接跳过即可〔原文：2016A(3) 附录程序 8 中 "if f(i,j)==0, lnfij(i,j)=0;" —— 这正是规范写法〕。**这是最干净的处理，推荐使用。**
2. **平移法**：先做极差归一化，再令 x'_ij ← x'_ij + 0.0001（或 +0.001），保证严格正。代价是引入微小偏差，需在论文中报告偏移量量级。
3. **截断法**：把 p_ij = 0 直接赋为 0.001 并另作归一〔原文：2016A(5) 附录四"熵值法"函数中 "if x(i,j)==0, P(i,j)=0.001;"〕。这个做法简单但**破坏了 Σp = 1 的约束**，严格说是不规范的，复现时要留意。

**负值**：若原始数据含负数（如收益率、温差），绝不能直接套熵权公式。必须先用极差法或平移法把全表映射到正数区间。**2026A 的提醒**：药材水分浓度始终为正，但若你把"温度变化率 dT/dt"这类可能为负的量作为评价指标，必须先平移。

### 3.4 CRITIC 法：对比强度 × 冲突性

CRITIC（CRiteria Importance Through Intercriteria Correlation）认为一个指标的"信息量"由两部分组成：

- **对比强度（contrast intensity）**：用标准差 sigma_j 度量该指标在各方案间的离散程度——和熵权法的差异系数是同一思路；
- **冲突性（conflict）**：用该指标与其他指标的相关系数度量。若指标 j 与多数指标高度正相关，说明它提供的是"重复信息"，应降低权重。

信息量：

$$C_j=\sigma_j\sum_{k=1}^{m}\left(1-r_{jk}\right),$$

其中 r_jk 是指标 j 与 k 的 Pearson 相关系数（r_jj = 1）。权重：

$$w_j=\frac{C_j}{\sum_{j=1}^{m}C_j}.$$

**CRITIC 相对熵权法的优势**：熵权法只看单指标分布，会把一组高度相关的"冗余指标"都赋高权重（因为它们各自都很分散），导致权重被同一维度重复占用；CRITIC 通过冲突性项抑制这种重复〔归纳〕。

**CRITIC 的实现前提**：指标必须先做**正向化 + 标准化（z-score 或极差）**，因为相关系数对量纲和方向敏感。若指标方向不统一（有的越大越好、有的越小越好），必须先把全部指标化为同向，否则相关系数的符号会失去意义。

## 4. 基本公式

**（1）决策矩阵与正向化**

$$X=(x_{ij})_{n\times m},\quad i=1,\dots,n\ (\text{方案}),\quad j=1,\dots,m\ (\text{指标}).$$

**（2）极差归一化（正向指标）**

$$x'_{ij}=\frac{x_{ij}-\min_i x_{ij}}{\max_i x_{ij}-\min_i x_{ij}}.$$

**（3）极差归一化（负向指标）**

$$x'_{ij}=\frac{\max_i x_{ij}-x_{ij}}{\max_i x_{ij}-\min_i x_{ij}}.$$

**（4）比重法**

$$p_{ij}=\frac{x'_{ij}}{\sum_{i=1}^{n}x'_{ij}}.$$

**（5）信息熵**

$$e_j=-k\sum_{i=1}^{n}p_{ij}\ln p_{ij},\qquad k=\frac{1}{\ln n}>0,$$

约定 p_ij = 0 时 p_ij ln p_ij = 0。

**（6）差异系数与熵权**

$$d_j=1-e_j,\qquad w_j=\frac{d_j}{\sum_{j=1}^{m}d_j},\qquad \sum_{j=1}^{m}w_j=1.$$

**（7）CRITIC 的信息量**

$$C_j=\sigma_j\sum_{k=1}^{m}\left(1-r_{jk}\right),\qquad \sigma_j=\sqrt{\frac{1}{n-1}\sum_{i=1}^{n}\left(z_{ij}-\bar{z}_j\right)^2},$$

其中 z_ij 为标准化后的值，r_jk 为指标 j、k 的相关系数。

**（8）CRITIC 权重**

$$w_j=\frac{C_j}{\sum_{j=1}^{m}C_j}.$$

**（9）线性组合赋权（最简主客观组合）**

$$w_j^{comb}=\alpha w_j^{AHP}+(1-\alpha)w_j^{entropy},\qquad \alpha\in[0,1].$$

**（10）博弈论组合赋权（纳什均衡意义）**

设 L 种赋权方法给出权重向量 w_k，组合权重为 w = Σ_k a_k w_k（a_k > 0）。以"组合权重与各单一权重的偏差最小"为目标做极小化，按矩阵微分法求解等价于求解线性方程组

$$\begin{pmatrix}\mathbf{w}_1\mathbf{w}_1^{T} & \cdots & \mathbf{w}_1\mathbf{w}_L^{T}\\ \vdots & \ddots & \vdots\\ \mathbf{w}_L\mathbf{w}_1^{T} & \cdots & \mathbf{w}_L\mathbf{w}_L^{T}\end{pmatrix}\begin{pmatrix}a_1\\ \vdots\\ a_L\end{pmatrix}=\begin{pmatrix}\mathbf{w}_1\mathbf{w}_1^{T}\\ \vdots\\ \mathbf{w}_L\mathbf{w}_L^{T}\end{pmatrix},$$

解出 a = (a1,…,aL)^T 后**归一化**：

$$a_k^{*}=\frac{|a_k|}{\sum_{l=1}^{L}|a_l|},\qquad \mathbf{w}^{*}=\sum_{k=1}^{L}a_k^{*}\mathbf{w}_k .$$

**（11）综合得分**

$$S_i=\sum_{j=1}^{m}w_j\,x'_{ij}.$$

## 5. 参数含义

| 符号 | 含义 | 注意 |
|---|---|---|
| n | 方案/样本数（矩阵行数） | **k = 1/ln n 中的 n 是行数，不是列数**——这是最常见的混淆点 |
| m | 指标数（矩阵列数） | —— |
| x_ij | 第 i 个方案在第 j 个指标上的原始值 | 必须全部非负或先平移 |
| x'_ij | 归一化后的值 | 不同归一化方式 → 不同权重 |
| p_ij | 比重 | Σ_i p_ij = 1，且 p_ij > 0 |
| k | 熵值归一化常数 | 1/ln n |
| e_j | 第 j 个指标的信息熵 | ∈ [0,1]，越接近 1 越"无用" |
| d_j | 差异系数/信息效用值 | 1 − e_j，越大越重要 |
| w_j | 权重 | Σw_j = 1 |
| sigma_j | 第 j 个指标的标准差（CRITIC 对比强度） | 必须先标准化 |
| r_jk | 指标 j 与 k 的相关系数（CRITIC 冲突性） | 必须先同向化 |
| C_j | CRITIC 信息量 | sigma_j 乘冲突性之和 |
| alpha | 主客观组合的线性权重系数 | 须做扫描敏感性分析 |

**2026A 的提醒**：2026A 的物性参数 rho、cp、k、D 都是**含水率 C 与温度 T 的光滑函数**（附录 3：rho = 650 + 128C，cp = 1450 + 2736C/(C+1)，k = 0.21 + 0.38C/(C+1)，D = 2.4e-3·exp(−0.45/C)·exp(−3850/T)）。它们**不是"待赋权的评价指标"，而是必须照抄的物理关系**。如果队伍为了让"多目标规划"好看，先用熵权法给 rho/cp/k 赋权再组合，那就是在编造物理规律，属于致命错误。

## 6. 建模步骤

**熵权法：**

1. 整理决策矩阵 X（n 行方案 × m 列指标），确认**全部数值非负**；若有负值，先整体平移。
2. 判断每个指标的**方向**（正向/负向），做正向化处理。
3. 选择归一化方式（极差法或比重法），得 x'_ij；记下所用方式，后面要做敏感性分析。
4. 计算比重 p_ij = x'_ij / Σ_i x'_ij。
5. 计算信息熵 e_j = −k Σ p_ij ln p_ij，k = 1/ln n；对 p_ij = 0 的项按 0 处理。
6. 计算 d_j = 1 − e_j，归一化得 w_j。
7. **诊断**：检查是否有指标的 w_j 接近 0（说明该指标在所有方案上取值几乎相同），在论文中说明其含义。
8. **敏感性分析**：换用另一种归一化方式重算权重，报告权重变化幅度与最终排序是否改变。
9. 用 w_j 计算综合得分并排序；若与 AHP/等权结果不一致，讨论原因。

**CRITIC 法：**

1. 决策矩阵正向化 + 标准化（z-score 或极差）。
2. 逐列算标准差 sigma_j。
3. 算指标间相关系数矩阵 R = (r_jk)。
4. 算冲突性 Σ_k (1 − r_jk)。
5. 算 C_j = sigma_j · Σ_k (1 − r_jk)，归一化得权重。
6. 与熵权结果并列成表，讨论两者差异（差异本身是很好的论文素材）。

**组合赋权（可选）：**

7. 按公式 (9) 或 (10) 合成；若用 (10)，务必做 a_k 的归一化与敏感性检验。

## 7. 算法

**算法 A：熵权法**

1. 输入矩阵 X（n×m），方向向量 dir（+1 正向 / −1 负向）。
2. 逐列检查 min(X[:,j]) ≥ 0；否则 X[:,j] ← X[:,j] − min(X[:,j]) + eps。
3. 逐列正向化 + 归一化得 X'。
4. p = X' / X'.sum(axis=0)（列和为 1）。
5. 令 L = where(p > 0, log(p), 0.0)；e = −(1/log(n)) · (p * L).sum(axis=0)。
6. d = 1 − e；w = d / d.sum()。
7. 输出 w、e、d 三列成表。
8. **复杂度**：时间 O(n·m)，空间 O(n·m)。**这是全场最便宜的方法之一**——凡是"数据量大、时间紧"的评价题，熵权法几乎无成本。

**算法 B：CRITIC 法**

1. 输入矩阵 X（n×m），正向化 + 标准化得 Z。
2. sigma = Z.std(axis=0, ddof=1)，O(n·m)。
3. 相关系数矩阵 R = corrcoef(Z)，**O(n·m²)**，是 CRITIC 的主要开销。
4. C = sigma * (m − R.sum(axis=0))（因为 Σ_k r_jk 中已含 r_jj = 1，故 Σ_k(1−r_jk) = m − Σ_k r_jk）。
5. w = C / C.sum()。
6. **复杂度**：时间 O(n·m²)，空间 O(m²)（存相关系数矩阵）。当 m ≤ 20 时微不足道；当 m > 100（如 2012A 葡萄酒有 65 个理化指标）时，m² = 10⁴，相关系数矩阵计算成为瓶颈，且大量高度相关指标会使冲突性项趋同——**此时应先做 PCA/因子分析降维再赋权**〔推理，参考 2012A(1) 论文确实先用了主成分分析降维〕。

## 8. Python实现思路

- 库：numpy（核心）、pandas（读写 Excel）、scipy.stats（相关系数）。CRITIC 可直接用 pandas.DataFrame.corr()。
- 熵权核心四行：p = Xn / Xn.sum(0)；L = np.where(p > 0, np.log(p), 0.0)；e = -(p * L).sum(0) / np.log(n)；w = (1 - e) / (1 - e).sum()。
- **易错点 1**：np.log(0) 会抛 RuntimeWarning 并返回 −inf，即使随后乘 0 也是 nan。**必须用 np.where 显式置零**，不要指望 nan_to_num 兜底。
- **易错点 2**：k = 1/np.log(n) 里的 n 是行数；写成 1/np.log(m) 是最常见的 bug，且结果看起来"也像权重"，不易察觉。**建议算完后检查每个 e_j 是否落在 [0,1]**。
- **易错点 3**：极差归一化后若某列 max = min，会产生 0/0 = nan。加一个 if max == min 分支，把该列全设为 0 并在报告中说明"该指标无区分度，权重为 0"。
- 组合赋权用 numpy.linalg.solve 解 (10) 的线性方程组；注意矩阵可能奇异（两法权重高度相关时），需改用 np.linalg.lstsq 并报告。
- 敏感性分析建议写成函数 fit_weight(X, normalizer=...)，外部循环传入不同 normalizer（minmax / vector / sum），把结果拼成 DataFrame 输出论文表格。
- 结果表至少包含：指标名、e_j、d_j、w_j（熵权）、sigma_j、冲突性、w_j（CRITIC）、两法权重差。

## 9. MATLAB实现思路

- 核心：先归一化，再用 repmat 或隐式扩展做比重；e = -k*sum(P.*log(P),1)；w = (1-e)/sum(1-e)。
- **log(0) 处理**：MATLAB 中 log(0) = -Inf，Inf*0 = NaN。惯用法是先记录掩码 idx = (P==0)，令 P(idx) = 1，tmp = log(P)，再 tmp(idx) = 0。
- 相关系数矩阵：R = corrcoef(Z); C = std(Z,0,1) .* sum(1-R,1); w = C/sum(C);
- 若用 Statistics Toolbox 的 corr，注意默认是 Pearson 且对 NaN 敏感，须先用 rmmissing 清洗。
- **2016A(3) 论文的写法可直接参考**：附录程序 8 的 EntropyWeight(A) 函数把 k、fij、lnfij、Hj、weights 全部展开写出，最后 weights = (1-Hj)/(cols-sum(Hj))——注意 sum(1-Hj) 与 cols-sum(Hj) 恒等，两种写法都对，但**论文中建议写 (1-Hj)/sum(1-Hj) 以免读者误解**。
- **2016A(5) 论文的 shangzhifa(x) 有一个已知不规范点**：把 x 中的 0 强行改成 P = 0.001 却不重新归一化，导致 Σp ≠ 1，会使熵值偏小。引用时可作为反面例子。
- 组合赋权解线性方程组用反斜杠求解，奇异时用 pinv(A)*b 并报告条件数 cond(A)。
- 出图：用 bar 画两法权重对比（分组柱状图），能直观展示"主观 vs 客观"的差异，是很好的论文插图。

## 10. 优点

1. **完全客观、可复现**：任何人拿同一份数据、同一种归一化方式都能算出完全相同的权重，从根本上避开了 AHP"判断矩阵来源不明"的质疑。
2. **计算成本极低**：熵权法 O(n·m)，一次矩阵运算搞定，可以在一分钟内跑完并做几十次敏感性测试。
3. **隐藏的信息量诊断功能**：e_j 接近 1 的指标说明它在所有方案上取值雷同，这本身就是一条有价值的结论——"该指标无法区分方案，建议从指标体系中剔除"。反过来，如果某个被专家认为无用的指标熵权很高，说明它实际上很有分辨力。
4. **可与主观方法互补**：主客观组合赋权既保留了领域知识，又让数据说话〔原文：2008B 论文明确写道"由于层次分析法成对比较矩阵的给出存在着一定的主观因素，于是我们想到了利用熵值取权法……它和层次分析法得出的结论是互补的且是客观的"〕。
5. **CRITIC 额外解决了"指标冗余"问题**：这是熵权法做不到的。

## 11. 缺点

1. **没有"重要性"概念，只有"分辨力"概念**。极其重要但全域取值相同的指标会被赋 0 权重，这在综合评价中可能造成荒诞结论〔归纳：这是熵权法被批评最多的点〕。
2. **对归一化方式敏感**：极差法、比重法、向量法给出的权重不同，且当数据含极端值时极差法会被单个离群点主导——若不做敏感性分析，结论的可信度大打折扣。
3. **对样本量敏感**：n 太小时熵值估计不稳定。n = 3~5 时算出的权重基本没有统计意义。
4. **熵值与差异系数之间是非线性映射**，权重对数据的微小变化可能被放大。
5. **CRITIC 的计算量随指标数平方增长**，且当指标间相关性普遍很高时，冲突性项趋同，退化为"只看标准差"。
6. **权重完全由数据决定，无法引入领域知识**，若数据本身有系统性偏差（如某指标测量误差大），熵权法会忠实地把偏差放大。

## 12. 适用条件

- 当**决策矩阵完整（n ≥ 10 个方案、m ≤ 20 个指标）且全部数值可转成非负**时，可以用熵权法。
- 当**题目明确要求"客观赋权"或未提供任何专家/问卷信息**时，应当用熵权法（而不是硬编一套 AHP 判断矩阵）。
- 当**指标间可能存在明显冗余**（多个指标测的是同一维度）时，可以用 CRITIC 替代或补充熵权法。
- 当**同时能获得主观权重（AHP）与客观权重（熵权）**时，可以用组合赋权，但必须做 alpha 或 a_k 的敏感性分析。
- **关于 2026A**：当题目（如 2026A）的解由**物理定律封闭确定**时，熵权法的合法用途只有"在多个候选方案/工艺之间做多目标比选"；**绝不可以**用它给 PDE 的物性参数或方程各项赋权。

## 13. 不适用情况

- 当**指标的物理量纲与方向未统一**时，不可以直接套用熵权公式（必须先正向化 + 归一化）。
- 当**数据含负值且未平移**时，不可以使用熵权法（p_ij 必须是概率，负值无意义）。
- 当**方案数 n < 5** 时，不建议用熵权法定权（统计不稳定），应改用 AHP 或等权。
- 当**全部指标在所有方案上取值几乎相同**（各列极差接近 0）时，不可以使用熵权法——此时所有 d_j 都接近 0，权重会被数值噪声主导。
- 当**题目已给出明确的专家权重或政策指定的权重**时，不可以单方面用熵权法覆盖（应以题目给定为准，熵权仅作对照）。
- 当**被赋权对象是物理参数而非评价指标**时，绝对不可以使用熵权法〔针对 2026A：rho、cp、k、D 是附录给定的函数，不是可赋权的指标〕。

## 14. 常见错误

1. **熵权法对零值与负值取对数报错**。
   具体表现：e = -k * sum(p * log(p)) 在 p 含 0 时返回 NaN（Python 是 RuntimeWarning + nan，MATLAB 是 Inf*0 = NaN），程序后续权重全变 NaN；或者更隐蔽——某个分支被静默跳过，权重看着"正常"但是错的。
   **可操作对策**：(a) 归一化后先检查 min(X') > 0 或显式处理零元；(b) 用数学上的约定 0·ln0 = 0，即 np.where(p > 0, np.log(p), 0.0)；(c) 若必须平移，选择 eps 后要在论文里报告引入了多大偏差；(d) **不要用把 0 改成 0.001 却不重新归一化的做法**——2016A(5) 附录四的 shangzhifa 函数就是这种做法〔原文〕，它会破坏 Σp = 1 的约束。
   **对 2026A 的具体提醒**：2026A 的初始含水率为 2.55 kg/kg，目标低于 0.15 kg/kg，问题 4 半径从 2 cm 收缩到 1.198 cm。若你把 2026A 的含水率矩阵拿来做"质量评价"并做极差归一化，注意中心点长时间后含水率可能极小，归一化后出现接近 0 的值，触发同样的取对数问题——**必须在归一化后加零值保护**。

2. **归一化方式不同导致权重不同，却不做敏感性分析**。
   极差归一化与比重归一化给出的权重可能相差几十个百分点，最终排序可能翻转。**只报告一种归一化的结果，等于隐藏了一个自由参数。**
   **可操作对策**：在论文中加一小节，并列给出三种归一化下的权重表 + 最终排序表，明确写出"在三种归一化方式下，前 3 名排序完全一致，说明结论对归一化方式不敏感"。**这半页纸是廉价的加分项**，而语料中的 2016A、2016B、2017B 三篇熵权案例**均未做此项检验**〔原文，阅读确认〕。

3. **用熵权法给评价指标赋权后，又用同一套数据调参**。
   典型场景：先用完整数据集算熵权，再用同一份数据去训练/标定模型参数（如阈值、权重衰减、回归系数），最后用同一份数据评估模型性能并宣称"效果好"。这构成**数据泄漏（data leakage）与循环论证**——权重已经"看过"全部数据，评估结果必然乐观。
   **可操作对策**：(a) 把数据集划分为"赋权集"与"验证集"，或至少用留一法（LOO）重新赋权验证；(b) 若数据量不足以划分，就在论文中明确声明"权重与评估使用同一数据集，结论存在乐观偏差，故同时报告等权基准下的结果作为对照"。
   **2026A 的类比**：问题 3 要确定"药材各处水分浓度低于 0.15 kg/kg 所需烘干时间"。若你先用全部仿真结果调好一个判定阈值（例如"中心点低于 0.14 即认为达标"）再宣布该阈值最优，同样是循环论证——**必须留出独立的验证工况或用解析解交叉校验**。

4. **把 k = 1/ln n 里的 n 写成指标数 m**。
   这是最隐蔽的 bug：结果依然是一组和为 1 的权重，图也画得出来，但 e_j 的取值会超出 [0,1]（当 n < m 时 k > 1，熵值可能大于 1，d_j 变负）。**对策**：算完后强制检查每个 e_j 是否在 [0,1] 内，以及每个 w_j 是否为正。**d_j 出现负值就是 n/m 搞反的铁证。**

5. **用熵权法的权重反过来解释"重要性"**。
   论文里写"熵权法表明指标 A 最重要"是概念错误。正确表述是"指标 A 在各方案间差异最大，因而分辨力最强、被赋予最大权重"。评审老师非常熟悉这个区别。

6. **组合赋权只给一个 alpha 值，不做扫描**。
   写"取 alpha = 0.5"而不说明为什么是 0.5，与 AHP"拍脑袋判断矩阵"是同一类问题。**对策**：给出 alpha ∈ [0,1] 的扫描曲线，标出排序翻转点。

7. **博弈论组合赋权忘记归一化 a_k**。
   解出的 a_k 可能为负（需取绝对值）且不满足 Σ|a_k| = 1，直接代入会得到权重和 ≠ 1 的组合权重。

8. **CRITIC 前没做正向化就直接算相关系数**。
   一个"越大越好"的指标与一个"越小越好"的指标，若都保留原方向，相关系数会带错误的符号，冲突性项完全失真。

9. **把"权重"直接当"得分"报告**。熵权只给出指标间的相对重要性，最终结论必须经由加权求和的综合得分 $S_i$ 得出，且要在论文中说明得分量纲（通常是无量纲的加权归一化值）。

## 15. 论文写法

**可套用句式**：

- 方法选取："考虑到题目附件 x 给出了 n 个方案在 m 个指标上的完整数值，且未提供任何专家评分或重要性排序，本文采用熵权法确定各指标权重，以避免主观赋权带来的不确定性。"
- 指标方向说明："在所选指标中，车流密度、行程时间、延误时间、道路饱和度、交叉路口阻塞率为负向指标（数值越小越优），车流速度为正向指标。本文先对负向指标作正向化处理，再统一进行极差归一化。"
- 熵权计算："对归一化后的矩阵按列计算比重 p_ij = x'_ij / Σ_i x'_ij，取 k = 1/ln n（n 为样本数），计算第 j 个指标的信息熵 e_j = −k Σ_i p_ij ln p_ij（约定 p_ij = 0 时该项取 0）。"
- 权重结果："由差异系数 d_j = 1 − e_j 归一化得权重 w = (…)，其中指标 x 的权重最大（w_x = …），说明该指标在各方案间差异最显著，对区分方案贡献最大。"
- 诊断性结论："指标 y 的信息熵 e_y = 0.9987，接近 1，说明其在所有方案上的取值几乎相同，分辨力极弱，权重仅为 0.003。本文保留该指标但不依赖其做区分。"
- 敏感性分析："为检验权重对归一化方式的敏感性，本文分别采用极差归一化、比重归一化和向量归一化重新计算权重。三种方式下权重最大偏差为 x.xx，最终排序的前 3 名完全一致，表明评价结论稳健。"
- 组合赋权："为兼顾领域先验与数据客观性，本文采用博弈论组合赋权。设 AHP 权重为 w1、熵权为 w2，以组合权重与两者偏差最小为目标求解线性方程组，得系数 a = (a1, a2) 并归一化，最终组合权重 w* = a1*w1 + a2*w2。"
- 与 AHP 的对照："熵权法结果为纯数据驱动，AHP 结果含主观先验。两者在指标 x 上的权重相差 x.xx，反映了'专家认为重要'与'数据上可区分'之间的差异，这一差异本身说明……"

**配图建议**：

1. **权重对比分组柱状图**：横轴指标名，纵轴权重，两组柱子分别对应 AHP 与熵权，是最直观的一张图。
2. **信息熵 / 差异系数条形图**：按 e_j 降序排列，配合一条 e = 0.99 的参考线标出"低分辨力指标"。
3. **归一化方式敏感性热力图**：行是归一化方式，列是指标，颜色表示权重，能一眼看出哪些指标的权重不稳定。
4. **alpha 扫描曲线**：横轴 alpha ∈ [0,1]，纵轴各方案综合得分，交叉点即排序翻转点。
5. **CRITIC 相关系数矩阵热力图**：能直观展示哪些指标冗余（深色块），是 CRITIC 方法的"证据图"。

## 16. 可创新方向

1. **熵权 + CRITIC + AHP 三法组合并与单一方法对比（3 天内可做）**：语料中 2016B(1)(4) 只用熵权，2008B 只用 AHP + 熵值取权，**未见一篇同时用三种方法做对照**。你可以做"三法权重对比表 + Spearman 秩相关矩阵 + 最终排序一致性（Kendall W 系数）"，把"权重方法的选择是否影响结论"变成一个定量的结论。工作量约半天。
2. **权重的自助法（Bootstrap）置信区间（3 天内可做）**：对决策矩阵做 1000 次有放回重抽样，每次重算熵权，得到每个指标权重的经验分布与 95% 置信区间。**这张"权重箱线图"能直接回答评委"你的权重稳定吗"，且语料中未见任何一篇做过**〔推理〕。
3. **动态熵权（时间维扩展，适合 2026A 式过程数据）**：把静态的 n×m 矩阵扩展为 T×n×m 的三维面板，对每个时刻单独算熵权，得到 w_j(t)。**2026A 的落地做法**：把烘干过程按每 1800 s 分箱，在每个时间窗内对"表面温度、中心温度、表面含水率、中心含水率、含水率径向梯度、干燥速率"等指标算动态熵权，画出权重随时间演化的曲线，指出"预热平衡阶段主导指标是温度、恒温干燥阶段主导指标是含水率梯度"。这比静态赋权信息量高一个量级，且**完全用题目给的附件数据就能做**〔推理，基于 2026A 真题结构：预热平衡与恒温干燥两阶段、0—259200 s、径向 0.1 cm 输出〕。
4. **把熵权法用于 2026A 的"参数敏感性排序"（本题可落地）**：2026A 的物性由 rho、cp、k、D 四个函数决定，它们的系数（如 D 的指前因子 7e-9、指数项 0.89）对最终干燥时间的贡献不同。你可以构造"参数扰动 × 输出偏差"的敏感性矩阵，用熵权法客观地给"哪个参数最需要精确测量"排序。**注意**：这里的赋权对象是"敏感性程度"这一统计量，不是物理参数本身——这个界限必须在论文中写清楚，否则会被误读为"给物理参数赋权"。
5. **熵权法权重的时间稳定性检验**：把数据按时间前后对半分割，分别算熵权，比较两组权重的差异。差异大 → 说明指标体系的时间稳健性差，应讨论是否需要分段建模。这是预测类和过程类题目都适用的检验手段；2026A 的两阶段结构（预热平衡 vs 恒温干燥）天然适合这个检验。

**案例 4（变体：AHP + 熵值取权组合赋权）**：2008B《关于高等教育学费标准的评价及建议》
出处：..._2008年优秀论文_2008B：《关于高等教育学费标准的评价及建议》.PDF.txt
它用它做了什么：论文先用层次分析法（成对比较矩阵）得出 5 个要素对"学费合理化指数"的权重 w1 = (0.1225, 0.2849, 0.4555, 0.0771, 0.060)，随后用熵值取权法给出客观权重 w2，并**按 W = 0.8*w1 + 0.2*w2 合成最终组合权重**〔原文〕。论文对熵值取权法的直觉解释非常精彩，可直接引用："熵值取权法的优势在于，它是通过判断各个因素的变化剧烈程度来决定该因素在最终目标中所占的权重。比如国家的财政支持对高等院校的学费的制定影响很重要，但是如果财政支持费用 10 年都不变，而家庭支付承受能力虽然对学费的制定没有国家财政支持的影响那么重要，但是它每年都在快速的增加，从熵值取权法的角度来看这时家庭的支付承受能力的影响就比国家财政的支持大"；论文进一步总结"它和层次分析法得出的结论是互补的且是客观的"〔原文〕。
**关系：变体（组合赋权，但用的是固定系数线性加权而非博弈论）**。**这是一段可以直接搬进论文的"为什么需要客观赋权"的论述**，也是第 16 节创新方向 1 的直接起点：把 0.8:0.2 这个未说明来源的系数改成 alpha 扫描或博弈论求解。
