# 参数估计与参数反演

## 1. 模型用途

参数估计（parameter estimation）与参数反演（inverse problem）解决的是同一个问题的两面：

- **参数估计**：模型结构已知，但某些参数的值未知，用**观测数据**把它们定出来（$\min_\theta\ \|\mathcal M(\theta)-\mathbf{y}^{obs}\|^2$）。
- **参数反演**：不仅参数未知，**连输入的边界条件、源项、初始场也可能未知**，需要通过输出端的观测反推输入端（例：由皮肤外侧实测温度反推换热系数；由 CT 投影反推衰减系数分布）。

在竞赛中的三大用法：

1. **标定物理常数**：题目给了实测数据但没给某个系数（2018A 由附件 2 皮肤温度反演换热系数 $h$）。
2. **识别隐藏参数**：几何参数、系统偏差（2017A 由 CT 投影数据反演探测器间距与旋转中心）。
3. **校准数值模型**：让模型输出与实测吻合，再做外推预测（2010A 储油罐变位识别）。

**2026A 的特殊性**〔原文〕：题目附录 2/3/4 **已经给出了全部参数**（$h=25$、$k_m=8\times10^{-7}$、$\rho,c_p,k,D$ 的经验式），因此**不需要做参数反演**。本卡片对 2026A 的价值主要在于：① 用"参数敏感性/不确定性量化"证明题目给的参数够用；② 如果要做额外问（比如用附件 2 的半径数据反演收缩系数），可以照搬本卡片的方法论。

## 2. 题目特征

出现下列任一条件句，说明需要参数估计/反演：

- 题目给出**实测数据表**，但不给某个关键系数——"附件 2 给出了 90 分钟内假人皮肤外侧的温度"；
- 题目要求**识别系统偏差或几何参数**——"标定 CT 系统的旋转中心与探测器间距"；
- 题目给了**传感器的间接观测**（投影、图像、光谱、频率响应），需要反推物理量——"由接收到的声波/电磁波反推源的位置"；
- 题目出现"标定""识别""反演""辨识""修正""校准"等词；
- 出现了**近似公式**（如 2026A 的 $D=2.4\times10^{-3}e^{-0.45C}e^{-3850/T}$）——这类公式的系数是拟合出来的，可以讨论其适用范围与敏感性。

典型真题：2018A（换热系数标定）、2017A（CT 系统参数标定）、2010A（储油罐变位识别）、2020A（回焊炉温曲线参数辨识）、2015A（太阳影子定位，位置与日期反演）、2011A（污染源位置反演）、2009A（制动器试验台等效转动惯量）。

## 3. 数学原理

### 3.1 反问题的数学结构

给定**正问题算子** $\mathcal M: \theta\mapsto \mathbf{u}(\mathbf{x},t;\theta)$ 与观测算子 $\mathcal H$（把场映射到观测点），反问题求

$$\hat\theta=\arg\min_{\theta\in\Theta}\ \Phi(\theta),\qquad \Phi(\theta)=\sum_{i=1}^{N}\omega_i\left[\mathcal H\mathcal M(\theta)_i-y_i^{obs}\right]^2$$

### 3.2 适定性与不适定性（Hadamard 三条件）

一个反问题适定（well-posed）需满足：**解存在、解唯一、解连续依赖于数据**。绝大多数反问题违反后两条，表现为：

- **不唯一**：多个参数组合给出同一条曲线——2018A 三篇论文用完全相同的材料参数，却给出 $h=-0.318$、$8.6125$、$113$ 三个相差两个数量级的值〔归纳〕；
- **不稳定**：微小的数据噪声导致巨大的参数偏差（CT 反投影是典型）；
- **解不存在**（在严格函数空间意义下）：观测误差使方程组不相容。

**正则化**是处理不适定的标准手段：

$$\hat\theta=\arg\min_\theta\ \|\mathcal M(\theta)-\mathbf{y}\|^2+\lambda\,\Omega(\theta)$$

- Tikhonov：$\Omega(\theta)=\|L\theta\|^2$（抑制参数幅度）；
- 全变差（TV）：$\Omega(\theta)=\|\nabla\theta\|_1$（保边界，适合分段常数）；
- 稀疏正则：$\Omega(\theta)=\|\theta\|_1$（Lasso，参数少时自动选变量）。
- $\lambda$ 的选法：L 曲线法、广义交叉验证（GCV）、 discrepancy 原则。

### 3.3 可辨识性分析

在估计之前先回答：**这个参数能不能被数据定出来？** 用**灵敏度矩阵**（Sensitivity / Jacobian）

$$J_{ij}=\frac{\partial \mathcal H\mathcal M(\theta)_i}{\partial \theta_j}$$

若 $J$ 的列近似线性相关（条件数 $\kappa(J)=\sigma_{max}/\sigma_{min}$ 极大），则参数不可辨识。**这解释了 2018A 的 $h$ 为何能取两个数量级不同的值而拟合都不错**〔归纳〕。

**2026A 的可辨识性诊断**〔推理〕：由 2018A(3) 的定性结论"$h_1$ 主要影响到达稳态的时间、$h_2$ 主要影响稳态温度"，可以预期在 2026A 中"$h$ 主要影响温度场、$k_m$ 主要影响含水率场"。**这两个参数是弱耦合的，因此可辨识性好**——题目直接给出数值是合理的。反之若题目只给实测的温度与含水率曲线而要求反演 $h$ 与 $k_m$，则应当做上述灵敏度分析来支撑。

### 3.4 贝叶斯反演（进阶）

把参数视为随机变量，用贝叶斯公式

$$p(\theta\mid \mathbf{y})\propto p(\mathbf{y}\mid \theta)\,p(\theta)$$

输出的是**后验分布**而非点估计，可直接给出**置信区间**。MCMC（Metropolis–Hastings、自适应 Metropolis）或近似贝叶斯计算（ABC）是标准工具。语料中**没有**论文用过贝叶斯反演〔归纳〕，是可创新方向。

## 4. 基本公式

### 4.1 最小二乘 / 加权最小二乘

$$\hat\theta=\arg\min_{\theta}\ \sum_{i=1}^{N}w_i\left[\hat y_i(\theta)-y_i\right]^2,\qquad w_i=\frac{1}{\sigma_i^2}\ (\text{加权})$$

线性情形（$\hat y=X\theta$）有闭式解：$\hat\theta=(X^TWX)^{-1}X^TWy$。

### 4.2 非线性最小二乘：Gauss–Newton 与 Levenberg–Marquardt

$$\theta_{k+1}=\theta_k-\left(J_k^TJ_k+\lambda_kI\right)^{-1}J_k^T\mathbf{r}_k$$

- $\lambda_k\to0$：退化为 Gauss–Newton（二阶收敛，但在病态时发散）；
- $\lambda_k$ 大：退化为梯度下降（稳定但慢）。
- 更新策略（2015A(1) 论文原文给出）：$\lambda_0=10^{-3}$，$v=10$；失败 $\lambda_{k+1}=v\lambda_k$，成功 $\lambda_{k+1}=\lambda_k/v$。

### 4.3 参数的置信区间与不确定性

在残差独立同分布假设下，参数的协方差矩阵为

$$\mathrm{Cov}(\hat\theta)=\hat\sigma^2\left(J^TJ\right)^{-1},\qquad \hat\sigma^2=\frac{\|\mathbf{r}\|^2}{N-p}$$

$\theta_j$ 的 $95\%$ 置信区间为 $\hat\theta_j\pm t_{0.025,N-p}\sqrt{\mathrm{Cov}_{jj}}$。

**2017A(1) 是全语料中唯一做过误差传递分析的论文**〔归纳〕：由正规方程求拟合系数协方差，用

$$\delta(y)=\sqrt{\frac{\sum_i(y_i-\hat y_i)^2}{N-1}}$$

推导 $\theta$ 的相对误差 $<10^{-4}$，并指出"180 次平均使误差降为 $1/\sqrt{180}$"。

### 4.4 灵敏度系数的无量纲形式

$$S_j=\frac{\partial \ln y}{\partial \ln \theta_j}=\frac{\theta_j}{y}\frac{\partial y}{\partial \theta_j}$$

$|S_j|$ 越大，该参数越重要。**做参数扫描后做回归，可以直接得到 $S_j$ 的经验值**——这是竞赛里最省事的敏感性分析做法。

### 4.5 正则化目标函数

$$\Phi(\theta)=\underbrace{\sum_i w_i\left[\hat y_i(\theta)-y_i\right]^2}_{\text{数据项}}+\lambda\underbrace{\Omega(\theta)}_{\text{正则项}}$$

### 4.6 双层优化（反演内嵌于优化）

当参数反演是某个优化问题的内循环时，严格写法是

$$\min_{\mathbf{d}}\ f(\mathbf{d})\quad \text{s.t.}\quad \hat\theta(\mathbf{d})=\arg\min_\theta\ \|\mathcal M(\theta;\mathbf{d})-\mathbf{y}\|^2$$

2018A 问题二/三即为此结构：外层优化厚度 $L_2$（或 $L_2,L_4$），内层每改一次厚度就要重跑一次传热 PDE。

## 5. 参数含义

| 符号 | 含义 | 说明 |
|---|---|---|
| $\theta$ | 待估参数向量 | 2026A 已有给定值 |
| $\mathbf{y}^{obs}$ | 观测向量 | 2018A：附件 2 的 5400 个皮肤温度点 |
| $\hat y(\theta)$ | 模型预测 | 由正问题求解得到 |
| $J$ | 灵敏度矩阵（Jacobian） | $J_{ij}=\partial\hat y_i/\partial\theta_j$ |
| $\Phi(\theta)$ | 目标函数（残差平方和） | 越小越好 |
| $\lambda$ | 正则化/阻尼参数 | L-M 中兼作步长控制 |
| $\Omega(\theta)$ | 正则项 | Tikhonov / TV / L1 |
| $w_i$ | 观测权重 | 一般取 $1/\sigma_i^2$ |
| $\kappa(J)$ | 条件数 | 判断可辨识性的核心指标 |
| $\hat\sigma^2$ | 残差方差 | 用于置信区间 |

## 6. 建模步骤

1. **明确正问题**：把 $\mathcal M(\theta)$ 写成可计算的黑箱——对 2026A 类问题就是"给定参数 → 跑一次 PDE 求解器 → 输出观测点的时间序列"。
2. **确定待估参数与观测量的对应关系**：几个参数、几组数据。**参数个数必须小于独立观测数**，否则问题欠定。
3. **参数的可辨识性预判**：写出灵敏度矩阵或做一次局部扫描（每个参数 ±10%，看输出变化）。若某参数几乎不改变输出，删掉它（否则会得到无意义的估计）。
4. **选目标函数**：最小二乘（同方差）、加权最小二乘（异方差）、极大似然（已知分布）、或加正则项（不适定）。
5. **选优化算法**：
   - 参数 $\le3$、有物理上下界 → 网格搜索 + 逐步细化（最稳，2017A/2010A 的做法）；
   - 参数可导、有初值 → L-M / Trust-Region（`scipy.optimize.least_squares`）；
   - 多峰、黑箱 → 差分进化 / 遗传算法（先粗搜，再用 L-M 精修）。
6. **设定初值与搜索域**：用物理常识界定（$h$ 在 $[5,25]$ 的空气自然对流范围；$k_m$ 在 $10^{-7}$ 量级）。
7. **求解并检查收敛**：看残差是否下降、梯度是否趋零、是否触到边界。
8. **不确定性量化**：给出参数的标准误或置信区间；画出残差随时间的分布。
9. **交叉验证**：留出法（用前 2/3 的数据估参数，后 1/3 验证）——**语料中 0 篇做过**〔归纳〕。
10. **敏感性分析**：单参数扫描 + 回归，给出经验敏感度。

## 7. 算法

### 7.1 网格搜索 + 逐步细化（最稳，竞赛最常用）

    1. 粗扫：θ 在 [a,b] 上取 N1 个点，计算 Φ，取最小点
    2. 缩域：以上一步最小点为中心，取 ±2Δ
    3. 细扫：步长除以 10，重复
    4. 直到步长 < 容差

- 复杂度：一维 $O(N_1+N_2+\dots)$；$p$ 维网格搜索 $O(N^p)$——**维数灾难**。
- 2018A(1) 用此法：先扫 8、9 定区间 → 步长 0.01 → 步长 0.0001，得 $h=8.6125$〔原文〕。

### 7.2 Levenberg–Marquardt

    初始化 θ0, λ0=1e-3, v=10
    repeat:
        解 (JᵀJ + λI) δ = -Jᵀr
        if Φ(θ+δ) < Φ(θ):  θ ← θ+δ;  λ ← λ/v
        else:              λ ← vλ
    until ‖δ‖ < ε 或 Φ 变化 < tol

- 每步复杂度：$O(Np^2+p^3)$（$J$ 为 $N\times p$）；线性最小二乘的 QR 为 $O(Np^2)$。
- 优点：兼具梯度下降的稳健与 Gauss–Newton 的速度。

### 7.3 全局优化（多峰时）

- 差分进化（`scipy.optimize.differential_evolution`）：$O(G\cdot NP\cdot N_{eval})$，$NP$ 为种群规模、$G$ 为代数；
- 先用 DE 全局粗搜，再用 L-M 局部精修（**这是最实用的组合**）。

### 7.4 正则化求解

    1. 构造增广系统: [J; √λ L] θ = [r; 0]
    2. 对一组 λ 求解，画 L 曲线（‖θ‖ vs ‖r‖）
    3. 取 L 曲线拐点处的 λ
    4. 用该 λ 的解得最终估计

- 复杂度：每个 λ 一次 $O(Np^2)$。

### 7.5 贝叶斯 / MCMC

    1. 设先验 p(θ)
    2. for k = 1..M:
           提议 θ' ~ q(·|θ_k)
           计算接受率 α = min(1, p(y|θ')p(θ')q(θ_k|θ') / (p(y|θ_k)p(θ_k)q(θ'|θ_k)))
           以概率 α 接受
    3. 去掉 burn-in，用剩余样本估计后验均值与分位数

- 复杂度：$O(M\cdot N_{eval})$，每次接收率约 0.234 时效率最高（自适应 Metropolis）。

## 8. Python实现思路

- **首选**：`scipy.optimize.least_squares(method='trf', bounds=(lo,hi), x_scale='jac')`。TRF 支持边界，比 `curve_fit` 更稳。残差函数返回数组即可。
- **需要导数**：用 `scipy.optimize.approx_fprime` 做有限差分近似 Jacobian；若能解析求导就直接给 `jac`，迭代次数减少数倍。
- **全局**：`scipy.optimize.differential_evolution` 先粗搜，把结果当 `least_squares` 的初值。
- **不确定性**：`least_squares` 返回的 `res.jac` 可直接算协方差 `np.linalg.inv(res.jac.T @ res.jac) * (2*res.cost/(N-p))`，再乘 $t$ 分位数得置信区间。
- **贝叶斯**：`emcee`（仿射不变 MCMC）、`PyMC`。
- **易错点**：
  1. 残差函数里参数顺序搞错 → 优化器给出"最优解"但物理上荒谬。
  2. 观测点与模型输出网格不对齐 → 必须先插值到同一时间点再算残差。
  3. 参数没有归一化（$h\sim10^1$、$k_m\sim10^{-7}$）→ 优化器步长失衡，用 `x_scale` 归一化。
  4. 只报点估计不报区间 → 评阅人会质疑精度。

## 9. MATLAB实现思路

- **非线性最小二乘**：`lsqcurvefit`（L-M 或 Trust-Region-Reflective）、`lsqnonlin`；设 `optimoptions('lsqcurvefit','Algorithm','levenberg-marquardt','Display','iter')`。
- **有边界**：用 `lsqcurvefit` 的 `lb`/`ub` 参数（内部自动切 TRR 算法）。
- **全局**：`ga`（遗传算法）、`simulannealbnd`（模拟退火）、`particleswarm`（粒子群）。**先 `ga` 后 `lsqcurvefit`** 是标准套路。
- **统计工具箱**：`nlinfit` 可直接返回参数与置信区间（`[beta,R,J,CovB,MSE]`）。
- **Curve Fitting Toolbox**：`cftool` 交互式拟合，适合快速试参。
- **易错点**：`lsqcurvefit` 的残差函数需返回"模型值向量"而非残差；`lsqnonlin` 才返回残差——两者搞混是最常见的低级错误。

## 10. 优点

1. **让机理模型落地**：没有参数估计，再漂亮的 PDE 也只是模板。
2. **可量化不确定性**：最小二乘的框架天然能给出参数的标准误与置信区间——这是"看起来严谨"与"确实严谨"的分界线。
3. **方法谱系丰富**：从网格搜索到 L-M 到贝叶斯，可按精度需求与算力预算自由选择。
4. **可诊断**：残差图能暴露模型结构错误（系统性弯曲说明模型形式不对，而非参数不对）。
5. **可交叉验证**：留出法、K 折、正反演互检都能直接套用。

## 11. 缺点

1. **不适定是常态**：反问题往往不唯一、不稳定，得到"能拟合的怪参数"（2018A(2) 反演出负的换热系数 $\delta=-0.318$，物理上不成立）〔归纳〕。
2. **计算成本高**：每次目标函数评估都要跑一次正问题。2018A(2) 用 0.1 mm × 0.1 mm 双重循环做了约 1.4 万次 PDE 求解〔归纳〕。
3. **对初值敏感**：L-M 是局部方法。2015A(1) 作者自述"求解的结果对初始值较为敏感"〔原文〕。
4. **容易自证**：用同一批数据既估参又验证（2010A 两篇、2017A 两篇都犯过）〔归纳〕。
5. **搜索域人为设定**：2018A(3) 的 $h_1\in[111,113]$ 区间是怎么定的论文没说〔归纳〕，区间外是否有更优解无法判断。

## 12. 适用条件

**当且仅当下列条件成立时做参数估计/反演：**

1. **正问题可解且计算成本可接受**——单次求解在秒级以内，才能支撑上千次的目标函数评估。
2. **观测数大于待估参数数**（一般要求 $N\ge5p$），否则欠定。
3. **参数对观测有可分辨的影响**（灵敏度矩阵条件数不过大）——先做可辨识性预判。
4. **观测噪声可控**，或能建模（用于加权与正则化）。

**2026A 的判定**〔原文 + 推理〕：

| 项 | 2026A 情况 | 结论 |
|---|---|---|
| 参数是否已给 | $h=25$、$k_m=8\times10^{-7}$、$\rho,c_p,k,D$ 全部由附录给出 | **不需要反演** |
| 是否有实测数据可标定 | 附件 1 给出烘房温湿度；附件 2 给出半径；**没有给出药材内部温度或含水率的实测值** | **无法标定** |
| 参数是否可辨识 | $h$ 影响温度、$k_m$ 影响含水率，弱耦合 | 可辨识性好 |
| 最值得做的"类反演"工作 | 用附件 2 的 $R(t)$ 反演收缩系数；用 $\rho=650+128C$ 的系数做敏感性分析 | 见第 16 节 |

> **结论**〔推理〕：2026A 中**不要把"参数反演"当成主线**——题目把参数都给全了，硬做反演反而会被质疑"为什么不用题目给的参数"。正确的做法是**参数敏感性分析 + 不确定性传播**：把 $h$、$k_m$、$D$ 的系数各扰动 ±10%，报告烘干时长的变化范围，说明"即使参数有 10% 误差，结论依然稳健"。

## 13. 不适用情况

1. **当题目已给出全部参数且不许改时**——硬做反演属于画蛇添足。2026A 正是这种情况。
2. **当观测数据少于待估参数时**——数学上欠定，任何解都是任意的。
3. **当单次正问题求解超过分钟级时**——上万次评估在竞赛时间内不可能完成，必须先做代理模型或降阶。
4. **当参数完全不可辨识时**——灵敏度矩阵某列为零（参数不影响任何观测量），估计值无意义，应从模型中删除。
5. **当正问题本身还没验证过时**——用一个错的模型去拟合数据，得到的只是"错的参数"，残差图会暴露但容易被忽略。

## 14. 常见错误

1. **反演出物理上不成立的参数却不去质疑。** 2018A(2) 反演出的换热系数 $\delta=-0.318291616$ 是**负值**，作者只标注"收敛异常"就放过了〔原文〕。负的换热系数意味着热量从冷流向热，违反热力学第二定律。**正确做法**：给参数加物理约束（$h>0$，$k_m>0$，$D>0$），并在残差图上检查系统偏差。$h$ 的物理范围应参照空气自然对流的 $5\sim25\ \mathrm{W/(m^2\cdot K)}$。

2. **参数不可辨识时给出唯一解。** 2018A 三篇论文用完全相同的材料参数得到 $h=-0.318$、$8.6125$、$113$，跨越两个数量级，却都能把皮肤温度曲线"拟合得不错"〔归纳〕。**这说明该反问题存在严重的参数不可辨识性**。正确做法：报告参数的置信区间或可行域，而不是一个点估计。

3. **用同一批数据既估参数又验证模型。** 2010A 两篇都用附件 1/附件 2 的数据标定，然后又用同一批数据声称"误差只有 0.0055%"〔归纳〕。**这是自证**。正确做法：留出法——用前 2/3 时刻估参数，用后 1/3 做验证，报告验证集误差。语料中**0 篇**做过留出法〔归纳〕。

4. **搜索区间人为给定且不说明来源。** 2018A(3) 的 $h_1\in\mathrm{linspace}(111,113,31)$、$h_2\in\mathrm{linspace}(8.33,8.35,31)$——步长分别是 0.0667 和 0.00067，但论文**没有说明这个区间是怎么定的**〔归纳〕。合理的做法是：先用文献范围或量纲分析给出宽区间，再逐步收窄，并把每一步的区间写清楚。

5. **对 2026A 而言：把 $h$ 与 $k_m$ 当作未知量去反演。** 题目附录 2 明确给出 $h=25\ \mathrm{W/(m^2\cdot K)}$、$k_m=8\times10^{-7}\ \mathrm{m/s}$〔原文〕，且**没有提供任何药材内部的温度或含水率实测数据**。此时反演是**不可辨识**的（观测不足）。正确做法是直接用题目给定值，并做敏感性分析。

6. **优化器的$\lambda$更新策略写错导致不收敛。** L-M 中 $\lambda$ 变大意味着更靠近梯度下降；把"失败时 $\lambda\leftarrow\lambda/v$"写反会导致步长发散。核对 2015A(1) 的原文设定：$\lambda_0=10^{-3}$、$v=10$、失败 $\lambda\leftarrow v\lambda$、成功 $\lambda\leftarrow\lambda/v$〔原文〕。

7. **残差函数里模型输出与观测量错位。** 2018A(1) 用附件 2 的 5400 个点（`xlsread('data.xlsx',2,'B3:B5402')`）与模型输出比较，两者时间步必须严格对齐〔原文〕。若模型时间步是 1 s 而观测间隔是 10 s，必须先插值。

8. **只报拟合优度 $R^2$ 不报物理量误差。** $R^2=0.99$ 在温度范围很窄时毫无意义。应报 RMSE 的**物理单位**（如"RMSE = 0.46 °C"），并给出最大绝对误差。2018A(1) 报的是 $f=0.4593$ 与最大误差 1.99 °C〔原文〕——**但它的阈值 0.5 是自定的、无依据的**〔归纳〕，这一点要在论文里避免。

## 15. 论文写法

### 15.1 可套用句式

**问题分析段（把"标定"翻译成反问题）：**
> "题目未直接给出药材表面对流换热系数，而附件 1 提供了烘房温湿度的时间序列、附录 2 给出 $h=25\ \mathrm{W/(m^2\cdot K)}$。因此本问不存在参数反演的必要性；为进一步考察结论的稳健性，本文对 $h$、$k_m$、$D$ 的系数实施 ±10% 的扰动实验，量化其对烘干时长的影响。"

**参数可辨识性段：**
> "为判断各参数是否可被观测数据分辨，本文构造灵敏度矩阵 $J_{ij}=\partial \hat y_i/\partial\theta_j$，其条件数 $\kappa(J)=\sigma_{\max}/\sigma_{\min}=x\times10^{y}$。$\kappa$ 的量级表明……（$\kappa<10^3$ 可辨识良好；$\kappa>10^6$ 表明存在强相关参数，只能给出参数的线性组合）。"

**参数估计段（若确实要做）：**
> "以最小二乘为准则建立参数估计模型
> $$(\hat h,\hat k_m)=\arg\min_{h,k_m}\sum_{i=1}^{N}\left[\hat C(\cdot,t_i;h,k_m)-C_i^{obs}\right]^2$$
> 采用 Levenberg–Marquardt 算法求解，初值取 $(h_0,k_{m,0})=(25,\ 8\times10^{-7})$，阻尼参数 $\lambda_0=10^{-3}$、缩放因子 $v=10$。"

**不确定性量化段：**
> "由残差方差 $\hat\sigma^2=\|\mathbf r\|^2/(N-p)$ 与协方差矩阵 $\mathrm{Cov}(\hat\theta)=\hat\sigma^2(J^TJ)^{-1}$，得到 $\hat h=25.3\ \mathrm{W/(m^2\cdot K)}$，95% 置信区间为 $[24.1,\ 26.5]$，参数的标准误为 0.58，说明估计精度满足工程要求。"

**留出法验证段（语料零先例，加分项）：**
> "为排除'用同一批数据既估参又验证'的自证风险，本文采用留出法：用前 2/3 时间段的观测数据估计参数，在后 1/3 时间段上独立验证。验证集 RMSE 为 $0.51\ ^\circ\mathrm{C}$，与训练集 $0.46\ ^\circ\mathrm{C}$ 相当，说明模型未过拟合。"

## 16. 可创新方向

1. **参数不确定性传播到结论**〔推理〕：把 $h$、$k_m$、$D_0$、$C_0$、$T_\infty$ 视为带误差的随机变量（如 ±10% 正态），用蒙特卡洛（1000 次采样）跑出"烘干时长"的分布，给出 95% 置信区间。**语料中 0 篇做过**。对 2026A 问题 3 的"烘干时长"结论尤其有价值。

2. **全局敏感性分析（Sobol 指数）**〔推理〕：用 `SALib` 做方差分解，输出各参数的一阶与总效应指数，指出"哪个参数最值得精确测量"。这比单参数扫描高一个层次，且计算量可控（$N(p+2)$ 次模型评估）。

3. **用附件 2 的半径数据反演收缩系数**〔推理〕：定义收缩系数 $\beta$，使 $R(t)=R_0[\rho_d(C_0)/\rho_d(\bar C)]^{\beta}$，用附件 2 的数据最小二乘拟合 $\beta$。若 $\beta$ 显著偏离理论值 0.5（圆柱）或 1/3（等比），就给出物理讨论。**这是 2026A 中唯一真正必要且可辨识的反演**。

4. **代理模型加速的反演**〔推理〕：先用 200 次 PDE 求解生成训练集，训练高斯过程或小 MLP 代理，把单次评估从 5 s 降到 1 ms，再在代理模型上做百万次参数搜索，最后用真实模型复核前 10 个候选。报告代理模型的交叉验证误差。

5. **正反演闭环自检**〔推理〕：用正问题生成"人造观测数据"（加 1% 高斯噪声），喂给反演算法，检查能否恢复真参数。这是**不依赖实测数据的最佳验证手段**，2015A(1) 用过类似思路（用 Q1 模型造数据喂 Q2 模型，经度相对误差 0.398%）〔归纳〕。

6. **贝叶斯反演给出后验分布**〔推理〕：用 `emcee` 或 `PyMC` 得到参数后验，画参数对的联合后验等高线图。语料中零先例，视觉冲击力强，且能直接回答"参数能不能定出来"。

## 17. 优秀论文案例

### 17.1 2018A《高温作业专用服装设计》（第一篇）——关系：**完全一致（参数估计主线）**

- **文件名关键词**：`2018A：高温作业专用服装设计.pdf.txt`（4751 行）。
- **它做了什么**：唯一需要反演的参数是换热系数 $h$，采用**变步长多重枚举**：查文献得 $h\in[5,25]$ → 粗扫 $h=8$ 与 $h=9$ 与实测曲线对比定区间 $[8,9]$ → 步长 0.01 遍历得 $\approx8.62$ → 步长 0.0001 在 $[8.1,8.3]$ 再遍历得 $h=8.6125$。用偏差指数 $f=0.4593$ 与最大误差 1.99 °C 作为验证指标〔原文〕。
- **与参数估计卡片的关系**：**完全一致**。它是"参数标定 + 用实测数据验证"的标准范式。
- **注意它的瑕疵**〔归纳〕：① 正文 Step3 写 8.6125、紧接着的符号说明又写 8.6124，代码里统一用 8.6125 —— 正文与代码不一致；② 精度 0.0001 的搜索区间 $[8.1,8.3]$ 与上一步步长 0.01 得到的 8.62 在叙述上打架，程序里实际写的是 `for h=8.61:0.0001:8.63`；③ 阈值 $f<0.5$ 是**自定的、无依据的**通过标准。这些都是第 14 节"常见错误"的实证素材。

### 17.2 2018A《高温作业服设计》（第三篇）——关系：**变体（更规范的最小二乘）**

- **文件名关键词**：`2018A：高温作业服设计.pdf.txt`（2525 行）。
- **它做了什么**：用**最小二乘参数估计**标定两端换热系数
  $$(\hat h_1,\hat h_2)=\arg\min_{h_1,h_2}\sum_{i=1}^{N}\left[T^*(L,t_i;h_1,h_2)-T^{**}(t_i)\right]^2$$
  用 **31×31 网格搜索**，得 $h_1=113$、$h_2=8.344\ \mathrm{W/(m^2\cdot K)}$，残差平方和 3.6552、误差极差 0.0061。并给出可辨识性的**定性诊断**："对流传热系数 $h_1$ 主要影响到达稳态的时间；$h_2$ 主要影响稳态时皮肤外侧温度。"〔原文〕
- **与参数估计卡片的关系**：**变体**。虽然搜索方式仍是网格枚举，但它有明确的统计准则（最小二乘）与两个残差指标，比"看曲线在实测上方还是下方"规范得多。
- **可迁移**：其"参数影响不同特征（时间 vs 稳态值）"的可辨识性诊断，可直接迁移到 2026A 的"$h$ 影响温度场、$k_m$ 影响含水率场"分析〔归纳〕。

### 17.3 2017A《CT系统参数标定及成像》（第一篇）——关系：**相关（误差传递与不确定性）**

- **文件名关键词**：`2017A：CT系统参数标定及成像  (1).pdf.txt`。
- **它做了什么**：对采样函数平方 $h^2(l)$ 作二次多项式最小二乘拟合（`polyfit(...,2)`），由 $-K_2/C_2=\Delta d^2/R^2$ 解析反解探测器间距 $\Delta d$，**180 次取均值**得 0.2768 mm；并用**误差传递公式**推导参数精度（正规方程求协方差、$\delta(\theta)=\delta(\cos2\theta)/|-2\sin2\theta|$ 定位失稳角区、180 次平均使误差降为 $1/\sqrt{180}$），最终给出 $\theta$ 的相对误差 $<10^{-4}$〔原文〕。
- **与参数估计卡片的关系**：**仅相关**（不是 PDE 参数反演），但它是**全语料中唯一做过误差传递与参数不确定性分析的论文**〔归纳〕，是第 4.3 节与第 15 节"不确定性量化"写法的最佳范本。
- **它还做了加噪蒙特卡罗鲁棒性实验**（高斯白噪声 −23.5/−25/−26.5 dB，重复 5 次），并**用已知模板反演误差 ±0.0174 作噪声标尺**，再比较 4 种滤波器的输出波动来选 wiener2。**「用已知样本做噪声标尺再迁移到未知样本」是无真值条件下最实用的验证设计**〔归纳〕。

### 17.4 2017A《CT系统参数标定及反投影重建成像》（第二篇）——关系：**相关（区间估计）**

- **文件名关键词**：`2017A：CT系统参数标定及成像  (2).pdf.txt`。
- **它做了什么**：用**三重区间夹逼**反推探测器间距：由"穿过条数"得 $27d<8<29d$、$107d<30<109d$、$93d<26<95d$，取交集得 $d\in(0.2759,0.2796)$，取 0.2776〔原文〕。
- **与参数估计卡片的关系**：**仅相关**。它给出的是**区间估计而非点估计**——这在方法论上是优点（诚实反映数据的信息量），但依赖于 Excel 色阶的目视判读。

### 17.5 2015A《太阳影子定位》（第一篇）——关系：**相关（L-M 非线性最小二乘）**

- **文件名关键词**：`2015A：太阳影子定位 (1).pdf.txt`。
- **它做了什么**：用 MATLAB `lsqcurvefit`（L-M 实现）反演经纬度、杆长、坐标系转角；**两步策略**：先用影长降维目标估 $(\varphi,\alpha,h)$，再以该解 ±20° 为搜索域做全参数精解；$\lambda_0=10^{-3}$、$v=10$〔原文〕。
- **与参数估计卡片的关系**：**仅相关**（反演的是地理参数而非物理系数），但它是**语料中唯一使用连续优化（L-M）而非网格枚举做参数估计的论文**，第 7.2 节的算法描述即来自它。

### 17.6 2010A《储油罐的变位识别与罐容表标定》——关系：**相关（含额外未知量的反演）**

- **文件名关键词**：`2010A：储油罐的变位识别与罐容表标定 (3).pdf.txt`、`2010A：倾斜卧式储油罐油量标定的实用方法.pdf.txt`。
- **它做了什么**：把纵倾角 $\alpha$、横倾角 $\beta$ 与初始油量 $V_0$ 一起枚举（$\alpha$ 步长 0.01°、$\beta$ 步长 0.1°、$V_0$ 步长 0.01 m³），目标 $\min I(\alpha,\beta)=\sum[(V(h_{i+1})-V(h_i))-x_i]^2$；并用附件 2 随机取 60 组检验〔原文〕。
- **与参数估计卡片的关系**：**仅相关**。它示范了"**额外未知常量与目标参数耦合**"的处理方式，以及"先退化（令 $\alpha=\beta=0$）再对标"的验证思路。
- **它的瑕疵**〔归纳〕：用同一批数据估参又验证（自证）；"多重搜索算法"的第二级窗口窄到近似写死答案。

### 17.7 综合结论〔归纳〕

语料中 14 篇机理类优秀论文的参数估计可归为四大家族：

| 家族 | 代表论文 | 方法 | 主要缺陷 |
|---|---|---|---|
| 确定性网格/枚举 | 2018A(1)(3)、2017A(2)、2010A、2016A(4) | 逐步细化、区间夹逼 | 精度被网格锁死；区间来源不明 |
| 连续优化 | 2015A(1)（L-M）、2011A(1)（GA） | 梯度类/进化类 | 对初值敏感；效果被夸大 |
| 拟合/回归 | 2017A(1)、2013A、2011A(1) | 多项式/幂律/BP | 同源数据自证；黑箱吞掉物理 |
| 反演/标定 | 2018A(2)、2017A(1)(2)、2010A | 数据驱动边界、误差传递、噪声标尺 | 循环论证、参数不唯一 |

**四类共有的缺失**〔归纳〕：**没有一篇给出参数的置信区间，没有一篇做过留出法交叉验证，没有一篇做过参数不确定性向结论的传播**。这三点在 2026A 里都不难实现，是性价比极高的加分项（详见 `数学建模竞赛知识库\_notes\N03_逆向分析_机理微分方程类.md` 的验证手法清单与参数反演方法清单）。
