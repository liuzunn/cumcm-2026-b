# 假设检验与抽样检验

## 1. 模型用途

在数学建模竞赛里，假设检验承担四种角色，缺一不可且不能互换：

1. **差异是否真实存在**：比较两组或多组数据。2012A《葡萄酒的评价_A285》对问题一"分析附件 1 中两组评酒员的评价结果有无显著性差异"的处理是：先用单样本 K-S 检验确定各样本评分数据的概率分布"从而确定显著性差异模型的建立"，再"引入 Wilcoxon 符号秩检验法来进行显著性差异的假设检验"，结论为红、白葡萄酒的两组品酒员评价结果均存在显著性差异〔原文〕。
2. **分布假设是否成立**：后续模型的前提校验。2013A 论文先对实际通行能力做正态性检验，"发现两者的 sig 都大于 0.05，说明两者都服从正态分布"，再"进行方差齐次检验……因此可以通过方差分析直接判断两者是否有显著性差异"〔原文〕。
3. **简化假设是否可接受**：2018A《高温作业服设计》在第一问用有限差分法反演出第一层与第四层换热系数 113 W/(m²·K) 与 8.344 W/(m²·K) 后，"扩展模型并检验忽略热辐射的合理性，考虑辐射传热，两端换热系数为：113 W/(m²·K) 和 8.496 W/(m²·K)。表明热辐射对传热过程影响较小可以忽略"〔原文〕——这是"先忽略→再建模验证"的**假设检验闭环**，而不是拍脑袋写一句"忽略辐射"。
4. **抽样检验（验收抽样）**：给定风险水平，设计检验次数最少的方案。2024B《生产过程中的决策问题》问题一就是标准验收抽样题〔原文，已 read 复核〕。

## 2. 题目特征

- 题面出现"**有无显著性差异**""**是否可信**""**检验**""**验证**""**信度**""**置信水平**"。
- 出现"**抽样**""**检测次数**""**接收/拒收**""**标称值**""**次品率**"——这是验收抽样（2024B）。
- 你的模型依赖某个分布假设（正态、指数、泊松），而数据是实测的——2025 真题里就有"建立……模型，并检验其显著性"〔原文〕。
- 需要对参数给**区间估计**而非点估计：2009B《医院病床合理安排模型探讨》的 Model 4 就是"入院等待时间区间估计模型"，"以附录表中 2008-7-13 至 2008-9-4 的统计信息作为样本，病人等待时间的随机……到其等待时间的区间估计"〔原文〕。

## 3. 数学原理

**核心逻辑（必须写进论文）**：假设检验把"要推翻的保守陈述"设为原假设 $H_0$，在 $H_0$ 成立的前提下计算观测到"至少这么极端"的样本的概率，即 p 值。若 p 值小于预先设定的显著性水平 $\alpha$，则称在 $\alpha$ 水平下**拒绝** $H_0$。

**两类错误**：
- 第一类错误（弃真）：$H_0$ 为真却拒绝，概率 $=\alpha$，即"生产者风险"。
- 第二类错误（取伪）：$H_0$ 为假却未拒绝，概率 $=\beta$。
- 功效（power）$=1-\beta$。**比赛里几乎没人报告 $\beta$，这正是 2024B 抽样检测题的得分点**。

**检验方法的适用条件**（是本卡片最重要的表）：

| 方法 | 适用场景 | 前置条件 | 不满足时的替代 |
|---|---|---|---|
| 单样本 t | 均值 vs 已知常数 | 近似正态或 $n\ge30$（CLT） | Wilcoxon 符号秩 |
| 配对 t | 同一对象两次测量 | 差值近似正态 | Wilcoxon 符号秩 |
| 双样本 t（Student） | 两组均值比较 | 正态 + **方差齐性** | Welch t（不假设等方差） |
| F 检验（方差齐性） | 两正态总体方差比较 | 各自正态 | Levene / Bartlett |
| F 检验（回归整体） | 回归模型整体显著性 | 残差独立同正态、同方差 | 稳健 F / 自助法 |
| 卡方拟合优度 | 频数是否服从某分布 | 每格期望频数 $\ge5$ | 合并类别 / 精确检验 |
| 卡方独立性 | 列联表两变量独立 | 同上 | Fisher 精确检验（小样本） |
| K-S 检验 | 连续分布拟合、两样本分布比较 | 参数**不可**由同一数据估计，否则临界值失效 | Lilliefors 修正版 |
| Shapiro-Wilk | 正态性 | $n$ 约 3—5000，小样本首选 | Anderson-Darling / JB |
| Jarque-Bera | 正态性 | **大样本**（$n\gtrsim100$），基于偏度峰度 | Shapiro-Wilk |
| Wilcoxon 符号秩 | 配对差异 | 差值分布对称 | 符号检验 |
| Mann-Whitney U | 两独立组 | 无 | — |
| Spearman 秩相关 | 单调相关 | 无 | Kendall $\tau$ |

**多重比较校正**：做 $m$ 次检验时族错误率 $=1-(1-\alpha)^m$。Bonferroni 令 $\alpha'=\alpha/m$；Holm 逐步法、Benjamini-Hochberg（FDR）控制更宽松。

**验收抽样（2024B 问题一）的数学结构**：设批量次品率 $p$，抽 $n$ 件中不合格数 $K\sim B(n,p)$。
- 情形（1）"在 95% 的信度下认定零配件次品率**超过**标称值，则**拒收**"：$H_0:p\le p_0$ 对 $H_1:p>p_0$，单侧 $\alpha=0.05$，当 $K\ge c$ 时拒收。
- 情形（2）"在 90% 的信度下认定次品率**不超过**标称值，则**接收**"：$H_0:p\ge p_0$ 对 $H_1:p<p_0$，单侧 $\alpha=0.10$，当 $K\le c$ 时接收。

## 4. 基本公式

**t 统计量**（单样本 / 双样本 / 配对）：

$$t=\frac{\bar X-\mu_0}{S/\sqrt n},\qquad t=\frac{\bar X_1-\bar X_2}{\sqrt{S_1^2/n_1+S_2^2/n_2}},\qquad t=\frac{\bar D}{S_D/\sqrt n}.$$

**F 统计量**（方差比与回归整体检验）：

$$F=\frac{S_1^2}{S_2^2}\ \ (\text{方差齐性}),\qquad F=\frac{SSR/k}{SSE/(n-k-1)}\ \ (\text{回归整体}).$$

**卡方检验**：

$$\chi^2=\sum_{i=1}^{k}\frac{(O_i-E_i)^2}{E_i},\qquad df=k-1-m\ (\text{估计了 } m \text{ 个参数}).$$

**K-S 统计量**：

$$D_n=\sup_x\bigl|F_n(x)-F_0(x)\bigr|.$$

**Jarque-Bera**：

$$JB=\frac{n}{6}\left(S^2+\frac{(K-3)^2}{4}\right)\ \xrightarrow{H_0}\ \chi^2_2,$$

其中 $S$ 为样本偏度、$K$ 为样本峰度。

**Wilcoxon 符号秩统计量**：对差值 $D_i$ 取绝对值排序得秩 $R_i$，

$$W^+=\sum_{i:\,D_i>0}R_i,\qquad E[W^+]=\frac{n(n+1)}{4}.$$

**样本量公式（两风险同时控制）**：

$$n\ \gtrsim\ \frac{\bigl(z_{1-\alpha}\sqrt{p_0(1-p_0)}+z_{1-\beta}\sqrt{p_1(1-p_1)}\bigr)^2}{(p_1-p_0)^2}.$$

**Bonferroni 校正**：$\alpha'=\alpha/m$，或等价地 $p_i^{\text{adj}}=\min(1,\,m\,p_i)$。

**二项精确尾概率**（验收抽样的真值算法）：

$$P(K\ge c\mid n,p)=\sum_{k=c}^{n}\binom{n}{k}p^k(1-p)^{n-k}.$$

## 5. 参数含义

- $\alpha$：显著性水平，也是第一类错误概率（生产方风险）。
- $p$ 值：**在 $H_0$ 成立时**观测到当前或更极端样本的概率。**不是**"$H_0$ 为真的概率"。
- $\beta$：第二类错误概率（使用方风险）；$1-\beta$ 是功效。
- $p_0$：标称值（AQL，可接收质量水平），2024B 中为 10%。
- $p_1$：不可接受质量水平（LTPD），需自行设定，**这是本题最容易被忽略的自由参数**。
- $n$：抽样检测次数；$c$：判定数（接收数/拒收数）。
- $m$：同时进行的检验个数，用于多重比较校正。
- $S,\ S_D$：样本标准差、配对差的标准差。

## 6. 建模步骤

### 6A. 一般假设检验流程
1. **明确问题**：差异/拟合/独立性，选检验族。
2. **设定 $H_0$ 与 $H_1$**：把"想推翻的、保守的"放 $H_0$；单侧还是双侧必须由题意决定，不能事后选。
3. **选 $\alpha$**：比赛里写"取 $\alpha=0.05$"即可，但要说明理由。
4. **校验前置条件**：正态性（Shapiro-Wilk，$n<50$；JB，$n>100$）、方差齐性（F 或 Levene）、期望频数（卡方）。**不满足就换非参数检验**。
5. **计算统计量与 p 值**，必要时给效应量与置信区间。
6. **多重比较校正**（若 $m>1$）。
7. **结论表述**：只写"在 $\alpha=0.05$ 水平下拒绝/不拒绝 $H_0$"，并给实际含义。

### 6B. 验收抽样方案设计（2024B 问题一）
1. 确定 $p_0=0.10$、$\alpha$（情形 1 为 0.05，情形 2 为 0.10）。
2. 设定 $p_1$（建议取 $1.5p_0=0.15$ 或 $2p_0=0.20$）与目标功效 $1-\beta=0.8$。
3. 用正态近似公式算初值 $n_0$，再用**二项精确尾概率**枚举修正最小的 $n$。
4. 对每个候选 $n$ 求判定数 $c^\*=\min\{c:P(K\ge c\mid n,p_0)\le\alpha\}$（情形 1）或 $c^{\*\*}=\max\{c:P(K\le c\mid n,p_0)\le\alpha\}$（情形 2）。
5. 给出 OC 曲线（接收概率随 $p$ 变化）与双风险表。
6. 计算检测总成本，与"检测次数尽可能少"的目标对照。

**二项精确计算示例**〔推理，由本卡片用精确二项分布枚举算得〕：$p_0=0.10$、$\alpha=0.05$ 时，
- $n=150,\ c=22$（实际 $\alpha=0.0440$），在 $p_1=0.15$ 处功效仅 0.5804；
- $n=254,\ c=34$（实际 $\alpha=0.0495$），$p_1=0.15$ 处功效 0.7885；
- $n=300,\ c=40$（实际 $\alpha=0.0378$），$p_1=0.15$ 处功效 0.8121，在 $p_1=0.20$ 处功效 0.9990。

即：若要求"次品率真为 15% 时能以 80% 把握查出"，所需检测次数约 300 件。这说明**"检测次数尽可能少"必须与功效约定绑定**，否则 $n=2$、$c=2$ 也是数学上合法的方案。

## 7. 算法

**算法 A：t 检验**
1. 计算 $\bar X$、$S$、$n$。
2. 若 $n<30$，先做正态性检验；不通过则转 Wilcoxon。
3. $t=(\bar X-\mu_0)/(S/\sqrt n)$；$df=n-1$。
4. $p=2\,(1-F_t(|t|))$（双侧）；查 $t$ 分布表或用库函数。
5. 输出 $t$、$df$、$p$、均值差的 95% 置信区间。
- 复杂度：$O(n)$ 时间，$O(1)$ 空间。

**算法 B：单因素方差分析（ANOVA）**
1. 计算组间平方和 $SSB=\sum_j n_j(\bar X_j-\bar X)^2$、组内 $SSW$。
2. $F=(SSB/(k-1))/(SSW/(n-k))$，$df_1=k-1$，$df_2=n-k$。
3. 若 $F$ 显著，做事后多重比较（Tukey HSD 或 Bonferroni）。
- 复杂度：$O(n)$ 时间；Tukey 步骤 $O(k^2)$。

**算法 C：K-S 拟合检验**
1. 排序样本 $X_{(1)}\le\dots\le X_{(n)}$。
2. $D^+=\max_i\bigl(\frac{i}{n}-F_0(X_{(i)})\bigr)$，$D^-=\max_i\bigl(F_0(X_{(i)})-\frac{i-1}{n}\bigr)$，$D=\max(D^+,D^-)$。
3. 查临界值 $D_{n,\alpha}$ 或用渐近分布 $P(\sqrt n D>z)\approx2\sum(-1)^{j-1}e^{-2j^2z^2}$。
4. **若分布参数是从同一数据估的，必须用 Lilliefors 修正临界值**。
- 复杂度：排序 $O(n\log n)$，扫描 $O(n)$。

**算法 D：验收抽样方案枚举**
1. for $n=n_{\min}$ to $n_{\max}$。
2. 对给定 $n$，求 $c^\*$ 使 $\sum_{k\ge c}\binom{n}{k}p_0^k(1-p_0)^{n-k}\le\alpha$。
3. 计算功效 $1-\beta=P(K\ge c^\*\mid n,p_1)$。
4. 若功能够，记录 $(n,c^\*)$ 并 break（因 $n$ 递增，第一个满足者即最小 $n$）。
- 复杂度：$O(n_{\max}^2)$ 次概率项计算（可用递推降到 $O(n_{\max})$）；实际 $n\le500$ 时毫秒级。

## 8. Python实现思路

- 首选 scipy.stats：ttest_ind(equal_var=False) 做 Welch t；ttest_rel 做配对 t；f_oneway 做 ANOVA；chisquare / chi2_contingency 做卡方；kstest / ks_2samp 做 K-S；shapiro 做 S-W；mannwhitneyu / wilcoxon 做非参数；levene 查方差齐性。
- Jarque-Bera 用 statsmodels.stats.stattools.jarque_bera；多重比较用 statsmodels.stats.multitest.multipletests(method='bonferroni'/'holm'/'fdr_bh')。
- 验收抽样用 scipy.stats.binom.sf(k-1, n, p0) 求 $P(K\ge k)$，binom.cdf 求 $P(K\le k)$；**不要用正态近似**，本题 $n$ 只有几百，精确值可算。
- 报告规范：统一输出"统计量、自由度、p 值、置信区间、效应量（Cohen's d / $\eta^2$）"五元组。
- 易错点：kstest 传入的是**标准化后**的样本会低估 $D$；shapiro 在 $n>5000$ 时会告警。

## 9. MATLAB实现思路

- 函数对照：ttest / ttest2（可指定 'Vartype','unequal' 做 Welch）、anova1 / anova2、chi2gof、kstest / kstest2、lillietest（Lilliefors）、swtest（需第三方，或 jbtest 做 JB 检验）、ranksum、signrank、corr 带 'type','Spearman'。
- 方差齐性：vartest2（F 检验）、vartestn（多组）。
- 多重比较：multcompare(stats) 做 Tukey；或手动 Bonferroni 调整 p = min(1, p*m)。
- 验收抽样：binocdf / binopdf 精确计算，写 for 循环枚举 $n$ 即可。
- 2012A 那篇用的是"MATLAB、SPSS、SAS 和 EXCEL 等软件"组合〔原文〕，比赛里 SPSS 做正态性/方差齐性界面友好，MATLAB 做批量计算更快。
- 易错点：jbtest 默认对**小样本**不可靠；kstest 单样本时若第二个参数给的是估计出来的参数，MATLAB 同样不会自动修正临界值。

## 10. 优点

1. **给出"差异是否真实"的量化判据**，避免把噪声当结论。2013A 论文用"p=0.20，接受原假设，两组数据不存在显著性差异"来证明元胞自动机模型可行〔原文〕，这是检验的正面用法。
2. **可把主观假设变成可证伪命题**。2018A 高温作业服"扩展模型并检验忽略热辐射的合理性"就是范本〔原文〕。
3. **验收抽样直接对应工程与商业决策**，2024B 的问题 1—4 全链条都依赖它。
4. 计算量极小，几乎是$O(n)$，不占用赛程时间。

## 11. 缺点

1. **只回答"是否"，不回答"多大"**：p 值小不等于效应大，必须补置信区间与效应量。
2. **强依赖前置条件**：t 检验对非正态与异方差敏感；K-S 对参数估计极敏感。
3. **多重比较会制造假阳性**：做 15 次检验时族错误率可达 $1-0.95^{15}\approx54\%$。2023 展示论文 C235 明确写了"两两检验，共进行 15 次检验"并逐组报告 p 值〔原文〕——**做了 15 次检验却不做校正**是常见失分点。
4. **对样本量高度敏感**：$n$ 大时微小差异也显著，$n$ 小时真实差异也查不出。

## 12. 适用条件

当且仅当下列条件满足时可以使用：

- 当数据是**随机样本**（非全总体、非人为挑选）时，可以做推断统计；2024B 明说次品率"是通过抽样检测方法得到的"，正是为问题 4 的误差传播铺垫〔原文〕。
- 当 $n\ge30$ 或样本近似正态时，可以用 t/F；否则必须换非参数。
- 当卡方检验每格期望频数 $\ge5$ 时，可以用卡方；否则需合并类别或改用 Fisher 精确检验。
- 当只有一个或少数预设假设时，可以不做校正；当检验数 $m>1$ 时，**必须**校正。
- 对 2026A 药材烘干题：当需要给出反演参数（如等效导热系数、对流传质系数 $k_m=8\times10^{-7}$ m/s）的**置信区间**，或检验"忽略某物性随含水率变化是否可接受"时，可以用 t 检验/F 检验/残差正态性检验〔推理〕。

## 13. 不适用情况

- 当检验是在看过数据之后才提出假设时（HARKing），不可以声称 p 值有效。
- 当样本不是随机抽取，而是全量数据（如 2005A 长江水质全部监测站点数据）时，不可以做"总体推断"式的假设检验，只能做描述统计或拟合优度。
- 当用 K-S 检验分布拟合、且分布参数由同一批数据估计，又直接查标准 K-S 临界值时，结论**不可以**采信（第一类错误被严重放大）。
- 当 $p_1$ 未设定就宣称"检测次数最少"时，2024B 问题一的方案**不可以**成立——缺乏功效约定时不存在唯一最优 $n$。
- 对 2026A 药材烘干题：当只做确定性 PDE 正问题求解、尚无可重复观测数据时，不可以对数值解做"显著性检验"；此时有效的检验对象是**数值解与解析解/网格收敛性**（如不同网格下解的差异是否随 $h^2$ 收敛），而不是统计假设检验〔推理〕。

## 14. 常见错误

1. **把"不拒绝 $H_0$"说成"接受 $H_0$"**（最严重、最高频）。反例见 2013A 优秀论文《基于差分方程和元胞自动机的交通阻塞模型》：该文对等待时间做 Jarque-Bera 检验，"得到的 P-value 为 $p=0.2475$，即在 $\log(t)$ 服从正态分布的条件下，出现实际数据中分布的概率为 0.2475。因此我们可以**接受原假设**，即时间服从对数正态分布"〔原文〕。严格表述应是"在 $\alpha=0.05$ 水平下**不能拒绝** $H_0$"，因为 $p=0.2475$ 只说明数据与正态假设不矛盾，不能证明正态成立。正确写法："$p=0.2475>\alpha=0.05$，故在 5% 显著性水平下不拒绝正态性假设；结合 Q-Q 图与偏度峰度，认为采用对数正态分布建模是合理的。"

2. **把原假设设反，或者设成"有差异"**。2023 展示论文 C050 在 Spearman 检验中写"原假设 $H_0$：Spearman 系数 $R\neq0$"，在 Pearson 检验中同样写"原假设 $H_0$：Pearson 相关系数 $R\neq0$"〔原文〕。相关检验的 $H_0$ 必须是"**不相关**（$R=0$）"，否则弃真/取伪的含义完全颠倒，整个结论作废。**正确做法**：$H_0:\rho=0$，$H_1:\rho\ne0$。

3. **p 值算出来是 0，却写成"接受原假设"**。同一篇 C050 论文写"由表 4 可知，六大蔬菜品类任意两者之间的 P 值均为 0，故**接受原假设**，可认为……"〔原文〕。$p\approx0$ 意味着极强的证据**拒绝** $H_0$。**正确做法**：$p<0.001$ 时写"在 0.001 水平下拒绝 $H_0$"，并报告效应量方向。

4. **不做前置条件检验直接用 t/F**。2013A 另一篇论文（《…(4)\_5486》）的正确顺序值得抄："方差分析需要通过正态检验和方差齐次检验，如果不通过这两种检验则需要进行非参数检验"，随后逐项给出正态性检验与齐次性检验的 sig 值〔原文〕。跳过这两步直接用 ANOVA，一旦前提不成立，p 值不可信。

5. **多重比较不校正**。C235 明确"两两检验，共进行 15 次检验"〔原文〕，15 次独立检验在 $\alpha=0.05$ 下的族错误率约 54%。**正确做法**：Bonferroni（$\alpha'=0.05/15\approx0.0033$）或 BH-FDR 校正，并在论文中说明所用方法。

6. **把 p 值当"原假设为真的概率"**。p 值是 $P(\text{数据}\mid H_0)$，不是 $P(H_0\mid\text{数据})$。要后者必须用贝叶斯因子或后验概率。

7. **验收抽样只做单点风险控制**。2024B 问题一若只算 $n$ 使 $\alpha\le0.05$，会得到荒谬的小 $n$（$n=2,c=2$ 即满足 $\alpha=0.01$）。必须同时约定 $p_1$ 与 $\beta$，画 OC 曲线，否则"检测次数尽可能少"无从比较。

8. **对 2026A 的坑**：把 PDE 数值解在若干时刻的离散值当成独立样本做 t 检验。同一时间推进序列内的相邻时刻解**高度自相关**，有效自由度远小于名义 $n$，会系统性低估 p 值。正确做法是做**网格收敛性**分析（比较 $N_r=21,41,81$ 的解），或用批均值法去相关〔推理〕。

## 15. 论文写法

**可套用句式**：

- "为判断两组数据是否存在显著差异，本文首先检验其分布特征。对……做 Shapiro-Wilk 正态性检验，得 $p=$……；对……做 F 检验得方差齐性 $p=$……。由于两项前提均满足（$p>0.05$），采用双样本 t 检验；否则改用 Mann-Whitney U 检验。"
- "检验结果为 $t=$……，$df=$……，$p=$……。在显著性水平 $\alpha=0.05$ 下拒绝原假设 $H_0$，认为两组数据存在显著差异；均值差的 95% 置信区间为 $[\cdot,\cdot]$，对应 Cohen's $d=$……，属中等效应。"
- "由于本文共进行 $m=$…… 次两两比较，为控制族错误率，采用 Bonferroni 校正取 $\alpha'=\alpha/m=$……；校正后仍有 $k$ 对比较显著。"
- "为验证'忽略热辐射'这一简化假设，本文建立含辐射项的扩展模型并重新反演参数，得到……与简化模型的……相差……%，在工程允许误差范围内，故该简化是合理的。"（仿 2018A 高温作业服写法）
- 验收抽样："设抽检 $n$ 件的不合格品数 $K\sim B(n,p)$。情形（1）取 $H_0:p\le0.10$、$\alpha=0.05$，当 $K\ge c$ 时拒收；为使次品率真为 15% 时仍有 80% 把握查出，需 $n=300,\ c=40$，此时实际 $\alpha=0.0378$、功效 0.8121。"

**配图建议**：
1. **Q-Q 图**（正态性直观验证）+ 直方图叠正态密度。
2. **箱线图/小提琴图**分组对比（配显著性星号标记，注明检验方法）。
3. **OC 曲线**（接收概率 vs 次品率 $p$），标出 $p_0$、$p_1$、$\alpha$、$\beta$ 四个点——2024B 必备。
4. **p 值森林图**：多组比较时把效应量与置信区间横向排列，比表格更易读。
5. **假设检验闭环图**：简化模型 vs 扩展模型的参数对比柱状图（仿 2018A 辐射验证）。

## 16. 可创新方向

1. **Bootstrap 取代参数检验（半天可做）**：对任意统计量（中位数、分位数、变异系数）用 10000 次重抽样构造经验分布，完全绕开正态假设。可给 p 值也可给置信区间。
2. **贝叶斯假设检验（1 天可做）**：用贝叶斯因子或后验概率 $P(H_0\mid\text{数据})$ 取代 p 值，直接回答"次品率超过 10% 的概率是多少"——与 2024B 的"信度"表述天然契合，且可以给出完整后验分布。
3. **序贯抽样方案（SPRT，1 天可做）**：2024B 问"检测次数尽可能少"，序贯概率比检验（Wald's SPRT）平均样本量可比固定样本方案少 30%—50%，是极强的加分项。
4. **OC 曲线族 + 成本最优（半天可做）**：把检测成本、误收成本、误拒成本写成期望总成本函数，对 $(n,c)$ 二维优化，得到经济最优抽样方案。
5. **多重比较 + FDR 可视化（半天可做）**：把 15 组两两检验的 p 值与 BH 阈值画成排序图，直观展示校正前后差异。
6. **对 2026A 的结合点**：把反演出的物性参数做成**带置信区间的参数集**，再跑 PDE 看烘干时长区间，比给单点值更有说服力〔推理〕。

## 17. 优秀论文案例

### 案例 1：2012A《葡萄酒的评价_A285》——关系：**完全一致**

**论文文件名关键词**：\`2012A：葡萄酒的评价_A285.pdf.txt\`（已 read 复核）。

**它做了什么**〔原文〕：针对问题一"分析附件 1 中两组评酒员的评价结果有无显著性差异，哪一组结果更可信"，其技术路线为"首先通过单样本 K-S 检验等方法确定了各葡萄酒样本评分数据的概率分布，从而确定了显著性差异模型的建立，接着考虑两组评分数据的配对关系约束，引入 Wilcoxon 符号秩检验法来进行显著性差异的假设检验。结果显示对于红、白葡萄酒，两个品酒组的评价结果均存在显著性差异。最后利用秩相关分析，引入肯德尔和谐系数……"。论文明确说明"此时不适用参数检验的方法，而只能用非[参数方法]"。

**可借鉴点**：**先定分布、再选检验族**的决策链写得极清楚——这是"检验方法选用条件"的标准答题模板。

### 案例 2：2018A《高温作业服设计》——关系：**完全一致（假设检验闭环）**

**论文文件名关键词**：\`2018A：高温作业服设计.pdf.txt\`（已 read 复核）。

**它做了什么**〔原文〕：先用有限差分法反演出第一层与第四层换热系数 113 W/(m²·K) 和 8.344 W/(m²·K)；随后"扩展模型并检验忽略热辐射的合理性，考虑辐射传热，两端换热系数为：113 W/(m²·K) 和 8.496 W/(m²·K)。表明热辐射对传热过程影响较小可以忽略"。模型假设中明确写"假设 1：不考虑作业服水汽、汗液蒸发等传热传质过程；假设 5：人体为绝对黑体，即辐射发射率为 1"。

**可借鉴点**：**对 2026A 药材烘干题直接可用**——把"忽略物性随含水率变化""忽略药材收缩""忽略辐射"等简化假设，用"扩展模型重算 + 参数对比"的方式验证，而不是在假设列表里写一句就完事〔推理〕。

### 案例 3：2013A《车道被占用对城市道路通行能力的影响》两篇——关系：**一正一反，均可引**

- **正向**：\`2013A：车道被占用…(4)_5486.docx.txt\` 完整走了"正态检验 → 方差齐次检验 → 方差分析"流程，并写明"方差分析需要通过正态检验和方差齐次检验，如果不通过这两种检验则需要进行非参数检验"；结论"使用方差分析得到同一横断面交通事故所占车道不同对该横断面实际通行能力的影响无显著性差异"，随后又用通径分析深挖〔原文〕。
- **反向（踩坑示范）**：\`2013A：车道被占用…(5)_基于差分方程和元胞自动机的交通阻塞模型.pdf.txt\` 对等待时间做 Jarque-Bera 检验，得到"P-value 为 $p=0.2475$"，却写"因此我们可以接受原假设"〔原文〕——**不拒绝 ≠ 接受**，第 14 节第 1 条即源于此。

### 案例 4：2023 展示论文 C050 / C235 ——关系：**C235 为正面，C050 为反面**

### 案例 5：2024B《生产过程中的决策问题》——关系：**完全一致（验收抽样）**
