# 非线性规划

> **证据等级说明**：〔原文〕= 语料中直接读到的句子/标题；〔归纳〕= 从多篇语料共有的写法中归纳；〔推理〕= 无直接语料支撑、由模型性质推出的判断。

## 1. 模型用途

当目标或约束里出现**乘积、平方、开方、三角、分式、对数、绝对值、最大值**时就该想起它。国赛里最常出现的三类：

1. **几何最优化**：距离、面积、覆盖率、路径长度（2010C 输油管布置、2023B 覆盖宽度）；
2. **费用非线性的经济问题**：运输费按吨公里计价、损耗按比例、收益按价格弹性（2000B 钢管订购运输、2023C 定价）；
3. **拟合/参数标定型**：把模型参数当成变量，让残差平方和最小——本质上也是 NLP（大量机理题的第 1 问）。

**一句话判断**：先按 LP 写，如果有一条约束是弯的，就换 NLP。

## 2. 题目特征

1. **题眼词**："尽量大/最小/最优"且含**几何量**（距离、角度、面积、体积）。
   - 2023B："请设计一组测量长度最短、可完全覆盖整个待测海域的测线"〔原文〕
   - 2010C：输油管布置，正文自述"所建立的模型具有一定的普适性，可以应用到选址问题的求解"〔原文〕
2. **成本函数带平方/分段/比例**："每吨公里的运输费""损耗率"。
   - 2000B 系列论文明确讨论"非线性费用的网络流模型"〔原文〕
3. **变量是连续的设计参数**：高度、厚度、半径、角度、系数。
   - 2018A："确定 II 层的最优厚度，确保工作 60 分钟时，假人皮肤外侧温度不超过 47 ºC"〔原文，N02 编目〕
4. **题目要"最优 XX 系数"**：
   - 2022A："建立确定直线阻尼器的最优阻尼系数的数学模型"〔原文〕
5. **给出大量数据 + 一个带参数的模型**：要你反演参数（曲线拟合、参数辨识）。

## 3. 数学原理

**来源**：NLP 的理论基础是 KKT 条件（Karush 1951、Kuhn–Tucker 1951）与无约束最优性条件（Fermat、Cauchy 最速下降、Newton 法）〔推理，属通用理论〕。

**标准形式**：

$$\min_{x\in\mathbb{R}^n} f(x)\quad \text{s.t.}\quad g_i(x)\le 0,\; h_j(x)=0$$

**成立前提与关键区别**：

1. **凸性决定"是否全局最优"**：若 $f$ 凸、$g_i$ 凸、$h_j$ 仿射，则任何 KKT 点都是全局最优；否则 KKT 点只是**局部最优**，必须多起点重启。
2. **约束规范（constraint qualification）**：KKT 需要 LICQ 等正则性条件成立，退化点处 KKT 可能失效。
3. **可微性**：梯度类算法要求 $f,g$ 至少一阶可微；含 $\max$、$|\cdot|$ 时要么光滑化，要么用无导数方法。
4. **规模**：中小规模（变量 $\le$ 数百）可直接梯度法；大规模需稀疏化或用分解。

**KKT 条件**（论文里写出来会显得专业）：

$$\nabla f(x^*)+\sum_i\mu_i\nabla g_i(x^*)+\sum_j\lambda_j\nabla h_j(x^*)=0$$
$$\mu_i\ge0,\quad \mu_i g_i(x^*)=0,\quad g_i(x^*)\le0,\quad h_j(x^*)=0$$

其中 $\mu_i g_i(x^*)=0$ 称**互补松弛**，含义正是"约束没起作用就没有代价"。

## 4. 基本公式

**一般 NLP**：

$$\min\; f(x)=\sum_{k} w_k f_k(x) \quad \text{s.t.}\quad g_i(x)\le 0,\; \underline{x}\le x\le \overline{x}$$

**几何型目标（覆盖/选址常见）**：

$$\min\; L=\sum_{i}d_i,\quad d_i=\sqrt{(x-x_i)^2+(y-y_i)^2}$$

**拟合型目标（最小二乘）**：

$$\min_{\theta}\; S(\theta)=\sum_{k=1}^{N}\bigl(y_k-\hat{y}(x_k;\theta)\bigr)^2$$

**惩罚函数法**（把约束搬到目标里，实现简单）：

$$\min\; P(x,\rho)=f(x)+\rho\sum_i \max\bigl(0,g_i(x)\bigr)^2+\rho\sum_j h_j(x)^2,\quad \rho\uparrow\infty$$

**效率/覆盖率类分式目标**（2023B 型）可直接写成覆盖宽度公式：

$$W=\frac{D\sin\theta}{\cos\alpha}\cdot\frac{1}{\cos\bigl(\theta/2+\alpha\bigr)}$$

（具体形式依赖题给几何关系，**论文中必须自己推导并画图**〔归纳〕）

## 5. 参数含义

| 符号 | 含义 | 例 |
|---|---|---|
| $x$ | 连续设计变量 | 输油管汇合点坐标、镜面尺寸、层厚 |
| $f(x)$ | 目标（费用、面积、误差） | 2000B 的运输 + 订购总费用 |
| $g_i(x)\le0$ | 不等式约束 | 覆盖重叠率 10%~20%、温度 ≤ 47 ºC |
| $h_j(x)=0$ | 等式约束 | 几何关系式、守恒方程 |
| $w_k$ | 多子目标权重 | 费用 vs 损失 |
| $\mu_i,\lambda_j$ | 拉格朗日乘子 | 影子价格、灵敏度 |

## 6. 建模步骤

1. **写清几何/物理关系**：NLP 的分全在"关系式推得对不对"，先把图与符号定义画出来。
2. **定决策变量与可行域**：注意上下界必须写（大量求解器的失败源于没有界）。
3. **构造目标**：单目标就写费用/误差；多子目标先分层或加权，说明权重来源。
4. **检验凸性**：能证明凸就写"全局最优"；不能证明就写"多起点求解以缓解局部最优"。
5. **选择算法**：光滑小规模 → SLSQP/内点；有界约束 → L-BFGS-B/trust-constr；有整数 → MINLP 或先松弛后圆整。
6. **多起点重启**：随机或网格生成初值，取最好解；论文里报告最好/中位/最差。
7. **残差与约束残差检查**：报告最大约束违反量。
8. **灵敏度分析**：对关键参数做扰动曲线。

## 7. 算法

1. **无约束**：
   a. 选初值 $x_0$，计算 $\nabla f(x_0)$。
   b. 沿负梯度/牛顿方向取步长（线搜索满足 Armijo/Wolfe 条件）。
   c. 更新 $x_{k+1}=x_k+\alpha_k d_k$，直到 $\|\nabla f\|<\epsilon$。
   - 收敛速度：最速下降线性收敛，牛顿法局部二次收敛；BFGS 拟牛顿为超线性。
2. **约束**：
   a. **序列二次规划（SQP）**：每步解一个 QP 子问题，对中小规模最稳。
   b. **内点法**：把不等式化为障碍项，多项式时间，适合大规模稠密。
   c. **信赖域（trust-constr）**：对强非线性、约束边界弯曲的问题更稳。
   d. **罚函数/增广拉格朗日**：实现简单，但 $\rho$ 过大导致病态。
3. **无导数方法**（梯度不可得/目标由仿真给出）：Nelder–Mead、模式搜索、CMA-ES、贝叶斯优化（贵目标）。
4. **全局方法**：多起点 + 局部精修（最实用）；差分进化、模拟退火（2023A A165 用"三分查找 + 蒙特卡洛"，B226 用"模拟退火"〔原文〕）。
5. **复杂度**：单次迭代 $O(n^3)$（牛顿/内点，稠密）或 $O(n^2)$（拟牛顿）；无导数方法随维数指数退化——**变量超过 50 个时不要用 Nelder–Mead**。

## 8. Python实现思路

- **SciPy**：`minimize(fun, x0, method='SLSQP', bounds=..., constraints=...)`；有界优先 `L-BFGS-B`；强约束用 `trust-constr`。
- **约束写法**：`constraints=[{'type':'ineq','fun':lambda x: g(x)}, {'type':'eq','fun':h}]`，注意 `ineq` 约定是 $\ge0$——**与数学模型里的 $\le0$ 符号相反，是最常见的翻车点**。
- **cvxpy**：若问题可表达为 DCP（凸），`cp.Problem(cp.Minimize(f), cons).solve()` 给出全局最优；**先试 cvxpy，能过就说明是凸的**。
- **scipy.optimize.least_squares / curve_fit**：拟合型问题的专用工具，比通用 minimize 稳得多。
- **Pyomo + Ipopt**：大规模带约束 NLP，支持自动微分（`pyomo.dae` 还能处理微分方程约束）。
- **易错点1**：符号约定（ineq 是 $\ge0$）写反，结果被优化到反方向。
- **易错点2**：不给 `bounds` 导致变量跑到负值（如负半径、负厚度）。
- **易错点3**：只跑一次 `minimize` 就报最优，实际上陷在局部极值。**必须多起点**。
- **易错点4**：目标函数里有除法/开方，初值取到分母为 0 处，直接 NaN。
- **易错点5**：`success=False` 但 `fun` 看着不错，直接采用；应检查 `message` 与约束违反量。

## 9. MATLAB实现思路

- **首选**：`fmincon(fun, x0, A, b, Aeq, beq, lb, ub, nonlcon, options)`，`nonlcon` 返回 `[c, ceq]`，约定 $c\le0,\;ceq=0$（**与 SciPy 符号约定相反，务必看清**）。
- **算法选择**：`'sqp'`（默认，中小规模）、`'interior-point'`（大规模）、`'trust-region-reflective'`。
- **全局**：`MultiStart` + `fmincon`，或 `GlobalSearch`；`patternsearch` 用于无导数。
- **拟合**：`lsqcurvefit` / `lsqnonlin` 优于通用 `fmincon`。
- **优化变量**：`optimvar` + `optimproblem` 支持非线性表达式，可直接写公式。
- **易错点1**：`nonlcon` 的返回顺序是 `[c, ceq]`，写反会导致约束完全错位。
- **易错点2**：`fmincon` 不做全局搜索，初始点选择决定结果。
- **易错点3**：`MaxFunctionEvaluations` 默认 3000 常不够，会提前退出。
- **易错点4**：目标函数里用 `abs`、`max` 时不可微，SQP 可能卡住，需改写成光滑近似。
- **易错点5**：把 `fmincon` 当成求解 MINLP 的工具（它不支持整数变量，需用 `ga`/`intlinprog` 组合）。

## 10. 优点

1. **表达能力强**：真实世界的费用、几何、物理关系几乎都非线性。
2. **变量少时非常高效**：几十个变量的光滑问题，毫秒到秒级。
3. **理论完备**：KKT 条件给出一阶必要性，可直接做灵敏度与对偶分析。
4. **可处理隐式约束链**：目标函数可以内部调用仿真/PDE 求解器（无导数方法）。
5. **与机理模型天然衔接**：机理题的第 1 问就是"参数辨识"，正是 NLP。

## 11. 缺点

1. **局部最优陷阱**：非凸问题的解依赖初值，必须多起点且报告分布。
2. **无最优性证书**：不像 MILP 能报 gap，NLP 只能说"这是找到的最好解"。
3. **对尺度敏感**：变量量级差 10^6 时收敛极慢甚至失败。
4. **无导数方法维数灾难**：变量一多就完全失效。
5. **约束可行性难保证**：很多算法只保证"接近可行"，需手工校验。

## 12. 适用条件

- **当**目标或约束是光滑非线性、变量连续、维数在几十到几百之间时，用 NLP。
- **当**你能证明（或至少论证）问题是凸的，用 NLP 可以宣称全局最优。
- **当**问题是"给定模型形式反演参数"或"最优设计参数"时，用 NLP。
- **当**目标由黑箱仿真给出（PDE/离散事件）时，用无导数 NLP/贝叶斯优化。
- **与本三题相关的明确判断**：
  - **2026B**：**有明确用武之地**。问题1 的"多边形定位区域直径"本身是几何量（可由示向度 ±1° 的两条射线交会出的四边形，直径 = 对角顶点最大距离）；问题2 的"第二个检测点选择策略"可写成 $\min$ 定位区域直径的几何最优问题。但注意：**这是几何解析式，通常可解析求解**，NLP 仅在你要做多检测点联合优化时才需要。 〔原文 + 推理〕
  - **2026C**：一般**不要用** NLP。除非你把"储能充放电效率随功率变化"或"电价随购电量阶梯上升"建成非线性函数——那属于自找麻烦，先试分段线性化。 〔推理〕
  - **2026D**：**不适用**。D 题的全部关系都是区间交叠的离散逻辑，是组合优化，不是 NLP。 〔推理〕

## 13. 不适用情况

- **当**问题是凸的且能被 LP/MILP 表达时，**不要用 NLP**——LP 给全局最优和影子价格，NLP 只给局部解。
- **当**变量必须取整数时，不要用纯 NLP（"2.7 辆车"不可接受），需用 MINLP 或启发式。
- **当**目标不可微且维数 > 50 时，不要用 Nelder–Mead/模式搜索，应改梯度近似或代理模型。
- **当**问题是大规模组合结构（TSP、调度、图着色）时，不要硬套 NLP 连续松弛，会得到毫无意义的小数解。
- **当**题面所有关系都是线性时，用 NLP 只会更慢更不稳。

## 14. 常见错误

1. **符号约定写反**：SciPy 的 `ineq` 要求 $\ge0$，MATLAB 的 `nonlcon` 要求 $\le0$。这是 NLP 第一大坑。
2. **单起点求最优**：直接 `minimize` 一次就写"最优解"，实际是局部极值。至少 50 个随机起点，报告最优/最差/成功率。
3. **忘了给变量界**：半径、厚度、角度跑到负值，几何式里开方直接 NaN。
4. **尺度不归一**：一个变量是 10^-3（层厚 0.15 mm），另一个是 10^4（坐标），收敛极慢。**先做无量纲化**。
5. **约束残差没检查**：`success=True` 只代表终止条件满足，不代表约束被满足；必须打印 $\max_i \max(0,g_i(x^*))$。
6. **把非凸问题当凸问题报全局最优**：评审一问"你怎么保证全局"就答不上来。
7. **数值微分精度不当**：有限差分步长过大/过小都会让梯度不准；能解析求导就解析求导（或用 autograd/JAX）。
8. **目标函数有噪声**（如目标含蒙特卡洛仿真）：梯度类方法完全失效，应改用 CMA-ES 或贝叶斯优化并固定随机种子。

## 15. 论文写法

**可套用句式**：

1. "以汇合点坐标 $(x,y)$ 为决策变量，以管线总造价 $\min\; C=\sum c_i l_i(x,y)$ 为目标，建立非线性规划模型；由于目标含欧氏距离，模型非凸，本文采用多起点 SLSQP 求解并报告最优、中位与最差结果。"
2. "对目标函数与约束分别求梯度，得 KKT 条件：……；由互补松弛条件 $\mu_i g_i(x^*)=0$ 可知，在最优解处重叠率约束取等号，说明该约束是紧的。"
3. "为缓解局部最优，本文在可行域内均匀生成 200 个初始点，各运行一次 SLSQP，其中 187 次收敛到同一解，据此认为该解具有较高的可信度。"
4. "灵敏度分析表明，当运输单价上浮 10% 时，最优选址点向原料产地移动约 3.2 km，说明模型对运输成本较为敏感。"

**应配的图表**：

- **几何示意图**（把决策变量、约束边界、最优解位置画在图上，NLP 论文没有这张图基本会被扣分）；
- **目标函数等值线/曲面图**（横纵轴为两个主要变量，叠加可行域边界与最优点）；
- **收敛曲线**（迭代次数 vs 目标值，多起点叠加）；
- **多起点解分布直方图**（说明非凸性）；
- **参数灵敏度曲线**。

## 16. 可创新方向

1. **凸化/凸松弛**：把非凸约束转成二阶锥（SOCP）或半定松弛，给出全局下界并报告与局部解的 gap——这是 NLP 论文里最能加分的技术动作。〔推理〕
2. **多目标 NLP + Pareto 前沿**：把"费用"与"覆盖质量"同时优化，用 NSGA-II 求前沿（与《多目标优化与Pareto前沿》联动）。
3. **鲁棒 NLP**：参数带区间时求"最坏情况下最优"（min-max），可用情景化近似。
4. **代理模型 + 贝叶斯优化**：目标需调用 PDE/仿真时（如 2026B 的路径-检测耦合仿真），用高斯过程代理显著降本。〔推理，与 2026B 相关〕
5. **混合整数非线性（MINLP）**：给 2026D 型问题加上连续平移量，或用 MINLP 表达"调整幅度连续但选择离散"的结构——注意规模控制。
6. **与 2026B 的具体结合点**：把"检测点选择 → 定位区域直径"写成几何最优问题并给出**解析解 + 数值验证**两条路，比单纯数值搜索更显水平。〔推理〕
7. **与 2026C 的结合点**：若把储能效率建模为功率的凹函数（效率曲线），则问题变为凹最大化（仍是凸优化），可作为"更精细建模"的创新点，并用 LP 解作为下界对比。

**与 2026 三题的接口**（本节小结）：
- **2026B**：**强**。问题1 的多边形定位区域直径、问题2 的第二个检测点选择都是几何最优化，可得解析解并用数值方法交叉验证。
- **2026C**：弱且不推荐。除非要把效率或电价建成非线性函数；优先试分段线性化而不是上 NLP。
- **2026D**：不适用。D 题全部关系都是区间交叠的离散逻辑。

## 17. 优秀论文案例

1. **2000B：钢管的订购和运输（系列，共 7 篇）**（2000 年国赛优秀论文）
   - 其中《钢管的订购和运输解答模型》正文原文："和具有非线性费用的网络流模型。通过改进传统的最小费用最大流算法，解决了本题的非线性费用网络流问题"；《一类运输问题的建模》涉及"非线性规划""分支定界""遗传算法"〔原文〕。
   - 与本节模型关系：**变体**——本质是"带非线性费用的网络流"，是 NLP 与网络流的交叉，非常适合作为"非线性费用如何建模"的参考。

2. **2010C：输油管布置问题的优化模型**（2010 年国赛优秀论文）
