# 图着色与冲突消解

> **证据等级说明**：〔原文〕= 语料中直接读到的句子/标题；〔归纳〕= 从多篇语料共有的写法中归纳；〔推理〕= 无直接语料支撑、由模型性质推出的判断。
>

## 1. 模型用途

图着色：给图的每个顶点染色，使**相邻顶点颜色不同**，求最少需要几种颜色（色数 $\chi(G)$）。它的现实对应是"**互斥资源的最小分配**"——给互相冲突的对象分配互不冲突的资源（时间槽、频段、车道、寄存器、考场）。

国赛里它对应的问题形态：

- **时频冲突消解**（**2026D 的核心**）：给互相冲突的用频计划分配频段/时间，使冲突全部消解；
- **排课/排班**：同一教师不能同时上两门课 → 时间槽着色；
- **考场安排**：同一学生不能同时考两门 → 考场着色；
- **信道分配**：相邻基站不能用同一频段 → 频段着色（**与 2026D 完全同构**）；
- **地图/区域划分**：相邻区域不同色。

**一句话判断**：题面里出现"不能同时""互斥""冲突""不可重叠""同一资源只能给一个"时，先想图着色。

## 2. 题目特征

1. **题眼词**："冲突""互斥""不能同时""重叠""干扰""占用""资源分配"。
   - 2026D 原句："当两个用频计划的**时间区间和频段区间都存在交叠时，则判定它们之间存在时频冲突**"；"时频冲突消解就是通过调整某些用频计划的参数……甚至撤销某些用频计划，使得消解后的用频计划**不存在时频冲突**"〔原文，`_work_extract\2026真题\D题.txt`〕
2. **有一个"冲突关系表"**：哪些对象两两不能共存。
3. **资源是离散且有限的**：100 个频段、若干个时间槽、若干间考场。
4. **要求"最少需要多少资源"或"在给定资源下最多安排多少对象"**：
   - 2026D 原句："**不限制频段和时间的平移幅度，在不增加时频资源的前提下，最多还能安排多少 C 类用频装备？**"〔原文〕
5. **对象带有权重/优先级**：2026D 的 A/B/C 类优先级〔原文〕——这是**加权着色 / 最大权独立集**问题。

## 3. 数学原理

**来源**：四色定理（Appel & Haken 1976）；Brooks 定理；完美图理论（Lovász 1972）证明**区间图的色数等于其最大团的大小**〔推理，属通用理论〕。

**核心概念**：

- **冲突图 $G=(V,E)$**：$V$ = 待分配对象；$(i,j)\in E$ ⟺ 对象 $i,j$ 冲突（不能同色）。
- **色数 $\chi(G)$** = 最少需要的"颜色"（资源）数。
- **独立集**：两两不冲突的对象集合（可分配同一颜色）——**"一种颜色能容纳多少对象"就是最大独立集**。
- **团**：两两互相冲突的对象集合（必须用不同颜色）——**团的下界即色数下界**：$\chi(G)\ge\omega(G)$。
- **加权版本（最大权独立集）**：每个对象带权重（如优先级、收益），选一组互不冲突的对象使总权最大。

**成立前提**：

1. **冲突关系是对称且二值的**：$i$ 与 $j$ 要么冲突要么不冲突。若冲突强度是连续的（干扰功率），需先设阈值二值化——**这个阈值的选择必须说明依据**。
2. **冲突关系是"两两"的**：若冲突是三方以上的联合约束（"三个同时用会互相干扰"），则是超图着色，难度更高。
3. **颜色（资源）是同质的**：所有频段等价。若各频段有优劣之分，则是列表着色（list coloring）或加权着色。
4. **对象不能再拆分**：一个用频计划必须整体分配。

**关键定理（2026D 最有用的两条）**：

- **区间图（interval graph）是完美图**：区间图的色数 = 最大团数，且可在多项式时间内求得。**若把 2026D 简化为一维时间轴上的冲突（忽略频段），则问题多项式可解**——这是极有价值的下界工具。
- **二部图的色数为 2**，判定等价于二分性检测（BFS 染色）。
- **一般图的 3-着色即 NP-complete**（Garey & Johnson）；$k$-着色对 $k\ge3$ 均 NP-complete。

## 4. 基本公式

**图着色问题**：

$$\min\; k\quad \text{s.t.}\quad \exists\, c:V\to\{1,\dots,k\},\; c(i)\ne c(j)\;\forall (i,j)\in E$$

**0-1 规划形式**（$x_{i,k}=1$ 表示对象 $i$ 用颜色 $k$）：

$$\min\;\sum_{k}y_k\quad \text{s.t.}\quad \sum_{k}x_{i,k}=1\;\forall i,\qquad x_{i,k}+x_{j,k}\le1\;\forall(i,j)\in E,\,\forall k$$

$$x_{i,k}\le y_k,\qquad x_{i,k},y_k\in\{0,1\}$$

**色数下界（团下界）**：

$$\chi(G)\ge\omega(G)=\max\{\,|S|: S\text{ 是团}\,\}$$

**最大独立集**：

$$\alpha(G)=\max\sum_i z_i\quad \text{s.t.}\quad z_i+z_j\le1\;\forall(i,j)\in E,\;z_i\in\{0,1\}$$

**加权最大独立集（2026D 问题3 型）**：

$$\max\sum_i w_iz_i\quad \text{s.t.}\quad z_i+z_j\le1\;\forall(i,j)\in E$$

**2026D 的冲突判定式**（时间区间与频段区间同时交叠，**这是本题最核心的一条公式**）：

$$\text{conflict}(i,j)\;\Longleftrightarrow\;\Bigl(\bigcup_{n=0}^{N_i-1}[t_i+n\Delta_i,\;t_i+n\Delta_i+L_i)\Bigr)\cap\Bigl(\bigcup_{m=0}^{N_j-1}[t_j+m\Delta_j,\;t_j+m\Delta_j+L_j)\Bigr)\ne\varnothing$$

$$\text{且}\qquad [f_i,\;f_i+W_i)\cap[f_j,\;f_j+W_j)\ne\varnothing$$

其中 $t_i$ 为首次使用时间区间起点、$\Delta_i$ 为间隔时长、$N_i$ 为使用次数、$L_i$ 为单次占用时长、$[f_i,f_i+W_i)$ 为频段区间。

## 5. 参数含义

| 符号 | 含义 | 2026D 对应 |
|---|---|---|
| $V$ | 待分配对象 | 150 条用频计划 |
| $E$ | 冲突对 | 时频双交叠的计划对 |
| $k$ | 颜色数 | 不多于 100 个频段 |
| $c(i)$ | 对象 $i$ 的颜色 | 计划 $i$ 占用的频段/时间位置 |
| $z_i$ | 是否选中 | 是否保留该计划 |
| $w_i$ | 权重/优先级 | A 类 100、B 类 10、C 类 1 |
| $\chi(G)$ | 色数 | 最少需要的资源数 |
| $\omega(G)$ | 最大团 | 同时互相冲突的最大计划数（色数下界） |

## 6. 建模步骤

1. **定义"冲突"判定规则**：把题干里的"冲突"条件逐字翻译成可计算的判定式（2026D 的核心工作就是这一步）。
2. **构造冲突图**：枚举所有 $\binom{150}{2}=11175$ 对，逐对判定冲突，得到邻接矩阵。
3. **选目标**：
   - 最小化颜色数（最少资源）→ 图着色；
   - 在给定资源下最大化保留对象 → 最大权独立集；
   - 允许调整位置（2026D）→ **着色 + 位置变量**，即"列表着色"或"着色 + 平移"，属于比标准着色更难的问题。
4. **分解图**：把冲突图按**连通分量**拆分，每个分量独立求解——**这是让 150 条计划可解的关键工程手段**。
5. **算下界**：用最大团、团覆盖、或 LP 松弛（分数色数）给出下界。
6. **求解**：小分量用精确 MILP/CP，大分量用 DSATUR / 禁忌搜索 / 遗传算法。
7. **验证**：写独立的冲突检测程序，对结果重新逐对检验。
8. **报告**：色数/保留数、下界、gap、运行时间。

## 7. 算法

1. **贪心着色（DSATUR，最实用的启发式）**：
   a. 计算每个顶点的度数；
   b. 每次选择"**饱和度高**（邻接点用过的不同颜色数最多）"的未着色顶点，并列时取度数最大者；
   c. 给它分配**编号最小的可用颜色**；
   d. 重复直到全部着色。
   - 复杂度 $O(V^2\log V)$（用堆优化）。
   - 质量：通常接近最优，色数一般不超过最优值的 1.1—1.3 倍。
2. **精确算法**：
   a. **分支定界 + 团下界**：先算最大团作为下界；
   b. **DSATUR + 回溯**：分支时选择饱和度最高的顶点；
   c. **列生成**（独立集形式）：把"每种颜色能覆盖顶点集合"作为列，用最大权独立集定价。
   - 复杂度：$k$-着色对 $k\ge3$ 是 NP-complete；精确算法最坏指数级。
3. **最大独立集 / 最大团**：
   a. 小规模（$n\le100$）用分支定界（Bron–Kerbosch 求最大团）；
   b. 大规模用启发式或 MILP。
   - 复杂度：NP-hard；区间图等特殊图上多项式可解。
4. **区间图特例**：若是一维区间冲突，按区间左端点排序 + 贪心求最大团（扫描线），并在多项式时间内给出最优着色。**这是 2026D 的宝贵下界来源。**
5. **局部搜索 / 元启发式**：禁忌搜索（TABUCOL）、模拟退火、遗传算法（2026D 若有 150 顶点 + 可平移选项，规模适合 MILP，不一定需要元启发式）。
6. **2026D 特有的"配置 + 着色"双层结构**：
   a. 对每条计划枚举其**可调位置集合**（平移 $-10\Delta f\sim+10\Delta f$、$ -5\Delta t\sim+5\Delta t$，或撤销）；
   b. 每个"（计划, 位置）"组合成为一个**候选节点**；
   c. 冲突关系变成候选节点之间的冲突；
   d. 约束"每条计划至多选一个候选"→ 在独立的计划之间用"恰好一个"约束，在候选之间用冲突约束；
   e. 目标为加权保留数最大。
   - **这是一个"多选择 + 独立集"模型，可用 MILP/CP-SAT 直接求解。**

## 8. Python实现思路

- **NetworkX**：`nx.greedy_color(G, strategy='DSATUR'|'largest_first'|'independent_set')`，返回 `{node: color}` 字典。
- **Igraph**：`g.coloring(method='dsatur')` / `g.maximal_independent_vertex_sets()`，速度比 NetworkX 快。
- **OR-Tools CP-SAT**（**2026D 首选**）：
  - 为每条计划建一个 `NewIntVar(0, num_options-1)` 选择候选位置；
  - 用 `AddForbiddenAssignments` 或布尔变量 `AddBoolOr` 表达"冲突的两个候选不能同时被选"；
  - 目标 `Maximize(sum(weight * is_kept))`；
  - 支持 `AddExactlyOne` 表达"每条计划恰好选一个候选（含撤销）"。
- **MILP 路线**：PuLP/Gurobi 写独立集形式（$z_i+z_j\le1$ + 每条计划的选择约束）。
- **易错点1**：冲突图建错（漏判区间重叠的"循环使用"部分）——2026D 的计划不是单次占用，而是"首次区间 + 间隔 × 使用次数"的**等差数列区间序列**，必须逐次展开再判交叠。**这是本题最大的实现陷阱**。
- **易错点2**：把"互斥"写成了"蕴含"（$z_i+z_j\le1$ 写成 $z_i\le z_j$）。
- **易错点3**：`nx.greedy_color` 的返回是颜色编号字典，颜色数要取 `max(d.values())+1`，**编号从 0 开始**。
- **易错点4**：忘记处理"一个计划可以与多个计划冲突"的情况，只处理了两两中的一部分。
- **易错点5**：用贪心着色直接当最优解提交，色数可能比最优多 1—2（在 150 顶点规模下完全可能）。
- **易错点6**：CP-SAT / MILP 未设时间上限，20 分钟程序时间跑不完。

## 9. MATLAB实现思路

- **无内置图着色函数**。三条路：
  a. 自己写 DSATUR（约 60 行，用 `graph` 的邻接矩阵）；
  b. 用 `ga` 做遗传算法（编码为颜色序列 + 冲突惩罚）；
  c. 用 `intlinprog` 写 0-1 规划（$n\times k$ 个变量，$n=150,k=100$ 时是 15000 个变量，可行）。
- **区间图扫描**：用 `sortrows` 按左端点排序 + 循环维护最大重叠数。
- **画图**：`plot(G,'Layout','force')` 后按颜色给节点上色，冲突图可视化效果好。
- **易错点1**：`intlinprog` 的变量数 = 顶点数 × 颜色数，$150\times100=15000$ 已接近舒适区，再乘"位置候选"会爆炸——**应先做图的连通分量分解**。
- **易错点2**：`ga` 的染色体若直接编码颜色编号，会产生大量不可行解（相邻同色），需用修复算子或大惩罚。
- **易错点3**：用邻接矩阵建 `graph` 时，无向图要保证矩阵对称（`A = A | A'`）。
- **易错点4**：DSATUR 实现中"选择饱和度最高顶点"的并列处理（度数最大）若漏掉，质量会明显下降。
- **易错点5**：MATLAB 的图对象节点编号是字符串，与矩阵索引的映射容易错位。

## 10. 优点

1. **建模直观**：一张冲突图就能把所有互斥关系画清楚，评审一眼就懂。
2. **下界易得**：最大团给出色数的下界，能报告 gap。
3. **有强大特例**：区间图、二部图、弦图都是多项式可解的，**识别出特例就能把 NP-hard 问题变成秒解**。
4. **启发式效果很好**：DSATUR 在大多数实例上接近最优，实现只要几十行。
5. **与其他模型衔接自然**：最大权独立集就是 0-1 规划；色数下界就是团。

## 11. 缺点

1. **$k\ge3$ 着色 NP-complete**：大规模问题无精确解保证。
2. **对冲突判定极敏感**：判定规则写错（例如漏算循环使用的时间段）会导致整张冲突图错误，后续全部作废。
3. **- 贪心解无保证**：可能比最优多 1—3 种颜色，而"最少资源"恰恰是题目要的答案。
4. **不表达"调整代价"**：标准着色只管"染成什么色"，不管"从原位置移过去要付多少代价"。2026D 需要的是**带代价的着色/平移**，是标准着色模型的扩展。
5. **加权版本更难**：最大权独立集在一般图上是 NP-hard，规模一大只能启发式。

## 12. 适用条件

- **当**冲突关系是两两的、二值的、对称的，且资源同质、对象不可拆分时，用图着色/独立集建模。
- **当**冲突图是**区间图**（一维区间冲突）时，用扫描线 + 贪心可在多项式时间内求最优，**不要上 NP-hard 算法**。
- **当**冲突图是二部图时，色数为 2，用 BFS 染色即可判定。
- **当**对象带优先级时，用**最大权独立集**（MILP/CP-SAT），而不是标准着色。
- **当**对象还可以"移动位置"时（2026D），用"多选择 + 独立集"的扩展模型。
- **与本三题相关的明确判断**：
  - **2026D**：**这就是本题的核心模型**。赛题原文给出完整的冲突定义（时间区间与频段区间同时交叠）、调整方式（平移频段或时间，幅度上限 10Δf 与 5Δt）、以及"一个用频计划只能调整其中一个参数或撤销"的硬约束〔原文〕。**推荐建模路径**：① 逐对判定冲突，构造冲突图（11175 对）；② 按连通分量分解；③ 对每条计划枚举候选（保持原样 / 平移频段 $\pm10$ / 平移时间 $\pm5$ / 撤销）；④ 建"多选择 + 冲突互斥"的 0-1 模型；⑤ 分层目标（先最少撤销，再最少调整，再最小幅度）；⑥ 用 CP-SAT 或 MILP 求解。**问题3（最多还能加多少 C 类）就是在现有占用下求最大独立集/最大装箱**。 〔原文 + 推理〕
  - **2026B**：**弱相关**。B 题的"频道切换"涉及 20 个频道，机器狗同一时刻只能检测一个频道〔原文〕——理论上可以把"频道分配"看成着色（互不冲突的频道可同时检测），但机器狗是单线程的，**实际上不需要着色，只需按频道顺序依次检测**。**建议不要为了套模型而强行使用图着色**。 〔原文 + 推理〕
  - **2026C**：**不适用**。C 题没有互斥资源分配结构。 〔推理〕

## 13. 不适用情况

- **当**冲突关系不是两两的（如"三者同时使用才出问题"）时，不要用普通图着色，那是超图着色。
- **当**资源不同质（100 个频段有优劣差异、带宽不同）时，不要用标准着色，应用列表着色或加权/费用着色。
- **当**对象可以被拆分（把一次用频拆成两段）时，不要用着色（顶点不可分假设被破坏）。
- **当**资源充裕（色数远小于可用颜色数）时，着色不是瓶颈，问题本质是"最大化保留数"，应直接建最大权独立集，不必绕着求色数。
- **当**需要"最小化调整幅度"而不只是"是否可以调整"时，标准着色不够，必须加连续的位置变量。
- **当**冲突图规模巨大且有稠密结构时，精确着色不现实，应转向启发式 + 下界报告。

## 14. 常见错误

1. **时间区间判交错算"使用次数"**：2026D 的计划是"首次区间 + 间隔 × (次数-1)"的**多条区间**，只判首次区间交叠会严重漏判冲突。**必须逐次展开**。这是本题最致命的错误。
2. **"一个计划只能调一个参数"被忽略**：若允许同时平移频段和时间，求解器会给出题目不允许的"更优"解。必须加互斥约束 $\sum_p\delta_{i,p}+z_i=1$。
3. **贪心着色当最优**：DSATUR 的解可能不是最小色数；必须报告下界（最大团）与 gap。
4. **冲突图不对称**：判定函数写成 $i$ 与 $j$ 不对称（如只在一侧展开区间），导致邻接矩阵不对称，后续算法出错。**建图后必须断言 `(A == A.T).all()`**。
5. **把"保留"与"撤销"的权重设错**：2026D 中 A/B/C 类优先级不同，"少撤销一个 A 类"比"少撤销十个 C 类"更重要，必须用足够悬殊的权重（如 A:B:C = 10000:100:1）或分层目标。**权重量级不够会导致优先级失效**。
6. **忽略平移幅度上限**：2026D 规定频段最大平移 10Δf、时间最大平移 5Δt〔原文〕，超出即为非法解。
7. **不检查"消解后是否真无冲突"**：必须用独立的检测程序复核，不能只信求解器。
8. **忘了"在不增加时频资源的前提下"**（问题3）：新安排的 C 类计划不能扩大到原有频段/时间范围之外。

## 15. 论文写法

**可套用句式**：

1. "将 150 条用频计划视为图的顶点；若两条计划的频段区间与时间区间同时存在交叠，则在对应顶点间连边，从而把时频冲突消解问题转化为图上的独立集与着色问题。"
2. "考虑到每条用频计划占用频段的时长为等差数列 $[t_i+n\Delta_i,\;t_i+n\Delta_i+L_i)$（$n=0,\dots,N_i-1$），本文对全部使用时段逐一展开后再判定交叠，共检测出冲突对 XXX 对。"
3. "引入 0-1 决策变量 $\delta_{i,f},\delta_{i,t},\delta_{i,n},z_i$，分别表示计划 $i$ 平移频段、平移时间、调整间隔或撤销；由题设'一个用频计划只能调整其中一个参数或撤销'得互斥约束 $\delta_{i,f}+\delta_{i,t}+\delta_{i,n}+z_i=1$。"
4. "冲突图可分解为 XX 个连通分量，最大分量含 XX 个顶点；对每个分量独立求解，使问题规模从 $2^{150}$ 降至可精确求解的范围，全部求解耗时 XX 秒。"

**应配的图表**：

- **时频占用图**（横轴时间片、纵轴频段编号，每个计划画成一个矩形块；这是 D 题最重要的图，调整前后各画一张对比）；
- **冲突图可视化**（节点 = 计划、边 = 冲突、颜色 = 所属连通分量或类别）；
- **冲突对统计表**（按 A-A、A-B、A-C、B-B、B-C、C-C 分类统计冲突对数）；
- **冲突矩阵热力图**（150×150 的 0-1 矩阵，稀疏结构一目了然）；
- **消解方案对照表**（每条计划的原始参数 vs 调整后参数 vs 是否撤销）；
- **求解收敛曲线**（目标值 vs 时间，展示 CP-SAT/MILP 的进展）。

## 16. 可创新方向

1. **识别区间图特例并求多项式最优**（**2026D 最有价值的理论贡献**）：若只考虑时间维（忽略频段），冲突关系构成**区间图**——区间图是完美图，色数 = 最大团数，可在 $O(n\log n)$ 内求得。**把这一结论写进论文，可以给出"最少需要多少个频段/时间资源"的严格下界**，再与 MILP 的实际解对比，形成漂亮的理论—算法双层结构。 〔推理〕
2. **多选择 + 加权独立集**（**2026D 的推荐主模型**）：每条计划枚举所有合法候选位置，转化为"每个组恰好选一个 + 跨组互斥"的 0-1 模型，本质是**带分组约束的最大权独立集**。这个建模视角比"图着色"更贴合题目（因为题目允许平移）。 〔推理〕
3. **分层着色/字典序目标**（**2026D 直接相关**）：把"最少撤销 A 类 → 最少撤销 B 类 → 最少调整数 → 最小平移幅度"做成四级字典序目标。 〔原文 + 推理〕
4. **冲突图的团下界 + LP 分数色数**：给出 $\chi(G)\ge\max\{\omega(G),\lceil\text{LP 松弛}\rceil\}$ 的双重下界，让 gap 报告更硬。
5. **滚动/动态着色**（**与 2021D、2026B 联动**）：新计划不断到达时（2026D 问题3"最多还能安排多少 C 类"），用增量着色算法维护解，比每次重解快得多。 〔推理〕
6. **超图着色**：若冲突涉及三方（如"三个同频段计划叠加超出干扰阈值"），推广为超图着色，是一个明显高于平均水平的建模提升。 〔推理〕
7. **随机/鲁棒着色**：用频需求不确定时求"以某概率无冲突"的分配方案（与《鲁棒优化与随机规划》联动）。
8. **与 2026B 的谨慎结合**：若一定要在 B 题中使用图结构，可把"频道"建成资源、把"可能同时存在信号的干扰源"建成冲突边，用最大匹配判断"哪些干扰源可以共用一个检测趟次"——**但这属于人为加戏，风险较高，不建议作为主线**。 〔推理〕

**与 2026 三题的接口**（本节小结）：
- **2026B**：弱。虽有 20 个频道与"频道切换 1 s"，但机器狗是单线程，按顺序切换即可，**不建议为了套模型强用着色**。
- **2026C**：不适用。
- **2026D**：**强，是本题的模型核心**。冲突图构造 → 连通分量分解 → 多选择加权独立集 → 分层目标；再用**区间图是完美图（色数 = 最大团数）**这一性质给出严格下界，形成漂亮的理论—算法双层结构。
