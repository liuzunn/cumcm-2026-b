# 动态规划

> **证据等级说明**：〔原文〕= 语料中直接读到的句子/标题；〔归纳〕= 从多篇语料共有的写法中归纳；〔推理〕= 无直接语料支撑、由模型性质推出的判断。

## 1. 模型用途

动态规划（DP）解决"**分阶段决策**"问题：系统沿时间（或逻辑阶段）演化，每一阶段做一个决策，当前决策既影响当期收益又改变下一阶段的状态，要求整体最优。

国赛里 DP 出现在四种形态：

1. **时序资源分配**：每天买多少水/食物、每周订多少货、每期投多少基金；
2. **序列切割/装箱**：一维下料、尾坯切割、天然肠衣搭配；
3. **图上最短路/最短回路**：DP 是 Bellman-Ford、Floyd、TSP 的 Held-Karp 的理论母体；
4. **在线决策/对抗决策**：天气未知时的策略（2020B 问题2）、信息不完全下的博弈。

**一句话判断**：如果"现在做什么"会改变"以后能做什么"，且阶段可以排序，就用 DP。

## 2. 题目特征

1. **题眼词**："每天/每周/第 $t$ 期"、"随时间"、"下一阶段"、"此后不能更改"。
   - 2020B 原句："每名玩家的行动方案需在第【k】天确定且此后不能更改"〔原文，N02 编目〕
   - 2020B 原句："仅知道当天的天气状况，可据此决定当天的行动方案"〔原文〕
2. **状态可以定义且可压缩**：位置、剩余资源、资金、天数。
3. **目标为累加型**：总收益 = 各阶段收益之和，总费用 = 各段费用之和。
   - 2020B 原句："目标是在规定时间内到达终点，并保留尽可能多的资金"〔原文〕
4. **多阶段或多物体串行处理**：2017D 巡检排班问题把"覆盖所有巡检点"转化为背包问题〔原文〕。
5. **需要"下界证明"**：1998B《灾情巡视路线最优解的证明》用下界论证最优性〔原文〕——DP 的思维方式。

## 3. 数学原理

**来源**：Bellman 于 1950s 提出的**最优性原理**（Principle of Optimality）与动态规划方法〔推理，属通用理论〕。

**最优性原理**：最优策略具有这样的性质——无论初始状态与初始决策如何，**从当前决策所形成的状态出发，其余决策必构成一个最优子策略**。

**成立前提**（少了任一条，DP 不成立）：

1. **无后效性（Markov 性）**：$t$ 阶段之后的状态只依赖当前状态与决策，与更早的历史无关。**这是 DP 唯一不可让步的前提**。
2. **阶段可排序**：整个决策过程能被切成有先后次序的阶段。
3. **状态可枚举且有界**：状态空间有限（或可离散化），否则表存不下。
4. **目标可递推**：$t$ 阶段的总目标能写成 $t$ 阶段收益 + 后续最优值的函数。
5. **决策集有限**：每阶段的动作集合可枚举。

**基本递推（Bellman 方程）**：

$$f_t(s)=\max_{a\in A_t(s)}\Bigl\{\, r_t(s,a)+f_{t+1}\bigl(T_t(s,a)\bigr)\Bigr\}$$

边界：$f_{T+1}(s)=$ 终端收益（如剩余资源退回价值或 0）。

**若状态里含随机性**（天气未知）：期望值形式

$$f_t(s)=\max_{a}\Bigl\{\, \mathbb{E}_{w}\bigl[r_t(s,a,w)\bigr]+\mathbb{E}_{w}\bigl[f_{t+1}(T_t(s,a,w))\bigr]\Bigr\}$$

若只知道部分信息，则升级为 POMDP（N02 编目对 2020B 的判定〔推理〕）。

## 4. 基本公式

**确定性 DP**（前推或后推）：

$$f_t(s)= \max_{a}\bigl\{r_t(s,a)+f_{t+1}(s')\bigr\},\qquad s'=T_t(s,a)$$

**背包型 DP**（2017D、2023E 用到，见《背包与装箱问题》）：

$$f_i(c)=\max\bigl\{f_{i-1}(c),\; v_i+f_{i-1}(c-w_i)\bigr\}$$

**区间 DP**（一维下料/切割，2021D 型）：

$$f(i,j)=\min_{k\in[i,j)}\bigl\{f(i,k)+f(k,j)+\text{cost}(k)\bigr\}$$

**最短路的 DP 形式**（Bellman 方程）：

$$d(v)=\min_{u\in N^-(v)}\bigl\{d(u)+w(u,v)\bigr\}$$

**2020B 型状态定义示例**（论文中可直接采用）：

$$s_t=(\text{位置},\; t,\; \text{水},\; \text{食物},\; \text{资金}),\qquad f_t(s_t)=\max\{\text{剩余资金}\}$$

## 5. 参数含义

| 符号 | 含义 | 例 |
|---|---|---|
| $t$ | 阶段（天/周/期） | 2020B 的天数 0—30 |
| $s$ | 状态 | 位置 + 资源 + 资金 |
| $a$ | 决策/动作 | 走哪、买多少、挖不挖矿 |
| $T_t(s,a)$ | 状态转移函数 | 消耗资源、天晴/沙暴约束 |
| $r_t(s,a)$ | 阶段收益 | 挖矿收益、购买成本 |
| $f_t(s)$ | 值函数（后推最优值） | 从 $t$ 到终点的最大剩余资金 |
| $A_t(s)$ | 可行动作集 | 沙暴日只能原地停留 |

## 6. 建模步骤

1. **识别阶段**：最常是时间，也可以是"第 $i$ 个物品/第 $i$ 段"。
2. **定义状态**：把"影响未来的一切信息"塞进状态，其余全部丢弃——状态定义是 DP 的全部难点。
3. **写状态转移**：$s'=T_t(s,a)$，逐条对应题目规则。
4. **写阶段收益**：$r_t(s,a)$，注意"原地停留"与"沙暴日"的差异收益。
5. **定边界与终值**：初始状态唯一（如 2020B 的第 0 天位于起点）、终端收益（剩余资源退回价）。
6. **定决策集**：把题目规则写成动作的可行性条件。
7. **估状态规模**：$|S|\times|A|\times T$，超过 10^7 就要考虑状态压缩或剪枝。
8. **实现与回溯**：存值函数表 + 记录转移来源，最后回溯出完整策略。
9. **验证**：用小规模手算/暴力枚举交叉验证。
10. **若含随机**：改期望形式或做情景树。

## 7. 算法

1. **确定迭代方向**：后推（已知终值）或前推（已知初值）；国赛多数是后推。
2. **初始化值函数**：$f_{T+1}(s)$。
3. **逐阶段循环**：对每个状态枚举动作，按 Bellman 方程取最优并记录来源。
4. **回溯构造策略**：从 $s_0$ 沿记录的最优动作走完整个时间轴。
5. **状态压缩**（规模大时）：
   - 只保留可达状态（哈希表/字典）；
   - 对连续状态做离散化 + 分段线性近似；
   - 利用单调性或凸性减少枚举。
6. **交换维度**：若状态维度少而值域大，可把"值"作为状态、把"资源"作为值（背包常见）。
7. **复杂度**：$O(T\cdot|S|\cdot|A|)$ 时间，$O(|S|)$ 空间（滚动数组）。典型数量级：状态 $10^5$—$10^7$、阶段 $10^1$—$10^3$；Held-Karp TSP 为 $O(n^2 2^n)$。
8. **近似 DP**（2020B 型大规模）：值函数近似（线性/神经网络）、滚动时域 + 启发式，牺牲最优性换可行性。

## 8. Python实现思路

- **自底向上**：用 `dict` 存 `{(t, state): value}`，或 `numpy` 多维数组（**推荐 numpy，速度快 100 倍**）。
- **自顶向下**：`functools.lru_cache` 做记忆化递归，代码最贴近递推公式，适合状态稀疏的场景。
- **规模控制**：状态数 > 10^6 时，用 `numpy` 向量化"对全部状态同时做转移"，避免 Python 双层循环。
- **回溯**：另开一张 `policy` 表存最优动作，最后从初态顺推。
- **易错点1**：状态里漏了关键信息（如忘了把"天气已知/未知"体现在状态或决策集里），导致无后效性被破坏，结果看似合理但错误。
- **易错点2**：递推方向与边界不匹配（后推却初始化了初值）。
- **易错点3**：递归深度超限——$T=30$、每个状态递归展开会爆栈，应改自底向上或调 `sys.setrecursionlimit`。
- **易错点4**：没做状态去重，同一状态被重复计算，复杂度指数化。
- **易错点5**：浮点作为状态键（`lru_cache` 用 float 做 key 会因精度产生大量"不同"状态），应先量化到整数。

## 9. MATLAB实现思路

- **数组式**：`f = -inf(nStates, T+1)` 预分配，双重循环填表；`f(:,t) = max(r(:,t,:) + f(next, t+1), [], 3)` 可向量化。
- **记忆化**：MATLAB 没有内建 `lru_cache`，用 `containers.Map` 做键值缓存，键用字符串或整数编码。
- **图上的 DP**：最短路可直接用 `shortestpath`（内部就是 Bellman-Ford/Dijkstra 的实现）。
- **易错点1**：MATLAB 下标从 1 开始，状态 0 要映射到索引 1，容易错位。
- **易错点2**：用 `containers.Map` 时键必须是标量或字符向量，元组要编码成整数（如 `state = pos*1000 + water`）。
- **易错点3**：忘记预分配导致循环内数组增长，慢几十倍。
- **易错点4**：`-inf` 参与加法会传染，不可达状态需先判 `isfinite`。
- **易错点5**：把 DP 写成递归函数在 MATLAB 里极慢，务必自底向上。

## 10. 优点

1. **能处理"决策影响未来"的耦合**：这是贪心做不到、LP 又要额外引入时序变量才能表达的结构。
2. **可处理非线性、非凸的分段收益**：不要求目标可微。
3. **能自然嵌入随机性与在线信息**：期望值 DP、POMDP 都是它的直接扩展。
4. **可给出最优性论证**：配合下界/上界可证明最优（1998B 的证明思路〔原文〕）。
5. **实现不需要求解器**：纯算法题，纯 Python 也能跑，比赛环境友好。

## 11. 缺点

1. **维数灾难**：状态维度每加一维，复杂度乘一个量级——这是 DP 最致命的限制。
2. **状态必须离散且有限**：连续资源（如连续的水量）只能近似。
3. **无后效性要求苛刻**：很多实际问题的状态天然带记忆（要记录"是否已购买过"），需要额外加状态位。
4. **只给最优值，不给灵敏度**：不像 LP 有对偶信息。
5. **大规模问题只能近似**：近似 DP 失去最优性保证，且调参困难。

## 12. 适用条件

- **当**问题能清楚地切成阶段、且当前状态充分描述未来时，用 DP。
- **当**目标是累加/累乘型、决策集可枚举时，用 DP。
- **当**状态规模 $\le 10^7$（可用数组或哈希存下）时，用精确 DP；更大时用近似 DP。
- **当**需要在线策略且信息逐步到达（2020B 问题2 型）时，用随机 DP/滚动决策。
- **与本三题相关的明确判断**：
  - **2026C**：**在"预报逐步到达"的语境下 DP 有意义**，但注意——若流量、价格、负载都已知且关系线性，**LP 更合适且给全局最优**。DP 的正确用法是处理**问题3 的"多时点预报下的调整决策"**：把"每次预报时刻是否调整、调整多少"作为阶段决策，状态含储能电量与已承诺计划量。**这是一个可以主动选择的建模路线，但复杂度高于 LP。** 〔推理〕
  - **2026B**：**DP/在线决策是核心工具之一**。机器狗在圆域内搜索 10—16 个未知干扰源，是典型的"信息逐步获取 + 路径规划"，可建模为**部分可观测马尔可夫决策过程（POMDP）**，实用近似是"贪心 + 滚动重规划"：每检测到一个示向度就更新目标概率地图（贝叶斯更新），再用旅行商/最短路求下一段路径。**注意：20 分钟程序时间与 25 分钟窗口是硬约束，纯 DP 求解器很可能超时**。 〔原文 + 推理〕
  - **2026D**：**不适用**。D 题是静态组合优化，没有阶段结构。 〔推理〕

## 13. 不适用情况

- **当**问题没有天然阶段结构时（如纯静态选址），不要强行 DP。
- **当**状态维数超过 4—5 维且每维取值多时，不要用精确 DP（会爆内存），应改 MILP 或启发式。
- **当**状态必须包含连续变量且精度要求高时，不要用离散化 DP（误差难以控制），改 LP/NLP。
- **当**决策之间存在全局耦合约束（如"整周只能选 3 家供应商"）时，纯 DP 表达困难，应上 MILP。
- **当**有严格的在线时间预算（2026B 的 20 分钟、2021D 的"30 分钟内产生方案"〔原文，2011D 题眼〕）时，不要在线跑 DP，应预计算策略表。

## 14. 常见错误

1. **状态定义不满足无后效性**：最典型的错误是"忘记把是否已购买记录进状态"，导致重复购买被允许。**检查方法：问自己"仅凭这个状态，能否唯一确定未来的可行决策集？"**
2. **阶段划分错位**：把"阶段"设成事件而不是时间刻度，导致转移关系混乱。
3. **边界条件写错**：终值设成 0 而不是"剩余资源的残值"，结果把所有资源都浪费掉。
4. **状态规模失控**：2020B 若把水、食物都按 0.5 箱精度离散，状态数立刻到 10^8，内存爆掉；必须做**精度与规模的取舍并写进论文假设**。
5. **把 DP 当贪心**：每步取当前最优（如 2020B 每步都挖矿）不等于全局最优。
6. **回溯路径与值函数不一致**：记录了值却忘了记录转移来源，最后算不出策略。
7. **忽略整数性与离散化误差**：连续问题离散后最优值有偏，需给误差界。
8. **随机 DP 忘记加权**：期望写成简单平均，忽略天气出现的概率分布。

## 15. 论文写法

**可套用句式**：

1. "以第 $t$ 天的位置、剩余水量、剩余食物量与剩余资金构成状态 $s_t$，以当天的行动（行走/停留/挖矿/购买）为决策 $a_t$，建立动态规划模型，值函数 $f_t(s_t)$ 表示从状态 $s_t$ 出发到游戏结束可保留的最大资金。"
2. "由于题目保证沙暴日必须原地停留、且到达矿山当天不能挖矿，状态转移函数 $T_t$ 分别按三种天气与四类行动逐条定义。"
3. "该模型满足最优性原理：给定当前状态后，未来的最优决策与历史路径无关，因此可采用自底向上的后推法求解。"
4. "求解得到的状态空间规模为 $3.2\times10^6$，在 Python 下耗时 18 s；回溯后得到完整的最优行动序列。"

**应配的图表**：

- **状态转移示意图**（一张小图把阶段、状态、动作、收益画清楚，是 DP 论文的核心图）；
- **价值函数热力图**（横轴时间、纵轴某关键状态量、颜色为值函数）；
- **最优策略序列表**（逐天的动作 + 剩余资源）；
- **不同离散精度下的最优值对比表**（说明近似误差）；
- **算法复杂度与规模增长曲线**。

## 16. 可创新方向

1. **状态压缩/降维**：用"资源总量"代替"水 + 食物"两维，或用主导性剪枝（Pareto 支配）删掉被支配状态——这是 DP 论文里最硬的技术贡献。
2. **近似动态规划（ADP）/值函数近似**：状态爆炸时的正解，可用线性基函数或神经网络拟合值函数。
3. **POMDP + 贝叶斯更新**（**2026B 强相关**）：把"干扰源位置"作为隐状态，示向度观测作为证据，用贝叶斯更新后验概率地图，再用信念状态做决策——这是把搜索问题从"随机游走"提升到"信息驱动搜索"的关键。 〔推理〕
4. **滚动时域/MPC + DP**：每步只解未来 $H$ 步子问题，兼顾实时性与前瞻性（2021D 实时切割、2026B 在线搜索都适用）。
5. **DP 与 MILP 的对照**：同一问题两种建模，比较解的质量与耗时，论文里做"方法对比"章节。
6. **随机 DP + 情景树**：把 2024C 的多年度种植策略写成情景树 DP，与 MILP 情景优化比较。
7. **与 2026C 的接口**：把"预报更新时刻的调整决策"写成小规模随机 DP，用于回答题目"是否需要引入其他时刻的预报制定调整购电策略"——用 DP 的最优费用下降幅度作为定量证据。 〔推理〕

**与 2026 三题的接口**（本节小结）：
- **2026B**：**强**。在线搜索可建模为 POMDP/随机 DP，实用近似是"贝叶斯更新目标概率地图 + 滚动重规划"；注意 20 分钟程序时限不允许在线跑重型 DP。
- **2026C**：中。把"每次预报时刻是否调整、调整多少"作为阶段决策可写成随机 DP，但复杂度高于 LP，适合作为对照方案。
- **2026D**：不适用。D 题是静态组合优化，没有阶段结构。

## 17. 优秀论文案例

1. **2020B：基于动态规划、统计分析、静态博弈的穿越沙漠游戏策略设计**（2020 年国赛优秀论文）
