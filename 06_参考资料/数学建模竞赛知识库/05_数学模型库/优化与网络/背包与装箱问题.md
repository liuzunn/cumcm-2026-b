# 背包与装箱问题

> **证据等级说明**：〔原文〕= 语料中直接读到的句子/标题；〔归纳〕= 从多篇语料共有的写法中归纳；〔推理〕= 无直接语料支撑、由模型性质推出的判断。

## 1. 模型用途

这两个问题常被混为一谈，但目标相反：

- **背包问题**（Knapsack）：**每件物品有价值和重量，背包容量有限，选一批使总价值最大**。选择对象是"物品"。
- **装箱问题**（Bin Packing）：**把物品全部装进最少的箱子**（或给定箱子数，判断能否装下）。选择对象是"箱子"。

国赛里的对应：

- **监测点/采样点选择**：2023E 论文原文"借用**背包问题**建立了 **0-1 规划模型**，获得了未来 2 年最优的采样监测方案"〔原文〕；
- **巡检覆盖的分段**：2017D 论文原文"于是问题转化为：至少需要几段时间，才能将该最大累计时间全部覆盖掉？于是建立**背包模型**"、"**关键词：无向赋权图；最短路模型；背包模型；巡检线路；排班方案**"〔原文〕；
- **拼接/复原中的块选择**：2013B 碎纸复原（"0-1 背包"）〔原文〕；
- **原料搭配与成品捆数**：2011D 天然肠衣搭配（LINGO 求最大成品捆数）〔原文〕；
- **切割下料**：2021D 连铸切割（一维下料，本质是装箱的变体）〔原文〕；
- **资源分配**：资金、人力、算力在多个项目间的分配。

**一句话判断**：题目里出现"最多能装多少""至少需要几个箱子/批次/组""在容量限制下选哪些"，就是这两个模型。

## 2. 题目特征

1. **题眼词**："容量""上限""不超过""至少需要多少箱/组/批""选出若干""搭配""下料""装载"。
   - 2011D 原句："对于给定的一批原料，装出的成品捆数越多越好"；"总长度允许有 0.5 米的误差，总根数允许比标准少 1 根"；"为了提高原料使用率……为了食品保鲜，要求在 30 分钟内产生方案"〔原文，N02 编目〕
2. **有明确的容量约束与一组"物品"**。
3. **物品不可拆分**（整数决策）：要么全选要么不选。
4. **目标是"数量最大"或"数量最小"**：典型的整数目标。
5. **可能有偏差容忍**：2011D 的"总长度允许 0.5 米误差、总根数允许少 1 根"〔原文〕——**这是把硬约束软化的典型处理，很有参考价值**。

## 3. 数学原理

**来源**：背包问题由 Dantzig 提出；0-1 背包的 DP 解法 $O(nW)$ 是伪多项式；装箱问题由 Johnson 等研究，其近似算法（FFD/NF）有经典界〔推理，属通用理论〕。

**成立前提**：

1. **容量可量化**（重量、体积、长度、时间、预算）。
2. **物品不可分**（可分则是 LP 的连续背包，贪心即最优——**这个区别至关重要**）。
3. **价值/成本可加**：总价值 = 所选物品价值之和。
4. **确定性**：物品重量与价值已知。

**复杂度与关键性质**：

- **0-1 背包**：NP-hard，但**有伪多项式 DP 算法** $O(nW)$（$W$ 为容量）——当 $W$ 不大时非常实用。
- **分数背包**（可拆分）：**贪心按价值密度降序即最优**，是 LP 特例。
- **装箱问题**：NP-hard；**FFD（首次递减）有 11/9·OPT + 6/9 的经典界**；NF 有 2·OPT 界。
- **完全背包 / 多重背包**：物品可重复选 / 每种有限个，DP 递推略有不同。
- **装箱判定的下界**：$\lceil\sum w_i/C\rceil$ 与"大于 $C/2$ 的物品数"取最大。

## 4. 基本公式

**0-1 背包**：

$$\max\;\sum_{i=1}^{n}v_ix_i\qquad \text{s.t.}\quad \sum_{i=1}^{n}w_ix_i\le W,\quad x_i\in\{0,1\}$$

**DP 递推**：

$$f(i,c)=\max\bigl\{f(i-1,c),\;\;v_i+f(i-1,\,c-w_i)\bigr\}$$

边界 $f(0,c)=0$，$f(i,c)=-\infty$ 当 $c<0$。答案 $f(n,W)$。

**装箱问题（最少箱数）**：

$$\min\;\sum_{k=1}^{K}y_k\qquad \text{s.t.}\quad \sum_{k}x_{ik}=1\;\forall i,\quad \sum_{i}w_ix_{ik}\le Cy_k\;\forall k,\quad x_{ik},y_k\in\{0,1\}$$

**下界**：

$$K_{\min}\ge\max\Bigl\{\Bigl\lceil\frac{\sum_i w_i}{C}\Bigr\rceil,\;\#\{i:w_i>C/2\}\Bigr\}$$

**2011D 型"搭配"模型**（带偏差容忍的装箱）：

$$\max\;\sum_{k}y_k\quad \text{s.t.}\quad \sum_i l_ix_{ik}\in[L_{\text{target}}-\delta,\;L_{\text{target}}+\delta],\quad \sum_i x_{ik}\in[N_{\text{target}}-1,\;N_{\text{target}}]$$

（$l_i$ 为原料长度、$L_{\text{target}}$ 为成品标准长度、$\delta=0.5$ m、$N_{\text{target}}$ 为标准根数〔原文〕）

**2021D 切割损失目标**：

$$\min\;\sum_{\text{段}}\text{loss}(\text{段长}),\qquad \text{loss}(l)=\begin{cases}\infty,&l<4.8\text{ 或 }l>12.6\\0,&8.0\le l\le11.6\\\text{需二次切割的量},&\text{其他}\end{cases}$$

## 5. 参数含义

| 符号 | 含义 | 例 |
|---|---|---|
| $v_i$ | 物品价值 | 监测点代表性得分 |
| $w_i$ | 物品重量/占用 | 采样成本、钢坯长度 |
| $W$ | 背包容量 | 预算、总长度 |
| $x_i$ | 是否选择物品 $i$ | 0-1 |
| $C$ | 单个箱子容量 | 标准成品长度 |
| $y_k$ | 是否启用箱子 $k$ | 0-1 |
| $\delta$ | 允许偏差 | 2011D 的 0.5 m |

## 6. 建模步骤

1. **判断"背包"还是"装箱"**：问"是要**选择一部分**（背包）还是"要**装下全部**（装箱）"。
2. **确认可不可分**：不可分才需要整数模型；可分则贪心或 LP。
3. **算容量与物品参数**：统一量纲（长度、重量、体积、时间都要换算一致）。
4. **估规模**：$n\le30$ 可精确（DP 或 MILP）；$n$ 大但容量小用 DP；$n$ 大且容量大用 FFD + 局部搜索。
5. **处理偏差容忍**：2011D 的"允许 0.5 米误差 / 少 1 根"要写成区间约束，**不要写等式**。
6. **写目标**：价值最大（背包）或箱数最少（装箱）。
7. **求解并校验**：逐箱检查容量是否超限（**必须写独立校验脚本**）。
8. **报告下界与 gap**。

## 7. 算法

1. **0-1 背包 DP**：
   a. 初始化 $f[0..W]=0$；
   b. 对每个物品 $i$，从 $c=W$ **倒序**到 $w_i$：$f[c]=\max(f[c],\;v_i+f[c-w_i])$；
   c. 答案 $f[W]$，用回溯或记录选择还原方案。
   - 复杂度 $O(nW)$ 时间、$O(W)$ 空间（滚动数组）。
   - **必须倒序遍历 $c$**，正序会变成"完全背包"（物品可重复选）。
2. **分支定界（容量大时）**：
   a. 按价值密度 $v_i/w_i$ 降序排序；
   b. 用分数背包的解作为上界（**这是极强的界**）；
   c. 分支 + 剪枝。
   - 复杂度最坏指数级，但实际很快。
3. **装箱——FFD（首次递减）**：
   a. 物品按重量降序排列；
   b. 依次放入**第一个能放下的箱子**，否则开新箱。
   - 复杂度 $O(n\log n+nK)$；近似比 $\le 11/9\,OPT+6/9$。
4. **装箱——NF（首次适应）/ BF（最佳适应）**：FFD 的变体，实践中 FFD 通常已接近最优。
5. **装箱——精确求解**：MILP（小规模）或分支定价（列生成，列 = 一个可行的箱子装载方案）。
6. **一维下料（2021D 型）**：
   a. 枚举所有可行的切割模式（长度在 $[4.8,12.6]$ 且尽量落在 $[8.0,11.6]$）；
   b. 建立"最大化利用 / 最小化损失"的整数规划；
   c. 或用 DP 按剩余长度递推。
7. **复杂度**：0-1 背包 $O(nW)$（伪多项式）；装箱精确解 NP-hard；FFD $O(n\log n)$。

## 8. Python实现思路

- **DP 一行流**：用 numpy 数组 + 倒序循环，$n=1000,W=10^4$ 时约 $10^7$ 次操作，秒级完成。
- **OR-Tools / PuLP**：写 0-1 模型，适合有额外约束（如"每组至少 3 件""某两类不能同组"）的场景。
- **列生成（装箱）**：主问题用 LP 选列，子问题用背包 DP 生成新列（价格 = 1 − 对偶值），是装箱精确解的标准方法。
- **易错点1**：**DP 循环方向写反**——0-1 背包必须倒序枚举容量，正序会允许同一物品被反复选取。
- **易错点2**：容量 $W$ 是浮点时不能直接做 DP（数组下标必须整数）；应**先按最小单位量化**（如把米换成厘米）。
- **易错点3**：容量过大（如 $10^8$）时 DP 数组内存爆炸，必须改分支定界或 MILP。
- **易错点4**：装箱问题用背包模型求解（把"箱数最少"写成"价值最大"），目标语义完全错。
- **易错点5**：求解结果未做逐箱校验，出现"某箱超重 0.3"这类肉眼难察的违规。
- **易错点6**：2011D 型偏差约束写成等式，导致无解（实际允许 0.5 m 误差）。

## 9. MATLAB实现思路

- **DP**：用向量化更新 `f(max(w_i,1):W) = max(f(...), v_i + f(...))` —— **注意方向**，MATLAB 同样必须"倒序"（从大到小更新），可直接用 `for c = W:-1:w_i`。
- **MILP**：`intlinprog` 或 `optimproblem` + `optimvar('x', n, 'Type','integer','LowerBound',0,'UpperBound',1)`。
- **装箱**：无内置函数，自写 FFD（`sort` 降序 + 循环找第一个能放的箱子）只要 20 行。
- **下料问题**：可用 `intlinprog` 对枚举出的切割模式求解。
- **易错点1**：MATLAB 的 `max` 对向量是逐元素，对两个向量要写成 `max(A,B)`（两参数形式），不是 `max([A;B])`。
- **易错点2**：`intlinprog` 的 `intcon` 若漏掉部分变量，会返回小数解且不报错。
- **易错点3**：用 `optimvar` 时忘记设 `'Type','integer'`，得到半件物品。
- **易错点4**：FFD 实现时若用 `find` 找第一个可放箱子，注意"索引从 1 开始"，与 Python 的 0 起点不同。
- **易错点5**：容量为浮点时 `intlinprog` 的数值容差可能导致"超重 $10^{-9}$"的伪违规，需设 `ConstraintTolerance`。

## 10. 优点

1. **模型极其通用**：几乎所有"容量限制下的选择/分组"问题都能归结为它们。
2. **DP 解 0-1 背包很快**：$O(nW)$ 对中小规模是秒级。
3. **有经典近似保证**：FFD 的 11/9 界、背包的分支定界上界，都能写进论文。
4. **下界易算**：装箱下界 $\max\{\lceil\sum w/C\rceil,\#\{w>C/2\}\}$ 一行就能算。
5. **易与其他模型结合**：装箱 + TSP = VRP；背包 + 划分 = 调度；背包 + 覆盖 = 覆盖选址。

## 11. 缺点

1. **NP-hard**：规模增大就只能近似。
2. **容量必须离散化**：浮点容量会带来量化误差。
3. **单一目标**：真实问题常要兼顾"装满率"与"组数最少"（多目标）。
4. **装箱的精确解很难**：$n>100$ 基本只能启发式。
5. **对参数精度敏感**：2011D 的"0.5 米误差""少 1 根"这类容忍度取多少直接决定结果，需说明依据。

## 12. 适用条件

- **当**决策是"从一批对象中挑选一部分，满足总容量约束，使总价值最大"时，用背包。
- **当**决策是"把全部对象分组，每组不超过容量，使组数最少"时，用装箱。
- **当**物品可任意拆分时，**不要用整数模型**——直接按价值密度贪心或用 LP。
- **当**容量 $W\le10^5$ 且 $n\le10^3$ 时，用 DP 求精确解；容量过大时用分支定界或 MILP。
- **与本三题相关的明确判断**：
  - **2026D**：**强相关（问题3）**。赛题原文："基于问题 2 求解得到的无冲突用频计划，如果**不限制频段和时间的平移幅度，在不增加时频资源的前提下，最多还能安排多少 C 类用频装备？**"〔原文〕——这本质是"**在二维资源（时间 × 频率）网格中装入尽可能多的新计划**"，是**二维装箱/最大装箱**问题。**推荐做法**：把时频资源离散成 100 频段 × 若干时间片的网格，每个新计划占用一个矩形块（考虑其重复使用的时间序列），用二维装箱的启发式或 MILP 求解，并报告下界。 〔原文 + 推理〕
  - **2026B**：**弱相关**。机器狗不涉及"装载"。唯一可能的相关点是"把有限的行进时间预算分配给不同搜索区域"——可写成背包（每个区域有"消除不确定性"的价值与"所需时间"的重量），但**这是人为建模，实际更应该用覆盖/路径模型**。 〔推理〕
  - **2026C**：**弱相关**。储能充放电的"不能同时充放"和功率上限形式上像容量约束，但因为是连续的，直接用 LP 即可，**不需要整数化**。 〔推理〕

## 13. 不适用情况

- **当**物品可拆分（如资金、电量、时间的分配）时，不要用 0-1 背包，那是 LP（分数背包）。
- **当**目标不是"价值最大"而是"全部装完且组数最少"时，不要用背包模型。
- **当**容量是连续的且精度要求高时，不要做 DP 离散化，改 MILP。
- **当**物品之间存在复杂相容性约束（如"这三件不能同组"）时，纯 DP 难以表达，应用 MILP 或图着色。
- **当**$n$ 极大（$10^5$）且有实时要求时，不要精确求解，用 FFD 类线性时间启发式。
- **当**存在"每组数量还要均衡"的公平要求时，标准背包/装箱不够，需加均衡约束。

## 14. 常见错误

1. **0-1 背包 DP 循环方向写反**：正序枚举容量会让物品被重复选取，结果是"完全背包"的值（通常更大更诱人）。**这是最经典的实现错误。**
2. **背包与装箱混用**：把"最少箱数"写成"价值最大"，得到语义错误的解——**箱数最少不等于装满率最高**。
3. **浮点容量直接做 DP**：数组下标必须是整数；若不量化会把容量截断（如 9.8 m 当 9 m），结果系统性偏差。
4. **忽略偏差容忍**：2021D 的"4.8~12.6 米"与"8.0~11.6 米"是两个不同层级的约束（硬约束 vs 可接受区间）〔原文〕，把它当成同一个约束会算错损失。
5. **装箱未做逐箱校验**：超重 0.01 吨的解在数值上"可行"但在题意上违规；必须用独立脚本按原始精度复核。
6. **目标权重失真**：2011D 是"成品捆数最多"为第一目标、"最短长度最长的成品越多"为第二目标〔原文〕，若只优化第一个目标会得到"捆数多但质量差"的方案。
7. **忽略计算时限**：2011D 明确要求"为了食品保鲜，要求在 30 分钟内产生方案"〔原文〕；忽略时限会写出现实不可用的算法。
8. **DP 数组内存爆炸**：$W=10^8$ 时分配 $10^8$ 个 float64 就是 800 MB，直接内存溢出。

## 15. 论文写法

**可套用句式**：

1. "以各待选监测点是否被选中为 0-1 决策变量 $x_i$，以监测代表性总得分为目标、以总采样成本不超过预算为约束，建立 0-1 背包模型，并采用动态规划求解，时间复杂度 $O(nW)$。"
2. "该问题等价于装箱问题：需将全部原料划分为若干捆，每捆总长度不超过标准长度加 0.5 m 的允许偏差，目标为捆数最大；由总长度与单捆容量可得捆数下界为 $\lceil L_{\text{total}}/L_{\text{max}}\rceil$。"
3. "本文采用首次递减（FFD）算法构造初始解，其近似比不超过 $11/9\,OPT+6/9$，随后用局部交换进一步改进，总捆数由初始的 186 捆降至 193 捆的最优值。"
4. "考虑到题设允许总长度有 0.5 m 的偏差、总根数允许比标准少 1 根，本文将容量约束由等式放宽为区间约束 $L_{\text{target}}-0.5\le\sum l_ix_{ik}\le L_{\text{target}}+0.5$。"

**应配的图表**：

- **装载方案示意条带图**（每个箱子/捆画成一条水平带，内部按物品长度分段着色，最直观）；
- **价值—容量 DP 表热力图**（小规模时展示 DP 的填表结构）；
- **算法对比表**（贪心 / FFD / DP / MILP 的解与耗时）；
- **装满率分布直方图**（每个箱子的利用率分布，展示方案质量）；
- **下界与解对比柱状图**。

## 16. 可创新方向

1. **二维/三维装箱**（**2026D 问题3 直接相关**）：时频资源是二维的（时间 × 频率），每个计划占用矩形块。**二维装箱比一维难得多，但可用"分层/分条带"启发式**，论文里要明确给出下界（面积下界 + 最长边下界）。 〔推理〕
2. **带冲突的装箱（Bin Packing with Conflicts）**：物品之间存在不能同箱的约束——**这正是 2026D 的完整结构：装箱 + 冲突图**。这个组合模型在文献中确实存在，用它来命名你的模型会显得专业。 〔推理〕
3. **多目标装箱**：箱数最少 + 装满率最高 + 每组均衡，用 NSGA-II 求前沿（与《多目标优化与Pareto前沿》联动）。
4. **鲁棒/随机装箱**：物品尺寸或数量不确定时的"以概率 $1-\alpha$ 装下"方案。
5. **在线装箱**：物品逐个到达，需立即决定放入哪个箱子——**2026B 的在线搜索、2021D 的实时切割都有这个味道**。可比较"在线算法"与"离线最优"的比值（竞争比）。 〔推理〕
6. **一维下料的模式枚举 + 列生成**（2021D 型）：枚举所有可行切割模式，用列生成求最优，报告与贪心的差距。
7. **带偏差容忍的装箱**：把 2011D 的"0.5 米误差"做成参数 $\delta$ 并做敏感性分析，说明容忍度对结果的影响。 〔原文 + 推理〕
8. **DP + 分支定界的混合**：大容量时用"分数背包上界 + DP 分支"，兼顾效率与精确性。

**与 2026 三题的接口**（本节小结）：
- **2026B**：弱。仅在"把有限行进时间预算分配到各搜索区域"这种人为建模下才成立，不建议。
- **2026C**：弱。储能约束是连续的，直接用 LP，不需要整数化。
- **2026D**：**强（问题3）**。在"不增加时频资源前提下最多还能安排多少 C 类"就是**二维装箱 + 冲突约束**——即"带冲突的装箱（Bin Packing with Conflicts）"，用这个文献名来命名模型会显著提升专业度。
