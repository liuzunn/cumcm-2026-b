# 最小生成树

> **证据等级说明**：〔原文〕= 语料中直接读到的句子/标题；〔归纳〕= 从多篇语料共有的写法中归纳；〔推理〕= 无直接语料支撑、由模型性质推出的判断。

## 1. 模型用途

最小生成树（MST）在赋权连通无向图中找一棵**连接全部节点、总权重最小**的树（$n$ 个节点、$n-1$ 条边、无环）。国赛里它的用途比想象中窄，但有三个固定位置：

1. **网络铺设设计**：管道、电缆、道路的最省连接方案；
2. **路径/结构的粗解**：多旅行商、巡视路线问题中，**MST 的权值是 TSP 最优解的下界**——这是 1998B"最优解的证明"用得上的理论工具〔原文，见《旅行商问题TSP》〕；
3. **聚类/骨架提取**：用 MST 的边做单链接聚类（去掉最长的 $k-1$ 条边得到 $k$ 个簇），2023B 多波束测线的区域划分可用这个思路〔推理〕。

**一句话判断**：当题目是"用最少的（长度/成本）把所有点连起来"，且**不要求回到起点、也不要求访问顺序**时，才是 MST。

## 2. 题目特征

1. **题眼词**："连接所有""铺设""布线""网络设计""最省""联通"。
2. **无向、无顺序要求**："把 $n$ 个点连成一个网络"——一旦题目要求"巡视""巡回""回到起点"，那就是 TSP 不是 MST。
3. **给了完整的距离/成本矩阵**。
4. **用它做下界**：题目要求"证明最优"或"给出下界"。
   - 1998B 原句（论文）："从理论上证明了完成巡视至少要分……"、"显然这也是在组数少于……的情况下最短巡视时间的**下界**"〔原文〕
5. **局部区域连通性分析**：2012D 机器人避障用 MST 思想处理障碍网络〔原文，检索命中〕。

## 3. 数学原理

**来源**：Kruskal（1956）与 Prim（1957）算法；Borůvka（1926）更早〔推理，属通用理论〕。

**成立前提**：

1. **图连通无向**：不连通时只有"最小生成森林"（每连通分量一棵树）。
2. **边权可加且固定**：权重是长度、成本、时间等加性量。
3. **无向**：MST 定义在有向图上不成立（有向图对应的是最小树形图/朱刘算法）。
4. **树结构约束**（无环 + 连通）是硬性的：题目若允许"环路""冗余连接"，那就不是 MST。

**核心定理（写进论文很加分）**：

- **切割性质（cut property）**：对任意把 $V$ 分成两部分的割，横跨该割的**最小权边**必属于某棵 MST。
- **环性质（cycle property）**：任意环中**权最大的边**必不属于任何 MST（权严格最大时）。
- **MST 的权值是 TSP 最优值的下界**：MST ≤ TSP（去掉 TSP 回路的一条边即得生成树）。**这是 1998B 型"下界证明"的理论依据。**
- **MST 最优性可直接验证**：检查所有非树边 $(u,v)$，其权应 ≥ 树上 $u$-$v$ 路径上的最大边权。这是一个 $O(E)$ 的正确性检验，比信任算法更硬。

## 4. 基本公式

**MST 问题**：

$$\min_{T\subseteq E}\;\sum_{e\in T}w(e)\quad \text{s.t.}\quad T\ \text{连通且无环},\; |T|=n-1$$

**Kruskal 的判环依据（拟阵/割性质）**：按权升序处理边，若边连接两个不同连通分量则加入。

**用 MST 做下界（TSP 论证，1998B 型）**：

$$\text{OPT}_{\text{TSP}}\;\ge\;\text{MST}\;\ge\;\frac{2}{n}\sum_{i}\text{(最小邻边权之和)}$$

更紧的下界（1-树下界）：

$$\text{OPT}_{\text{TSP}}\ge\;\min_{1\in T}\bigl\{w(1,\text{其最小邻边})+w(\text{MST of }V\setminus\{1\})\bigr\}$$

**单链接聚类的切边准则**：保留 MST 中权最小的 $n-k$ 条边，得 $k$ 个簇。

## 5. 参数含义

| 符号 | 含义 | 例 |
|---|---|---|
| $G=(V,E)$ | 连通无向赋权图 | 乡镇路网、待铺管道的点位 |
| $w(e)$ | 边权 | 距离 / 造价 / 铺设长度 |
| $T$ | 生成树（$n-1$ 条边） | 最终铺设方案 |
| $n$ | 节点数 | 需要在 $n$ 个点间铺线 |

## 6. 建模步骤

1. **确认"是不是 MST"**：先问三个问题——① 是不是要连接**全部**点？② 是不是**无向、无顺序**？③ 是不是只要求**总权最小**、且允许多条边从同一点分叉？三个都是"是"才是 MST。
2. **建图**：节点 = 待连通的点；边 = 可铺设的连接（**稠密图就建完全图**，稀疏图按实际可行连接建）。
3. **定权重**：欧氏距离、曼哈顿距离，或题目给的造价（含地形系数）。
4. **处理约束**：有些边因地形/禁飞区不可用 → 直接从图中删除（等价于权 $\infty$）。
5. **跑算法**得 $T$。
6. **最优性验证**：用"每条非树边的权 ≥ 树上对应路径最大边权"逐条检查。
7. **下界应用**（若用于 TSP）：报告 MST 权作为下界，与启发式解比较，给出 gap。
8. **结果可视化**：把树画在地图上。

## 7. 算法

1. **Kruskal（稀疏图首选，边驱动）**：
   a. 把所有边按权升序排序；
   b. 初始化并查集，每个节点自成一类；
   c. 依次取边 $(u,v)$：若 $\text{find}(u)\ne\text{find}(v)$ 则加入 $T$ 并 $\text{union}(u,v)$；否则跳过（会成环）；
   d. 直到 $|T|=n-1$。
   - 复杂度：$O(E\log E)$（排序主导），并查集近似 $O(E\alpha(n))$。
2. **Prim（稠密图首选，点驱动）**：
   a. 任取起点加入 $S$，维护 $\text{key}[v]$ = $v$ 到 $S$ 的最小边权；
   b. 每次取 $\text{key}$ 最小的未加入点 $u$ 加入 $S$，记录其连接边；
   c. 用 $u$ 的出边更新邻居的 $\text{key}$；
   d. 重复 $n-1$ 次。
   - 复杂度：$O(E\log V)$（堆）/ $O(V^2)$（朴素，稠密图更快）。
3. **Borůvka**：每轮每个连通分量选最小出边，适合并行与分布式。
4. **正确性检验**：对每条非树边 $(u,v)$，检查 $w(u,v)\ge \max_{e\in P_T(u,v)}w(e)$。
5. **不连通处理**：得到最小生成森林，各分量分别处理并报告"需额外连接"。
6. **复杂度总结**：Kruskal $O(E\log E)$；Prim+堆 $O(E\log V)$；朴素 Prim $O(V^2)$。

## 8. Python实现思路

- **NetworkX**：`nx.minimum_spanning_tree(G, algorithm='kruskal'|'prim'|'boruvka', weight='weight')`，返回一棵树（`Graph` 对象），用 `T.edges(data=True)` 取出边与权。
- **SciPy**：`scipy.sparse.csgraph.minimum_spanning_tree(csgraph)`，输入**稀疏邻接矩阵**（0 表示无边），返回同样是稀疏矩阵。**大规模时比 NetworkX 快很多**。
- **易错点1**：NetworkX 的 MST 函数对**有向图**会先转成无向图（把两条反向边合并取最小），若语义上有向则结果错误。
- **易错点2**：权重属性名不匹配（默认 `'weight'`），忘传就按权重 1 处理，得到"边数最少的生成树"。
- **易错点3**：SciPy 的 `minimum_spanning_tree` **把 0 当作"无边"**，所以权为 0 的边会消失。若确有 0 权边，需加一个小正数偏移再减回。
- **易错点4**：图不连通时 NetworkX 只返回**一个分量**的树（不报错），需先 `nx.is_connected(G)` 检查。
- **易错点5**：完全图的边数 $O(n^2)$，$n=5000$ 就是 1250 万条边，NetworkX 会非常慢——用 SciPy 或自己写 Kruskal。

## 9. MATLAB实现思路

- **内置**：`minspantree(G)`（`graph` 对象），返回一棵 `graph` 表示的树，`T.Edges` 给出边与权。
- **有向图**：`minspantree` 不支持 `digraph`（有向对应的是 `shortestpathtree` 或朱刘算法），需转无向。
- **自己实现 Kruskal**：用 `sortrows` 对边表排序，用简单的父指针数组实现并查集（MATLAB 无内建并查集）。
- **易错点1**：`minspantree` 要求图连通，否则报错；先 `conncomp` 检查。
- **易错点2**：边的权重存在 `G.Edges.Weight`，若表里还有别的数值列可能被误用。
- **易错点3**：自己写并查集时路径压缩写错会导致性能急剧退化（甚至超时）。
- **易错点4**：用邻接矩阵建图时，未连接的边应设 `Inf` 而不是 0（`graph` 用邻接矩阵时 0 表示无边）。
- **易错点5**：返回的 `T` 是 `graph` 对象，若要取边列表需 `T.Edges.EndNodes`，直接当矩阵用会出错。

## 10. 优点

1. **极快**：$O(E\log E)$，百万节点可实用。
2. **最优性可验证**：切割性质、环性质给出简洁的正确性判据，论文里可以给证明。
3. **是 TSP 等难题的下界来源**：MST ≤ TSP，这为启发式解提供质量保证（gap）。
4. **结果直观**：一张树状网络图，评审一眼就懂。
5. **易于加约束**：把不可用边删除即可（等价于权 $\infty$）。

## 11. 缺点

1. **适用面窄**：只解决"最小连接"，不解决"顺序/巡回/容量/时间窗"。
2. **对权重误差敏感**：接近平局的边权变化会改变树结构（虽然总权变化很小）。
3. **只能处理无向图**：有向连接需用最小树形图（朱刘算法），实现复杂得多。
4. **不能表达节点容量、流量、层级**：这些要网络流或 MILP。
5. **不允许冗余**：现实中网络需要冗余（单点故障容忍），MST 是"最脆弱"的连接方式。

## 12. 适用条件

- **当**题目要求"用最少的（长度/成本）把 $n$ 个点连成一个连通网络"，且不涉及巡回、顺序、容量时，用 MST。
- **当**你需要给 TSP/VRP 的启发式解一个**下界**以报告 gap 时，用 MST（或用 1-树下界更紧）。
- **当**需要做基于距离的层次聚类时，可用 MST + 切边。
- **当**图不连通但需要"最小生成森林"时，也用它（分分量求解）。
- **与本三题相关的明确判断**：
  - **2026B**：**弱相关**。圆域内没有障碍物，连接各检测点用直线即可，"最小生成树"仅在你想给"访问全部点的巡回路径"求下界时才有意义——**推荐把它作为 TSP 下界工具，而不是主模型**。 〔推理〕
  - **2026C**：**不适用**。C 题没有图结构。 〔推理〕
  - **2026D**：**不适用**。D 题是区间冲突图（求独立集/着色），不是生成树问题。 〔推理〕

## 13. 不适用情况

- **当**题目要求"回到起点""巡回""巡视一遍"时，**不要用 MST**——那是 TSP（见《旅行商问题TSP》）。这是国赛里最常见的模型误用之一。
- **当**图是有向的（单行道、单向传输）时，不要用 MST，应用最小树形图（朱刘/Edmonds 算法）。
- **当**需要网络的**可靠性/冗余**（某条边断掉后仍连通）时，不要用 MST，应用 $k$-连通子图或环网设计。
- **当**节点有容量上限、流量守恒要求时，用网络流或 MILP。
- **当**目标是"最小化最长边"（瓶颈生成树）时，虽然 MST 恰好也是瓶颈生成树，但要明确说明这一性质，避免误解。
- **当**权重是"最大坡度/最小宽度"这类不可加量时，MST 的加法目标不成立。

## 14. 常见错误

1. **把 TSP 当 MST**：做完了发现"没有回到起点、也没有考虑访问顺序"，题目其实要求巡回路线。**必须回到题干确认有没有"回到出发点""巡视一圈"的字样。**
2. **有向图误用 MST**：2017D 巡检、2011B 单行道这类场景必须判断边的方向性。
3. **SciPy 的 0 权陷阱**：`minimum_spanning_tree` 把 0 当无边，0 权边会静默消失。
4. **未检查连通性**：不连通时算法只覆盖一个分量，结果"少了几个点"却不报错。
5. **权重属性名不匹配**：得到按边数最少的树，结果看起来合理但完全不对。
6. **把 MST 权当作 TSP 最优值**：MST 只是**下界**，直接当答案会严重低估（差距可达 30%—50%）。
7. **忽略节点数上限**：完全图 $O(n^2)$ 条边，$n$ 上千时内存与时间都会出问题。
8. **结果未做正确性检验**：至少抽查几条非树边，验证环性质。

## 15. 论文写法

**可套用句式**：

1. "以 17 个乡镇为节点、以两两之间的公路距离为边权，构建完全无向赋权图 $G=(V,E)$，建立最小生成树模型，目标为铺设总长度最小。"
2. "采用 Kruskal 算法求解：将所有边按权升序排列，用并查集维护连通分量，依次加入不构成环的边，直至选出 $|V|-1=16$ 条边，时间复杂度 $O(E\log E)$。"
3. "由最小生成树的切割性质可知，对任意将节点集分为两部分的割，横跨该割的最小权边必属于某棵最小生成树，故所求方案为全局最优。"
4. "进一步地，由于最小生成树的权值是旅行商问题最优值的下界，本文用 MST 权 $L_{\text{MST}}=386.4$ km 作为下界，与模拟退火求得的 $L=472.1$ km 相比，gap 为 22.2%，说明启发式解仍有改进空间。"

**应配的图表**：

- **网络节点与候选边示意图**（标出哪些边可用、哪些被禁）；
- **最小生成树结果图**（用粗线高亮选中的 $n-1$ 条边）；
- **算法过程表**（Kruskal 逐步加入的边及累计权，展示算法执行过程）；
- **下界对比柱状图**（MST 下界 vs 启发式解 vs 理论最优（若已知））；
- **聚类树状图（dendrogram）**（若用于聚类）。

## 16. 可创新方向

1. **带约束的 MST**（约束生成树，NP-hard）：如"每个节点的度数不超过 $d$"（度约束 MST）、"总边数受限"，可用 MILP 或启发式，是很好的加分点。
2. **双层：MST 下界 + 启发式上界**（**与 2026B 相关**）：对 2026B 的"访问全部检测点的巡回路径"，用 MST 给下界、用最近邻/2-opt 给上界，报告 gap ——这是把"本来只能给个方案"提升为"有质量保证的方案"的捷径。 〔推理〕
3. **鲁棒 MST**：边权不确定时求"最坏情况下最优"或"最小期望"生成树。
4. **MST 用于聚类与区域划分**（**与 2023B 相关**）：把测线按水深/坡度分区时，可用 MST + 切边自动确定分区数量，比人工划分更有说服力。 〔推理〕
5. **MST + 网络可靠性**：在 MST 基础上加冗余边，做"成本 vs 可靠性"的 Pareto 分析（与《多目标优化与Pareto前沿》联动）。
6. **动态/在线 MST**：边权随时间变化（如道路拥堵）时的增量维护，属算法层面的创新。
7. **与 2026D 的弱接口**：若把频率资源建模成"必须把若干频段连成一个可用块"的结构，可能用到生成树思想，但这偏离 D 题主线，**不建议**。

**与 2026 三题的接口**（本节小结）：
- **2026B**：中。最佳用法是**给"访问全部检测点的巡回路径"提供下界**（MST ≤ TSP），从而量化在线策略相对离线最优的代价。
- **2026C**：不适用。
- **2026D**：不适用（D 题是独立集/着色，不是生成树）。
