# 岭回归与Lasso

> **证据强度提示**：两模型在国赛语料中证据极薄。岭回归全库仅 1 处命中，且出现在 2023C C228 中作为**被证伪的对照模型**；Lasso 全库 0 命中。第 17 节会如实区分，勿把推荐强度误读为语料支持强度。

## 1. 模型用途

二者都是**带惩罚项的最小二乘**，定位是"普通最小二乘（OLS）不好用时的替代估计器"，解决两类困境：

1. **共线性使 OLS 系数爆炸**。自变量两两相关系数接近 1、VIF 远超 10 时，OLS 系数方差极大、符号可能翻转。岭回归加 L2 惩罚把系数往零收缩，以少量偏差换方差大幅下降。
2. **变量数逼近或超过样本数**（$p\ge n$）。此时 $\mathbf X^\top\mathbf X$ 奇异，OLS 无解或极不稳定；岭回归让矩阵可逆，Lasso 进一步把不重要变量的系数压成**精确的 0**，同时完成估计与变量选择。

国赛里还有次级用途：作为"简单模型试过、不行"的证据。2023C C228 原文："首先采用 ARIMA、岭回归、灰色预测模型等统计时间序列模型进行预测，结果发现效果较差。因此本文采用 LSTM……"〔原文〕——岭回归在此陪跑，但让后文上 LSTM 显得有依据。

## 2. 题目特征

出现下列特征才考虑（否则直接用 OLS）：

- 自变量多（$p\ge 8$）且**彼此高度相关**：2012A 葡萄酒题有 27 个葡萄理化指标〔原文〕；2012C 脑卒中题有气压、气温、湿度等 10 余个互相高度相关的指标〔原文〕。
- 题目要求"筛选关键因素""找出主要影响指标""消除多重共线性"。
- 样本少（几十），候选变量却多，或含大量二次项、交互项。1992A 正是因"交互项仍可表为其它项的线性组合"导致"系数矩阵不满秩"〔原文〕。
- 需要**系数随惩罚强度变化的图**（岭迹图、系数路径图）来论证变量重要性排序。
- 已做 OLS 但 VIF 超标、系数符号与常识矛盾。

**注意**：若自变量间相关系数都在 0.5 以下、$n$ 又远大于 $p$，惩罚方法相对 OLS 几无优势，强行使用只显得"为用而用"。

## 3. 数学原理

**来源**：岭回归由 Hoerl 与 Kennard（1970）提出，用于解决 $\mathbf X^\top\mathbf X$ 病态时最小二乘解不稳定；Lasso 由 Tibshirani（1996）提出，用 L1 惩罚替代 L2 以获得稀疏解。

**共同原理——偏差-方差权衡**：

$$\mathrm{MSE}(\hat{\boldsymbol\beta})=\mathrm{tr}\,\mathrm{Var}(\hat{\boldsymbol\beta})+\|\mathbb E[\hat{\boldsymbol\beta}]-\boldsymbol\beta\|^2$$

OLS 在无偏前提下最小化方差；共线性严重时方差项极大，此时**主动引入偏差**可换得方差更大幅度的下降，使总 MSE 变小。Gauss-Markov 定理保证的是"无偏估计中方差最小"，不是"所有估计中 MSE 最小"。

**等价约束形式**：岭回归等价于在球约束 $\|\boldsymbol\beta\|^2\le t$ 下最小化残差平方和；Lasso 等价于在菱形约束 $\|\boldsymbol\beta\|_1\le t$ 下最小化。菱形有尖角，最优解易落在顶点，从而产生精确为零的坐标——这是 Lasso 稀疏性的几何来源。

**前提与失效情形**：

1. **必须先标准化**。惩罚项与量纲直接相乘：一个变量以"元"、另一个以"万元"为单位时，同一 $\lambda$ 的压缩力度完全不同。**不标准化等于给量纲大的变量额外惩罚**，最致命。
2. **截距不参与惩罚**（或先把数据中心化），否则惩罚强度会随因变量平移而改变。
3. **$\lambda$ 必须选得合适**。$\lambda\to0$ 退化为 OLS，$\lambda\to\infty$ 只剩截距，须用交叉验证或 GCV 选取。
4. **Lasso 的前提是真实模型稀疏**。若真实关系是"100 个变量各贡献一点"，Lasso 会随机保留一部分，重抽样下极不稳定，此时应用 Elastic Net 或岭回归。
5. **二者都是有偏估计，经典推断失效**。不要对 Lasso 选出的变量照抄 OLS 式 t 检验，给 Lasso 系数报 p 值是常见的方法论错误。

## 4. 基本公式

先中心化与标准化：$\tilde x_{ij}=(x_{ij}-\bar x_j)/s_j$，$\tilde y_i=y_i-\bar y$。

**岭回归**：

$$\hat{\boldsymbol\beta}^{ridge}=\arg\min_{\boldsymbol\beta}\left\{\|\tilde{\mathbf y}-\tilde{\mathbf X}\boldsymbol\beta\|^2+\lambda\|\boldsymbol\beta\|_2^2\right\}
=(\tilde{\mathbf X}^\top\tilde{\mathbf X}+\lambda\mathbf I)^{-1}\tilde{\mathbf X}^\top\tilde{\mathbf y}$$

加 $\lambda\mathbf I$ 后条件数下降，恒可逆。

**Lasso**：

$$\hat{\boldsymbol\beta}^{lasso}=\arg\min_{\boldsymbol\beta}\left\{\frac{1}{2n}\|\tilde{\mathbf y}-\tilde{\mathbf X}\boldsymbol\beta\|^2+\lambda\|\boldsymbol\beta\|_1\right\},\qquad \|\boldsymbol\beta\|_1=\sum_{j=1}^{p}|\beta_j|$$

**弹性网**：$\displaystyle\frac{1}{2n}\|\tilde{\mathbf y}-\tilde{\mathbf X}\boldsymbol\beta\|^2+\lambda\left(\alpha\|\boldsymbol\beta\|_1+\frac{1-\alpha}{2}\|\boldsymbol\beta\|_2^2\right)$。

**正交设计下的解析解**（说明收缩方式的差别），记 $\mathbf z=\tilde{\mathbf X}^\top\tilde{\mathbf y}$：

$$\hat\beta_j^{ridge}=\frac{z_j}{1+\lambda},\qquad
\hat\beta_j^{lasso}=\mathrm{sign}(z_j)\max(|z_j|-\lambda,\,0)=S(z_j,\lambda)$$

后式即软阈值算子，是 Lasso 产生精确零的代数根源；岭回归只做等比收缩、永不为零。

**有效自由度**：$\mathrm{df}(\lambda)=\sum_j d_j^2/(d_j^2+\lambda)$（$d_j$ 为奇异值）；Lasso 的自由度近似为**非零系数个数**。

**GCV 选参**：$\displaystyle\mathrm{GCV}(\lambda)=\frac{\|\tilde{\mathbf y}-\tilde{\mathbf X}\hat{\boldsymbol\beta}(\lambda)\|^2/n}{[1-\mathrm{df}(\lambda)/n]^2}$；**K 折交叉验证**：$\displaystyle\mathrm{CV}(\lambda)=\frac{1}{K}\sum_{k=1}^{K}\|\tilde{\mathbf y}^{(k)}-\tilde{\mathbf X}^{(k)}\hat{\boldsymbol\beta}^{(-k)}(\lambda)\|^2$。

## 5. 参数含义

| 符号 | 含义 | 备注 |
|---|---|---|
| $\lambda$ | 惩罚强度 | 岭回归中常记作 $k$；必须由 CV/GCV 选出并报告 |
| $\alpha$ | 弹性网混合比例 | $\alpha=1$ 为 Lasso，$\alpha=0$ 为岭回归 |
| $\boldsymbol\beta$ | 回归系数向量 | 均为标准化尺度，报告时须还原 |
| $s_j$、$\bar x_j$ | 第 $j$ 个自变量的标准差与均值 | 标准化用 |
| $n$、$p$ | 样本数、自变量数 | $p\ge n$ 时 OLS 失效、惩罚方法仍可用 |
| $\mathrm{df}(\lambda)$ | 有效自由度 | 岭回归 $<p$ 且随 $\lambda$ 递减 |
| $K$ | 交叉验证折数 | 国赛小样本常用 $K=5$ 或留一法 |
| $\sigma^2$ | 误差方差 | 决定最优 $\lambda$ 的量级 |

## 6. 建模步骤

1. **先跑 OLS 并诊断共线性**（相关矩阵、VIF）。**只有 OLS 确实出问题才上惩罚方法**，否则无法论证引入的必要性。
2. **标准化**自变量、中心化因变量，并记录 $s_j$ 与 $\bar x_j$ 以便系数还原。
3. **选类型**：消除共线、保留全部变量 → 岭回归；挑出少数关键变量 → Lasso；变量成组相关、要求组内同进同出 → Elastic Net。
4. **画收缩路径**：岭迹图或 Lasso 系数路径图（横轴 $\log\lambda$）。
5. **用 K 折交叉验证或 GCV 选 $\lambda$**；Lasso 常另取"1SE 规则"下更大的 $\lambda$ 以获得更稀疏稳健的解。
6. **在最优 $\lambda$ 下拟合**，输出系数表与选中变量集合。
7. **bootstrap 检验选择稳定性**，选中频率低的变量不写进结论。
8. **与 OLS 并列对照**，两套系数与 VIF（或交叉验证误差）同表比较。
9. **报告预测性能**（验证集 RMSE/MAE），不要只报拟合 $R^2$。

## 7. 算法

1. 输入标准化设计矩阵 $\tilde{\mathbf X}$ 与中心化响应 $\tilde{\mathbf y}$。
2. 岭回归是**闭式解**。工程上用 SVD（$\tilde{\mathbf X}=\mathbf U\mathbf D\mathbf V^\top$）：$\hat{\boldsymbol\beta}(\lambda)=\mathbf V\,\mathrm{diag}\!\left(d_j/(d_j^2+\lambda)\right)\mathbf U^\top\tilde{\mathbf y}$，一次分解即可扫遍整条 $\lambda$ 路径。
3. Lasso 无闭式解，主流是**坐标下降**：固定其余系数，更新 $\beta_j\leftarrow S\!\left(\frac{1}{n}\mathbf x_j^\top(\tilde{\mathbf y}-\tilde{\mathbf X}_{-j}\boldsymbol\beta_{-j}),\lambda\right)\big/\big(\frac{1}{n}\|\mathbf x_j\|^2\big)$，循环扫描至收敛。
4. 沿 $\lambda$ 由大到小生成**正则化路径**，用前一个解作下一个的初值（warm start）。
5. 每个 $\lambda$ 上用 K 折交叉验证估计泛化误差，取最小者（或 1SE 规则）。
6. 在最优 $\lambda$ 上做最终拟合，并对 Lasso 结果做 bootstrap 稳定性统计。

**复杂度**：岭回归一次 SVD 为 $O(np^2)$，之后每多一个 $\lambda$ 仅增 $O(p)$，整条路径几乎免费。Lasso 坐标下降每次全扫描 $O(np)$，通常几十至几百次扫描收敛，即 $O(npT)$；整条路径因 warm start 近似线性叠加。全流程为"路径点数 × K 折 × $O(npT)$"，$n,p$ 为几百量级时秒级完成。

## 8. Python实现思路

- 首选 sklearn.linear_model 的 Ridge、Lasso、ElasticNet，以及自动选参的 RidgeCV、LassoCV、ElasticNetCV（内置 K 折交叉验证，结果在 alpha_ 属性）。
- **标准化必须显式做**：StandardScaler 先行，或用 Pipeline 串联以避免交叉验证时数据泄漏；旧版 normalize 参数已不推荐。
- 岭迹图：对一组对数等距 alpha 循环 fit，收集 coef_ 后画折线（横轴 $\log\alpha$）；系数路径图用 lasso_path 或 LassoCV 的 path 属性。
- 稳定性检验：sklearn.utils.resample 做 bootstrap，统计各变量被选中的频率。
- 系数还原：标准化系数除以 scaler.scale_，截距用 $\bar y-\sum_j\hat\beta_j\bar x_j$ 反算。
- statsmodels 的 fit_regularized 可给 p 值，但要清楚其推断是近似而非精确。
- 务必与 OLS 基线对照，把两者系数与 CV 误差放进同一张表。

## 9. MATLAB实现思路

- 岭回归用 ridge(y, X, k, 0)：k 为岭参数向量，末位 0 表示不做内部标准化（数据已自行标准化）；传 1 则由函数内部标准化。k = ridge(y, X, 0) 可获 GCV 自动选取的岭参数。
- 岭迹图：k 取对数等距序列循环调用 ridge，把返回的系数矩阵画成折线。
- Lasso 用 lasso(X, y) 系列，返回系数路径 B 与 FitInfo（含 Lambda、DF、MSE、SE），再由 IndexMinMSE 或 Index1SE 取最优模型。
- 交叉验证：lasso 支持 'CV' 名称-值对；岭回归可手写循环或用 cvshrink。
- 弹性网：lasso(X, y, 'Alpha', a)。
- 易错点：ridge 在 k=0 时给出的是 OLS 解，不要当作岭回归结果；ridge 返回的是**标准化尺度**系数，须手工还原。

## 10. 优点

- **共线性下系数稳定性显著优于 OLS**，把被 VIF 放大的方差压回去，符号不再乱跳。
- **允许 $p\ge n$**，OLS 无解时惩罚方法仍给唯一解。
- **Lasso 自带变量选择**，输出稀疏模型，可解释性优于主成分回归这类"合成变量"方法。
- **计算廉价**：闭式解与坐标下降都是秒级，整条正则化路径几乎免费，很适合作敏感性分析。
- **可产出论文级可视化**：岭迹图与系数路径图本身就能撑起一节"变量选择"论证。

## 11. 缺点

- **有偏估计**，系数不能按 OLS 方式做 t 检验与置信区间。
- **$\lambda$ 的选择影响结论**：最小 CV 误差与 1SE 规则可能选出不同变量集，必须报告准则。
- **Lasso 在强相关变量组上表现差**，会从一组高度相关的变量中任意保留一个，随样本扰动而变。
- **岭回归不产生稀疏解**，全部变量留在模型里，无法回答"哪几个因素最关键"。
- **系数被压缩后不能直接做边际解释**，"每增 1 单位、$y$ 变化多少"在岭回归系数语境下是错的。

## 12. 适用条件

- 当自变量间共线性明显（VIF 普遍大于 10、相关矩阵有 0.8 以上成片区块）且不想删任何变量时，用岭回归。
- 当候选变量多（$p\ge10$）、相信只有少数真正起作用、需输出"关键因素清单"时，用 Lasso。
- 当 $p$ 与 $n$ 同量级或 $p>n$ 时，必须用惩罚方法（或主成分回归、偏最小二乘）。
- 当变量成组高度相关、希望组内同进同出时，用 Elastic Net。
- 当自变量与因变量近似线性、需要稳健系数估计，或论文需要展示系数收缩的敏感性分析图时适用。

## 13. 不适用情况

- 当 $n$ 远大于 $p$ 且无共线性（VIF 全部接近 1）时不要用——OLS 已是最优线性无偏估计，惩罚只引入无谓偏差。
- 当关系本身非线性（曲面、阈值、饱和）时，不要指望惩罚方法解决，应先改模型形式（见《非线性回归与参数估计》）。
- 当题目要求严格的假设检验与置信区间（"在 5% 显著性水平下检验"）时，不要用 Lasso 系数替代 OLS 的推断结果。
- 当数据是带趋势与周期的时间序列时，不要把岭回归当时间序列模型——它没有任何自回归或季节性结构。2023C C228 把它与 ARIMA、灰色预测并称为"统计时间序列模型"是**概念误用**〔原文〕，不宜模仿。
- 当因变量是类别或计数时，应改用带惩罚的 Logistic/Poisson 回归。
- 当变量未标准化时，不要执行任何惩罚拟合。

## 14. 常见错误

1. **不标准化就加惩罚**。最致命的错误：量纲大的变量被过度压缩，变量重要性排序完全失真。
2. **对截距施加惩罚**，会让模型对因变量整体平移敏感；sklearn 默认不惩罚截距，手写求解时极易忽略。
3. **用岭回归做变量选择**。系数只趋近于 0 而不等于 0，"系数很小"不等于"变量不重要"；要稀疏就用 Lasso 或 Elastic Net。
4. **把岭回归当时间序列模型**。2023C C228 原文"首先采用 ARIMA、岭回归、灰色预测模型等统计时间序列模型进行预测"〔原文〕把三者并列，而岭回归本身不含时间结构；要写进论文须明确说明它是"以滞后项为自变量的回归"才成立。
5. **照抄 Lasso 系数的 p 值**，或**只报 $\lambda$ 不报选择准则**（必须写明是"K 折交叉验证最小误差"还是"1SE 规则"，否则结果不可复现）。
6. **忽略 Lasso 的选择不稳定性**。在高度相关的变量组上换个随机种子选出的变量就变了，至少跑一次 bootstrap 稳定性统计。
7. **拿惩罚模型的拟合 $R^2$ 与 OLS 比大小**。训练集 $R^2$ 必然更低（引入了偏差），该比较毫无意义。
8. **共线性其实该用别的办法**。国赛实际做法是**构造比值型复合指标**（2008B 用"生均事业性经费指数"替代人均 GDP，后者与生均事业性经费支出相关系数达 0.81〔原文〕）、**先降维再回归**（2012A A285 用主成分分析遴选指标〔原文〕）、或**逐步回归**（2012C 脑卒中题〔原文〕）；这些做法解释成本更低、评审接受度更高。

## 15. 论文写法

可直接套用的句式（尖括号为占位符）：

1. "由相关系数矩阵可见〈变量 $x_2$ 与 $x_3$〉的相关系数达 $\langle r\rangle$，VIF 最大值为 $\langle 值\rangle$，超过经验阈值 10，表明自变量间存在显著多重共线性，OLS 估计不稳定。为此本文改用岭回归，在标准化数据上求解 $\hat{\boldsymbol\beta}^{ridge}=(\tilde{\mathbf X}^\top\tilde{\mathbf X}+\lambda\mathbf I)^{-1}\tilde{\mathbf X}^\top\tilde{\mathbf y}$。"
2. "以 $\lambda$ 为横轴绘制岭迹图（图 $\langle n\rangle$），可见 $\lambda>\langle 阈值\rangle$ 后各系数趋于稳定，故取 $\lambda=\langle 值\rangle$（由 $K=\langle K\rangle$ 折交叉验证误差最小准则确定）。"
3. "Lasso 在 $\lambda=\langle 值\rangle$ 处将 $p=\langle p\rangle$ 个候选变量压缩至 $\langle 非零个数\rangle$ 个，非零变量为 $\langle 变量列表\rangle$；该结果在 $\langle B\rangle$ 次 bootstrap 中的选中频率均高于 $\langle 阈值\rangle$，选择是稳定的。"
4. "为验证惩罚回归的必要性，并列给出 OLS 与岭回归两套系数及交叉验证误差（表 $\langle n\rangle$）：OLS 系数中〈变量〉的符号与机理分析矛盾，而岭回归估计的符号与机理一致，交叉验证 RMSE 由 $\langle 值1\rangle$ 降至 $\langle 值2\rangle$。"

**配套图表**：**岭迹图**（各系数随 $k$ 变化的曲线簇，岭回归论文标配）；**Lasso 系数路径图**（横轴 $\log\lambda$，竖线标最优 $\lambda$）；**交叉验证误差曲线**（纵轴 CV 均方误差 ±1 标准误）；**VIF 对比表**（处理前/后）；**系数对照表**（变量/OLS/岭回归/Lasso/是否选中）；变量选择稳定性条形图。

## 16. 可创新方向

1. **把"处理共线性"写成完整论证链条**：相关矩阵热图 → VIF 表 → OLS 系数符号异常 → 岭迹图选参 → 系数稳定性提升 → 交叉验证误差下降。这条链条本身即是可评分点。
2. **惩罚方法 + 业务变量分组**。用 group Lasso 或先按业务含义分组再组内 Lasso，输出"哪一类因素更重要"，比逐个变量报系数更贴题目。
3. **与主成分回归、偏最小二乘并列对照**。三者都是应对共线性的路线（岭回归保留原变量、主成分回归造合成变量、PLS 兼顾因变量方向），做三方法对照表并说明选择理由，是语料中极少见但方法学扎实的写法。
4. **自适应权重**。用自适应 Lasso（权重 $1/|\hat\beta_j^{OLS}|^\gamma$）改善普通 Lasso 对大系数的过度压缩，低成本易实现。
5. **正则化路径 + 稳健性检验**。多轮 bootstrap 画出每个变量系数的箱线图，用"系数是否稳定地异于零"替代单次拟合的结论。

## 17. 优秀论文案例

### （一）岭回归：有 1 处直接案例，但证据薄弱

**2023C C228：蔬菜类商品的自动定价与补货决策**〔原文〕——**完全一致（作为被证伪的对照模型）**。

原文："基于问题一的分析可知题中所给的数据为一组时间序列，具有明显的周期性与趋势性，因此普通的回归模型较难良好的进行拟合预测。因此本文采用时间序列预测模型，首先采用 ARIMA、岭回归、灰色预测模型等统计时间序列模型进行预测，结果发现效果较差。因此本文采用 LSTM 长短时记忆网络模型进行预测。"同篇论文在需求弹性分析处报告了共线性诊断："六种品类销量的回归结果显著性 P 值均为 0.000……同时其 VIF 全部小于 10，模型构造良好，没有多重共线性问题"，随后用需求价格弹性（六品类均在 1% 水平显著为负）与支出弹性（辣椒类大于 1 属非必需品，其余多小于 1 属必需品）完成定价建模。

**必须如实说明的证据薄弱之处**：

- 该论文对岭回归**没有给出任何具体做法**——无岭参数选取准则、无岭迹图、无系数表、无交叉验证误差，只在摘要与正文各出现一次作为"试过但效果差"的列举项，**不能当作岭回归的标准用法范例**。
- 同一句把岭回归与 ARIMA、灰色预测并称为"统计时间序列模型"在方法学上不准确（岭回归本身不含时间结构），引用时应作为**概念混用的实例**而非方法范例。
- 该论文最终选用 LSTM 并报告"平均 R 方均达到 0.8 以上"〔原文〕，岭回归的角色是基线对照。

*可迁移要点*：即便只是陪跑，把它写进"我们试过的方法"清单也能让后续复杂模型的选择显得有依据；但要写得像样，至少应补上岭参数选取准则与一条 CV 误差曲线。

### （二）不用岭回归时，国赛实际怎么做共线性处理

1. **1992A：施肥方案对作物蔬菜的影响**〔原文〕——**仅相关**。论文明确引入方差膨胀因子作判据："当 VIF 最大值接近或超过 10，共线性显著，最小二乘所得结果失真；而当均趋于 1 时，认为共线性影响很弱。"据此把变量编码到 $[-1,1]$ 消除一次项与平方项间的共线性，再做逐步回归与二次响应面拟合，并指出"回归模型的不唯一性是由自变量间存在较强共线性所引起的"。
   *价值*：语料中**最早出现 VIF 判据**的论文，"编码变换 + 逐步回归"传统路线的完整展示。
2. **2008B：高等教育学费标准的探讨**〔原文〕——**仅相关**。建二本模型时发现"人均 GDP 与生均事业性经费支出高度线性相关（相关系数为 0.81），直接引入模型会使自变量之间产生多重共线性"，遂**构造比值型复合指标**"生均事业性经费指数"（生均事业性经费支出/人均 GDP）替代原变量。
   *价值*：处理共线性**最讨巧**的做法——不换算法，换变量定义，既解决问题又保留业务解释力。
3. **2012A：葡萄酒的评价_A285**〔原文〕——**仅相关**。面对 27 个高度相关的理化指标，**用主成分分析做指标遴选**，再以筛选后的指标建多元线性回归。语料中主成分回归路线的实际形态不是"用主成分当自变量"，而是"用主成分筛变量、再对原变量回归"，保留了系数可解释性。
4. **2012C：脑卒中发病环境因素分析及干预（逐步回归篇）**〔原文〕——**仅相关**。论文先指出"由于某些变量之间存在非常大的互相关（如温度之间的三个指标互相关系数都比较大），因此需要对多个变量进行筛选"，再用 SPSS 逐步回归完成变量选择，得以平均湿度为唯一显著变量的模型（F 检验 $p=0.006$），并进一步以平均湿度为因变量做二次逐步回归揭示间接影响。
   *价值*：逐步回归是语料中**出现频率远高于岭回归**的共线性应对方案，实现成本最低。

另一条编目层面的推理线索：N02 编目在 2019D（空气质量校准）下把"多元回归 / 岭回归 / 主成分回归"列为〔推理〕的核心模型候选〔推理〕；该年份论文抽取文本中未出现岭回归的实际使用，故不作为案例引用。

5. **2025E E030（AI 体测题）**〔原文〕——**仅相关（反向对照）**。据该论文摘要，其方法结构为 **Spearman 秩相关 + 随机森林 + 多元回归**：先用 Spearman 秩相关处理非正态与有序变量之间的相关性初筛，再用随机森林做变量重要性与预测，最后用多元回归给出可解释系数。（据 2025 年优秀论文 E030 摘要，原文为扫描件，经图像阅读核对）也就是说，面对变量类型混杂、相关性结构复杂的 2025 年题目，作者选作"可解释层"的仍是**普通多元回归**而非岭回归或 Lasso。
   *证据限度*：该摘要未说明是否做过共线性诊断（未提 VIF、未提相关系数矩阵），也未提及任何惩罚回归方法；因此它只能说明"到 2025 年惩罚回归在国赛优秀论文中仍无确证案例"，**不能反推岭回归不必要**。摘要未给出的任何数值（样本量、系数、精度指标）在本卡中一律不得写出。

### （三）Lasso：【资料中未找到直接案例，以下为〔推理〕】

**【资料中未找到直接案例，以下为〔推理〕】**"Lasso / LASSO / 弹性网 / 惩罚项"在本库全部优秀论文抽取文本中**0 命中**，编目笔记 N01、N02 的方法—真题映射表中也没有任何一条把 Lasso 归入某年题目。故本节无真实论文案例，以下为基于方法学与题型特征的〔推理〕：

1. **最可能落地的题型**〔推理〕：理化指标众多且高度相关的"辨识/标定/评价"类题目，如 2012A 葡萄酒（27 个葡萄理化指标）、2017C 颜色与物质浓度辨识（若扩展到多物质与多颜色空间维度）、2019D 空气质量校准类。共同点是候选变量远多于有效样本、变量间相关系数大片偏高。
2. **建议的写法**〔推理〕：不要只报 Lasso 结果，应写成"OLS → 主成分/逐步回归 → Lasso"的三方法对照，用 Lasso 回答"哪几个指标最关键"这一题目直接关心的问题，并用 bootstrap 选中频率说明稳定性。
3. **需警惕的坑**〔推理〕：样本量在几十量级时，交叉验证选 $\lambda$ 的方差很大，选出的变量集可能高度依赖随机划分；此时应优先报告"1SE 规则"下的稀疏模型并明确说明。
4. **不要做的事**〔推理〕：不要为了用 Lasso 就给本来只有 5–6 个变量的题目硬加几十个交互项当"候选特征"，这会触发与 2017C(1)"数据量不能低于 6，一维模型就不成立"〔原文〕同类的样本量不足问题。
