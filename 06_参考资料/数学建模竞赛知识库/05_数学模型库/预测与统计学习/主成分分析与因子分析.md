# 主成分分析与因子分析

## 1. 模型用途

两者都把**多个高度相关的指标压缩成少数互不相关的综合维度**。国赛里它们几乎不当主角，而是承担四类"清理战场"的工作：

- **指标遴选**：指标太多时先压成若干主成分再建评价体系。2012A A285 原文"运用主成分分析法进行指标遴选，构建酿酒葡萄质量的综合评价指标体系"〔原文〕。
- **成因解析**：把"哪个因素是主因"转化为"哪些指标在成分上载荷高"。2011A(5) 据此得出"工业区 Hg、Cu，交通区 As、Hg，生活区 Cu 为重金属污染的主要原因"〔原文〕。
- **定权重**：用方差贡献率给综合指标赋权。2010B 用因子分析得到 9 个影响因素的权重〔原文〕；2018C 以公因子方差贡献率为权重加权求和算出会员激活率〔原文〕。
- **消除多重共线性**：为后续回归铺路（2008B 是改用替代指标规避共线性的朴素做法〔原文〕）。

## 2. 题目特征

1. **指标多且高度相关**：通常 8–30 个指标，相关系数矩阵中有大量 0.7 以上的块。2011A(5) 的 8 个特征值里有 4 个恰为 0，说明 8 个变量实际只承载 4 维信息，正是强线性相关的直接证据〔原文〕。
2. **样本量相对指标数不充裕**：几十到几百个样本，样本不足时因子分析结果不稳定。
3. **题面问"主要影响因素 / 主要原因 / 主要成分"**：最强的信号词。2011A 问污染主要原因，2010B 问文化影响力的影响因素。
4. **后续要建回归或评价模型**：降维常是前置步骤——先降维再回归（主成分回归）、再评价（综合得分排序）、再聚类。2012A A285 即"主成分遴选指标 → 综合评价分级"〔原文〕。
5. **需要一张"信息浓缩"图**：碎石图与载荷矩阵表是这类论文的标配。

## 3. 数学原理

### 3.1 主成分分析（PCA）

PCA 的本质是一次**正交坐标旋转**：把原始 `p` 维坐标系转到"数据方差最大"的方向上。第一主成分是使投影方差最大的单位向量方向，第二主成分在与第一正交的约束下再最大化方差，依此类推。数学上等价于对**相关系数矩阵 `R`** 做特征分解：特征值即各主成分的方差，特征向量即载荷方向。

**成立前提**：

- **(P1) 变量间存在线性相关**。若各变量近乎正交，则特征值接近相等，第一主成分贡献率仅约 `1/p`，压缩失败——此时不能写"主成分分析表明各指标同等重要"，那是降维失败而非结论。
- **(P2) 线性结构**。强非线性关系需先变换；成分数据（各成分之和恒为 100%）须做 CLR/ILR 对数比变换。
- **(P3) 量纲可比**。用协方差矩阵时，量纲大、方差大的变量会独占第一主成分。**前提不成立时**（未标准化），第一主成分常只是"哪个指标数值最大"，而非真实主因。故实务统一用**相关系数矩阵**（等价于先做 z-score 标准化）。
- **(P4) 对异常值不敏感**。均值—协方差结构极受离群点影响，一个极端样本就能扭转载荷方向。

### 3.2 因子分析（FA）

FA 假设观测变量由**少数不可观测的公共因子**线性生成，外加各自的特殊因子：`X_i=\mu_i+\lambda_{i1}F_1+\cdots+\lambda_{im}F_m+\varepsilon_i`。

与 PCA 的关键差别：**PCA 是纯粹的方差分解（无模型、得分唯一确定）；FA 是协方差结构模型（载荷矩阵不唯一、因子得分是估计值）**。正因载荷不唯一，FA 才能做**旋转**（如 varimax 方差最大正交旋转），使每个变量只在少数因子上有大载荷，让因子可被命名——这是 FA 在归因场景下的核心优势。

**成立前提**：① 变量间的相关确实由少数公因子驱动（用 **KMO** 与 **Bartlett 球形检验**判断，KMO<0.5 或球形检验不显著则不宜做）；② 正交因子模型成立；③ 样本量足够（经验 `n\ge 5p` 且 `n\ge 100`）。**前提不成立时**：共同度 `h_i^2<0.4` 说明该变量无法被公因子解释，应剔除，强行保留会把噪声包装成"因子"。

## 4. 基本公式

**相关系数矩阵**

$$R=\frac{1}{n-1}Z^{\!\top}Z,\qquad z_{ij}=\frac{x_{ij}-\bar x_j}{s_j}$$

**特征方程（特征值与特征向量）**

$$|R-\lambda I|=0,\qquad R a_j=\lambda_j a_j,\qquad \lambda_1\ge\lambda_2\ge\cdots\ge\lambda_p\ge 0$$

**主成分**

$$Y_j=a_{j1}X_1+a_{j2}X_2+\cdots+a_{jp}X_p=a_j^{\!\top}X,\qquad \mathrm{Var}(Y_j)=\lambda_j$$

**贡献率与累计贡献率**（2011A(5) 采用的定阶规则）〔原文〕

$$\text{贡献率}_j=\frac{\lambda_j}{\sum_{k=1}^{p}\lambda_k},\qquad \text{累计贡献率}(m)=\frac{\sum_{j=1}^{m}\lambda_j}{\sum_{k=1}^{p}\lambda_k}$$

**因子模型与载荷**

$$X_i=\mu_i+\sum_{j=1}^{m}\lambda_{ij}F_j+\varepsilon_i,\qquad \mathrm{Cov}(X_i,F_j)=\lambda_{ij},\qquad h_i^2=\sum_{j=1}^{m}\lambda_{ij}^2$$

**因子得分**（回归/Bartlett 估计）

$$\hat F=(\Lambda^{\!\top}\Psi^{-1}\Lambda)^{-1}\Lambda^{\!\top}\Psi^{-1}(X-\mu)$$

**综合得分**（以方差贡献率为权重，2018C 与 2010B 的做法）〔原文〕

$$S_i=\sum_{j=1}^{m}w_j F_{ij},\qquad w_j=\frac{\lambda_j}{\sum_{k=1}^{m}\lambda_k}$$

**KMO 统计量**

$$KMO=\frac{\sum_{i\neq j}r_{ij}^2}{\sum_{i\neq j}r_{ij}^2+\sum_{i\neq j}q_{ij}^2}$$

其中 `q_{ij}` 为偏相关系数；KMO 越大越适合做因子分析。

## 5. 参数含义

| 符号 | 含义 | 取值/注意 |
|---|---|---|
| `p`、`n` | 原始指标数、样本数 | FA 经验要求 `n\ge 5p` 且 `n\ge 100` |
| `R` | 相关系数矩阵 | 用相关矩阵等价于先标准化，避免量纲主导 |
| `\lambda_j` | 第 `j` 个特征值 | 等于第 `j` 个主成分的方差（2011A(5) 记法〔原文〕） |
| `a_j` | 特征向量（载荷方向） | 符号不唯一（整体反号等价），解释时需统一 |
| `m` | 保留的主成分/因子个数 | 常用 `\lambda>1` 或累计贡献率 85%–95%〔2011A(5) 原文〕 |
| `Y_j`/`F_j` | 主成分 / 公共因子 | FA 的 `F_j` 不可观测，需估计 |
| `\lambda_{ij}` | 变量 `i` 在因子 `j` 上的载荷 | 2010B 称"第 i 个变量在第 j 个公共因子上的负荷"〔原文〕 |
| `h_i^2`、`\Psi` | 共同度、特殊因子方差阵 | `h_i^2<0.4` 的变量考虑剔除 |
| `w_j` | 综合得分的权重 | 用方差贡献率归一化（2018C、2010B 做法〔原文〕） |
| KMO、Bartlett | 可因子性检验 | KMO>0.7 良好，0.5–0.7 勉强，<0.5 不宜；Bartlett 需 p<0.05 |
| 旋转方法 | varimax / promax | 正交旋转使载荷两极分化、便于命名 |

## 6. 建模步骤

**PCA 路线**：① 选指标并检查是否含类别型/成分型变量（需先变换）；② 缺失值与异常值处理；③ **z-score 标准化**；④ 计算相关系数矩阵 `R`，检查是否存在强相关块（若几乎无相关则直接放弃降维）；⑤ 特征分解得 `\lambda_j` 与 `a_j`；⑥ **定阶**：取 `\lambda>1` 或累计贡献率达 85%–95% 的前 `m` 个（2011A(5) 规则〔原文〕）；⑦ 解释各主成分——按载荷绝对值大的变量命名（2012A A285 称"正交解"〔原文〕）；⑧ 计算主成分得分，用于后续回归/评价/聚类；⑨ 稳健性检验（剔除异常样本后载荷是否稳定）。

**FA 路线**：①②③ 同上；④ **KMO 与 Bartlett 检验**，不合格就不做；⑤ 估计载荷矩阵；⑥ **旋转**（varimax），观察旋转后载荷是否更易命名；⑦ 检查共同度，剔除 `h_i^2<0.4` 的变量后重跑；⑧ 计算因子得分；⑨ 按方差贡献率加权得综合得分（2018C、2010B 做法〔原文〕）。

## 7. 算法

1. **标准化**：`z_{ij}=(x_{ij}-\bar x_j)/s_j`，得矩阵 `Z`（`n×p`）。
2. **构造相关矩阵**：`R=\frac{1}{n-1}Z^{\!\top}Z`。
3. **特征分解**：对对称矩阵 `R` 做特征分解 `R=A\Lambda A^{\!\top}`；数值上用 **SVD** 更稳定（`Z=U\Sigma V^{\!\top}`，则 `\lambda_j=\sigma_j^2/(n-1)`，`a_j=v_j`）。
4. **定阶**：按 `\lambda_j` 从大到小排序，取 `\lambda_j>1` 或累计贡献率首次达到阈值的前 `m` 个。
5. **（FA 专用）旋转**：对前 `m` 个载荷做 varimax 正交旋转，最大化载荷平方的方差，使每个变量只在少数因子上有大载荷。
6. **得分**：PCA 为 `Y=ZA_m`；FA 用回归法或 Bartlett 法估计 `\hat F`。
7. **加权综合**：`S=\sum_j w_j F_j`，`w_j` 取归一化方差贡献率。

**复杂度**：相关矩阵 `O(np^2)`；对称矩阵特征分解 `O(p^3)`；载荷与得分 `O(np\cdot m)`。总量级 `O(np^2+p^3)`。由于 `p` 通常只有几十，实际瓶颈是数据读取而非计算，可在秒级完成。

## 8. Python实现思路

- PCA：`sklearn.decomposition.PCA(n_components=m, svd_solver='full')`，用 `explained_variance_ratio_` 看贡献率、`components_` 看载荷、`transform(X_std)` 得得分。
- **必须自己先标准化**：`StandardScaler().fit_transform(X)`——`PCA` 只做中心化不做标准化，漏掉这一步结果会被大方差指标主导。
- 碎石图：`plt.plot(np.arange(1,p+1), np.cumsum(explained))`，同时画累计贡献率曲线并标出 85% 横线。
- 因子分析：`factor_analyzer.FactorAnalyzer(n_factors=m, rotation='varimax')` 或 `statsmodels` 的 `Factor`；KMO 用 `factor_analyzer.factor_analyzer.calculate_kmo`，球形检验用 `calculate_bartlett_sphericity`。
- **易错点**：① 忘标准化；② `components_` 符号可整体翻转，两次运行可能反号，解释前需统一方向；③ 把 PCA 用在类别型变量上；④ 成分数据（如 2022C 古代玻璃的化学成分百分比）必须先做 CLR/ILR 变换，直接 PCA 会因闭合效应产生伪相关——该步骤在编目笔记中被列为该题的核心模型之一〔推理〕。

## 9. MATLAB实现思路

- PCA：`[coeff, score, latent, tsquared, explained] = pca(Z)`，`latent` 即特征值（2011A(5) 报告的 6.3757、0.9437、0.4392、0.2415、0、0、0、0 就是这组量〔原文〕），`explained` 是各主成分贡献率百分比。
- **标准化**：`Z = zscore(X)`；`pca` 默认只中心化，不标准化。
- 旋转：`rotatefactors(coeff(:,1:m), 'Method','varimax')`。
- 因子分析：`[lambda, psi, T, stats] = factoran(Z, m, 'rotate','varimax')`；`stats` 含检验统计量。球形检验可用 `barttest`。
- **易错点**：① `factoran` 默认 `'rotate','none'`，不给旋转就得不到好解释的载荷；② 它要求 `m<p` 且样本量足够，样本太少会报"矩阵接近奇异"；③ `coeff` 每列符号可翻转，两次运行可能不一致；④ MATLAB 无内置 KMO，需自行按公式计算偏相关。

## 10. 优点

- **一次性解决共线性**：主成分之间严格正交，后续回归不会出现方差膨胀与系数符号错乱。2008B 因"引入模型会使自变量之间产生多重共线性"而改用替代指标〔原文〕，主成分回归是更系统的解法。
- **定阶有客观依据、结果可视化**：碎石图 + 累计贡献率给出"保留几个维度"的判据；2011A(5) 正是靠 8 个特征值中只有前 4 个非零判断有效维度〔原文〕。
- **PCA 无分布假设、得分唯一**，实现简单。
- **FA 可解释性更强**：旋转后载荷两极分化，因子可命名。2012A A285 的"正交解"直接给出"主成分1 为葡萄总黄酮、总酚、DPPH 自由基和单宁的组合"这类可引用结论〔原文〕。
- **与评价模型天然衔接**：方差贡献率本身就是一组现成权重（2010B 由此得到权重表〔原文〕）。

## 11. 缺点

- **降维后失去原指标量纲含义**：主成分是线性组合，不能表述为"第一主成分增加了多少毫克"。
- **主成分个数可能仍很多**：2012A A285 在累计方差 83.044% 下保留**8 个**主成分、白葡萄**10 个**〔原文〕，相对 20 余个原始指标只压缩一半，必须说明降维收益有限。
- **PCA 对量纲与异常值敏感，且只捕捉线性结构**。
- **FA 的因子得分是估计值**：回归法与 Bartlett 法结果不同，据此排名次可能变动，须报告稳健性。
- **两者都无因果含义**（载荷高只说明共变），且**样本量要求常被忽视**——十几个样本对 20 个指标做因子分析，结果完全不可信。

## 12. 适用条件

用 **PCA**，当：① 指标数 `p\ge 6` 且相关系数矩阵中有明显强相关块；② 后续要建回归/评价/聚类模型且共线性是障碍；③ 需要把高维指标可视化；④ 变量都是连续数值型且已标准化。

用 **FA**，当：① 目标是**归因与命名**（找出"主要影响因素"）而非单纯压缩；② KMO>0.5 且 Bartlett 球形检验显著；③ `n\ge 5p` 且 `n` 不少于 100；④ 接受"因子是估计出来的"这一前提。

用**主成分回归**，当：① 回归自变量间共线性严重（VIF 很大）；② 目标是预测而非解释单个系数的量纲含义。

## 13. 不适用情况

1. **当变量之间几乎不相关时不要用 PCA**——第一主成分贡献率仅约 `1/p`，压缩失败；应保留原指标或改用其他方法。
2. **当指标为类别型变量时不要直接 PCA**——数值编码强加虚假序关系，应改对应分析（CA）。
3. **当数据为成分数据（各成分之和恒为 100%）时不要直接 PCA**——闭合效应产生伪负相关，须先做 CLR/ILR 变换。
4. **当 `n<p` 或样本量远低于 `5p` 时不要做因子分析**——相关矩阵接近奇异，因子解不稳定、不可复现。
5. **当目标是预测且不要求解释单个系数时，不必用 PCA 做主模型**——系数难以回转，可考虑岭回归（语料无此案例，仅为方法学建议〔推理〕）。
6. **当保留的主成分数接近原指标数时**——降维没有发生，与其硬写"主成分分析表明……"，不如直接做相关分析或聚类。

## 14. 常见错误

1. **不标准化就做 PCA**（或误用协方差矩阵）：量纲大、方差大的指标会独占第一主成分。2011A(5) 用的是**相关系数矩阵**，已隐含标准化〔原文〕；若改用协方差矩阵，绝不会得到 6.3757、0.9437……那组特征值。
2. **主成分个数缺乏说明，或选了却不交代降维收益**：2011A(5) 依据"取累计贡献率达 85%—95% 的特征值"得 3 个主成分〔原文〕；2012A A285 则在累计方差 83.044%（红葡萄）与 83.516%（白葡萄）下分别保留 8 个与 10 个主成分〔原文〕——后者接近"全保留"，必须说明压缩了什么。
3. **把主成分得分当原始指标解释**：应解读**载荷（正交解）**。2012A A285 写"主成分1 为葡萄总黄酮、总酚、DPPH 自由基和单宁的组合……"〔原文〕可以引用；写"主成分1 的值为 3.2，故总黄酮含量为 3.2"则错误。
4. **主成分回归按原始指标解释系数**：`\hat y=\gamma_1Y_1+\cdots+\gamma_mY_m` 中的 `\gamma_j` 对应主成分，要得到原指标系数须按 `\beta=A_m\gamma` 回转，并说明回转后系数仍不完全稳定。
5. **不做 KMO/Bartlett 就上因子分析**：无法证明"变量确实由少数公因子驱动"，KMO<0.5 时因子解无意义。
6. **把因子得分当成真实测量值**，据此排名次却不报告稳健性（换估计方法与旋转后名次是否稳定）。
7. **样本量不足仍做因子分析**：`n=15`、`p=20` 时相关矩阵接近奇异，结果完全随机。
8. **把共线性当成"信息丰富"**：1992A 在施肥量—产量模型中反复检验"共线性影响"〔原文〕，2005A 长江水质论文写"具有极强的共线性"〔原文〕——共线性必须在建模前处理。

## 15. 论文写法

**可直接套用的句式**：

- "为消除指标间的相关性并突出主要影响因素，本文对标准化后的 `\{p\}` 个指标计算相关系数矩阵，求得特征值为 `\{\lambda_1,\dots\}`；各主成分的贡献率与累计贡献率如表 `\{n\}` 所示。"
- "取累计贡献率达 `\{85\}`% 的前 `\{m\}` 个主成分（`\lambda_j>1`），其累计贡献率为 `\{数值\}`%，说明这 `\{m\}` 个主成分保留了原始指标 `\{数值\}`% 的信息。"
- "由载荷矩阵（正交解）可知，第一主成分主要由 `\{指标1\}`、`\{指标2\}` 与 `\{指标3\}` 决定，可解释为 `\{因子名\}`；据此得出 `\{区域/对象\}` 的 `\{原因\}` 主要来自 `\{结论\}`。"
- "以各主成分（因子）的方差贡献率为权重加权求和，得综合得分 `S_i=\sum_j w_jF_{ij}`，权重分别为 `\{w_1\}`%、`\{w_2\}`%……，与 `\{业务判断\}` 基本一致。"

**配套图表**：① **碎石图**（横轴主成分序号、纵轴特征值，画出 `\lambda=1` 水平线）；② **累计贡献率曲线或表**（标出 85% 阈值线）；③ **载荷矩阵表 / 载荷热力图**（行是原指标、列是主成分，绝对值大的加粗，是"命名主成分"的依据）；④ **旋转前后载荷对比表**；⑤ **主成分得分双标图 biplot**（样本散点叠加指标箭头）；⑥ **共同度表**（FA 专用，标注被剔除的低共同度变量）；⑦ **可因子性检验表**（KMO 值与 Bartlett 球形检验的 `\chi^2`、自由度与 p 值）。

## 16. 可创新方向

1. **主成分回归 + 系数回转**：把共线性处理从 2008B 式的"换替代指标"〔原文〕升级为系统方案——先 PCA 得正交主成分，对主成分回归，再用 `\beta=A_m\gamma` 回转成原指标系数并给出标准差，使论文同时拥有稳健预测与可解释系数。
2. **权重体系交叉验证**：除方差贡献率定权（2010B、2018C 做法〔原文〕）外，再用熵权法或 CRITIC 法独立算一套权重，比较两套权重的秩相关；一致则结论稳健，不一致则分析分歧来源——评价类题目最容易加分的一步。
3. **降维 + 成因定位的串联**：2011A(5) 停在"工业区 Hg、Cu，交通区 As、Hg，生活区 Cu"〔原文〕；可再进一步，把主成分得分作为因变量做空间插值（克里金/IDW），画出空间等值线图，从"哪个区污染重"推进到"污染源在哪里"。
4. **载荷的稳健性检验**：用 Bootstrap 估计载荷分布并报告关键载荷的 95% 区间，或比较剔除离群样本前后载荷符号是否翻转；同时报告 `m`、`m\pm1` 下综合得分排名的 Spearman 秩相关，把"取几个"变成有据可查的结论。

## 17. 优秀论文案例

1. **`2011A：城市表层土壤重金属污染分析（5）.pdf`**——"建立主成分分析模型，利用模型一中的单因子指数，建立矩阵，利用 matlab 进行处理后，得到相关系数矩阵，计算的八个特征值分别为：6.3757，0.9437，0.4392，0.2415，0，0，0，0。据累计贡献率得出三个主成分，由此确定工业区 Hg、Cu，交通区 As、Hg，生活区 Cu 为重金属污染的主要原因"；正文给出"取累计贡献率达 85%—95% 的特征值所对应的第一、第二…第 p 个主成分"的定阶规则与贡献率公式，并列特征值/贡献率/累计贡献率表〔原文〕。**与 PCA 的关系：完全一致**——特征值、主成分个数、区域结论三要素齐全，是国赛 PCA 归因类的最标准样本。证据等级〔原文〕。
2. **`2012A：葡萄酒的评价_A285.pdf`**——"问题二，运用主成分分析法进行指标遴选，构建酿酒葡萄质量的综合评价指标体系，并利用该指标体系建立基于综合评价的酿酒葡萄分级模型"；红葡萄"在累计方差为 83.044% 的前提下分析得到八个主成分"，白葡萄为 83.516% 下十个主成分；用 SPSS 得正交解并逐一命名——"主成分1 为葡萄总黄酮、总酚、DPPH 自由基和单宁的组合，主成分2 为总糖、可溶性固形物和干物质含量的组合"；并把"主成分分析中的贡献度"用于给 AHP 判断矩阵赋值〔原文〕。**与 PCA 的关系：完全一致**——同时展示 PCA 的两种用法（遴选指标、定权重），也是"主成分个数偏多"的真实样本。证据等级〔原文〕。
3. **`2010B：对上海世博会文化影响力的定量评估.pdf`**——"首先运用了线性关系因素的因子分析法，得出了各影响因素对文化影响力的影响权重"；正文给出因子模型 `z_i` 由 `p` 个公共因子与独特因子线性表示的形式、"公共因子"与"第 i 个变量在第 j 个公共因子上的负荷"的定义，并写"按预先规定所取的 P=9 个公共因子的累计方差贡献率达到的百分比(85%)"；把文化商品贸易份额、文化服务贸易份额、国际旅游收支份额、国际旅游人次份额、图书出版种类份额、电影产量份额、劳动生产率、国际移民份额、森林覆盖率这 **9 个因素**代入，得权重表 **23%、19%、17%、15%、8%、8%、4%、2%、0.003%**（表 5-6 原始数值为 0.23、0.19、0.17、0.15、0.08、0.08、0.04、0.02、0.00003，**九项合计约 96%，原文并未归一化到 100%——引用时不要替它凑成"合计 100%"**）；同篇再以 BP 神经网络补充非线性映射能力〔原文〕。**与因子分析的关系：完全一致**——因子分析直接产出权重表支撑后续评价。证据等级〔原文〕。
4. **`2018C：基于 RFMT 模型的百货商场会员画像描绘.pdf`**——"通过构建非活跃会员的相关指标，使用因子分析法，可计算得各非活跃会员激活率"；做法是"针对非活跃会员的 RFMT 指标进行因子分析，可得到相应指标的因子得分，以每个公因子的方差贡献率作为权重系数，对每个因子进行加权求和，从而计算得到各非活跃会员的激活率"，用 SAS 实现；随后建多元线性回归模型分析激活率与促销活动的关系，最小二乘拟合表明二者在流失会员与沉默会员两个群体中均呈正比例关系〔原文〕。**与因子分析的关系：变体（因子分析用于构造综合指标而非归因）**——降维方法服务于业务度量的典型用法。证据等级〔原文〕。
