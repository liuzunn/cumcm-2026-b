# 非线性回归与参数估计

## 1. 模型用途

解决两类问题：散点图明显弯曲；题目直接给了含待定参数的机理式。国赛四类用法：

1. **曲线拟合与外推**。2016C《电池剩余放电时间预测 (2)》由采样数据推断"电压的变化率，符合指数函数"，积分得 $u_t=ae^{bt}+ct+d$ 并用 MATLAB 拟合各电流下的参数〔原文〕。
2. **响应曲面与最优条件**。1992A《施肥方案对作物蔬菜的影响》对土豆与生菜建含一次项、平方项、交互项的二次回归模型，用"二次响应面回归"求最佳施肥水平，并由一阶导数（边际产量）、二阶导数（报酬递减性）分析极值〔原文〕。
3. **参数反演**：给了机理方程但参数未知，用观测数据估参后再做预测或优化。
4. **为非线性的存在提供证据**。2010B 世博会题原文："影响文化影响力指数的因素之间有一定的非线性，所以要求求解算法最好有一定的非线性映射能力"〔原文〕。

判断标准：**散点图呈系统性弯曲（饱和、抛物线、S 形、指数衰减），或题目已写出含未知参数的函数式时，用它**。

## 2. 题目特征

- 数据画出来是曲线：施肥量-产量、浓度-吸光度、时间-电压、剂量-响应。
- 题目出现"用初等函数表示""建立……的函数关系""求出最优……""确定其参数"。2016C 第 1 问原话即"用初等函数表示各放电曲线，并分别给出各放电曲线的平均相对误差"〔原文〕。
- 业务上存在饱和或递减机制：施肥报酬递减（1992A）、电压随放电时间衰减（2016C）、颜色读数与浓度非线性相关（2017C）。
- 存在明确的极值问题：最优施肥量、最优配比、收率最大。
- 已有线性模型但残差图出现明显 U 形。2017C(1) 正是因线性拟合"残差较大，拟合效果不佳"才"考虑建立非线性二次回归模型"〔原文〕。

## 3. 数学原理

**来源**：非线性最小二乘（NLS），是高斯-马尔可夫框架在 $f$ 对参数非线性时的推广。求解思路是把 $f$ 在当前估计处一阶泰勒展开、**局部线性化**，再用线性最小二乘迭代更新参数。

**前提**（比多元线性回归多出两条关键的）：

1. **模型形式正确指定**。系数含义完全依附于函数形式，$y=ae^{bx}$ 与 $y=a(1-e^{-bx})$ 是两套物理解释；形式选错，参数估得再准也无意义。
2. **误差为加性且同方差**：$y_i=f(\mathbf x_i;\boldsymbol\theta)+\varepsilon_i$。**最容易被"线性化技巧"破坏**——把 $y=ae^{bx}$ 取对数变成 $\ln y=\ln a+bx$ 后再做线性回归，实际假设的是**乘性误差**，并对 $y$ 小的观测点赋予过高权重，参数估计有系统偏差。
3. **参数可辨识**：不同 $\boldsymbol\theta$ 必须对应不同的 $f$，参数间不能有函数依赖。不可辨识时出现"参数相关阵接近 ±1、标准误巨大、拟合曲线却很好"的假象——**曲线对，参数错**。
4. **雅可比矩阵 $\mathbf J$ 在最优点列满秩**，是 Gauss-Newton 可解的必要条件，即前提 3 的局部版本。
5. **初值足够接近真值**：$S(\boldsymbol\theta)$ 一般非凸，初值太差会落入局部极小或发散。
6. **误差正态**：用于构造参数的 t 检验与置信区间（渐近成立）。

**前提不成立会怎样**：

- 参数不可辨识：$\mathbf J^\top\mathbf J$ 近乎奇异，标准误趋于无穷、协方差阵求不出（Python 中表现为 pcov 出现 inf）。2016C 对新电池数据回归得 $u_t=-2.51\times10^4e^{0.6387t}+2.513\times10^4e^{0.6386t}$〔原文〕，两指数项指数仅差 0.0001、系数等大反号，实为把同一指数项硬拆成两项的**过参数化**〔归纳〕：曲线好看，四个参数各自无意义。
- 初值太差：不收敛或落入错误局部极小。
- 线性化近似求解：得到的是"对数尺度上最小二乘"的解，与原尺度解不同，参数与残差解释都走样。
- 外推：指数模型与高次多项式在数据范围外迅速失真。

## 4. 基本公式

**一般形式** $y_i=f(\mathbf x_i;\boldsymbol\theta)+\varepsilon_i$，目标 $\displaystyle\hat{\boldsymbol\theta}=\arg\min_{\boldsymbol\theta}S(\boldsymbol\theta)=\arg\min_{\boldsymbol\theta}\sum_{i=1}^{n}\left[y_i-f(\mathbf x_i;\boldsymbol\theta)\right]^2$。

**Gauss-Newton 迭代**（$J_{ij}=\partial f(\mathbf x_i;\boldsymbol\theta)/\partial\theta_j$）：

$$\boldsymbol\theta_{k+1}=\boldsymbol\theta_k+\left(\mathbf J_k^\top\mathbf J_k\right)^{-1}\mathbf J_k^\top\mathbf r_k$$

**Levenberg-Marquardt 阻尼修正**：

$$\left(\mathbf J_k^\top\mathbf J_k+\lambda\,\mathrm{diag}(\mathbf J_k^\top\mathbf J_k)\right)\Delta\boldsymbol\theta_k=\mathbf J_k^\top\mathbf r_k,\qquad \boldsymbol\theta_{k+1}=\boldsymbol\theta_k+\Delta\boldsymbol\theta_k$$

**误差方差与参数协方差（渐近）**：

$$\hat\sigma^2=\frac{S(\hat{\boldsymbol\theta})}{n-q},\qquad
\mathrm{Cov}(\hat{\boldsymbol\theta})\approx\hat\sigma^2\left(\mathbf J^\top\mathbf J\right)^{-1}\Big|_{\hat{\boldsymbol\theta}}$$

**精度指标**（非线性模型下 $R^2$ 意义弱于线性模型，优先报误差类）：

$$R^2=1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y)^2},\quad
\mathrm{RMSE}=\sqrt{\frac{1}{n}\sum_i(y_i-\hat y_i)^2},\quad
\mathrm{MRE}=\frac{1}{n}\sum_i\left|\frac{y_i-\hat y_i}{y_i}\right|$$

信息准则用于不同形式比选：$\mathrm{AIC}=n\ln(S/n)+2q$。

**国赛常用函数形式**：二次多项式（含交互项）$y=\beta_0+\sum_j\beta_jx_j+\sum_j\beta_{jj}x_j^2+\sum_{j<k}\beta_{jk}x_jx_k$（1992A 响应面〔原文〕、2017C(1) 线性二次回归〔原文〕）；指数衰减/增长 $y=ae^{bx}$ 或 $y=ae^{bx}+ct+d$（2016C 放电曲线〔原文〕）；双指数生灭型 $y=me^{nt}+ke^{qt}$（2016C〔原文〕）；指数饱和 $y=a(1-e^{-bx})$；Logistic 阻滞增长 $y=K/(1+e^{-r(x-x_0)})$（2005A 与线性回归对照〔原文〕）；幂函数 $y=ax^b$。

**边际与极值（1992A 核心用法）**〔原文〕：边际产量 $\partial y/\partial x_j$；报酬递减判据 $\partial^2y/\partial x_j^2<0$；最优施肥量由 $\partial y/\partial x_j=0$ 解出；计入肥料价格 $p_j$ 与产品价格 $p_y$ 时经济最优条件为 $\partial y/\partial x_j=p_j/p_y$。

## 5. 参数含义

| 符号 | 含义 | 备注 |
|---|---|---|
| $\boldsymbol\theta$（或 $\boldsymbol\beta$） | 待估参数向量 | 个数 $q$，须 $n>q$，一般要求 $n\ge 3q$ |
| $f(\cdot;\boldsymbol\theta)$ | 指定的非线性函数形式 | 形式选择决定一切 |
| $\mathbf J$ | 雅可比矩阵 | $n\times q$，迭代与方差估计的核心 |
| $k$、$\lambda$ | 迭代次数、LM 阻尼因子 | 算法参数，非模型参数；须报告收敛标志 |
| $S(\boldsymbol\theta)$ | 残差平方和 | 目标函数 |
| $\hat\sigma^2$ | 误差方差估计 | 分母为 $n-q$，不是 $n-1$ |
| $K,r,x_0$ | Logistic 的饱和值、内禀增长率、半饱和点 | 2005A 用 Logistic 与线性对照〔原文〕 |
| $R^2$、RMSE、MRE | 拟合优度与误差 | 2016C 以平均相对误差 MRE 为主要精度指标〔原文〕 |

## 6. 建模步骤

1. **散点图定形式**：单调上凸且趋稳 → 指数饱和或 Logistic；先升后降 → 二次；单调衰减 → 指数。1992A 即先由图确认报酬递减形态再选形式〔原文〕。
2. **给初值**：图估法（读饱和值、初始值、拐点）、线性化反解（先对 $\ln y$ 与 $x$ 线性回归）、或多组随机初值试算取残差最小者。
3. **执行 NLS**，报告迭代次数、收敛标志与最终残差平方和。
4. **参数显著性检验**并剔除不显著项。1992A 发现"交互项仍不能进入模型，说明施肥交互作用对生菜产量无显著影响"〔原文〕。
5. **参数相关性诊断**：输出参数相关矩阵，非对角元绝对值接近 1 即参数不可辨识，须重新参数化（合并、固定其一或换形式）。
6. **残差诊断**：残差-拟合值图、残差-自变量图、Q-Q 图；仍有系统弯曲说明形式不对，异方差则说明该加权或取对数。
7. **模型比选**：用 SSE、RMSE、MRE、AIC 与残差结构比较。2017C(1) 的结论是"线性二次回归模型中，剩余标准差很小……残差相比多元线性回归模型降低了一个数量级，因此线性二次回归模型比线性回归模型更优"〔原文〕。
8. **敏感性分析**：扰动初值与数据子集看参数是否稳定；高次多项式还要检查范围外的行为。
9. **反演应用**：把参数代回机理式，求边际量、极值点或区间预测。

## 7. 算法

1. 输入数据、函数形式 $f$、初值 $\boldsymbol\theta_0$、容差 $\varepsilon$、最大迭代数 $T$；令 $k=0$，算 $\mathbf r_k=\mathbf y-f(\mathbf X;\boldsymbol\theta_k)$ 与 $S_k=\mathbf r_k^\top\mathbf r_k$。
2. 算雅可比 $\mathbf J_k$（解析求导优先，否则有限差分）。
3. 解 $\left(\mathbf J_k^\top\mathbf J_k+\lambda\,\mathrm{diag}(\mathbf J_k^\top\mathbf J_k)\right)\Delta\boldsymbol\theta_k=\mathbf J_k^\top\mathbf r_k$（Cholesky 或 QR，不显式求逆）。
4. 试探步：算 $\boldsymbol\theta_{k+1}=\boldsymbol\theta_k+\Delta\boldsymbol\theta_k$ 与 $S_{k+1}$；下降则接受并减小 $\lambda$（$\lambda\leftarrow\lambda/10$），否则拒绝并增大（$\lambda\leftarrow10\lambda$）后重试。
5. 收敛判据 $\|\Delta\boldsymbol\theta_k\|<\varepsilon_1$ 或 $|S_{k+1}-S_k|<\varepsilon_2$ 或 $\|\mathbf J_k^\top\mathbf r_k\|<\varepsilon_3$；未收敛且 $k<T$ 则回第 2 步。
6. 在 $\hat{\boldsymbol\theta}$ 处重算 $\mathbf J$，得 $\hat\sigma^2=S/(n-q)$ 与 $\mathrm{Cov}(\hat{\boldsymbol\theta})\approx\hat\sigma^2(\mathbf J^\top\mathbf J)^{-1}$。
7. 由协方差阵对角元算 t 值与置信区间；由相关阵非对角元诊断可辨识性；算 $R^2$、RMSE、MRE、AIC 并输出拟合曲线、残差与参数表。

**复杂度**：单次迭代含雅可比 $O(nq)$、构造 $\mathbf J^\top\mathbf J$ 为 $O(nq^2)$、解 $q\times q$ 方程组 $O(q^3)$，共 $O(nq^2+q^3)$；总代价 $O\big(T(nq^2+q^3)\big)$，$T$ 通常 10–50。$q$ 一般不超过 6，国赛规模下均为秒级。

## 8. Python实现思路

- 首选 scipy.optimize.curve_fit：传入函数、自变量、因变量与初值 p0，返回参数与协方差阵 pcov，标准误即 sqrt(diag(pcov))。
- 需更可控时用 scipy.optimize.least_squares，method="lm" 或 "trf"（带边界），用 bounds 限制参数的物理范围（如饱和值必须为正）。
- 多项式回归本质仍是线性最小二乘，优先用 numpy.polynomial.Polynomial.fit（比 polyfit 数值稳健），或 sklearn 的 PolynomialFeatures + LinearRegression。
- **易错点一**：初值不给或默认取 1 几乎必挂，先画图估初值。
- **易错点二**：不检查 pcov 是否含 inf——含 inf 即参数不可辨识，必须换参数化或换形式，不能硬报结果。
- **易错点三**：maxfev 太小导致"未收敛但返回结果"，务必打印成功标志 ier。
- 参数相关矩阵 corr = pcov / outer(sd, sd)，检查非对角元是否接近 ±1。
- 报告 MRE、RMSE 而不仅是 $R^2$；用 matplotlib 把拟合曲线与原始散点画在一起。

## 9. MATLAB实现思路

- 最省事的入口是 cftool 与 fit：fit(x, y, fittype("a*exp(b*x)+c*x+d")) 直接给出参数、置信区间与拟合优度（2016C 用的就是 MATLAB 拟合求参〔原文〕）。
- 交互式响应曲面用 rstool(x, y)：可指定纯二次、交互、全二次等形式，自动给出拟合曲面与残差（2017C(1) 的"多元非线性二次回归"就是用它建的〔原文〕）。
- 需精细控制时用 lsqcurvefit（支持上下界初值）或 nlinfit（返回参数协方差与残差）。
- nlinfit 配套 nlparci（参数置信区间）与 nlpredci（预测区间），是论文"参数估计表"的现成来源。
- 多项式用 polyfit 与 polyval；注意按降幂返回系数，阶数不宜超过 4–5（龙格现象）。
- 画图用 plot + hold on 叠加散点，残差用 plot(x, r, ".") 加 refline(0, 0)。
- 易错点：cftool 默认不打印参数相关矩阵，诊断可辨识性需自己由协方差算。

## 10. 优点

- **能刻画真实机理形态**：饱和、递减、S 形增长在国赛题中极常见，线性模型无能为力。
- **参数有物理意义**。1992A 从生产函数派生边际产量与报酬递减性并外推最优施肥量〔原文〕，"参数→业务结论"的链条是评审非常看重的。
- **仅需少量参数**即可拟合复杂曲线，比高次多项式泛化更好、外推更可控。
- **残差结构有诊断价值**：残差若仍呈系统弯曲，说明机理理解不到位，是改进方向的直接来源。
- 实现成本低，Python 与 MATLAB 都有一行式拟合入口。

## 11. 缺点

- **结果强烈依赖函数形式的选择**，而形式选择常带主观性；换一个同样"看起来合理"的形式，参数与结论可能完全不同。
- **参数不可辨识风险高**：多指数项、多余参数是重灾区。2016C 新电池模型两指数项的指数只差 0.0001〔原文〕即典型〔归纳〕。
- **对初值敏感**，存在局部极小与不收敛，需多初值试算。
- **外推危险**：指数与高次多项式在数据范围外会失控。
- 参数标准误与置信区间是**渐近**结果，小样本下不可靠。
- $R^2$ 在非线性模型下没有"解释方差比例"的严格含义，用它比较不同形式的模型会误导。

## 12. 适用条件

- 当散点图呈明确单调弯曲、饱和或抛物线形态，且能被一个 $q\le6$ 的初等函数刻画时适用。
- 当题目直接给定函数形式（含待定参数），要求"确定参数"或"用初等函数表示"时适用。
- 当业务上存在可解释的机制（报酬递减、指数衰减、阻滞增长）从而可以论证函数形式时适用。
- 当样本量至少为参数个数的 3–5 倍时适用；1992A 有完整的试验设计数据支撑二次响应面〔原文〕。
- 当需要求最优条件（极值点、边际量）且能对拟合函数求导时适用。

## 13. 不适用情况

- 当采样点只有 5–6 个却想拟合 4–5 个参数的双指数或高次多项式时不要用——自由度不足，曲线好看但参数无意义。2017C(1) 已实测"数据量不能低于 6，一般在 10–15 之间"〔原文〕。
- 当关系本质上是分段、跳变或阈值的，用一个光滑初等函数硬拟合时不要用，应改分段回归或阈值模型。
- 当自变量间已有强共线性、又做了多项式展开（一次项、平方项、交互项彼此高度相关）时，不要直接照抄参数符号；1992A 的处理是先做 VIF 诊断、再编码变换到 $[-1,1]$〔原文〕。
- 当数据只有趋势没有机理解释、目的是纯预测时，不要为"显得有理论"硬套函数式，应改时间序列方法。
- 当误差明显是乘性的（标准差随均值增大）时，不要用普通加性最小二乘，应改加权最小二乘或对数变换并说明。
- 当预测点远离建模数据范围时，不要用指数或高次多项式外推。

## 14. 常见错误

1. **数据点极少就上高参数模型**。2017C(1) 实测"数据量不能低于 6，一般在 10–15 之间"，且维度降得太低"模型就不太优甚至不成立"〔原文〕。6 个点拟合 4 个参数的双指数模型是典型自由度不足。
2. **参数不可辨识却照抄结果**。2016C(2) 对新电池数据的回归式 $u_t=-2.51\times10^4e^{0.6387t}+2.513\times10^4e^{0.6386t}$〔原文〕实为把同一指数项拆成两项，四个参数各自不可解释〔归纳〕。必须检查参数相关矩阵与标准误，不能只看曲线好不好看。
3. **用对数线性化代替非线性最小二乘**。对 $y=ae^{bx}$ 取对数做线性回归改变的是误差结构，且过度拟合小 $y$ 的点；要用须说明"假设乘性误差"。
4. **初值随手填 1**，导致不收敛或局部极小；也不能因"跑了三次结果不同"就挑最好看的那次报告。
5. **用 $R^2$ 比较不同函数形式的模型**。$R^2$ 在非线性拟合下不是无约束的方差分解，应改用 RMSE、MRE、AIC 与残差结构；2016C 的主指标就是平均相对误差 MRE〔原文〕。
6. **外推失控**。若最优施肥量落在试验范围之外，必须标注为外推并给置信区间。1992A 专门讨论"取最优量时，产量对〈某元素〉的取值敏感……应特别注意其使用量不能过高"〔原文〕。
7. **把二次项的显著性当交互作用的显著性**。1992A 的逐步回归显示交互作用对土豆显著、对生菜不显著〔原文〕，逐项检验才能得出这种区分。
8. **只报参数不报标准误**，或**多项式阶数无依据地往上加**（阶数每加一 $R^2$ 必升，但范围外的振荡急剧恶化）。
9. **遇到非线性就直接上神经网络**。2010B 确实因"因素之间有一定的非线性……要求求解算法最好有一定的非线性映射能力"而加用了 BP 网络〔原文〕，但那是**因子分析之后作为补充**。样本只有几十个时，3–5 个参数的非线性模型远比神经网络可靠。

## 15. 论文写法

可直接套用的句式（尖括号为占位符）：

1. "由〈图 n〉可见，〈因变量〉随〈自变量〉呈〈单调递增并趋于饱和 / 先增后减 / 指数衰减〉形态，据此选用 $y=f(x;\boldsymbol\theta)$，其中 $\boldsymbol\theta=\langle 参数列表\rangle$。初值由〈图估法 / 线性化反解〉确定，采用 Levenberg-Marquardt 算法求解 $\hat{\boldsymbol\theta}=\arg\min\sum_i[y_i-f(x_i;\boldsymbol\theta)]^2$，迭代 $\langle k\rangle$ 步收敛。"
2. "参数估计为 $\hat{\boldsymbol\theta}=\langle 估计值\rangle$，标准误 $\langle 标准误\rangle$，95% 置信区间 $\langle 区间\rangle$；残差平方和 $\langle SSE\rangle$，平均相对误差 MRE $=\langle 值\rangle\%$，最大相对误差 $\langle 值\rangle\%$。"
3. "为验证函数形式，本文并列比较〈线性 / 二次 / 指数饱和〉三种形式（表 $\langle n\rangle$）：〈二次模型〉的残差平方和为 $\langle 值\rangle$，相比〈线性模型〉降低一个数量级，且残差图中不再出现系统性弯曲，故最终选用该形式。"
4. "对拟合所得的生产函数求偏导得边际产量 $\partial y/\partial x_j=\langle 表达式\rangle$；令其为零解得最优〈施肥量 / 配比〉为 $\langle 值\rangle$。二阶导数 $\partial^2y/\partial x_j^2=\langle 表达式\rangle<0$，说明该范围内呈报酬递减，符合〈生物学 / 经济学〉规律。"

**配套图表**：**拟合曲线叠加原始散点图**（必备，须标出数据范围与外推区间的分界）；**残差图**（残差 vs 拟合值、残差 vs 自变量，并列展示不同模型的残差结构改善）；**参数估计表**（参数/估计值/标准误/t/p/95% 置信区间）；**参数相关系数矩阵**（论证可辨识性）；**模型比选表**（形式/参数个数/SSE/RMSE/MRE/AIC）；**响应曲面三维图与等高线图**（1992A 的二次响应面即此形式〔原文〕）；**边际产量曲线图**并标注极值点与最优投入量〔原文〕。

## 16. 可创新方向

1. **函数形式的比选本身就是贡献点**。并列 2–3 个形式，用 RMSE/MRE/AIC 与残差结构选优，并说明落选形式为何不符合机理。2017C(1) 的"线性 vs 线性二次"与 2005A 的"Logistic vs 线性回归"都是现成模板〔原文〕。
2. **参数约束与物理可行性**。用 bounds 把饱和值、增长率限制在物理合理范围内，避免拟合出"负饱和值"这类荒谬结果。
3. **分段非线性建模**。2016C 发现"参数在 50A 开始左右分为两段有规律的线段"，于是 20–50 A 段用二次多项式、50–100 A 段用直线分别建模〔原文〕；"先识别机制切换点、再分段拟合"比强行用一个函数拟合全区间更有说服力。
4. **参数可辨识性的显式讨论**。给出参数相关矩阵、做多初值试算、报告置信区间宽度——绝大多数队伍会漏写这一节，写出来即差异化优势。
5. **非线性回归 + 优化闭环**。以拟合出的响应面为优化目标求最优决策变量，再回到数据检查该点是否落在实验范围内；若在范围外则做外推敏感性分析并建议补充实验。1992A 从生产函数推最优施肥量即此思路雏形〔原文〕。
6. **稳健与加权拟合**。残差方差不齐时改用加权最小二乘（权重取 $1/\hat y_i^2$ 等），并对照普通最小二乘结果做稳健性说明。

## 17. 优秀论文案例

1. **1992A：施肥方案对作物蔬菜的影响（优秀论文②）**〔原文〕——**完全一致**。
   对土豆与生菜分别建含一次项、平方项、交互项的二次回归模型，用编码值把变量水平变换到 $[-1,1]$ 消除共线性后拟合"二次响应面回归"，并由因子分析给出各元素影响大小排序。论文对回归曲面做典型特征分析求最佳响应水平，写出"在土豆的回归方程中，各营养元素的交互作用，使任何一种的边际产量都包含自身和另两种元素的固定量……一种营养元素的生产率是受另两种与之配合使用的营养素高度制约的"，并用生产函数的二阶导数作报酬递减性指标；还指出"回归模型的不唯一性是由自变量间存在较强共线性所引起的"，用逐步回归验证交互作用对土豆显著、对生菜不显著。
   *要点*：**散点图定形式 → 编码变换消共线 → 二次响应面拟合 → 参数检验 → 逐步回归筛项 → 导数求边际与极值**，这是语料中最完整的一条非线性回归建模链。

2. **2017C：颜色与物质浓度辨识 (1)**〔原文〕——**完全一致**。
   在多元线性回归"残差较大，拟合效果不佳"之后，"考虑建立非线性二次回归模型，利用 MATLAB 统计工具箱中的 rstool 函数建模，通过剩余标准差和残差评估模型优劣"，结论是"剩余标准差很小，预测模型非常好，模型的残差相比多元线性回归模型降低了一个数量级，因此线性二次回归模型比线性回归模型更优"。关键词栏含"多元线性回归，多元非线性二次回归，MATLAB，误差，层次分析法"。
   *要点*：**用残差图作为"该上非线性了"的判据，用"残差降低一个数量级"作为选它的量化理由**——两句话可直接写进任何曲线拟合类论文。

3. **2016C：电池剩余放电时间预测 (2)**〔原文〕——**完全一致**（机理函数 + 参数估计 + 参数再回归）。
   论文由采样数据推断电压变化率符合指数函数，积分得电压-时间关系并用 MATLAB 验证"两条曲线基本吻合"。问题二对参数做线性回归：发现"参数在 50A 开始左右分为两段有规律的线段"，故 $20\le I\le50$ A 段用 $f(I)=gI^2+hI+r$ 拟合各参数、$50<I\le100$ A 段用直线拟合。问题三先对新电池、衰减状态 1、衰减状态 2 分别回归（得 $u_t=4980e^{0.6268t}-4952e^{0.6273t}$，SSE $=0.015$；$u_t=-6.702e^{0.6967t}+39.67e^{0.5261t}$，SSE $=0.02$ 等），再以 $u_t=me^{nt}+ke^{qt}$ 为形式"根据衰减状态 3 已给的数据，调整模型参数"，用最小二乘拟合四个常数并预测衰减状态 3 的剩余放电时间；全篇以平均相对误差 MRE 为主要精度指标。
   *要点*：**"机理函数 → 参数随工况变化 → 对参数再回归 → 外推到新工况"**是参数估计类题目的经典三段式创新结构。
   *必须如实说明的瑕疵*：对新电池数据的回归式 $u_t=-2.51\times10^4e^{0.6387t}+2.513\times10^4e^{0.6386t}$〔原文〕中两指数项指数仅差 0.0001、系数等大反号，属过参数化写法，参数不可辨识〔归纳〕；引用时不要照抄这四个参数，应作为"必须检查参数可辨识性与标准误"的反面教材。

4. **2010B：对上海世博会文化影响力的定量评估**〔原文〕——**仅相关**。
   论文"首先运用了线性关系因素的因子分析法，得出了各影响因素对文化影响力的影响权重"，随后因"影响文化影响力指数的因素之间有一定的非线性，所以要求求解算法最好有一定的非线性映射能力，因此我们又利用了 BP 神经网络的方法建立了神经网络模型"，最后对两种方法做系统性比较与误差分析。关键词栏同时列出"因子分析法""非线性回归""BP 神经网络模型"，但实际使用的非线性工具是 BP 网络〔原文〕。
   *要点*：示范了"先线性可解释模型、再非线性模型、最后两模型对照"的写法；但不可把它当作参数化非线性回归的实例。

5. **2012C：脑卒中发病环境因素分析及干预 (2)**〔原文〕——**仅相关**。
   论文在方法论部分给出线性与非线性的判定句："多元回归分析包括多元线性回归及多元非线性回归，判断方法主要通过绘制因变量与各个自变量之间的散点图……如果从散点图可以看出明显的线性关系，那么可以考虑通过多元线性回归进行分析；如果从散点图并不能发现明显的线性规律，可能是呈非线性，也可能是多个自变量之间的耦合关系的影响，需要进一步分析才能决定。"该篇正文出现"非线性回归"4 次，但最终落地的是逐步回归的线性形式（发病率与平均湿度直接线性相关，F 检验 $p=0.006$）。
   *要点*：可直接引用这段判定句，来论证本文为何选择线性或非线性形式。

6. **2005A：基于回归分析的长江水质预测与控制**〔原文〕——**仅相关**。
   论文"比较了 Logistic 模型、线性回归模型在预测长江水质发展趋势方面的优劣"，并对水质类别百分比序列"具有极强的共线性"的现象做定性讨论（发现污染类 II 与 III 走势"此消彼长""很像一只蝴蝶结"，合并后走势平稳，称之为"缓冲区"）。
   *要点*：**Logistic 与线性回归的并列比选**是"同一现象两种函数形式谁更合适"的标准论证写法；而它对类别比例共线性的识别提醒我们，非线性建模前必须先看变量间是否存在结构性约束（各类占比之和恒为 1）。
