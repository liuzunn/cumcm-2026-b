# 支持向量机

## 1. 模型用途

国赛中它有三种用法，第一种最容易写对，第二种最容易写砸：

- **小样本非线性判别**：样本几十到几千、维度高、边界不是直线时，靠最大间隔获得比逻辑回归更稳的泛化，适合"根据一组理化/影像指标判别样本类别"。
- **非参数回归（SVR）**：函数形式完全未知、又不能接受"多项式 + 最小二乘"强假设时使用。**2006B 是这条路线的国赛范本**：正态分布、多项式回归、支持向量机并列比优，SVM 平均相对误差 18.38%，线性回归 97.68%、$k$ 近邻 78.35%〔原文〕。
- **择优候选模型**：与灰色、回归、神经网络并列，用同一指标比优后选一个写进结论。

判据：**样本量不足以训练深度网络、线性模型又明显欠拟合时**，SVM 是首选折中；样本上万时不要用它。

## 2. 题目特征

适用信号：$n\in[50,10^{4}]$，$d$ 可与 $n$ 同量级甚至更大；指标已做或可做统一标准化；散点或降维图上两类样本有非线性但光滑的分界；题目强调"稳健""泛化能力"而不要求解析表达式。

警惕信号：$n>10^{5}$；要求输出概率并给置信区间；要求给出显式函数式并求导、解方程；噪声点与重叠类占比很高；量纲差异悬殊而无法标准化。

## 3. 数学原理

**来源。** Vapnik 等在统计学习理论基础上提出，核心是**结构风险最小化**：同时最小化经验风险与 VC 维相关的容量项。线性可分时取"分开两类且间隔最大"的超平面；不可分时引入松弛变量与惩罚系数 $C$；非线性时用核函数把样本映射到高维空间，在那里构造线性最大间隔分类器，核技巧使高维内积无需显式计算。回归版本（ε-SVR）把"分类正确"换成"落在宽度 $2\varepsilon$ 的管道内即不计损失"。

**成立前提与失效后果。**

**(1) 核函数须满足 Mercer 条件**（核矩阵半正定）。RBF、多项式、线性核均满足；自行拼凑的"相似度函数"若不满足，对偶问题不再是凸二次规划，可能无解或不稳定。

**(2) 特征必须同尺度。** RBF 核 $K=\exp(-\gamma\lVert x-x'\rVert^{2})$ 直接用欧氏距离度量相似性，若某变量量纲是另一个的 $10^{3}$ 倍，它会在核函数中独占权重。**前提不成立时**模型退化为"只按量纲最大的那个变量分类"，看似能跑，结论却无意义——这是 SVM 最高频的失效方式。

**(3) 样本 i.i.d. 且边界光滑、噪声有限。** 最大间隔对**标签噪声与离群点敏感**：一个错标样本可能成为支持向量并显著改变分界（$C$ 越大越严重）。时序或分组数据不满足 i.i.d.，随机交叉验证会高估性能。

**(4) 稀疏性的两面性。** 只有支持向量决定分界，这带来泛化优势，**但也意味着结论对个别样本高度敏感**。2006B 写道："尽管支持向量机对已有样本的效果不错，但由于 $f(\cdot)$ 本质上的不稳定，导致该算法不稳定。如果抛弃某一个样本点后重新计算支持向量机，并应用到被抛弃样本上，误差仍比较大"〔原文〕。这句话应被引为"必须做稳定性检验"的正当理由。

**(5) SVR 不产生显式表达式。** 预测值是核函数的加权和。2006B 明确指出"$C_i(t)$ 没有显式的表达式，终止时间的确定，即方程 $=0$ 无法解析求解"〔原文〕——**前提不成立（要求闭式）时只能改用数值求根**。

## 4. 基本公式

分类超平面与间隔：

$$w^{\mathrm T}x+b=0,\qquad \text{间隔}=\frac{2}{\lVert w\rVert}$$

硬间隔原始问题：

$$\min_{w,b}\ \frac{1}{2}\lVert w\rVert^{2}\quad \text{s.t.}\quad y_i\big(w^{\mathrm T}x_i+b\big)\ge 1,\ i=1,\dots,n$$

软间隔（松弛 $\xi_i$ 与惩罚 $C$）：

$$\min_{w,b,\xi}\ \frac{1}{2}\lVert w\rVert^{2}+C\sum_{i=1}^{n}\xi_i\quad \text{s.t.}\quad y_i\big(w^{\mathrm T}x_i+b\big)\ge 1-\xi_i,\ \xi_i\ge 0$$

对偶问题（$\alpha_i$ 为 Lagrange 乘子，仅支持向量处非零）：

$$\max_{\alpha}\ \sum_{i=1}^{n}\alpha_i-\frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n}\alpha_i\alpha_j y_i y_j K(x_i,x_j)\quad \text{s.t.}\ \sum_i\alpha_i y_i=0,\ 0\le\alpha_i\le C$$

决策函数与核：

$$f(x)=\mathrm{sgn}\Big(\sum_{i\in SV}\alpha_i y_i K(x_i,x)+b\Big),\qquad K_{\mathrm{RBF}}(x,x')=\exp\big(-\gamma\lVert x-x'\rVert^{2}\big),\ \gamma=\frac{1}{2\sigma^{2}}$$

ε-SVR（$\varepsilon$ 不敏感损失）：

$$\min_{w,b,\xi,\xi^{*}}\ \frac{1}{2}\lVert w\rVert^{2}+C\sum_{i=1}^{n}(\xi_i+\xi_i^{*})\quad \text{s.t.}\quad \begin{cases} y_i-w^{\mathrm T}\varphi(x_i)-b\le\varepsilon+\xi_i\\ w^{\mathrm T}\varphi(x_i)+b-y_i\le\varepsilon+\xi_i^{*}\\ \xi_i,\xi_i^{*}\ge0\end{cases}$$

回归预测：$f(x)=\sum_{i=1}^{n}(\alpha_i-\alpha_i^{*})K(x_i,x)+b$。2006B 用于比优的指标：

$$\text{平均相对误差}=\frac{1}{m}\sum_{j=1}^{m}\left|\frac{\hat y_j-y_j}{y_j}\right|\times100\%$$

## 5. 参数含义

| 符号 | 含义 | 取值建议 |
|---|---|---|
| $C$ | 惩罚系数，权衡间隔宽度与训练误差 | 越大越不容忍错分、越易过拟合；对数网格 $10^{-2}\sim10^{3}$ |
| $\gamma$ | RBF 核宽度参数，$\gamma=1/(2\sigma^{2})$ | 越大边界越崎岖；**必须与 $C$ 联合搜索**，单独调一个无效 |
| $\varepsilon$ | SVR 不敏感带宽度 | 决定支持向量比例；过大欠拟合，过小则几乎全部样本成为支持向量 |
| $K(\cdot,\cdot)$ | 核函数 | 小样本非线性首选 RBF；特征极多且近线性可分时用线性核 |
| degree, coef0 | 多项式核阶数与常数项 | 阶数取 2～3，更高阶数值不稳定 |
| $\alpha_i,\alpha_i^{*}$ | 对偶乘子 | 非零者对应的样本即支持向量 |
| class_weight / tol | 类别权重 / 停止容差 | 不平衡时按类频率倒数加权；tol 一般取 $10^{-3}$ |
| $\sigma$ | RBF 带宽 | 与 $\gamma$ 一一对应，论文中二者只出现一个 |

## 6. 建模步骤

1. 明确任务是分类（SVC）还是回归（SVR），两者的损失函数与评价指标完全不同。
2. **标准化**（z-score 或 min-max）。这一步不能省，并须在论文中写明所用方法与参数。
3. 划分数据（分类用分层抽样，时序用滚动窗口，不得随机切分），并先试线性核作基线、再试 RBF。
4. 联合网格搜索 $C$ 与 $\gamma$（回归再加 $\varepsilon$），以交叉验证误差为准，画出二维网格热图。
5. 用最优参数重训，并检查**支持向量占比**：接近 100% 说明 $\varepsilon$ 或 $C$ 设置不当，过低说明模型太简单。
6. 在独立测试集上报告误差，并做稳定性检验（重复随机划分或留一法，报告均值与标准差）——**2006B 的自我批评正是针对这一点〔原文〕**；最后与至少一个对照模型（线性回归、灰色、随机森林）比较并给出误差对比表。

## 7. 算法

1. 标准化特征，构造训练矩阵 $X$ 与标签 $y$。
2. 选定核函数与参数 $(C,\gamma,\varepsilon)$ 的搜索网格。
3. 对每组参数求解对偶凸二次规划——实际用 SMO：每次选两个乘子 $\alpha_i,\alpha_j$ 固定其余，解析求解二维子问题，迭代至 KKT 条件满足；由 KKT 条件识别支持向量（$\alpha_i>0$）并计算偏置 $b$。
4. 以交叉验证误差选最优参数，用全部训练数据重训一次，再在测试集上输出分类指标或回归误差。

**复杂度量级。** 核矩阵需 $O(n^{2})$ 内存；SMO 训练约 $O(n^{2}d)\sim O(n^{3})$；预测 $O(n_{SV}\cdot d)$，$n_{SV}$ 为支持向量个数。**$n$ 从 1000 增到 10000，训练耗时约增两个数量级以上**，这是 SVM 的第一硬约束。

## 8. Python实现思路

1. 用 sklearn.svm.SVC / SVR；**必须放进 Pipeline([('scaler',StandardScaler()),('svm',SVC())])**，否则标准化会被漏在交叉验证之外造成泄漏。
2. 参数搜索用 GridSearchCV，$C$ 与 $\gamma$ 同时取对数网格（如 $2^{-5}\sim2^{15}$），cv 用分层 K 折。
3. 特征数远大于样本数时设 kernel='linear' 或改用 LinearSVC，速度快得多。
4. probability=True 会内部做 Platt 校准的交叉验证，**慢且与 decision_function 结果不完全一致**；只需判别结果时不要打开。
5. 查看 support_vectors_、n_support_，把支持向量占比写进论文作为模型复杂度的证据。
6. 易错点：忘记标准化；只调 $C$ 不调 $\gamma$；用测试集选参；把 decision_function 的数值当概率解释。

## 9. MATLAB实现思路

1. 分类用 fitcsvm，回归用 fitrsvm；关键名值对：'KernelFunction'、'BoxConstraint'（即 $C$）、'KernelScale'（与 $\gamma$ 互为倒数关系，注意换算）、'Standardize',true。
2. **2006B 使用的 LibSVM 是国赛中真实出现过的工具**〔原文〕：其 MATLAB 接口为 svmtrain/svmpredict，参数串形如 '-s 3 -t 2 -c C -g gamma -p eps'，-s 3 表示 ε-SVR、-t 2 表示 RBF 核。
3. 自动调参用 'OptimizeHyperparameters','auto' 配合 'HyperparameterOptimizationOptions' 指定交叉验证。
4. 概率输出用 fitPosterior，但它同样是后处理校准，须在论文中说明。
5. 支持向量与决策函数可由 svInd、Beta、Bias 读出，预测用 predict。
6. 易错点：KernelScale 与 $\gamma$ 的定义方向容易搞反；不做标准化时 fitcsvm 表现会远逊于 Python 侧，别据此下"SVM 不行"的结论。

## 10. 优点

1. **小样本泛化能力强**：以结构风险最小化为目标，比经验风险最小化的方法更不易过拟合。
2. **高维友好**：$d>n$ 时仍可用，核技巧避免了显式高维映射的组合爆炸。
3. **凸优化、全局最优**，不存在神经网络那样的局部极小与随机初始化问题，**结果可复现**。
4. **解稀疏**：只有支持向量参与预测，存储与预测开销小；支持向量的位置本身有解释价值（最难分的样本）。

## 11. 缺点

1. **大样本不可用**：训练 $O(n^{2})\sim O(n^{3})$、内存 $O(n^{2})$，$n$ 上万即难以承受。
2. **对核函数与参数高度敏感**：$C$ 与 $\gamma$ 联合决定成败，网格搜索本身就是主要工作量。
3. **必须先标准化**，否则结论无效。
4. **无原生概率输出**，Platt 校准是外挂，校准后概率未必可靠。
5. **无显式表达式**：给不出可写进论文的函数式，求零点、求导、求极值都要靠数值方法（2006B 的明确痛点〔原文〕）。
6. **多分类需拆解**：原生二分类，多类靠 one-vs-one 或 one-vs-rest，类别多时训练次数呈平方增长；且对标签噪声与离群点敏感（2006B 已实证〔原文〕）。

## 12. 适用条件

当以下条件同时成立时适用：$50\le n\le 10^{4}$；特征已统一标准化；边界非线性但光滑，或响应函数形式未知；样本大致独立同分布；评价指标是误差或判别准确率而非概率区间或解析表达式；时间允许做 $C$-$\gamma$ 网格搜索。

## 13. 不适用情况

出现下列任一情况时不要用：

1. 当 $n>10^{5}$ 或特征稀疏高维时——改用线性 SVM、随机森林或梯度提升。
2. 当题目要求给出解析表达式并求导、解方程时——改用回归或灰色这类有闭式的模型。2006B 正栽在此处：拟合后方程无显式解，只能改用数值方式确定终止时间〔原文〕。
3. 当题目要求概率有良好校准（如风险定价）时——改用逻辑回归或经校准的集成模型。
4. 当样本未标准化或类别严重重叠、标签本身不可靠时——前者会让 RBF 核失效，后者会让最大间隔被离群点带偏。
5. 当需要外推时间趋势时——SVR 在训练域外同样趋于常数，改用 ARIMA 或灰色预测；当类别数很多（>20 类）且样本有限时——one-vs-one 拆解会显著抬高调参成本。

## 14. 常见错误

1. **不标准化。** 多指标国赛附件量纲差异常达两三个数量级，不标准化直接跑 RBF 核，模型会退化为只按量纲最大的变量分类，误差表看似正常而结论无意义。
2. **只报一次划分的结果，不做稳定性检验。** 2006B 自己就承认"如果抛弃某一个样本点后重新计算支持向量机，并应用到被抛弃样本上，误差仍比较大"〔原文〕。引用它时必须同时引用这句自我批评，并报告重复划分或留一法的误差均值与标准差，否则属选择性引用。
3. **静默剔除异常样本而不声明。** 2006B 在模型局限中写明"使用支持向量机建模时，没有用到有病情反复现象的数据"〔原文〕，这是可接受的写法（**明确声明 + 划出适用边界**）；不声不响地删掉不理想的数据点，结论外推即失效。
4. **用 SVM 拟合后忘记说明如何求零点。** 2006B 明确写道方程 $=0$ "无法解析求解"〔原文〕。遇到同类需求（最优停药时间、最优切换点）必须在论文中写明数值方法（网格扫描、二分法、黄金分割）及其步长与精度，否则结论链是断的。
5. **把 2023B B477 当成 SVM 案例。** 该文"支持向量"仅命中 1 次，是作为被淘汰的对照模型出现的——论文最终写"尝试了线性回归、支持向量机、随机森林等多种模型……最终发现随机森林模型与原数据拟合度可以达到 99% 以上"〔原文〕。**它是 SVM 输给随机森林的记录，不是成功案例。**
6. **分类 SVM 在国赛中缺少直接案例。** 语料中"支持向量机"与"SVM"共命中 5～6 个文件，唯一真实的国赛案例是 2006B 的**回归**用法〔归纳〕；**没有任何优秀论文把 SVC 用作分类主模型**。检索时还须剔除同词不同物的命中：2023A 的"判别式"指几何遮挡判别式，2007A/2002B 的"Logistic"指人口阻滞增长曲线与彩票评价函数〔原文〕。
7. **用默认参数、或把 decision_function 的值当概率。** $C$ 与 $\gamma$ 取默认值时性能可能低于线性回归，不调参就下"SVM 不行"的结论不成立；而 decision_function 只是到超平面的有符号距离，不构成概率。

## 15. 论文写法

**可直接套用的句式：**

1. 模型引入处：考虑到〔问题〕的样本量仅为〔n〕，且〔自变量〕与〔因变量〕之间的函数形式难以由机理导出，本文选取以结构风险最小化为准则的支持向量机模型，通过核函数 $K(x_i,x_j)=\exp(-\gamma\lVert x_i-x_j\rVert^{2})$ 将样本映射至高维特征空间并构造最大间隔超平面。
2. 参数确定处：本文以对数网格 $C\in\{2^{-5},\dots,2^{15}\}$、$\gamma\in\{2^{-15},\dots,2^{3}\}$ 联合搜索，以〔k〕折交叉验证的平均〔误差/准确率〕为准则，得最优参数 $(C^{*},\gamma^{*})=$〔值〕，搜索结果如图〔k〕所示。
3. 结果处：在〔比例〕%的独立测试集上，支持向量机的平均相对误差为〔18.38〕%，而线性回归为〔97.68〕%、$k$ 近邻为〔78.35〕%，说明〔响应变量〕与自变量之间确存在强非线性——**这一对比表可直接照 2006B 的表 1 形式组织**〔原文〕。
4. 稳定性与局限处：为检验结论稳健性，本文对训练集重复随机划分〔次数〕次，误差均值为〔值〕、标准差为〔值〕；由于支持向量机解不具有显式表达式，$f(t)=0$ 无法解析求解，本文采用〔二分法/网格扫描〕在区间〔a,b〕上求根、精度取〔值〕；且本文建模未使用〔某类异常样本〕，结论不适用于该情形。

## 16. 可创新方向

1. **把 SVR 当优化/机理模型的代理模型。** 机理计算昂贵或只能给离散数值解时，用 SVR 拟合光滑代理面再在其上优化；创新点写成"以代理模型替代单次昂贵仿真，优化迭代次数由〔值〕降至〔值〕"。
2. **定制核函数并做组合预测。** 变量含周期性时用周期核或周期核与 RBF 核的乘积，比通用 RBF 更贴合数据生成机制；再沿用国赛出现的"多模型并列 + 择优/加权"写法〔归纳〕，用交叉验证误差的倒数定权，报告组合后误差的下降量。

**案例 1（完全一致：SVR 作核心预测模型，国赛唯一强案例）**
论文：2006 年国赛 B 题优秀论文《艾滋病药物治疗的研究》（文件名片段：`2006B：艾滋病药物治疗的研究.pdf`）。
做法：针对问题一，"分别基于正态分布、多项式回归预测、支持向量机预测建立了三个模型"，并"使用开放源代码的 Matlab 工具包 LibSVM 来执行支持向量机算法"；论文表 1 给出三种方法的**平均相对误差：线性回归 97.68%、$k$ 近邻法 78.35%、支持向量机 18.38%**，作者解释为"它能够逼近任意连续函数的缘故"；5.1.2.5 节把样本分为训练与测试两部分，得测试集上的**平均相对偏差 30.7%**；最终用 SVM 拟合的 CD4 函数确定**最佳终止治疗时间**〔原文〕。
关系：**完全一致（SVR 变体）**。论文自述"支持向量机是新近出现的回归算法，从同名的分类算法修改而来"〔原文〕，即用 ε-SVR 而非 SVC；这是全库唯一可作为 SVM 主模型引用的国赛案例。
证据等级：〔原文〕。**引用时务必同时引用其两处局限声明**：其一"尽管支持向量机对已有样本的效果不错，但由于 $f(\cdot)$ 本质上的不稳定，导致该算法不稳定。如果抛弃某一个样本点后重新计算支持向量机，并应用到被抛弃样本上，误差仍比较大"；其二"$C_i(t)$ 没有显式的表达式，终止时间的确定，即方程 $=0$ 无法解析求解"，以及"使用支持向量机建模时，没有用到有病情反复现象的数据"〔原文〕。

**案例 2（仅相关：SVM 是被淘汰的对照模型）**
论文：2023 年国赛展示论文 B477（文件名片段：`2023年展示论文_B477.pdf`，多波束测深题）。
做法：论文写"为此，我们尝试了线性回归、支持向量机、随机森林等多种模型，并以拟合接近度 $R^2$ 进行评估，最终发现随机森林模型与原数据拟合度可以达到 99% 以上"，随后选择随机森林；全文中"支持向量"仅命中 1 次〔原文〕。
关系：**仅相关，且是负面记录**——它记录的是 SVM 在该任务上输给随机森林，不能表述为"SVM 用于多波束测深建模"。证据等级：〔原文〕。

**案例 3（归纳性线索）**
出处：编目笔记 N01《真题编目 1992—2010》方法—真题映射表，原文"神经网络 / 支持向量机 / 机器学习分类 → 2000 A；2004 D；2006 A；2006 B；2008 A；2008 B；2010 B"〔归纳〕。该表把 SVM 与神经网络并作一行，其中只有 2006 B 有正文证据（见案例 1），其余年份属推测性归属，**不能作为"某年用了 SVM"的证据**。证据等级：〔归纳〕。

**案例 4（分类 SVM 的直接案例）**
【资料中未找到直接案例，以下为〔推理〕】。全库"支持向量机"命中 5 个文件、"SVM"命中 6 个文件，其中真正实现支持向量机的国赛论文只有 2006B 一篇，且用的是**回归**版本〔归纳〕；**没有任何一篇优秀论文把支持向量分类机（SVC）作为分类主模型**（最接近的分类路线是 2000A 系列的判别分析：欧氏距离、马氏距离分类法与 Fisher 判别模型〔原文〕）。
〔推理〕使用建议：若须在分类题使用 SVM，建议把 SVC 与 Fisher 判别分析、$k$ 近邻并列，在同一份训练/测试划分下比较分类正确率（2000A 中浙江大学队对 182 个自然序列的分类正确率为 88%〔原文〕，可作参照量级），并说明类间是否近似正态同协方差，以论证 SVC 有理由优于 LDA。
