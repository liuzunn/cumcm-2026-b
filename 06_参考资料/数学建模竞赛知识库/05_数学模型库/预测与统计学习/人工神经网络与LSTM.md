# 人工神经网络与LSTM

## 1. 模型用途

国赛中它有三种用法，按"该不该用"排序：

- **非参数回归与评价（BP 网络）**：变量间非线性明确、机理又写不出来时用它拟合或综合评价。2010B 用"因子分析给权重 + BP 补非线性"，理由是"影响因素之间有一定的非线性，所以要求求解算法最好有一定的非线性映射能力"〔原文〕；2011A 用 3-N-1 的 BP 网络建立污染传播模型〔原文〕。
- **时间序列预测（LSTM）**：序列存在长期依赖、统计模型拟合不佳时使用。2023C C228 是范本：先试 ARIMA、岭回归、灰色预测"结果发现效果较差"，再改用 LSTM，六类品类进价预测 $R^2$ 达 0.62～0.96〔原文〕。
- **多模型并列之一**：2006B 把正态分布、多项式回归、支持向量机并列比优〔原文〕，网络也可放进这个候选池，但**必须给出同一指标下的对照表**。

判据：**样本量与序列长度够、关系非线性且机理不明、能接受黑箱时才用**；只有几十个点时优先灰色、回归或指数平滑。

## 2. 题目特征

适用信号：散点图明显弯曲、饱和或呈阈值型；机理式写不出，或写出来误差仍大（2011A 即因插值"没有考虑地形对重金属污染物传播的影响"而另建 BP 网络〔原文〕）；样本量 $10^{2}$ 以上，或序列长度不少于 3～5 个周期；题目不要求解析表达式。

警惕信号：样本量几十个以内；序列不足 50 点且趋势平稳（此时 ARIMA、灰色、指数平滑更稳且可解释）；题目要求显式函数式或因果解释；三天内没有调参与反复训练的时间预算。

## 3. 数学原理

**来源。** MP 神经元 → 感知机 → 多层前馈网络 + 误差反向传播（Rumelhart 等，1986）。BP 的本质是"复合函数链式求导 + 梯度下降"：前向算出预测，反向把误差逐层回传以调整权值和阈值。RNN 沿时间反向传播会导致梯度消失/爆炸；LSTM（Hochreiter & Schmidhuber, 1997）引入**细胞状态**与**三个门**，使梯度近似无损地沿"常数误差传送带"传播，从而捕捉长期依赖。

**成立前提与失效后果。**

**(1) 通用逼近定理的前提。** 定理保证紧集上足够宽的单隐层网络可任意精度逼近任意连续函数，**但它只说"存在"，不说"能被梯度下降学到"，也不说"泛化好"**。前提不成立时（样本不足、函数不连续、定义域无界）拟合能力无从兑现。

**(2) 样本量与参数量的匹配。** 参数量约为 $\sum n_i n_{i+1}$。2008B 给出可引用的国赛经验法则："在小样本的条件下，一般每个权重选 3～8 个训练样本"，并警告训练样本过多"容易出现'过拟和'问题"〔原文〕。**前提不成立时**网络会记住训练集。

**(3) 误差曲面的非凸性。** BP 是局部搜索，**对初始权重非常敏感**。2010B 原文："以不同的权重初始化网络，BP 算法会收敛于不同的局部极小。其次是它往往停滞于误差梯度曲面的平坦区，收敛缓慢甚至不能收敛"〔原文〕。不做多次随机初始化时结论不可复现。

**(4) LSTM 的长期依赖前提。** 门控机制的价值依赖序列中**确实存在长期依赖**。前提不成立时（序列短、只有趋势与季节、跳变主要来自外生冲击），LSTM 相对 ARIMA/灰色没有优势，参数量却更大。C228 之所以 LSTM 胜出，是因为数据"具有明显的周期性与趋势性"，且论文随后引入价格与人均收入做外生变量修正〔原文〕；把该结论搬到"单调递增的年度数据"上不成立。

## 4. 基本公式

前向传播（$L$ 层）：$a^{(l)}=f\big(W^{(l)}a^{(l-1)}+b^{(l)}\big)$，$a^{(0)}=x$，$\hat y=a^{(L)}$。

激活函数：$f_{\text{sig}}(z)=\dfrac{1}{1+e^{-z}}$，$\tanh(z)=\dfrac{e^{z}-e^{-z}}{e^{z}+e^{-z}}$，$\mathrm{ReLU}(z)=\max(0,z)$。

$$E=\frac{1}{2m}\sum_{j=1}^{m}(\hat y_j-y_j)^{2}\ (\text{回归}),\qquad E=-\frac{1}{m}\sum_{j=1}^{m}\big[y_j\ln\hat y_j+(1-y_j)\ln(1-\hat y_j)\big]\ (\text{二分类})$$

$$\delta^{(L)}=\nabla_{a}E\odot f'\big(z^{(L)}\big),\qquad \delta^{(l)}=\big(W^{(l+1)\mathrm T}\delta^{(l+1)}\big)\odot f'\big(z^{(l)}\big)$$

$$w_{ij}\leftarrow w_{ij}-\eta\frac{\partial E}{\partial w_{ij}},\qquad b_i\leftarrow b_i-\eta\frac{\partial E}{\partial b_i}$$

LSTM 门控与细胞状态（$[h_{t-1},x_t]$ 为拼接输入，$\odot$ 为逐元素乘）：

$$f_t=\sigma\big(W_f[h_{t-1},x_t]+b_f\big),\qquad i_t=\sigma\big(W_i[h_{t-1},x_t]+b_i\big)$$

$$\tilde C_t=\tanh\big(W_C[h_{t-1},x_t]+b_C\big),\qquad C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t$$

$$o_t=\sigma\big(W_o[h_{t-1},x_t]+b_o\big),\qquad h_t=o_t\odot\tanh(C_t)$$

归一化与评价：$x'=\dfrac{x-x_{\min}}{x_{\max}-x_{\min}}$，$R^{2}=1-\dfrac{\sum_i(y_i-\hat y_i)^{2}}{\sum_i(y_i-\bar y)^{2}}$。

## 5. 参数含义

| 参数 | 含义 | 取值建议 |
|---|---|---|
| 隐层数与节点数 | 网络容量 | 2011A 用 $l=\sqrt{n+m}+a$（$a\in[0,10]$）与 $l=\log_2 n$ 定范围再试凑，取 $N=100$〔原文〕 |
| $f(\cdot)$ | 激活函数 | 隐层 tanh/tansig、输出层线性（回归）；2011A 即此设置〔原文〕 |
| $\eta$ | 学习率 | 2011A 取 0.01〔原文〕；过大不收敛、过小收敛慢 |
| 迭代次数 | 训练轮数 | 2011A 设 300，实际第 222 次迭代达最小 MSE〔原文〕 |
| batch size | 批大小 | 小样本取 1～16 |
| 损失 / 优化器 | 优化目标与更新规则 | 回归用 MSE；传统 BP 用梯度下降，LSTM 常用 Adam |
| $T$（look_back） | LSTM 时间窗 | C228 用 input_shape=(1, look_back)〔原文〕 |
| 正则化 | L2 / dropout / 早停 | 抑制过拟合，早停需留验证集 |
| 样本分配 | 训练/验证/检验 | 2008B 因数据缺失最终训练 20 个、检验 7 个〔原文〕 |

## 6. 建模步骤

1. 明确任务（回归、分类或序列预测），据此定输出层激活函数与损失函数。
2. 预处理：缺失值处理、归一化到 [0,1] 或标准化，并记录参数以便反归一化（2011A 写明网络"还只能输出归一化后的浓度数据，为了得到真实的数据"需反归一化〔原文〕）
3. 划分训练/验证/检验三份；**时序数据严禁随机打乱**，按时间顺序切分或用滚动窗口。
4. 定结构：先按经验公式定隐层节点范围再试凑（2011A 的做法〔原文〕）；2008B 用 SCG 与 COB 两种算法在 MATLAB 中定最佳隐层节点数〔原文〕。
5. 训练：固定随机种子，多次不同初始化重复训练，记录各次收敛误差；用验证集早停并比较训练误差与验证误差的分离程度。
6. 反归一化并在独立检验集上报告指标，与至少一个对照模型（回归、灰色、ARIMA）比较。
7. 稳健性检验：对输入加微小扰动观察输出波动（C228 的做法〔原文〕），并报告多次训练的指标均值与标准差。

## 7. 算法

1. 随机初始化权值 $W^{(l)}$ 与阈值 $b^{(l)}$（小随机数或 Xavier）。
2. 前向传播：逐层算 $z^{(l)}=W^{(l)}a^{(l-1)}+b^{(l)}$、$a^{(l)}=f(z^{(l)})$，得预测 $\hat y$。
3. 计算输出层误差 $E$ 与误差项 $\delta^{(L)}$。
4. 反向传播：按 $\delta^{(l)}=(W^{(l+1)\mathrm T}\delta^{(l+1)})\odot f'(z^{(l)})$ 逐层回传。
5. 更新参数 $w\leftarrow w-\eta\,\partial E/\partial w$（LSTM 改用 Adam 等自适应方法按门控方程组回传）。
6. 重复 2～5 至迭代上限或验证误差不再下降（早停），取验证误差最小的权值。

**复杂度量级。** 单次前向 $O(\sum_l n_l n_{l+1})$；一次 epoch 为 $O(N\sum_l n_l n_{l+1})$，总代价 = 迭代次数 × 单次代价。LSTM 单时间步约 $O(4h(d+h))$（$h$ 隐单元数、$d$ 输入维数），长度 $T$ 的序列为 $O(T\,h(d+h))$，且时间维不能并行。

## 8. Python实现思路

1. 小规模可用 sklearn 的 MLPRegressor / MLPClassifier（参数少、可进 Pipeline）；时序与深层网络用 PyTorch 或 Keras。
2. Keras 搭 LSTM 骨架：Sequential → LSTM(units, input_shape=(look_back, n_features)) → Dense。C228 用的就是 model.add(LSTM(6, input_shape=(1, look_back))) 加一个全连接层〔原文〕。
3. **归一化只在训练集上 fit**，再 transform 验证/测试集，最后 inverse_transform 还原量纲；在全量数据上 fit 会造成时序泄漏。
4. 时序数据不要 shuffle；划分用前段训练、后段测试，或用 TimeSeriesSplit 滚动窗口。
5. 稳定性：固定 random seed，跑 5～10 次并报告指标均值±标准差，而不是只报最好的一次。
6. 早停与正则化：显式验证集 + EarlyStopping(patience)，必要时加 Dropout 或 L2。
7. 易错点：忘记反归一化导致量纲错位；batch_size 设得远大于样本数；只在一个随机种子上调参。

## 9. MATLAB实现思路

1. 浅层 BP 用 feedforwardnet(hiddenSizes) 或 fitnet；trainFcn 可选 'trainlm'、'trainscg'（2008B 用过的量化共轭梯度）、'traingd'；train(net,X,T) 训练，net(X) 预测。
2. **2008B 即用 MATLAB 以 SCG 与 COB 两种算法定隐层节点数**〔原文〕，可作方法引用。
3. 数据划分用 net.divideParam 设 trainRatio/valRatio/testRatio（如 0.7/0.15/0.15）；数据缺失时可改为手动指定训练与检验集（2008B 即如此〔原文〕）。
4. 归一化用 mapminmax，训练与检验必须用同一套映射参数。
5. 训练自带的性能图可直接作为"训练误差随迭代步数下降"图；2011A 即报告"训练在第 222 次迭代过程达到均方误差最小，MSE=0.00044917"〔原文〕。
6. LSTM 需 Deep Learning Toolbox：sequenceInputLayer → lstmLayer → fullyConnectedLayer → regressionLayer，配 trainingOptions('adam',...)。易错点：未设 rng 种子会使每次结果不同；数据未转成序列格式（cell 数组）会直接报错。

## 10. 优点

1. **通用逼近能力**：无需事先指定函数形式，并自动学习交互与非线性；多输入多输出天然支持。
2. **LSTM 擅长长期依赖与变长序列**，门控机制缓解梯度消失，训练比朴素 RNN 稳定（C228 列举了这三条优点〔原文〕）。
3. **可避开人工定权**：2010B 指出 BP 评价"避开了权数确定问题……不需要计算衡量权数"〔原文〕。

## 11. 缺点

1. **黑箱**：给不出可解释的参数含义与解析表达式，难以承载因果解释。
2. **需要足够样本**，小样本极易过拟合（2008B 的明确警告〔原文〕）。
3. **易陷局部极小、对初始权值敏感**：2010B 原文"以不同的权重初始化网络，BP 算法会收敛于不同的局部极小""往往停滞于误差梯度曲面的平坦区，收敛缓慢甚至不能收敛"〔原文〕。
4. **超参数多**，调参成本远高于 SVM；不固定种子时结果不可复现。
5. **外推能力差**；LSTM 计算与调参成本高，在小样本短序列上常不如 ARIMA 或灰色预测——这一点常被论文忽略。

## 12. 适用条件

当以下条件同时成立时适用：样本量满足 2008B 的经验法则（每个权重大致对应 3～8 个以上训练样本）〔原文〕；非线性明确且机理式无法导出；用 LSTM 时序列长度不少于 3～5 个完整周期；题目不要求解析表达式与因果解释；时间预算允许多次随机初始化与调参；已备好一个可解释的对照模型用于比优。

## 13. 不适用情况

出现下列任一情况时不要用：

1. 当样本量只有几十个、自变量不到十个时——改用回归、灰色 GM(1,1) 或指数平滑。
2. 当序列只有单调趋势、没有长期依赖时——LSTM 无优势。C228 中 ARIMA 失效的原因是数据"具有明显的周期性与趋势性"且受促销及外生变量冲击〔原文〕，**不能推广为"ARIMA 普遍不如 LSTM"**。
3. 当题目要求显式表达式、参数含义或因果解释时；当需要外推远超样本范围的未来值时。
4. 当三天赛期内无法完成调参与多次重复训练时。

## 14. 常见错误

1. **把 2015A 里的"LSTM"当成神经网络。** 2015A《太阳影子定位 (4)》中反复出现 `LSTM = 15.*dGMT`，这里的 LSTM 是 **Local Standard Time Meridian（地方标准时经度）**，属太阳时角公式，与长短期记忆网络毫无关系〔原文〕。全库"LSTM"共命中 10 个文件，真正涉及神经网络时序预测的**只有 2023C C228 一篇**〔归纳〕。
2. **数据量不够就上 LSTM 或注意力机制。** 赛前提示词常"不问数据量就默认推荐随机森林+XGBoost 集成、LSTM 时序预测+注意力机制"〔归纳〕，而同一批材料的讲义写着"不要盲目上深度学习：数据量和可解释性要匹配"〔原文〕。参数量超过样本支撑规模时，$R^2$ 可以很高而外推完全失效。
3. **写"ARIMA 效果较差所以改用 LSTM"却不给对照误差。** C228 的真实写法是"首先采用 ARIMA、岭回归、灰色预测模型等统计时间序列模型进行预测，结果发现效果较差。因此本文采用 LSTM"〔原文〕——照抄时务必补上与 LSTM 同指标的对照表，否则"效果较差"无法核验。
4. **不做归一化，或不做反归一化。** 2011A 写明网络"还只能输出归一化后的浓度数据，为了得到真实的数据"还需反归一化〔原文〕；漏掉这一步会让预测值量纲完全错位。
5. **只报一次随机种子的结果。** 2010B 已指出 BP"对初始权重非常敏感……会收敛于不同的局部极小"〔原文〕；应跑 5～10 次不同初始化并报告指标均值与标准差。
6. **只报 $R^2$ 不看量纲。** C228 论述了指标选择理由："均方误差、均方根误差、平均绝对误差的范围与数据本身大小密切相关无法直观的了解模型的效果，因此本文主要考虑 R 方"〔原文〕。主指标选 $R^2$ 合理，但仍应给出 MSE/RMSE/MAE 的数值。

## 15. 论文写法

**可直接套用的句式：**

1. 模型引入处：由于〔若干影响因素〕与〔响应变量〕之间存在明显的非线性关系，且其作用机理难以由解析式刻画，本文建立〔3-N-1〕结构的 BP 神经网络模型，隐层采用双曲正切 S 形传递函数、输出层采用线性传递函数，以误差反向传播算法调整权值与阈值，使网络预测输出不断逼近期望输出。
2. 结构确定处：隐层节点数过少会导致学习不足、过多则易过拟合。本文按 $l=\sqrt{n+m}+a$（$a\in[0,10]$）与 $l=\log_2 n$ 定取值范围，再以试凑法比较不同节点数下的验证误差，最终取 $N=$〔值〕；学习速率取〔0.01〕，训练次数取〔300〕。
3. 结果处：网络在第〔222〕次迭代达到最小均方误差 MSE=〔0.00044917〕；独立检验集上 $R^2$ 为〔值〕、平均绝对百分比误差为〔值〕。作为对照，〔ARIMA/灰色/回归〕的 $R^2$ 为〔值〕，说明〔响应变量〕的长期依赖需由门控循环网络刻画。
4. 稳健性与局限处：本文对输入序列施加均值为零的正态微小扰动并重复输出，预测波动幅度在〔5〕% 以内；且网络对初始权值敏感，本文通过〔次数〕次不同初始化的重复训练报告了指标均值与标准差。

**配图清单：** 网络结构示意图（2011A 的图 3 即此类）；训练误差随迭代步数下降曲线（2011A 报告第 222 次迭代达最小 MSE）；预测值 vs 实测值对比图（含 45° 参考线）；预测误差/残差图；多次运行结果的箱线图；LSTM 的扰动鲁棒性图（C228 的图 20）；由权值矩阵经均值滤波得到的"影响程度系数表"（2008B 的做法）。

## 16. 可创新方向

1. **机理模型 + 网络残差补偿（最推荐）。** 2011A 的思路即此：插值未考虑地形影响，于是另建 BP 网络学习"地形 → 污染物浓度"的映射〔原文〕。把机理主项与网络补偿项分开写，创新点落在"网络只学机理未覆盖的部分"，并报告补偿前后的误差下降百分比。
2. **引入外生变量改造时序预测。** 照 C228 的做法：先用 LSTM 拟合序列，再引入价格、人均收入等外生变量，用双对数需求模型修正预测值〔原文〕。

3. **打开黑箱：权值到影响系数的转换。** 2008B 用"反序归一权值法"与"均值滤波"把权值矩阵转成六因素的**影响程度系数矩阵**并得出排序〔原文〕，成本低、效果好。

做法：以 **30 所"211 工程"高校**为样本、6 个影响因素；因数据缺失，"用于网络训练的样本有 20 个，检验样本共有 7 个"；隐层节点数用 **SCG 与 COB 两种算法在 MATLAB 中确定**；写明"小样本条件下，一般每个权重选 3～8 个训练样本"并警告训练样本过多"容易出现'过拟和'问题"；最后用"反序归一权值法"与"均值滤波"把权值矩阵转成**影响程度系数矩阵**，排序为**生均教育成本（1.2830）居首、国家财政投入（0.2408）居末**〔原文〕。
关系：**完全一致**，是全库唯一以 BP 网络为标题主模型且正文完整可引的国赛优秀论文。证据等级：〔原文〕。

**案例 2（完全一致：BP 网络作非线性评价模型）**
论文：2010 年国赛 B 题优秀论文《对上海世博会文化影响力的定量评估》（文件名片段：`2010B：对上海世博会文化影响力的定量评估.pdf`）。
做法：先用**因子分析**给权重，再用 **BP 神经网络**补非线性，理由是"影响因素之间有一定的非线性，所以要求求解算法最好有一定的非线性映射能力"；借 **DPS 软件**工具箱解算，残差分析称"拟合的近似程度很高"；缺点分析写明"往往停滞于误差梯度曲面的平坦区，收敛缓慢甚至不能收敛"〔原文〕。
关系：**完全一致**，与第 15 节句式 1 的论证链条互证。证据等级：〔原文〕。

**案例 3（完全一致：BP 网络用于机理之外的残差建模）**
论文：2011 年国赛 A 题优秀论文《城市表层土壤重金属污染分析（1）》（文件名片段：`2011A：城市表层土壤重金属污染分析（1）.pdf`）。
做法：指出插值"并没有考虑地形对重金属污染物传播的影响"，因而"建立 **3—N—1 的 BP 网络结构**"，输入 $(x,y,z)$、输出重金属浓度；隐层双曲正切 S 形函数、输出层线性；试凑取 **$N=100$**，学习速度 **0.01**、训练 **300** 次；报告"训练在第 **222** 次迭代过程达到均方误差最小，**MSE=0.00044917**"〔原文〕。
关系：**完全一致**，是第 16 节方向 1"机理 + 网络残差补偿"的国赛原始范例。证据等级：〔原文〕。

**案例 4（完全一致：LSTM 时序预测，国赛唯一强案例）**
论文：2023 年国赛 C 题展示论文 C228（文件名片段：`2023年展示论文_C228.pdf`，蔬菜类商品的自动定价与补货决策）。
做法：先试统计模型——"首先采用 ARIMA、岭回归、灰色预测模型等统计时间序列模型进行预测，结果发现效果较差。因此本文采用 LSTM 长短时记忆网络模型进行预测"；参数为**单层 LSTM 单元数 6、全连接层 7、损失 MSE、优化器 Adam、迭代 400、批量 1**；六类品类进价预测的 **$R^2$ 分别为 0.88、0.91、0.73、0.91、0.96、0.62**；加正态微小扰动后输出"波动幅度在 5% 以内"；随后"引入定价作为外生变量"并结合双对数需求模型修正销量〔原文〕。
关系：**完全一致**，是全库 LSTM 作时序预测主模型的唯一样本，其"统计模型失效 → LSTM 接管 → 鲁棒性检验 → 外生变量修正"链条可直接作写作模板。证据等级：〔原文〕。

**案例 5（反面提醒：关键词误伤）**
论文：2015 年国赛 A 题《太阳影子定位 (4)》（文件名片段：`2015A：太阳影子定位 (4).pdf`）。
做法：文中反复出现 `LSTM = 15.*dGMT`，其 LSTM 是 **Local Standard Time Meridian（地方标准时经度）**，属太阳时角公式，与神经网络无关〔原文〕。
关系：**关键词误伤的反面案例**，用于校准检索口径——全库"LSTM"的 10 个命中文件中真正涉及神经网络的只有 C228 一篇〔归纳〕。证据等级：〔原文〕。
