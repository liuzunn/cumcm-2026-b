# 层次聚类与DBSCAN

## 1. 模型用途

两者是 K-means 在**簇数与簇形状无法预先假定**时的替代方案，各有专属地盘：

- **层次聚类**回答"分成几级最合适"。它输出一棵**树状图**，可在不同高度切出任意层数的划分，特别适合题面本身是"分级/分档/分层"且层次有业务含义的场合。2012A(4) 用系统聚类的树状图把酿酒葡萄分成 8 类并归并为 A/B/C/D 四个等级〔原文〕。
- **DBSCAN** 回答"哪些点该抱团、哪些是噪声"。它按密度聚类，**不需要预设簇数**，能发现任意形状的簇，并**同时标出噪声点**。2017B 的任务打包正是它的主场：任务点分布不均匀，作者据此弃用 K-means 改用改进 DBSCAN〔原文〕。
- **有序样本聚类（Fisher 最优分割）** 是层次聚类在**有序**对象（时段、桩号、批次）上的专用形式，2001B 用它划分公交客流时段〔原文〕。

## 2. 题目特征

1. **对象数中等**：几十到几千。层次聚类的 `O(n^2)` 内存使它在十万级数据上不可行；DBSCAN 配空间索引可达 `O(n\log n)`，稍好。
2. **类数不确定**：题面只说"合理划分/分级"而不给类数——这正是树状图切割与 DBSCAN 自动定簇数的用武之地。
3. **样本含噪声或离群点**：题面出现"异常数据/离群/噪声/不可信记录"。2023C C235 原文"考虑到该数据异常数据多等特点，使用 CURE 层次聚类的方法对 31 种单品进行划分"，并说明收缩因子"可以减少噪音对聚类的影响"〔原文〕。
4. **对象是空间点且分布不均匀**：DBSCAN 的典型信号。2017B 原文"以上的聚类方法一般只适用于凸样本集的聚类。不适合本文任务点分布情况"〔原文〕。
5. **对象天然有序**（时段、桩号、批次）：应优先用有序样本聚类，普通层次聚类会浪费顺序信息、把相邻段切碎。

## 3. 数学原理

### 3.1 层次聚类

**凝聚式（AGNES）**从 `n` 个自成一类的样本出发，每步合并最相似的两类直到并成一类（分裂式 DIANA 反向）。它是**贪心**算法，早期合并不可撤销，除单链外多数准则不保证全局最优。核心在于类间距离的定义：**单链**（最短距离）能发现长条、弯曲等非凸簇，但有**链式效应**——一条稀疏的样本桥会把本应分开的两簇连起来；**全链**（最长距离）抗噪更稳健但倾向紧凑球状簇；**平均链（UPGMA）**取所有跨类点对距离的平均，介于两者之间；**Ward 法**每次合并使簇内平方和（ESS）增量最小，**在欧氏距离下它是 K-means 目标的层次化版本**，前提与 K-means 同源（欧氏距离 + 各维等方差 + 偏好球状等大簇）——**前提不成立时**（量纲未统一、簇为长条），Ward 会给出与 K-means 同样错误的结论。

成立前提只有两条：① 相异度矩阵能反映"相似"的业务含义；② 树状图切割高度可对应业务分级阈值。它**不需要**凸性或等方差假设，但也因此**没有统计模型支撑**，"切几类"完全靠人为判断。

### 3.2 DBSCAN

DBSCAN 把簇定义为**由密度可达关系导出的最大密度相连样本集合**——这正是 2017B 原文的表述〔原文〕。参数只有半径 `\varepsilon` 与最小点数 `MinPts`：若 `|N_\varepsilon(p)|\ge MinPts` 则 `p` 为核心点；落在某核心点邻域内的非核心点为边界点；两者都不是则为噪声。**成立前提**是存在一个**全局** `\varepsilon` 使"簇内密度 ≥ 阈值 > 簇间密度"。**前提不成立时**（如市中心与郊区任务点密度悬殊），要么把稀疏簇整片判为噪声，要么把两个高密簇连成一个——此时应改用 OPTICS 或 HDBSCAN。`\varepsilon` 常由 **k-距离曲线拐点**标定（取 `k=MinPts`，把每点到第 `k` 近邻的距离排序作图）。

### 3.3 CURE

CURE 用**多个代表点**而非单个质心代表一类，并把代表点向类中心**收缩**，在保持非球形识别能力的同时降低离群点影响。2023C C235 用此路线处理"异常数据多"的单品序列〔原文〕，细节见 §17。

## 4. 基本公式

**类间距离的 Lance–Williams 统一递推**

$$d(C_k,\,C_i\cup C_j)=\alpha_i d(C_k,C_i)+\alpha_j d(C_k,C_j)+\beta\, d(C_i,C_j)+\gamma\,\bigl|d(C_k,C_i)-d(C_k,C_j)\bigr|$$

系数决定准则：单链 `\alpha_i=\alpha_j=\tfrac12,\beta=0,\gamma=-\tfrac12`；全链 `\gamma=\tfrac12`；平均链 `\alpha_i=\tfrac{n_i}{n_i+n_j},\ \alpha_j=\tfrac{n_j}{n_i+n_j},\ \beta=\gamma=0`。

**Ward 法合并准则（ESS 增量）**

$$\Delta ESS(C_i,C_j)=\frac{n_i n_j}{n_i+n_j}\,\|\bar x_i-\bar x_j\|^2$$

**DBSCAN 的邻域与核心点**

$$N_\varepsilon(p)=\{q\in D\mid \mathrm{dist}(p,q)\le\varepsilon\},\qquad p\ \text{为核心点}\iff |N_\varepsilon(p)|\ge MinPts$$

**CURE 代表点收缩**（符号与 C235 原文一致）〔原文〕

$$p'=p+\alpha\,(w_{mean}-p)$$

**评价指标**

$$\bar s=\frac{1}{n}\sum_i\frac{b(i)-a(i)}{\max\{a(i),b(i)\}},\qquad ARI=\frac{\text{一致点对数}-\text{期望值}}{\text{最大可能值}-\text{期望值}}$$

**同表型相关系数**：树状图导出的同表型距离与实际相异度的相关系数，用于比较不同链接准则的保真度。

## 5. 参数含义

| 符号 | 含义 | 取值/注意 |
|---|---|---|
| `n`、`p` | 样本数、维数 | 层次聚类要求 `n` 不过大（`O(n^2)` 内存） |
| `linkage` | 链接准则 | `ward`/`average`/`complete`/`single`；论文必须声明 |
| `metric` | 相异度 | 欧氏、明考斯基、切比雪夫、曼哈顿；**Ward 只能用欧氏** |
| `h` 或 `K` | 树状图切割高度 / 类数 | `h` 由最大间隙或轮廓系数确定 |
| `\varepsilon` | DBSCAN 邻域半径 | 最敏感的参数，由 k-距离曲线拐点确定 |
| `MinPts` | 核心点最小邻域点数 | 经验 `MinPts\ge p+1`，二维点常用 4–10；越大越抗噪、簇越少 |
| `\alpha` | CURE 收缩因子 | `\alpha\to1` 趋近质心法，`\alpha\to0` 趋近代表点法 |
| `\bar s`、`ARI` | 轮廓系数、调整兰德指数 | `ARI` 用于度量两次划分的一致性（稳健性检验） |

## 6. 建模步骤

1. **定对象与相异度**：选指标 → 标准化 → 选距离度量并说明理由。2012A(4) 列明"明考斯基距离""切比雪夫距离"，并强调"当各变量的测量值相差悬殊时……需先将数据标准化"〔原文〕。
2. **（可选）降维**：用 PCA/因子分析去掉冗余维度，避免同一"话题"被重复加权。
3. **层次聚类路线**：算相异度矩阵 → 选链接准则 → 画树状图 → 按最大间隙/轮廓系数/业务阈值定切割高度 → 得类别 → 检验同表型相关系数。
4. **DBSCAN 路线**：画 **k-距离曲线**定 `\varepsilon` → 试 2–3 组 `(\varepsilon,MinPts)` → 检查噪声比例与簇数是否合理 → 若簇数多于业务需要，再对簇心做一次层次聚类归并。
5. **类别命名与业务解释**：与 K-means 同一要求，给出每类特征画像。
6. **稳健性检验**：换链接准则、换 `\varepsilon(\pm10\%)`，用 ARI 量化类别是否稳定。

## 7. 算法

**凝聚层次聚类**：① 算 `n\times n` 相异度矩阵 `D`；② 每样本自成一类；③ 合并 `D` 中距离最小的两类；④ 用 Lance–Williams 递推更新新类到其余类的距离；⑤ 重复 ③–④ 共 `n-1` 次并记录合并高度，形成树状图；⑥ 在选定高度切树得最终划分。

**复杂度**：朴素实现 `O(n^3)`；用优先队列/最近邻链可降至 `O(n^2\log n)`；存储恒为 `O(n^2)`，这是内存瓶颈（`n=10^4` 即约 `10^8` 个距离值，不宜直接上层次聚类）。

**DBSCAN**：① 取未访问点 `p` 求 `N_\varepsilon(p)`；② 若 `|N_\varepsilon(p)|<MinPts` 暂标噪声（后续可能被划为边界点）；③ 否则新建簇并把 `N_\varepsilon(p)` 入队，对队中每点 `q`，若 `q` 为核心点则把 `N_\varepsilon(q)` 并入队列，直到队列空；④ 重复 ①–③ 直到全部点被访问；⑤ 输出各簇与噪声集合。

**复杂度**：无索引 `O(n^2)`；配 kd-tree/ball-tree 平均 `O(n\log n)`，最坏仍 `O(n^2)`，空间 `O(n)`。CURE 在随机采样 `s` 个点后为 `O(s^2\log s)`，故能处理较大数据。

## 8. Python实现思路

- 层次聚类：`scipy.cluster.hierarchy.linkage(X, method='ward'|'average'|'complete'|'single')` → `dendrogram(Z)` → `fcluster(Z, t=h, criterion='distance')`；`cophenet(Z, pdist(X))` 算同表型相关系数。
- 或 `sklearn.cluster.AgglomerativeClustering(n_clusters=None, distance_threshold=h, linkage='ward')`，注意 `ward` 只接受欧氏距离。
- DBSCAN：`sklearn.cluster.DBSCAN(eps=eps, min_samples=MinPts).fit(X)`，标签 `-1` 即噪声；用 `NearestNeighbors(n_neighbors=k).kneighbors(X)` 取第 `k` 列排序画 **k-距离曲线**定 `eps`。
- 变密度数据改用 `sklearn.cluster.OPTICS` 或第三方 `hdbscan`。
- **易错点**：① 忘标准化；② `ward` 配非欧氏距离会静默给错结果；③ `fcluster` 的 `criterion='maxclust'` 与 `'distance'` 含义不同，混用会得到完全不同的划分；④ `DBSCAN` 在大 `n` 且无索引时极慢；⑤ 把噪声标签 `-1` 当成一个类来解释。

## 9. MATLAB实现思路

- 层次聚类：`Z = linkage(X, 'ward', 'euclidean')` 或 `linkage(pdist(X), 'average')`；`dendrogram(Z)` 画树；`T = cluster(Z, 'maxclust', K)` 或 `cluster(Z, 'cutoff', h)`；`cophenet(Z, pdist(X))` 给同表型相关。
- DBSCAN：R2019a 起 Statistics and Machine Learning Toolbox 提供 `dbscan(X, epsilon, minpts)`；更早版本需自行实现核心点判定与队列扩展。
- 选类数：`evalclusters(X, 'linkage', 'Silhouette', 'KList', 2:10)`。
- 可视化：`dendrogram(Z, 'ColorThreshold', h)` 直接标出切割线；`gscatter` 按类着色散点。
- **易错点**：① `linkage` 若传入 `pdist(X,'cityblock')` 必须同步指定对应方法；② `cluster` 的 `'cutoff'` 是树高、`'maxclust'` 是类数；③ 未标准化直接 `linkage(X)` 会让大数量级指标主导。

## 10. 优点

- **不需要预设簇数**：树状图一次给出全部层级的划分，可回答"分成 2–6 类分别是什么"，天然支持类数敏感性分析。
- **DBSCAN 能发现任意形状的簇并显式识别噪声**。2017B 原文"它最大的优势是可以发现任意形状的聚类簇，同时过滤噪声信号，对于本题数据分布有较好表现"〔原文〕。
- **层次聚类结果可解释性强**：树状图本身就是可入文的图，层级结构与业务分级（A/B/C/D 四档）天然契合〔2012A(4) 原文〕。
- **DBSCAN 参数少、无随机初始化**，结果可复现；CURE 通过代表点 + 收缩因子进一步增强抗噪性〔C235 原文〕。

## 11. 缺点

- **层次聚类复杂度高**：`O(n^2)` 时间与内存，样本上千即吃力。
- **合并不可撤销**（贪心），不同链接准则给出不同答案，缺少"哪个对"的客观判据。
- **DBSCAN 对参数极敏感**：`\varepsilon` 稍变，簇数与噪声比例可能剧烈变化；且要求**全局统一密度**。
- **DBSCAN 在高维失效**：维数升高后密度概念退化，`\varepsilon` 几乎无法标定。
- **无统计显著性检验**，划分优劣依赖轮廓系数、同表型相关等几何指标；**DBSCAN 的簇也没有原型**，解释时需另算类中心与类内均值。

## 12. 适用条件

用**层次聚类**：当 ① `n\le 2000`；② 相异度矩阵能由标准化 + 合理度量构造；③ 题目本身是"分级/分档/分层"且层次有业务意义；④ 不确定类数、需要一次给出多个层级的方案。

用 **DBSCAN**：当 ① 对象是空间点或可用距离刻画；② 数据含噪声且需要显式标出；③ 各簇密度大致可比（同一量级）；④ 维度不高（`p\lesssim 10`，最好先降维）；⑤ 簇明显非凸或大小悬殊致 K-means 不可用。

用**有序样本聚类**：当对象天然有序（时间、桩号、批次），且要求分段连续。

## 13. 不适用情况

1. **当样本量上万时不要用层次聚类**——`O(n^2)` 内存先崩；改用 K-means，或先 K-means 粗分再在类内做层次聚类。
2. **当各簇密度差异很大时不要用 DBSCAN**——如市中心与郊区任务点并存，任何单一 `\varepsilon` 都会失败；应改 OPTICS/HDBSCAN，或分区域各自设 `\varepsilon`。
3. **当维度 `p\gg 10` 且未降维时不要用 DBSCAN**——密度不可辨别，参数无法标定。
4. **当指标主要是类别型变量时不要直接套用**——距离无法自然定义，需先做 Gower 距离或对应分析。
5. **当需要每个样本的隶属概率时**——两者都是硬划分，应改 GMM 或模糊 C 均值。
6. **当题面已明确给出类数且簇近似球状时**——K-means 更快更简单，没有理由上层次聚类。
7. **当对象有序却用无序聚类时**——会把相邻时段切碎再拼起来，破坏顺序结构（2001B 正是靠有序样本聚类才保证时段连续〔原文〕）。

## 14. 常见错误

1. **把"K-means 和层次聚类只适用于凸样本集"当普适结论**。2017B(5) 原话是"K-means 聚类、层次聚类等，以上的聚类方法一般只适用于凸样本集的聚类"〔原文〕，它针对的是当时所用的**基于质心的链接准则**；严格说**单链层次聚类可以发现非凸簇**（代价是链式效应）。引用时必须写明链接准则，否则会被判为概念错误。
2. **不标准化就构造相异度矩阵**。距离型算法的通病，但在这两种方法上更致命：前者会污染整棵树状图，后者会让"密度"的定义彻底离谱。2012A(4) 专门强调"当各变量的测量值相差悬殊时……需先将数据标准化，然后用标准化后的数据进行计算"〔原文〕。
3. **只贴树状图不报切割依据**。树状图能切 2 类也能切 10 类，必须给出切割高度或类数的判据（最大间隙、轮廓系数峰值、业务阈值），否则"分成 4 类"纯属主观。
4. **DBSCAN 的 `\varepsilon` 凭手感取**，不画 k-距离曲线也不做参数敏感性分析。参照 2017B 的做法：该文对 LOF 参数做了波动分析并报告"我们取的 `k` 值为 3，实际上当 `k` 超过 5 之后，LOF 因子就基本不变""当参数波动为 +5.0% 时……"〔原文〕——参数敏感性表是这类算法的必备附件。
5. **把 DBSCAN 的噪声标签 `-1` 当成一个类来解释**。噪声点不是一类，而是"密度不足以归入任何簇"的个体，应单独讨论其成因（录入错误、真实异类，还是特殊业务对象）。

## 15. 论文写法

**可直接套用的句式**：

- "为刻画 `\{研究对象\}` 的层级结构，本文对标准化后的指标矩阵计算 `\{欧氏/切比雪夫\}` 距离，采用 `\{Ward/平均链\}` 系统聚类得到聚类树（图 `\{n\}`）；在高度 `h=\{数值\}` 处切割得到 `\{K\}` 类，此时同表型相关系数为 `\{数值\}`，说明树状图对原始距离的保真度良好。"
- "鉴于 `\{对象\}` 分布不均匀且含离群点，本文采用 DBSCAN 密度聚类：以 `k=\{k\}` 的 k-距离曲线拐点确定 `\varepsilon=\{数值\}`，取 `MinPts=\{数值\}`，得到 `\{m\}` 个簇与 `\{q\}` 个噪声点（占 `\{p\}`%），符合 `\{业务预期\}`。"
- "为验证稳健性，本文将 `\varepsilon` 在 `\pm10\%` 范围内扰动，簇数与各类成员的平均调整兰德指数为 `\{数值\}`，表明划分对参数不敏感。"
- "与 K-means 相比，本文选用 DBSCAN 的原因在于 `\{任意形状簇/显式识别噪声\}`；并进一步以 `\{业务判据\}` 对聚类结果做合理性检验，剔除 `\{q\}` 个不合理的簇。"（后一句对应 2017B 的真实做法〔原文〕）

**配套图表**：① **树状图 dendrogram**（标出切割高度虚线）——层次聚类的标志图；② **k-距离曲线**（排好序的第 `k` 近邻距离，标出拐点）——`\varepsilon` 的选取依据；③ **`(\varepsilon,MinPts)` 敏感性表**（簇数、噪声比例、轮廓系数随参数变化的网格）；④ **散点图/地图**（簇着色，噪声点用空心标记）；⑤ **轮廓系数图**或各类规模柱状图；⑥ **类别特征表**（每类指标均值 + 规模 + 占比），与 K-means 同一要求；⑦ 若用 CURE，加一张**相关系数热力图叠加聚类边界**（C235 做法〔原文〕）。

## 16. 可创新方向

1. **参数化 DBSCAN**：把固定半径 `\varepsilon` 换成由业务指标驱动的**可变半径**，让"密度"具有业务含义。2017B 引入任务得分半径与用户得分半径，明确"任务的预期成功率越小，任务得分半径越大；用户的信誉度越高、预订任务时间越早，用户得分半径越大"〔原文〕——这是把通用算法改造成题目专属模型的最佳范式。
2. **聚类 + 可行性检验的双层结构**：先按密度聚类得到候选簇，再用业务约束（服务能力覆盖、容量上限）检验每个簇是否可行，不可行者打散。2017B 即"打包后我们还基于用户得分半径检验打包是否合理"，并规定打包任务数上限不超过 4 个〔原文〕。
3. **降维 + 密度的串联**：先 PCA/因子分析压到 2–3 维（同时便于可视化）再跑 DBSCAN，绕开高维密度失效；空间数据则用地理坐标加少量业务维度做加权距离。
4. **多种子密度聚类**：用不同 `(\varepsilon,MinPts)` 组合多次运行，构造"两点被分到同一簇的频率"共现矩阵，再对该矩阵做一次层次聚类，得到对参数不敏感的稳定分群——这是 DBSCAN 缺少统计模型的补丁。
