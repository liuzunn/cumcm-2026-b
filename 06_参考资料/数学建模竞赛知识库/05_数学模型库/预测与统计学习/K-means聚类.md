# K-means聚类

## 1. 模型用途

K-means 在**无标签**条件下把 `n` 个样本按"相近程度"硬划分成 `K` 个互斥的簇，每簇用均值（质心）代表。国赛里它极少单独成篇，通常承担两件事：

- **分群/分档**：把对象划成业务等级。2018C 用 K-means 把会员划成活跃/沉默/流失三类〔原文〕；2023C C050 用 K-means++ 把蔬菜单品划成热销/畅销/平销/滞销四类〔原文〕。
- **给后续模型造标签或造决策单元**：把连续的综合得分变成离散等级（2018C 走的是"RFMT 得分 → 聚类 → 价值等级"这条路线〔原文〕），或把大量个体压缩成几类代表，再对类别做定价、补货、调度决策。

## 2. 题目特征

1. **数据形态**：一张 `n×p` 的样本—指标数值表，无标签列，来自题目附件（消费流水、会员记录、地理坐标、理化指标）。2018C 是会员流水汇总出的 R、F、M、T 四指标；C050 是单品的总销售量、每日最大销售量、日均销售量三指标〔原文〕。
2. **问句形态**："将……划分为几类""给出……的分级标准""刻画……的画像"。C050 摘要直接写"将单品划分为热销、畅销、平销和滞销四大类"〔原文〕。
3. **量纲混杂**：指标单位不一致（天、次、元、百分比），必须先标准化。2012A(4) 写"由于所选数据的量纲和数值大小都不一致……因此必须首先对所选数据进行标准化处理"〔原文〕。
4. **几何形状**：对象若是空间点（经纬度），必须**先画散点图**判断是否团状。2017B 的任务点分布不均匀，作者因此否决了 K-means〔原文〕。

## 3. 数学原理

### 3.1 目标函数的来源

K-means 求解的是**最小化簇内平方误差和**（WCSS / SSE）：

$$\min_{\{C_k\},\{\mu_k\}} J = \sum_{k=1}^{K}\sum_{x_i \in C_k} \|x_i-\mu_k\|_2^2$$

其理论出处是**向量量化（Lloyd–Max 量化）**：用区域质心代表该区域的全部样本，则最优划分是 **Voronoi 划分**、最优代表点是**区域均值**。固定划分求 `\mu_k` 是凸问题（求导即得均值）；固定 `\mu_k` 求划分也可精确求解（每点归到最近质心）。两个子问题各自最优，但联合问题非凸。

### 3.2 统计前提

把 K-means 当分类器看，它等价于**等协方差、等先验混合高斯模型的硬分配极限**：若每簇服从 `\mathcal{N}(\mu_k,\sigma^2 I)` 且先验相等，贝叶斯最优边界就是最近质心规则。由此隐含三条前提：

- **(P1) 各维等权同方差**——欧氏距离把 `p` 个维度等权相加，只有当量纲统一、方差量级相近时"距离近"才等于"相似"。**前提不成立时**：量纲大或方差大的那一维支配整个距离，结果退化成"按该单指标分箱"。
- **(P2) 簇是凸的、近似球形、大小相近**——**不成立时**：长条簇被从中间切断，环形与嵌套簇完全失效，相邻但大小悬殊的两簇被合并。
- **(P3) 质心能代表整簇**——均值对离群点极不稳健。**不成立时**：一个远端异常点把质心拉偏，进而带歪整个划分。

### 3.3 收敛性与局部最优

`J` 在有限个划分上取值、每步单调不增，故 Lloyd 迭代**必在有限步内收敛**；但收敛点只是**局部最优**，若两个初始中心落在同一真实簇内，该簇就会被劈开。这正是 K-means++ 的动机——C050 原文写明"摒弃了 K-means 算法随机初始化的思想，其选择初始化聚类中心的原则是初始化簇中心之间的相互距离要尽可能地远"〔原文〕。

## 4. 基本公式

**目标函数与质心更新**

$$\min_{\{C_k\},\{\mu_k\}} J = \sum_{k=1}^{K}\sum_{x_i \in C_k} \|x_i-\mu_k\|_2^2,\qquad \mu_k = \frac{1}{n_k}\sum_{x_i\in C_k} x_i,\quad n_k=|C_k|$$

**样本到质心的欧氏距离**（C050 式(6)）

$$D_{ij}=\sqrt{\sum_{k=1}^{m}(x_{ik}-K_{jk})^2},\quad j=1,\dots,K;\ i=1,\dots,n$$

**K-means++ 选点概率**（C050 式(5)）

$$P(x)=\frac{d^2(x,\mathcal{C})}{\sum_{x'\in X} d^2(x',\mathcal{C})},\qquad d(x,\mathcal{C})=\min_{c\in\mathcal{C}}\|x-c\|$$

**标准化、轮廓系数与 CH 指数**

$$z_{ij}=\frac{x_{ij}-\bar x_j}{s_j},\qquad s(i)=\frac{b(i)-a(i)}{\max\{a(i),b(i)\}},\qquad CH=\frac{\mathrm{tr}(B)/(K-1)}{\mathrm{tr}(W)/(n-K)}$$

其中 `a(i)` 为 `i` 到同簇其余点的平均距离，`b(i)` 为 `i` 到最近邻簇所有点的平均距离，`\bar s\in[-1,1]`。

## 5. 参数含义

| 符号 | 含义 | 取值/注意 |
|---|---|---|
| `n`、`p` | 样本数、指标数 | `n` 太小（如 `<30`）聚类不可信；`p` 高时欧氏距离退化 |
| `K` | 簇数 | 必须预先给定；由肘部 + 轮廓 + 业务可解释性共同确定 |
| `\mu_k`、`n_k` | 质心、簇规模 | 在标准化尺度下求得，解释前必须反标准化；`n_k` 过小要查离群点 |
| `J`/SSE | 簇内平方和 | 随 `K` 单调下降，**不能**用于直接比较不同 `K` |
| `\bar s` | 平均轮廓系数 | >0.5 结构清晰；0.25–0.5 一般；<0.25 基本无结构 |
| `init`、`n\_init`、`tol` | 初始化、重启次数、容差 | 用 `k-means++`；重启 ≥10 取最优 SSE |

## 6. 建模步骤

1. **界定对象与粒度**：给样本聚类还是给指标聚类？2018C 给会员聚、C050 给单品聚——对象搞错后面全错。
2. **构造指标**：选 `p` 个能区分对象、信息不冗余的数值指标；高度相关的一组先做 PCA 或合并，否则该"话题"被重复加权。
3. **预处理**：缺失值填补、异常值识别（箱线图 / 3σ / LOF）、**z-score 标准化**（必做）。
4. **确定 `K`**：SSE 肘部拐点 + 轮廓系数峰值 + CH 峰值 + 业务可解释性，多准则一致才算定下来。
5. **求解**：K-means++ 初始化，重启 10–50 次，取 `J` 最小者。
6. **结果命名**：按质心大小关系给出业务标签——论文里最值钱的一步（见 §15）。
7. **稳健性检验**：换随机种子、换 `K\pm1`、换距离度量、剔除离群点前后对比、Bootstrap 重抽样算 ARI。

## 7. 算法

1. **初始化（K-means++）**：随机选 1 个样本作 `\mu_1`；对每个样本算 `d^2(x,\mathcal{C})` 与 `\sum d^2`，按 `P(x)` 抽样选下一个中心；重复直到选出 `K` 个中心。
2. **分配**：对每个样本计算 `D_{ij}`（`j=1\dots K`），令 `x_i` 归入 `\arg\min_j D_{ij}`。
3. **更新**：对每簇按 `\mu_k=\frac{1}{n_k}\sum_{x_i\in C_k}x_i` 重算质心。
4. **判停**：若 `\max_k\|\mu_k^{new}-\mu_k^{old}\|<\varepsilon`（或分配不再变化、或达最大迭代数）则停，否则回第 2 步。
5. **多次重启**：重复 1–4 共 `n_{init}` 次，取 `J` 最小的一次为最终解。
6. **事后评估**：计算 `\bar s`、CH 与各簇规模，画轮廓图确认没有严重负轮廓样本。

**复杂度**：单次分配 `O(nKp)`、单次更新 `O(np)`，迭代 `T` 次得单轮 `O(nKpT)`；初始化 `O(nKp)`；`n_{init}` 次重启再乘 `n_{init}`。总量级 `O(n_{init}\cdot nKpT)`，空间 `O(n+Kp)`。**不要**预先算 `n\times n` 距离矩阵（`O(n^2p)` 且内存爆炸）。层次聚类与 DBSCAN 的 `O(n^2)` 量级与此形成对比，这正是 K-means 能上大数据的关键。

## 8. Python实现思路

- 主体：`sklearn.cluster.KMeans(n_clusters=K, init='k-means++', n_init=10, random_state=0).fit_predict(X_std)`，结果在 `.cluster_centers_`、`.inertia_`、`.labels_`。
- 预处理用 `StandardScaler`（不用 MinMax——K-means 假设各向等方差，z-score 更贴合）；类别型指标先 one-hot 或业务编码。
- 定 `K`：循环 `K=2…10` 记录 `inertia_`、`silhouette_score`、`calinski_harabasz_score`，画双轴图找拐点与峰值。
- 大数据用 `MiniBatchKMeans(batch_size=1000)`；`n` 上万时不要调用 `pairwise_distances`。
- 可视化：`PCA(n_components=2)` 投影后着色散点并标质心，或画平行坐标图。
- **易错点**：① 忘标准化；② 用 `inertia_` 比较不同 `K`；③ `n_init=1` 且不固定 `random_state`，结果每次不同；④ 把标准化空间的质心当原始指标均值写进论文（须 `scaler.inverse_transform(cluster_centers_)`）；⑤ 经纬度直接算欧氏距离——应先投影到平面或用 haversine。

## 9. MATLAB实现思路

- 主体：`[idx, C, sumd, D] = kmeans(X, K, 'Distance','sqeuclidean', 'Start','plus', 'Replicates',10)`；`'Start','plus'` 即 K-means++，`Replicates` 相当于 `n_init`。C050 的聚类就是用 MATLAB 求解的〔原文〕。
- 定 `K`：`evalclusters(X, 'kmeans', 'CalinskiHarabasz', 'KList', 2:10)`，可换 `'Silhouette'`、`'DaviesBouldin'`；返回对象的 `OptimalK` 给出建议值。
- 标准化用 `zscore(X)`（按列）——`kmeans` 内部不做标准化，必须自己先做。
- 高维可视化：`[coeff, score] = pca(X);` 取前两列画散点。
- 依赖 Statistics and Machine Learning Toolbox；R2017b 之前无 `'plus'` 选项，需自行实现 K-means++。
- **易错点**：① 默认距离为 `sqeuclidean`，改成 `cityblock` 结果会变，论文须声明距离度量；② 返回的 `C` 与输入同尺度，若 `X` 已标准化则 `C` 也是标准化尺度；③ `Replicates` 默认值随版本变化，显式写死更稳；④ `evalclusters` 在 `n` 大时很慢，可先抽样评估。

## 10. 优点

- **快且可扩展**：`O(nKpT)`，数十万行流水也能跑，这是相对层次聚类、DBSCAN 的压倒性优势。
- **结果直观可解释**：质心向量就是"该类对象的平均画像"，可直接列表（2018C 正是靠中心数值完成类别命名〔原文〕）。
- **易与后续模型衔接**：簇标签可直接作为自变量喂给回归、优化或仿真模型。
- **实现门槛低**：Python、MATLAB、SPSS、Clementine 均有成熟实现（2018C 用 Clementine，C050 用 MATLAB）〔原文〕。

## 11. 缺点

- **`K` 要人为给定**，且不同 `K` 的结果缺乏统一判据，只能靠肘部 / 轮廓 / 业务三重佐证。
- **只擅长凸的球状簇**：对长条、环形、嵌套、密度差异大的分布系统性出错。2017B 原文"K-means 聚类、层次聚类等，以上的聚类方法一般只适用于凸样本集的聚类。不适合本文任务点分布情况"〔原文〕就是最直接的国赛级表述。
- **对量纲与离群点敏感**：必须标准化、必须处理异常值。
- **只保证局部最优**，且是**硬分配**（边界样本无法给出从属概率，要概率须用 GMM 或模糊 C 均值）。
- **没有统计显著性**：`\bar s` 只是几何指标而非假设检验统计量，不能像回归那样报 p 值。

## 12. 适用条件

当以下条件**同时**成立时，优先用 K-means：

1. 题目核心动词是"划分 / 分档 / 分群"，且没有现成标签。
2. 对象数 `n` 至少是目标类数 `K` 的 10 倍以上且 `n\ge 50`（`n` 只有个位数时不要聚类）。
3. 聚类指标全为数值型，且已完成标准化与异常值处理。
4. 散点图或相关结构显示各簇大致呈团状、大小相近、无极端密度差。
5. 每个簇能被命名成有业务含义的类别——这是论文能成立的必要条件，不只是技术条件。

## 13. 不适用情况

1. **当对象已有类别标签、任务是判别新样本归属时**——那是分类问题，用 LDA/SVM/随机森林，不要用 K-means 反过来"发现"已知的类。
2. **当空间分布明显非凸（长条、环形、嵌套）或密度极不均匀时**——2017B 的任务点即属此类，论文明确弃用 K-means 改用改进 DBSCAN〔原文〕；应改 DBSCAN、谱聚类或 CURE。
3. **当存在明显离群点且不能剔除时**——离群点会被强行塞进最近的簇并拉偏质心，应先用 LOF 或 DBSCAN 识别噪声。
4. **当样本量极小（如 6–20 个点）却要分 3–4 类，或指标为大量未编码的类别型变量，或维度 `p` 远大于 `n` 时**——前者的"类均値"没有统计意义；后者独热编码后欧氏距离把类别差异摊薄；`p\gg n` 时欧氏距离集中化使最近邻与最远邻差别消失，必须先降维再聚类。
5. **当需要输出样本属于某类的概率/隶属度时**——改高斯混合模型或模糊 C 均值。

## 14. 常见错误

1. **不做标准化直接聚类**。指标里混了"消费金额（万元）"与"购买次数（次）"，距离会被金额完全支配，聚类退化成按金额分箱。2012A(4) 在聚类前专门写了一段"量纲不一致必须标准化"〔原文〕；K-means 比系统聚类更敏感，因为它完全靠距离判别。
2. **用 inertia/SSE 的下降证明"`K` 越大越好"**。SSE 是 `K` 的单调不增函数，`K=n` 时取 0。必须用肘部拐点 + 轮廓系数峰值 + CH 峰值综合定 `K`，并把这张图放进论文。
3. **空间不均匀点数据硬上 K-means**。这是国赛语料里被明确记录的踩坑：2017B“拍照赚钱”的任务定价 (5) 写下"我们能想到一些聚类方式如 K-means 聚类、层次聚类等，以上的聚类方法一般只适用于凸样本集的聚类。不适合本文任务点分布情况"，最终改用改进 DBSCAN 并配合遗传算法求解〔原文〕。凡对象带经纬度，**先画散点图**再决定算法。
4. **样本量过小还做聚类**。同期的 2017C 颜色与物质浓度辨识 (1) 明确讨论过数据量下限——"数据量不能低于 6，一般 10-15；颜色维度降到一维模型就不成立"〔原文〕。聚类对样本量的要求更高于回归：`n=15` 分 4 类等于每类 3–4 个点，质心没有意义。
5. **只报聚类编号，不报业务命名与中心数值**。K-means 的论文价值九成在于把编号翻译成业务类别。2018C 之所以被引用，是因为它给出"聚类1 的 R 聚类中心为 982.932、F 聚类中心约 4 次→流失会员；聚类2 的 R 聚类中心为 113.681、F 聚类中心为 16.458→活跃会员；聚类3 的 R 聚类中心为 447.715、F 聚类中心为 5.695"这样可直接阅读的结论〔原文〕；只写"第 3 类有 218 人"是无效结论。
6. **只运行一次且不设随机种子，或在标准化空间解释质心**。前者结果不可复现，评审追问时给不出同样答案；后者会把 z 值（0.8、−1.2）当成原始量纲的均值，必须反标准化后再列表。

## 15. 论文写法

**可直接套用的句式**：

- "为将 `\{N\}` 个 `\{研究对象\}` 划分为若干类别，本文选取 `\{指标1\}`、`\{指标2\}`、`\{指标3\}` 作为聚类变量，先做 z-score 标准化以消除量纲差异，再采用 K-means++ 初始化以降低算法对初始中心的敏感性。"
- "以簇内平方和（SSE）的肘部拐点与平均轮廓系数（`\bar s=\{数值\}`）为准则，兼顾 `\{业务含义\}` 的可解释性，最终确定聚类数 `K=\{K\}`。"
- "根据质心大小关系，将第 1 类命名为 `\{类别名\}`（中心为 `\{数值\}`，共 `\{n_1\}` 个，占 `\{p_1\}`%）；该结果与 `\{题目背景或常识\}` 相符。"
- "为检验稳健性，本文更换随机种子重复 30 次，各次划分的平均调整兰德指数为 `\{数值\}`；且在 `K\in\{K-1,K,K+1\}` 时各类含义保持一致，说明划分基本稳定。"

**配套图表**：① **SSE 肘部图**（标出拐点），证明 `K` 的选取有据；② **轮廓系数曲线或 silhouette plot**（每簇一条横向条形并标平均线），证明簇内紧致、簇间分离；③ **二维投影散点图**（PCA 前两个主成分着色、质心用大符号标出），最直观；④ **聚类中心表**（行是类别，列是各指标原始量纲均值 + 类规模 + 占比），K-means 结果的标准呈现，2018C 用的就是这张表〔原文〕；⑤ **平行坐标图**（每类一条折线），适合指标多于 3 个时展示"哪类在哪几个指标上高"；⑥ 可选的**稳健性表**（不同 `K`、不同种子、剔除离群点前后的 ARI 或类别规模对比）。

## 16. 可创新方向

1. **把"定 `K`"从看图升级为准则**：引入 Gap Statistic 或基于 BIC 的近似判据，与肘部、轮廓形成三准则投票，并给出 `K=3,4,5` 下各类含义是否稳定的敏感性表——这比"看图说话"更像可辩护的模型选择过程。
2. **指标合成 + 聚类的两阶段路线**：先用 RFM/RFMT、熵权法或 PCA 把 `p` 个原始指标压成少数综合维度再聚类。2018C 走的正是"RFMT 得分 → K-means"〔原文〕，C050 是"三个销量指标 → K-means++ 四档"〔原文〕；好处是类别天然对应业务等级，命名不牵强。
3. **加权 / 约束 K-means**：用熵权、AHP 或灰色关联度（C050 的关键词里就有灰色关联分析）构造加权欧氏距离；或加入**容量均衡约束**（各类规模相当）与**空间连通约束**（同类必须地理相邻），使划分可直接用于后续决策。
4. **与异常检测串联**：先用 LOF 或 DBSCAN 剔除噪声点，再在干净数据上聚类，最后单独报告被剔除的点（2017B 用 LOF 刻画任务离群度就是这一思路的邻接做法〔原文〕），论文里写成"清洗—聚类—复核"三步闭环。
5. **两层或混合聚类**：K-means 粗分 + 类内再聚，适合"大品类下再分小单品"（2023C C235 的 CURE 就是"3 个大簇、每簇内部还有细分小簇"的两级结构〔原文〕）；或 K-means 给初值 → 高斯混合模型输出软隶属度。
6. **与业务深度耦合的解释层**：聚类本身不产生结论。在分群后对各群做差异检验（Kruskal–Wallis 或方差分析），证明"各群在 `\{目标指标\}` 上确实有显著差异"，可把聚类从"分段"升级为"发现"。

## 17. 优秀论文案例

1. **`2018C：基于 RFMT 模型的百货商场会员画像描绘.pdf`**——用 K-means 做了两次聚类：先按 RFMT 综合得分对会员价值等级分类，再选 R、F 两指标、设 `K=3`、用 Clementine 软件**迭代 17 次**，把会员划分为**活跃会员、沉默会员、流失会员**三类，并给出可读的质心结论："聚类1 的 R 聚类中心为 982.932、F 聚类中心约 4 次→流失会员；聚类2 的 R 聚类中心为 113.681、F 聚类中心为 16.458→活跃会员；聚类3 的 R 聚类中心为 447.715、F 聚类中心为 5.695"；文中还写出了"聚类目标是使各类总的距离平方和最小""根据最小二乘法和拉格朗日原理求聚类中心"的目标函数与推导〔原文〕。**与 K-means 的关系：完全一致**（标准 K-means + 业务命名 + 目标函数推导，是国赛里 K-means 写得最规范的样板之一）。证据等级〔原文〕。
2. **`2023 展示论文 C050.pdf`（2023C 蔬菜类商品定价与补货决策）**——以单品的**总销售量、每日最大销售量、日均销售量**为指标，设定 `K=4`，用 **K-means++** 把单品划分为**热销、畅销、平销、滞销**四大类，给出四类聚类中心表与前 60 种单品的分类结果；正文完整写出 6 步算法（含式(5) `P(x)=d^2(x)/\sum d^2(x)`、式(6) 欧氏距离、式(7) 质心更新），并说明"摒弃了 K-means 算法随机初始化的思想，其选择初始化聚类中心的原则是初始化簇中心之间的相互距离要尽可能地远"，求解工具为 MATLAB〔原文〕。**与 K-means 的关系：完全一致（K-means++ 变体）**——把初始化动机写清楚的最佳范本。证据等级〔原文〕。
3. **`2017B：“拍照赚钱”的任务定价 (5).pdf`**——**反面对照案例**。该文在任务打包处主动写出"打包实际上就是分类的一种……我们能想到一些聚类方式如 K-means 聚类、层次聚类等，以上的聚类方法一般只适用于凸样本集的聚类。不适合本文任务点分布情况，为此，我们提出一种改进的基于 DBSCAN 的聚类算法"，随后引入任务得分半径与用户得分半径改写固定半径，用遗传算法求解，最终求得 **62 个需打包的任务点、打成 25 组，成功率最高提升 7.2%、平均提升 2.3%**〔原文〕。**与 K-means 的关系：反面对照（明确的适用性否决）**——写"什么时候不要用 K-means"时最有力的国赛证据。证据等级〔原文〕。
4. **`2001B：公交车调度的规划数学模型.pdf`（编者按）**——该文用 **Fisher 有序样本聚类（最优分割）** 对客流分布做优化分类，得到上行客流峰值 5 段（5:00—6:00、6:00—9:00 等）；编者按原文"第一种模型中使用 Fisher 聚类算法对客流分布进行了优化分类，这使得客流时间段的划分更为合理"〔原文〕。**与 K-means 的关系：仅相关**——任务同构（都是"分档/分段"），但有序样本聚类利用了时间顺序信息，是 K-means 在一维有序场景下更好的替代，可作"同类目标不同解法"的对照。证据等级〔原文〕。
