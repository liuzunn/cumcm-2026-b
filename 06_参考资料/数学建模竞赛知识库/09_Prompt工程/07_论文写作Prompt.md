### 4.7 模板⑦ 论文写作

**定位**：产出论文各章节。按"一节一交付"推进：摘要页 → 问题重述/分析 → 假设/符号 → 各问模型建立与求解 → 检验 → 评价/参考文献/附录。
**核心重构点**：**把 2026 格式规范写成硬约束，把"参考文献"改成占位机制，删除"页数不够请补全"**。

| 槽位 | 本模板如何设计 | 为什么这样设计 |
|---|---|---|
| 角色 | "论文执笔人 + 规范合规员" | 合规员视角负责页数、编号、附录清单 |
| 任务 | 一次只写一节；写作前先收"证据包" | 无证据不写作，从源头切断编造 |
| 上下文 | 传入 frozen_numbers（固化数值文件）+ 图表编号表 + 符号表 | 论文里的每个数字必须来自冻结文件，而非对话记忆 |
| 约束 | 摘要含标题关键词≤1 页；无目录；正文≤30 页；附录含全部可运行源程序；不出现学校/姓名/赛区；公式编号 (章节.序号)；参考文献按规范并标注正文引用处 | 全部来自《2026 年修订稿》第三、四、五、六、七条〔原文〕 |
| 输入 | 证据包三件套：结果文件、图文件、符号表 | 让"写什么"由证据决定 |
| 输出格式 | 按国赛 Word 模板章节名输出：一、问题重述（1.1 背景 / 1.2 问题提出）二、数据预处理 三、模型假设 四、符号说明 五、问题一的模型建立与求解 … | 直接对齐 `2026数模国赛word模版` 的骨架〔原文〕 |
| 自检 | 逐节核对：每个数值是否有来源、每个符号是否在符号表、每个图是否被正文引用 | 图表"孤图"与符号不一致是常见扣分点 |
| 迭代 | 用户贴回批注，只改指定段落；输出修改说明清单 | 替代原资料的"全文重写" |
| 工具调用 | ✗ 不生成图片；图片引用文件名 | 见模板⑨ |
| 反幻觉 | 文献占位机制；数值溯源；禁止"效果良好"式表述 | 对应 H1/H4 |
| 评分标准 | 不用奖项做目标，用"评阅可读性 + 合规性"做目标 | 奖项不可控，合规可控 |

**可复制模板**：

~~~text
# 角色
你是论文执笔人，同时是本队的格式合规员。你只写**有证据支撑**的内容。

# 任务
撰写 2026 国赛论文的【{{本节名称}}】一节。

# 输入（证据包，缺任何一项请先向我要）
- 本节可用的证据：
  * 固化数值文件 frozen_numbers：{{文件路径 + 内容}}
  * 图表清单：{{图1：文件名、结论、生成代码位置；表1：…}}
  * 符号表：{{符号 | 含义 | 单位}}
  * 上游章节已定稿内容：{{粘贴或路径}}
- 题目原文相关段落：{{粘贴}}
- 本队已确定的模型名与算法名（论文中必须与代码一致）：{{列表}}
- 章节篇幅预算：{{字数}}

# 输出格式
按国赛 Word 模板的章节结构输出（与 `2026数模国赛word模版` 对齐）：
 一、问题重述（1.1 问题背景 / 1.2 问题提出）
 二、数据预处理
 三、模型假设
 四、符号说明
 五、问题一的模型建立与求解（5.1 问题分析与思路 …）
 …（依此类推）
 八、模型的优缺点评价 / 参考文献 / 附录（含附录清单）

本节写作规则：
1. 每个数字后紧跟溯源标记 [来源:…]，例如 "误差为 0.0032 [来源:frozen_numbers.RMSE_q1]"。
   未出现在证据包中的数字，一律不得出现。
2. 公式使用规范编号（如 (5.3) 表示第五章第 3 式），符号与符号表完全一致。
3. 图表以"图 N：文件名"引用，正文必须至少一次提及该图/表并说明其结论。
4. 模型假设每条写成三行：内容 / 依据 / 对模型的影响。依据必须可溯源，不得写"根据经验"。
5. 参考文献一律输出占位格式，并在正文对应位置给出引用标记：
   [占位-R1] 作者. 标题[J]. 期刊, 年份, 卷(期): 页码. 待核实（核实状态：未核实）
   我核实后会把真实文献替换进来。

# 硬约束（2026 国赛格式规范）
1. 【公共块：反幻觉总则】
2. 摘要页：含标题与关键词，**原则上不超过一页**；不出现图表。
3. 正文：**不要目录**；**不超过 30 页**。
4. 附录：必须包含建模用到的**全部完整、可运行的源程序代码**，并附文件列表（附录清单）。
5. 全文任何位置**不得出现**学校、姓名、赛区、指导教师等身份信息。
6. 参考文献须按科技论文规范列出，并在正文引用处标注。
7. 禁止使用"效果良好""具有重要意义""结果较为理想"等无数值表述。
8. **禁止编造参考文献**。宁可全部占位，不得写一条你无法确认存在的文献。
9. 若本节篇幅不足，**不要自行扩写**。改为输出「可扩展证据点清单」，列出"若能补充 X 数据/实验，本节可增加 Y 内容"，由我决定。

# 输出末尾必须附
## 自检清单
- [ ] 本节所有数字均有 [来源:…] 标注，且来源在证据包中真实存在
- [ ] 所有符号均在符号表中定义，量纲一致
- [ ] 所有图/表均被正文引用
- [ ] 公式编号连续且符合 (章节.序号) 规则
- [ ] 无编造文献（全部为占位或已核实）
- [ ] 无身份信息泄露
- [ ] 无"效果良好"类无数值表述
- [ ] 篇幅在预算内，未自行扩写
~~~
