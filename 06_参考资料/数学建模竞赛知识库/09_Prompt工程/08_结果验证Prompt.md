### 4.8 模板⑧ 结果验证与检验

**定位**：产出 `05_检验报告.md`。**前置为门禁**：不通过则回退到模板②/④。
**核心重构点**：**把检验拆成四层，且必须允许输出"不通过"**。原资料（附录四）检验设计相对完整，但仍缺少两件事：① 提交物格式合规性校验（2026 特有）；② 允许并鼓励给出否定结论。原资料的口径是"输出检验结果并解读（如'平均MSE=0.02，约束满足度100%，模型有效'）"——示例即暗示结论必须是"模型有效"。

| 槽位 | 本模板如何设计 | 为什么这样设计 |
|---|---|---|
| 角色 | "独立验证员（与被检验模型无利益关系）" | 独立第三方设定，降低"证实偏差" |
| 任务 | 四层检验：数值正确性 / 模型有效性 / 鲁棒性 / 提交物合规性 | 前三层学术，第四层是 2026 国赛特有的生死线 |
| 上下文 | 完整证据链（代码、输出、模板） | 无代码无法复算，无模板无法校验格式 |
| 约束 | 必须给出"通过 / 不通过 / 存疑"三态判定；不通过时必须给最小反例 | 三态判定是硬性要求，破除"结论必须正面"的暗示 |
| 输入 | frozen_numbers + result*.xlsx 模板定义 + 题目逐条要求 | 合规性校验需要模板的行列定义 |
| 输出格式 | 四张检验表 + 逐条题目要求对照表 + 判定 | 对照表直接把"答非所问"暴露出来 |
| 自检 | 复核每条检验方法是否真的能证伪该结论 | 防"用 R² 检验优化模型的约束满足性"这类错配 |
| 迭代 | 不通过 → 输出"最小返工路径"（改哪一步最小代价） | 72 小时内返工成本必须可控 |
| 工具调用 | 输出检验代码；不执行 | 同模板⑤ |
| 反幻觉 | 检验指标必须说明"高于/低于多少算通过"及依据 | 防"R²=0.85 说明模型有效"这类无阈值断言 |
| 评分标准 | 阈值来源必须可溯源（题目/文献/领域惯例，惯例须标注） | 阈值编造是隐蔽幻觉 |

**可复制模板**：

~~~text
# 角色
你是独立验证员，与被检验的模型没有利益关系。你的任务不是证明模型对，而是**尝试把它证伪**。
如果你找不到任何可证伪的点，你必须明确说"本次检验未能证伪，但同时也未充分验证，理由是……"。

# 任务
对 {{题号}} 第 {{小问}} 的模型与结果做四层检验，并给出三态判定。

# 输入
- 模型与算法说明：{{模板④的伪代码与参数表}}
- 代码与真实运行输出：{{粘贴 stdout / 日志 / 生成的结果文件内容}}
- 提交物模板定义：{{result1.xlsx 的行列、单位、小数位；来自附件3}}
- 题目的逐条要求：{{从题目原文摘录，编号列出}}
- 已有中间量与另一语言实现：{{模板⑥的一致性比对结果，若有}}

# 输出格式
## 第一层 数值正确性检验
| 检验项 | 方法 | 阈值及来源 | 实测值 | 判定 |
（必查：量纲一致性；边界条件是否满足；守恒量是否守恒（若适用）；步长/网格减半后结果变化量；
 单位换算处是否有多算少算（s↔h、cm↔m、kg/kg 干基湿基）；NaN/Inf；解越界）
## 第二层 模型有效性检验
| 检验项 | 方法 | 阈值及来源 | 实测值 | 判定 |
（按模型类型选择，并说明为什么这个指标适配这个模型：
 预测类→RMSE/MAE/MAPE + 残差白噪声检验；优化类→约束满足度 + 与松弛下界/上界的差距 + 最优性证书；
 评价类→权重一致性检验、排序稳定性；机理类→与解析解/极限情形的偏差）
## 第三层 鲁棒性检验
| 扰动对象 | 扰动方式（±10% / 加噪 / 极端场景） | 结果变化量 | 判定 | 现实含义 |
要求：逐条给出"该扰动的现实对应物是什么"（例如"±10% = 传感器精度"）。
## 第四层 提交物合规性检验（2026 国赛专用）
| 检查项 | 要求（来自题目原文与格式规范） | 实测 | 判定 |
（result*.xlsx 文件名是否正确；行/列是否与模板一一对应；数量是否足够；小数位数是否符合；
 是否有多余空白行列；表头是否与原模板一致；单位是否一致；
 附录中源程序是否完整可运行；论文正文是否 ≤30 页，摘要是否 ≤1 页；全文是否含身份信息）
## 逐条要求对照表
| 题目要求（逐字引用，编号） | 我们的输出 | 是否满足 | 若否，缺口是什么 |
## 三态判定
- 结论：通过 / 不通过 / 存疑
- 若不通过或存疑：给出**最小反例**（一个具体的输入或条件，使模型给出明显错误或不可接受的结果）
- 最小返工路径：改哪一步代价最小（回退到模板②选型 / 模板④伪代码 / 模板⑤代码 / 仅是记录方式错）

# 硬约束
1. 【公共块：反幻觉总则】
2. 每个阈值必须写出处：题目给定 / 领域惯例（标注"惯例"并说明适用范围）/ 【缺失】。
   禁止给出没有出处、"看起来合理"的阈值。
3. 禁止因"结果看起来对"而省略检验步骤。
4. 禁止输出"模型有效"这类无实测值支撑的结论。
5. 若某层无法检验（缺数据、缺代码），明确写"无法检验，缺少：……"，不得跳过。
6. 检验代码不得与求解代码共用同一处可能的实现错误（例如不得用同一个手写函数既生成又校验）。

# 输出末尾必须附
## 自检清单
- [ ] 四层检验全部执行，或明确标注"无法检验"及原因
- [ ] 每个阈值都有出处
- [ ] 检验方法与被检验模型类型适配
- [ ] 提交物格式逐项对照了模板
- [ ] 题目逐条要求都有对照结论
- [ ] 已尝试构造最小反例
- [ ] 未出现"模型有效"式无证据结论
~~~
