### 4.11 模板⑪ 最终审稿（评委视角）

**定位**：T+62h 起，产出 `07_终审报告.md` + 修改清单。**只做减法与合规，不允许新增内容**。
**核心重构点**：**审稿产出是"必须修改项清单"，不是"分数"**。原资料高频要求"契合 O 奖/M 奖评审偏好"却从不给评分维度（第 1.3 节），本模板给出六维量表，并**强制声明该评分为内部一致性评分、不是赛事预测**〔推理：国赛无公开评分细则与分数预测依据〕。

| 槽位 | 本模板如何设计 | 为什么这样设计 |
|---|---|---|
| 角色 | "全国评阅组评阅人" | 与国赛三层评阅（赛区→全国）语境一致 |
| 任务 | 六维审查 + 合规终检 + 必须修改项 + 建议修改项 | 分"必须/建议"两档，保证 72h 末段不会去改不必要的东西 |
| 上下文 | 论文 PDF/Word + 附录 + 支撑材料清单 + 承诺书/编号页排除情况 | 电子版第一页必须是摘要页 |
| 约束 | **禁止新增内容**；只允许删、改、调格式、补引用 | 末段新增内容是风险最大的一类动作 |
| 输入 | 全文 + 附录清单 + 支撑材料压缩包内容 + 页数统计 | — |
| 输出格式 | 六维评分表 + 合规终检表 + 修改清单（定位到页/段/图/公式）+ 提交前 checklist | 修改清单可直接派工 |
| 自检 | 复核每条修改建议是否会导致页数超限或前后不一致 | 末段修改最常见副作用 |
| 迭代 | 改完后再跑一次，只报差异 | — |
| 工具调用 | ✗ | — |
| 反幻觉 | 禁止预测奖项、禁止编造"历年获奖论文的做法" | 这是原资料最普遍的隐性编造 |
| 评分标准 | 六维 × 1–5 分，且必须写"评分依据在文中的位置" | 让评分可核对 |

# 硬约束
1. 【公共块：反幻觉总则】
2. **禁止新增内容**：不得建议"补做实验""增加一节""再加一个模型"。只允许删/改/调格式。
3. **禁止预测奖项**（如"此稿可达国一水平"）。禁止引用"历年获奖论文"的具体做法，除非我提供了原文。
4. 每条修改项必须定位到具体位置，不得写"整体优化语言"。
5. 修改建议不得导致正文超过 30 页或摘要超过 1 页；若会超页，必须同时给出删减方案。
6. 不得建议删除附录中的源程序（格式规范要求必须包含）。
