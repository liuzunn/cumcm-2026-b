### 4.9 模板⑨ 图表生成

**定位**：产出 `figures/figN.py` + `figures/figN.png` + 图注文本 + 图表清单。
**核心重构点**：**把"生成图片"整体改写为"生成绘图代码 + 图形参数 + 图注"**。这一条直接消灭第 3 节 R1/R2/R6 三类缺陷，同时把 pptx 课件里点出的"AI 绘图痕迹"（默认字号 12、默认 SimHei、浅色调）变成显式的反痕迹参数要求〔原文，痕迹课件 L3-10〕。

| 槽位 | 本模板如何设计 | 为什么这样设计 |
|---|---|---|
| 角色 | "数据可视化设计师（输出代码不输出图片）" | 从根上消除"图片生成失败→重试"的死循环 |
| 任务 | 每张图独立一个脚本 + 图注 + 清单 | 一图一脚本便于单独返工与单独进附录 |
| 上下文 | 图的"结论"必须先写出来 | 图服务结论，而非结论事后附会（讲义 L93〔原文〕"论文图表要服务结论，不是越多越好"） |
| 约束 | 尺寸/字号/字体/dpi/配色/线宽显式指定；中文字体显式设置；禁默认参数 | 对抗"AI 默认画风"，也是评委观感的直接来源 |
| 输入 | 真实数据文件 + 字段 + 已在论文中确定的图表编号 | 防图表编号与正文引用错位 |
| 输出格式 | 脚本 + 参数表 + 图注（30–50 字，含具体数值）+ 正文引用建议 | 图注含数值是"图不是装饰"的证据 |
| 自检 | 断言：图上标注的每个数值都来自数据文件 | 防"图上写 98.5% 但数据里没有" |
| 迭代 | 按单图返工，不重画全部 | 原资料"重新生成该阶段全部图片"是反模式 |
| 工具调用 | 明确输出 matplotlib/MATLAB 代码；**拒绝直接产出图像** | 核心重构点 |
| 反幻觉 | 图注不得包含图中没有的信息；插图数据必须来自结果文件 | 对应 H6 |
| 评分标准 | 可读性优先（字号≥9pt、色盲友好、黑白打印可辨） | 国赛部分赛区需纸质打印 |

**可复制模板**：

~~~text
# 角色
你是数据可视化设计师。重要：你**不能生成图片**。你的产出是**绘图代码 + 图形参数 + 图注文本**，
由我在本地渲染成 PNG/PDF。

# 任务
为 {{题号}} 生成第 {{N}} 张图，图号 {{图N}}。

# 输入
- 本图要支撑的结论（一句话，必须来自已固化的结果）：{{…}}
- 数据来源：{{文件路径 | 列名 | 单位 | shape}}
- 论文中该图的引用位置：{{章节名}}
- 若为机理示意图：给出要表达的逻辑链 {{A→B→C}}，禁止凭空添加环节

# 输出格式
## 1. 图形规格表（必须显式给值，不得留默认）
| 项 | 取值 | 理由 |
| 画布尺寸（英寸） | | 单栏/通栏 |
| dpi | ≥300 | 纸质与电子提交 |
| 中文字体 | 显式设置 plt.rcParams['font.sans-serif'] / fontname | 防止中文方框 |
| 字号（标题/轴标签/刻度/图例/图注） | 均为显式值，刻度≥9 | 打印可读 |
| 配色 | 给出具体色值，色盲友好，黑白打印可区分（用线型+标记区分而非仅靠颜色） | 部分赛区黑白打印 |
| 线宽/标记尺寸 | | |
| 是否含误差线/置信区间 | | 有重复实验时必须含 |
## 2. 绘图代码（单文件，可直接运行）
- 只读 {{数据文件}}，不得内联任何数值；
- 必须写 fig.savefig(..., dpi=..., bbox_inches='tight')；
- 若图上有文字标注（如"阈值 0.15"），该数值必须从变量读取，不得字符串硬编码；
- **不要执行代码，不要输出图片，不要描述"图中显示……"**。
## 3. 图注（30–50 字，必须含至少一个具体数值）
格式：图N  {{图题}}。{{关键数值观察}}+{{该数值说明的结论}}。
要求：图注中的每个数值都能在数据文件中找到。
## 4. 正文引用建议句（1 句）
## 5. 图表清单更新行
| 图号 | 文件名 | 支撑的结论 | 生成脚本 | 正文引用位置 |

# 硬约束
1. 【公共块：反幻觉总则】
2. **禁止生成或描述图片内容。** 不得写"该图显示……"，因为没有图。
3. 禁止使用默认字号、默认字体、默认色板（那是 AI 生成图的最明显特征）。
4. 禁止在同一图中堆叠 3 个以上信息维度（多维数据拆成多图或多子图）。
5. 若数据不足以支撑该结论，明确回答"数据不支持此图，缺少：……"，不得换一种画法硬凑。

# 输出末尾必须附
## 自检清单

- [ ] 中文字体已显式设置
- [ ] 配色在黑白打印下仍可区分
- [ ] 代码未内联任何数据
- [ ] 图注中的数值全部来自数据文件
- [ ] 未输出/未描述任何图片内容
- [ ] 未使用"图片生成失败请重试"类指令
~~~
