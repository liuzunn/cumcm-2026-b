### 0.3 2026 国赛的硬事实（第 4 节模板设计的现实约束）

以下均为〔原文〕要点摘录（`2026_format2026.doc.txt`）：

- 摘要专用页为电子版论文第一页，摘要含标题关键词**原则上不超过一页**；页码从该页起连续编号（第三条）。
- 正文从第四页开始，**不要目录，不超过 30 页**；正文后为附录，**页数不限**，必须与正文装订。
- 附录须包含**建模所用到的全部完整、可运行的源程序代码**；"如果缺少必要的源程序、程序不能运行或运行结果与论文不符，都可能会被取消评奖资格"（第五条）。
- 电子版论文 + 支撑材料两个文件，**各不超过 20MB**，支撑材料含所有可运行源程序与数据资料（第九~十一条）。
- 摘要页、正文、附录任何地方**不得出现参赛者身份、学校、赛区信息**（第六条）。
- **论文还应符合《全国大学生数学建模竞赛人工智能工具使用规定（2026年试行）》**（说明第(5)条）。
- 本科组从 ABC 中任选一题，高职高专组从 DE 中任选一题（说明第(1)条）。

〔归纳〕2026 真题的"提交物约束"远强于美赛：A 题要求把 1800s×0.1cm 网格与 3h 网格结果写入 `result1.xlsx`/`result2.xlsx` 并**保留四位小数**；A/C/D/E 四题均配套 `result*.xlsx` 模板文件（`_work_extract/2026_A题_附件_附件3_result1.xlsx.txt` 等）。**现有 24 份提示词中没有一份提到 result*.xlsx、四位小数、附件模板行列对齐** —— 这是本次分析发现的最大结构性缺口〔推理〕。

关键读数：

1. **"评分标准"与"自检"严重错位。** 19 份提示词反复要求输出"契合美赛评分标准/O奖偏好"，但没有任何一份要求 AI 按评分维度**逐条打勾或给分**〔归纳〕。评分标准被当作形容词使用，而不是验收函数。
2. **反幻觉槽位缺位且被"数据补充"条款反向抵消。** 经全目录精确检索：**10 处**要求"全网自主寻找合适数据"、**10 处**要求"无法获取时基于场景逻辑合理假设补充"、**9 处**要求提供"虚拟下载链接"、**9 处**要求代码"无需借助本地数据上传"（见第 3 节）。这是主动授权模型造数。
3. **角色槽位近乎缺席。** 24 份中 3 份有角色，其余靠"我是一名参赛选手"的**用户自述**代替。模型没有被定位为"评审者""红队"或"某类工程角色"，因此无法触发对抗性输出。
4. **迭代槽位的方向是"续写"而不是"收敛"。** 18 份里的迭代语全是"继续生成下一部分""重新生成全部图片"，没有一处是"根据上一轮自检失败项定向重写"〔归纳〕。

## 2. 共同骨架与通用元模板

### 2.1 八段式骨架〔归纳〕

把 24 份提示词纵向对齐后，反复出现的是同一根骨架，只是每段的"填充度"不同：

    ① 身份与目标声明     —— "我是X赛参赛选手 / 我要冲击O奖 / 团队情况 / 擅长语言 / 需求重点"
    ② 题目与数据投喂     —— "在此粘贴完整题目文本、附件说明、隐含背景"
    ③ 题目分析           —— 逐句解析（背景/核心问题/已知条件/约束）→ 小问划分（直接目标+隐含目标）→ 逻辑关系图 → 题型定位
    ④ 模型选择           —— 方案1（基础保分）+ 方案2（创新冲奖），各含 核心原理/适配性/创新点/局限性/可视化流程
    ⑤ 数据处理           —— 必要性判断 → 缺失/异常/转换/补充 → 双语言代码 → 处理后数据前10后5行 → 预处理结论
    ⑥ 模型建立与求解     —— 变量定义 → 假设(3-5条，内容+依据+影响) → 公式推导 → 流程图 → 求解步骤 → 代码 → 可视化
    ⑦ 结果分析           —— 基础分析（数值解读+统计描述）+ 深层分析（关联性+敏感性+实际意义）
    ⑧ 检验与改进         —— 有效性检验 → 改进方向 → 鲁棒性分析（参数±10%）→ 优缺点评价

出现的两个"派生分支"〔归纳〕：

- **论文分支（附录三 / 附录十二~十七 / 论文撰写提示词）**：开篇三要素 → 基础章节（问题重述/问题分析/假设/符号）→ 数据处理 → 模型建立与求解 → 结果分析 → 收尾（评价/参考文献/附录）→ 全文优化。
- **选题分支（2026美赛赛题分析）**：翻译 → 类型界定 → 小问与算法推荐 → 难度与排序 → 难点要点思路获奖要点 → 分背景选题建议。

### 2.2 这个骨架的四个结构性缺陷〔推理〕

1. **它是"文章目录"，不是"工作流"。** 八段之间没有数据契约：⑤ 产出的"处理后数据"没有约定落盘路径与列名，⑥ 的代码无从引用；⑧ 的鲁棒性分析没有约定要复用 ⑥ 的哪个参数。结果是每一轮对话都要重新贴上下文。
2. **它把"模型选择"放在"数据分析"之前。** 骨架顺序是 ③④⑤：先选模型，再看数据。真实建模中数据决定模型（2026 C 题的光伏预测数据长度决定能否用 LSTM；2026 B 题只给示向度决定只能用几何交会而非统计学习）〔推理，依据 2026_真题.txt B题 L394-399〕。
3. **⑧ 被放在最后。** 检验沦为收尾装饰。国赛评阅中"模型检验"是与"模型建立"并列的评分点，且**检验结论会反过来否定模型选择**，必须前置为门禁〔推理〕。
4. **没有"提交物对齐"环节。** 2026 国赛 A/C/D/E 题都有 `result*.xlsx` 模板，行=时间、列=距离，四位小数〔原文，2026_真题.txt A题 L15-18〕。骨架里没有任何一段负责"把内存里的结果按模板写进 Excel"。

### 2.3 通用元模板（可复用的主模板）

设计原则：**保留原骨架的覆盖面，但补上四个缺失槽位（自检 / 反幻觉 / 提交物对齐 / 评分函数），并把检验前置为门禁。**

~~~text
# 角色
你是{{角色_按阶段选择}}。你的输出会被人类建模手逐条核验，任何无法被核验的内容都视为失败输出。

# 任务
在 {{当前阶段}} 阶段，完成 {{唯一交付物名称}}。

# 上下文（我只给这些，不给的一律视为未知）
- 赛事与题号：{{2026国赛 A/B/C/D/E 题，及选择的题号}}
- 题目原文：{{粘贴全文，不得概括}}
- 附件清单：{{附件1.xlsx：字段=...，行数=...；附件2.docx：...}}
- 提交物模板：{{result1.xlsx 的行列定义、小数位数、单位}}
- 已完成的上游产出：{{文件路径 + 关键数值}}
- 时间预算：{{剩余小时数}}

# 输入契约
你必须先输出"输入核对表"：逐项列出我提供的信息中，哪些是你**确实读到**的，哪些是**缺失**的。

1. 禁止编造条款：不得生成任何我未提供的数值、文献、数据集、下载链接、链接、API、函数名、结论。

   [占位] 作者. 标题[J]. 期刊, 年份, 卷(期): 页码. —— 待人工核实（核实状态：未核实）
4. 数值必须可溯源：每个数值后标注 [来源:{{文件/代码行/附件表}}]。

{{按阶段指定：表格列名 / 文档小节名 / 编号规则}}

- [ ] 所有数值均可溯源到我的输入或你的代码输出
- [ ] 无编造文献 / 无编造数据 / 无编造链接
- [ ] 所有公式符号已定义且量纲自洽
- [ ] 与上游产出（{{上游文件}}）无冲突
- [ ] 与提交物模板（{{result*.xlsx}}）行列与小数位对齐
- [ ] 每个结论都有对应的数据或检验支撑

# 迭代规则
输出末尾给出"待确认问题清单"（≤5 条），每条格式：
Q: …… | 为什么需要你确认 | 若默认取值我会取什么
我回答后，你只重写受影响的段落，不重写全文。

# 评分函数（仅当角色为审稿/红队时启用）
按 {{评分维度表}} 逐维度给 1-5 分 + 扣分项定位到"章节/公式编号/图表编号"，
并明确标注"该评分是相对本稿内部一致性，不是赛事预测分数"。
~~~

### 2.4 关于元模板的自我批判〔推理〕

- 这个元模板把单次对话的**信息密度**提高了约 3–4 倍，代价是**首轮 token 成本**。在 72 小时赛程里，最值得用它的是 ①赛题分析、②建模方案、⑩红队、⑪终审 这四个"决策点"，而 ⑤⑥ 编程阶段应改用更窄的专用模板（见第 4 节）。
- "禁止编造文献 → 输出占位格式"会牺牲"参考文献看起来完整"的表观质量。这是**有意的取舍**：据 2026 格式规范第七条，引用必须按科技论文规范列出并在正文标注；一条不存在的文献一旦被评委识别，损失远大于"占位待补"的不美观〔推理〕。

### 3.6 一句话总结〔推理〕

> 这批提示词把 AI 当作**产出机器**（要更多字、更多公式、更多图、更多创新点），而竞赛真正需要的是把 AI 当作**受约束的核对器**（更少幻觉、更可溯源、更能自证）。
> 24 份里唯一同时具备"反幻觉 + 自检 + 人工拍板门禁"的是 AI+数学建模工作流讲义，而它恰恰是唯一不是"提示词"的那一份。

## 4. 面向 2026 国赛的 11 个重构模板

### 4.0 设计总纲

**四条设计律**〔推理，依据第 1–3 节的缺陷清单与 2026 格式规范〕：

1. **一模板一交付物。** 每个模板只产出一个可以被下游直接引用的文件（表格/代码/清单），不做"全流程大提示词"。原资料 24 份提示词的共同问题是"一份提示词想要全部"（附录二一份覆盖八阶段），导致每阶段都没有可验收的产物。
2. **输入契约先于任务。** 每个模板第一步都是"输入核对表"，把缺失项显式暴露。原资料全部把"粘贴题目"写在最前但从不检查粘贴结果。
3. **反幻觉条款必须是可执行的句式**（"凡未提供，写【未在资料中找到】"），而不是态度声明（"避免编造"）。
4. **自检清单必须输出给用户看**，且带 ✗ 时必须先修正。原资料 0 份具备此槽位。

**编号与时机**（按 72 小时赛程）〔推理〕：

| 时点 | 模板 |
|---|---|
| T+0 ~ T+3h | ① 赛题分析（含选题） |
| T+3h ~ T+8h | ② 建模方案设计 |
| T+8h ~ T+14h | ③ 数据分析与预处理 |
| T+14h ~ T+20h | ④ 算法设计 |
| T+20h ~ T+40h | ⑤ Python / ⑥ MATLAB 编程（并行） |
| T+30h ~ T+50h | ⑧ 结果验证与检验、⑨ 图表生成（交错） |
| T+36h ~ T+60h | ⑦ 论文写作 |
| T+50h ~ T+66h | ⑩ 模型检查（红队） |
| T+62h ~ T+72h | ⑪ 最终审稿 |

**通用公共条款（下称"公共块"，11 个模板均默认包含，正文中不再重复展开）**：

~~~text
【反幻觉总则】
1. 我只承认三类内容：(a) 我粘贴给你的原文；(b) 附件中实际存在的数值/字段；(c) 你代码的真实输出。
   除此之外的一切，必须写成「【推测】……（依据：……）」或「【未在资料中找到】」。

【自检总则】
每次输出末尾必须附「自检清单」，逐项 ✓/✗ 并给理由；出现 ✗ 时先修正再交付。
~~~

### 4.1 模板① 赛题分析

**定位**：T+0 起，读题 + 选题决策。产出 `01_赛题分析.md`。
**核心重构点**：**不让 AI 推荐模型**。原资料（附录二 三、2026美赛分析 L5）在"题目分析"阶段就要求"每小问推荐适配算法/模型"，结果是模型推荐早于数据理解，且会把后续所有思路锚死。本模板把"选模型"推迟到模板②。

| 槽位 | 本模板如何设计 | 为什么这样设计 |
|---|---|---|
| 角色 | "命题人 + 评阅人"双视角 | 不用"建模专家"：专家视角会急着给方案；命题人视角才能还原出题人的埋点（哪一问是送分、哪一问是分水岭） |
| 任务 | 只做四件事：拆句、定类型、标数据缺口、列提交物 | 任务越窄，越不容易发散；原资料把"分析+选模型+推算法+给思路"混在一份里，等于没有交付物 |
| 上下文 | 强制粘贴全文 + 附件文件名清单 | 附件字段名往往就是变量定义；不粘附件 = 后面全部返工 |
| 约束 | 禁止提出任何模型名；禁止改写原题句 | 防锚定。一旦 AI 写"建议用遗传算法"，后面所有分析都会向它收敛 |
| 输入 | 输入核对表（读到/缺失分栏） | 暴露题目里的图表、公式、附件没粘贴成功的情况 |
| 输出格式 | 五张固定表 + 一个提交物清单 | 表格可被队友直接分工；原资料的"思维导图（文字描述）"不可分工 |
| 自检 | 逐问核对"是否答非所问" | 国赛扣分重灾区是答非所问，而非模型不新 |
| 迭代 | 只输出待确认问题清单，不自动续写 | 读题阶段的续写会把猜测固化成结论 |
| 工具调用 | ✗ 明确禁止（本阶段不写代码） | 保持分析纯度 |
| 反幻觉 | 公共块 + 附件逐字引用要求 | 防"题目隐含背景"类脑补。原资料附录二要求填"题目隐含背景"，且不给核验方式 |
| 评分标准 | 只标"命题人埋点"和"分水岭小问"，不给获奖预测 | 国赛无公开评分细则，任何分数预测都是编造 |

### 4.2 模板② 建模方案设计

**定位**：题目读透后，产出 `02_建模方案.md`，用于队内拍板。
**核心重构点**：**不要求"创新"，要求"可证伪"**。原资料强制"每问都要有创新模型"（（最新版）L9）并给出"改进BP神经网络""灰色-BP组合"这类举例，直接导致模型堆砌。本模板改为：给 3 个方案（最简可解释 / 稳健主流 / 创新），但**每个方案必须写出"它在什么条件下会失败"**，并做决策记录。

| 槽位 | 本模板如何设计 | 为什么这样设计 |
|---|---|---|
| 角色 | "建模总师 + 怀疑论者" | 怀疑论者视角强制产出失败条件；原资料无此角色 |
| 任务 | 3 方案 × 8 维对比 + 失败条件 + 决策记录 | 对比维度覆盖"数据要求/实现难度/可解释性/可检验性/论文可写性/时间成本"，而非只比"创新性" |
| 上下文 | 传入模板①的产物，而非重新读题 | 建立数据契约，避免重复劳动 |
| 约束 | 创新方案必须给出"相对最简方案的量化收益预期"与"代价"；禁止无量化收益的创新 | 用成本收益取代形容词。原资料"创新点（非形式化创新）"无判据（见 M3） |
| 输入 | 模板①表B/表D 必填 | 无数据支撑的方案讨论无意义 |
| 输出格式 | 对比矩阵 + 每问决策记录（含"被否决的方案及原因"） | 被否决方案是论文"模型选择依据"章节的现成素材，也是 AI 使用记录的加分项 |

### 5.2 真实作用机理〔推理，依据 5.1 条款特征反推〕

"AI 率"检测与"查重率"检测是**两套完全不同的机制**，本模块只对其中一套起作用：

| 检测机制 | 依赖的特征 | 本模块哪些条款会命中 | 有效程度 |
|---|---|---|---|
| **AI 生成检测**（困惑度 perplexity + 突发性 burstiness） | 词频分布是否过于"平滑可预测"；句长方差是否过小；过渡词密度；段落结构是否模板化 | (a) 降过渡词密度；(b) 增大句长方差；(d) 强制长短句与主语变化；(f) 打断段落均质衔接 | **有效**。这些条款直接作用于检测器所依赖的低阶统计量〔推理〕 |
| **查重 / 文字复制比** | 与已有文献/网络文本的 n-gram 重合 | 仅 (a) 的替代方案与 (e) 的"用具体事实替换抽象过渡"间接降低通用短语重合；模块 D 提到注释风格会被查重检测 | **基本无效**。真正决定查重率的是"是否原创表述、是否复述已有句式"。本模块**没有任何一条要求改写文献复述、要求原创定义表达、要求控制引用密度**〔归纳，全文 213 行无相关条款〕 |

〔推理〕因此该文件的标题"**降低AI率/查重率提示词模块**"存在**过度承诺**：它对 AI 检测特征有针对性，对查重率几乎无作用。使用者若据此以为查重也能降下来，会产生错误的安全感。

### 5.3 逐条判定：有效 / 部分有效 / 风格伪装 / 不可接受

判定口径〔推理〕：
- **有效** = 既改变统计特征，又**增加真实信息或强制可核验**，即"内容上被迫说得更实"；
- **风格伪装** = 只改变表层形式，**可被零成本满足且不增加信息**，甚至可能损害学术性；
- **不可接受** = 要求或默许生成不存在的事实。

| 条款 | 判定 | 判断依据 |
|---|---|---|
| A(c) 思考痕迹：假设要有依据链 | **有效（质量提升）** | 它强制把"假设忽略空气阻力"改写为"速度≈1 m/s→Re≈10⁴→阻力≈0.003 N，驱动力≈10 N，差三个数量级"〔原文 L55〕。**这是在强制补做量级估算**，即便不为降AI率，这条也该写进任何建模提示词。 |

### 5.4 三个结构性批判〔推理〕

**批判一：规则化的"反痕迹"会形成新的痕迹。**
本模块给出的是一套**公开、固定、可批量执行**的写作规则。若被广泛采用，那么"长短句交错 + 每段末尾一句自我审视 + 每千字 3 处口语化 + 至少两段意外发现"就会成为新一代的统一文风。讲义 L278-282 已经点破了这个机制〔原文〕：
> "同质化太严重。不同队伍问AI类似的问题，AI给的答案也差不多……最后论文的思路、结构、甚至用词都像复印出来的，评委根本看不出谁好谁坏。"

〔推理〕降 AI 率解决的是"这篇像 AI 写的"，但没有解决"所有队都像同一套提示词写的"。后者恰恰是讲义认为更致命的问题。**从竞赛区分度看，规则化的反痕迹是负收益。**

**批判二：把"写作风格"误当成"研究质量"的替代品。**
模块 A 的 (a)(b)(d)(f) 四条占全文件约 50% 篇幅，但全部作用于**表达层**；真正提升论文可信度的 (c)(e)、B(e)、C(e)、D 四条作用于**内容层**，篇幅占比却明显更低〔归纳，按行数统计〕。如果只能保留 3 条，应当保留 C(e) 数据锚定清单、B(e) 权衡与风险提示、D 踩坑注释，删除 (b)(d)(f)。**判断依据：前者强制补做量级估算与模型取舍，后者只强制改变句子排列。**

**批判三：与国赛的 AI 使用规则存在张力。**
2026 格式规范说明第(5)条要求论文符合《全国大学生数学建模竞赛人工智能工具使用规定（2026年试行）》〔原文〕，且承诺书要求"对参赛队的行为和论文的真实性负责"〔原文，承诺书文本〕。模块 C(f) 允许"构造"调试经历，与"真实性负责"直接冲突。**即使这种构造在文本上无法被检出，它也是一个应当被显式否定的选项。** 本报告在第 4 节模板⑩/⑪ 中以"禁止编造缺陷/禁止新增内容"的方式回避同类风险〔推理〕。

### 5.5 结论与可提取资产〔归纳〕

**结论**：降 AI 率模块的**真实作用机理**是——通过提高句式突发性、降低模板化过渡词密度、增加第一人称过程叙述，来偏离 AI 检测器所依赖的低阶统计特征。这一层是**真实的、可测量的**。
但它同时混入了三类不同性质的内容：
1. **真正提升论文质量、值得保留的**（约占 40%）：A(c) 思考痕迹、A(e) 与 C(e) 数据锚定、B(e) 作者视角权衡与风险提示、D 踩坑注释；
2. **形式约束、可被零成本满足的**（约占 45%）：A(a) 的词表替换部分、A(b)、A(d)、A(f)；
3. **应当删除的**（约占 15%）：C(f) 中"合理构造调试经历"的授权；以及标题中"查重率"的过度承诺。

## 6. 结论与落地建议

### 6.1 五条核心结论

1. **槽位分布严重失衡。** 25 份提示词中，"任务"覆盖率 100%，"自检"仅 16%（且全库 grep `自检|检查清单` 命中 0 处），"反幻觉"仅 28%，"角色"仅 12%（仅附录一、附录四、讲义）。**评分标准被高频提及（76%）却从未被转成可执行的验收函数。**〔归纳〕

3. **最危险的不是缺失，是"主动授权造数"。** 「全网自主寻找数据」（10 处）、「无法获取时合理假设补充」（10 处）、「虚拟下载链接」（9 处）、「无需借助本地数据上传」（9 处）、「自动运行代码给出结果」（2 处）、「直接生成图片 + 生成失败重试」（4 处）构成一条完整的**从缺数据到伪造结果的流水线**。〔归纳〕
4. **"模型堆砌"是被提示词直接生产出来的。** （最新版）L9 自相矛盾地同时要求"每一问都要创新"与"禁止无意义套模型"；六份分题型提示词共用同一组奥运奖牌题示例数字（"参数校准精度提升25%""预测覆盖度达88.6%"）；附录二/六/七/九/十/十一 在数据量未知时默认推荐 LSTM/CNN/集成学习。**而同批材料的讲义 L127 把"模型堆砌"列为风险 1、L72 明确说"不要盲目上深度学习"——风险提示存在，但没有被任何一份提示词采纳。**〔归纳〕
5. **降AI率模块的价值是分层的。** 其内容层条款（数据锚定、权衡叙述、踩坑注释）是真实的质量提升手段；其形式层条款（长短句指标、呼吸感）是可被零成本满足的风格包装；其 C(f) 中"可以合理构造调试经历"属于诚信风险；标题中的"查重率"是过度承诺。〔推理〕
