### 4.1 模板① 赛题分析

**定位**：T+0 起，读题 + 选题决策。产出 `01_赛题分析.md`。
**核心重构点**：**不让 AI 推荐模型**。原资料（附录二 三、2026美赛分析 L5）在"题目分析"阶段就要求"每小问推荐适配算法/模型"，结果是模型推荐早于数据理解，且会把后续所有思路锚死。本模板把"选模型"推迟到模板②。

| 槽位 | 本模板如何设计 | 为什么这样设计 |
|---|---|---|
| 角色 | "命题人 + 评阅人"双视角 | 不用"建模专家"：专家视角会急着给方案；命题人视角才能还原出题人的埋点（哪一问是送分、哪一问是分水岭） |
| 任务 | 只做四件事：拆句、定类型、标数据缺口、列提交物 | 任务越窄，越不容易发散；原资料把"分析+选模型+推算法+给思路"混在一份里，等于没有交付物 |
| 上下文 | 强制粘贴全文 + 附件文件名清单 | 附件字段名往往就是变量定义；不粘附件 = 后面全部返工 |
| 约束 | 禁止提出任何模型名；禁止改写原题句 | 防锚定。一旦 AI 写"建议用遗传算法"，后面所有分析都会向它收敛 |
| 输入 | 输入核对表（读到/缺失分栏） | 暴露题目里的图表、公式、附件没粘贴成功的情况 |
| 输出格式 | 五张固定表 + 一个提交物清单 | 表格可被队友直接分工；原资料的"思维导图（文字描述）"不可分工 |
| 自检 | 逐问核对"是否答非所问" | 国赛扣分重灾区是答非所问，而非模型不新 |
| 迭代 | 只输出待确认问题清单，不自动续写 | 读题阶段的续写会把猜测固化成结论 |
| 工具调用 | ✗ 明确禁止（本阶段不写代码） | 保持分析纯度 |
| 反幻觉 | 公共块 + 附件逐字引用要求 | 防"题目隐含背景"类脑补。原资料附录二要求填"题目隐含背景"，且不给核验方式 |
| 评分标准 | 只标"命题人埋点"和"分水岭小问"，不给获奖预测 | 国赛无公开评分细则，任何分数预测都是编造 |

**可复制模板**：

~~~text
# 角色
你现在是 2026 年全国大学生数学建模竞赛的命题人与评阅人。你的唯一职责是把题目"读透"，
不是解题，不是设计方案。

# 任务
对下面这道 2026 国赛 {{题号}} 题，输出一份纯分析报告。**本阶段禁止提出任何具体的模型名称或算法名称。**

# 输入
题目原文（必须全文，不得概括）：
{{粘贴题目全文}}

附件清单（真实文件名 + 你实际看到的字段）：
{{附件1：文件名=…；我看到的工作表=…；列名=…；行数=…}}
{{附件2：…}}

提交物要求（从题目原文中逐字摘录，不要改写）：
{{例如：将完整结果保存到 result1.xlsx（模板见附件3），所有结果保留四位小数}}

# 输出格式（严格按此五张表 + 一节）
## 表A 逐句拆解表
| 原句（逐字引用） | 类别（背景/核心问题/已知条件/约束/提交物要求） | 我的解读 | 不确定点 |
## 表B 小问拆解表
| 小问 | 直接目标 | 隐含目标（为什么出题人把它放在这一问） | 交付物形态（数值/表格/xlsx/方案） | 与前问的依赖 |
## 表C 题型判定表
| 小问 | 类型（优化/预测/评价/机理/分类/综合） | 判定依据（引用表A的哪些原句） | 置信度（高/中/低） |
## 表D 数据与缺口表
| 需要的量 | 是否在附件中 | 附件位置（文件名+列名） | 单位 | 若缺失，题目是否给了经验公式/常数 | 状态（有/缺/部分） |
## 表E 提交物与合规清单
| 要求 | 原文出处 | 我的实现风险 |
（含：result*.xlsx 文件名、行列定义、小数位数、单位；摘要页；正文页数上限；附录中需附的源程序清单）

## 命题人埋点分析
逐小问回答：这一问是送分题还是分水岭？出题人最想看到什么？最容易踩的坑是什么？
（只允许基于题目原文推理，不确定处写「【推测】」）

# 硬约束
1. 【公共块：反幻觉总则】
2. 禁止出现任何模型名/算法名（如"遗传算法""LSTM""层次分析法"）。违反即重做。
3. 表A的"原句"列必须逐字复制题目原文，不得改写、不得翻译、不得省略数字与单位。
4. 不得填写题目未给出的"隐含背景"。

# 输出末尾必须附
## 自检清单
- [ ] 表A每一行的原句都能在题目原文中找到（逐字比对）
- [ ] 全文中没有出现任何模型名/算法名
- [ ] 所有"隐含目标"都标注了依据或【推测】
- [ ] 表D没有出现附件中不存在的字段
- [ ] 表E完整覆盖了题目原文提出的全部提交物要求
- [ ] 未出现任何编造的文献、链接、数据
## 待确认问题清单（≤5 条）
Q: … | 为什么需要你确认 | 若你默认取值我会取什么
~~~
