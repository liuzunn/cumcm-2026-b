# 09_Prompt工程 · 索引与使用说明

> 本目录是**可直接在比赛中复制的提示词模板**，以及它们的设计依据。
> 全部模板由 `_notes/N06_Prompt工程分析.md`（对资料包中 25 份原始提示词的逐份拆骨分析）重构而来，**不是照抄原文**。

---

## 1. 目录

| 文件 | 用途 | 适用比赛阶段 |

## 2. 本目录的核心结论（来自对 25 份原始提示词的分析）

### 2.1 原始提示词的槽位覆盖（〔归纳〕）

| 槽位 | 覆盖率 | 说明 |
|---|---|---|
| 任务 | 100% | 都说了要做什么 |
| 约束 | 100% | 都提了限制条件 |
| 输出格式 | 92% | 大多要求表格或分段 |
| 评分标准 | 84% | 提到"冲奖""获奖目标" |
| 上下文 | 84% | 都要求粘贴题目 |
| 输入 | 80% | 要求粘贴数据 |
| 迭代 | 80% | 要求"继续下一问" |
| 工具调用 | 52% | 提到 Python / MATLAB |
| **自检** | **16%** | **全库检索"自检""检查清单""核对清单"命中 0 处** |
| **角色** | **12%** | 只有 2 份写了"你是……" |
| **反幻觉** | **约 4%** | 仅工作流讲义 1 份明确提到 |

### 2.2 原始提示词的六类结构性缺陷（逐条有出处，详见 N06 第 3 节）

1. **不可执行指令 7 条**：要求"直接生成图片"并在文末反复写「注意！图片生成失败，请帮我重新生成该阶段全部图片！」（4 处）、要求"虚拟下载链接"（9 处）、要求"无需借助本地上传路径"（9 处）、要求"自动运行代码给出结果"（2 处）。
2. **诱发幻觉 6 条**：要求"全网自主寻找合适数据"（10 处）、"无法获取时合理假设补充"（10 处）、"列出 5-10 条近 5 年文献"（3 处）、"每个模型至少有 10 个左右的公式"（1 处）。
3. **诱发模型堆砌 5 条**：如"每一问都要创新型模型"与"禁止无意义套模型"在同一份文件中自相矛盾。
4. **校勘缺陷 7 条**：如"C 题常见扣分点"文本被错误地放进 A 题、E 题、F 题；六份同源文件的中文序号缺号各不相同（证明是复制后手工删改未校对）。
5. **最高危单条**：附录六至附录十一共六份分题型提示词**共用同一组奥运奖牌题示例数字**（"参数校准精度提升 25%""预测覆盖度达 88.6%"）——**示例即模板，会被整段照抄进论文**。
6. **与 2026 国赛脱节**：全部 24 份提示词**无一份提及** 2026 国赛的 result*.xlsx 结果文件、四位小数保留、附件模板行列结构、正文页数上限、附录须含可运行源程序、AI 使用规定等硬性要求。

### 2.3 重构时做的四件事〔推理〕

1. **把"生成图片"改成"生成绘图代码"**——彻底消灭"生成图片 → 失败 → 重试"的死循环（模板⑨）。
2. **补上"自检清单"槽位**——每个模板末尾都有可勾选的自检项（原库缺失率 84%）。
3. **补上"反幻觉条款"**——每个模板都写明"禁止编造数据 / 文献 / 结论；缺失信息标注【未提供】并列入待确认清单"。
4. **对齐 2026 国赛硬约束**——评分、格式、结果文件、AI 使用申报都写进模板（模板③⑦⑧⑪）。

## 3. 使用顺序（建议）

    01 赛题分析  →  03 数据分析  →  02 建模方案  →  04 算法设计
         ↓
    05 Python 实现  ⇄  06 MATLAB 交叉验证
         ↓
    08 结果验证  →  10 模型检查（红队）  →  07 论文写作  →  09 图表
         ↓
    11 最终审稿

**门禁规则**：每一环节的输出必须通过该模板的"自检清单"才能进入下一环节；人工拍板点（选定模型、判定结果有效性、终稿放行）**不可交给 AI**〔归纳，来源 _keydocs/AI+数学建模工作流讲义.txt 的"AI 负责提效，人负责判断"〕。

## 4. 关于"降 AI 率"模块的独立结论

资料包中另有 `2026国赛论文写作模版/降AI率提示词模块（独立版）.md`。经逐条分析（详见 N06 第 5 节）：

| 判定 | 占比 | 代表条款 |
|---|---|---|
| **真正提升质量，值得保留** | 约 40% | 「数据锚定清单」（要求每段物理解释至少引用一个具体数值 + 指出数值来自哪张表 + 给出变化幅度 + 与前文估计对照）；「作者视角的取舍说明」；「假设依据链」（如用 Reynolds 数量级估算来论证忽略空气阻力）；代码"踩坑注释" |
| **可被零成本满足的风格包装** | 约 45% | 禁用过渡词表、句式节奏 KPI、段落呼吸感、对称式并列的禁令——这些改变的是低阶统计特征（困惑度、突发性、过渡词密度），**对内容质量没有实质影响** |
| **应当删除** | 约 15% | 模块 C(f) 明文允许「可以是合理构造的、物理上有意义的调试经历」——**这等于授权编造科研过程，与论文真实性要求直接冲突**；以及标题中"降低查重率"的承诺（该模块 213 行内没有任何针对文献复述、引用密度、原创表述的条款） |

**本知识库的立场**〔推理〕：主张保留「数据锚定」与「假设依据链」两条，因为它们迫使作者真正去看数据、做量级估算；删除"构造调试经历"条款。至于禁用词表一类，**如果论文本身没有内容，改词是改不出分的**。

## 5. 证据与局限

- 本目录模板的设计依据全部来自 N06 对原始提示词的**文本级分析**（含逐条行号取证）。
- **未做实证测试**：没有实跑这些提示词去测量大模型的幻觉率或产出质量。模板是设计，不是实测结论。
- 资料包中的 `AI一键生成数模国奖级绘图.pptx` 与 `数模国赛 AI 进阶：AI 痕迹识别与改写实操.pptx` 均为图片型 PPT，可提取文本极少，**其图片内可能含未提取的提示词，本目录未覆盖**。
