### 4.5 模板⑤ Python 编程

**定位**：产出 `solve_qN.py` + `requirements.txt` + `run_log.txt` 模板。按小问分片交付。
**核心重构点**：**"我不运行代码"写进提示词**。原资料要求 AI"自动运行代码给出完整代码处理结果"（（最新版）L19/L32），这是幻觉的直接来源。同时补上国赛特有的 **result*.xlsx 落盘** 与 **四位小数** 约束。

| 槽位 | 本模板如何设计 | 为什么这样设计 |
|---|---|---|
| 角色 | "Python 工程师（不执行代码）" | 显式声明能力边界，避免模型假装运行 |
| 任务 | 一次只写一个小问的一个模块（数据读取/核心求解/落盘） | 单次长代码出错率高、且报错定位成本大 |
| 上下文 | 伪代码行号 + 真实 schema + 环境信息 | "按模板④伪代码第 12–31 行实现"比"实现该模型"精确得多 |
| 约束 | 只用 stdlib + numpy/pandas/scipy + （声明的）求解器；顶部集中路径常量；固定随机种子；断言式自检 | 国赛附录要求源程序**可运行**，一条 import 不到的库就会毁掉附录 |
| 输入 | 报错场景下必须提供：完整报错 + 相关代码 + 数据格式 + 预期结果 + 环境版本 | 直接采用讲义 L87〔原文〕的调试输入清单 |
| 输出格式 | 单文件脚本 + 落盘函数 + run_log 模板 | 便于直接塞进论文附录 |
| 自检 | 代码末尾必须有 `if __name__ == "__main__":` 自检块，打印关键 shape/极值/约束满足度 | 让"运行结果与论文相符"（格式规范第五条）可被自动证明 |
| 迭代 | 只改报错相关段落；每次修改给出 changelog | 防止"重写全文"导致已修好的部分回归 |
| 工具调用 | 输出代码即止；**明确拒绝声称执行结果** | 消除 R4 |
| 反幻觉 | 禁止编造 API/参数名；不确定的 API 必须标注"请核对版本" | 模型对冷门库参数的幻觉率很高 |
| 评分标准 | 以"附录可运行 + 结果可复现"为准入门槛 | 与国赛规则对齐 |

# 输出格式
## 1. 源码（单文件，完整可运行）
必须包含并在注释中标注：
- [CONFIG] 区块：INPUT_FILE / OUTPUT_FILE / 关键参数 集中定义，注释"请替换为你的路径"
- [READ] 区块：try/except 读取；失败时打印真实路径 + 候选原因（不存在/权限/编码/表头行号）
- [CORE] 区块：严格对应伪代码行号，逐行注释"对应伪代码第 N 行"
- [WRITE] 区块：按目标模板落盘；写出小数位控制与形状断言
- [SELFTEST] 区块：__main__ 下断言并打印——
    * 输入 shape / 输出 shape
    * 关键中间量的 min / max / 是否有 nan
    * 约束满足度（逐条约束列出"满足 / 违反条数"）
    * 是否触发了模板④的终止/降级条件
## 2. 依赖清单
requirements.txt 内容，并在每行后注释"用于做什么"。
## 3. 运行说明
单条命令行 + 预期 stdout 模板（写清楚"你应该看到什么"）。
## 4. 变更说明（若是修改稿）
| 改动位置 | 原写法 | 新写法 | 为什么改 |

# 硬约束
1. 【公共块：反幻觉总则】
2. **禁止声称你运行了代码，禁止输出任何"运行结果"。** 若我要求你给结果，你的回答是：
   "我无法执行代码。请运行后把 stdout 贴给我。"
3. 不得 import 未经我确认的库；不得使用我未声明的求解器（gurobi/cplex 等商业求解器需先确认授权）。
4. 随机过程必须固定种子（np.random.default_rng(0) 或等价写法）。
5. 所有路径使用 pathlib.Path，禁止写死 Windows 绝对路径。
6. 涉及浮点比较必须用容差，禁止直接 ==。
7. 不得在代码中硬编码数据。数据只能来自 INPUT_FILE。
8. 若伪代码中某步你无法用现有库实现，必须停下来告诉我，不得用近似写法静默替代。
