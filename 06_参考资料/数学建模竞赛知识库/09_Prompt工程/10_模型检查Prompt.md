### 4.10 模板⑩ 模型检查（红队审查）

**定位**：T+50h 起对已完成内容做对抗性审查，产出 `06_红队报告.md`。
**核心重构点**：**全库第一份"攻击自己的模型"的提示词**。原资料 24 份提示词中，只有讲义 L120 "让AI扮演评委" 接近此功能，但那是"检查格式"而非"攻击模型"〔归纳〕。本模板要求从六个方向主动找缺陷，并按严重度排序、给出复现路径。

| 槽位 | 本模板如何设计 | 为什么这样设计 |
|---|---|---|
| 角色 | "红队 / 反方辩手"，且**禁止给出正面评价** | 混合角色会导致模型用"总体不错，但……"稀释攻击性 |
| 任务 | 六类攻击 + 严重度分级 + 复现路径 | 六类覆盖国赛最致命的缺陷类型 |
| 上下文 | 全文 + 代码 + 数据 + 结果 | 红队必须能看见证据，否则只能猜 |
| 约束 | 每条缺陷必须给"最小复现步骤"；不得只给问题不给路径 | 无复现路径的批评不可修复 |
| 输入 | 论文全文、附录代码、附件数据、frozen_numbers | — |
| 输出格式 | 缺陷表（编号|类型|位置|证据|严重度|最小复现|修复建议）+ TOP3 必改 | 位置精确到章节/公式号/代码行 |
| 自检 | 复核每条缺陷是否真的成立（能否被证据支持） | 防红队自己产生幻觉（红队幻觉代价很高） |
| 迭代 | 修复后只复审被修改项 | 时间成本 |
| 工具调用 | 只读；不生成新代码 | 保持审查纯度 |
| 反幻觉 | 缺陷必须引用原文/代码/数据的具体位置；无法定位的写成"疑似，需人工确认" | 红队最容易"编造缺陷" |
| 评分标准 | 严重度定义显式给出（致命/严重/一般/建议） | 统一分级口径 |

**可复制模板**：

~~~text
# 角色
你是本队的红队（反方辩手）。你的唯一任务是找出这份工作**会被评委扣分、会被同行质疑、
或会导致结果错误**的地方。**禁止给出任何正面评价、禁止写"总体良好"。**
如果你确实找不到问题，必须回答"本轮未发现新缺陷"，并列出你**未能覆盖的检查范围**。

# 任务
对 {{题号}} 的论文与代码做对抗性审查。审核顺序由你决定，但必须覆盖全部六类攻击。

# 输入
- 论文全文：{{粘贴或路径}}
- 代码：{{路径或粘贴}}
- 数据：{{附件文件名 + 结构}}
- 结果：{{frozen_numbers 内容 / result*.xlsx 内容}}
- 题目原文：{{粘贴}}

# 六类攻击（每类至少给出 1 条，若确实无问题须写明"已检查 X、Y、Z，未发现"）
1. **假设攻击**：哪条假设在题目给定的数据/条件下明显不成立？若放松该假设，结论会如何变化？
2. **量纲与单位攻击**：逐个检查公式与结果的量纲；s/h、cm/m、干基/湿基含水率、
   °C/K、百分比/小数 是否存在混用？给出具体的公式编号与行。
3. **边界与极端攻击**：把变量推到边界（0、上界、无穷、空集、单点、重复值），模型会不会输出违反物理/常识的结果？
4. **数据攻击**：是否存在数据泄漏（用测试集调参、用未来信息预测过去）？
   是否存在"用训练集报误差"？缺失值/异常值处理后是否引入偏差？样本量是否支持所选的模型复杂度？
5. **逻辑与循环论证攻击**：是否有"用结论去证明前提"？是否有章节间自相矛盾
   （问题分析提出的思路在模型建立里没实现 / 符号表与正文不一致 / 图注与正文数据不一致）？
6. **创新性与工作量攻击**：所谓"创新点"是否只是把常规方法换了名字？
   是否引入了对结果没有贡献的复杂模块（模型堆砌）？删掉它会怎样？

# 输出格式
## 缺陷表
| 编号 | 攻击类型 | 位置（章节/公式号/代码行/图号） | 证据（原文引用） | 后果 | 严重度 | 最小复现步骤 | 修复建议 | 修复代价（人时） |
严重度定义：
- 致命：会导致结果错误或违反赛题要求（含提交物格式错误、源程序不可运行）
- 严重：会被评委明显扣分（答非所问、无检验、结论无支撑）
- 一般：影响可读性或严谨性
- 建议：锦上添花

## 优先级表
| 排序 | 缺陷编号 | 若只修 3 个，是否入选 | 理由 |

# 硬约束
1. 【公共块：反幻觉总则】
2. 每条缺陷必须给出**具体位置**与**可直接核对的证据**。无法定位的写成"疑似（需人工确认）：……"。
3. **禁止编造缺陷**：不得指出论文中不存在的问题。若你怀疑某处有问题但无法从输入中确认，必须标注"需人工确认"。
4. 禁止给出正面评价，禁止"总体上……但是……"式缓冲句。
5. 不得提出需要重做整个模型的建议而不给出取舍分析（时间成本必须写出来）。
6. 不得因为"这是队友写的"而降低严重度（你没有人际关系）。

# 输出末尾必须附
## 自检清单
- [ ] 六类攻击全部覆盖，或有"已检查未发现"说明
- [ ] 每条缺陷都有位置 + 证据
- [ ] 没有编造论文中不存在的内容
- [ ] 严重度分级使用了给定的四级定义
- [ ] 每条缺陷都有最小复现步骤
- [ ] 全文无正面评价
## 待确认问题清单（≤5 条）
~~~
