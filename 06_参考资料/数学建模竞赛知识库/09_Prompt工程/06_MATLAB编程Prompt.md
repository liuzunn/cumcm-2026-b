### 4.6 模板⑥ MATLAB 编程

**定位**：产出 `solve_qN.m` + `deps.txt`。与模板⑤并行，或作为交叉验证的第二实现。
**核心重构点**：**把 MATLAB 版定位为"交叉验证实现"而非"平行实现"**。原资料附录一 2.3 要求"双语言"但两版互不相干；本模板要求两版在**同一组中间量**上做数值一致性比对——这是国赛环境下最廉价、最有说服力的模型验证证据〔推理〕。

| 槽位 | 本模板如何设计 | 为什么这样设计 |
|---|---|---|
| 角色 | "MATLAB 工程师 + 交叉验证者" | 第二实现的价值在互验，不在复刻 |
| 任务 | 实现同一算法，输出可比对的中间量 | 比对点必须预先约定 |
| 上下文 | Python 版的中间量导出文件 | 让两版有共同基准 |
| 约束 | 版本 R2020b+；只用基础+明确列出的工具箱；禁用新版本函数；避免三方工具箱 | 附录一 2.3 原有要求〔原文〕，保留并强化 |
| 输入 | 伪代码行号 + .mat/.csv 结构 | 避免 load 后变量名猜错 |
| 输出格式 | .m 单文件 + 用的工具箱清单 + writetable 落盘 + 一致性比对脚本 | 比对脚本是新增交付物 |
| 自检 | 断言 max|Δ| 与 Python 版的差异并给出容差判据 | 量化"两语言一致" |
| 迭代 | 同模板⑤ | — |
| 工具调用 | 不执行 | 同模板⑤ |
| 反幻觉 | 工具箱与函数名必须存在于指定版本；不确定的标注"请在校验版本后使用" | MATLAB 函数跨版本差异大，是最容易翻车的一环 |
| 评分标准 | 合格线 = 能跑 + 与 Python 版一致 | 交叉验证是模型验证章节的实质内容 |

# 硬约束
1. 【公共块：反幻觉总则】
2. **禁止声称你运行过 MATLAB，禁止输出任何"运行结果"。**
3. 只能使用我列出的已授权工具箱。若算法需要其它工具箱，先提出再写代码。
4. 避免使用较新版本才引入的函数；若必须使用，注明"需 R20xxa 及以上"。
5. 不得使用第三方工具箱或 File Exchange 代码。
6. 不得硬编码数据；不得用 eval 拼接变量名。
7. 输出数值的精度必须与 Python 版一致，并在 [CHECK] 中断言一致容差（建议 rtol=1e-9, atol=1e-12，若达不到须说明原因）。
8. 注释使用中文，文件保存为 UTF-8。
