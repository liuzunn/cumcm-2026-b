## 2. 题型的横向关联（哪些题型常常同时出现）

    优化类 ──┬── 组合优化类（离散决策空间）
             ├── 多目标优化类（目标冲突）
             ├── 调度类（时间维）
             ├── 路径规划类（空间维）
             └── 鲁棒/随机优化（参数不确定）

    评价类 ──┬── 概率统计类（权重与显著性）
             ├── 聚类类（先分群再评价）
             └── 回归类（指标与结果的关系）

    预测类 ──┬── 时间序列类（只有自身历史）
             ├── 回归类（有外生变量）
             └── 机器学习类（大样本非线性）

    机理类 ──┬── 微分方程类（只随时间）
             ├── 偏微分方程类（时间 + 空间）
             ├── 动力系统类（反馈与长期行为）
             └── 参数反演（把实测数据接进机理模型）

    仿真类 ──┬── 概率统计类（随机性）
             ├── 优化类（仿真评估 + 搜索）
             └── 调度/路径类（策略执行）

**实证支撑**〔归纳〕：1992—2024 年真题中，**优化类与概率统计类是唯二 19/19 年全覆盖的题型**；2020、2023、2024 三年出现"5 题全部含优化类标签"的满配。详见 `02_数学建模题型体系.md` 与 `_notes/N01`、`_notes/N02`。

## 3. 模型的纵向演化关系（基础 → 改进 → 高级）

### 3.1 优化族

    线性规划 LP
      ├─► 整数规划 IP ──► 0-1 规划 ──► 组合优化（背包/覆盖/装箱/指派）
      │                                └─► 网络流 / 最小费用流
      ├─► 多目标规划 ──► Pareto 前沿 / NSGA-II
      ├─► 非线性规划 NLP ──► 全局优化 / 元启发式
      └─► 不确定参数 ──► 随机规划 / 鲁棒优化 / 机会约束
                        └─► 多阶段随机规划（滚动时域）

### 3.2 预测族

    朴素外推
      ├─► AR / MA / ARMA ──► ARIMA ──► SARIMA（季节性）
      │                          └─► GARCH（波动聚集）
      ├─► 回归 ──► 广义线性模型 ──► 混合效应模型（分层数据）
      ├─► 灰色 GM(1,1)（小样本）
      ├─► 状态空间 / 卡尔曼滤波
      └─► 机器学习 ──► 集成学习 ──► 组合预测

### 3.3 机理族

    经验公式 / 集总参数
      ├─► 一维 ODE ──► 方程组（SIR/房室）──► 最优控制
      ├─► 一维 PDE ──► 多层耦合 ──► 变物性（非线性）──► 移动边界（Stefan）
      ├─► 有限差分 ──► 有限元 / 有限体积 ──► 谱方法
      └─► 加数据 ──► 参数反演 ──► 灰箱 / PINN

### 3.4 评价族

    AHP（主观）
      ├─► 熵权 / CRITIC / 变异系数（客观）
      ├─► 主客观组合赋权（博弈论 / 最小偏差 / 最大熵）
      ├─► PCA / 因子分析（降维赋权）
      └─► 合成：TOPSIS / 灰色关联 / RSR / 模糊综合评价 / DEA

〔原文佐证〕用户任务书给出的两条范式："线性规划 → 整数规划 → 多目标优化 → 鲁棒优化"、"普通预测 → 时间序列 → 机器学习 → 集成学习"。

## 8. 一句话总结这张图

> **题眼是入口，题型是分类，数学结构是桥梁，模型是主体，算法是工具，代码是载体，结果是答案，验证是保险，论文是出口。**
> 任何一环缺失，链条就断；国赛评审扣分，往往不是扣在"模型不够高级"，而是扣在**链条上的某一个断点**（最常见的是"没有验证"和"没读附录里的约束"）。
