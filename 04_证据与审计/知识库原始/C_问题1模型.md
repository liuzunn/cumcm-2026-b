# C · 问题 1 模型（定位区域直径与覆盖判定）

## C1 从物理到数学 `[题目原文]` + `[自行推导]`
检测点 → 示向度 θ → 射线 → 考虑 ±1° → **角度扇区（楔形）** → 多测点交集 → 定位区域。

| 环节 | 数学对象 |
|---|---|
| 检测点 | 平面点 $\mathbf{s}=(x,y)\in\mathbb{R}^2$ `[题目原文]` |
| 示向度 | $\hat\theta\in[0°,360°)$ `[题目原文]` |
| ±1° | $\theta^\ast\in[\hat\theta-\delta,\hat\theta+\delta]$，$\delta=1°$ `[题目原文]` |
| 楔形 | $\mathcal{W}(\mathbf{s},\hat\theta,\delta)$ = **两半平面之交** `[自行推导]` |
| 定位区域 | $\mathcal{R}=\mathcal{D}\cap\bigcap_j\mathcal{W}(\mathbf{s}_j,\hat\theta_j,\delta)$，**凸多边形** `[自行推导]` |

## C2 半平面形式（可计算）`[自行推导]`
$$\mathcal{W}=\{p:\mathrm{cross}(\mathbf{u}(\hat\theta-\delta),p-\mathbf{s})\ge0\}\cap\{p:\mathrm{cross}(\mathbf{u}(\hat\theta+\delta),p-\mathbf{s})\le0\}$$
⇒ n 个测点 = 2n 个半平面 ⇒ 最多 2n 条边；n=2 时即题面图 2 的四边形。

## C3 直径与退化 `[自行推导]` + `[代码验证]`
- 直径 = **顶点对最大距离**（凸性保证）；
- 三类退化：**无界**（方向区间有公共方向）/ **不缩小**（测点重合）/ **角度跨 0° 环绕**；
- 数值复核：题面图 2 场景（$\mathbf{s}_1=(0,0)$、$\mathbf{s}_2=(0,1000)$、真源 $(1000,0)$）⇒ **D = 110.59 m**，与解析式差 **0.17%**。`[代码验证]` `05_EXPERIMENTS/scripts/_work_b26_geom.py`

## C4 覆盖判定（Q1 第二问）`[自行推导]` + `[代码验证]`
- **充要条件**：设 $\mathbf{a},\mathbf{b}$ 实现直径，则以 $\mathbf{ab}$ 为直径的圆覆盖 $\mathcal{R}$ ⟺ 每个顶点 $\mathbf{v}$ 满足 $(\mathbf{a}-\mathbf{v})\cdot(\mathbf{b}-\mathbf{v})\le0$（Thales）；
- **结论：一般不成立**。197 745 个良态配置中 **1.73% 不可覆盖**；最强反例 $\alpha=90.04°$、$D=59.65$ m、最小覆盖圆半径 $29.84\,\mathrm{m}>D/2$；
- **保底上界**：半径 $D/\sqrt3$ 的圆一定够（比 $D/2$ 大 15.47%）。

## C5 误差规律 `[自行推导]` + `[代码验证]`
$$D=\frac{2\delta}{\sin\alpha}\sqrt{d_1^2+d_2^2+2d_1d_2|\cos\alpha|},\qquad d_1=d_2=d\Rightarrow D(\alpha)=\begin{cases}2\delta d/\sin(\alpha/2),&\alpha\le90°\\2\delta d/\cos(\alpha/2),&\alpha\ge90°\end{cases}$$
- $D_{\min}=2\sqrt2\,\delta d\approx0.0494d$（$\alpha=90°$）；曲线关于 90° **对称**；两端发散；
- **D ∝ d、D ∝ δ 均为严格线性**；
- 可清除门槛 $D\le40$ m ⇒ α=90° 等距时 $d\le810$ m。
