# G · HTTP / 模拟器协议

## G1 四条指令 `[题目原文]` `[附件2]`
| 指令 | 含义 | 是否推进虚拟时间 |
|---|---|---|
| `POST /enter` | 进入目标区域 | **否** |
| `POST /measure` | 到指定位置对指定频道检测 | **是** |
| `POST /clear` | 到指定位置清除指定频道目标 | **是** |
| `POST /exit` | 退出 | **否** |

必填字段：`arena_id="default"`、`robot_id=参赛队号`、`request_id`；`/measure` 与 `/clear` 还需 `position{x,y}` 与 `channel`。

## G2 时间账 `[附件2]`
| 动作 | 耗时（虚拟时间） |
|---|---|
| 移动 | 直线距离 / 5 |
| 切换频道 | 1 s，**仅由 `/measure` 触发**；频道相同则 0 |
| 检测 | 5 s（no_signal / near / direction 三种结果都一样） |
| 清除 | 未发现 **3 s**；成功 **5 s**（3 s 光学 + 2 s 激光） |
| `/enter` / `/exit` | **0** |

**关键**：`/clear` 的 channel 只表示"要清除的目标频道"，**不改变测向机当前频道**。当前频道**只由成功的 `/measure` 更新**。

## G3 幂等与错误码 `[附件2 §5.3]`
- 每个新动作用**新的 `request_id`**；**重试必须复用原 ID 与原内容**；
- 同一 ID 同内容 ⇒ 返回第一次的完整响应，**不重复推进时间**；
- 同一 ID 不同内容 ⇒ **HTTP 409**；
- 结构错误 / 未知字段 / arena / robot 不匹配 **不占用该 ID**，修正后可复用；
- `accepted=false` 时 `virtual_time_s=0`，**不是当前时刻**。

## G4 三个时间轴（本项目最易混）`[自行推导]`
| 时间轴 | 上限 | 推进方式 | 是否进入"平均定位清除时间" |
|---|---|---|---|
| **虚拟时间** | 360000 s（"通常不构成约束"） | 由动作推进 | **是**（分子） |
| **程序运行时间（现实）** | min(1200, 25 min 窗口剩余) | 真实时钟 | 否（但表 1 要报） |
| **25 分钟窗口** | 1500 s | 真实时钟 | 否 |
