# H · 实验方法（本项目实验设计口径）

## H1 对照实验的公平性条款 `[自行推导]`
1. **同一种子集合**逐局对应（本项目用 seed 1…100）；
2. 除被对照的因子外，**代码路径完全一致**；
3. **路程预算一致**（选点对照时统一上限 $\sqrt2\hat d$）；
4. **回退规则与终止判据一致**；
5. **不得只报赢的指标**（移动距离、检测次数、复测轮数、清除失败都要报）。

## H2 统计口径 `[自行推导]`
| 项 | 做法 |
|---|---|
| 集中趋势 | 均值 **+ 中位数** |
| 离散 | 总体标准差、**标准误**、**95% 置信区间**（$t_{0.975,n-1}\cdot s/\sqrt n$） |
| 尾部 | 最小、**P90 / P95 / 最大**（"确保全部清除"是硬前提，最坏局必须单列） |
| 配对比较 | 逐局配对差 + 95% CI + **Bonferroni 校正区间** + **Cohen's d（配对）** + **胜率** |
| 分层 | 按源数 $N$ 分层 |

## H3 三门禁（本项目自定义的放行标准）`[自行推导]`
| 门禁 | 判据 |
|---|---|
| **1 正确性** | 清除比例 = 1.0000 且全清局数 = 全部局数 |
| **2 终止性** | 停滞触发 / 硬上限触发 / 卡死频道 = 0；**最大重复动作次数为个位数量级** |
| **3 性能稳定性** | 相对基线优势的 CI 不含 0 |

## H4 防"看起来跑通了"的三个措施 `[已有实验]`
1. **同种子回归**：修任何缺陷后，必须用**完全相同的种子**重跑，不得换种子；
2. **逐局明细落盘**：不只存聚合值（本项目存 `_work_b26_100.json` 逐局数据）；
3. **运行时缺陷探测器**：在循环里统计"同一 (动作, 频道, 量化位置)"的重复次数，作为活锁的运行时证据。

## H5 已知教训（本项目真实踩过）`[已有实验]`
| # | 教训 | 后果 |
|---|---|---|
| 1 | **8 局全清 ≠ 算法可靠** | 36 局才暴露尾部活锁（最大重复动作 472 次） |
| 2 | **离散化会产生假判空** | 40 m 栅格把 2° 楔形"打空"，导致有源频道被误判为空；20/10 m 才一致 |
| 3 | **"我以为我验过了"的地方最容易出错** | mock 幂等分支从未被真正执行；核对脚本的频道语义写错 |
| 4 | **均值会掩盖尾部** | 修复前 std 81.4 s、最坏局 721 s；修复后 40.6 s / 380.7 s |
