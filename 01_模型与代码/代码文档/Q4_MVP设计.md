## Gate-1：P_cert 是否真的存在？

### 1.1 问题形式化

目标圆域 `D = {P : ‖P‖ ≤ 1800}`（题面「半径为 1800 米的圆形区域」，取**闭**圆盘）【题目明确要求】。要求构造**有限**探测点集 `P_cert`，使得

```
∀P ∈ D, ∀β ∈ [0°,360°), ∃s ∈ P_cert:
      ‖P − s‖ ≤ r_min = 1000      （距离条件）
   ∧  φ(P→s) ∈ [β−90°, β+90°]     （扇区条件，闭区间）
```

- `r_min = 1000` 取题面有效接收半径区间下界（「有效接收半径在 1000 米到 1500 米之间」）【题目明确要求】。用下界 ⇒ 结论是**保证**而非「大概」。
- 扇区**闭**：题面附录 1(3)「定向方向两侧各 90°（**含**）」；附件 2 §2.2「有效覆盖角度范围为 （**包含边界**）」【题目明确要求】。此点同时关闭 `03_MODEL/2026B_赛题分析报告.md` 的待确认问题 Q4。
- 探测点**允许在区域外**：附件 2 §1.1「机器狗可以向模拟器提交目标区域外的位置；模拟器仍会按提交的位置计算移动耗时和检测、清除结果」【题目明确要求】。

### 1.2 本轮可给出的严格结论（【模型推导】，附证明）

**定理 1（精确判据）** 记 `D(P) = { φ(P→s) : s ∈ S_c, ‖P−s‖ ≤ r_min }`（方位角集合，模 360°），则

```
P ∈ E(S_c)  ⟺  D(P) 不被任何开半平面（长度 180° 的开弧）包含
            ⟺  max_gap(D(P)) ≤ 180°
```

其中 max_gap 为把 D(P) 按角度排序后（含首尾环绕）相邻角间隙的最大值。

*证明.* （⇒）若 D(P) 含于某开弧 (a, a+180°)（即被某开半平面包含），则扇区 [β−90°, β+90°] 的**补集**恰是一个长度 180° 的开弧：取 β = a 时补集为 (a+90°, a+270°)，取 β = a+180° 时补集为 (a+270°, a+450°) = (a−90°, a+90°)。由开弧/开半平面的旋转不变性，必存在某个 β 使其补集 ⊇ D(P) ⇒ 该 β 下无探测点可检出 ⇒ P ∉ E。
（⇐）反之若 ∀β 都有可检出探测点，则不存在 β 使其补集包含 D(P)；而所有开半平面都可写成某个扇区的补集 ⇒ D(P) 不被任何开半平面包含。∎

**角度间隙形式（等价）**：D(P) 含于某开弧长 180° ⟺ 排序后存在相邻间隙 > 180°（含首尾环绕间隙）。故 `P ∈ E ⟺ max_gap ≤ 180°`。∎

**定理 2（充分条件 SC，便于设计与快速验证）** 若 D(P) 中存在四个方位角 `θ⁻ ≤ θ⁺ ∈ [−90°, 90°]`（前向）与 `ψ⁻ ≤ ψ⁺ ∈ [90°, 270°]`（后向），且 `ψ⁻ − θ⁺ ≤ 180°` 且 `θ⁻ + 360° − ψ⁺ ≤ 180°`，则 P ∈ E。
*证明.* 排序后四点相邻间隙为 θ⁺−θ⁻、ψ⁻−θ⁺、ψ⁺−ψ⁻、θ⁻+360°−ψ⁺。前两者各 ≤ 180°（两端点各自落在同一条闭半圆内）；后两者由假设 ≤ 180°。其余方位角只会在这些间隙内部插入，不会增大最大间隙 ⇒ max_gap ≤ 180° ⇒ 由定理 1 得 P ∈ E。∎

**推论 2.1（对径充分条件）** 若 D(P) 含两个相差 180° 的方位角，则 max_gap = 180° ⇒ P ∈ E（SC 在 δ_in = δ_out = 0 的退化形式）。

**定理 3（越界探测点的必要性）** 设 `‖P‖ = 1800`。对任意 `s` 满足 `‖s‖ ≤ 1800`：令 `v = s − P`，则 `v·P = s·P − ‖P‖² = 1800·s_x − 1800² = 1800(s_x − 1800) ≤ 1800(‖s‖ − 1800) ≤ 0`。故 `v` 与 `P` 夹角 ≥ 90°，即 `φ(P→s) ∈ [90°, 270°]`；等号仅在 `s = P`（距离 0）时取得。
若全部探测点满足 `‖s‖ ≤ 1800`，且**不把「与源重合」当作可检出**（§7.5 保守规则 A13），则 `D(P) ⊆ (90°, 270°)`，被**开半平面**包含 ⇒ `max_gap > 180°` ⇒ `P ∉ E`。
**故任何 Q4 证书必须包含 `‖s‖ > 1800` 的探测点。** 本命题把项目原「推论 1（探测点必须布到区域之外）」从经验判断提升为**已证定理**。∎

**推论 3.1** 对 `‖P‖ = ρ`，区域内探测点在方位 θ 上可达的最远距离为 `t(θ) = −ρcosθ + √(1800² − ρ²sin²θ)`；前向（cosθ > 0）还要求 `t(θ) ≤ 1000`。当 `ρ → 1800` 时 `t(0) → 0`，前向张角退化为 0°。

它检验的是 **「存在某个朝向 β 使某个探测点能检出」（∃β）**，而 Q4 保证性要求的是 **「任意朝向 β 都存在探测点能检出」（∀β）**——**量词被写反**。由于任一 1000 m 内的探测点都有 180° 宽的 β 区间可使其被检出（区间非空），该函数实际退化为「该点是否被 1000 m 圆盘并集覆盖」（即 Q3 的覆盖条件），**与 Q4 保证性无关**。此外其网格为 **90 m**（`grid=90.`），与文档百分比隐含的分母不一致（1009 点对应 100 m 网格；`N(18)=1009`）。

## 5. 定向源检测模型

**探测域**：固定源 `(g, β, r)`，可检出它的探测点集合 = 以 `g` 为心、半径 `r` 的**半圆盘**，其直边过 `g` 且垂直于 `β`，即 `{s : ‖s−g‖ ≤ r ∧ φ(g→s) ∈ [β−90°, β+90°]}`。【题目明确要求】+【模型推导】

**结构性要点**：直边**必过源点**——这是「信号/无信号的空间分界可反推朝向」的几何基础；但**本 MVP 不使用该反推**（§18 β-free）。

**与清除的接口**：半圆盘只影响「能否发现」，不影响「能否清除」【题目明确要求，附录 2(8)：光学精确定位及清除是否成功仅与距离有关，与有效覆盖角度范围无关】。

**与全向源的唯一差别**：`γ = omni` 时扇区条件恒真 ⇒ 半圆盘退化为整圆盘。这保证了 §11 的退化对标成立。

## 6. no_signal 三义性

**三种成因（题面逐字）**【题目明确要求，附件 2 §2.2】：
1. 该频道没有未清除的源；
2. 距离超过有效接收半径（真值 1000—1500，接口不返回）；
3. 该频道是定向源，但当前位置不在其覆盖角内。

**关键判断（【模型推导】）**：接口**不返回**任何可区分三者的信息（不返回半径、类型、朝向，也不返回失败原因）；且 `near` 亦要求「位于覆盖角内」（附件 2 §2.4）。因此

> **「三义性」在单点上不可消解。任何「换一种测法就能在单点判别」的方案在原理上都不成立。**

**正确结构（强制实现）**：

```
ns → S_c ← S_c ∪ {s} → 重算 E(S_c) → 判 E(S_c) ⊇ D ?
        ├─ 是 → EMPTY_PROVED（可证判空，永久成立，单调性见 §7.6）
        └─ 否 → 继续在 P_cert 的剩余点攒证据
```

**明令禁止的写法**：`if ns: source_not_exist = True`（Q4 头号失分点）。

## 7. E(S) 精确判据

### 7.1 定义

```
D(P)   = { φ(P→s) : s ∈ S_c, ‖P−s‖ ≤ r_min }
E(S_c) = { P ∈ D : ∀β ∈ [0°,360°), ∃s ∈ S_c 使 ‖P−s‖ ≤ r_min ∧ φ(P→s) ∈ [β−90°, β+90°] }
```
含义：**无论朝向取何值，证据集中总有一个探测点能检出 P**。

### 7.2 等价判据（定理 1，已证）

`P ∈ E(S_c) ⟺ max_gap(D(P)) ≤ 180°`，其中 max_gap 为排序后（含首尾环绕）相邻角间隙的最大值。

### 7.3 退化情形逐一讨论

| 情形 | D(P) 形态 | max_gap | 判定 | 处置 |
|---|---|---|---|---|
| **单点** | `{θ}` | 360° | `P ∉ E` | 单个探测点**永远不足以**保证；需其他证据 |
| **两点对径** | `{θ, θ+180°}` | 180° | `P ∈ E` ✅（**临界**） | 判定通过但**零裕量**；设计要求改用带裕量的构型 |
| **两点非对径** | `{θ, θ+δ}`，δ < 180° | 360° − δ > 180° | `P ∉ E` | — |
| **三点及以上** | 任意 | ≤ 180° ⟺ 不落入开半圆 | 按定理 1 | — |
| **共线（去重后仅 1 个方位）** | `{θ}` | 360° | `P ∉ E` | 与单点同 |
| **P 与某探测点重合** | 该点方位**未定义** | — | **不计入** D(P)（A13 保守规则） | 必须显式跳过；**不得**像 `_work_b26_dir.py:12` 那样 `return True` |
| **角度 0°/360° 环绕** | 环绕间隙 | — | 必须用**模 360°** 的间隙 | 排序后取 `(θ_{i+1} − θ_i) mod 360`，末间隙为 `(θ_1 + 360 − θ_k)` |
| **数值误差（间隙恰 180°）** | 临界 | 180° | 判定通过但无裕量 | 设计要求 `max_gap ≤ 180° − γ`（γ = 10° 余量），**禁止依赖临界相等** |

### 7.4 与项目现有三份实现的差异（【代码实际行为】审计）

| 实现 | 文件:行 | 判据 | 与定理 1 的关系 | 处置 |
|---|---|---|---|---|
| `in_hull`（A） | `05_EXPERIMENTS/scripts/_work_b26_dir.py:6–21` | `gap > 180°` 判失败；**但 `d < 1e−9 → return True`**；`len(ds) < 3 → False` | 主体一致；「重合即保证」**乐观**（违反 A13） | **禁止沿用**；其历史百分比全部需重算 |
| `in_hull`（B） | `05_EXPERIMENTS/scripts/_work_b26_qc.py:81–90` | `gap > 180°` 判失败；无重合分支；`len(ds) < 3 → False` | **与定理 1 一致（保守侧）** | 可作为验证器的参考实现 |
| `worst_case_fail` | `05_EXPERIMENTS/scripts/_work_b26_q2.py:64–76` | ∃β 检得即判 `hit` | **量词相反，错误** | **禁止引用**（见 Gate-2） |

### 7.5 保守规则（A13）的正式表述

```
若 ‖P − s‖ < ε_pos（ε_pos = 1e−6 m），则 s 不计入 D(P)。
```
理由：题面未定义「距离为 0 时是否位于覆盖角内」；作为「保证」必须取保守侧。**该规则使 `_work_b26_dir.py` 的历史百分比可能被低估**（移除乐观分支后失败点只会增多）⇒ **历史数字必须重算**。

### 7.6 单调性（引理 1，【模型推导】，已证）

`S ⊆ S′ ⇒ D(P) ⊆ D′(P) ⇒ max_gap 不增 ⇒ E(S) ⊆ E(S′)`。
用途：证据只能「越攒越能排除」，不会因新证据而回退 ⇒ **`EMPTY_PROVED` 一旦成立即永久成立**。

## 8. 凸包充分条件与精确判据的关系

**原项目表述（【已有项目结论】）**：`E(S) = { P : P ∈ int conv(S ∩ B(P, r_min)) }`，并被写成「充要条件」（`03_MODEL/2026B_模型建立与求解报告.md` §5.4(2)；`03_MODEL/2026B_赛题分析报告.md` §5 事实 6）。

**本轮修正（【模型推导】）**：

| 集合 | 定义 | 与 E_true 的关系 |
|---|---|---|
| `E_true` | 方位集不被**开**半平面包含（定理 1） | 精确 |
| `C(S) = {P : P ∈ int conv(S ∩ B(P,r_min))}` | 等价于「方位集不被**闭**半平面包含」 | `C(S) ⊆ E_true`（**充分条件**） |

**包含关系**：`C(S) ⊆ E_true`。二者仅在**临界构型**（方位集恰被一条闭半平面的边界两端夹住，例如两点对径）时不等——此时 `P ∉ int conv(·)` 但 `P ∈ E_true`。

**两种退化**：
- **两点对径**：`conv` 退化为线段，`int conv` 为空 ⇒ 凸包判据判**失败**；精确判据判**通过**。⇒ **精确判据更紧**。
- **全部共线**：同上。

**本稿的最终决定**：
1. **论文与验证器一律使用精确角隙判据（定理 1）**，并如实说明它与凸包条件的包含关系（把原「充要」改为「充分」）；
2. **凸包条件保留为「快速预筛」，且只允许朝保守方向使用**：`C(S)` 判通过 ⇒ 必然 `E_true` 通过（可跳过精算）；`C(S)` 判失败 ⇒ **不得**据此判定失败，必须用精确判据复算；
3. 理由：① 精确判据已证且实现成本极低（排序 + 求最大间隙，O(k log k)，k ≤ 150）；② 预筛在 k 很小时没有性能意义，但保留它可使论文的「从凸包到角隙」叙事连贯；③ **避免把「充分」当「充要」写进论文**。

## 9. P_cert 构造

### 9.1 目标

构造**有限**点集 `P_cert`，使 `∀P ∈ D: max_gap(D(P)) ≤ 180° − γ`（γ 为设计余量，本稿取 **γ = 10°**【模型推导】，须做敏感性）。

### 9.2 几何分解（本稿的核心设计工具，【模型推导】）

设 `P` 在半径 `ρ`、方位 0（旋转可归一化）。对半径 `a` 的环，令

```
κ(a,ρ) = (ρ² + 10⁶ − a²) / (2000ρ)      （两圆相交时 |ρ−a| ≤ 1000 ≤ ρ+a）
θ_sub  = arccos(κ)
```

（几何含义：三角形 (圆心 O, P, 环上交点 s) 在 P 处的内角；由余弦定理直接得到。）则对**连续**环（环上点稠密）：

| 条件 | 环的贡献 |
|---|---|
| `ρ + a ≤ 1000` | 整个环都在 1000 m 内 ⇒ `P` 在环多边形内部 ⇒ 方位覆盖**整圆**，`max_gap = 360°/n` |
| `a < ρ` 且两圆相交 | **背向弧**：`[180° − δ_in, 180° + δ_in]`，`δ_in = θ_sub` |
| `a > ρ` 且两圆相交 | **前向弧**：`[−δ_out, +δ_out]`，`δ_out = 180° − θ_sub` |
| 两圆不相交且 `a > ρ + 1000` | 无贡献 |

**设计规则（由定理 1/2 直接推出）**：对每个 `ρ`，方案需要在半径集中同时具备
- 一个**内环** `a ∈ [max(0, ρ−1000), ρ)`（提供背向弧，且 `δ_in < 90°` 自动成立）；
- 一个**外环** `b ∈ (ρ, ρ+1000]`，且为满足 SC 的 `δ_out ≤ 90°` 需要 `b ≥ √(ρ² + 10⁶)` ⇒ 对 `ρ` 取到 1800 时 **b ≥ 2059 m** ⇒ **外环必须位于区域之外**。

**与定理 3 的一致性**：定理 3 说明边界点必须由越界探测点提供「前向」方位；§9.2 给出其**定量版本**（外环半径下界）。

**离散化效应（必须在验证器中处理）**：环上只有 `n` 个采样点、间距 `2π/n`，因此「弧的两端被填充」需要环的**可测窗口** `2ψ_max ≥ 2·(2π/n)`，其中 `ψ_max = arccos((ρ² + a² − 10⁶)/(2ρa))`。等价地 `ψ_max ≥ 2π/n`（n = 12 时为 30°）。**该条件与相位（各环角度偏移）共同决定成败，须由验证器裁决。**

## 10. P_cert 严格验证算法（设计）

### 10.1 为什么网格不够

**离散网格上的 0% ≠ 连续域上的数学保证**——除非同时给出网格误差的**严格界**。因此验证器必须输出**认证裕量**，而不是只输出「0 例外」。

### 10.2 验证命题

对给定 `P_cert` 与余量 γ：`∀P ∈ D: max_gap(D(P)) ≤ 180° − γ`。

### 10.3 算法（四步）

**步骤 1｜极坐标基础网格**
- 域：`ρ ∈ [0, 1800]` 步长 5 m（361 点）；`α ∈ [0°,360°)` 步长 1°（360 点）⇒ 129 960 点；
- 每点：筛出 `‖P−s‖ ≤ 1000` 的探测点（**排除**距离 `< 1e−6` 的重合点，A13），计算方位并求 max_gap；
- 记录 `margin = 180° − max_gap`；统计 `min margin` 与例外数（margin < 0）。

**步骤 2｜近临界单元自适应细分**
- 对 `margin < 2γ` 的单元递归二分（ρ 与 α 各半分），直到单元尺度 ≤ 0.05 m 或 margin 明显大于该单元的 Lipschitz 界；
- 输出这些单元内的最小 margin、最坏点坐标与最坏朝向。

**步骤 3｜Lipschitz 认证（把网格结果升级为证明）**
- 方位 `θ_s(P)` 的梯度满足 `‖∇θ_s‖ = 1/d_s`（`d_s = ‖P−s‖`）；
- 在步长 `h` 的单元 `U` 内，若所有入选探测点满足 `d_s ≥ d_min`，则
  ```
  max_gap 的变化 ≤ 2 · (h·√2/2) / d_min · (180/π)   度
  ```
  （系数 2 来自最大间隙的两端各移动一次）；
- 探测点**进出 1000 m 圆**造成的集合变化同样被同一界覆盖（进出发生在边界 `d_s = 1000`，方位连续）；
- **认证条件**：`min margin > 2·(h·√2/2)/d_min·(180/π)` ⇒ 网格结果即为连续域上的**证明**；
- `d_min` 的取值：单元内所有入选探测点到 `P` 的最小距离。**对落在探测点邻域的单元必须单独处理**：更细网格（≤0.05 m）并排除该探测点，再用同一界（此时 `d_min` 由次近探测点决定）。

**步骤 4｜输出（强制字段）**

| 字段 | 含义 |
|---|---|
| `P_cert` 生成规则与坐标 | 环半径、每环点数、相位 |
| 点数 | 总数与分环数 |
| 最大不可保证区域 | 有例外时给出测度估计与样例点；无例外时填「未见」 |
| 最坏位置 P* | `argmin margin` 的 (ρ, α) |
| 最坏朝向 β* | 由 P* 的方位集反解：取最大间隙的角平分线方向 + 180° |
| 验证步长 | 基础步长与细分后的最小步长 |
| 认证裕量 | `min margin − Lipschitz 界`（> 0 才算认证通过） |
| 是否达到 0% | **认证通过 / 未认证**（不得只报「网格 0 例外」） |

### 10.4 验收判据

| 项 | 判据 |
|---|---|
| 硬判据 | 基础网格例外数 = 0 **且** 认证裕量 > 0 |
| 设计余量 | 全程 `margin ≥ γ = 10°`（吸收数值与相位效应） |
| 失败处置 | 未认证 ⇒ Gate-1 FAIL ⇒ **禁止编码控制器**，回炉改 §9.3 候选族 |

## 11. Q3 → Q4 退化证明

### 11.1 算子退化（C-1 的理论依据，【模型推导】，已证）

令扇区退化为全圆，则对任意 β，`φ(P→s) ∈ [β−90°, β+90°]` 恒成立（条件变为整圆）。于是

```
E_Q4(S) = { P : ∀β ∃s∈S 使 ‖P−s‖ ≤ r_min 且 φ(P→s) ∈ [β−90°,β+90°] }
        = { P : ∃s∈S 使 ‖P−s‖ ≤ r_min }        （∀β 成为空条件）
        = ∪_{s∈S} B(s, r_min)                    ∎
```

即 **Q4 判空算子在「全圆」极限下逐点等于 Q3 的圆盘并集条件**。C-1 的数值检验（≤5 m 网格逐点比较）检验的是该恒等式的**实现正确性**，而非理论本身。

### 11.2 证书退化（C-2）

`COVER_9` 满足 Q3 条件 `max_D min_s ‖P−s‖ ≤ 1000`；Q4 证书模块在全圆模式下应复现同一证书值。
**注意**：Q4 的 `P_cert` **不是** `COVER_9` 的超集（§9.2：外环在区域外、半径更大），因此 Q4 证书条件**严格强于** Q3 覆盖条件；C-2 只是**模块自洽性**检验（同一段代码在全圆模式下必须退化为 Q3 的算法）。

### 11.3 行为退化（C-3 / C-4 / C-5）

## 12. Q4 状态机

```

                                   ├── DC    ──► LOCATE ──► (REFINE ⇄ LOCATE) ──► CLEAR_DECIDE
                                   ├── NEAR  ──► CLEAR_NOW（原地 /clear，必成）
                                   └── NS    ──► UPDATE_E ──► EMPTY_PROVED ?

                                                                        ├─ YES ─► CERT_SCAN
                                                                        └─ NO  ─► FALLBACK
FALLBACK: ① 有界复测 → ② 有界清除尝试 → ③ F_c 铺网清除（可证命中） → ④ 换未用过的证书点复测 → ⑤ STALL → 退出
CLEAR_DECIDE: diam(F_c) ≤ 40 m ? → /clear(centroid) → 失败则 F_c 铺网 → 成功 ⇒ CHANNEL_DONE
```

| 状态 | 进入条件 | 动作 | 退出条件 |
|---|---|---|---|
| `INIT` | — | `/enter`；读 `remaining_real_duration_s` | 成功 |
| `CERT_SCAN` | 存在未解决频道且 `P_cert` 尚有未访问点 | 由 §17 调度选出下一个证书点 | 选点完成 |
| `MEASURE` | 到达点 | 对每个「仍需证据」的频道依次 `/measure`（串行、新 `request_id`） | 全部返回 |
| `CLASSIFY` | 有响应 | 三态分派 | 分派完成 |
| `UPDATE_E` | `ns` | `S_c ← S_c ∪ {s}`；重算 `E(S_c)` | 重算完成 |
| `EMPTY_PROVED` | `E(S_c) ⊇ D` | 标记判空；退出该频道一切后续探测 | — |
| `MORE_CERT` | `E(S_c) ⊉ D` 且 `P_cert` 有剩余点 | 回到 `CERT_SCAN` | — |
| `LOCATE` | 收到 `dc` | `F_c ← F_c ∩ W(s,θ̂,1°) ∩ D ∩ B(s,1500)` | `diam(F_c) ≤ 40` 或有界复测计数到限 |

| `CLEAR_DECIDE` | `diam(F_c) ≤ 40` | `/clear(centroid(F_c))` | 成功 / 失败 |
| `FALLBACK` | 复测或清除连续失败、或 `F_c` 无法收缩 | §15 兜底链 | 成功 或 记入 `stuck` |
| `CHANNEL_DONE` | 已清除 或 已判空 | 退出该频道 | — |
| `STALL` | 进度签名连续 `S` 步不变 | 强制换点；无点可换 ⇒ 记录并退出 | — |

**为什么是 40 m（清除门槛）与其审计修正**：清除半径 `ℓ_clr = 20` m。若 `diam(F_c) ≤ 2·ℓ_clr = 40` m，则**存在**某点距源 ≤ 20 m ⇒ 一次清除**可能**成功。

> **⚠️ 审计修正（【模型推导】，重要）**：`diam ≤ 40` **不保证「取质心一次必成」**。严格结论是：
> - 由 **Jung 定理**，直径 `D` 的平面点集可被半径 `≤ D/√3` 的圆覆盖；且**凸集的最小覆盖圆圆心必属于该凸集**（由 2—3 个边界点的凸组合给出，凸性保证其在内）⇒ `D ≤ 20√3 ≈ 34.6` m 时，**取最小覆盖圆圆心**一次清除**必成**；
> - 质心的界不等于 `D/2`：例如边长 40 m 的等边三角形，质心到顶点 23.1 m > 20 m ⇒ **可能失败**；
> - 【项目已有实验事实】G 臂 100 局共 `清除失败合计 = 22`（`05_EXPERIMENTS/results/_work_b26_100.json`），与「40 m + 质心是工程口径而非定理」的判断一致；
> - **Q4 MVP 处置**：① 保留「40 m ⇒ 先试质心」（与 Q3 行为一致，便于对照）；② **失败后立即执行 §15.2③ 的 F_c 铺网清除**（可证命中）；③ 论文中把 40 m 写成「清除门槛（工程口径）」，把 34.6 m + 最小覆盖圆圆心写成「严格门槛」，**不得**再把「40 m ⇒ 一次必成」当定理。

**代价**：放弃了「用通/不通分界反推朝向以加速探测」的潜在收益（列为非 MVP 优化方向，需先有模型依据与实验）。
