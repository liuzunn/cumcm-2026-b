## 1. 创新点 I-1（方向 1 · 算法改进）

### ① 原模型是什么
- **名称与出处**：阶段二 **L1-A/L1-C 合并方案**（"离散覆盖点 + 连成轨迹"）+ **L2-A**（滚动时域决策）。
- **数学形式**：先离线解覆盖问题 min k s.t. ∪ᵢ B(sᵢ, 1000) ⊇ D(0,1800)（本报告族内可行解 k = 7，@_work_b26_cover.py@），得到固定点集；执行时按固定顺序走完 7 点并逐点扫描全部未解决频道；清除阶段再由 L2-A 在线决定目标顺序。
- **阶段二编号与得分**：L1-C 5.00 / L1-A 4.90（合并，触发简单性条款）；L2-A 4.70。

### ② 原模型存在什么问题
- **具体困难（含量化）**：**移动代价被付了两次**。
  - 覆盖路线：7 点（半径 1000 m 圆周三等分位 + 圆心）的访问路径 ≈ 1000 + 6×867.8 = **6207 m ≈ 1241 s**（@_work_b26_cover.py@ 的族内可行解）；
  - 清除路线：10—16 个目标的遍历下界 **7183—9086 m ≈ 1437—1817 s**（阶段一 §5 事实 5）；
  - 两条路线**互不知情**，合计 **13390—15293 m**，而其中相当一部分是同一片区域的重复穿越。
  - 扫描开销另计：7 点 × 20 频道 ×（5 + 1）s = **833 s**（阶段一 §5 事实 4）。
- **证据**：阶段一 §5 事实 4/5（自算）+ 阶段二 L1 对比表"平凡基线对照"行。
- **为什么调参解决不了**：调整 k（覆盖点数）只改变点数，不改变"**覆盖路线与清除路线是两条独立的路线**"这一结构；k 从 7 降到 6 在本报告的族内搜索里已不可行（@_work_b26_cover.py@），k 增到 8 只会让重复穿越更多。

### ③ 本文如何改进
- **结构性改动**：把保证条件从"**预先存在的点集**"换成"**执行过程中不断收缩的覆盖缺口**"，从而把"覆盖"从一条**独立路线**降级为一个**硬约束**：
  - 定义**覆盖缺口** G(t) = D(0,1800) \ ∪_{s ∈ 已采样点} B(s, 1000)（尚未被任何一次检测覆盖过的区域）；
  - **硬约束**：终止时必须有 G = ∅（否则"确保全部清除"不成立）；
  - 在满足该硬约束的前提下，路线的顺序与走向**完全自由**，由在线决策层与"顺路性"共同决定。
- **接口变化**：
  - 输入：原方案需要"离线算好的固定点序"；新方案只需要"缺口集 G"，它在每次检测后自动更新；
  - 输出：原方案输出一条固定路线；新方案输出一个**以必做集合为约束的在线动作序列**。

### ④ 数学表达是什么
- **符号**：p 为机器狗当前位置（m）；G ⊆ ℝ² 为覆盖缺口（m²）；K 为已清除频道集合；U 为未解决频道集合；τ(p→q) = ‖p−q‖/5 为移动时间（s，虚拟）。
- **硬约束**（保证性）：
  `G(t_end) = ∅  ∧  ∀c ∈ U : B_c(t_end) = ∅`
- **目标**（在硬约束下的最小化）：
  `min  T_total = Σ τ(p_k → p_{k+1})  +  Σ_{停点} [ 5·|U| + (|U| − 1) ]  +  5·|K|`
- **决策**（与 L2-A 衔接）：
  `a* = argmin_{a ∈ M(t)} [ τ(p → p_a) + Ĉ(p_a, G', {B_c'} ) ]`
  其中**必做集合** M(t) = { 到 G 中某点采样 } ∪ { 清除 B_c 直径 ≤ 40 m 的频道 } ∪ { 复测未达标频道 }；Ĉ 为剩余成本的启发式估计。
- **可证性质（写进论文的关键）**：任何满足 G(t_end) = ∅ 的动作序列都是**合法保证序列**，因此新方案在所有合法序列中择优，其可行域**严格包含**"先走完固定覆盖路线再清除"这一子类 ⇒ 最优值不会变差。
- **复杂度**：状态含 G（用栅格或圆盘并集表示）与 {B_c}；每步在 |M(t)| 个必做动作中取最近者，O(|M|)；栅格分辨率 50 m 时 G 的更新 O(N_cells)，毫秒级。

### ⑤ 改进后解决了什么问题
- **对应 ② 的哪一个困难**："移动代价付两次"这一条（一一对应）。
- **量化增益**：
  - **基线**（固定覆盖路线 + 事后 TSP）：13390—15293 m 移动 + 833 s 扫描 + 364 s 定位动作 + 65 s 清除 ≈ **3940—4320 s**；
  - **目标**（缺口驱动自适应）：移动 9500—10500 m ⇒ ≈ **3200—3700 s**；
  - 「移动距离从 13390—15293 m 变到 9500—10500 m（来源：基线为阶段一 §5 事实 4/5 的自算和下界；目标为设计目标，**【待实测】**）」。
- **理论下界与达成率**：移动距离的**不可压缩下界** = max(覆盖所需位移, 目标遍历下界) = max(6207, 7183) = **7183 m**（n=10）到 **9086 m**（n=16）。按目标的 9500—10500 m 计算，**达成率 = 7183/9500 ≈ 76% 至 9086/10500 ≈ 87%**。

### ⑥ 如何通过实验验证创新有效
- **对照实验**：A 组 = 固定覆盖路线 + 事后最近邻 TSP（阶段二原样）；B 组 = 缺口驱动自适应。同一批演练案例（固定源数 10/13/16 各 10 组），指标 = 虚拟时间、移动距离、清除比例。
- **消融实验**：把"缺口驱动"关掉（G 在开局一次性算完并固定路线），其余（L2-A 打分、L3 定位子程序）完全不变 ⇒ 两组位移差即为本创新点的净增益。**【待实测】**
- **独立验证**：用**两条原理不同的路径**复核——① 解析下界 max(覆盖位移, 遍历下界) 与实测位移比，报达成率；② 用"覆盖位移"与"遍历位移"的**重叠面积**（用栅格统计两条路线的 1000 m 邻域交集）独立估计可省位移，与实测节省量对照。
- **边界实验**：当 N 很小且源集中在区域中心时，遍历下界远小于覆盖位移，增益趋近 0；给出"**增益 > 5% 的源数阈值**"（预期在 N ≥ 12 时显著）。
- **可复现性**：演练测试的随机种子由模拟器决定、不可控 ⇒ 采用**同一批案例对照**（同一局演练分别跑 A/B 两组），并另用自建离线仿真固定种子做 30 次重复，报均值 ± 标准差。

### 四句式小结
- **困难句**：原方案把覆盖路线与清除路线当成两条独立路线，7 点覆盖行程 6207 m，10—16 目标的遍历下界 7183—9086 m，合计 13390 m 以上，其中相当部分是同一片区域的重复穿越。
- **动作句**：把"预先存在的覆盖点集"换成"执行中不断收缩的覆盖缺口 G"，把覆盖从一条独立路线降级为一个硬约束 G(t_end) = ∅，路线顺序完全交给在线决策。
- **增益句**：移动距离由 13390—15293 m 降到设计目标 9500—10500 m（**达成率 76%—87%**），对应总虚拟时间由 3940—4320 s 降到 3200—3700 s（**【待实测】**）。
- **边界句**：当源数 N 偏小（10 个）且集中分布时，遍历下界小于覆盖位移，增益趋近 0；该创新点只在 N ≥ 12 且分布分散时显著。

## 2. 创新点 I-2（方向 2 · 跨领域模型迁移）

### ① 原模型是什么
- **名称与出处**：阶段二 **L2-C 静态优先级规则**（"未测频道优先" / "最近优先" / "最坏优先"），作为 L2-A 的对照准则。
- **数学形式**：给定固定的优先级键值（如"该频道被探测次数最少"或"该频道最近一次检出点距离最近"），对全部未解决频道排序，取队首。
- **阶段二编号与得分**：L2-C 4.30（被选为对照，未选定）。

### ② 原模型存在什么问题
- **具体困难（含量化）**：**没有"额度"概念**。20 个频道里**至少 4 个是空的**（阶段一 §5 计数事实：20 频道、每频道至多 1 源、源数 10—16），但固定规则无法区分三种"测不到"：
  1. 该频道真的为空；
  2. 该频道有源但尚未进入有效接收半径（半径 1000—1500 m，**接口不返回**，附件 2 §2.1）；
  3. （Q4）该频道是定向源且当前不在覆盖角内。
  在 7 点覆盖扫描下，一个空频道会被**完整扫 7 次**，代价 7×6 = 42 s；至少 4 个空频道 ⇒ **≥168 s 的纯浪费**；Q4 下这个数字还要翻倍（探测点更多）。
- **证据**：阶段一 §5 事实 4/5（自算）；阶段二 L2 对比表"数据需求"与"创新空间"两行。
- **为什么调参解决不了**：优先级键值是**固定的函数形式**，把"被探测次数"换成"最近距离"只改变了排序依据，不改变"每次探测都是全价、且不区分信息价值"这一结构。

### ③ 本文如何改进
- **结构性改动**：把"下一个探测投给哪个频道"形式化为**有限预算下的额度分配问题**，并迁移**多臂老虎机（multi-armed bandit）指数策略的结构**：
  - 臂 = 频道 c；
  - 拉动 = 在位置 s 对频道 c 做一次 `/measure`；
  - 回报 = 可行域 B_c 的收缩量（用面积或直径衡量）；
  - **指数形式** = 期望收益/成本 + 探索奖励。
- **迁移的诚实说明（准入条件要求）**：
  - **迁移了什么结构**：①"用指数给臂排序"这一决策结构；②"期望收益 ÷ 成本"的性价比形式；③"不确定性越大越值得探索"的探索奖励项。
  - **丢掉了什么**：**丢掉了"回报独立同分布"这一 bandit 的核心假设**。本题的回报是**确定性的、路径依赖的**（同一个点在同一天线朝向下重复检测得到同一个读数，题面附录 2(1)），且成本随机器狗位置变化。
  - **为什么丢掉的部分在本题不重要**：bandit 的遗憾界（regret bound）在 i.i.d. 假设下才有意义；本题不需要遗憾界（我们要的是保证性与总时间下界），只需要一个**可解释、可消融的排序准则**。因此把 β 从"统计置信度的系数"改释为"**探索强度的可调参数**"，并对其做敏感性——这样既保留了迁移的结构，又不引入站不住的统计假设。

### ④ 数学表达是什么
- **符号**：c ∈ {1..20}；n_c 为对频道 c 的探测次数；A_c 为"若在最有价值的位置再探一次 c"可望收缩的可行域面积（m²）；τ_c 为到达该位置所需移动时间（s）；β ≥ 0 为探索强度。
- **指数**：
  `index_c = [ A_c / (τ_c + 6) ] · ( 1 + β · √( ln(T+1) / (n_c+1) ) )`
  其中 T = Σ_c n_c 为总探测次数，6 s = 5 s 检测 + 1 s 切换。
- **与"原模型"的逐项对应**：
  - **新增**：A_c（可行域可收缩面积）项 —— 原模型没有；
  - **新增**：探索奖励因子 √(ln(T+1)/(n_c+1)) —— 原模型没有；
  - **替换**：原模型的"固定优先级键值" → 被替换为"性价比 × 探索奖励"；
  - **删除**：原模型里"必须按固定顺序轮询 20 个频道"的隐含约束 —— 被删除（探测顺序本身成为决策变量）。
- **退化性质（可消融）**：β = 0 时退化为"纯利用"（只探最有价值的频道，容易饿死其他频道）；β → ∞ 时退化为"轮询"（等价于原模型）。**两端都有已知行为，使消融实验有明确锚点**。
- **复杂度**：每次决策对 20 个频道计算指数，O(20)；A_c 由可行域栅格统计给出，O(N_cells)，毫秒级。

### ⑤ 改进后解决了什么问题
- **对应 ② 的哪一个困难**："空频道被反复全额付费"这一条（一一对应）。
- **量化增益**：「单个空频道的探测次数由 ≤7 次降到 ≤3 次（判据：当 index_c 降到当前必做动作指数的 1/3 以下时冻结该频道），4 个空频道合计节省 ≥ 4×4×6 = 96 s（来源：阶段一 §5 事实 4 的扫描代价模型）」；综合估计**节省 100—200 s**（占扫描开销 833 s 的 12%—24%）**【待实测】**。
- **增益上界**：若能在"刚好判定"的探测次数上停止，理论最优 = 每频道 2—3 次探测 ⇒ 扫描开销可由 833 s 降到约 400 s，即**最多可省 430 s**。

### ⑥ 如何通过实验验证创新有效
- **对照实验**：A 组 = 静态"未测频道优先"；B 组 = 静态"最近优先"；C 组 = 本指数策略。同批演练案例（每种源数 10 组，共 30 组），指标 = 总探测次数、扫描开销（s）、总虚拟时间。
- **消融实验**：β ∈ {0, 0.5, 1, 2, ∞} 五档扫描，报"探测次数—β"曲线；去掉 A_c 项（只按探测次数均衡）作为第二重消融。**【待实测】**
- **独立验证**：离线计算**事后最优额度**（已知真值时，每个频道只需探到"刚好判定"为止的探测次数之和），把实测探测次数与它相减得到**遗憾值**，报遗憾率。这是与被测对象**原理不同**的一条路径。
- **边界实验**：当所有 20 个频道都有源且分布均匀时，各频道指数接近，策略退化为轮询 ⇒ 增益趋近 0；给出"**空频道数 ≥ 4 时增益 > 5%**"这一阈值，并与题面的"源数 10—16 ⇒ 空频道 4—10 个"对应。
- **可复现性**：β 与冻结阈值固定写死在配置中；自建离线仿真的随机种子固定并写入论文附录。

### 四句式小结
- **困难句**：20 个频道里至少 4 个是空的，但静态优先级规则无法区分"空频道"与"有源但暂时测不到"，导致空频道在 7 点覆盖下被完整扫 7 次，至少 4×42 = 168 s 是纯浪费。
- **动作句**：把"下一个探测投给哪个频道"形式化为有限预算下的额度分配，迁移额度分配（多臂老虎机）指数策略的结构——性价比 × 探索奖励；并明确弃用其"回报独立同分布"假设，把探索系数改释为可标定参数并做敏感性。
- **增益句**：空频道探测次数由 ≤7 次降到 ≤3 次，扫描开销节省 100—200 s（占 833 s 的 12%—24%）；相对事后最优额度的遗憾率作为独立指标**【待实测】**。
- **边界句**：当 20 个频道全有源（题面不允许，源数上限 16）或各频道指数接近时，策略退化为轮询，增益趋近 0。

## 3. 创新点 I-3（方向 3 · 多模型融合）

### ① 原模型是什么
- **名称与出处**：阶段二选定方案里的**三套并行口径**：
  1. **区域口径**（Q1/Q2，L3）：定位区域 = 多个"示向度 ±1° 楔形"之交，用**直径**度量精度；
  2. **点集口径**（L1）：判空 = 用半径 1000 m 的判别圆**覆盖**整个圆域（Q3），Q4 下升级为"凸包包含"条件；
  3. **计数口径**（L4）：终止 = 20 个频道状态机的计数（已清除 + 已判空 = 20，或已清除 = 16）。
- **数学形式**：三者分别是"集合交"、"覆盖判定"、"整数计数"，**互不引用**。

### ② 原模型存在什么问题
- **具体困难（含量化）**：
  1. **Q4 下 L1 的判空条件直接失效**：阶段一 §5 事实 6 的数值实验显示，仅在区域内布"6@1700 + 6@700"两环时，**60.3%** 的采样点无法保证任意朝向可检出（@_work_b26_dir.py@）⇒ 必须另起一套"凸包包含"条件。结果是论文里出现**两套互不解释的保证性论证**，评阅人无法判断它们的关系。
  2. **三口径之间无法传递信息**：一次 `direction` 读数在 L3 里被用于缩小定位区域，但 L1 的覆盖层不知道"这个频道已经被定位到很近"，L4 的计数层也不知道"这个频道的可行域已经很小"。最直接的实现会把**已经检出的频道继续按"未解决频道"参与覆盖扫描**——Q4 下这意味着对约 10—13 个已检出频道多付 **（20—40 − 2~4）× 6 s ≈ 100—220 s/频道**。
  3. **终止判据不自洽**："已判空"在 Q3 里指"覆盖过没测到"，在 Q4 里指"凸包条件下没测到"——同一个词两种含义。
- **证据**：阶段一 §5 事实 6（自算 + @_work_b26_dir.py@）；阶段二 L1/L4 对比表的"适用性"行。
- **为什么调参解决不了**：这是三个模块**各自独立定义**造成的，不是参数取值问题；把 1000 m 改成 1300 m、把点数从 7 增加到 20，都不会让三个口径互相解释。

### ③ 本文如何改进
- **结构性改动**：引入**唯一的状态对象——可行域账本** {B_c}，B_c ⊆ D(0,1800) 表示"频道 c 的干扰源还可能在哪里"。**所有模块只读写这一个对象**，不再各自维护口径：
  - **几何定位**（L3）变成 B_c 的一次**集合交**；
  - **判空**（L1）变成 B_c 的**集合差**；
  - **终止**（L4）变成 **∀c: B_c = ∅**；
  - **Q3 与 Q4 的差别**只体现在"集合差"算子的**定义**上（见 ④），不再体现为两套独立条件。
- **接口变化**：
  - 输入：三个模块原先各自接收不同的中间量（楔形集合 / 探测点集 / 状态计数）；现在统一接收与输出 {B_c}；
  - 输出：终止判据由"计数"变为"全部可行域为空"。

### ④ 数学表达是什么
- **符号**：D(0,1800) 为目标圆域（m²）；B(s, ρ) 为以 s 为心、ρ 为半径的圆盘；W(s, θ, Δ) 为顶点在 s、中轴方位 θ、半角 Δ 的楔形；S_c 为频道 c 已完成的探测点集合；β 为定向源的朝向（°）；sector(β) = [β−90°, β+90°]。
- **状态**：{B_c}_{c=1..20}，初值 B_c = D(0,1800)。
- **三个更新算子**：
  1. `/measure` 返回 `direction` θ：`B_c ← B_c ∩ W(s, θ, 1°) ∩ D(0,1800) ∩ B(s, 1500)`
     （1500 m 为有效接收半径的上界；交集里也可以改用保守下界 1000 m，见"边界实验"）
  2. `/measure` 返回 `no_signal`：`B_c ← B_c \ E(S_c)`
  3. `/clear` 返回 `success`：`B_c ← ∅`
- **可排除集 E(S) 的定义（本创新点的核心）**：
  `E(S) = { P ∈ D(0,1800) : ∀β ∈ [0°,360°) , ∃ s ∈ S 使得 |P − s| ≤ 1000 且 dir(P → s) ∈ sector(β) }`
  即"**无论朝向取何值，证据集 S 中总有一个探测点能检出它**"的点集 —— 这些点不可能是该频道的源。
- **两条可证引理（写进论文的关键）**：
  - **引理 1（单调性）**：B_c 随证据增加单调不增；E(S) 随 S 单调不减。
  - **引理 2（Q4 条件的推导）**：E(S) = { P : P ∈ int( conv( S ∩ B(P,1000) ) ) }。
    *证明要点*：各探测点相对 P 的方位落在某个开半平面内 ⟺ 取该半平面的法向作为 β 即可构造反例；反之若方位不被任何开半平面包含，则任何闭半平面（= sector(β)）都至少含一个方位。∎
    —— **阶段一 §5 事实 6 的"凸包充要条件"由此成为框架的推论，而不是一条外加假设。**
- **退化对标（准入条件要求的"零成本自检"）**：令朝向集合退化为整个圆周（即全向源），则"∀β"变为空条件，E(S) 退化为 ∪_{s∈S} B(s,1000) —— **框架自动复现 Q3 的圆盘覆盖条件**，且应逐点复现 @_work_b26_cover.py@ 求得的 7 点解。
- **复杂度**：B_c 用半径 25 m 的栅格位图表示，则每个圆域约 (1800/25)²×π ≈ 16300 格；一次 ∩ 或 \ 更新为 O(格数)，毫秒级；20 个频道的账本内存约 2 MB（位图），可接受。

### ⑤ 改进后解决了什么问题
- **对应 ② 的哪一个困难**：三条一一对应 ——
  ① "Q4 必须有第二套独立条件" → 由引理 2 推导得出，不再是外加假设；
  ② "三口径无法传递信息" → 统一为 {B_c} 后，已检出频道自动转入定位流程，不再参与昂贵的覆盖/凸包扫描；
  ③ "终止判据不自洽" → 统一为 ∀c: B_c = ∅。
- **量化增益**：
  - **可证明性收益（无争议）**：论文中"保证性论证"由两套并列变为"一个框架 + 一次退化对标"；
  - **时间收益（实现相关，必须如实说明）**：若原方案的覆盖扫描对**全部未解决频道**一视同仁（最直接的实现方式），则 Q4 下对约 10—13 个已检出频道多付 (25 − 3) × 6 ≈ 132 s/频道，合计 **约 1300—1700 s**；若原方案实现时已显式区分"已检出/未检出"，则时间收益接近 0，只剩可证明性收益。**「该差值从 __ 变到 __（来源：按 25 个凸包探测点的代价模型估算，【待实测】）」**
- **增益上界**：Q4 下的扫描代价下界 = （从未检出的频道数）×（凸包覆盖所需点数）× 6 s ≈ 10 × 25 × 6 = 1500 s；框架保证不会超出该下界。

### ⑥ 如何通过实验验证创新有效
- **独立验证之一（退化对标，零成本）**：把 sector 设为全圆（全向），用同一段代码跑 @_work_b26_cover.py@ 的算例，**必须逐点复现** 7 点覆盖解（面积下界 4、族内最小 7）。若不能复现，说明框架实现有误。
- **对照实验**：A 组 = 三套口径各自实现（原方案）；B 组 = 统一账本。Q3 与 Q4 各跑 10 组演练，指标 = 总探测次数、总虚拟时间、**"已检出频道被额外扫描的次数"**（这是一个直接度量"口径不通"造成的浪费的指标）。
- **消融实验**：关掉"已检出频道退出覆盖扫描"这一条（即强制所有未清除频道都参与覆盖扫描），其余不变 ⇒ 时间差即为信息传递带来的净增益。**【待实测】**
- **边界实验**：把算子 1 中的 1500 m 上界换成保守的 1000 m 下界，会使 B_c 收缩变慢、探测次数上升；给出"**保守度（用 1000 还是 1500）与探测次数**"的曲线，找出结论翻转的阈值。同时给出"若实测发现有效接收半径确实 ≥1300 m，可放宽到 1300"的判据。
- **可复现性**：账本用位图实现，无随机性；离线仿真固定种子。

### 四句式小结
- **困难句**：现阶段定位用"区域"、判空用"点集"、终止用"计数"三套口径互不引用，导致 Q4 必须另起一套凸包条件（区域内布点时 60.3% 的采样点无法保证），且已检出的频道仍被当成"未解决频道"重复扫描。
- **动作句**：引入唯一状态对象"可行域账本"{B_c}，把定位、判空、终止分别重写为集合的**交、差、空判定**；并用一条引理把 Q4 的凸包条件从框架中**推导**出来。
- **增益句**：论文层面把两套保证性论证合并为"一个框架 + 一次退化对标"；实现层面在 Q4 下可减少约 1300—1700 s 的重复扫描（实现相关，**【待实测】**）。
- **边界句**：若原方案实现时已显式区分"已检出/未检出"频道，则时间收益接近 0，仅剩可证明性收益；若算子中的接收半径上界取得过松（1500 m），在半径真值偏小时会漏判，故必须保留"用 1000 m 下界"的保守开关并做边界实验。

## 4. 创新点 I-4（方向 4 · 自适应参数 / 动态权重）

### ① 原模型是什么
- **名称与出处**：阶段二 **L2-A 滚动时域 + 多准则打分**。
- **数学形式**：`J(a) = 期望信息增益(a) − λ · 移动时间(a) + μ · 清除确定性(a)`，取 a* = argmax J(a)；λ、μ 为**人为设定的权重**。
- **阶段二编号与得分**：L2-A 4.70（选定）。

### ② 原模型存在什么问题
- **具体困难（含量化）**：
  1. **权重不可自证**：λ、μ 是人为自由参数。知识库明确指出"**人为调参一旦进入目标函数就无法自证**"（@07_优秀论文逆向分析/02_…@ 第 1967 行）。
  2. **固定权重在两个阶段必然冲突**：探索期（多数频道未解决、缺口集 G 很大）需要一个小的 λ（敢走）；收割期（缺口集很小、只剩 1—2 个频道）需要一个大 λ（省移动）。**但收割期一旦 λ 过大，就可能出现"为了省移动而不去补扫最后一个缺口"** —— 这直接违反"确保全部清除"这一硬前提。这是一个**可以量化的致命风险**：缺口未清空 ⇒ 该次测试的清除比例必然小于 1。
  3. **无临界点概念**：原模型说不出"从第几秒起必须停止探索"，因而无法在墙钟不足时给出可执行的降级方案。
- **证据**：阶段二 L2 对比表"稳定性（4 分，需固定候选集与权重）"与"创新空间"行；知识库 N04 第 1967、1928 行。
- **为什么调参解决不了**：λ 是**一个标量**，它只能表达一种"移动 vs 信息"的偏好；而本题需要的是**随剩余时间自动切换的偏好**——这是函数与常数的差别，不是取值问题。

### ③ 本文如何改进
- **结构性改动（两步，且**减少**自由参数）**：
  1. **把"必须保证"从目标函数的惩罚项提升为硬约束**：缺口集清空（G = ∅）与全部可行域清空（∀c: B_c = ∅）写成**必做集合 M(t)**；凡属 M(t) 的动作**不需要打分**，直接执行（取最近者）。
  2. **把 λ、μ 删除**，只保留**一个**可标定的缓冲量 δ：只有在"剩余时间充裕"时才允许执行**可选动作**（即 I-2 的指数探测），判据为
     `T_remain − T_need(t) ≥ δ`
     其中 T_remain 为 `/enter` 返回的剩余现实时间（s）；T_need(t) 为完成剩余必做集合所需的估计**现实**时间（由已跑案例的实测行程时间外推）；δ 为安全缓冲（s）。
- **接口变化**：原方案输出"打分最高的动作"；新方案先输出"必做集合中最近的动作"，只有在时间充裕时才把可选动作纳入候选。
- **自由参数计数**：原方案 {λ, μ} = **2 个**；新方案 {δ} = **1 个**，且 δ 有明确的统计含义（"留出多少缓冲才敢做非必要动作"），可由演练实测的行程时间标准差标定 ⇒ **满足准入条件"减少人为自由参数"**。

### ④ 数学表达是什么
- **符号**：p 为当前位置（m）；M(t) 为必做集合；O(t) 为可选动作集合；τ(p→q) = ‖p−q‖/5（s，虚拟）；T_rem 为剩余程序运行时间（s，现实）；T_need 为剩余必做工作的估计现实时间（s）；δ ≥ 0 为安全缓冲（s）。
- **必做集合**：
  `M(t) = { 对 G 中某点采样 } ∪ { 清除 B_c 直径 ≤ 40 m 的频道 } ∪ { 复测 B_c 尚未达标的频道 }`
- **决策规则（分层，无权重）**：
  `a*(t) = argmin_{a ∈ M(t)} τ(p → p_a)`                （M(t) ≠ ∅ 时）
  `a*(t) = argmax_{c} index_c(t)`                        （M(t) = ∅ 且 T_rem − T_need ≥ δ 时）
  `a*(t) = /exit`                                        （否则）
- **与"原模型"的逐项对应**：
  - **删除**：λ·移动时间 项、μ·清除确定性 项（连同 λ、μ 两个参数）；
  - **新增**：硬约束 M(t)（把"必须保证"从软惩罚变成硬约束）、缓冲判据 T_rem − T_need ≥ δ；
  - **保留**：期望信息增益项 —— 但它只在可选动作之间比较，不再与必做动作竞争。
- **切换时刻（显式表达）**：`t_switch = T_total − T_need(t) − δ`；t > t_switch 时只执行必做动作。
- **复杂度**：M(t) 规模为 O(|G| + 20)，取最近者为 O(|M|)；毫秒级。

### ⑤ 改进后解决了什么问题
- **对应 ② 的哪一个困难**：一一对应 ——
  ① "权重不可自证" → λ、μ 被删除，自由参数降为 1 个；
  ② "收割期可能漏扫缺口" → 缺口采样属于**硬约束必做集合**，任何权重都无法把它挤掉，**该风险被结构性消除**；
  ③ "无临界点" → 给出 t_switch 的显式表达。
- **量化增益**：「清除比例：固定 λ 扫描（λ ∈ {0.1, 0.5, 1, 2, 5}）的某些取值下可能 < 1；分层版本恒为 1（来源：硬约束的结构性保证，**【待实测】**）」；「人为自由参数由 2 个降为 1 个」。
- **增益上界**：由于必做集合是硬的，清除比例的**下界**由"是否能在墙钟内跑完 M(t)"决定，而不是由权重决定；这使"确保"从**概率性**变成**结构性**。

### ⑥ 如何通过实验验证创新有效
- **对照实验**：A 组 = 固定 λ 扫描 5 档（λ ∈ {0.1, 0.5, 1, 2, 5}，μ 固定）；B 组 = 分层 + δ。同批演练案例（源数 10/13/16 各 10 组），指标 = **清除比例**、平均定位清除时间、虚拟时间。
  - **预期可观测的对照结果**：A 组在 λ 较大的档位上出现"清除比例 < 1"的案例，B 组恒为 1。**【待实测】**
- **消融实验**：δ = 0（永远做可选动作，等价于纯探索）与 δ = ∞（从不做可选动作，等价于纯必做）两端，观察"清除比例—δ"与"时间—δ"两条曲线。
- **独立验证**：用**约束回代**（硬检验）作为与被测指标原理不同的路径 —— 每次测试结束后逐条检查"G 是否为空""∀c: B_c 是否为空""每个必做动作是否都执行过"，输出"满足/不满足"表（知识库 §7.4 推荐的"零争议"验证）。
- **边界实验**：δ 的标定依赖行程时间方差；给出"**δ 与清除比例的曲线**"，找出使清除比例恒为 1 的**最小 δ**，并报告该最小 δ 对行程时间标准差（±20%）的敏感性。若最小 δ 超过可用时间的 30%，说明本策略在该案例规模下不可行，必须降级为"只做必做动作"。
- **可复现性**：δ 写死在配置中；离线仿真固定种子并报 30 次重复的均值 ± 标准差。

### 四句式小结
- **困难句**：L2-A 依赖 λ、μ 两个人为权重，而"人为调参一旦进入目标函数就无法自证"；更要命的是收割期的大 λ 可能导致"为省移动而漏扫覆盖缺口"，直接违反"确保全部清除"。
- **动作句**：把"必须保证"从目标函数的惩罚项提升为硬约束必做集合 M(t)，删除 λ、μ，只保留一个可标定的安全缓冲 δ，并给出探索—收割的切换时刻 t_switch。
- **增益句**：人为自由参数由 2 个降为 1 个；"漏扫缺口"这一致命风险被结构性消除，清除比例从"依赖权重取值"变为"由硬约束保证"（**【待实测】**：固定 λ 扫描 5 档 vs 分层 + δ 的对照实验）。
- **边界句**：安全缓冲 δ 依赖行程时间的方差；若实测方差大导致最小 δ 超过可用时间的 30%，本策略不可行，只能退化为纯必做动作的执行器。

## 5. 创新点 I-5（方向 5 · 多目标优化）

### ① 原模型是什么
- **名称与出处**：阶段二采用的**字典序目标**。
- **数学形式**：`lex min ( − k/N ,  T_total / k )`，其中 k 为已清除数（个）、N 为源总数（10—16，未知）、T_total 为虚拟总时间（s）。第一层最大化清除比例，第二层在清除比例不变的前提下最小化平均定位清除时间。
- **阶段二编号与得分**：由题面"在确保所有干扰源被清除的前提下，完成任务的时间越短越好"（阶段一表A-7）确定，属硬约束优先。

### ② 原模型存在什么问题
- **具体困难（含量化）**：
  1. **只给一个解，答不了"时间不够怎么办"**。题面明确"程序运行时间最长 20 分钟"，且 `/enter` 返回的 `remaining_real_duration_s` **可能小于 1200**（附件 2 §6.2），加上 25 分钟窗口的夹逼 ⇒ 实际可用时间是一个**区间**而不是常数。字典序不说在可用时间只有 600 s 时该怎么办。
  2. **没有"主动牺牲"的机制**。知识库的反面教材（2011B-1）已经证明：以平均为目标的模型会把少量远点**隐性牺牲**掉而不自知（N04 第 1928 行）。字典序虽然避免了这一点，但它同样没有给出"若不得不牺牲，按什么顺序牺牲"的显式规则 —— 结果是**被动挨掐**（到点被强制退出，清除比例不确定）。
  3. **无法在测试前做风险决策**：队伍无法根据 `/enter` 返回的剩余时间选择一个"有下界保证"的完成率。
- **证据**：题面附录 3 与附件 2 §4.5/§6.2；知识库 N04 第 1928、1970 行。
- **为什么调参解决不了**：这不是权重问题，而是**解集的结构**问题 —— 字典序的解集是**一个点**，要回答"时间不够怎么办"必须给出**一条曲线**。

### ③ 本文如何改进
- **结构性改动**：把字典序**扩展为 ε-约束的参数族**，并画出"**完成率—时间前沿**"：
  - 主问题改为 `min T_total  s.t.  k ≥ (1 − ε)·N`，ε ∈ {0, 1/16, 2/16, 3/16, 4/16}；
  - **ε = 0 时，ε-约束解恒等于字典序解** —— 这就是准入条件要求的"可退化复现"；
  - 每个 ε 对应一个策略，扫出前沿；
  - 增加**显式的牺牲排序准则**：在 ε > 0 时，被放弃的目标按"**单位时间代价**"降序排列，即
    `ρ_i = ΔT(保留目标 i) / 1 个目标`，优先牺牲 ρ_i 最大者。
    —— 这与"按距离牺牲"不同：距离最远的目标未必是最不值得保留的（可能顺路）。
- **接口变化**：原方案给外部一个"解"；新方案给外部一个"**解族 + 一张前沿图 + 一条选择规则**"，队伍可在 `/enter` 返回实际可用时间后现场选 ε。

### ④ 数学表达是什么
- **符号**：x 为策略；k(x) 为清除数；N 为源数（已知区间 [10,16]）；T(x) 为虚拟总时间；ε 为允许的未完成比例；ρ_i 为保留目标 i 的边际时间代价率（s/个）。
- **主问题（ε-约束形式）**：
  `min_x T(x)   s.t.   k(x) ≥ (1 − ε)·N`
- **前沿**：`ℱ = { ( k*_j / N , T*_j / k*_j ) }_{j}`，其中 T*_j 为 ε_j 对应的最优总时间。
- **牺牲排序**：`ρ_i = [ T(x | 保留 i) − T(x | 放弃 i) ] / 1`，按 ρ_i 降序放弃。
- **与"原模型"的逐项对应**：
  - **替换**：目标由"两层的字典序"替换为"单层 + ε 参数化约束"；
  - **新增**：前沿 ℱ 与牺牲排序 ρ_i；
  - **保留**：ε = 0 时与字典序**完全一致**（退化对标）。
- **在线实现**：由于本题是在线问题，前沿不能离线算完；采用**滚动重优化**：每次决策时按当前 ε 与剩余时间重新解一次"保留哪些目标"，并对已放弃集合做单调化（一旦放弃不得反悔，避免抖动）。
- **复杂度**：每次重优化在 |候选目标| ≤ 16 上做一次排序与贪心，O(16 log 16)，毫秒级。

### ⑤ 改进后解决了什么问题
- **对应 ② 的哪一个困难**：一一对应 ——
  ① "答不了时间不够" → 前沿给出"完成率 ≥ 1−ε 所需的最小时间"；
  ② "没有主动牺牲机制" → ρ_i 给出显式的牺牲顺序，且**不是**按距离（避免知识库记录的"牺牲远点"教训）；
  ③ "测试前无法做风险决策" → 队伍可在 `/enter` 返回实际剩余时间后选 ε。
- **量化增益**：
  - 「完成率下界：ε = 0 时为 1（字典序）；ε = 1/16 时为 15/16，对应时间上界**【待实测】**」；
  - **风险控制收益（主收益）**：把"到点被掐断、完成率未知"变成"主动选 ε、完成率有下界"。在人为限制墙钟的对照实验中（可用时间限制为 400/600/800/1200 s），比较"硬性字典序"与"按前沿选 ε"两种用法的实际 (完成率, 平均时间)。**【待实测】**
- **增益上界**：前沿的**左端点**（ε = 0）即字典序解，因此本创新点**不会让性能变差**，只是把解集从一点扩展为一条曲线。

### ⑥ 如何通过实验验证创新有效
- **对照实验**：人为限制可用程序运行时间为 {400, 600, 800, 1200} s 四档，每档跑同一批演练案例，比较 A 组（始终 ε = 0）与 B 组（按前沿选 ε）的实际完成率与平均时间。
- **消融实验**：把牺牲排序从"按单位时间代价 ρ_i"换成"按距离降序"，其余不变 ⇒ 比较完成率差，用以证明"**牺牲顺序本身有讲究**"，而不是随便牺牲谁都可以。**【待实测】**
- **独立验证（双路径生成前沿）**：前沿必须由**两条原理不同的路径**生成——① ε-约束的分层求解；② 加权和法扫描权重 ω 并取非支配点（这是知识库 §7.1 推荐的做法）。两条曲线应重合（相对误差 ≤5%）；若重合，说明前沿可信；若不重合，说明在线重优化有不一致，必须排查。
- **边界实验**：当墙钟充裕（≥1200 s）时，前沿应退化为一个点（ε = 0 最优）；给出"**墙钟阈值**"，低于该阈值时选 ε > 0 才有意义。同时报告该阈值对源数 N ∈ {10, 13, 16} 的敏感性。
- **可复现性**：ε 的取值集合与牺牲排序规则写死在配置中；离线仿真固定种子，报 30 次重复。

### 四句式小结
- **困难句**：字典序只给一个解，而实际可用程序运行时间由 `/enter` 返回、可能低于 1200 s，字典序说不出"只剩 600 s 时该怎么办"；也没有显式的牺牲顺序，只能被动挨掐。
- **动作句**：把字典序扩展为 ε-约束参数族（ε ∈ {0, 1/16, …, 4/16}），扫出"完成率—时间前沿"，并给出按**单位时间代价**降序的牺牲排序；ε = 0 时严格退化为字典序解。
- **增益句**：解集由一点扩展为一条前沿，完成率由"未知"变为"有下界 1−ε"；在人为限制墙钟的对照实验中报告 (完成率, 平均时间) 的差异（**【待实测】**）。
- **边界句**：墙钟充裕（≥1200 s）时前沿退化为一点，ε > 0 无意义；牺牲排序若改成"按距离降序"会牺牲掉顺路的近点，完成率下降（该对照即为本创新点的边界实验）。

```text
                    │  I-3 可行域账本 {B_c}  +  覆盖缺口集 G    │  ← 单一状态对象
                    └───────────────┬──────────────────────────┘
                                    │ 只读写这一个对象
        ┌───────────────────────────┼───────────────────────────┐
        ▼                           ▼                           ▼
  I-1 覆盖缺口驱动路线        I-2 额度分配指数            I-4 分层决策
  （决定"去哪"）              （决定"探哪个频道"）         （决定"什么时候只做必做"）
        └───────────────────────────┼───────────────────────────┘
                                    ▼
                          I-5 ε-约束前沿（决定"完成率目标"）
```

| 关系 | 说明 | 能否单独消融 |
|---|---|---|
| I-3 → I-1 | 路线由缺口集 G 驱动；G 由 I-3 的账本维护 | ✓（关闭 I-1 后 G 仍由账本给出，只是路线退回固定点序） |
| I-3 → I-2 | 指数中的 A_c（可行域可收缩面积）直接来自 B_c | ✓（关闭 I-2 后退回静态优先级） |
| I-3 → I-4 | 必做集合 M(t) 由 G 与 {B_c} 定义 | ✓（关闭 I-4 后回到 λ、μ 打分） |

**依赖检查结论**：五个创新点共享同一个状态对象（I-3 的账本），但**没有一个是另一个的必要条件**——关掉任意一个，其余四个仍能运行，只是行为退化。这满足提示词"每个创新点必须能被单独关掉"的硬约束。
